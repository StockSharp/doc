# Benachrichtigungspanel

Das Panel **Benachrichtigungen** ist eine Tabelle, die Informationen zu allen aktuell eingerichteten Benachrichtigungen anzeigt.

![Terminal Benachrichtigungs-Panel](../../../images/terminal_notifications_panel.png)

Im Panel **Benachrichtigungen** können Sie eine vorhandene Benachrichtigung bearbeiten ![Designer Erstellen eines Repositorys historischer Daten 01](../../../images/designer_creating_repository_of_historical_data_01.png), sie löschen ![Designer Erstellen eines Repositorys historischer Daten 02](../../../images/designer_creating_repository_of_historical_data_02.png) oder eine neue Benachrichtigung einrichten ![Designer Erstellen eines Repositorys historischer Daten 00](../../../images/designer_creating_repository_of_historical_data_00.png).
