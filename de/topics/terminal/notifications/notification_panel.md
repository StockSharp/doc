# Benachrichtigungspanel

Das Panel **Benachrichtigungen** ist eine Tabelle, die Informationen zu allen aktuell eingerichteten Benachrichtigungen anzeigt.

![Terminal Notifications Panel](../../../images/terminal_notifications_panel.png)

Im Panel **Benachrichtigungen** können Sie eine vorhandene Benachrichtigung bearbeiten ![Designer Creating a repository of historical data 01](../../../images/designer_creating_repository_of_historical_data_01.png), sie löschen ![Designer Creating a repository of historical data 02](../../../images/designer_creating_repository_of_historical_data_02.png) oder eine neue Benachrichtigung einrichten ![Designer Creating a repository of historical data 00](../../../images/designer_creating_repository_of_historical_data_00.png).
