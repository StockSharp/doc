# Auf neue Version aktualisieren

Aktualisieren Sie Terminal über StockSharp Installer. Die Aktualisierungsanleitung erklärt die Prüfung verfügbarer Versionen und die Installation von Programmaktualisierungen.

[Apps aktualisieren](../installer/update_apps.md)

Das neue plattformübergreifende Terminal, das zum ersten Mal im Einstellungsordner des bisherigen Terminals gestartet wird, ordnet die Panels so an, wie das bisherige sie hinterlassen hat. Danach speichert es seine Anordnung selbst.
