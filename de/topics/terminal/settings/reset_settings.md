# Einstellungen zurücksetzen

Beim Zurücksetzen der Terminal-Einstellungen können Informationen aus dem Einstellungsverzeichnis gelöscht werden. Lesen Sie vor der Bestätigung die gemeinsame Anleitung, um zu verstehen, welche Daten entfernt werden.

Siehe [Einstellungen zurücksetzen](../../designer/settings/reset_settings.md).
