# Kaufen/Verkaufen

Die Komponente **Kaufen/Verkaufen** ist eine Panelgruppe, die die besten Preisinformationen für die ausgewählten Instrumente anzeigt und es ermöglicht, das benötigte Volumen zu kaufen oder zu verkaufen.

Um ein neues Instrument hinzuzufügen, klicken Sie auf die Schaltfläche ![Designer Creation tool 00](../../../../images/designer_creation_tool_00.png).
