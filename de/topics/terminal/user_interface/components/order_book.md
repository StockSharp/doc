# Orderbuch

Die Komponente **Orderbuch** ist eine Tabelle mit Limit-Orders für Kauf und Verkauf.

Wenn Sie auf die Schaltfläche für die Einstellungen ![Designer Symbolleiste für den Schnellzugriff 02](../../../../images/designer_quick_access_toolbar_02.png) klicken, erscheint ein Panel, in dem Sie das benötigte Instrument und Portfolio festlegen sowie die Anzeigeoptionen des Orderbuchs konfigurieren können.

Orders können entweder über die Schaltflächen **Kaufen/Verkaufen** oder durch Klicken auf die Zellen in den Spalten **Geld/Brief** im Orderbuch selbst registriert werden.
