# Menüband

Das wichtigste Element der Benutzeroberfläche von [Terminal](../../terminal.md) ist das **Menüband**, das sich am oberen Rand des Anwendungsfensters befindet. Über das Menüband können Sie die benötigten Befehle schnell finden. Die Befehle sind in logischen Gruppen angeordnet, die auf Tabs zusammengefasst sind. Um zum benötigten Tab zu wechseln, klicken Sie einfach auf seinen Namen. Jeder Tab ist mit der Art der ausgeführten Aktion verbunden.

Der Tab **Allgemein**, der nach dem Start standardmäßig geöffnet ist, enthält die Elemente, die Sie zu Beginn der Arbeit benötigen können. Im Tab **Allgemein** können Sie [Arbeitsbereich](../../designer/user_interface/workspace.md) hinzufügen oder [Protokolle](../../designer/user_interface/logs.md), [Portfolios](../../designer/user_interface/portfolios.md), [Börsenplätze](../../designer/user_interface/boards.md) öffnen oder [Komponenten](../../designer/user_interface/components.md) hinzufügen. Außerdem können Sie im Tab **Allgemein** das Design von [Terminal](../../terminal.md) auswählen.
