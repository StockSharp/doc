# Identifier \*@ALL

Wenn das Instrument an mehreren Boards gehandelt wird, können Sie als Board-Code "ALL" verwenden. Das Instrument mit dem Bezeichner AAPL@ALL bedeutet beispielsweise, dass Daten von allen Boards für den Ticker AAPL gesammelt werden (AAPL@BATS, AAPL@ICE usw.) und diese Daten außerdem ein gemeinsames Orderbuch haben.

Der Board-Code wird verwendet, um die Order in ein bestimmtes Handelssystem zu senden. Wenn Sie "ALL" angeben, bestimmt der Broker oder die Börse die Orderroute. In diesem Fall entscheidet der Broker oder die Börse selbst, auf welchem Board eine Order am besten ausgeführt wird. Wenn Sie dagegen ein bestimmtes Board wie BATS angeben, wird die Order nur an BATS gesendet.
