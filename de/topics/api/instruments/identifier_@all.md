# Identifier \*@ALL

Wenn das Instrument an mehreren Handelsplätzen gehandelt wird, können Sie als Handelsplatzcode "ALL" verwenden. Das Instrument mit dem Bezeichner AAPL@ALL bedeutet beispielsweise, dass Daten von allen Handelsplätzen für den Ticker AAPL gesammelt werden (AAPL@BATS, AAPL@ICE usw.) und diese Daten außerdem ein gemeinsames Orderbuch haben.

Der Handelsplatzcode wird verwendet, um die Order in ein bestimmtes Handelssystem zu senden. Wenn Sie "ALL" angeben, bestimmt der Broker oder die Börse die Orderroute. In diesem Fall entscheidet der Broker oder die Börse selbst, auf welchem Handelsplatz eine Order am besten ausgeführt wird. Wenn Sie dagegen einen bestimmten Handelsplatz wie BATS angeben, wird die Order nur an BATS gesendet.
