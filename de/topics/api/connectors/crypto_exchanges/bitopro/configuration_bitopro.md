# Connector-Konfiguration: BitoPro

Konfigurieren Sie vor der Verbindung mit BitoPro die folgenden Adaptereigenschaften. Die Liste wurde anhand von [BitoProMessageAdapter](xref:StockSharp.BitoPro.BitoProMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Email` (`string`)
- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
