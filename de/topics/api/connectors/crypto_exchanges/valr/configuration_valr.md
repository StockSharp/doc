# VALR-Connector-Einstellungen

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `Key` - API-Schlüssel.
- `Secret` - Geheimer API-Schlüssel.
- `SubAccountId` - Kennung des Unterkontos.
- `RestEndpoint` - Adresse der REST-API.
- `TradeWebSocketEndpoint` - Adresse des WebSocket-Servers.
- `AccountWebSocketEndpoint` - Adresse des WebSocket-Servers.
