# Connector-Konfiguration: AltCoinTrader

Konfigurieren Sie vor der Verbindung mit AltCoinTrader die folgenden Adaptereigenschaften. Die Liste wurde anhand von [AltCoinTraderMessageAdapter](xref:StockSharp.AltCoinTrader.AltCoinTraderMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
