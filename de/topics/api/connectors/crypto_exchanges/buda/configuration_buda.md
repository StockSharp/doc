# Connector-Konfiguration: Buda

Konfigurieren Sie vor der Verbindung mit Buda die folgenden Adaptereigenschaften. Die Liste wurde anhand von [BudaMessageAdapter](xref:StockSharp.Buda.BudaMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
