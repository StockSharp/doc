# Initialisierung des Amberdata-Adapters

Der folgende Code zeigt, wie man den [AmberdataMessageAdapter](xref:StockSharp.Amberdata.AmberdataMessageAdapter) initialisiert und ihn an den [Connector](xref:StockSharp.Algo.Connector) übergibt.

```cs
Connector Connector = new Connector();
...
var messageAdapter = new AmberdataMessageAdapter(Connector.TransactionIdGenerator)
{
	Token = "<Ihr Wert>".To<SecureString>(),
};
Connector.Adapter.InnerAdapters.Add(messageAdapter);
...
```
