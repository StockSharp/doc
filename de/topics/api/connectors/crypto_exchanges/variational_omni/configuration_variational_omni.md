# Variational Omni-Connector-Einstellungen

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `Endpoint` - API-Endpunkt für Marktdaten.
- `PollingInterval` - Intervall für die Datenabfrage.
