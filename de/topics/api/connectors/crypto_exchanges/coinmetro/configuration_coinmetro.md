# Connector-Konfiguration: Coinmetro

Konfigurieren Sie vor der Verbindung mit Coinmetro die folgenden Adaptereigenschaften. Die Liste wurde anhand von [CoinmetroMessageAdapter](xref:StockSharp.Coinmetro.CoinmetroMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Token` (`SecureString`)
- `IsDemo` (`bool`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `DemoRestEndpoint` (`string`)
- `DemoWebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
