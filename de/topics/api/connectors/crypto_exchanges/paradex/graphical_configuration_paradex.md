# Grafische Konfiguration von Paradex

Für alle [S#](../../../../api.md)-Produkte erfolgt die grafische Konfiguration im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md).

Wichtige Felder:

- **Key** - API-Schlüssel.
- **Secret** - API-Secret.
- **Starknet account** - Header-Wert des Starknet-Kontos.
- **Starknet key** - Material des privaten Starknet-Schlüssels.
- **Section** - Handelsbereich (`Spot` oder `Derivatives`).
- **Enable spot** - aktiviert den Spot-Bereich.
- **Demo** - Demoumgebungsmodus.
- **Spot REST / Derivatives REST** - REST-Endpunkte.
- **Spot WS / Derivatives WS** - Websocket-Endpunkte.
- **Auth path** - Pfad des Authentifizierungsendpunkts.
