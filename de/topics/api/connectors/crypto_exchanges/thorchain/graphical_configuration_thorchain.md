# Grafische Konfiguration von THORChain

Für alle [S#](../../../../api.md)-Produkte erfolgt die grafische Konfiguration der Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md):

- `WalletAddress` - öffentliche Blockchain-Wallet-Adresse für Kontostände und Aufträge.
- `PrivateKey` - privater Schlüssel zum lokalen Signieren von Transaktionen.
- `MidgardEndpoint` - Endpunkt der THORChain-Midgard-API.
- `ThornodeEndpoint` - Endpunkt der THORChain-Thornode-REST-API.
