# Initialisierung des Coin Metrics-Adapters

Der folgende Code zeigt, wie man den [CoinMetricsMessageAdapter](xref:StockSharp.CoinMetrics.CoinMetricsMessageAdapter) initialisiert und ihn an den [Connector](xref:StockSharp.Algo.Connector) übergibt.

```cs
Connector Connector = new Connector();
...
var messageAdapter = new CoinMetricsMessageAdapter(Connector.TransactionIdGenerator)
{
	Token = "<Ihr Wert>".To<SecureString>(),
};
Connector.Adapter.InnerAdapters.Add(messageAdapter);
...
```
