# Grafische Konfiguration von CoinMarketCap

Für alle [S#](../../../../api.md)-Produkte erfolgt die grafische Konfiguration der Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md):

- `AccessMode` - CoinMarketCap-Zugriffsmodus: ohne Schlüssel oder mit API-Schlüssel.
- `Token` - API-Zugriffstoken.
- `ApiEndpoint` - Endpunkt der REST-API.
- `SocketEndpoint` - Endpunkt der WebSocket-API.
- `QuoteCurrency` - Währung für die Notierung der Marktpreise.
- `IsStreamingEnabled` - Echtzeitdaten über WebSocket aktivieren.
