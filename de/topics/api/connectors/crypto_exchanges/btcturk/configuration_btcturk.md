# Connector-Konfiguration: BtcTurk

Konfigurieren Sie vor der Verbindung mit BtcTurk die folgenden Adaptereigenschaften. Die Liste wurde anhand von [BtcTurkMessageAdapter](xref:StockSharp.BtcTurk.BtcTurkMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `GraphEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
