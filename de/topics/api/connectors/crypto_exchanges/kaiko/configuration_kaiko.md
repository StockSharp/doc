# Kaiko-Connector-Einstellungen

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `Token` - API-Zugriffstoken.
- `Region` - regionaler Kaiko-API-Endpunkt.
- `ReferenceEndpoint` - API-Endpunkt für Referenzdaten.
- `MarketEndpoint` - API-Endpunkt für historische Marktdaten.
- `StreamEndpoint` - Endpunkt für Echtzeitmarktdaten.
- `IsStreamingEnabled` - Echtzeitdaten über WebSocket aktivieren.
