# Grafische Konfiguration CoinExchange

Für alle [S#](../../../../api.md)-Produkte erfolgt die grafische Konfiguration der Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md):

![API GUI Settings CoinExchange](../../../../../images/api_gui_settings_coinexchange.png)

- **Key** - Schlüssel.
- **Secret** - Secret.
- **Heart beat** - Intervall der Serverprüfung, um zu überwachen, ob die Verbindung aktiv ist. Standardmäßig 1 Minute.
- **Reconnection settings** - Mechanismus zur Überwachung der Verbindungen entsprechend den Einstellungen des Handelssystems. ([Wiederverbindungseinstellungen](../../reconnection_settings.md))
