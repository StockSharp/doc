# Connector-Konfiguration: WazirX

Konfigurieren Sie vor der Verbindung mit WazirX die folgenden Adaptereigenschaften. Die Liste wurde anhand von [WazirXMessageAdapter](xref:StockSharp.WazirX.WazirXMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `ReceiveWindow` (`long`)
- `PrivatePollingInterval` (`TimeSpan`)
