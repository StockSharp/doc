# Initialisierung des Bullish-Adapters

Der folgende Code zeigt, wie man den [BullishMessageAdapter](xref:StockSharp.Bullish.BullishMessageAdapter) initialisiert und ihn an den [Connector](xref:StockSharp.Algo.Connector) übergibt.

```cs
Connector Connector = new Connector();
...
var messageAdapter = new BullishMessageAdapter(Connector.TransactionIdGenerator)
{
	Key = "<Ihr Wert>".To<SecureString>(),
	Secret = "<Ihr Wert>".To<SecureString>(),
	TradingAccountId = "<Ihr Wert>",
	RateLimitToken = "<Ihr Wert>".To<SecureString>(),
};
Connector.Adapter.InnerAdapters.Add(messageAdapter);
...
```
