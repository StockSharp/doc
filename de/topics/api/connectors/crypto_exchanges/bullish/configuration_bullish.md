# Bullish-Connector-Einstellungen

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `Key` - API-Schlüssel.
- `Secret` - Geheimer API-Schlüssel.
- `TradingAccountId` - Kennung des Handelskontos.
- `RateLimitToken` - Bullish-Token zur Zuordnung der API-Anfragelimits.
- `RestEndpoint` - Adresse der REST-API.
- `WsEndpoint` - Adresse des WebSocket-Servers.
