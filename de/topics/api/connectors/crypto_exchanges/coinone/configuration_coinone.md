# Coinone-Connector-Einstellungen

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `Key` - API-Schlüssel.
- `Secret` - Geheimer API-Schlüssel.
- `QuoteCurrency` - Notierungswährung für die Marktabfrage.
- `RestEndpoint` - Adresse der REST-API.
- `PublicWebSocketEndpoint` - Adresse des WebSocket-Servers.
- `PrivateWebSocketEndpoint` - Adresse des WebSocket-Servers.
