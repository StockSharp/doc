# Grafische Konfiguration von ApeX Omni

Für alle [S#](../../../../api.md)-Produkte erfolgt die grafische Konfiguration der Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md):

- `Key` - API-Schlüssel.
- `Secret` - API-Geheimnis.
- `Passphrase` - API-Kennwortsatz.
- `Seeds` - zkLink-Seed zum Signieren von Aufträgen.
- `Environment` - Verbindungsumgebung: Produktions- oder Testnetzwerk.
- `RestEndpoint` - Endpunkt der REST-API.
- `WebSocketEndpoint` - Endpunkt der WebSocket-API.
- `MarketDepth` - Anzahl der angeforderten Orderbuchtiefen.
