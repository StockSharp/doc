# Grafische Konfiguration von Orderly Network

Für alle [S#](../../../../api.md)-Produkte erfolgt die grafische Konfiguration der Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md):

- `AccountId` - Kennung des Handelskontos.
- `Secret` - API-Geheimnis.
- `RestEndpoint` - Endpunkt der REST-API.
- `PublicWebSocketEndpoint` - öffentlicher WebSocket-Endpunkt für Marktdaten.
