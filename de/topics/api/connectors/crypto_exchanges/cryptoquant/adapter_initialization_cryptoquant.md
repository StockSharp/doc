# Initialisierung des CryptoQuant-Adapters

Der folgende Code zeigt, wie man den [CryptoQuantMessageAdapter](xref:StockSharp.CryptoQuant.CryptoQuantMessageAdapter) initialisiert und ihn an den [Connector](xref:StockSharp.Algo.Connector) übergibt.

```cs
Connector Connector = new Connector();
...
var messageAdapter = new CryptoQuantMessageAdapter(Connector.TransactionIdGenerator)
{
	Token = "<Ihr Wert>".To<SecureString>(),
};
Connector.Adapter.InnerAdapters.Add(messageAdapter);
...
```
