# Grafische Konfiguration von GRVT

Für alle [S#](../../../../api.md)-Produkte erfolgt die grafische Konfiguration der Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md):

- `Key` - API-Schlüssel für die Authentifizierung.
- `Secret` - API-Geheimnis für die Authentifizierung.
- `SubAccountId` - Kennung des Handelsunterkontos.
- `Environment` - Dienstumgebung: Produktions- oder Testnetzwerk.
- `EdgeEndpoint` - API-Endpunkt für die Authentifizierung.
- `MarketDataEndpoint` - API-Endpunkt für Marktdaten.
- `TradingEndpoint` - API-Endpunkt für den Handel.
- `MarketWebSocketEndpoint` - WebSocket-Endpunkt für Marktdaten.
- `TradingWebSocketEndpoint` - WebSocket-Endpunkt für den Handel.
- `SnapshotInterval` - Intervall der Marktdatenschnappschüsse in Millisekunden.
- `MarketDepth` - Anzahl der angeforderten Orderbuchtiefen.
