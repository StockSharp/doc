# Connector-Konfiguration: zondacrypto

Konfigurieren Sie vor der Verbindung mit zondacrypto die folgenden Adaptereigenschaften. Die Liste wurde anhand von [ZondaCryptoMessageAdapter](xref:StockSharp.ZondaCrypto.ZondaCryptoMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
