# Konfiguration Hyperliquid

Für die Arbeit mit dem Connector geben Sie Trading-Anmeldedaten auf Wallet-Ebene an.

Haupteinstellungen:

- **Wallet address**.
- **Private key**.
- **Vault address** (optional).
- **Expires after** (optional).
- **Section**: `Spot` oder `Derivatives`.
- **Testnet**-Modus.
- **Info endpoint / Exchange endpoint / WS endpoint**.
- **Market slippage** für Market-Orders.
