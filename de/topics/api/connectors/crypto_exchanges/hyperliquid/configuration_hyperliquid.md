# Konfiguration Hyperliquid

Für die Arbeit mit dem Connector geben Sie Trading-Anmeldedaten auf Wallet-Ebene an.

Haupteinstellungen:

 - **Wallet-Adresse**.
 - **Privater Schlüssel**.
 - **Vault-Adresse** (optional).
 - **Ablaufzeit** (optional).
- **Section**: `Spot` oder `Derivatives`.
- **Testnet**-Modus.
 - **Info-Endpunkt / Exchange-Endpunkt / WS-Endpunkt**.
- **Markt-Slippage** für Market-Orders.
