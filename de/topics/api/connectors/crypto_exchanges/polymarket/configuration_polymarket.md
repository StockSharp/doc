# Polymarket-Connector-Einstellungen

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `ApiKey` - API-Schlüssel.
- `ApiSecret` - API-Geheimnis.
- `Passphrase` - API-Kennwortsatz.
- `SignerAddress` - Adresse, die Aufträge signiert.
- `FunderAddress` - Adresse zur Finanzierung des Handelskontos.
- `PrivateKey` - privater Schlüssel zum lokalen Signieren von Anfragen und Transaktionen.
- `SignatureType` - Signaturverfahren für Aufträge.
