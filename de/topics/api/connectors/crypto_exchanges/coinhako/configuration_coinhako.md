# Coinhako-Connector-Einstellungen

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `Key` - API-Schlüssel.
- `Secret` - Geheimer API-Schlüssel.
- `RestEndpoint` - Adresse der REST-API.
- `CounterCurrencies` - Notierungswährungen, für die Märkte abgefragt werden.
- `PollingInterval` - Intervall zwischen den Abfragen des Dienstes.
