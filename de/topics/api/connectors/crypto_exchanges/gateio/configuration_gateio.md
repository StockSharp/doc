# Connector-Einstellungen Gate.io

Für die Arbeit mit dem Connector müssen im persönlichen Konto der Börse ein **API Key** und ein **Secret** generiert und anschließend bei der Einrichtung der Verbindung angegeben werden.

> [!TIP]
> Beachten Sie, dass **API Key and Secret** nicht **Login and Password** sind. **API Key and Secret** werden separat im persönlichen Konto generiert. Login und Password werden für den Connector nicht benötigt und sollten nirgends angegeben werden.
