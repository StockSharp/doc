# Connector-Konfiguration: NovaDAX

Konfigurieren Sie vor der Verbindung mit NovaDAX die folgenden Adaptereigenschaften. Die Liste wurde anhand von [NovaDaxMessageAdapter](xref:StockSharp.NovaDax.NovaDaxMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `AccountId` (`string`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `EngineIoVersion` (`int`)
