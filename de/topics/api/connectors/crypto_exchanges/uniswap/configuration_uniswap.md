# Uniswap-Connector-Einstellungen

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `Token` - API-Zugriffstoken.
- `GraphApiKey` - API-Schlüssel für The Graph.
- `WalletAddress` - Adresse der Blockchain-Geldbörse.
- `PrivateKey` - Privater Schlüssel zum Signieren von Transaktionen.
- `Chain` - Blockchain-Netzwerk für die Anfragen.
- `RouterVersion` - Version des Routers der dezentralen Börse.
- `RpcEndpoint` - RPC-Endpunkt des Blockchain-Netzwerks.
- `TradingEndpoint` - Endpunkt der Handels-API.
