# Connector-Konfiguration: Delta Exchange India

Konfigurieren Sie vor der Verbindung mit Delta Exchange India die folgenden Adaptereigenschaften. Die Liste wurde anhand von [DeltaExchangeIndiaMessageAdapter](xref:StockSharp.DeltaExchangeIndia.DeltaExchangeIndiaMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `PublicWebSocketEndpoint` (`string`)
- `PrivateWebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
