# Anchorage-Connector-Einstellungen

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `Environment` - Verbindungsumgebung: Produktion, Demo oder Test.
- `ApiKey` - API-Schlüssel.
- `SigningKey` - privater Schlüssel zum Signieren von API-Anfragen.
- `ApiEndpoint` - Endpunkt der REST-API.
- `SocketEndpoint` - Endpunkt der WebSocket-API.
