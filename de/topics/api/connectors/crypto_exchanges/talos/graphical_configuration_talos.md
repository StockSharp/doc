# Grafische Konfiguration von Talos

Für alle [S#](../../../../api.md)-Produkte erfolgt die grafische Konfiguration der Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md):

- `Address` - von Talos bereitgestellte Adresse und Port des FIX-Servers.
- `SenderCompId` - FIX-Absenderkennung.
- `TargetCompId` - FIX-Empfängerkennung.
- `Login` - Anmeldename der FIX-Sitzung.
- `Password` - Passwort der FIX-Sitzung.
- `ClientCode` - Kundencode für die Kontoweiterleitung.
- `TargetHost` - Hostname im TLS-Zertifikat.
