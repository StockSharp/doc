# Pyth-Connector-Einstellungen

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `Token` - API-Zugriffstoken.
- `HistoryEndpoint` - API-Endpunkt für historische Daten.
- `RouterEndpoint` - REST-API-Endpunkt für aktuelle Preise.
- `WebSocketEndpoint1` - primärer WebSocket-Endpunkt für Echtzeitdaten.
- `WebSocketEndpoint2` - sekundärer WebSocket-Endpunkt für Echtzeitdaten.
- `WebSocketEndpoint3` - dritter WebSocket-Endpunkt für Echtzeitdaten.
- `Channel` - Pyth-Datenkanal.
