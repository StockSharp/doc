# Grafische Konfiguration von BTSE

Für alle [S#](../../../../api.md)-Produkte erfolgt die grafische Konfiguration der Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md):

- `Key` - API-Schlüssel.
- `Secret` - Geheimer API-Schlüssel.
- `SpotRestEndpoint` - Adresse der REST-API.
- `SpotWebSocketEndpoint` - Adresse des WebSocket-Servers.
- `SpotOrderBookWebSocketEndpoint` - Adresse des WebSocket-Servers.
- `FuturesRestEndpoint` - Adresse der REST-API.
- `FuturesWebSocketEndpoint` - Adresse des WebSocket-Servers.
- `FuturesOrderBookWebSocketEndpoint` - Adresse des WebSocket-Servers.
