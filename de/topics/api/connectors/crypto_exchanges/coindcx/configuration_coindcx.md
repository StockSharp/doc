# CoinDCX-Connector-Einstellungen

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `Key` - API-Schlüssel.
- `Secret` - Geheimer API-Schlüssel.
- `RestEndpoint` - Adresse der REST-API.
- `PublicRestEndpoint` - Adresse der REST-API.
- `WebSocketEndpoint` - Adresse des WebSocket-Servers.
