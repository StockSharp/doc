# Connector-Konfiguration: Quidax

Konfigurieren Sie vor der Verbindung mit Quidax die folgenden Adaptereigenschaften. Die Liste wurde anhand von [QuidaxMessageAdapter](xref:StockSharp.Quidax.QuidaxMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Token` (`SecureString`)
- `UserId` (`string`)
- `RestEndpoint` (`string`)
- `PollingInterval` (`TimeSpan`)
