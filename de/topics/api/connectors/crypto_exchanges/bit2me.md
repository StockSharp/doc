# Bit2Me

**Bit2Me** ist ein Konnektor für die Kryptowährungs-Spotbörse Bit2Me Pro. Er unterstützt öffentliche Marktdaten, historische Kerzen, Kontosalden und Handelsoperationen über REST- und WebSocket-APIs.

Lesen Sie vor der Entwicklung von Handelsrobotern den Abschnitt [Konnektoren](../../connectors.md).
