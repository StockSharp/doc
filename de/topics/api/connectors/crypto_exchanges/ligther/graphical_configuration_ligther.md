# Grafische Konfiguration Ligther

Für alle [S#](../../../../api.md)-Produkte erfolgt die grafische Konfiguration im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md).

Hauptfelder:

- **Key** - API-Schlüssel.
- **Secret** - API-Secret.
- **Account index** - Kontoindex.
- **API key index** - API-Schlüsselindex.
- **Section** - Handelssektion (`Spot` oder `Derivatives`).
- **Demo** - Modus für die Demo-Umgebung.
- **Spot REST / Derivatives REST** - REST-Endpunkte.
- **Spot WS / Derivatives WS** - Websocket-Endpunkte.
- **WS read-only mode** - Flag für den schreibgeschützten Websocket-Modus.
