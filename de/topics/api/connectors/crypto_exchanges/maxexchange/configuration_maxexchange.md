# Connector-Konfiguration: MAX Exchange

Konfigurieren Sie vor der Verbindung mit MAX Exchange die folgenden Adaptereigenschaften. Die Liste wurde anhand von [MaxExchangeMessageAdapter](xref:StockSharp.MaxExchange.MaxExchangeMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
