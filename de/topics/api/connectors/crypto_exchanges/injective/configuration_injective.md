# Injective-Connector-Einstellungen

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `Environment` - Verbindungsumgebung: Produktions- oder Testnetzwerk.
- `WalletAddress` - öffentliche Blockchain-Wallet-Adresse für Kontovorgänge.
- `PrivateKey` - privater Schlüssel zum lokalen Signieren von Anfragen und Transaktionen.
