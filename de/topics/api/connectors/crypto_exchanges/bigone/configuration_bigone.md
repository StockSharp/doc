# Connector-Konfiguration: BigONE

Konfigurieren Sie vor der Verbindung mit BigONE die folgenden Adaptereigenschaften. Die Liste wurde anhand von [BigOneMessageAdapter](xref:StockSharp.BigOne.BigOneMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `SpotRestEndpoint` (`string`)
- `SpotWebSocketEndpoint` (`string`)
- `ContractRestEndpoint` (`string`)
- `ContractWebSocketEndpoint` (`string`)
- `ContractPrivateWebSocketEndpoint` (`string`)
