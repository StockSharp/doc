# Grafische Konfiguration: Tokocrypto

Konfigurieren Sie die Verbindung in allen StockSharp-Produkten im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md).

Der Grundbereich des Verbindungseditors enthält:

- `Key`
- `Secret`
- `AccountRestEndpoint`
- `MarketDataRestEndpoint`
- `WebSocketEndpoint`

Alle adapterspezifischen Eigenschaften sind oben aufgeführt. Ändern Sie vorgegebene Anbieteradressen nur, wenn der Anbieter andere Werte zugewiesen hat.
