# LFJ-Connector-Einstellungen

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `WalletAddress` - öffentliche Blockchain-Wallet-Adresse für Kontostände und Aufträge.
- `PrivateKey` - privater Schlüssel zum lokalen Signieren von Transaktionen.
- `RpcEndpoint` - RPC-Endpunkt der Blockchain.
- `WebSocketEndpoint` - WebSocket-Endpunkt der Blockchain.
