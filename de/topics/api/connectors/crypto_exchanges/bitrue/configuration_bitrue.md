# Bitrue-Connector-Einstellungen

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `Key` - API-Schlüssel.
- `Secret` - Geheimer API-Schlüssel.
- `SpotRestEndpoint` - Adresse der REST-API.
- `SpotStreamRestEndpoint` - Adresse der REST-API.
- `SpotPublicWsEndpoint` - Adresse des WebSocket-Servers.
- `SpotPrivateWsEndpoint` - Adresse des WebSocket-Servers.
- `FuturesRestEndpoint` - Adresse der REST-API.
- `FuturesStreamRestEndpoint` - Adresse der REST-API.
- `FuturesPublicWsEndpoint` - Adresse des WebSocket-Servers.
- `FuturesPrivateWsEndpoint` - Adresse des WebSocket-Servers.
