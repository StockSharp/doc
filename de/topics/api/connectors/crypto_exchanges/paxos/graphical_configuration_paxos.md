# Grafische Konfiguration von Paxos

Für alle [S#](../../../../api.md)-Produkte erfolgt die grafische Konfiguration der Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md):

- `Environment` - Verbindungsumgebung: Produktion, Demo oder Test.
- `ClientId` - OAuth-Clientkennung.
- `ClientSecret` - OAuth-Clientgeheimnis.
- `ApiEndpoint` - Endpunkt der REST-API.
- `OAuthEndpoint` - OAuth-Token-Endpunkt.
- `SocketEndpoint` - Endpunkt der WebSocket-API.
