# Connector-Konfiguration: CoinTR

Konfigurieren Sie vor der Verbindung mit CoinTR die folgenden Adaptereigenschaften. Die Liste wurde anhand von [CoinTRMessageAdapter](xref:StockSharp.CoinTR.CoinTRMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `Passphrase` (`SecureString`)
- `RestEndpoint` (`string`)
- `PublicWebSocketEndpoint` (`string`)
- `PrivateWebSocketEndpoint` (`string`)
