# Initialisierung des CoinJar-Adapters

Der folgende Code zeigt, wie man den [CoinJarMessageAdapter](xref:StockSharp.CoinJar.CoinJarMessageAdapter) initialisiert und ihn an den [Connector](xref:StockSharp.Algo.Connector) übergibt.

```cs
Connector Connector = new Connector();
...
var messageAdapter = new CoinJarMessageAdapter(Connector.TransactionIdGenerator)
{
	Token = "<Ihr Wert>".To<SecureString>(),
};
Connector.Adapter.InnerAdapters.Add(messageAdapter);
...
```
