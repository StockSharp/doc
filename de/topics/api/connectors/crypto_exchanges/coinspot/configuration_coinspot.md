# Connector-Konfiguration: CoinSpot

Konfigurieren Sie vor der Verbindung mit CoinSpot die folgenden Adaptereigenschaften. Die Liste wurde anhand von [CoinSpotMessageAdapter](xref:StockSharp.CoinSpot.CoinSpotMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `PublicEndpoint` (`string`)
- `TradingEndpoint` (`string`)
- `ReadOnlyEndpoint` (`string`)
- `PollingInterval` (`TimeSpan`)
