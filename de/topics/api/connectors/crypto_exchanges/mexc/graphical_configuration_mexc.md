# Grafische Konfiguration von MEXC

Für alle [S#](../../../../api.md)-Produkte erfolgt die grafische Konfiguration der Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md):

![API-GUI-Einstellungen MEXC](../../../../../images/api_gui_settings_mexc.png)

- **Schlüssel** - Schlüssel.
- **Geheimnis** - Geheimer Schlüssel.
- **Demo** - Demomodus.
- **Einstellungen für die Wiederverbindung** - Parameter des Mechanismus zur Wiederverbindung mit dem Handelssystem ([Einstellungen für die Wiederverbindung](../../reconnection_settings.md)).
