# Grafische Konfiguration von Bit2Me

In allen [S#](../../../../api.md)-Produkten erfolgt die grafische Konfiguration im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md):

- `Key` — Bit2Me-API-Schlüssel für private Operationen.
- `Secret` — Bit2Me-API-Secret.
- `RestEndpoint` — REST-API-Adresse.
- `WebSocketEndpoint` — WebSocket-Adresse.

Lassen Sie `Key` und `Secret` leer, wenn nur öffentliche Marktdaten benötigt werden. Für Handel und Kontodaten müssen beide Werte gesetzt sein.
