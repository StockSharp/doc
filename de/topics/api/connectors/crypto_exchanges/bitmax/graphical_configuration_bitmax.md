# Grafische Konfiguration BitMax

Für alle [S#](../../../../api.md)-Produkte wird die grafische Konfiguration der Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md) durchgeführt:

![API GUI Settings BitMax](../../../../../images/api_gui_settings_bitmax.png)

- **Key** - Key.
- **Secret** - Secret.
- **Balance** - Intervall für die Prüfung des Kontostands. Erforderlich bei Ein- und Auszahlungsvorgängen.
- **Heart beat** - Intervall für die Serverprüfung, um zu verfolgen, dass die Verbindung aktiv ist. Standardmäßig gleich 1 Minute.
- **Reconnection settings** - Mechanismus zur Verfolgung von Verbindungen mit den Einstellungen des Handelssystems. ([Einstellungen für die Wiederverbindung](../../reconnection_settings.md))
