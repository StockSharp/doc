# Chainlink Data Streams-Connector-Einstellungen

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `Key` - API-Schlüssel.
- `Secret` - API-Geheimnis.
- `RestEndpoint` - Endpunkt der REST-API.
- `WebSocketEndpoint` - Endpunkt der WebSocket-API.
