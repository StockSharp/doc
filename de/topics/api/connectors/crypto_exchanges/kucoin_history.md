# Kucoin-Verlauf

**Kucoin-Verlauf** - öffentlicher Dienst für historische Marktdaten von Kucoin.

Bevor Sie mit dem Schreiben von Handelsrobotern für diese Handelsplattform beginnen, empfehlen wir Ihnen, die Links im Abschnitt [Konnektoren](../../connectors.md) zu lesen.

> [!CAUTION]
> Der Connector unterstützt ausschließlich Marktdaten; Transaktionen werden nicht unterstützt.
