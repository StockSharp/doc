# Connector-Konfiguration: Coinstore

Konfigurieren Sie vor der Verbindung mit Coinstore die folgenden Adaptereigenschaften. Die Liste wurde anhand von [CoinstoreMessageAdapter](xref:StockSharp.Coinstore.CoinstoreMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
