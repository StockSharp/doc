# Grafische Konfiguration: Finam Trade API

Konfigurieren Sie die Verbindung in allen StockSharp-Produkten im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md).

Der Grundbereich des Verbindungseditors enthält:

- `Token`
- `AccountId`

In der erweiterten Ansicht lassen sich `AppId`, `PollingInterval`, `LookupLimit`, `RestAddress` und `WebSocketAddress` einstellen. Bedeutung und Standardwert der Felder finden Sie auf der Seite [Connector-Konfiguration](configuration_finam_trade.md).

Es ist kein konnektorspezifischer Screenshot enthalten, da der Quellcode des Finam-Trade-Konnektors keinen echten Produkt-Screenshot enthält. Verwenden Sie die obige Feldliste und das standardmäßige Fenster für Verbindungseinstellungen.
