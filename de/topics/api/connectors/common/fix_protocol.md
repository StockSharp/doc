# FIX-Protokoll

Das **FIX**-Protokoll ermöglicht die Erstellung von Handelsrobotern, die das internationale Standardprotokoll für den Zugriff auf elektronische Märkte verwenden: [FIX](https://en.wikipedia.org/wiki/Financial_Information_eXchange).
