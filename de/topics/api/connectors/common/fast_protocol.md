# FAST-Protokoll

Das **FAST**-Protokoll ermöglicht die Erstellung von Handelsrobotern, die das internationale Standardprotokoll für den Zugriff auf elektronische Märkte verwenden: [FAST](https://en.wikipedia.org/wiki/FAST_protocol).
