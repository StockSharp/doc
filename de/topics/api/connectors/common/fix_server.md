# FIX-Server

Mit [FixServer](xref:StockSharp.Server.Fix.FixServer) können Sie eigene FIX-Server erstellen, die die internationalen Protokolle [FIX](https://en.wikipedia.org/wiki/Financial_Information_eXchange)\/[FAST](https://en.wikipedia.org/wiki/FAST_protocol) verwenden. Er verwendet FIX 4.4 für Transaktionen und FAST für Marktdaten. Das Serverschema ist in der folgenden Abbildung dargestellt:
