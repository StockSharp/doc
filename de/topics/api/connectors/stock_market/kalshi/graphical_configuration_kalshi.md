# Grafische Konfiguration von Kalshi

Für alle [S#](../../../../api.md)-Produkte erfolgt die grafische Konfiguration der Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md):

- `ApiKey` - API-Schlüssel.
- `PrivateKey` - privater Schlüssel zum lokalen Signieren von Anfragen und Transaktionen.
- `IsDemo` - Kalshi-Demoumgebung verwenden.
- `Subaccount` - Kalshi-Unterkontonummer von 0 bis 63.
