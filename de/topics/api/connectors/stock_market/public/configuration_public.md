# Konfiguration des Public.com-Konnektors

Beschaffen Sie die für Public.com-API erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **Token** - Eigenschaft `Token`.
- **Abfrageintervall** - Eigenschaft `PollingInterval`. Standardwert: `2 s`.
