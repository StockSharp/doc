# Connector-Konfiguration: Capital.com

Beziehen Sie die Zugangsdaten vom Anbieter und geben Sie die Verbindungsparameter an.

- `ApiKey` - Zugangsdaten für die Authentifizierung.
- `Login` - Konto- oder Clientkennung.
- `Password` - Zugangsdaten für die Authentifizierung.
- `AccountId` - Konto- oder Clientkennung.
- `IsDemo` - Schalter für das Verhalten des Konnektors. Standardwert: `true`.
- `IsPasswordEncryptionEnabled` - Schalter für das Verhalten des Konnektors.
