# Konfiguration ITCH

Um mit dem Connector zu arbeiten, muessen Sie **Login** und **Password** angeben. **Login** und **Password** werden vom Broker bereitgestellt. Fuer den API-Zugriff wird empfohlen, den Broker zu kontaktieren.

[ITCH](../itch.md) - direktes Datenfeed-Protokoll, das Verbindungen ueber TCP- und UDP-Protokolle ermoeglicht. [ITCH](../itch.md) stellt das Orderlog bereit, um alle Aenderungen an einer Order zu verfolgen. Dieses Protokoll wird von NASDAQ (siehe [TotalView-ITCH](https://www.nasdaqtrader.com/Trader.aspx?id=Totalview2) ) und LSE (siehe [MITCH](https://www.londonstockexchange.com/) ) verwendet.
