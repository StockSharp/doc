# Konfiguration ITCH

Um mit dem Connector zu arbeiten, müssen Sie **Benutzername** und **Passwort** angeben. **Benutzername** und **Passwort** werden vom Broker bereitgestellt. Für den API-Zugriff wird empfohlen, den Broker zu kontaktieren.

[ITCH](../itch.md) - direktes Datenfeed-Protokoll, das Verbindungen über TCP- und UDP-Protokolle ermöglicht. [ITCH](../itch.md) stellt das Orderlog bereit, um alle Änderungen an einer Order zu verfolgen. Dieses Protokoll wird von NASDAQ (siehe [TotalView-ITCH](https://www.nasdaqtrader.com/Trader.aspx?id=Totalview2) ) und LSE (siehe [MITCH](https://www.londonstockexchange.com/) ) verwendet.
