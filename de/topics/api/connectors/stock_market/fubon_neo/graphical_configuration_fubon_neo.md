# Grafische Konfiguration: Fubon Neo

In allen StockSharp-Produkten wird die Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md) konfiguriert.

- `SdkPath` - Pfad zu einer lokalen Datei oder einem Verzeichnis.
- `PersonalId` - Konto- oder Clientkennung.
- `Password` - Zugangsdaten für die Authentifizierung.
- `ApiKey` - Zugangsdaten für die Authentifizierung.
- `IsApiKeyLogin` - Schalter für das Verhalten des Konnektors.
- `CertificatePath` - Pfad zu einer lokalen Datei oder einem Verzeichnis.
- `CertificatePassword` - Zugangsdaten für die Authentifizierung.
- `EnvironmentUrl` - Adresse des Dienstes.
- `RealtimeMode` - Betriebsart oder Option des Konnektors. Standardwert: `FubonNeoRealtimeModes.Normal`.
- `ReconnectAttempts` - Maximale Anzahl der Wiederverbindungsversuche. Standardwert: `10`.
