# Konfiguration Dow Jones

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `AuthenticationMode` - Authentifizierungsmethode.
- `Token` - API-Zugriffstoken.
- `ClientId` - OAuth-Clientkennung.
- `Login` - Anmeldename des Kontos.
- `Password` - Kontokennwort.
- `Address` - Adresse der REST-API.
- `OAuthAddress` - Endpunkt des OAuth-Dienstes.
