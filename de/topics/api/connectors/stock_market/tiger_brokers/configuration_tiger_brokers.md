# Konfiguration des Tiger Brokers-Konnektors

Beschaffen Sie die für Tiger Brokers OpenAPI erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **Tiger-Kennung** - Eigenschaft `TigerId`.
- **Konto** - Eigenschaft `Account`.
- **Lizenz** - Eigenschaft `License`. Standardwert: `Singapore`.
- **Privater Schlüssel** - Eigenschaft `PrivateKey`.
- **Token** - Eigenschaft `Token`.
- **Kursberechtigung automatisch übernehmen** - Eigenschaft `AutoGrabPermission`. Standardwert: `true`.
