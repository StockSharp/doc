# Konfiguration des Questrade-Konnektors

Beschaffen Sie die für Questrade API erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **Zugriffstoken** - Eigenschaft `AccessToken`.
- **Aktualisierungstoken** - Eigenschaft `RefreshToken`.
- **API-Server** - Eigenschaft `ApiServer`.
- **Konto** - Eigenschaft `Account`.
