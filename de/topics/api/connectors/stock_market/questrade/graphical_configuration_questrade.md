# Grafische Konfiguration von Questrade

Für alle StockSharp-Produkte wird die Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md) konfiguriert.

- **Zugriffstoken** - Eigenschaft `AccessToken`.
- **Aktualisierungstoken** - Eigenschaft `RefreshToken`.
- **API-Server** - Eigenschaft `ApiServer`.
- **Konto** - Eigenschaft `Account`.
