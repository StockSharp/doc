# Connector-Konfiguration: Groww

Beziehen Sie die Zugangsdaten vom Anbieter und geben Sie die Verbindungsparameter an.

- `AccessToken` - Zugangsdaten für die Authentifizierung.
- `ApiKey` - Zugangsdaten für die Authentifizierung.
- `ApiSecret` - Zugangsdaten für die Authentifizierung.
- `TotpSecret` - Zugangsdaten für die Authentifizierung.
- `DefaultProduct` - Betriebsart oder Option des Konnektors. Standardwert: `GrowwProducts.Delivery`.
