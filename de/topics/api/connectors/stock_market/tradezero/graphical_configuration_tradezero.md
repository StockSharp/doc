# Grafische Konfiguration von TradeZero

Für alle StockSharp-Produkte wird die Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md) konfiguriert.

- **Schlüssel** - die Kennung des TradeZero-API-Schlüssels.
- **Geheimnis** - das TradeZero-API-Geheimnis.
- **Standardroute** - die bevorzugte Orderroute. Lassen Sie das Feld leer, damit automatisch eine kompatible Route ausgewählt wird.
