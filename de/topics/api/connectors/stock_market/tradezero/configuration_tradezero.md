# Konfiguration des TradeZero-Konnektors

Erstellen Sie API-Zugangsdaten im TradeZero-Portal und geben Sie sie in den Konnektoreinstellungen an.

- **Schlüssel** - der Wert `TZ-API-KEY-ID`.
- **Geheimnis** - der Wert `TZ-API-SECRET-KEY`.
- **Standardroute** - eine optionale bevorzugte Orderroute, die vom Endpunkt für Kontorouten zurückgegeben wird.

Ist die Standardroute leer, wählt der Konnektor automatisch eine kompatible aktive Route aus. Demo- und Live-Konten verwenden denselben API-Host; die Zugangsdaten bestimmen die Kontoumgebung.
