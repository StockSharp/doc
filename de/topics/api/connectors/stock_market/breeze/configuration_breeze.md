# Konfiguration des ICICI Direct Breeze-Konnektors

Beschaffen Sie die für ICICI Direct Breeze API erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **API-Schlüssel** - Eigenschaft `ApiKey`.
- **Geheimer Schlüssel** - Eigenschaft `SecretKey`.
- **API-Sitzung** - Eigenschaft `ApiSession`.
