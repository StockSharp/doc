# Konfiguration CQG

Es gibt zwei Moeglichkeiten, mit dem **CQG**-Connector zu arbeiten:

1. **CQG COM**, Verbindung ueber den lokalen **CQG Integrated Client**, der direkt auf dem Computer installiert ist, von dem aus die Verbindung hergestellt wird. Der **CQG Integrated Client** kann [auf der Entwicklerwebsite](https://www.cqg.com/products/cqg-integrated-client) heruntergeladen werden. Fuer die Verbindung mit dem **CQG Integrated Client** geben Sie **Login** und **Password** an.

2. **CQG Continuum**, direkte Verbindung zum Server. Geben Sie **Login**, **Password** und die **Serveradresse** an.

**Login**, **Password** und **Serveradresse** werden vom Broker bereitgestellt. Fuer den API-Zugriff wird empfohlen, den Broker zu kontaktieren.
