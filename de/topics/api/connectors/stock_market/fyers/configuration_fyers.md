# Konfiguration des FYERS-Konnektors

Beschaffen Sie die für FYERS API v3 erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **Clientkennung** - Eigenschaft `ClientId`.
- **Token** - Eigenschaft `Token`.
- **Standardprodukt** - Eigenschaft `DefaultProduct`. Standardwert: `Intraday`.
