# Connector-Konfiguration: Daishin CYBOS Plus

Bereiten Sie das lokale Gateway oder den Client des Anbieters vor und geben Sie die Verbindungsparameter an.

- `Account` - Konto- oder Clientkennung.
- `Market` - Betriebsart oder Option des Konnektors. Standardwert: `DaishinStockMarkets.Consolidated`.
- `IsTradingEnabled` - Schalter für das Verhalten des Konnektors. Standardwert: `true`.
