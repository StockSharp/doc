# Konfiguration des TradeStation-Konnektors

Beschaffen Sie die für TradeStation API v3 erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **Token** - Eigenschaft `Token`.
- **Demomodus** - Eigenschaft `IsDemo`.
- **Standardroute** - Eigenschaft `DefaultRoute`. Standardwert: `Intelligent`.
