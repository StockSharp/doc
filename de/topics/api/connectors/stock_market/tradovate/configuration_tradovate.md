# Konfiguration des Tradovate-Konnektors

Registrieren Sie eine API-Anwendung bei Tradovate und geben Sie deren Zugangsdaten in den Konnektoreinstellungen an.

- **Benutzername** - der Tradovate-Benutzername.
- **Passwort** - das Tradovate-Passwort.
- **Clientkennung** - die API-Clientkennung (`cid`).
- **Geheimnis** - das API-Clientgeheimnis (`sec`).
- **Anwendungskennung** - die registrierte Anwendungskennung. Der Standardwert ist `StockSharp`.
- **Anwendungsversion** - die registrierte Anwendungsversion. Der Standardwert ist `1.0`.
- **Gerätekennung** - eine dauerhafte, für den API-Zugriff registrierte Gerätekennung. Der Konnektor erzeugt und speichert sie automatisch.
- **Demomodus** - Verbindung mit der Tradovate-Simulationsumgebung statt mit der Live-Umgebung.
