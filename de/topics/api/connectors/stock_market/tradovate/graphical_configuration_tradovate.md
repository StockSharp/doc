# Grafische Konfiguration von Tradovate

Für alle StockSharp-Produkte wird die Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md) konfiguriert.

- **Benutzername** - der Tradovate-Benutzername.
- **Passwort** - das Tradovate-Passwort.
- **Clientkennung** - die API-Clientkennung.
- **Geheimnis** - das API-Clientgeheimnis.
- **Anwendungskennung** - die registrierte Anwendungskennung.
- **Anwendungsversion** - die registrierte Anwendungsversion.
- **Gerätekennung** - die dauerhafte Gerätekennung.
- **Demomodus** - die Simulationsumgebung verwenden.
