# Grafische Konfiguration: Zerodha Kite Connect

In allen StockSharp-Produkten wird die Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md) konfiguriert.

- `ApiKey` - Zugangsdaten für die Authentifizierung.
- `ApiSecret` - Zugangsdaten für die Authentifizierung.
- `Token` - Zugangsdaten für die Authentifizierung.
- `RequestToken` - Zugangsdaten für die Authentifizierung.
- `DefaultProduct` - Betriebsart oder Option des Konnektors. Standardwert: `ZerodhaProducts.Intraday`.
