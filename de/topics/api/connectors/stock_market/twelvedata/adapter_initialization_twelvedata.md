# Adapterinitialisierung Twelve Data

Der folgende Code zeigt, wie der [TwelveDataMessageAdapter](xref:StockSharp.TwelveData.TwelveDataMessageAdapter) initialisiert und an den [Connector](xref:StockSharp.Algo.Connector) übergeben wird.

```cs
Connector Connector = new Connector();
...
var messageAdapter = new TwelveDataMessageAdapter(Connector.TransactionIdGenerator)
{
	Token = "<Ihr Wert>".To<SecureString>(),
};
Connector.Adapter.InnerAdapters.Add(messageAdapter);
...
```
