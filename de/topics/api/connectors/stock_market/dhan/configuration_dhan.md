# Konfiguration des DhanHQ-Konnektors

Beschaffen Sie die für DhanHQ API v2 erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **Clientkennung** - Eigenschaft `ClientId`.
- **Token** - Eigenschaft `Token`.
- **Standardprodukt** - Eigenschaft `DefaultProduct`. Standardwert: `Intraday`.
