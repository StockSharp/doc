# Connector-Konfiguration: GLEIF

Konfigurieren Sie vor der Verbindung mit GLEIF die folgenden Adaptereigenschaften. Die Liste wurde anhand von [GleifMessageAdapter](xref:StockSharp.Gleif.GleifMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Address` (`Uri`)

## Erweiterte Einstellungen

Diese Eigenschaften steuern Endpunkte, Filter, Grenzwerte und weitere anbieterspezifische Optionen.

- `ActiveOnly` (`bool`)
- `ExpandIsins` (`bool`)
- `PageSize` (`int`)
- `MaxPages` (`int`)
