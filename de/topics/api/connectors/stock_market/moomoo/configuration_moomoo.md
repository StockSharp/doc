# Konfiguration des Moomoo-Konnektors

Beschaffen Sie die für Moomoo OpenAPI und OpenD erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **Adresse** - Eigenschaft `Address`. Standardwert: `127.0.0.1:11111`.
- **Passwort** - Eigenschaft `Password`.
- **Demomodus** - Eigenschaft `IsDemo`. Standardwert: `true`.
