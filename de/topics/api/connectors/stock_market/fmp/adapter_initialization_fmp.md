# Adapterinitialisierung Financial Modeling Prep

Der folgende Code zeigt, wie der [FmpMessageAdapter](xref:StockSharp.FinancialModelingPrep.FmpMessageAdapter) initialisiert und an den [Connector](xref:StockSharp.Algo.Connector) übergeben wird.

```cs
Connector Connector = new Connector();
...
var messageAdapter = new FmpMessageAdapter(Connector.TransactionIdGenerator)
{
	Token = "<Ihr Wert>".To<SecureString>(),
};
Connector.Adapter.InnerAdapters.Add(messageAdapter);
...
```
