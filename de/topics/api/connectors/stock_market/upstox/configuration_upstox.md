# Konfiguration des Upstox-Konnektors

Beschaffen Sie die für Upstox API v3 erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **Token** - Eigenschaft `Token`.
- **Demomodus** - Eigenschaft `IsDemo`.
- **Standardprodukt** - Eigenschaft `DefaultProduct`. Standardwert: `Delivery`.
