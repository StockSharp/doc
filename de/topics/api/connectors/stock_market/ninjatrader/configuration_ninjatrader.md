# Konfiguration des NinjaTrader-Konnektors

Beschaffen Sie die für REST- und WebSocket-APIs von NinjaTrader erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **Benutzername** - Eigenschaft `Login`.
- **Passwort** - Eigenschaft `Password`.
- **Clientkennung** - Eigenschaft `ClientId`.
- **Geheimnis** - Eigenschaft `Secret`.
- **Anwendungskennung** - Eigenschaft `AppId`. Standardwert: `StockSharp`.
- **Anwendungsversion** - Eigenschaft `AppVersion`. Standardwert: `1.0`.
- **Gerätekennung** - Eigenschaft `DeviceId`.
- **Demomodus** - Eigenschaft `IsDemo`.
