# Grafische Konfiguration von Angel One

Für alle StockSharp-Produkte wird die Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md) konfiguriert.

- **Benutzername** - Eigenschaft `Login`.
- **Passwort** - Eigenschaft `Password`.
- **API-Schlüssel** - Eigenschaft `ApiKey`.
- **TOTP-Geheimnis** - Eigenschaft `TotpSecret`.
- **Lokale Client-IP-Adresse** - Eigenschaft `ClientLocalIp`. Standardwert: `127.0.0.1`.
- **Öffentliche Client-IP-Adresse** - Eigenschaft `ClientPublicIp`.
- **MAC-Adresse** - Eigenschaft `MacAddress`.
- **Standardprodukt** - Eigenschaft `DefaultProduct`. Standardwert: `Delivery`.
