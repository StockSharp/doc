# Connector-Konfiguration: Capital Futures

Installieren Sie das offizielle Entwicklerpaket und geben Sie dessen Pfad, die Zugangsdaten und die weiteren Verbindungsparameter an.

- `SdkPath` - Pfad zu einer lokalen Datei oder einem Verzeichnis.
- `Login` - Konto- oder Clientkennung.
- `Password` - Zugangsdaten für die Authentifizierung.
- `Account` - Konto- oder Clientkennung.
- `Environment` - Betriebsart oder Option des Konnektors. Standardwert: `CapitalFuturesEnvironments.Production`.
- `IsTradingEnabled` - Schalter für das Verhalten des Konnektors. Standardwert: `true`.
- `LogPath` - Pfad zu einer lokalen Datei oder einem Verzeichnis.
