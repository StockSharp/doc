# Nasdaq Cloud Data Service

**Nasdaq Cloud Data Service** - ein Konnektor für den Bezug von Marktdaten eines Datenanbieters.

Bevor Sie Handelsroboter für die aktuelle Handelsplattform schreiben, wird empfohlen, die Links unter [Konnektoren](../../connectors.md) zu lesen.

> [!CAUTION]
> Der Konnektor stellt Marktdaten bereit und unterstützt keine Orderweiterleitung.
