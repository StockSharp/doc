# Konfiguration des Robinhood-Konnektors

Beschaffen Sie die für agentenbasierter Handel von Robinhood erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **Token** - Eigenschaft `Token`.
- **Adresse** - Eigenschaft `Address`. Standardwert: `https://agent.robinhood.com/mcp/trading`.
- **Abfrageintervall** - Eigenschaft `PollingInterval`. Standardwert: `2 s`.
