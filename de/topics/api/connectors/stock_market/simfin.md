# SimFin

**SimFin** verbindet StockSharp mit der SimFin Web API v3 für Unternehmens-, Kurs- und Fundamentaldaten.

## Wichtige Funktionen

- Im Quellcode geprüfte Funktionen: Unternehmenssuche, tägliche Level-1-Kurswerte, Tageskerzen und strukturierte Fundamentaldaten über `SimFinDataTypes.Fundamentals`. Der Adapter ist historisch und unterstützt keinen Handel.
- Anbieterspezifische Transporte, Sitzungen und Datenformate werden hinter der standardisierten StockSharp-API verborgen.

## Typische Verwendung

Geeignet zum Herunterladen täglicher Kurse, Abschlüsse, abgeleiteter Werte und optionaler Kennzahlen für unterstützte Unternehmen.

Unternehmensabdeckung, Historie, Felder, Anfragelimits und Verfügbarkeit hängen vom SimFin-Abonnement ab.
