# Konfiguration des Saxo OpenAPI-Konnektors

Beschaffen Sie die für Saxo OpenAPI erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **Zugriffstoken** - Eigenschaft `AccessToken`.
- **Aktualisierungstoken** - Eigenschaft `RefreshToken`.
- **Clientkennung** - Eigenschaft `ClientId`.
- **Clientgeheimnis** - Eigenschaft `ClientSecret`.
- **Weiterleitungs-URI** - Eigenschaft `RedirectUri`.
- **Kontoschlüssel** - Eigenschaft `AccountKey`.
- **Umgebung** - Eigenschaft `Environment`. Standardwert: `Simulation`.
