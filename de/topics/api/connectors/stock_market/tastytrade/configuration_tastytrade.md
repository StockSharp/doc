# Konfiguration des tastytrade-Konnektors

Beschaffen Sie die für tastytrade Open API erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **Token** - Eigenschaft `Token`.
- **Clientgeheimnis** - Eigenschaft `ClientSecret`.
- **Zugriffsbereiche** - Eigenschaft `Scopes`.
- **Demomodus** - Eigenschaft `IsDemo`.
