# Connector-Konfiguration: QMT

Bereiten Sie das lokale Gateway oder den Client des Anbieters vor und geben Sie die Verbindungsparameter an.

- `GatewayHost` - Adresse des Dienstes. Standardwert: `127.0.0.1`.
- `GatewayPort` - TCP-Port des lokalen Gateways. Standardwert: `58630`.
- `GatewayToken` - Zugangsdaten für die Authentifizierung.
- `ReconnectAttempts` - Maximale Anzahl der Wiederverbindungsversuche. Standardwert: `10`.
- `RequestTimeout` - Zeitintervall. Standardwert: `30`.
