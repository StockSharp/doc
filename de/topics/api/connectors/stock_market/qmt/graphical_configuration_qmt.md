# Grafische Konfiguration: QMT

In allen StockSharp-Produkten wird die Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md) konfiguriert.

- `GatewayHost` - Adresse des Dienstes. Standardwert: `127.0.0.1`.
- `GatewayPort` - numerischer Konnektorparameter. Standardwert: `58630`.
- `GatewayToken` - Zugangsdaten für die Authentifizierung.
- `ReconnectAttempts` - numerischer Konnektorparameter. Standardwert: `10`.
- `RequestTimeout` - Zeitintervall. Standardwert: `30`.
