# Konfiguration des IG Markets-Konnektors

Beschaffen Sie die für IG-APIs für REST und Datenströme erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **API-Schlüssel** - Eigenschaft `ApiKey`.
- **Benutzername** - Eigenschaft `UserName`.
- **Passwort** - Eigenschaft `Password`.
- **Kontokennung** - Eigenschaft `AccountId`.
- **Umgebung** - Eigenschaft `Environment`. Standardwert: `Demo`.
- **Passwort verschlüsseln** - Eigenschaft `EncryptPassword`.
