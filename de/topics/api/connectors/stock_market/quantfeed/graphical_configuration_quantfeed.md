# Grafische Konfiguration QuantFEED

Für alle [S#](../../../../api.md)-Produkte erfolgt die grafische Konfiguration der Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md):

![API GUI Settings QuantFEED](../../../../../images/api_gui_settings_quantfeed.png)

- **Address** - Serveradresse.
- **Login** - Login.
- **Password** - Password.
- **Heart beat** - Intervall zur Serverprüfung, um die Verbindung zu überwachen. Standardmäßig 1 Minute.
- **Reconnection settings** - Mechanismus zur Überwachung von Verbindungen mit den Einstellungen des Handelssystems. ([Einstellungen für die Wiederverbindung](../../reconnection_settings.md))
