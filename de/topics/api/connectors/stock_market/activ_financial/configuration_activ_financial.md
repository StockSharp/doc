# Konfiguration ACTIV Financial

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `Login` - Anmeldename des Kontos.
- `Password` - Kontokennwort.
- `Host` - Host des ACTIV-Gateways.
- `DataSource` - Zu verwendende Marktdatenquelle.
- `NodePath` - Pfad zum Knoten des ACTIV-Gateways.
- `GatewayDirectory` - Pfad zum Installationsverzeichnis des ACTIV-Gateways.
