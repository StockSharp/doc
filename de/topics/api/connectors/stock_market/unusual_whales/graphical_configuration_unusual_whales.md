# Grafische Konfiguration: Unusual Whales

Konfigurieren Sie die Verbindung in allen StockSharp-Produkten im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md).

Der Grundbereich des Verbindungseditors enthält:

- `Token`
- `Address`

Die übrigen Eigenschaften finden Sie in der erweiterten Ansicht und auf der Seite [Connector-Konfiguration](configuration_unusual_whales.md). Ändern Sie vorausgefüllte Anbieterendpunkte nur, wenn der Anbieter andere Werte zugewiesen hat.
