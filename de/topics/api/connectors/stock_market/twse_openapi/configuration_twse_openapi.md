# Connector-Konfiguration: TWSE

Konfigurieren Sie vor der Verbindung mit TWSE die folgenden Adaptereigenschaften. Die Liste wurde anhand von [TwseMessageAdapter](xref:StockSharp.Twse.TwseMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Address` (`Uri`)

## Erweiterte Einstellungen

Diese Eigenschaften steuern Endpunkte, Filter, Grenzwerte und weitere anbieterspezifische Optionen.

- `IncludeProfiles` (`bool`)
- `IncludeValuations` (`bool`)
- `CacheTimeout` (`TimeSpan`)
