# Grafische Konfiguration: Swissquote OpenWealth

In allen StockSharp-Produkten wird die Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md) konfiguriert.

- `Token` - Zugangsdaten für die Authentifizierung.
- `CustomerId` - Konto- oder Clientkennung.
- `SafekeepingAccountId` - Konto- oder Clientkennung.
- `CashAccountId` - Konto- oder Clientkennung.
- `AccountCurrency` - Verbindungsparameter. Standardwert: `CHF`.
- `IsDemo` - Schalter für das Verhalten des Konnektors. Standardwert: `true`.
- `IsDryRun` - Schalter für das Verhalten des Konnektors.
- `IsBestEffort` - Schalter für das Verhalten des Konnektors.
