# TradeStation

**TradeStation** bindet **TradeStation API v3** für Marktdaten und Handel in StockSharp ein.

Der Konnektor unterstützt Wertpapiersuche, Kurse, historische Kerzen, Konten, Salden und Positionen, Orderverwaltung, Echtzeitaktualisierungen für Konten und Orders, Simulations- und Live-Umgebungen.

Lesen Sie vor der Entwicklung von Handelsrobotern für TradeStation die Verweise im Abschnitt [Konnektoren](../../connectors.md).
