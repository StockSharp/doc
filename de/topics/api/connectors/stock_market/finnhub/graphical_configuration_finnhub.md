# Grafische Konfiguration Finnhub

Für alle [S#](../../../../api.md)-Produkte wird die grafische Konfiguration der Verbindung im [Fenster Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md) vorgenommen:

- `Token` - API-Zugriffstoken.
- `Address` - Adresse der REST-API.
- `WebSocketAddress` - Adresse des WebSocket-Servers.
- `StockExchange` - Börsencode für die Anfragen.
- `ForexExchange` - Code des Devisenhandelsplatzes bei Finnhub.
- `CryptoExchange` - Code des Kryptowährungshandelsplatzes bei Finnhub.
