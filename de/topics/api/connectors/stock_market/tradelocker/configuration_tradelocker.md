# Konfiguration TradeLocker

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `Login` - Anmeldename des Kontos.
- `Password` - Kontokennwort.
- `Server` - Adresse des TradeLocker-Servers.
- `AccountId` - Vom Dienst vergebene Kontokennung.
- `IsDemo` - Modus der Demoumgebung.
