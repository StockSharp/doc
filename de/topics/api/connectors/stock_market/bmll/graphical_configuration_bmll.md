# Grafische Konfiguration BMLL

Für alle [S#](../../../../api.md)-Produkte wird die grafische Konfiguration der Verbindung im [Fenster Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md) vorgenommen:

- `AuthenticationMode` - Authentifizierungsmethode.
- `Login` - Anmeldename des Kontos.
- `PrivateKeyPath` - Pfad zur Datei mit dem privaten Schlüssel.
- `Password` - Kontokennwort.
- `Token` - API-Zugriffstoken.
- `ApiKey` - API-Schlüssel.
- `Address` - Adresse der REST-API.
- `AuthenticationAddress` - Endpunkt des Authentifizierungsdienstes.
- `TradesDataset` - Name des BMLL-Handelsdatensatzes.
- `Level3Dataset` - Name des BMLL-Level-3-Datensatzes.
