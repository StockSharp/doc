# Connector-Konfiguration: ESMA FIRDS

Konfigurieren Sie vor der Verbindung mit ESMA FIRDS die folgenden Adaptereigenschaften. Die Liste wurde anhand von [EsmaFirdsMessageAdapter](xref:StockSharp.EsmaFirds.EsmaFirdsMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Address` (`Uri`)

## Erweiterte Einstellungen

Diese Eigenschaften steuern Endpunkte, Filter, Grenzwerte und weitere anbieterspezifische Optionen.

- `CfiCategories` (`string`)
- `ActiveOnly` (`bool`)
- `MaxResults` (`int`)
