# Connector-Konfiguration: LS Securities

Beziehen Sie die Zugangsdaten vom Anbieter und geben Sie die Verbindungsparameter an.

- `AppKey` - Zugangsdaten für die Authentifizierung.
- `AppSecret` - Zugangsdaten für die Authentifizierung.
- `Account` - Konto- oder Clientkennung.
- `IsDemo` - Schalter für das Verhalten des Konnektors. Standardwert: `true`.
