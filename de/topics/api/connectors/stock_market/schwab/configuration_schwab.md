# Konfiguration des Charles-Schwab-Konnektors

Erstellen Sie eine Anwendung mit Zugriff auf die [Charles Schwab Trader API](https://developer.schwab.com/products/trader-api--individual) und beziehen Sie ein OAuth-Token.

- **Zugriffstoken** (`Token`) — ein gültiges OAuth-Zugriffstoken.
- **Adresse** (`Address`) — die Adresse der Trader API. Standardwert: `https://api.schwabapi.com/`.

Die WebSocket-Adresse und die Kennungen der Echtzeitverbindung ermittelt der Konnektor automatisch. Erneuern Sie das OAuth-Token entsprechend den Vorgaben von Charles Schwab.
