# Konfiguration MT Newswires

Geben Sie in den Konnektoreinstellungen die vom Dienst bereitgestellten Verbindungsparameter an.

## Verbindungsparameter

- `Token` - API-Zugriffstoken.
- `Address` - Adresse der REST-API.
- `DataSource` - Zu verwendende Marktdatenquelle.
- `DatasetId` - Kennung des abzurufenden Datensatzes.
