# Connector-Konfiguration: Trading Economics

Konfigurieren Sie vor der Verbindung mit Trading Economics die folgenden Adaptereigenschaften. Die Liste wurde anhand von [TradingEconomicsMessageAdapter](xref:StockSharp.TradingEconomics.TradingEconomicsMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Token` (`SecureString`)
- `Address` (`Uri`)

## Erweiterte Einstellungen

Diese Eigenschaften steuern Endpunkte, Filter, Grenzwerte und weitere anbieterspezifische Optionen.

- `DefaultMarket` (`string`)
- `DefaultSearch` (`string`)
- `NewsLimit` (`int`)
