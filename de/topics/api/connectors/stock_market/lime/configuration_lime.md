# Konfiguration des Lime Trader-Konnektors

Beschaffen Sie die für Lime-API erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **Benutzername** - Eigenschaft `Login`.
- **Passwort** - Eigenschaft `Password`.
- **Clientkennung** - Eigenschaft `ClientId`.
- **Clientgeheimnis** - Eigenschaft `ClientSecret`.
