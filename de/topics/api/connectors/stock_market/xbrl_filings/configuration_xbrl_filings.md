# Connector-Konfiguration: XBRL Filings

Konfigurieren Sie vor der Verbindung mit XBRL Filings die folgenden Adaptereigenschaften. Die Liste wurde anhand von [XbrlFilingsMessageAdapter](xref:StockSharp.XbrlFilings.XbrlFilingsMessageAdapter) geprüft.

## Grundeinstellungen

Diese Einstellungen werden im Verbindungseditor zuerst angezeigt.

- `Address` (`Uri`)

## Erweiterte Einstellungen

Diese Eigenschaften steuern Endpunkte, Filter, Grenzwerte und weitere anbieterspezifische Optionen.

- `PublicAddress` (`Uri`)
- `Country` (`string`)
- `PageSize` (`int`)
- `MaxPages` (`int`)
