# Grafische Konfiguration: B3 UP2DATA

Konfigurieren Sie die Verbindung in allen StockSharp-Produkten im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md).

Der Grundbereich des Verbindungseditors enthält:

- `Key`
- `Secret`
- `CertificatePath`
- `CertificatePassword`
- `Address`

Die übrigen Eigenschaften finden Sie in der erweiterten Ansicht und auf der Seite [Connector-Konfiguration](configuration_b3_up2data.md). Ändern Sie vorausgefüllte Anbieterendpunkte nur, wenn der Anbieter andere Werte zugewiesen hat.
