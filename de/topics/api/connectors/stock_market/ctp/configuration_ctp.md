# Konfiguration des CTP-Konnektors

Beschaffen Sie die für CTP-APIs für Handel und Marktdaten erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **Benutzername** - Eigenschaft `Login`.
- **Passwort** - Eigenschaft `Password`.
- **Brokerkennung** - Eigenschaft `BrokerId`.
- **Anlegerkennung** - Eigenschaft `InvestorId`.
- **Marktdatenadresse** - Eigenschaft `MarketDataAddress`.
- **Handelsserveradresse** - Eigenschaft `TraderAddress`.
- **Anwendungskennung** - Eigenschaft `AppId`.
- **Authentifizierungscode** - Eigenschaft `AuthCode`.
- **Produktinformationen** - Eigenschaft `ProductInfo`. Standardwert: `StockSharp`.
- **Wiederherstellungsmodus** - Eigenschaft `ResumeType`. Standardwert: `Quick`.
- **Produktionsmodus** - Eigenschaft `ProductionMode`. Standardwert: `true`.
- **Datenverzeichnis** - Eigenschaft `DataPath`.
- **Abfrageintervall** - Eigenschaft `QueryInterval`. Standardwert: `1 s`.
- **Verbindungszeitlimit** - Eigenschaft `ConnectionTimeout`. Standardwert: `30 s`.
