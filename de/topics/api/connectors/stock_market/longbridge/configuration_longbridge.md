# Konfiguration des Longbridge OpenAPI-Konnektors

Beschaffen Sie die für Longbridge OpenAPI erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **Anwendungsschlüssel** - Eigenschaft `AppKey`.
- **Anwendungsgeheimnis** - Eigenschaft `AppSecret`.
- **Zugriffstoken** - Eigenschaft `AccessToken`.
- **Portfolio** - Eigenschaft `Portfolio`. Standardwert: `Longbridge`.
- **API-Adresse** - Eigenschaft `ApiUrl`. Standardwert: `https://openapi.longbridge.com`.
- **Kursdatenadresse** - Eigenschaft `QuoteUrl`. Standardwert: `wss://openapi-quote.longbridge.com/v2`.
- **Handelsserveradresse** - Eigenschaft `TradeUrl`. Standardwert: `wss://openapi-trade.longbridge.com/v2`.
