# Connector-Konfiguration: SnapTrade

Beziehen Sie die Zugangsdaten vom Anbieter und geben Sie die Verbindungsparameter an.

- `ClientId` - Konto- oder Clientkennung.
- `ConsumerKey` - Zugangsdaten für die Authentifizierung.
- `UserId` - Konto- oder Clientkennung.
- `UserSecret` - Zugangsdaten für die Authentifizierung.
- `AccountId` - Konto- oder Clientkennung.
- `PollingInterval` - Zeitintervall. Standardwert: `TimeSpan.FromMinutes(1)`.
