# Konfiguration des Kotak Neo-Konnektors

Beschaffen Sie die für Kotak Neo Handels-API v2 erforderlichen Zugangsdaten, Serveradressen und Kontokennungen und geben Sie anschließend die folgenden Konnektoreinstellungen an.

- **Consumer-Schlüssel** - Eigenschaft `ConsumerKey`.
- **Mobilnummer** - Eigenschaft `MobileNumber`.
- **Benutzercode** - Eigenschaft `UserCode`.
- **MPIN** - Eigenschaft `Mpin`.
- **TOTP-Geheimnis** - Eigenschaft `TotpSecret`.
- **Standardprodukt** - Eigenschaft `DefaultProduct`. Standardwert: `Intraday`.
