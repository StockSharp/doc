# Konfiguration Sterling

Für die Arbeit mit dem **Sterling**-Connector müssen Sie das lokale Terminal **Sterling Trader Pro** verwenden, das direkt auf dem Computer installiert ist, von dem aus die Verbindung hergestellt wird. Für die Verbindung mit **Sterling Trader Pro** müssen Sie **Benutzername** und **Passwort** angeben.

![Sterling login](../../../../../images/sterling_login.png)

**Sterling Trader Pro**, **Benutzername**, **Passwort** und die Serveradresse werden vom Broker bereitgestellt. Um API-Zugriff zu erhalten, empfehlen wir, den Broker zu kontaktieren.

> [!TIP]
> Damit die Sterling API korrekt funktioniert, müssen Sie Visual Studio als Administrator ausführen.
