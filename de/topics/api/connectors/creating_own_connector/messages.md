# Liste der Nachrichten

Eine Nachricht (Message) enthält Informationen über Marktdaten, Transaktionen oder einen Befehl. Nachfolgend finden Sie eine Liste der wichtigsten Nachrichten, die in Connectoren verwendet werden.

Die [ExecutionMessage](xref:StockSharp.Messages.ExecutionMessage) ist eine universelle Nachricht, die es ermöglicht, verschiedene Börseninformationen zu Aufträgen und Trades zu übertragen: Tick-Trades, Auftragsprotokolle, eigene Aufträge und Trades.

Der Typ der Informationen in der Nachricht wird durch den Wert der Eigenschaft [ExecutionMessage.ExecutionType](xref:StockSharp.Messages.ExecutionMessage.ExecutionType) bestimmt:

- [ExecutionTypes.Tick](xref:StockSharp.Messages.ExecutionTypes.Tick) - Tick-Trade.
- [ExecutionTypes.Transaction](xref:StockSharp.Messages.ExecutionTypes.Transaction) - Transaktion (Informationen über einen eigenen Trade oder Auftrag).
- [ExecutionTypes.OrderLog](xref:StockSharp.Messages.ExecutionTypes.OrderLog) - Auftragsprotokoll.

Wenn der Typ [ExecutionTypes.Transaction](xref:StockSharp.Messages.ExecutionTypes.Transaction) verwendet wird, bezieht er sich auf eigene Aufträge oder Trades. Enthält die Nachricht in diesem Fall Informationen über einen Auftrag, ist die Eigenschaft [ExecutionMessage.HasOrderInfo](xref:StockSharp.Messages.ExecutionMessage.HasOrderInfo) = true, sind Informationen über einen Trade vorhanden, ist die Eigenschaft [ExecutionMessage.HasTradeInfo](xref:StockSharp.Messages.ExecutionMessage.HasTradeInfo) = true. Beachten Sie, dass ein *eigener Trade* sowohl Informationen über den Trade selbst als auch über den mit diesem Trade verbundenen Auftrag enthält. Daher haben die oben genannten Eigenschaften in diesem Fall den Wert true. Diese Eigenschaften ermöglichen die Unterscheidung von Nachrichten mit eigenen Trades und Aufträgen.
