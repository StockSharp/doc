# Grafische SBE-Konfiguration

In StockSharp-Produkten wird die SBE-Verbindung im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md) konfiguriert.

- `Address` - TCP-Endpunkt des SBE-Servers.
- `SenderCompId` - Clientkennung.
- `TargetCompId` - Kennung des Zielservers.
- `Password` - Anmeldedaten für die Authentifizierung.
- `IsSupportNativeCandles` - aktiviert Abonnements für native Kerzen.
