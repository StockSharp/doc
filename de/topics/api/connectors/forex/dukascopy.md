# DukasCopy

**DukasCopy** - der Anbieter historischer Daten stellt verschiedene Finanzinstrumente bereit, z. B. Forex, Rohstoffe und Indizes.

Bevor Sie mit dem Schreiben von Handelsrobotern für diese Handelsplattform beginnen, empfehlen wir, die Links im Abschnitt [Connectoren](../../connectors.md) zu lesen.

> [!CAUTION]
> Der Connector unterstützt nur Marktdaten; Transaktionen werden nicht unterstützt.
