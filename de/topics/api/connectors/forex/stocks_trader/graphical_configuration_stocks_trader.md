# Grafische Konfiguration: StocksTrader

Konfigurieren Sie die Verbindung in allen StockSharp-Produkten im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md).

Tragen Sie das vom Webterminal ausgestellte Token ein. Aktivieren Sie `IsDemo` für ein Demokonto. Lassen Sie `AccountId` leer, wenn das Token für den gewählten Modus genau ein Konto enthält. Ändern Sie die Standardadresse nur, wenn StocksTrader einen anderen Endpunkt zugewiesen hat, und passen Sie `PollingInterval` an die erforderliche Aktualisierungsrate an.
