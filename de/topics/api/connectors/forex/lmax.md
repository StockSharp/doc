# LMAX

**LMAX Global** - LMAX Global ist ein von der FCA regulierter Broker für FX. LMAX Global bietet Brokern und professionellen Tradern die Möglichkeit, über das zentrale Limit-Orderbuch der LMAX Exchange zu handeln, mit engeren Spreads auf fortlaufend gestellte, verbindliche Liquidität von erstklassigen Banken und proprietären Handelsfirmen.

Bevor Sie mit dem Schreiben von Handelsrobotern für diese Handelsplattform beginnen, empfehlen wir, die Links im Abschnitt [Connectoren](../../connectors.md) zu lesen.
