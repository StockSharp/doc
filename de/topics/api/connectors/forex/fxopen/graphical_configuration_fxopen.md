# Grafische Konfiguration: FXOpen TickTrader

Konfigurieren Sie die Verbindung in allen StockSharp-Produkten im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md).

Tragen Sie Token-ID, Schlüssel und Geheimnis ein. Aktivieren Sie `IsDemo` für ein Demokonto. `OneTimePassword` ist nur bei vorgeschriebener Zwei-Faktor-Authentifizierung nötig. Ändern Sie die REST-, Feed-WebSocket- und Trade-WebSocket-Adressen nur, wenn FXOpen andere Endpunkte zugewiesen hat.
