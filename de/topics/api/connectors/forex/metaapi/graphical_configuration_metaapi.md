# Grafische Konfiguration: MetaApi

Konfigurieren Sie die Verbindung in allen StockSharp-Produkten im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md).

Tragen Sie das Token und die Kennung des bereitgestellten Kontos ein. Füllen Sie `Region` nur bei einem kontobezogenen Token aus. Ändern Sie die Standarddomain nur, wenn MetaApi eine andere zugewiesen hat, und erhöhen Sie `SynchronizationTimeout` bei Konten mit langer Historie.
