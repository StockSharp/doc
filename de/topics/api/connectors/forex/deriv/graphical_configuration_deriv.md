# Grafische Konfiguration: Deriv

Konfigurieren Sie die Verbindung in allen StockSharp-Produkten im [Fenster für Verbindungseinstellungen](../../../graphical_user_interface/connection_settings_window.md).

Tragen Sie das Token und die Anwendungskennung ein. Aktivieren Sie `IsDemo` für ein Demokonto. Lassen Sie `AccountId` leer, wenn das Token für den gewählten Modus genau ein aktives Konto enthält. Ändern Sie die REST- und WebSocket-Adressen nur, wenn Deriv andere Endpunkte zugewiesen hat.
