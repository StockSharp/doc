# Dienstpanels

Dieser Abschnitt versammelt die Panels, die keine Marktdaten anzeigen, sondern die Arbeitsweise der Anwendung einrichten: Verzeichnisse, Speicher\- und Importeinstellungen, Lizenzen, Konten und Abonnements.

- Provisionsregeln \- [CommissionPanel](xref:StockSharp.Xaml.CommissionPanel).
- Importeinstellungen \- [ImportSettingsPanel](xref:StockSharp.Xaml.ImportSettingsPanel).
- Lizenzen \- [LicensePanel](xref:StockSharp.Xaml.LicensePanel).
- Instrumentensuche \- [SecurityLookupPanel](xref:StockSharp.Xaml.SecurityLookupPanel).
- Zuordnung von Instrumentencodes \- [SecurityMappingPanel](xref:StockSharp.Xaml.SecurityMappingPanel).
- Speichereinstellungen \- [StorageSettingsPanel](xref:StockSharp.Xaml.StorageSettingsPanel).
- Abonnements \- [SubscriptionPanel](xref:StockSharp.Xaml.SubscriptionPanel).
- Börsen \- [ExchangesPanel](xref:StockSharp.Xaml.ExchangesPanel).
- Börsenplätze \- [ExchangeBoardsPanel](xref:StockSharp.Xaml.ExchangeBoardsPanel).
- Zeitplan \- [WorkingTimeControl](xref:StockSharp.Xaml.WorkingTimeControl).
- Konten und Rechte \- [PermissionCredentialsPanel](xref:StockSharp.Xaml.PermissionCredentialsPanel).
