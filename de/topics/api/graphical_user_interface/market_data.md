# Marktdaten

Es gibt grafische Komponenten zur Anzeige aller Arten von Marktdaten in [S#](../../api.md):

- Tabelle zur Anzeige von Trades - [TradeGrid](xref:StockSharp.Xaml.TradeGrid).
- Tabelle zur Anzeige von Level1 - [Level1Grid](xref:StockSharp.Xaml.Level1Grid).
- Komponente zur Anzeige eines Orderbuchs - [MarketDepthControl](xref:StockSharp.Xaml.MarketDepthControl).
- Tabelle zur Anzeige eines Orderlogs - [OrderLogGrid](xref:StockSharp.Xaml.OrderLogGrid).
- Tabellen zur Anzeige von Nachrichten - [NewsGrid](xref:StockSharp.Xaml.NewsGrid), [NewsPanel](xref:StockSharp.Xaml.NewsPanel).
