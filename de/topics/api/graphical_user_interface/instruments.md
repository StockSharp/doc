# Instrumente

[S#](../../api.md) bietet eine große Auswahl grafischer Komponenten für die Arbeit mit Instrumenten. Diese Auswahl umfasst:

- Die Komponente zum Erstellen eines Instruments - [SecurityCreateWindow](xref:StockSharp.Xaml.SecurityCreateWindow).
- Die Komponente zur Anzeige von Finanzinformationen zum Instrument - [SecurityGrid](xref:StockSharp.Xaml.SecurityGrid).
- Komponenten zum Suchen und Auswählen von Instrumenten - [SecurityPicker](xref:StockSharp.Xaml.SecurityPicker), [SecurityPickerWindow](xref:StockSharp.Xaml.SecurityPickerWindow) und [SecurityEditor](xref:StockSharp.Xaml.PropertyGrid.SecurityEditor).
- Komponenten zum Erstellen kontinuierlicher Instrumente und Indexinstrumente - [ContinuousSecurityWindow](xref:StockSharp.Xaml.ContinuousSecurityWindow) und [IndexSecurityWindow](xref:StockSharp.Xaml.IndexSecurityWindow).
