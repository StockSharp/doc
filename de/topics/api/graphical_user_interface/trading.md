- Panel für die schnelle Ordererfassung \- [QuickOrderPanel](xref:StockSharp.Xaml.QuickOrderPanel).
- Satz von Kaufen\/Verkaufen\-Panels \- [BuySellGrid](xref:StockSharp.Xaml.BuySellGrid).
- Tabelle der Risikomanagement\-Regeln \- [RiskPanel](xref:StockSharp.Xaml.RiskPanel).
