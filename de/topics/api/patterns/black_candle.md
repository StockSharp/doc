# Schwarze Kerze

Schwarze Kerze (bärische Kerze) ist ein klassisches Candlestick-Muster, das entsteht, wenn der Schlusskurs unter dem Eröffnungskurs liegt. Diese Kerze spiegelt eine bärische Marktstimmung wider, bei der Verkäufer während der Kerzenbildungsperiode den Preis kontrollierten.

##### Hauptmerkmale:

- Der Eröffnungskurs ist höher als der Schlusskurs (O > C).
- Der Kerzenkörper ist üblicherweise schwarz gefärbt (oder rot in modernen Charts).
- Zeigt die Dominanz von Verkäufern gegenüber Käufern.
- Die Größe des Kerzenkörpers zeigt die Stärke der bärischen Bewegung.

![Schwarzes Kerzenmuster](../../../images/blackcandlepattern.png)

### Interpretation

Schwarze Kerze signalisiert bärischen Druck im Markt:

- Je länger der Kerzenkörper, desto stärker ist der bärische Druck.
- Eine länge schwarze Kerze nach einem Aufwärtstrend kann auf eine mögliche Umkehr hinweisen.
- Kurze Schatten zeigen, dass Bären den Preis während der gesamten Periode kontrollierten.
- Aufeinanderfolgende schwarze Kerzen weisen auf einen stabilen Abwärtstrend hin.

### Handelsstrategien

Obwohl eine einzelne schwarze Kerze normalerweise kein eigenständiges Handelssignal ist, kann sie als Teil einer breiteren Strategie verwendet werden:

- Bestätigung eines Abwärtstrends oder einer Umkehr nach einer Aufwärtsbewegung.
- Suche nach langen schwarzen Kerzen an Widerstandsniveaus für mögliche Short-Positionen.
- Verwendung in Kombination mit anderen Candlestick-Mustern, zum Beispiel einer schwarzen Kerze nach einer bärischen Umschließung.
- Identifikation von Unterstützungsniveaus nach einer Serie aufeinanderfolgender schwarzer Kerzen.
