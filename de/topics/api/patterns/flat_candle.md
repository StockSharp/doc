# Flache (neutrale) Kerze

Eine flache (neutrale) Kerze ist ein Candlestick-Muster, das entsteht, wenn Eröffnungs- und Schlusskurs identisch oder sehr nahe beieinander liegen. Diese Kerze spiegelt Unentschlossenheit im Markt wider, wenn die Kräfte von Käufern und Verkäufern ausgeglichen sind.

##### Hauptmerkmale:

- Der Eröffnungskurs entspricht dem Schlusskurs (O == C).
- Obere und untere Schatten können unterschiedlich lang sein.
- Weist auf Neutralität oder Unentschlossenheit im Markt hin.
- Kann eine Konsolidierung vor der Fortsetzung des bestehenden Trends oder eine mögliche Umkehr signalisieren.

![Flaches Kerzenmuster](../../../images/flatcandlepattern.png)

### Interpretation

Eine flache Kerze liefert für sich genommen kein klares Signal zur Marktrichtung, kann aber im Kontext vorheriger Kerzen und des Gesamttrends nützlich sein:

- Nach einer starken Aufwärts- oder Abwärtsbewegung kann eine flache Kerze nachlassendes Momentum und eine mögliche Umkehr signalisieren.
- Während einer Seitwärtsbewegung bestätigt eine flache Kerze die Fortsetzung der Konsolidierung.
- Die Größe der Schatten kann zusätzliche Informationen zur Marktstimmung liefern - lange Schatten weisen auf zurückgewiesene Preisbewegungsversuche hin, kurze Schatten auf geringe Volatilität.

### Handelsstrategien

Flache Kerzen werden selten als eigenständige Signale für den Positionseinstieg verwendet, können aber bei Handelsentscheidungen helfen:

- Suchen Sie nach Bestätigung durch nachfolgende Kerzen oder andere technische Indikatoren, bevor Sie einen Trade ausführen.
- Verwenden Sie flache Kerzen zusammen mit anderen Analysemethoden, um Unterstützungs- oder Widerstandsniveaus zu identifizieren.
- Vergrößern Sie Stop-Loss oder Take-Profit, wenn flache Kerzen in einem Trend auftreten, da dies auf eine Abschwächung der Bewegung hinweisen kann.
