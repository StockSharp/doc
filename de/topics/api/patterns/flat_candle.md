# Pattern Flat (Neutral) Candle

Eine flache (neutrale) Candle ist ein Candlestick-Muster, das entsteht, wenn Eröffnungs- und Schlusskurs identisch oder sehr nahe beieinander liegen. Diese Candle spiegelt Unentschlossenheit im Markt wider, wenn die Kräfte von Käufern und Verkäufern ausgeglichen sind.

##### Hauptmerkmale:

- Der Eröffnungskurs entspricht dem Schlusskurs (O == C).
- Obere und untere Schatten können unterschiedlich lang sein.
- Weist auf Neutralität oder Unentschlossenheit im Markt hin.
- Kann eine Konsolidierung vor der Fortsetzung des bestehenden Trends oder eine mögliche Umkehr signalisieren.

![Flat Candle Pattern](../../../images/flatcandlepattern.png)

### Interpretation

Eine flache Candle liefert für sich genommen kein klares Signal zur Marktrichtung, kann aber im Kontext vorheriger Candles und des Gesamttrends nützlich sein:

- Nach einer starken Aufwärts- oder Abwärtsbewegung kann eine flache Candle nachlassendes Momentum und eine mögliche Umkehr signalisieren.
- Während einer Seitwärtsbewegung bestätigt eine flache Candle die Fortsetzung der Konsolidierung.
- Die Größe der Schatten kann zusätzliche Informationen zur Marktstimmung liefern - länge Schatten weisen auf zurückgewiesene Preisbewegungsversuche hin, kurze Schatten auf geringe Volatilität.

### Handelsstrategien

Flache Candles werden selten als eigenständige Signale für den Positionseinstieg verwendet, können aber bei Handelsentscheidungen helfen:

- Suchen Sie nach Bestätigung durch nachfolgende Candles oder andere technische Indikatoren, bevor Sie einen Trade ausführen.
- Verwenden Sie flache Candles zusammen mit anderen Analysemethoden, um Unterstützungs- oder Widerstandsniveaus zu identifizieren.
- Vergrößern Sie Stop-Loss oder Take-Profit, wenn flache Candles in einem Trend auftreten, da dies auf eine Abschwächung der Bewegung hinweisen kann.
