# Weiße Kerze

Weiße Kerze (bullische Kerze) ist ein klassisches Candlestick-Muster, das entsteht, wenn der Schlusskurs über dem Eröffnungskurs liegt. Diese Kerze spiegelt eine bullische Marktstimmung wider, bei der Käufer während der Kerzenbildungsperiode den Preis kontrollierten.

##### Hauptmerkmale:

- Der Eröffnungskurs liegt unter dem Schlusskurs (O < C).
- Der Kerzenkörper ist normalerweise weiß gefärbt (oder grün in modernen Charts).
- Weist auf die Dominanz von Käufern gegenüber Verkäufern hin.
- Die Größe des Kerzenkörpers zeigt die Stärke der bullischen Bewegung.

![Weißes Kerzenmuster](../../../images/whitecandlepattern.png)

### Interpretation

Weiße Kerze signalisiert bullischen Druck im Markt:

- Je länger der Kerzenkörper ist, desto stärker ist der bullische Druck.
- Eine lange weiße Kerze nach einem Abwärtstrend kann auf eine mögliche Umkehr hinweisen.
- Kurze Schatten zeigen, dass Bullen den Preis während der gesamten Periode kontrollierten.
- Aufeinanderfolgende weiße Kerzen weisen auf einen stabilen Aufwärtstrend hin.

### Handelsstrategien

Obwohl eine einzelne weiße Kerze normalerweise kein eigenständiges Handelssignal ist, kann sie als Teil einer breiteren Strategie verwendet werden:

- Bestätigung eines Aufwärtstrends oder einer Umkehr nach einer Abwärtsbewegung.
- Suche nach langen weißen Kerzen an Unterstützungsniveaus für mögliche Long-Positionen.
- Verwendung in Kombination mit anderen Candlestick-Mustern, zum Beispiel einer weißen Kerze nach einer bullischen Umschließung.
- Identifikation von Widerstandsniveaus nach einer Serie aufeinanderfolgender weißer Kerzen.
