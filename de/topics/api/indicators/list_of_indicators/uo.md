# UO

**ultimativer Oszillator (UO)** ist ein 1976 von Larry Williams entwickelter technischer Indikator zur Messung von Momentum über mehrere Zeitrahmen. Durch einen gewichteten Durchschnitt für drei unterschiedliche Zeitrahmen weist der Indikator weniger Volatilität und weniger Handelssignale auf als Indikatoren, die nur auf einem einzigen Zeitrahmen beruhen.

Um den Indikator zu verwenden, nutzen Sie die Klasse [UltimateOscillator](xref:StockSharp.Algo.Indicators.UltimateOscillator).
