# PVT

**Price Volume Trend (PVT)** ist ein kumulativer Indikator, der Preisänderungen mit Volumen multipliziert, um Kauf- oder Verkaufsdruck anzuzeigen.

Um den Indikator verwenden zu können, müssen Sie die Klasse [PriceVolumeTrend](xref:StockSharp.Algo.Indicators.PriceVolumeTrend) verwenden.
