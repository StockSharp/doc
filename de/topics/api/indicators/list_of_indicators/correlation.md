# Correlation

**Correlation** oder **Korrelationsabhängigkeit** ist eine statistische Beziehung zwischen zwei oder mehr Zufallsvariablen (oder Variablen, die mit einem gewissen Grad an Genauigkeit als solche betrachtet werden können), wobei Änderungen der Werte einer oder mehrerer dieser Variablen mit systematischen Änderungen der Werte einer oder mehrerer anderer Variablen einhergehen.

Das mathematische Maß für die Korrelation zwischen zwei Zufallsvariablen ist das Korrelationsverhältnis bzw. Korrelationskoeffizient. Es charakterisiert die Stärke der Beziehung zwischen Variablen.

Correlation-Koeffizient
1. Kann Werte von -1 bis +1 annehmen.
2. Das Vorzeichen des Koeffizienten gibt die Richtung der Beziehung an (direkt oder invers).
3. Der absolute Wert gibt die Stärke der Beziehung an.
4. Immer basierend auf Zahlenpaaren.
