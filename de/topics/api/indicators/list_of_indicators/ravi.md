# RAVI

**Bereichsbewegungs-Bestätigungsindex (Ravi)** ist ein Indikator für die technische Analyse, der das Vorhandensein eines Trends auf dem Markt und seine Richtung bestimmt, basierend auf einem Paar einfacher gleitender Durchschnitte mit anpassbaren Zeiträumen.

Um den Indikator verwenden zu können, müssen Sie die Klasse [RangeActionVerificationIndex](xref:StockSharp.Algo.Indicators.RangeActionVerificationIndex) verwenden.
