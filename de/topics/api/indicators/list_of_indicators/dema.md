# DEMA

**Doppelter exponentieller gleitender Durchschnitt (DEMA)** verwendet mehrere (doppelte) exponentielle gleitende Durchschnitte (EMA), um Verzögerungen bei der Preisprognose zu vermeiden.

Um den Indikator verwenden zu können, müssen Sie die Klasse [DoubleExponentialMovingAverage](xref:StockSharp.Algo.Indicators.DoubleExponentialMovingAverage) verwenden.
