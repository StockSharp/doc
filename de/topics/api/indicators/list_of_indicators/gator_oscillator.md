# Gator-Oszillator

**Gator-Oszillator** ist ein von Bill Williams entwickelter Oszillator. Er ist eng mit dem ähnlichen Alligator-Indikator verwandt. Als Trendindikator ist er am nützlichsten in Märkten, die eine starke Richtungsbewegung aufweisen.

Um den Indikator verwenden zu können, müssen Sie die Klasse [GatorOscillator](xref:StockSharp.Algo.Indicators.GatorOscillator) verwenden.
