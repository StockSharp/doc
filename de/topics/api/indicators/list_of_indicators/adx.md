# ADX

**Welles Wilders ADX (Durchschnittlicher Richtungsindex)** ist eine Gruppe von Richtungsbewegungsindikatoren. Die Linien bilden den Directional Movement Index (DMI): ADX, DI+ und DI-. ADX zeigt die Trendstärke an, DI+ und DI- die aktuelle Preisrichtung.

Zur Verwendung des Indikators müssen Sie [AverageDirectionalIndex](xref:StockSharp.Algo.Indicators.AverageDirectionalIndex) verwenden.
