# RSI

**Relative-Stärke-Index (RSI)** ist ein Momentum-Indikator, der das Ausmaß der jüngsten Preisänderungen misst, um die Bedingungen für überkaufte oder überverkaufte Preise einer Aktie oder eines anderen Vermögenswerts zu beurteilen.

Um den Indikator verwenden zu können, müssen Sie die Klasse [RelativeStrengthIndex](xref:StockSharp.Algo.Indicators.RelativeStrengthIndex) verwenden.
