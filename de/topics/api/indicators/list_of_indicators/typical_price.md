# Typischer Preis

**Typischer Preis** berechnet den Durchschnitt aus High-, Low- und Close-Werten einer Kerze.

Um den Indikator zu verwenden, nutzen Sie die Klasse [TypicalPrice](xref:StockSharp.Algo.Indicators.TypicalPrice).
