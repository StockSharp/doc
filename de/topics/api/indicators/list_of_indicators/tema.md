# TEMA

**Triple Exponential Moving Average (TEMA)** verwendet mehrere (dreifache) exponentielle gleitende Durchschnitte (EMA), um Verzögerungen bei der Preisprognose zu vermeiden.

Um den Indikator verwenden zu können, müssen Sie die Klasse [TripleExponentialMovingAverage](xref:StockSharp.Algo.Indicators.TripleExponentialMovingAverage) verwenden.
