# VHF

**Vertikal-Horizontal-Filter (VHF)** - der Vertical-Horizontal-Filter wurde 1991 von Adam White entwickelt. Dieser Indikator wird in der technischen Analyse verwendet, um Phasen zu erkennen, in denen sich der Preis in einem Trend befindet (Aufwärts- oder Abwärtstrend), oder in denen der Markt in eine Überlastungsphase beziehungsweise Seitwärtsbewegung übergeht.

Um den Indikator zu verwenden, nutzen Sie die Klasse [VerticalHorizontalFilter](xref:StockSharp.Algo.Indicators.VerticalHorizontalFilter).
