# Optimal Tracking

Der **Optimal Tracking Filter**-Indikator passt schnelle Preisänderungen an und ist relativ gleichmäßig, wenn der Preis einen Nebeneffekt hat. Der Effekt dieses Filters ähnelt dem Adaptive Moving Average von Kaufman.

Um den Indikator verwenden zu können, müssen Sie die Klasse [OptimalTracking](xref:StockSharp.Algo.Indicators.OptimalTracking) verwenden.
