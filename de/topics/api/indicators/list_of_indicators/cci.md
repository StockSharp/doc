# CCI

**Commodity-Channel-Index (CCI)** ist ein technischer Indikator, der auf der Analyse der Abweichung des aktuellen Preises von seinem Durchschnittswert und dem statistisch durchschnittlichen absoluten Wert basiert.

Zur Verwendung des Indikators müssen Sie die Klasse [CommodityChannelIndex](xref:StockSharp.Algo.Indicators.CommodityChannelIndex) verwenden.
