# TRIX

**TRIX** ist ein Oszillator, der zur Bestimmung überverkaufter und überkaufter Märkte oder als Momentum-Indikator verwendet wird. Wie viele Oszillatoren schwankt TRIX um die Nulllinie. Wird er als Oszillator verwendet, weist ein positiver Wert auf einen überkauften Markt und ein negativer Wert auf einen überverkauften Markt hin. Wird TRIX als Momentum-Indikator verwendet, signalisiert ein positiver Wert eine Zunahme des Momentums und ein negativer Wert eine Abnahme des Momentums.

Um den Indikator zu verwenden, nutzen Sie die Klasse [Trix](xref:StockSharp.Algo.Indicators.Trix).
