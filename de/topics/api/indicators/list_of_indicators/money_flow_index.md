# Geldflussindex

**Geldflussindex (MFI)** berechnet die Differenz zwischen eingehenden und ausgehenden Geldflüssen. Wenn der Basiswert des Vermögenswerts unter der Differenz liegt, deutet dies auf einen Anstieg der eingehenden Geldmasse hin, was bedeutet, dass der Markt bullisch ist. Wenn das Gegenteil zu beobachten ist, bedeutet dies, dass Anleger das Instrument verlassen und der Markt rückläufig ist.
Der Indikator ist ein technischer Oszillator zur Bestimmung überkaufter oder überverkaufter Bedingungen in einem Vermögenswert. Es kann auch verwendet werden, um Divergenzen zu identifizieren, die auf eine Trendänderung des Preises hinweisen. Der Oszillator bewegt sich zwischen 0 und 100.

Um den Indikator zu verwenden, sollte die Klasse [MoneyFlowIndex](xref:StockSharp.Algo.Indicators.MoneyFlowIndex) verwendet werden.
