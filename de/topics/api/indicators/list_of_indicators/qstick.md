# QStick

**Qstick** ist ein technischer Indikator, der zur Bestimmung von Trends in Kerzendiagrammen verwendet wird. Er wird berechnet, indem der gleitende Durchschnitt für N Perioden aus der Differenz zwischen Eröffnungs- und Schlusskursen ermittelt wird. Der positive Qstick-Wert bedeutet, dass der Kaufdruck zunimmt.

Um den Indikator verwenden zu können, müssen Sie die Klasse [QStick](xref:StockSharp.Algo.Indicators.QStick) verwenden.
