# Lineare Regressionsprognose

**Lineare Regressionsprognose (LRF)** prognostiziert zukünftige Preiswerte basierend auf einer linearen Regression über einen ausgewählten Zeitraum.

Um den Indikator verwenden zu können, müssen Sie die Klasse [LinearRegressionForecast](xref:StockSharp.Algo.Indicators.LinearRegressionForecast) verwenden.
