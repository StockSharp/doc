# Mittlere Abweichung

Der Indikator **Mittlere Abweichung** zeigt die durchschnittliche Abweichung des Preises von seinem einfachen gleitenden Durchschnitt (SMA) über einen bestimmten Zeitraum.

Um den Indikator zu verwenden, sollte die Klasse [MeanDeviation](xref:StockSharp.Algo.Indicators.MeanDeviation) verwendet werden.
