# Volumengewichteter gleitender Durchschnitt

**Volumengewichteter gleitender Durchschnitt (VWMA)** - der Indikator zeigt den volumen­gewichteten Preis für einen bestimmten Zeitraum. Er folgt dem Preis als wellenförmige Linie und weist eine gewisse Abweichung gegenüber dem Preis-Chart auf.

Um den Indikator zu verwenden, nutzen Sie die Klasse [VolumeWeightedMovingAverage](xref:StockSharp.Algo.Indicators.VolumeWeightedMovingAverage).
