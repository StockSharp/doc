# Medianpreis

Der **Medianpreis**-Indikator zeigt den mittleren Preis für die Kerze.

Um den Indikator verwenden zu können, müssen Sie die Klasse [MedianPrice](xref:StockSharp.Algo.Indicators.MedianPrice) verwenden.
