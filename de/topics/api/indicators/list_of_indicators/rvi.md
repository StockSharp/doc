# RVI

Der **Relative Vigor Index (RVI, relative energy index)**-Indikator vergleicht den Preis mit einer bestimmten Preisspanne und gibt einen Hinweis auf die Stärke der Preisbewegung. Höhere RVI-Werte deuten auf eine Zunahme der Trendstärke hin, während niedrigere Werte auf eine Trendabnahme hinweisen.

Um den Indikator verwenden zu können, müssen Sie die Klasse [RelativeVigorIndex](xref:StockSharp.Algo.Indicators.RelativeVigorIndex) verwenden.
