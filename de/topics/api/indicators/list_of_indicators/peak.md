# Spitzenwert

Der Indikator **Spitzenwert** zeigt den Spitzenwert für den Zeitraum an.

Um den Indikator verwenden zu können, müssen Sie die Klasse [Peak](xref:StockSharp.Algo.Indicators.Peak) verwenden.
