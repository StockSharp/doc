# Standard Error

Der **Standard Error**-Indikator ist eine Schätzung der mittleren quadratischen Abweichung des Regressionskoeffizienten von seinem wahren Wert.

Um den Indikator verwenden zu können, müssen Sie die Klasse [StandardError](xref:StockSharp.Algo.Indicators.StandardError) verwenden.
