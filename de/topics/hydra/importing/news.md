# News

Um Nachrichten zu importieren, wahlen Sie im Hauptmenu der Anwendung **Import \=\> News**.

![hydra import news](../../../images/hydra_import_news.png)

## Nachrichtenimportprozess

1. Fuhren Sie **CSV Import Settings** aus.

   Siehe Import von [Candles](candles.md).
2. Importparameter fur [S#](../../api.md)-Felder konfigurieren.

   Siehe Import von [Candles](candles.md).
3. Um eine Vorschau der Daten anzuzeigen, klicken Sie auf die Schaltflache **Preview**
4. Klicken Sie auf die Schaltflache **Import**.
