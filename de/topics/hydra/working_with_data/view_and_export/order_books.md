# Order Books

Waehlen Sie im erscheinenden Fenster die Instrumente und das erforderliche Zeitintervall aus und klicken Sie auf die Schaltflaeche ![hydra find](../../../../images/hydra_find.png):

![hydra export depth](../../../../images/hydra_export_depth.png)

> [!TIP]
> Order Books koennen aus [Order Log and Level 1 files](../any_market_data_types.md) erstellt werden. Ausserdem koennen Sie die Tiefe und den Aktualisierungszeitraum des Order Books anpassen.

Die empfangenen Werte koennen [in das erforderliche Format exportiert](../export_data.md) werden.
