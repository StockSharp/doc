# Level 1

Waehlen Sie im erscheinenden Fenster die Instrumente und das erforderliche Zeitintervall aus und klicken Sie auf die Schaltflaeche ![hydra find](../../../../images/hydra_find.png):

![hydra export level1](../../../../images/hydra_export_level1.png)

Sie koennen ausserdem auswaehlen, welche Arten von Aenderungen exportiert werden sollen. Dies erfolgt ueber die unten gezeigte Dropdown-Liste:

![hydra export security change selected](../../../../images/hydra_export_security_change_selected.png)

Die empfangenen Werte koennen [in das erforderliche Format exportiert](../export_data.md) werden.
