# Level 1

Wählen Sie im erscheinenden Fenster die Instrumente und das erforderliche Zeitintervall aus und klicken Sie auf die Schaltfläche ![hydra find](../../../../images/hydra_find.png):

![hydra Level1-Ansicht exportieren](../../../../images/hydra_export_level1.png)

Sie können ausserdem auswählen, welche Arten von Änderungen exportiert werden sollen. Dies erfolgt über die unten gezeigte Dropdown-Liste:

![hydra export ausgewähltes Wertpapier ändern](../../../../images/hydra_export_security_change_selected.png)

Die empfangenen Werte können [in das erforderliche Format exportiert](../export_data.md) werden.
