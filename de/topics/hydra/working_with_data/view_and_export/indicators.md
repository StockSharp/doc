# Indikatoren

Wählen Sie im erscheinenden Panel das Instrument und den gewünschten Zeitbereich aus, geben Sie den Datentyp an, aus dem der Indikator erstellt werden soll, setzen Sie den [Indikator](../../../api/indicators/list_of_indicators.md) und seine Parameter, und klicken Sie dann auf die Schaltfläche ![Hydra Suchschaltfläche](../../../../images/hydra_find.png):

![Hydra Indikator exportieren](../../../../images/hydra_export_indicator.png)

Um den Chart der Werte anzuzeigen, klicken Sie einfach auf die Schaltfläche ![Hydra Kerzen](../../../../images/hydra_candles.png).

![Hydra Indikatoransicht exportieren](../../../../images/hydra_export_indicator_view.png)

Die empfangenen Werte können [in das erforderliche Format exportiert](../export_data.md) werden.
