# Indikatoren

Wählen Sie im erscheinenden Panel das Instrument und den gewünschten Zeitbereich aus, geben Sie den Datentyp an, aus dem der Indikator erstellt werden soll, setzen Sie den [indicator](../../../api/indicators/list_of_indicators.md) und seine Parameter, und klicken Sie dann auf die Schaltfläche ![hydra find](../../../../images/hydra_find.png): :

![hydra export indicator](../../../../images/hydra_export_indicator.png)

Um den Chart der Werte anzuzeigen, klicken Sie einfach auf die Schaltfläche ![hydra candles](../../../../images/hydra_candles.png).

![hydra export indicator view](../../../../images/hydra_export_indicator_view.png)

Die empfangenen Werte können [in das erforderliche Format exportiert](../export_data.md) werden.
