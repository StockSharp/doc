# Instrumente bearbeiten

Um ein Instrument zu bearbeiten, zum Beispiel wenn es ohne alle erforderlichen Daten erstellt wurde, doppelklicken Sie auf das Instrument oder klicken Sie auf die Schaltfläche ![Hydra Bearbeitung](../../../images/hydra_edit.png), um das Fenster zu öffnen, in dem Sie die notwendigen Änderungen vornehmen können:

Wechseln Sie zum Fenster **Instrumente**.

![Hydra Instrument bearbeiten 00](../../../images/hydra_security_edit_00.png)

Das Bearbeitungsfenster wird geöffnet.

![Hydra Instrument bearbeiten](../../../images/hydra_security_edit.png)

Bei Bedarf können Sie die Instrumentengruppe bearbeiten. Wählen Sie eine Instrumentengruppe aus und klicken Sie auf die Schaltfläche ![Hydra Bearbeitung](../../../images/hydra_edit.png).

![Hydra Instrumente bearbeiten 00](../../../images/hydra_securities_edit_00.png)

Bearbeiten Sie danach die Gruppe nach Bedarf.

![Hydra Instrumente bearbeiten](../../../images/hydra_securities_edit.png)

Wenn alle ausgewählten Instrumente in einem Feld denselben Wert haben, wird dieser Wert angezeigt. Wenn sich die Werte unterscheiden, bleibt das Feld leer. Wenn zum Beispiel zwei Instrumente einen Preisschritt von 1 haben, aber eines eine Lot-Größe von 10 und das andere von 100, zeigt das Feld Preisschritt den Wert 1 an, während das Feld Volumenschritt leer bleibt.
