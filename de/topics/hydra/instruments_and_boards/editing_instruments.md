# Instrumente bearbeiten

Um ein Instrument zu bearbeiten, zum Beispiel wenn es ohne alle erforderlichen Daten erstellt wurde, doppelklicken Sie auf das Instrument oder klicken Sie auf die Schaltflaeche ![hydra edit](../../../images/hydra_edit.png), um das Fenster zu oeffnen, in dem Sie die notwendigen Aenderungen vornehmen koennen:

Wechseln Sie zum Fenster **Securities**.

![hydra security edit 00](../../../images/hydra_security_edit_00.png)

Das Bearbeitungsfenster wird geoeffnet.

![hydra security edit](../../../images/hydra_security_edit.png)

Bei Bedarf koennen Sie die Instrumentengruppe bearbeiten. Waehlen Sie eine Instrumentengruppe aus und klicken Sie auf die Schaltflaeche ![hydra edit](../../../images/hydra_edit.png).

![hydra securities edit 00](../../../images/hydra_securities_edit_00.png)

Bearbeiten Sie danach die Gruppe nach Bedarf.

![hydra securities edit](../../../images/hydra_securities_edit.png)

Wenn alle ausgewaehlten Instrumente in einem Feld denselben Wert haben, wird dieser Wert angezeigt. Wenn sich die Werte unterscheiden, bleibt das Feld leer. Wenn zum Beispiel zwei Instrumente einen Price Step von 1 haben, aber eines eine Lot-Groesse von 10 und das andere von 100, zeigt das Feld Price Step den Wert 1 an, waehrend das Feld Volume Step leer bleibt.
