# Neue Quelle erstellen

Um eine eigene Quelle hinzuzufügen, müssen Sie einen eigenen [IMessageAdapter](xref:StockSharp.Messages.IMessageAdapter) erstellen. Wie das geht, ist unter [Erstellen eines eigenen Connectors](../api/connectors/creating_own_connector.md) beschrieben. Nach der Erstellung müssen Sie die resultierende dll-Datei in den Ordner mit [Hydra](../hydra.md) kopieren.
