# Instrumentenliste

Einrichtung des Instruments zum Herunterladen.

Für eine Reihe von Quellen ist es möglich, Einstellungen für das Herunterladen der erforderlichen Instrumente vorzunehmen.

Betrachten wir als Beispiel das Herunterladen von Instrumenten aus der Quelle **ByBit**:

1. Klicken Sie auf **Instrumente herunterladen**. Standardmäßig ist der Eintrag **Alle** markiert - es werden alle Instrumente der Quelle heruntergeladen.![Hydra Instrumentenauswahl](../../../images/hydra_choose_securitiy.png)
2. Entfernen Sie die Markierung **Alle** und markieren Sie **Zusatzbedingungen**. Danach wird eine Liste erweiterter Einstellungen für das herunterzuladende Instrument geöffnet; die Markierung **Allgemein** stellt die kurze Liste wieder her.![Hydra Instrumentenauswahl 00](../../../images/hydra_choose_securitiy_00.png)
3. Es sollen die Instrumente heruntergeladen werden, deren Code BTC enthält. Dazu geben wir BTC im Feld **Code** an und klicken auf **OK**.![Hydra Instrumentenauswahl 01](../../../images/hydra_choose_securitiy_01.png)

   Danach lädt das Programm [Hydra](../../hydra.md) alle Instrumente herunter, die den angegebenen Parametern entsprechen, und meldet, wie viele davon neu sind. ![Hydra Instrumentenauswahl 02](../../../images/hydra_choose_securitiy_02.png)![Hydra Instrumentenauswahl 03](../../../images/hydra_choose_securitiy_03.png)

Die Einstellung ermöglicht dem Benutzer, verschiedene Parameter für das herunterzuladende Instrument auszuwählen.

So kann der Benutzer zum Beispiel Folgendes auswählen:

- **Preis- und Volumenschritt**
- **Minimales und maximales Volumen**
- **Externe ID** ![Hydra Instrumentenauswahl 04](../../../images/hydra_choose_securitiy_04.png)
- Für Optionen können der **Basiswert** und der **Asset-Typ** (Typ des zugrunde liegenden Instruments) festgelegt werden. ![Hydra Instrumentenauswahl 05](../../../images/hydra_choose_securitiy_05.png)
