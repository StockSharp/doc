# Instrumentenliste

Einrichtung des Instruments zum Herunterladen.

Für eine Reihe von Quellen ist es möglich, Einstellungen für das Herunterladen der erforderlichen Instrumente vorzunehmen.

Betrachten wir als Beispiel das Herunterladen von Instrumenten aus der Quelle **Interactive Brokers**:

1. Wählen Sie **Instrumente herunterladen** und klicken Sie auf die Schaltfläche **Erweiterte Bedingung**.![Hydra Instrumentenauswahl](../../../images/hydra_choose_securitiy.png)
2. Danach wird eine Liste erweiterter Einstellungen für das herunterzuladende Instrument geöffnet.![Hydra Instrumentenauswahl 00](../../../images/hydra_choose_securitiy_00.png)
3. Es soll ein Instrument heruntergeladen werden, das die folgenden Parameter erfüllt: Aktie von APPLE, Währung - US-Dollar. Dazu setzen wir die Instrumentparameter wie unten gezeigt und klicken auf **OK**.![Hydra Instrumentenauswahl 01](../../../images/hydra_choose_securitiy_01.png)

   Danach lädt das Programm [Hydra](../../hydra.md) alle Instrumente herunter, die den angegebenen Parametern entsprechen. ![Hydra Instrumentenauswahl 02](../../../images/hydra_choose_securitiy_02.png)![Hydra Instrumentenauswahl 03](../../../images/hydra_choose_securitiy_03.png)

Die Einstellung ermöglicht dem Benutzer, verschiedene Parameter für das herunterzuladende Instrument auszuwählen.

So kann der Benutzer zum Beispiel Folgendes auswählen:

- **Preis- und Volumenschritt**
- **Minimales und maximales Volumen**
- **Externe ID** ![Hydra Instrumentenauswahl 04](../../../images/hydra_choose_securitiy_04.png)
- Für Optionen können der **Basiswert** und der **Asset-Typ** (Typ des zugrunde liegenden Instruments) festgelegt werden. ![Hydra Instrumentenauswahl 05](../../../images/hydra_choose_securitiy_05.png)
