# Portfoliooptimierung

Der [Designer](../../designer.md) kann eine Strategie gleichzeitig auf verschiedenen Instrumenten testen. Klicken Sie dazu auf die Schaltfläche [Optimierung](brute_force.md).

![Designer Portfoliotest](../../../images/designer_portfolio_testing.png)

Legen Sie in den Optimierungsparametern den Parameter **Handelsinstrument** fest und wählen Sie aus der Liste die Instrumente aus, für die Sie Tests durchführen möchten. Legen Sie im **Menüband** den Testzeitraum und den Marktdatenspeicher fest. Nach dem Klicken auf die Schaltfläche **Starten** beginnen die Tests gleichzeitig für alle Instrumente.
