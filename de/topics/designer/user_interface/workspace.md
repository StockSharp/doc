# Arbeitsbereich

Der **Arbeitsbereich** in [Designer](../../designer.md) ist eine Fensteroberflache mit Panel-Docking, ahnlich wie in Microsoft Visual Studio. Wenn Sie mit der linken Maustaste auf den Kopfbereich eines Panels klicken und die Taste gedruckt halten, können Sie das Panel an einer passenden Stelle andocken. Durch Ziehen an den Randern des Panels können Sie dessen Hohe oder Breite anpassen:
