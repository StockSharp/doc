# Börsenplätze

Im Panel **Börsenplatz-Editor** können Sie **Börsenplätze** und **Börsen** erstellen sowie vorhandene anzeigen oder anpassen.

![Börsenplätze Bildschirmfoto](../../../images/designer_boards.png)

In [S#](../../api.md) verwenden Instrumente aus verschiedenen Quellen eine einheitliche Kennung, die aus dem Instrumentencode und dem Handelsplatzcode besteht. Die Syntax lautet **[Instrumentcode]@[Handelsplatzcode]**. Für Aktien von **AAPL** an der Börse **NASDAQ** lautet die Kennung zum Beispiel **AAPL@NASDAQ**. Jedes Instrument ist einem bestimmten Handelsplatz zugeordnet, auf dem es gehandelt wird. Ein Instrument kann jedoch auf verschiedenen Handelsplätzen gehandelt werden. In diesem Fall unterscheiden sich die Handelsplatzcodes. Für jeden Handelsplatz können Sie einen Arbeitsplan mit Arbeitstagen und Wochenenden einrichten.

Die Börse kann mehrere Börsenplätze mit unterschiedlichen Handelsbedingungen haben (Sitzungszeit, Provision usw.). Jeder Börsenplatz ist jedoch einer bestimmten Börse zugeordnet. Wenn Sie daher im **Börsenplatz-Editor** einen Börsenplatz auswählen, ändern sich die Informationen über die Börse automatisch zur Börse, auf der sich der Börsenplatz befindet. Für jede Börse können Sie den Börsencode, das Land sowie den russischsprachigen und englischsprachigen Namen festlegen.
