# Tick-Trades

Die Komponente **Ausführungs-Feed** ist eine Tabelle mit Trades, die vollständige Informationen zu allen Trades für die ausgewählten Instrumente anzeigt.

Der **Ausführungs-Feed** verfügt über einen Filter zur Auswahl der benötigten Instrumente. Außerdem können Sie im Fenster [Benachrichtigungseinstellungen](../../../terminal/notifications.md) Benachrichtigungen für Ereignisse konfigurieren, die mit den ausgewählten Instrumenten verbunden sind.
