# P&L-Kurve

Die P\/L-Komponente ist ein Chart für Gewinn\/Verlust (nicht realisiert), Gewinn\/Verlust (realisiert) und Provision. In der oberen linken Ecke des Charts werden alle grafischen Elemente angezeigt, die dem Chart hinzugefügt wurden. Wenn Sie das Kontrollkästchen beim grafischen Element ![Designer Grafikelement 00](../../../../images/designer_schedule_00.png) entfernen, wird das Element ebenfalls aus dem Chart entfernt. Ein Klick auf die Schaltfläche ![Designer Grafikelement 01](../../../../images/designer_schedule_01.png) öffnet die Einstellungen für das grafische Element.
