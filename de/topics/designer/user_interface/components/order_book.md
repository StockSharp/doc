# Order book

Die Komponente **Order book** ist eine Tabelle mit Limit-Orders für Kauf und Verkauf. Oben in der Komponente wählen Sie die Datenquelle aus, aus der die Daten empfangen werden. Die Datenquelle ist der Würfel [Order Book Panel](../../strategies/using_visual_designer/elements/market_depths/order_book_panel.md). 

In der Strategie können Sie mehrere unterschiedliche Typen von Orderbüchern (oder Orderbücher aus verschiedenen Instrumenten) gleichzeitig verwenden und sie in verschiedenen Panels anzeigen.
