# Portfolios

Für die Arbeit mit Portfolios gibt es das Panel **Portfolios**. Sie können es öffnen, indem Sie auf der Registerkarte **Allgemein** auf die Schaltfläche Portfolios klicken.

![Designer Portfolios-Panel A 00](../../../images/designer_panel_portfolios_00.png)

Das Panel **Portfolios** ist eine Tabelle, die die grundlegenden Daten zum Portfolio sowie die aktuellen Positionen für diese Portfolios anzeigt. Durch Doppelklick auf ein Portfolio oder eine Position wird das Fenster **Portfolio erstellen** bzw. **Position erstellen** geöffnet, in dem Sie das ausgewählte Portfolio oder die ausgewählte Position bearbeiten können. Um ein neues Portfolio oder eine neue Position zu erstellen, klicken Sie auf die Schaltfläche ![Designer Schaltungs-Panel 01](../../../images/designer_panel_circuits_01.png) und wählen den entsprechenden Eintrag im Dropdown-Menü.

![Designer Portfolios-Panel A 01](../../../images/designer_panel_portfolios_01.png)

Wenn Sie auf die Schaltfläche ![Designer Benachrichtigungsglocke](../../../images/designer_alert_bell.png) klicken, wird das Fenster [Benachrichtigungseinstellungen](../../terminal/notifications.md) geöffnet.
