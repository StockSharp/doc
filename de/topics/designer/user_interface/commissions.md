# Kommissionen

Im Panel [Backtesting-Einstellungen](components/backtesting_settings.md) können Sie die Einstellungen zur Provisionsüberwachung festlegen.

Im Fenster **Provisionen** sollten Sie den Provisionstyp auswählen, den Provisionswert festlegen und die Bedingung angeben, unter der die Provision berechnet wird.

![Designer Provisionsregel](../../../images/designer_commission_rule.png)

### Liste der Provisionstypen

Liste der Provisionstypen

- **Aufträge (Anzahl)** - die Provision für die Anzahl der Orders.
- **Auftrag** - die Provision für die Order.
- **Auftrag (Volumen)** - die Provision für das Volumen in der Order.
- **Ausführung (Anzahl)** - die Provision für die Anzahl der Trades.
- **Ausführung (Preis)** - die Provision für den Trade-Preis.
- **Ausführung** - die Provision für den Trade.
- **Ausführung (Volumen)** - die Provision für das Volumen in der Order.
- **Handelsinstrument** - die Instrumentenprovision.
- **Instrument (Typ)** - die Provision für den Instrumententyp.
- **Umsatz** - die Provision für den Umsatz.
- **Board** - die Board-Provision.
