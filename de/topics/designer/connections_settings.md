# Verbindungseinstellungen

1. Wenn Sie auf den Pfeil neben der Schaltfläche **Verbinden** ![Designer The quick access toolbar 00](../../images/designer_quick_access_toolbar_00.png) klicken, erscheint die Schaltfläche **Verbindungseinstellungen**:

![Designer The connection settings 00](../../images/designer_connection_settings_00.png)

2. Wenn Sie auf die Schaltfläche **Verbindungseinstellungen** klicken, öffnet sich das Fenster **Verbindungseinstellungen**, das in 3 Bereiche unterteilt ist:

![Designer The connection settings 01](../../images/designer_connection_settings_01.png)

3. Ein Klick auf die Schaltfläche ![Designer The connection settings 02](../../images/designer_connection_settings_02.png) aktiviert die Dropdown-Liste der unterstützten Connectors. Die ausgewählten Connectors werden im Bereich Nr. 1 angezeigt. Die Schaltfläche ![Designer The connection settings 03](../../images/designer_connection_settings_03.png) entfernt den ausgewählten Connector. Die erste Spalte von Bereich Nr. 1 zeigt, ob der Connector verbunden wird, wenn Sie auf die Schaltfläche Connect ![Designer The connection settings 04](../../images/designer_connection_settings_04.png) klicken, oder ob er nicht verbunden wird ![Designer The connection settings 05](../../images/designer_connection_settings_05.png). Diese Werte werden mit den Schaltflächen ![Designer The connection settings 06](../../images/designer_connection_settings_06.png) und ![Designer The connection settings 07](../../images/designer_connection_settings_07.png) gesetzt.

Die Felder **Marktdaten** und **Trades** zeigen, ob der Connector Marktdaten und die Arbeit mit Orders unterstützt.

4. Wenn das Kontrollkästchen **Auto-connect** ausgewählt ist, verbindet sich die Verbindung automatisch beim Start von [Designer](../designer.md).

5. Bereich Nr. 2 zeigt die Einstellungen des ausgewählten Connectors. Wenn auf ![Designer The connection settings 09](../../images/designer_connection_settings_09.png) geklickt wird, leitet das Programm zur Dokumentation ([API](../api.md)) für die Konfiguration des ausgewählten Connectors weiter.

  > [!IMPORTANT]
  > **Advanced settings** werden nur in besonderen Fällen benötigt; ihre Änderung wird nicht empfohlen.

6. Ein Klick auf die Schaltfläche **Prüfen** prüft die Verbindung des aktuellen Connectors. Wenn die Prüfung fehlschlägt, erscheint ein Fenster mit einem Fehler, der den Grund der erfolglosen Verbindung beschreibt. Ist die Prüfung erfolgreich, erscheint folgendes Fenster:

![Designer The connection settings 10](../../images/designer_connection_settings_10.png)

7. Bereich Nr. 3 zeigt Datentypen, die vom Connector empfangen oder übertragen werden. Durch Klicken auf das Kontrollkästchen ![Designer The connection settings 11](../../images/designer_connection_settings_11.png)\/ ![Designer The connection settings 12](../../images/designer_connection_settings_12.png) können Sie die Übertragung oder den Empfang für diesen Datentyp aktivieren bzw. deaktivieren.

8. Ein Klick auf die Schaltfläche **Network settings** öffnet das Fenster **Proxy-server settings**:

![Designer The connection settings 13](../../images/designer_connection_settings_13.png)
