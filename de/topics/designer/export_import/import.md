# Import

Der Designer ermöglicht den Import jeder Art von Daten: Strategien, Blöcke und Indikatoren. Es gibt mehrere Möglichkeiten zum Import:

- Klicken Sie im Panel **Schemes** mit der rechten Maustaste auf den Strategieordner und wählen Sie im erscheinenden Menü **Import**.
- Drücken Sie im Tab **Common** die Schaltfläche **Import** und wählen Sie im erscheinenden Menü **Strategy**, **Own element** oder **Indicator**:

![Designer Import strategies 00](../../../images/designer_import_strategies_00.png)

Wenn bereits Daten mit demselben Namen vorhanden sind, erscheint ein Fenster, das anbietet, sie zu überschreiben oder unter anderem Namen hinzuzufügen:

![Designer Import strategies 01](../../../images/designer_import_strategies_01.png)
