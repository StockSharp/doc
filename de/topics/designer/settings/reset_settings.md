# Einstellungen zurücksetzen

> [!CAUTION]
> **Lesen Sie diesen Abschnitt sorgfältig, bevor Sie Einstellungen zurücksetzen.**

Das **Schnellzugriffspanel** befindet sich standardmäßig oben im Programmfenster und enthält die Einstellungsschaltfläche ![Designer The quick access toolbar 02](../../../images/designer_quick_access_toolbar_02.png). Wenn Sie auf ![Designer The quick access toolbar 02](../../../images/designer_quick_access_toolbar_02.png) klicken, können Sie den Startmodus ändern, die Oberflächensprache ändern oder alle Einstellungen zurücksetzen.

![Designer Reset language settings 00](../../../images/designer_reset_language_settings_00.png)

Wenn Sie **Einstellungen zurücksetzen** auswählen, öffnet sich ein Bestätigungsfenster.

![Designer Reset language settings 01](../../../images/designer_reset_language_settings_01.png)

Nachdem Sie auf **OK** geklickt haben, werden alle Einstellungen auf ihre Standardwerte zurückgesetzt. Das Verzeichnis der Programmeinstellungen wird vollständig geleert. **Alle erstellten Strategien, heruntergeladenen Instrumente und anderen im Einstellungsverzeichnis gespeicherten Informationen werden gelöscht.**
