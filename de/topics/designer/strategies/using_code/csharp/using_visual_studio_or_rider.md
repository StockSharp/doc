# Visual Studio oder Rider verwenden

Bei der Verwendung von **Visual Studio** und **JetBrains Rider** zum Erstellen von Code, der in **Designer** ausgeführt wird, ist die einzige Möglichkeit der permanente [Dateiimport](../../../export_import/import.md). Der Grund ist die spezielle Dateistruktur der von **Designer** erstellten Dateien, wodurch es unmöglich ist, die Dateien direkt zu ändern, selbst bei Strategien, die in C# erstellt wurden. Wenn externe Programme zum Schreiben von Code benötigt werden, wird daher empfohlen, den Ansatz mit [DLL-Dateien](../../using_dll.md) zu verwenden.
