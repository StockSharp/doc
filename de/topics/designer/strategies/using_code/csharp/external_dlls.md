# Externe DLLs

Beim Erstellen von Inhalten aus **Quellcode** können Sie neben den Bibliotheken der [API](../../../../api.md) auch andere C#-Bibliotheken verwenden, einschließlich eigener Bibliotheken. Diese Bibliotheken müssen mit .NET 10 kompatibel sein. Um eine Referenz auf eine Bibliothek hinzuzufügen, klicken Sie im Code-Panel auf die Schaltfläche **Referenzen**. Danach öffnet sich das Fenster **Zusätzliche Referenzen**, in dem Sie die benötigten Bibliotheken hinzufügen oder entfernen können:

- **Assembly** - eine Referenz auf eine Bibliotheksdatei hinzufügen;
- **Projekt** - eine Referenz auf eigenen Code oder einen im Designer erstellten Indikator hinzufügen;
- **Löschen** - die markierte Referenz löschen.

Die Referenztabelle zeigt Name, Pfad und Status jeder Referenz, und die Zeile **Suche** darüber findet eine Referenz in einer langen Liste. Wenn eine Referenz nicht hinzugefügt werden kann, wird der Grund rot unter der Tabelle angezeigt.
