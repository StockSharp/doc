# Externe DLLs

Beim Erstellen von Inhalten aus **Source Code** können Sie neben den Bibliotheken der [API](../../../../api.md) auch andere C#-Bibliotheken verwenden, einschließlich eigener Bibliotheken. Diese Bibliotheken müssen mit .NET 6.0 kompatibel sein. Um eine Referenz auf eine Bibliothek hinzuzufügen, klicken Sie im Tab **Backtest** auf die Schaltfläche **References**. Danach öffnet sich das Fenster **Extra references**, in dem Sie die benötigten Bibliotheken hinzufügen oder entfernen können:
