# Externe DLLs

Beim Erstellen von Inhalten aus **Quellcode** können Sie neben den Bibliotheken der [API](../../../../api.md) auch andere C#-Bibliotheken verwenden, einschließlich eigener Bibliotheken. Diese Bibliotheken müssen mit .NET 6.0 kompatibel sein. Um eine Referenz auf eine Bibliothek hinzuzufügen, klicken Sie im Tab **Rücktest** auf die Schaltfläche **Referenzen**. Danach öffnet sich das Fenster **Zusätzliche Referenzen**, in dem Sie die benötigten Bibliotheken hinzufügen oder entfernen können:
