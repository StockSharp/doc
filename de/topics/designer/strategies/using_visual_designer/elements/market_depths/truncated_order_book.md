# Truncated order book

![Designer MarketDepthTruncateDiagramElement 00](../../../../../../images/designer_marketdepthtruncatediagramelement_00.png)

Der Würfel wird verwendet, um ein auf eine angegebene Tiefe gekürztes Orderbuch zu erhalten.

### Eingehende Sockets

- **Order book** ist ein Orderbuch, das gekürzt werden soll.

### Ausgehende Sockets

- **Order book** ist das gekürzte Orderbuch.

### Parameter

- **Depth** - die maximale Tiefe des Orderbuchs.
