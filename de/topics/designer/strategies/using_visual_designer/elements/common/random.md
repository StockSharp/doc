# Zufallswert

![Designer Random 00](../../../../../../images/designer_random_00.png)

Dieser Block wird verwendet, um einen Zufallswert zu generieren.

## Eingehende Sockets

- **Trigger** - das Signal (jeder Wert außer `False`), das den Zeitpunkt bestimmt, zu dem ein generierter Zufallswert über den ausgehenden Socket weitergegeben werden soll.

## Ausgehende Sockets

- **Value** - ein Zufallswert.

## Parameter

- **Min** - die minimal zulässige Wertgrenze.
- **Max** - die maximal zulässige Wertgrenze.
