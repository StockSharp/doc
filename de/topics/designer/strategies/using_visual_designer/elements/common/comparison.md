# Comparison

![Designer Comparison 00](../../../../../../images/designer_comparison_00.png)

Ein Element wird verwendet, um zwei Eingabeobjekte zu vergleichen.

## Eingehende Sockets

- **Value 1** – Werte, die verglichen werden können (zum Beispiel ein numerischer Wert, eine Zeichenfolge, ein Indikatorwert usw.).
- **Value 2** – Werte, die verglichen werden können (zum Beispiel ein numerischer Wert, eine Zeichenfolge, ein Indikatorwert usw.).

## Ausgehende Sockets

- **Flag** – der Flag-Wert (zeigt den Zustand an und hat zwei Werte: oben (true) und unten (false)).

## Parameter

- **Left** – der Parameter, dessen Wert auf der linken Seite des Vergleichs verwendet wird.
- **Operator** – die Bedingung, nach der die übergebenen Werte verglichen werden müssen.
- **Right** – der Parameter, dessen Wert auf der rechten Seite des Vergleichs verwendet wird.

Wenn Sie den Operator ändern, ändert sich der Würfelname automatisch in den Namen des Operators.
