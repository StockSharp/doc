# Index

![Designer Indexansicht 00](../../../../../../images/designer_index_00.png)

Der Würfel wird verwendet, um einen eigenen Index zu erstellen.

### Ausgehende Anschlüsse

Ausgehende Anschlüsse

- **Handelsinstrument** - der berechnete Index, dargestellt als **Handelsinstrument**.

### Parameter

Parameter

- **Index** - die mathematische Formel einer Kombination mehrerer Instrumente (zum Beispiel (AAPL@NASDAQ+10)\*(abs(20\/GOOG@NYSE)).
- **Fehler ignorieren** - das gesetzte Flag gibt an, dass Fehler bei der Berechnung des Index ignoriert werden.
- **Erweiterte Informationen berechnen** - das gesetzte Flag gibt an, dass bei der Berechnung des Index zusätzlich zu den Basisinformationen (Gesamtvolumen, Eröffnungspreis, Schlusskurs, Höchstpreis, Tiefstpreis) auch die erweiterten Informationen (Gesamtumsatz, Eröffnungsvolumen, Schlussvolumen, Höchstvolumen, Tiefstvolumen) berechnet werden.

Verfügbare mathematische Formeln entsprechen denen im Würfel [Formel](../common/formula.md).
