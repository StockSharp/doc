# Black-Scholes

![Black-Scholes-Optionsmodellblock im Designer](../../../../../../images/designer_black_scholes_00.png)

Dieser Block wird verwendet, um ein Optionspreismodell zu erstellen.

### Eingehende Anschlüsse

Eingehende Anschlüsse

- **Option** - der Strike, für den das Modell erstellt werden soll.

### Ausgehende Anschlüsse

Ausgehende Anschlüsse

- **Modell** - das Preismodell (zum Beispiel Black-Scholes).

### Parameter

Parameter

- **Black-Modell** - ein Flag, das angibt, ob ein Black-Scholes-Modell erstellt werden soll.
