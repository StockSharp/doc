# Black-Scholes

![Designer Black Sols 00](../../../../../../images/designer_black_scholes_00.png)

Dieser Block wird verwendet, um ein Optionspreismodell zu erstellen.

### Eingehende Sockets

Eingehende Sockets

- **Option** - der Strike, für den das Modell erstellt werden soll.

### Ausgehende Sockets

Ausgehende Sockets

- **Model** - das Preismodell (zum Beispiel Black-Scholes).

### Parameter

Parameter

- **Black Model** - ein Flag, das angibt, ob ein Black-Scholes-Modell erstellt werden soll.
