# Basket

![Designer Black Basket 00](../../../../../../images/designer_black_basket_00.png)

Dieser Block wird verwendet, um ein Optionspreismodell zu erstellen.

### Eingehende Sockets

Eingehende Sockets

- **Options** - die Strikes, für die das Modell erstellt werden soll.

### Ausgehende Sockets

Ausgehende Sockets

- **Model** - das Preismodell (zum Beispiel Black-Scholes).

### Parameter

Parameter

- **Black Model** - ein Flag, das angibt, ob ein Black-Scholes-Modell erstellt werden soll.
