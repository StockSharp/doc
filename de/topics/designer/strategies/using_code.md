# Programmiersprachen

[Designer](../../designer.md) unterstützt drei Programmiersprachen zum Erstellen von Handelsstrategien:

- [C#](using_code/csharp.md)
- [F#](using_code/fsharp.md)
- [Python](using_code/python.md)

Umfangreiche Strategiebeispiele in C# und Python sind im Ordner [AlgoTrading API](https://github.com/StockSharp/AlgoTrading/tree/main/API) verfügbar. Sie funktionieren alle mit [Designer](../../designer.md).

## C#

C# ist die Hauptsprache für die Entwicklung von Handelsstrategien. Alle Komponenten, Beispiele und der Kerncode sind in C# geschrieben. C# bietet vollständigen Zugriff auf die gesamte Architektur der Plattform [S#](../../api.md).

## F#

F# ist eine funktionale Programmiersprache von Microsoft. Handelsstrategien in F# haben vollständigen Zugriff auf alle API-Funktionen und können sowohl für Testing als auch für Live-Handel verwendet werden.

## Python

Die Python-Integration ermöglicht das Schreiben von Handelsstrategien mit der Programmiersprache Python und erleichtert Python-Entwicklern die Arbeit mit der Plattform.
