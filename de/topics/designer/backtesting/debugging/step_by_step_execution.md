# Schrittweise Ausführung

Um die schrittweise Ausführung zu starten, setzen Sie einen Haltepunkt auf das Element, bei dem die Ausführung zuerst anhalten soll. Nachdem [Designer](../../../designer.md) an diesem Element angehalten hat, klicken Sie auf die Schaltfläche ![Designer Debug 03](../../../../images/designer_debug_03.png)**Next element**. Designer wechselt von einem Element zum nächsten und zeigt Schritt für Schritt, wie die Strategie ausgeführt wird.

Um in ein **Composite element** hineinzugehen, warten Sie, bis die schrittweise Ausführung dieses Element erreicht, und klicken Sie dann auf ![Designer Debug 04](../../../../images/designer_debug_04.png)**Step in**. Der nächste Schritt wird innerhalb des **Composite element** ausgeführt. Um das **Composite element** zu verlassen, klicken Sie auf ![Designer Debug 05](../../../../images/designer_debug_05.png)**Step out**.
