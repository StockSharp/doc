# Schrittweise Ausführung

Um die schrittweise Ausführung zu starten, setzen Sie einen Haltepunkt auf das Element, bei dem die Ausführung zuerst anhalten soll. Nachdem [Designer](../../../designer.md) an diesem Element angehalten hat, klicken Sie auf die Schaltfläche ![Designer Fehlersuche 03](../../../../images/designer_debug_03.png)**Nächstes Element**. Designer wechselt von einem Element zum nächsten und zeigt Schritt für Schritt, wie die Strategie ausgeführt wird.

Um in ein **Zusammengesetztes Element** hineinzugehen, warten Sie, bis die schrittweise Ausführung dieses Element erreicht, und klicken Sie dann auf ![Designer Fehlersuche 04](../../../../images/designer_debug_04.png)**Schritt hinein**. Der nächste Schritt wird innerhalb des **Zusammengesetztes Element** ausgeführt. Um das **Zusammengesetztes Element** zu verlassen, klicken Sie auf ![Designer Fehlersuche 05](../../../../images/designer_debug_05.png)**Schritt heraus**.
