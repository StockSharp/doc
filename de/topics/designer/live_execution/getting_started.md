# Erste Schritte

Um eine Strategie zum **Live-Handel** hinzuzufügen, klicken Sie im Panel [Schemata](../user_interface/schemas.md) mit der rechten Maustaste auf die gewünschte Strategie aus dem Ordner **Strategien** und wählen ![Designer Live-Handel 00](../../../images/designer_live_trade_00.png) **Live-Handel**. Die Strategie wird dem Ordner **Live-Handel** im Panel **Schemata** hinzugefügt.

![Designer Live-Handel 01](../../../images/designer_live_trade_01.png)

Sie können eine Strategie auch zum Live-Handel hinzufügen, indem Sie im Tab **Rücktest** auf die Schaltfläche ![Designer Live-Handel 00](../../../images/designer_live_trade_00.png) **Live-Handel** klicken.

![Designer Live-Handel 02](../../../images/designer_live_trade_02.png)

Der Ordner Trade enthält die Strategien, die für die Ausführung im Live-Handel hinzugefügt wurden. Laufende Strategien sind mit dem Zeichen ![Designer Schaltungs-Panel 02](../../../images/designer_panel_circuits_02.png) markiert, gestoppte Strategien mit dem Zeichen ![Designer Schaltungs-Panel 03](../../../images/designer_panel_circuits_03.png).
