# Strategien außerhalb von Designer ausführen

In [Designer](../../designer.md) erstellte Strategien können sowohl in eigenen Programmen ausgeführt werden, die auf der [API](../../api.md) basieren, als auch in den Anwendungen [Runner](../../runner.md) oder [Shell](../../shell.md).

- [Runner](../../runner.md) ist schneller und verbraucht weniger Speicher als [Designer](../../designer.md), sodass Strategien leistungsfähiger ausgeführt werden. Dieser Ansatz ist ideal für die Ausführung von Strategien auf einem Server. Weitere Details finden Sie unter [Export aus Designer](../../runner/export_from_designer.md).

- [Shell](../../shell.md) wird als Quellcode bereitgestellt. Dieser Ansatz ist ideal für die Verteilung von Strategien mit einer speziell für die Strategien erstellten individuellen Oberfläche. Weitere Details finden Sie unter [Ausführen einer in Designer erstellten Strategie](../../shell/run_strategies_from_designer.md).
