# Echtzeit

Auf der Registerkarte **Real-time** können Sie im Handel gestartete Strategien verwalten.

![Shell realtime 00](../../../images/shell_realtime_00.png)

Durch Klicken auf die Schaltfläche **Add** ![Designer Creation tool 00](../../../images/designer_creation_tool_00.png) können Sie eine Strategie hinzufügen, um den Handel zu starten. Jede hinzugefügte Strategie wird auf einer separaten Registerkarte geöffnet und auf der Registerkarte **Strategies** zur Strategieliste hinzugefügt.

Auf der Registerkarte **Strategies** können Sie Strategien löschen, starten, stoppen und konfigurieren. Dasselbe ist auf einer einzelnen Strategieregisterkarte möglich. Die einzelne Strategieregisterkarte enthält ausführlichere Informationen zur Strategie, Statistiken, eine Liste der registrierten Orders und Trades der Strategie usw.
