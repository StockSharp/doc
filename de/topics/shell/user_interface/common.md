# Allgemein

Auf der Registerkarte **Allgemein** können Sie allgemeine Informationen zu Portfolios, Orders, Trades und Instrumenten anzeigen. Außerdem können Sie hier das Theme der [Shell](../../shell.md)-Oberfläche festlegen.

![Shell Allgemein 00](../../../images/shell_common_00.png)

Auf der Registerkarte **Instrumente** können Sie Instrumente aus dem lokalen Speicher laden und Instrumenteinstellungen ändern.

![Shell Allgemein 01](../../../images/shell_common_01.png)
