# Strategien aus dem Designer ausführen

[Shell](../shell.md) kann Strategien ausführen, die im [Designer](../designer.md) erstellt wurden.

Um eine im [Designer](../designer.md) erstellte Strategie zu starten, wählen Sie sie auf der Registerkarte [Echtzeit](user_interface/real_time.md) aus und klicken Sie auf die Schaltfläche **Designer-Strategie hinzufügen**. Wählen Sie im angezeigten Fenster die aus dem [Designer](../designer.md) exportierte Strategiedatei aus.

![Shell Designer-Strategie starten 00](../../images/shell_run_designer_strategy_00.png)

Danach erscheint sie in der Liste der verfügbaren Strategien.

![Shell Designer-Strategie starten 01](../../images/shell_run_designer_strategy_01.png)

Wenn Sie die hinzugefügte Strategie auswählen, können Sie die erforderlichen Parameter setzen und sie für den Handel starten.

![Shell Designer-Strategie starten 02](../../images/shell_run_designer_strategy_02.png)
