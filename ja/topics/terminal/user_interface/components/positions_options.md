# ポジション（オプション）

**Positions (options)** は、オプション別ポジションをグラフィカルに表示するものです。

オプション別ポジションを表示するには、原資産と、その価格に基づいてポジションが構築されるオプションを選択する必要があります。

さらに、オプションの正確な満期日のフィルター、および最小\/最大ストライクのフィルターを指定できます。
