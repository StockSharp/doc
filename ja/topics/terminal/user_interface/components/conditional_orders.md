# 条件付き注文

**条件付き注文** コンポーネントは注文のテーブルであり、すべての条件付き注文に関する完全な情報を表示します。注文上でマウスの右ボタンをクリックするとパネルが表示され、このパネルから新しい条件付き注文の登録、選択した条件付き注文のキャンセルまたは変更を行うことができます。

![Terminal Orders conditional panel 01](../../../../images/terminal_orders_conditional_panel_01.png)

**注文登録** ボタンをクリックすると、ウィンドウが表示されます。新しい条件付き注文を登録するには、その内容を入力して **送信** をクリックします。

![Terminal Orders conditional panel 02](../../../../images/terminal_orders_conditional_panel_02.png)

**注文変更** ボタンをクリックすると、ウィンドウが表示されます。条件付き注文を変更するには、必要な変更を行って **送信** をクリックします。

![Terminal Orders conditional panel 03](../../../../images/terminal_orders_conditional_panel_03.png)
