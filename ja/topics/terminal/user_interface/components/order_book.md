# 板情報

**Order book** コンポーネントは、買いと売りの指値注文を表示するテーブルです。

設定 ![Designer The quick access toolbar 02](../../../../images/designer_quick_access_toolbar_02.png) ボタンをクリックすると、必要な銘柄とポートフォリオを設定し、板情報の表示オプションを構成できるパネルが表示されます。

注文は、**Buy/Sell** ボタンをクリックするか、板情報自体の **Bid/Offer** 列のセルをクリックして登録できます。
