# コンポーネント

取引中は、プロセスを完全に制御する必要がある場合があります。完全な制御と分析のために、**Terminal** では、**リボン** の **コンポーネント** グループで選択して追加できるグラフィカルコンポーネントが用意されています。

![Designer コンポーネント](../../../images/designer_components.png)

- [銘柄](components/instruments.md) - 選択したすべての銘柄に関する情報を表示する銘柄テーブルです。
- [Level 1](components/level_1.md) - 選択した銘柄の Level 1 の変更履歴を表示するテーブルです。
- [売買](components/buy_sell.md) - 選択した銘柄の最良価格情報を表示するパネルグループであり、選択した銘柄について必要な数量の買いまたは売りを行うことができます。
- [板情報](components/order_book.md) - 買いおよび売りの指値注文のテーブルです。
- [チャート](components/chart.md) - 選択した銘柄のローソク足とインジケーターを描画できます。
- [P&L エクイティ](../../designer/user_interface/components/pnl_equity.md) - 損益（未実現）、損益（実現）、および手数料のチャートです。
- [約定](../../designer/user_interface/components/trades.md) - ストラテジーのすべての約定に関する完全な情報を表示する約定テーブルです。
- [注文](../../designer/user_interface/components/orders.md) - ストラテジーのすべての注文に関する完全な情報を表示する注文テーブルです。
- [条件付き注文](components/conditional_orders.md) - ストラテジーのすべての条件付き注文に関する完全な情報を表示する条件付き注文のテーブルです。
- [ポジション](../../designer/user_interface/components/positions.md) - 現在のポジションのテーブルです。
- [ティック約定](../../designer/user_interface/components/tick_trades.md) - 選択した銘柄のすべての約定に関する完全な情報を表示する約定テーブルです。
- [ポジション](../../designer/user_interface/components/positions.md) - ポジションのチャートです。
- [ニュース](components/news.md) - 接続から受信したニュースを表示します。
- [ポジション（オプション）](components/positions_options.md) - オプション別ポジションのグラフィック表示です。
- [オプションデスク](components/option_desk.md) - 原資産に対して選択したオプションの主要パラメーターを表示するテーブルです。
- [スマイルボラティリティ](components/smile_volatility.md) - 同一の原資産で異なる権利行使価格を持つオプションについて、期待ボラティリティ水準をグラフィックで表したものです。
- [注文ログ](components/order_log.md) - 選択した銘柄のすべての注文に関する完全な情報を表示する注文テーブルです。
