# ステータスバー

[Terminal](../../terminal.md) のウィンドウの下部には、ステータスバーがあります。左から順に、次の項目があります。

- **状態** — **接続が切断されました**、**接続中**、**接続済み**、**切断中**、または接続エラーのテキスト。ここには、Terminal が最後に行った操作の結果（たとえば「レイアウトを保存しました。」や「銘柄を作成しました: …」）も表示されます。
- **StockSharp のニュース** — サイトのニュースの見出し。矢印のボタンで切り替えられます。
- ログの **警告とエラーのカウンター** — ログに警告やエラーがある場合に表示されます。
- **最新のログメッセージ** — 右クリックすると、そのテキストがクリップボードにコピーされます。ログ全体は [ログパネル](logs.md) にあります。
- **1 秒あたりのティック数**（tps） — 直前の 1 秒間に Terminal が受信した市場約定（ティック）の数。
- **遅延**（ms） — 最後のティックまたは最後の Level 1 の変更が、取引所での時刻より何ミリ秒遅れて届いたか。
- Terminal のデータが使用している **メモリ**（メガバイト単位）。
- 起動してからのプログラムの **稼働時間**。
- **ログディレクトリ** ボタン — Terminal がログを書き込むフォルダーを開きます。

![Terminal ステータスバー 00](../../../images/terminal_status_bar_00.png)

Terminal が接続されていない間は、ティックと遅延は計測されません。バーには **0 tps** と **— ms** が表示されます。
