# 通知パネル

**通知** パネルは、現在設定されているすべての通知に関する情報を表示するテーブルです。

![Terminal Notifications Panel](../../../images/terminal_notifications_panel.png)

**通知** パネルでは、既存の通知を編集 ![Designer Creating a repository of historical data 01](../../../images/designer_creating_repository_of_historical_data_01.png) したり、削除 ![Designer Creating a repository of historical data 02](../../../images/designer_creating_repository_of_historical_data_02.png) したり、新しい通知 ![Designer Creating a repository of historical data 00](../../../images/designer_creating_repository_of_historical_data_00.png) を設定したりできます。
