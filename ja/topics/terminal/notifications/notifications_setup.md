# 通知設定

通知を設定するには、通知パネル（[通知パネル](notification_panel.md)）の ![Designer Creation tool 00](../../../images/designer_creation_tool_00.png) ボタンをクリックするか、通知をサポートするパネル（[ポートフォリオ](../user_interface/portfolios.md)、[約定フィード](../user_interface/components/trades_feed.md)、[ニュース](../user_interface/components/news.md)、[Level 1](../user_interface/components/level_1.md)）内の ![Designer Alert Bell](../../../images/designer_alert_bell.png) ボタンを直接クリックする必要があります。

![Designer Notifications Setting](../../../images/designer_notifications_setting.png)

通知は、次のデータ型の変更に対して設定できます: Portfolio、Customer code、Broker、Depository、Server time、Trade、Data type、Cancellation、Order ID、Order ID (string)、Order ID (board)、Derivative、Derivative (string)、Price、Volume (order)、Volume (trade)、Visible volume、Direction、Remainder、Order type、Status、Comment、Message to order、System order、Order expiration time、Execution condition、Order ID、Order ID (string)、Price、Trade initiator、Open interest、Error、Condition、Uptrend、Commission、Delay、Slippage、ID (user)、Currency、P\/L、Position、Market Maker。

通知には、次の形式があります。

- **Window** – メッセージ付きの小さなポップアップウィンドウが画面の隅に表示されます。
- **Melody** – メロディーが再生されます。
- **SMS** – メッセージが SMS 経由で送信されます。
- **Email** – メッセージがメールで送信されます。
- **Speech** – メッセージがコンピューター生成音声で読み上げられます。
- **Log** – メッセージが Designer のログウィンドウに送信されます。
- **Off** – 通知は表示されません。
