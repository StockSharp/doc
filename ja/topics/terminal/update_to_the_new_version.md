# 新しいバージョンへの更新

Terminal は StockSharp Installer を使って更新します。更新ガイドでは、利用可能なバージョンの確認とアプリケーションの更新方法を説明しています。

[アプリの更新](../installer/update_apps.md)

新しいクロスプラットフォーム版の Terminal を、以前の Terminal の設定フォルダーで初めて起動すると、以前の Terminal に残されていたとおりにパネルが配置されます。その後は、新しい Terminal が自分のレイアウトを保存します。
