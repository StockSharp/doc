# エミュレーション

**エミュレーション** タブでは、ヒストリカルデータ上でストラテジーをテストできます。

![Shell エミュレーション 00](../../../images/shell_emulation_00.png)

**追加** ![Designer 追加ボタン 00](../../../images/designer_creation_tool_00.png) ボタンをクリックすると、テスト用のストラテジーを追加できます。追加された各ストラテジーは、個別のタブで開かれます。

個別のストラテジータブには、ストラテジー、統計、ストラテジーの登録済み注文と約定のリストなどに関する詳細な情報があります。このタブでは、テストパラメーター、ヒストリカルデータへのパス、テストの開始日と終了日、およびヒストリカルデータストレージの形式を設定できます。
