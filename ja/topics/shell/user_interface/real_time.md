# リアルタイム

**リアルタイム** タブでは、取引で起動されたストラテジーを管理できます。

![Shell realtime 00](../../../images/shell_realtime_00.png)

**追加** ![Designer Creation tool 00](../../../images/designer_creation_tool_00.png) ボタンをクリックすると、取引を開始するためのストラテジーを追加できます。追加された各ストラテジーは個別のタブで開かれ、**ストラテジー** タブのストラテジー一覧に追加されます。

**ストラテジー** タブでは、ストラテジーの削除、開始、停止、および設定を行えます。同じ操作は個別のストラテジータブでも実行できます。個別のストラテジータブには、ストラテジー、統計、ストラテジーの登録済み注文と約定のリストなどに関する、より詳細な情報があります。
