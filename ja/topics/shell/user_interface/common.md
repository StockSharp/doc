# 共通

**Common** タブでは、ポートフォリオ、注文、約定、銘柄に関する一般情報を表示できます。ここでは、[Shell](../../shell.md) インターフェイスのテーマも設定できます。

![Shell Common 00](../../../images/shell_common_00.png)

**Securities** タブでは、ローカルストレージから銘柄をアップロードし、銘柄設定を変更できます。

![Shell Common 01](../../../images/shell_common_01.png)
