# Envelope

**Envelope** は、移動平均を特定の値だけオフセットして作成されるチャネルを形成するインジケーターです。このインジケーターの構築方法は、外側のラインが平均からどれだけ離れるかを計算する方法を除き、ボリンジャーバンド の構築と完全に同じです。ボリンジャーバンド がこの計算に標準偏差を使用するのに対し、**Envelope** では、この距離は設定で手動で指定します。
設定するパラメーターは、移動平均の期間と偏差の大きさです。

このインジケーターを使用するには、[Envelope](xref:StockSharp.Algo.Indicators.Envelope) クラスを使用する必要があります。
