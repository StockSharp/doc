# PGO

**プリティグッドオシレーター (PGO)** は Mark Johnson によって開発されたテクニカルインジケーターで、現在の終値を過去の価格と比較し、ボラティリティを考慮して、市場の買われ過ぎまたは売られ過ぎ状態を判断します。

このインジケーターを使用するには、[PrettyGoodOscillator](xref:StockSharp.Algo.Indicators.PrettyGoodOscillator) クラスを使用する必要があります。

## 説明

プリティグッドオシレーター (PGO) は、特定の期間における過去の値に対して、現在の終値の強さを評価するインジケーターです。PGO は、過去レンジ内での現在価格の位置だけでなく、このレンジのボラティリティも考慮するため、変化する市場環境により適応的です。

"プリティグッドオシレーター" という名称は、作成者の実用的な考え方を反映しています。このインジケーターは完璧なツールであることを主張するものではなく、現在の市場状況を評価するための「かなり良い」方法を提供します。

PGO は、買われ過ぎおよび売られ過ぎ状態の特定に加え、トレンド反転に先行する可能性のあるダイバージェンスの検出に特に有用です。

## パラメーター

このインジケーターには、次のパラメーターがあります。
- **Length** - 計算期間（既定値: 14）

## 計算

プリティグッドオシレーター の計算は、次の手順で行います。

1. 指定期間における最高値（最高値）と最安値（最安値）を決定します。
   ```
   最高値 = Highest(High, Length)
   最安値 = Lowest(Low, Length)
   ```

2. 指定期間における終値の標準偏差を計算します。
   ```
   標準偏差 = StdDev(Close, Length)
   ```

3. プリティグッドオシレーター を計算します。
   ```
   PGO = (Close - (最高値 + 最安値) / 2) / 標準偏差
   ```

ここで:
- Close - 現在の終値
- High - 最高価格
- Low - 最低価格
- Length - 計算期間
- StdDev - 標準偏差

## 解釈

プリティグッドオシレーター は、次のように解釈できます。

1. **買われ過ぎおよび売られ過ぎ水準**:
   - +2 を上回る値は、多くの場合、市場の買われ過ぎ状態を示します
   - -2 を下回る値は、多くの場合、市場の売られ過ぎ状態を示します
   - 極端な値（+3/-3 以上/以下）は、著しい買われ過ぎ/売られ過ぎ状態と潜在的な反転を示す場合があります

2. **ゼロラインのクロスオーバー**:
   - PGO がゼロラインを下から上へ交差する場合、強気シグナルと見なせます
   - PGO がゼロラインを上から下へ交差する場合、弱気シグナルと見なせます

3. **ダイバージェンス**:
   - 強気ダイバージェンス: 価格が新しい安値を形成する一方で、PGO はより高い安値を形成します
   - 弱気ダイバージェンス: 価格が新しい高値を形成する一方で、PGO はより低い高値を形成します
   - ダイバージェンスは、多くの場合、大きなトレンド反転に先行します

4. **トレンド確認**:
   - 正の PGO 値は、価格が平均レンジを上回っていることを示し、上昇トレンドの特徴です
   - 負の PGO 値は、価格が平均レンジを下回っていることを示し、下降トレンドの特徴です

5. **トレンドの強さの評価**:
   - PGO 値がゼロから離れるほど、現在のトレンドは強くなります
   - PGO がゼロラインに収束することは、トレンドの弱まりを示す場合があります

6. **シグナルフィルタリング**:
   - PGO は、他のインジケーターからのシグナルをフィルタリングするために使用できます
   - たとえば、PGO が正の場合は強気シグナルのみを考慮し、PGO が負の場合は弱気シグナルのみを考慮します

7. **ポジションの手仕舞い**:
   - 極端な PGO 値は、利益確定のシグナルとして使用できます
   - たとえば、PGO が +2 を超えたらロングポジションを手仕舞いし、PGO が -2 を下回ったらショートポジションを手仕舞いします
