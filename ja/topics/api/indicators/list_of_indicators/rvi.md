# RVI

**相対活力指数 (RVI, 相対エネルギー指数)** 指標は、価格を特定の価格レンジと比較し、価格変動の一定の強さを示します。RVI の値が高いほどトレンドの強さが増していることを示し、低い値はトレンドの低下を示します。

この指標を使用するには、[RelativeVigorIndex](xref:StockSharp.Algo.Indicators.RelativeVigorIndex) クラスを使用する必要があります。
