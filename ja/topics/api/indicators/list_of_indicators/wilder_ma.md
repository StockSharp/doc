# ワイルダー移動平均

**Wilder移動平均 (WilderMA)** は、加重移動平均インジケーターです。他のすべての移動平均インジケーターと同様に、WMA インジケーターは市場ノイズを平滑化し、市場トレンドをより明確に表示します。この目的を達成するために、このインジケーターは市場の変動 (ノイズ) をフィルタリングし、計算対象となる期間の価格値を平均化します。同時に、EMA、LWMA、SMMA などのすべての加重インジケーターの計算と同様に、平均価格に追加の値 (重み) が加えられます。

このインジケーターを使用するには、[WilderMovingAverage](xref:StockSharp.Algo.Indicators.WilderMovingAverage) クラスを使用する必要があります。
