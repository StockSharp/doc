# KC

**ケルトナーチャネル (KC)** は、中心線として指数移動平均（EMA）を使用し、チャネル幅を決定するために平均真の値幅（ATR）を使用する、ボラティリティバンドのセットで構成されるテクニカルインジケーターです。

インジケーターを使用するには、[KeltnerChannels](xref:StockSharp.Algo.Indicators.KeltnerChannels) クラスを使用する必要があります。

## 説明

ケルトナーチャネルは 3 本のラインで構成されます。
1. **中心線**: 通常は 20 期間 EMA で表されます
2. **上側バンド**: 中心線に ATR の乗数を加えたもの
3. **下側バンド**: 中心線から同じ ATR 乗数を引いたもの

このインジケーターは 1960 年代に Chester Keltner によって開発され、その後 Linda Raschke によって修正されました。彼女は単純移動平均（SMA）を指数移動平均（EMA）に置き換え、チャネル幅の計算に高値-安値レンジの代わりに ATR を使用し始めました。

ケルトナーチャネルは、トレーダーがトレンド方向と潜在的なサポートおよびレジスタンスレベルを判断するのに役立ちます。また、価格がそれぞれ上側または下側のバンドに接触する、またはそれを突破する場合に、買われすぎおよび売られすぎ状態を特定するためにも使用されます。

## パラメーター

このインジケーターには、次のパラメーターがあります。
- **期間** - EMA と ATR を計算する期間（デフォルト値: 20）
- **乗数** - ATR の乗数。チャネル幅を決定します（デフォルト値: 2.0）

## 計算

ケルトナーチャネルの計算には、次の手順があります。

1. 指数移動平均を計算します。
   ```
   中央線 = EMA(価格, 期間)
   ```

2. 平均真の値幅を計算します。
   ```
   ATR = Length 期間の平均真の範囲
   ```

3. 上側バンドと下側バンドを計算します。
   ```
   上限バンド = 中央線 + (乗数 * ATR)
   下限バンド = 中央線 - (乗数 * ATR)
   ```

ここで:
- Price - 通常は終値
- EMA - 指数移動平均
- ATR - 平均真の値幅
- Length - EMA と ATR の計算期間
- Multiplier - チャネル幅を決定する乗数

## 解釈

ケルトナーチャネルは、次のように解釈できます。

1. **トレンド方向**:
   - 3 本すべてのラインが上向きの場合、上昇トレンドを示します
   - 3 本すべてのラインが下向きの場合、下降トレンドを示します
   - ラインの水平な動きは横ばいトレンドを示します

2. **ブレイクアウト**:
   - 価格が上側バンドを上抜ける場合、強い上方向モメンタムを示す場合があります
   - 価格が下側バンドを下抜ける場合、強い下方向モメンタムを示す場合があります
   - ブレイクアウトは、多くの場合、ブレイクアウト方向へのエントリーシグナルとして使用されます

3. **中心線への回帰**:
   - 上側または下側バンドを突破した後、価格は中心線に戻ることがよくあります
   - 中心線はサポートまたはレジスタンスレベルとして機能する場合があります

4. **買われすぎおよび売られすぎ状態**:
   - 上側バンド付近またはそれを超えた価格は、買われすぎ状態を示す場合があります
   - 下側バンド付近またはそれを超えた価格は、売られすぎ状態を示す場合があります
   - トレンド市場では、価格が「極端な」ゾーンに長期間とどまることがあります

5. **チャネルの収縮と拡大**:
   - チャネルの狭まり（バンド間距離の減少）はボラティリティの低下を示し、多くの場合、強い価格変動に先行します
   - チャネルの拡大はボラティリティの増加を示します

6. **取引戦略**:
   - 「端から中央へ」戦略: 価格が上側または下側バンドに接触したときにポジションを開き、中心線を目標にする
   - ブレイクアウト戦略: 価格が上側または下側バンドを突破したときにポジションを開き、同じ方向への継続的な動きを期待する
   - 「中央から端へ」戦略: 価格が中心線から反発したときにポジションを開き、上側または下側バンドを目標にする
