# MMI

**市場の意地悪さ指数 (MMI)** は、市場がトレンド状態にあるのか、横ばい（カオス）状態にあるのかを判断するために開発されたテクニカル指標です。

この指標を使用するには、[MarketMeannessIndex](xref:StockSharp.Algo.Indicators.MarketMeannessIndex) クラスを使用する必要があります。

## 説明

市場の意地悪さ指数 (MMI) は、現在の市場の性質、つまりトレンド状態か横ばい状態かをトレーダーが判断するのに役立つツールです。"Meanness" という名前は、特に横ばいの動きにあるとき、市場がトレーダーに対して「意地悪」または予測不能に振る舞うことがあるという考えを反映しています。

MMI は、単純な線形パターンに従わない価格値ペア（通常は終値）の数と、分析対象ペア総数に対するその比率を数えることに基づいています。この指標は、特定期間における価格変動の「カオス」または「ランダム性」を測定します。

この指数は 0 から 100 の範囲で振動します。
- 低い値（通常 50 未満）は、トレンドの動きが優勢であることを示します
- 高い値（通常 50 超）は、横ばいまたはカオスな動きが優勢であることを示します

## パラメーター

この指標には次のパラメーターがあります。
- **Length** - 計算期間（デフォルト値: 20）

## 計算

市場の意地悪さ指数 の計算には、次の手順が含まれます。

1. 指定された Length 期間内で、連続する終値 (Close) のペアの集合を作成します。

2. 「非順序的」ペアの数を数えます。ペアがトレンドに典型的な線形パターンに従わない場合、そのペアは非順序的と見なされます。2 つの連続するペア (P1, P2) と (P2, P3) が反対方向（差分の符号が異なる）である場合、そのペアは非順序的と見なされます。

3. MMI をパーセンテージ比率として計算します。
   ```
   MMI = (非連続ペア数 / ペア総数) * 100
   ```

形式的には、これは次のように表せます。
1. 連続する各 3 価格 (Close[i-2], Close[i-1], Close[i]) について確認します。
   - (Close[i-1] - Close[i-2]) * (Close[i] - Close[i-1]) < 0 の場合、そのペアは非順序的と見なされます
   - そのようなペアの総数を数えます

2. MMI = (非順序ペアの数 / (Length - 2)) * 100

## 解釈

市場の意地悪さ指数 は次のように解釈できます。

1. **指標レベル**:
   - MMI > 50: 市場は横ばいまたはカオス状態にあります
   - MMI < 50: 市場はトレンド状態にあります
   - MMI が 100 に近いほど、市場はよりカオスです
   - MMI が 0 に近いほど、トレンドはより明確です

2. **取引ストラテジーへの適用**:
   - MMI が高い場合 (>50)、横ばい市場向けのストラテジー（例: レンジ取引、オシレーター）を使用します
   - MMI が低い場合 (<50)、トレンドストラテジー（例: トレンドフォロー）を使用します

3. **変化のダイナミクス**:
   - 高い水準からの MMI の低下は、新しいトレンド形成を示唆する可能性があります
   - 低い水準からの MMI の上昇は、トレンドの完了と保ち合いへの移行を示す可能性があります

4. **極端な値**:
   - 非常に低い値 (MMI < 20) は強いトレンドを示す可能性がありますが、買われ過ぎ/売られ過ぎの可能性も示します
   - 非常に高い値 (MMI > 80) は、どのストラテジーも適用しにくい極度にカオスな市場を示します

5. **シグナルのフィルタリング**:
   - MMI は、他の指標のフィルターとしてよく使用されます。
     - トレンド指標のシグナル (MA, MACD) は、MMI が低いときにより信頼できます
     - オシレーターのシグナル (RSI, ストキャスティクス) は、MMI が高いときにより信頼できます

6. **他の指標との組み合わせ**:
   - MMI は ADX (平均方向性指数) と組み合わせると有効に機能します
   - 低い MMI と高い ADX は、強いトレンドを確認します
   - 高い MMI と低い ADX は、横ばい市場を確認します

7. **時間枠**:
   - MMI は、市場の性格を判断するために異なる時間枠で使用できます
   - 長期 MMI は、市場の主要な状態を判断するのに役立ちます
   - 短期 MMI は、現在の状況に適したストラテジーを選択するのに役立ちます
