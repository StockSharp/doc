# 移動中央値

**移動中央値** 指標は、直近 N 個の値の中央値を計算します。移動平均と比較すると、外れ値の影響を受けにくく、
急激な価格変化を保持するため、ノイズの多い環境で有用です。

指標にアクセスするには、[Median](xref:StockSharp.Algo.Indicators.Median) クラスを使用します。

## 説明

メディアンフィルターは、移動ウィンドウ内の価格をソートし、中央の値を選択します。その結果:

- 単発の急騰や急落は出力を歪めません。
- 多くの平滑化フィルターより遅れが小さくなります。
- シグナルの形状はより角ばったままになり、反転を捉えやすくなります。

## パラメーター

- **Length** - 中央値の計算に使用するウィンドウサイズ。大きいウィンドウほど平滑化が強くなりますが、遅れも増加します。

## 使用法

- 価格データに大きなノイズが含まれる場合、移動平均の代替として 移動中央値 を適用します。
- 価格と中央値のクロスオーバーは、トレンド変化シグナルとして扱うことができます。
- 重要な価格ジャンプを維持しながらトレンドを抽出するために、中央値を他のフィルターと組み合わせます。
