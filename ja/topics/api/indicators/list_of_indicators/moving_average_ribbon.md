# MAR

**移動平均リボン (MAR)** は、トレンドの強さと方向を可視化するために、期間が段階的に増加する複数の移動平均を表示するテクニカルインジケーターです。

インジケーターを使用するには、[MovingAverageRibbon](xref:StockSharp.Algo.Indicators.MovingAverageRibbon) クラスを使用する必要があります。

## 説明

移動平均リボン (MAR) は、チャート上に「リボン」または「扇」状に表示される複数の移動平均の集合です。このインジケーターは、1 つまたは 2 つの移動平均を使用する場合よりも直感的に、現在のトレンド状態とその強さをトレーダーが可視化するのに役立ちます。

MAR には、期間が段階的に増加する複数の移動平均 (通常 5 から 10 本) が含まれます。期間間隔は、均等 (例: 10, 20, 30, 40...) にすることも、指数的 (例: 5, 10, 20, 40...) にすることもできます。

主な考え方は、これらの移動平均の相互の位置関係と形状が、現在のトレンドの状態と強さに関する有用な情報を提供し、潜在的な反転ポイントの特定に役立つというものです。

## パラメーター

このインジケーターには次のパラメーターがあります:
- **短期期間** - 移動平均の初期 (最小) 期間 (既定値: 10)
- **長期期間** - 移動平均の最終 (最大) 期間 (既定値: 100)
- **RibbonCount** - リボン内の移動平均の本数 (既定値: 10)

## 計算

移動平均リボンの計算には、次の手順が含まれます:

1. 移動平均の期間の列を決定します:
   ```
   Step = (LongPeriod - ShortPeriod) / (RibbonCount - 1)
   Periods = [ShortPeriod, ShortPeriod + Step, ShortPeriod + 2*Step, ..., LongPeriod]
   ```

2. 各期間について移動平均を計算します:
   ```
   MAs = [各期間について SMA(価格, 期間)]
   ```

ここで:
- Price - 価格 (通常は終値)
- SMA - 単純移動平均
- ShortPeriod - 初期期間
- LongPeriod - 最終期間
- RibbonCount - 移動平均の本数

注: SMA の代わりに、EMA (指数移動平均)、WMA (加重移動平均) など、他の種類の移動平均を使用できます。

## 解釈

移動平均リボンは次のように解釈できます:

1. **移動平均の相互位置**:
   - すべてのラインが期間の昇順に並んでいる (最短が上、最長が下) 場合、強い上昇トレンドを示します
   - すべてのラインが期間の降順に並んでいる (最短が下、最長が上) 場合、強い下降トレンドを示します
   - ラインが交差し、明確な順序がない場合、横ばいトレンドまたは不確実性を示します

2. **リボンの形状**:
   - 拡大するリボン (ライン間の距離が増加する) は、トレンドの強まりを示します
   - 縮小するリボン (ライン間の距離が減少する) は、トレンドの弱まりを示します
   - ラインが密集している場合、保ち合いまたは明確なトレンドの欠如を示します

3. **移動平均のクロスオーバー**:
   - ラインの交差が始まると、潜在的なトレンド変化を示す場合があります
   - 短期移動平均が長期移動平均をクロスし始めると、トレンド反転の早期シグナルになる場合があります

4. **リボンの傾斜角**:
   - 急な角度は強いトレンドを示します
   - 緩やかな角度は弱いトレンドを示します
   - リボンが水平に位置している場合、横ばいトレンドを示します

5. **リボンに対する価格の位置**:
   - 価格がリボン全体の上にある場合、強い上昇トレンドを確認します
   - 価格がリボン全体の下にある場合、強い下降トレンドを確認します
   - 価格がリボン内で推移している場合、移行状態または保ち合いを示す場合があります

6. **取引戦略**:
   - 価格がトレンド方向にリボンの端から反発したときにポジションに入ります
   - 移動平均が反対方向にクロスし始めたときにポジションを手仕舞います
   - リボン幅を使用してストップロスとテイクプロフィットを設定します
