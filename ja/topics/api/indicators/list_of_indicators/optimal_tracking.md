# 最適追跡

**最適追跡フィルター** インジケーターは、急速な価格変化に適応し、価格が横ばいの影響を受けているときには比較的滑らかになります。このフィルターの効果は Kaufman適応移動平均に似ています。

インジケーターを使用するには、[OptimalTracking](xref:StockSharp.Algo.Indicators.OptimalTracking) クラスを使用する必要があります。
