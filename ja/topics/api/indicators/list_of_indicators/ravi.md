# RAVI

**レンジアクション検証指数 (Ravi)** は、カスタマイズ可能な期間を持つ 2 本の単純移動平均に基づいて、市場におけるトレンドの有無とその方向を判定するテクニカル分析インジケーターです。

このインジケーターを使用するには、[RangeActionVerificationIndex](xref:StockSharp.Algo.Indicators.RangeActionVerificationIndex) クラスを使用する必要があります。
