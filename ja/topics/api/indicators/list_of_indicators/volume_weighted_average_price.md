# VWAP

**Volume Weighted Average Price (VWAP)** は、取引出来高で加重された平均価格を示します。

このインジケーターを使用するには、[VolumeWeightedAveragePrice](xref:StockSharp.Algo.Indicators.VolumeWeightedAveragePrice) クラスを使用する必要があります。
