# 出来高加重 MA

**Volume Weighted Moving Average (VWMA)** - このインジケーターは、一定期間における出来高加重価格を表示します。このインジケーターは波状のラインとして価格に追随し、価格チャートに対して一定の乖離を持ちます。

このインジケーターを使用するには、[VolumeWeightedMovingAverage](xref:StockSharp.Algo.Indicators.VolumeWeightedMovingAverage) クラスを使用する必要があります。
