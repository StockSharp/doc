# KER

**カウフマン効率比 (KER)** は、方向性のある価格変動を全体的なボラティリティと比較することで、価格変動の効率性を測定する、Perry Kaufman によって開発されたテクニカルインジケーターです。

インジケーターを使用するには、[KaufmanEfficiencyRatio](xref:StockSharp.Algo.Indicators.KaufmanEfficiencyRatio) クラスを使用する必要があります。

## 説明

カウフマン効率比 (KER) は、価格が移動した総経路と比較して、特定の方向にどれだけ「効率的に」動いているかを評価します。これは、特定期間におけるすべての価格変化の合計に対する、正味の方向性価格変動の比率を表します。

KER は Perry Kaufman によって開発され、当初は Kaufman適応移動平均 (KAMA) の構成要素として使用されていました。ただし、KER 自体も、市場がトレンド状態にあるのかオシレーション状態にあるのかを判断するのに役立つ有用なツールです。

KER の値は 0 から 1 の間で振動します。
- 1 に近い値は、非常に効率的な価格変動（強いトレンド）を示します
- 0 に近い値は、非効率的な価格変動（横ばい市場または高ボラティリティ）を示します

## パラメーター

このインジケーターには、次のパラメーターがあります。
- **Length** - 効率性計算の期間（デフォルト値: 10）

## 計算

カウフマン効率比 の計算には、次の手順があります。

1. 期間内の方向性変動（正味変化）を計算します。
   ```
   方向 = |Price[current] - Price[current - Length]|
   ```

2. 期間内の総変動（すべての変化の合計）を計算します。
   ```
   ボラティリティ = Sum(|Price[i] - Price[i-1]|) i = (current - Length + 1) から current まで
   ```

3. 効率比を計算します。
   ```
   KER = 方向 / ボラティリティ
   ```

ここで:
- Price - 通常は終値
- Length - 計算期間
- | | - 絶対値を表します

ボラティリティがゼロの場合（これはまれです）、ゼロ除算を避けるために KER はゼロに設定されます。

## 解釈

カウフマン効率比 は、次のように解釈できます。

1. **効率レベル**:
   - 高い KER 値（>0.6）は強いトレンドを示します
   - 中程度の KER 値（0.3-0.6）は中程度のトレンドを示します
   - 低い KER 値（<0.3）は横ばい市場または高ボラティリティを示します

2. **KER の変化**:
   - KER の上昇は、トレンドの形成または強化を示す場合があります
   - KER の低下は、トレンドの弱化または横ばいへの移行を示す場合があります

3. **取引戦略**:
   - 高効率期間（高い KER）では、トレンド戦略が望ましいです
   - 低効率期間（低い KER）では、レンジ取引戦略が望ましいです

4. **シグナルのフィルタリング**:
   - KER は、他のインジケーターからのシグナルをフィルタリングするために使用できます
   - 高い KER では、トレンドインジケーターのシグナルの信頼性が高くなります
   - 低い KER では、オシレーターのシグナルの信頼性が高くなります

5. **市場状態への適応**:
   - KER により、変化する市場状態に取引戦略を適応させることができます
   - トレーダーは、KER 値に基づいて他のインジケーターのパラメーターを動的に調整できます

6. **変化の前兆**:
   - KER の急激な変化は、新たな価格変動に先行することがよくあります
   - 高い値が続いた後の KER の低下は、潜在的なトレンド反転を警告する場合があります
