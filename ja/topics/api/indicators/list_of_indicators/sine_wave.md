# SW

**Sine Wave (SW)** は、価格変動の周期的パターンを識別するためにサインの数学関数を使用するテクニカル指標です。この指標は、周期的な市場の振動を識別し、予測することを目的としています。

この指標を使用するには、[SineWave](xref:StockSharp.Algo.Indicators.SineWave) クラスを使用する必要があります。

## 説明

Sine Wave 指標は、市場の動きには周期的な性質があり、正弦関数を使用してモデル化できるという考えに基づいています。この指標は、横ばいレンジで動く市場や、予測可能な周期的変動を持つ市場で特に有用です。

指標の主な特徴:
- 潜在的な市場反転ポイントの特定に役立ちます
- サイクル内の現在位置を判断できます
- 将来の価格変動の予測に使用できます

指標シグナル:
- サイン波の線が最小値に達し、上向きに転じ始めたときに潜在的な買い
- 線が最大値に達し、下向きに転じ始めたときに潜在的な売り

## パラメーター

- **Length** - サイン波サイクルの期間で、価格バーにおけるサイクル長を定義します。

## 計算

Sine Wave 指標の計算は、サイン関数の使用と、価格変動における支配的サイクルの判定に基づいています。

1. スペクトル分析または別のサイクル識別手法を使用して、支配的サイクルを判定します。

2. 識別されたサイクルをモデル化するためにサイン関数を適用します。
   ```
   SineWave(t) = A * sin(2π * t / Length + φ)
   ```
   ここで:
   - A - 振幅（波の高さ）
   - t - 現在時刻またはバー
   - Length - サイクル長
   - φ - サイン波を実際の価格サイクルに合わせるための位相シフト

3. さらに、メインのサイン波を 4 分の 1 サイクル先行するリード指標を計算する場合があります。
   ```
   Lead(t) = A * sin(2π * t / Length + φ + π/2)
   ```

この指標には、シグナル精度を向上させるために、トレンドラインやフィルターなどの追加コンポーネントが含まれる場合があります。
