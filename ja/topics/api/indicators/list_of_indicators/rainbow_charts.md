# RC

**Rainbow Charts (RC)** は、異なる期間の移動平均線の集合を 1 つのチャート上に表示するテクニカル分析指標です。視覚的に虹に似ているため、この名前が付けられています。

この指標を使用するには、[RainbowCharts](xref:StockSharp.Algo.Indicators.RainbowCharts) クラスを使用する必要があります。

## 説明

Rainbow Charts は、期間が段階的に長くなる複数の移動平均（通常は単純移動平均 SMA）を使用することに基づいています。異なる移動平均線は異なる色で表示され、チャート上に虹のような効果を作ります。

この指標は、トレンドの方向と強さを判断するのに役立ちます。
- 線が広がる場合、これはトレンドの強まりを示します
- 線が収束する場合、これはトレンドの弱まりまたは潜在的な反転を示す可能性があります
- 価格がすべての線を上回っている場合、強い上昇トレンドを示します
- 価格がすべての線を下回っている場合、強い下降トレンドを示します

## パラメーター

- **Lines** - レインボーチャートで使用される SMA 移動平均の数。

## 計算

Rainbow Charts は複数の移動平均（SMA）で構成され、後続の各線の期間は一定のステップで増加します。基準期間 p を持つ n 本の線について、期間は次のように計算されます。

```
Period(i) = p + i * step
```

ここで:
- i - 線番号（0 から n-1）
- step - 期間増加ステップ（通常は 1）
