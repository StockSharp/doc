# MACD

**移動平均収束拡散 (MACD)** は、証券価格の 2 つの移動平均の関係を示すモメンタムインジケーターです。

このインジケーターは、短期移動平均と長期移動平均の差として計算されます。デフォルトでは、これらの平均の期間はそれぞれ 12 と 26 に設定されています。

このインジケーターを使用するには、[MovingAverageConvergenceDivergence](xref:StockSharp.Algo.Indicators.MovingAverageConvergenceDivergence) クラスを使用する必要があります。
