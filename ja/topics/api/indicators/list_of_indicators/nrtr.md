# NRTR

**ニック・ライポック追跡反転 (NRTR)** は、到達した価格の極値から一定の区間上に常に位置することを本質とするインジケーターです。ここでは、メイントレンドに逆行する小さな調整的な動きは無視し、メイントレンドに逆行する動きが一定の水準を超えた場合に反転トレンドを示す、という考え方が実装されています。

インジケーターを使用するには、[NickRypockTrailingReverse](xref:StockSharp.Algo.Indicators.NickRypockTrailingReverse) クラスを使用する必要があります。
