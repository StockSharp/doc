# CCI

**Commodity Channel Index (CCI)** は、現在価格の平均値からの乖離と、統計的な平均絶対値の分析に基づくテクニカルインジケーターです。 

このインジケーターを使用するには、[CommodityChannelIndex](xref:StockSharp.Algo.Indicators.CommodityChannelIndex) クラスを使用する必要があります。
