# DPI

**Disparity Index (DPI)** は、指定期間における移動平均からの現在価格の相対的な乖離をパーセンテージで測定するテクニカル指標です。

この指標を使用するには、[DisparityIndex](xref:StockSharp.Algo.Indicators.DisparityIndex) クラスを使用する必要があります。

## 説明

Disparity Index (DPI) は、価格がその移動平均からどの程度乖離しているかを測定するために設計されています。この指標は、価格が平均値に対してどれだけ「引き伸ばされている」かを判断するのに役立ち、潜在的な買われ過ぎまたは売られ過ぎの状態を特定するために使用できます。

DPI は、価格は大きく乖離した後に平均値へ戻る傾向があるという前提に基づいています。乖離が大きいほど、その後に価格が反対方向へ動き、平均に近づく確率が高くなります。

Disparity Index は次の用途に有用です。
- 平均からの極端な価格乖離の特定
- 潜在的な反転ポイントの検出
- 現在のトレンドの強さの測定
- 平均回帰に基づく取引戦略の作成

## パラメーター

この指標には次のパラメーターがあります。
- **Length** - 移動平均を計算する期間（既定値: 14）

## 計算

Disparity Index の計算式は非常に単純です。

```
DPI = ((Price / MA) - 1) * 100
```

ここで:
- Price - 現在価格（通常は終値）
- MA - Length 期間における価格の移動平均
- 結果はパーセンテージで表されます

正の DPI 値は価格が移動平均を上回っていることを示し、負の値は価格が移動平均を下回っていることを示します。

## 解釈

Disparity Index は次のように解釈できます。

1. **極端な水準**:
   - 高い正の値（例: +10% 超）は、市場の買われ過ぎ状態を示している可能性があります
   - 高い負の値（例: -10% 未満）は、市場の売られ過ぎ状態を示している可能性があります

2. **ゼロラインのクロスオーバー**:
   - 下から上へのクロス（負の値から正の値へ）は、価格が移動平均を下から上へ抜けたことを示し、強気シグナルと見なすことができます
   - 上から下へのクロス（正の値から負の値へ）は、価格が移動平均を上から下へ抜けたことを示し、弱気シグナルと見なすことができます

3. **ダイバージェンス**:
   - 強気ダイバージェンス: 価格が新安値に達する一方で、DPI はより高い安値を形成します
   - 弱気ダイバージェンス: 価格が新高値に達する一方で、DPI はより低い高値を形成します

4. **トレンド分析**:
   - 一貫して正の DPI 値は、強い上昇トレンドを示します
   - 一貫して負の DPI 値は、強い下降トレンドを示します
   - ゼロ付近での振動は、横ばいトレンドまたは保ち合いを示している可能性があります

5. **平均回帰戦略**:
   - 極端な DPI 値は、平均への回帰を期待して現在の価格変動に逆らうポジションを開くために使用できます
