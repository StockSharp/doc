# KST

**Know Sure Thing (KST)** は、長期的な市場サイクルを特定するために、異なる期間を持つ 4 つの平滑化された変化率（ROC）の合計を表す、Martin Pring によって開発されたテクニカルインジケーターです。

インジケーターを使用するには、[KnowSureThing](xref:StockSharp.Algo.Indicators.KnowSureThing) クラスを使用する必要があります。

## 説明

Know Sure Thing (KST) インジケーターは、さまざまな時間期間にわたる価格モメンタムを測定してトレンドを特定するために Martin Pring によって開発されたオシレーターです。このインジケーターは、異なる期間を持つ 4 つの変化率（ROC）測定値を組み合わせ、より長い期間により大きな重要性を与えます。

KST は、異なる長さの市場サイクルが集合的に価格変動に影響を与えるという理論に基づいています。異なる期間の ROC を組み合わせることで、KST は長期的な循環トレンドを特定し、潜在的な反転ポイントを判断することを目指します。

このインジケーターには通常、シグナルライン（KST の移動平均）が伴い、それらのクロスオーバーを取引シグナルの生成に使用できます。

## 計算

KST インジケーターの計算には、次の手順があります。

1. 異なる期間を持つ 4 つの変化率（ROC）測定値を計算します。
   ```
   ROC1 = ((Close / Close[n1 periods ago]) - 1) * 100
   ROC2 = ((Close / Close[n2 periods ago]) - 1) * 100
   ROC3 = ((Close / Close[n3 periods ago]) - 1) * 100
   ROC4 = ((Close / Close[n4 periods ago]) - 1) * 100
   ```

2. 単純移動平均（SMA）を使用して各 ROC を平滑化します。
   ```
   RCMA1 = SMA(ROC1, m1)
   RCMA2 = SMA(ROC2, m2)
   RCMA3 = SMA(ROC3, m3)
   RCMA4 = SMA(ROC4, m4)
   ```

3. 加重合計により KST を取得します。
   ```
   KST = (RCMA1 * 1) + (RCMA2 * 2) + (RCMA3 * 3) + (RCMA4 * 4)
   ```

4. シグナルラインを計算します。
   ```
   シグナルライン = SMA(KST, シグナル期間)
   ```

ここで:
- Close - 終値
- n1, n2, n3, n4 - ROC 計算の期間（デフォルト値: 10, 15, 20, 30）
- m1, m2, m3, m4 - ROC 平滑化の期間（デフォルト値: 10, 10, 10, 15）
- シグナル期間 - シグナルラインの期間（デフォルト値: 9）

## 解釈

KST インジケーターは、次のように解釈できます。

1. **ゼロラインのクロスオーバー**:
   - KST がゼロラインを下から上へクロスする場合、強気シグナルと見なすことができます
   - KST がゼロラインを上から下へクロスする場合、弱気シグナルと見なすことができます

2. **シグナルラインのクロスオーバー**:
   - KST がシグナルラインを下から上へクロスする場合、強気シグナルと見なすことができます（ゼロラインのクロスより感度が高い）
   - KST がシグナルラインを上から下へクロスする場合、弱気シグナルと見なすことができます（ゼロラインのクロスより感度が高い）

3. **ダイバージェンス**:
   - 強気ダイバージェンス: 価格が新たな安値を形成する一方で、KST はより高い安値を形成します
   - 弱気ダイバージェンス: 価格が新たな高値を形成する一方で、KST はより低い高値を形成します

4. **極端な値**:
   - 高い正の KST 値は、市場の買われすぎ状態を示す場合があります
   - 高い負の KST 値は、市場の売られすぎ状態を示す場合があります

5. **移動方向**:
   - 上昇する KST トレンドは、全体的に強気の市場センチメントを示します
   - 下落する KST トレンドは、全体的に弱気の市場センチメントを示します

6. **トレンド確認**:
   - KST は、他のインジケーターからのシグナルを確認するために使用できます
   - KST の方向と価格の一致は、現在のトレンドの強さを確認します

7. **市場センチメント分析**:
   - 正の KST 値は、強気センチメントが優勢であることを示します
   - 負の KST 値は、弱気センチメントが優勢であることを示します
