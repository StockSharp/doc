# DEMA

**二重指数移動平均 (DEMA)** は、価格を予測する際の遅れを取り除くために、複数（二重）の指数移動平均 (EMA) を使用します。

このインジケーターを使用するには、[DoubleExponentialMovingAverage](xref:StockSharp.Algo.Indicators.DoubleExponentialMovingAverage) クラスを使用する必要があります。
