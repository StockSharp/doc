# NVI

**Negative Volume Index (NVI)** は Paul Dysart によって開発されたテクニカルインジケーターで、取引出来高が前日と比較して減少した日の価格変化に注目します。

インジケーターを使用するには、[NegativeVolumeIndex](xref:StockSharp.Algo.Indicators.NegativeVolumeIndex) クラスを使用する必要があります。

## 説明

Negative Volume Index (NVI) は、出来高が少ない日に「スマートマネー」が活動し、出来高が多い日には「群衆」(非プロのトレーダー) がより活動的であるという考え方に基づいています。NVI は、現在の出来高が前日の出来高より低い日にのみ変化します。

このインジケーターの概念は、出来高が減少したときの価格変動はより重要であり、情報を持つ投資家の行動を反映することが多い、というものです。NVI は、出来高が増加した日の価格変化を無視しながら、これらの動きを追跡しようとします。

NVI は、対になる Positive Volume Index (PVI) と併用されることがよくあります。PVI は対照的に、出来高が増加した日のみを考慮します。

## 計算

Negative Volume Index の計算には、次の手順が含まれます:

1. 初期 NVI 値を設定します (通常は 1000):
   ```
   NVI[initial] = 1000
   ```

2. 以降の各期間について:
   ```
   Volume[current] < Volume[previous] の場合:
       NVI[current] = NVI[previous] * (1 + (Price[current] - Price[previous]) / Price[previous])
   Otherwise:
       NVI[current] = NVI[previous]
   ```

ここで:
- Price - 価格 (通常は終値)
- Volume - 取引出来高

言い換えると、NVI は取引出来高が減少した日にのみ変化し、出来高が増加した日または変化しない日には変化しません。

## 解釈

Negative Volume Index は次のように解釈できます:

1. **トレンド分析**:
   - NVI の上昇は「スマートマネー」が買っていることを示し、将来の価格上昇を予告する場合があります
   - NVI の下落は「スマートマネー」が売っていることを示し、将来の価格下落を予告する場合があります

2. **移動平均のクロスオーバー**:
   - NVI は多くの場合、その 255 日移動平均 (取引日でおよそ 1 年) と比較されます
   - NVI が 255 日 SMA を上回っている場合、強気シグナルと見なされます
   - NVI が 255 日 SMA を下回っている場合、弱気シグナルと見なされます

3. **ダイバージェンス**:
   - 強気ダイバージェンス: 価格が新しい安値を形成する一方で、NVI はより高い安値を形成します
   - 弱気ダイバージェンス: 価格が新しい高値を形成する一方で、NVI はより低い高値を形成します

4. **PVI との組み合わせ**:
   - NVI と PVI の両方が上昇している場合、強い強気シグナルです
   - NVI と PVI の両方が下落している場合、強い弱気シグナルです
   - NVI が上昇し PVI が下落している場合、「スマートマネー」が買い、「群衆」が売っていることを示す場合があります (潜在的に強気のシナリオ)
   - NVI が下落し PVI が上昇している場合、「スマートマネー」が売り、「群衆」が買っていることを示す場合があります (潜在的に弱気のシナリオ)

5. **長期的な変化**:
   - NVI は多くの場合、長期インジケーターとして見られます
   - NVI 方向の継続的な変化は、市場心理の重要な変化を示す場合があります

6. **他のインジケーターの確認**:
   - NVI は、他のテクニカルインジケーターや分析手法と組み合わせたときに最もよく機能します
   - NVI のシグナルは、他のインジケーターによって確認されると、より信頼性が高まります

7. **しきい値の設定**:
   - 一部のトレーダーは、NVI にしきい値水準を設定します (例: 移動平均の上下 5%)
   - これらのしきい値をクロスすることは、単純なクロスオーバーよりも強いシグナルと見なされる場合があります
