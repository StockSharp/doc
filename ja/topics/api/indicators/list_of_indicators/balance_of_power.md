# BOP

**勢力バランス (BOP)** は、安値から高値へ価格を押し上げる強気側の能力を評価することで、弱気側（売り手）に対する強気側（買い手）の強さを測定するために設計されたインジケーターです。

このインジケーターを使用するには、[BalanceOfPower](xref:StockSharp.Algo.Indicators.BalanceOfPower) クラスを使用する必要があります。

## 説明

勢力バランス (BOP) インジケーターは、市場における買い手と売り手の力の均衡を表示します。これは、トレンドでは買い手（強気側）または売り手（弱気側）がセッション全体を通じて価格をコントロールできるという仮定に基づいています。終値と始値の差を価格レンジ全体（高値-安値）と比較することで、現在誰が市場を支配しているかを評価できます。

BOP はトレーダーが次のことを行うのに役立ちます。
- 現在のトレンドの方向と強さを判断する
- 潜在的な反転ポイントを特定する
- 価格とインジケーターの間のダイバージェンスを検出する
- 買われ過ぎと売られ過ぎの水準を判断する

## 計算

勢力バランス (BOP) インジケーターの計算式は非常に単純です。

```
BOP = (Close - Open) / (High - Low)
```

ここで:
- Close - 終値
- Open - 始値
- High - 期間中の最高値
- Low - 期間中の最安値

(High - Low) がゼロの場合、ゼロ除算を避けるため BOP はゼロに設定されます。

BOP は、ボラティリティを低減し、シグナルの読みやすさを向上させるために、移動平均を使用して追加で平滑化されることがよくあります。

## 解釈

- **正の BOP 値**（ゼロより上）は、買い手（強気側）が市場をコントロールしていることを示し、上昇トレンドを示唆する場合があります。
- **負の BOP 値**（ゼロより下）は、売り手（弱気側）が市場をコントロールしていることを示し、下降トレンドを示唆する場合があります。
- **ゼロラインのクロス** は、潜在的なトレンド方向の変化を示すシグナルと見なすことができます。
- **極端な値**（強く正または強く負の値）は、市場が買われ過ぎまたは売られ過ぎの状態にあることを示す場合があります。
- **BOP と価格の間のダイバージェンス** は、トレンド反転の可能性を示すことがあります。
  - 価格が上昇している一方で BOP が低下している場合、上昇トレンドが弱まっている警告である可能性があります。
  - 価格が下落している一方で BOP が上昇している場合、下降トレンドが終わる可能性を示している場合があります。
