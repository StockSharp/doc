# VIDYA

**Variable Index Dynamic Average (VIDYA)** は、動的に変化する平均化期間を用いて指数移動平均 (EMA) を計算する独自の方法を持つインジケーターです。平均化期間は市場ボラティリティに依存し、ボラティリティの尺度としてモメンタム・オシレーター (CMO) が選択されています。

このインジケーターを使用するには、[Vidya](xref:StockSharp.Algo.Indicators.Vidya) クラスを使用する必要があります。
