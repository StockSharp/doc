# ストキャスティクスオシレーター

**ストキャスティクスオシレーター** は、証券の特定の終値を、一定期間における価格範囲と比較するモメンタムインジケーターです。市場の動きに対するオシレーターの感度は、この期間を調整するか、結果に移動平均を適用することで下げることができます。

このインジケーターを使用するには、[StochasticOscillator](xref:StockSharp.Algo.Indicators.StochasticOscillator) クラスを使用する必要があります。
