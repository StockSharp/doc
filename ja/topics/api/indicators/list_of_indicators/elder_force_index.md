# Elder's Force Index

**Elder's Force Index (EFI)** は、価格変化と出来高を使用して買い圧力と売り圧力を測定します。

この指標を使用するには、[ElderForceIndex](xref:StockSharp.Algo.Indicators.ElderForceIndex) クラスを使用する必要があります。
