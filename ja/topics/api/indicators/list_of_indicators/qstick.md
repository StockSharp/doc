# QStick

**Qstick** は、ローソク足チャートでトレンドを判定するために使用されるテクニカルインジケーターです。始値と終値の差から N 期間の移動平均を取ることで計算されます。Qstick の値が正の場合、買い圧力が増加していることを意味します。

このインジケーターを使用するには、[QStick](xref:StockSharp.Algo.Indicators.QStick) クラスを使用する必要があります。
