# DC

**ドンチャンチャネル (DC)** は、トレーダーの Richard Donchian によって開発されたテクニカル指標で、特定期間における価格の最高値と最安値に基づく上側および下側のバンド（チャネル境界）で構成されます。

この指標を使用するには、[DonchianChannels](xref:StockSharp.Algo.Indicators.DonchianChannels) クラスを使用する必要があります。

## 説明

ドンチャンチャネル は、シンプルでありながら効果的なボラティリティおよびトレンド指標です。この指標は 3 本のラインで構成されます。
- 上側ライン: 選択期間における最高値
- 下側ライン: 選択期間における最安値
- 中央ライン: 上側ラインと下側ラインの平均値

この指標は、Richard Donchian の 4 週間チャネルルールで最初に使用されました。このルールでは、価格が 4 週間の最高値を上回ると買いシグナルが発生し、価格が 4 週間の最安値を下回ると売りシグナルが発生します。

ドンチャンチャネル は次の用途に有用です。
- 市場ボラティリティの特定
- サポートおよびレジスタンス水準の判断
- ブレイクアウトシグナルの生成
- 現在の取引レンジの定義

## パラメーター

この指標には次のパラメーターがあります。
- **Length** - 計算期間（既定値: 20）

## 計算

ドンチャンチャネル の計算は非常に単純です。

1. 上側チャネルライン:
   ```
   上側ライン = Length 期間の最高値
   ```

2. 下側チャネルライン:
   ```
   下側ライン = Length 期間の最安値
   ```

3. 中央チャネルライン:
   ```
   中央ライン = (上側ライン + 下側ライン) / 2
   ```

## 解釈

ドンチャンチャネル はさまざまな方法で使用できます。

1. **ブレイクアウト戦略**:
   - 上側チャネルラインを上抜けることは、買いシグナルと見なすことができます
   - 下側チャネルラインを下抜けることは、売りシグナルと見なすことができます

2. **トレンド判断**:
   - 価格がチャネルの上半分（中央ラインより上）にある場合、上昇トレンドを推測できます
   - 価格がチャネルの下半分（中央ラインより下）にある場合、下降トレンドを推測できます

3. **サポートおよびレジスタンス水準**:
   - 上側チャネルラインはレジスタンス水準として機能できます
   - 下側チャネルラインはサポート水準として機能できます

4. **ボラティリティ測定**:
   - チャネル幅（上側ラインと下側ラインの差）は市場ボラティリティを示します
   - チャネルの拡大はボラティリティの増加を示します
   - チャネルの収縮はボラティリティの低下を示します

5. **逆張り戦略**:
   - 一部のトレーダーは、価格がチャネル端に到達した後に中央ラインへ戻ることを期待して、反対シグナルを使用します
