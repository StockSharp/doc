# CHOP

**チョピネス指数 (CHOP)** は、市場が横ばいの動き（レンジ内）にあるのか、トレンド状態にあるのかを判断するために設計されたインジケーターです。

このインジケーターを使用するには、[ChoppinessIndex](xref:StockSharp.Algo.Indicators.ChoppinessIndex) クラスを使用する必要があります。

## 説明

チョピネス指数 (CHOP) は、ボラティリティを定量的に評価し、市場の動きの性質を判断するために作成されました。他の多くのインジケーターと異なり、CHOP はトレンドの方向を特定したり、買いまたは売りのシグナルを生成したりすることを目的としていません。代わりに、市場がコンソリデーション（横ばいの動き）にあるのか、方向性のあるトレンドにあるのかをトレーダーが判断するのに役立ちます。

CHOP インジケーターは 0 から 100 の間で振動します。
- 100 に近い値は、強いコンソリデーション（高い「チョッピーさ」）を示します
- 0 に近い値は、強い方向性トレンド（低い「チョッピーさ」）を示します

CHOP は特に次の用途に役立ちます。
- 市場の性質に基づく適切な取引戦略の決定
- 横ばいの動きからトレンドへの移行、およびその逆の特定
- 他のインジケーターからのシグナルの確認または否定
- コンソリデーション中の誤シグナルの回避

## パラメーター

このインジケーターには次のパラメーターがあります。
- **Length** - 計算期間（既定値: 14）

## 計算

チョピネス指数 の計算には、次の手順が含まれます。

1. 選択した期間にわたる真の値幅の合計を計算します。
   ```
   TRの合計 = i = 1 から Length までの Sum(TR(i))
   ```

2. 選択した期間にわたる最高 High と最低 Low を計算します。
   ```
   最高値 = Length 期間における High の最大値
   最安値 = Length 期間における Low の最小値
   ```

3. CHOP インデックスを計算します。
   ```
   CHOP = 100 * LOG10(Sum TR / (最高値 - 最安値)) / LOG10(Length)
   ```

ここで:
- TR - 各ローソク足のトゥルーレンジ
- Length - 選択した期間
- LOG10 - 常用対数

## 解釈

- **高い CHOP 値（60-70 超）** は、市場が横ばいの動き（コンソリデーション）にあることを示します。この期間は、トレンド戦略を避け、レンジ取引戦略を検討する方がよい場合があります。

- **低い CHOP 値（30-40 未満）** は、強い方向性トレンドを示します。これは、トレンド戦略を使用し、価格の動きに追随するのに適した時期です。

- **高い値と低い値の間の移行** は、市場の性質の変化を示すことがあります。高い値からの CHOP の低下は、新しいトレンドの始まりを示す場合があります。低い値からの CHOP の上昇は、トレンドの消耗とコンソリデーションへの移行を警告する場合があります。

- **しきい値レベルの設定**: 通常、次のしきい値レベルが使用されます。
  - 60-70 超: 高い「チョッピーさ」（横ばいの動き）
  - 30-60: 中程度の「チョッピーさ」（移行状態）
  - 30 未満: 低い「チョッピーさ」（強いトレンド）
