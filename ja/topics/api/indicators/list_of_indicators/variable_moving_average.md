# Variable MA

**Variable Moving Average (VMA)** は、市場ボラティリティに基づいて平滑化期間を適応させます。

このインジケーターを使用するには、[VariableMovingAverage](xref:StockSharp.Algo.Indicators.VariableMovingAverage) クラスを使用する必要があります。
