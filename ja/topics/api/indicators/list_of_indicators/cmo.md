# CMO

**チャンデ・モメンタム・オシレーター (CMO)** は、Momentum インジケーターを改良したものです。CMO の考案者はトレーダーの Tushar Chande です。

このインジケーターを使用するには、[ChandeMomentumOscillator](xref:StockSharp.Algo.Indicators.ChandeMomentumOscillator) クラスを使用する必要があります。
