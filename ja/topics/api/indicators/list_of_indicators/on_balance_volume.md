# OBV

**オンバランスボリューム (OBV)** は Joseph Granville によって開発されたテクニカルインジケーターで、価格方向に基づいて出来高を累積することにより、取引出来高を使用して価格変化を予測します。

インジケーターを使用するには、[OnBalanceVolume](xref:StockSharp.Algo.Indicators.OnBalanceVolume) クラスを使用する必要があります。

## 説明

オンバランスボリューム (OBV) は、終値が上昇したときに出来高を加算し、終値が下落したときに出来高を減算する累積インジケーターです。このインジケーターは、出来高の変化が価格変化に先行するという概念に基づいています。この理論によれば、対応する価格変化を伴わずに出来高が大きく増加した場合、最終的に価格が上昇すると予想され、その逆も同様です。

OBV は、「スマートマネー」(大規模な機関投資家) がポジションを蓄積または分配している局面を検出することを目的としており、これは将来の価格変動を予告する場合があります。このインジケーターは、潜在的な市場反転を示す可能性がある価格と出来高のダイバージェンスを特定するのに特に有用です。

OBV インジケーターは、Joseph Granville が 1963 年に著書『グランビルの株式市場利益への新しい鍵』で初めて紹介し、それ以降、最も広く使用される出来高インジケーターの 1 つになりました。

## 計算

オンバランスボリューム の計算は非常に単純です:

1. 初期 OBV 値を設定します (通常は 0 または任意の数値):
   ```
   OBV[initial] = 0
   ```

2. 以降の各期間について:
   ```
   Close[current] > Close[previous] の場合:
       OBV[current] = OBV[previous] + Volume[current]
   Close[current] < Close[previous] の場合:
       OBV[current] = OBV[previous] - Volume[current]
   Close[current] = Close[previous] の場合:
       OBV[current] = OBV[previous]
   ```

ここで:
- Close - 終値
- Volume - 取引出来高

## 解釈

オンバランスボリューム は次のように解釈できます:

1. **トレンド分析**:
   - OBV の上昇は、出来高が市場に流入していること (蓄積) を示し、価格上昇を予告する場合があります
   - OBV の下落は、出来高が市場から流出していること (分配) を示し、価格下落を予告する場合があります
   - 横ばいの OBV は、方向性のある出来高の動きがないことを示し、横ばいトレンドに対応する場合があります

2. **価格トレンドの確認**:
   - OBV が価格と同じ方向に動く場合、現在の価格トレンドを確認します
   - OBV と価格が反対方向に動く場合、潜在的なトレンド反転を示す場合があります

3. **ダイバージェンス**:
   - 強気ダイバージェンス: 価格が新しい安値を形成する一方で、OBV はより高い安値を形成します (買いシグナル)
   - 弱気ダイバージェンス: 価格が新しい高値を形成する一方で、OBV はより低い高値を形成します (売りシグナル)

4. **OBV ブレイクアウト**:
   - OBV がレジスタンスまたはサポート水準をブレイクアウトすることは、多くの場合、価格チャート上の同様のブレイクアウトに先行します
   - トレーダーは、将来の価格変動を予測するために OBV のトレンドラインブレイクアウトを使用できます

5. **ベースライン**:
   - 一部のトレーダーは、OBV の移動平均を「ベースライン」として使用します
   - OBV がその移動平均をクロスすると、取引シグナルを生成する場合があります

6. **テクニカル分析パターン**:
   - OBV チャート上には、「ヘッドアンドショルダー」、「ダブルボトム」などの古典的なテクニカル分析パターンが形成される場合があります
   - これらのパターンは追加の取引シグナルを提供できます

7. **出来高スパイク**:
   - OBV の突然の急激な変化は、市場心理の大きな変化を示す場合があります
   - このような「出来高スパイク」は、多くの場合、大きな価格変動に先行します

OBV は累積インジケーターであるため、その絶対値はあまり重要ではない点に注意することが重要です。重要なのは、OBV の動きの方向と価格変動との関係です。
