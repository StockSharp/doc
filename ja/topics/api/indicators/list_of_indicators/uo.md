# UO

**Ultimate Oscillator (UO)** は、複数の時間軸にわたるモメンタムを測定するために、1976 年に Larry Williams によって開発されたテクニカルインジケーターです。3 つの異なる時間軸に対して加重平均を使用することで、単一の時間軸に依存する他のインジケーターと比較して、ボラティリティが低く、売買シグナルも少なくなります。

このインジケーターを使用するには、[UltimateOscillator](xref:StockSharp.Algo.Indicators.UltimateOscillator) クラスを使用する必要があります。
