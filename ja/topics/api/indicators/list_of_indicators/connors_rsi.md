# CRSI

**Connors RSI (CRSI)** は、Larry Connors によって開発された総合的なテクニカルインジケーターで、市場の買われ過ぎおよび売られ過ぎの状態を測定するために 3 つの構成要素を組み合わせます。

このインジケーターを使用するには、[ConnorsRSI](xref:StockSharp.Algo.Indicators.ConnorsRSI) クラスを使用する必要があります。

## 説明

Connors RSI は、従来の Relative Strength Index (RSI) の高度なバージョンであり、より正確な買われ過ぎおよび売られ過ぎのシグナルを提供するために 2 つの追加構成要素を加えています。

標準的な RSI は価格変化のみを考慮しますが、Connors RSI はストリーク（一方向への連続した価格変動の系列）と変化率 (ROC) も考慮します。そのため、短期的な変化に対してより敏感で、市場の極端な状態を識別する際により信頼性が高くなります。

CRSI は特に次の用途に役立ちます。
- 短期的なエントリーおよび出口機会の特定
- 極端な買われ過ぎおよび売られ過ぎ水準の判断
- 平均回帰に基づく取引システムの作成
- 他のインジケーターからのシグナルのフィルタリング

## パラメーター

このインジケーターには次のパラメーターがあります。
- **RSIPeriod** - RSI 構成要素を計算するための期間（既定値: 3）
- **StreakRSIPeriod** - ストリーク RSI 構成要素を計算するための期間（既定値: 2）
- **ROCRSIPeriod** - 変化率 RSI 構成要素を計算するための期間（既定値: 100）

## 計算

Connors RSI の計算には 3 つの構成要素が含まれ、それらを平均して最終値を得ます。

1. **価格 RSI 構成要素** - 短い期間（通常は 3 日）で計算される標準的な RSI:
   ```
   RSI = 100 - (100 / (1 + RS))
   ここで RS = 平均上昇変化 / 平均下落変化
   ```

2. **ストリーク RSI 構成要素**:
   - まず、ストリーク（価格上昇または下落が連続した日数）を計算します
   - 次に、StreakRSIPeriod を使用してこのストリークに RSI を適用します

3. **変化率 RSI 構成要素 (ROC RSI)**:
   - ROCRSIPeriod にわたる現在の ROC のパーセンタイルランクを計算します
   - パーセンタイルランクを 0 から 100 にスケーリングします

4. **最終的な Connors RSI 値**:
   ```
   CRSI = (RSI + StreakRSI + ROCRSI) / 3
   ```

## 解釈

Connors RSI は、標準的な RSI と同様に 0 から 100 の間で振動します。

- **極端に高い値（90 超）** は、強い買われ過ぎ状態を示します。これは売却またはショートポジションを取るシグナルとなる場合があります。

- **極端に低い値（10 未満）** は、強い売られ過ぎ状態を示します。これは買い、またはショートポジションを決済するシグナルとなる場合があります。

- **標準レベル**:
  - 70-80 超: 買われ過ぎ
  - 20-30 未満: 売られ過ぎ
  - 40-60: 中立ゾーン

- **ダイバージェンス**:
  - 強気ダイバージェンス: 価格が新しい安値を形成する一方で、CRSI はより高い安値を形成します
  - 弱気ダイバージェンス: 価格が新しい高値を形成する一方で、CRSI はより低い高値を形成します

Connors RSI は、日足から週足までの時間枠のチャート、および平均回帰志向の取引戦略で最も効果的に機能します。
