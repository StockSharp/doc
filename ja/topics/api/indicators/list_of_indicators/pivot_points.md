# PP

**ピボットポイント (PP)** は、前の高値、安値、終値を使用して、現在の取引期間における潜在的なサポートおよびレジスタンス水準を決定するテクニカルインジケーターです。

このインジケーターを使用するには、[PivotPoints](xref:StockSharp.Algo.Indicators.PivotPoints) クラスを使用する必要があります。

## 説明

ピボットポイント（ピボットポイント）は、主要な市場水準を特定するための最も古く、最も広く使用されている手法の 1 つです。このインジケーターは、前期間のデータに基づいて、中央のピボットポイント（PP）と複数のサポート（S1、S2、S3）およびレジスタンス（R1、R2、R3）水準を計算します。

もともとピボットポイントは、取引所フロアのトレーダーが前日のデータに基づいて当日の主要水準を決定するために使用していました。現在、この手法は日中から月次まで、さまざまな時間軸に適用されています。

ピボットポイントの主な考え方は、市場が事前に計算されたこれらの水準に反応し、それらを反転ポイントまたは保ち合いが発生し得るゾーンとして使用する傾向があるというものです。トレーダーはこれらの水準を使用して、市場へのエントリーとエグジット、ならびに目標水準とストップロスの設定に関する判断を行います。

## 計算

ピボットポイントの計算方法には、標準、Fibonacci、Woodie、Camarilla、DeMark など、いくつかの方法があります。以下は標準的な計算方法です。

1. メインのピボットポイント（PP）を計算します。
   ```
   PP = (High + Low + Close) / 3
   ```

2. 第 1 レジスタンス（R1）およびサポート（S1）水準を計算します。
   ```
   R1 = (2 * PP) - Low
   S1 = (2 * PP) - High
   ```

3. 第 2 レジスタンス（R2）およびサポート（S2）水準を計算します。
   ```
   R2 = PP + (High - Low)
   S2 = PP - (High - Low)
   ```

4. 第 3 レジスタンス（R3）およびサポート（S3）水準を計算します。
   ```
   R3 = High + 2 * (PP - Low)
   S3 = Low - 2 * (High - PP)
   ```

ここで:
- High - 前期間の最高価格
- Low - 前期間の最低価格
- Close - 前期間の終値

## 解釈

ピボットポイントは、次のように解釈できます。

1. **メインピボットポイント（PP）**:
   - PP は、市場全体のセンチメントを判断するための主要な基準として機能します
   - 価格が PP を上回っている場合、強気のセンチメントを示します
   - 価格が PP を下回っている場合、弱気のセンチメントを示します
   - PP はサポートまたはレジスタンス水準としても機能します

2. **レジスタンス水準（R1、R2、R3）**:
   - これらの水準は、強気市場における潜在的なレジスタンスゾーンを表します
   - 水準のブレイクアウトは、次の水準への継続的な動きにつながる場合があります
   - 水準からの反発は、下方向への反転につながる場合があります

3. **サポート水準（S1、S2、S3）**:
   - これらの水準は、弱気市場における潜在的なサポートゾーンを表します
   - 水準のブレイクアウトは、次の水準への継続的な動きにつながる場合があります
   - 水準からの反発は、上方向への反転につながる場合があります

4. **取引戦略**:
   - **反発取引**: サポートまたはレジスタンス水準から反発したときにポジションに入ります
   - **ブレイクアウト取引**: 水準のブレイクアウトが確認された後にポジションに入ります
   - **レンジ取引**: サポート水準で買い、レジスタンス水準で売ります
   - **目標設定**: 次の水準を利確目標として使用します
   - **ストップロス配置**: 対応する水準の外側にストップロスを配置します

5. **他のインジケーターとの組み合わせ**:
   - ピボットポイントは、シグナルを確認するために他のテクニカルインジケーターと組み合わせて使用されることがよくあります
   - モメンタムインジケーター（RSI、ストキャスティクス）およびトレンドインジケーター（MA、MACD）と組み合わせると特に効果的です

6. **時間軸**:
   - 日次ピボットポイントは、前取引日に基づいて計算されます
   - 週次ピボットポイントは、前週に基づいて計算されます
   - 月次ピボットポイントは、前月に基づいて計算されます
   - 時間軸の選択は、取引スタイルと時間的視野によって異なります
