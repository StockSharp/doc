# DZRSI

**Dynamic Zones RSI (DZRSI)** は、固定された水準の代わりに動的に変化する買われ過ぎおよび売られ過ぎ水準を使用する、従来の 相対力指数 (RSI) の改良版です。

この指標を使用するには、[DynamicZonesRSI](xref:StockSharp.Algo.Indicators.DynamicZonesRSI) クラスを使用する必要があります。

## 説明

Dynamic Zones RSI (DZRSI) は従来の RSI に基づいていますが、重要な改良点があります。固定された買われ過ぎおよび売られ過ぎ水準（通常は 70 と 30）を使用する代わりに、DZRSI はこれらの水準を現在の市場状況に適応させます。

DZRSI の主な考え方は、市場状況が異なれば、買われ過ぎおよび売られ過ぎ状態を判断するためのしきい値も異なる必要があるというものです。強い上昇トレンドでは、RSI は正確なエントリーまたはイグジットシグナルを提供しないまま、従来の買われ過ぎ水準である 70 を長期間上回り続けることがあります。同様に、強い下降トレンドでは、RSI は売られ過ぎ水準である 30 を長期間下回り続けることがあります。

DZRSI は、RSI 自体の過去の挙動に基づいてこれらの水準を動的に調整することでこの問題を解決し、指標をさまざまな市場レジームに対してより適応的にします。

## パラメーター

この指標には次のパラメーターがあります。
- **Length** - 基本 RSI を計算する期間（既定値: 14）
- **OverboughtLevel** - 初期の買われ過ぎ水準（既定値: 70）
- **OversoldLevel** - 初期の売られ過ぎ水準（既定値: 30）

## 計算

DZRSI の計算には、いくつかの手順が含まれます。

1. 指定された Length 期間にわたって標準 RSI を計算します。
   ```
   RSI = 100 - (100 / (1 + RS))
   RS = 平均上昇変化 / 平均下落変化
   ```

2. 特定の過去期間における RSI の振動範囲を決定します。

3. この範囲に基づいて買われ過ぎおよび売られ過ぎ水準を適応させます。
   ```
   動的買われ過ぎレベル = 基準買われ過ぎレベル + 履歴データに基づく調整
   動的売られ過ぎレベル = 基準売られ過ぎレベル - 履歴データに基づく調整
   ```

4. 現在のトレンドの強さに基づいて動的ゾーンを調整します。

## 解釈

DZRSI は従来の RSI と同様に解釈されますが、動的ゾーンを考慮します。

1. **買われ過ぎおよび売られ過ぎシグナル**:
   - DZRSI が現在の動的な買われ過ぎ水準を上回る場合、市場の買われ過ぎ状態を示している可能性があります
   - DZRSI が現在の動的な売られ過ぎ水準を下回る場合、市場の売られ過ぎ状態を示している可能性があります

2. **反転シグナル**:
   - 動的な買われ過ぎ水準から下方向へ反転する場合、売りシグナルと見なすことができます
   - 動的な売られ過ぎ水準から上方向へ反転する場合、買いシグナルと見なすことができます

3. **ダイバージェンス**:
   - 強気ダイバージェンス: 価格が新安値を形成する一方で、DZRSI はより高い安値を形成します
   - 弱気ダイバージェンス: 価格が新高値を形成する一方で、DZRSI はより低い高値を形成します

4. **トレンド分析**:
   - 上昇トレンドでは、動的な売られ過ぎ水準が従来の 30 より高くなる場合があります
   - 下降トレンドでは、動的な買われ過ぎ水準が従来の 70 より低くなる場合があります

5. **センターライン (50) のクロスオーバー**:
   - 下から上へのクロスは強気シグナルと見なすことができます
   - 上から下へのクロスは弱気シグナルと見なすことができます
