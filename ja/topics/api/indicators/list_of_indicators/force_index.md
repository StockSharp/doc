# FI

**Force Index (FI)** は、Dr. Alexander Elder によって開発されたテクニカルインジケーターで、各価格変動の強さを、その方向、大きさ、取引出来高に基づいて測定します。

このインジケーターを使用するには、[ForceIndex](xref:StockSharp.Algo.Indicators.ForceIndex) クラスを使用する必要があります。

## 説明

Force Index は、各価格変動における「ブル」(買い手) または「ベア」(売り手) の強さを測定するオシレーターです。市場情報の 3 つの重要な要素、すなわち価格変動の方向、変動の大きさ、取引出来高を組み合わせます。

このインジケーターの主な考え方は、価格変化が大きく取引出来高も大きいほど、市場の動きが強いというものです。正の Force Index 値は買い手優勢 (強気圧力) を示し、負の値は売り手優勢 (弱気圧力) を示します。

Force Index は特に次の用途に役立ちます:
- 現在のトレンドの強さの判断
- 潜在的な反転ポイントの識別
- ブレイクアウトの確認
- 価格と変動の強さの間のダイバージェンスの検出

## パラメーター

このインジケーターには次のパラメーターがあります:
- **Length** - 平滑化期間 (デフォルト値: 13)

## 計算

Force Index の計算には次の手順が含まれます:

1. 単一期間の Force Index を計算します:
   ```
   1-Period Force Index = (Close[current] - Close[previous]) * Volume[current]
   ```

2. Exponential Moving Average (EMA) を使用して平滑化します:
   ```
   Force Index = EMA(1-Period Force Index, Length)
   ```

ここで:
- Close - 終値
- Volume - 取引出来高
- EMA - 指数移動平均
- Length - 平滑化期間

## 解釈

Force Index はさまざまな方法で解釈できます:

1. **ゼロラインのクロスオーバー**:
   - 負の値から正の値への移行は強気圧力の増加を示し、買いシグナルと見なすことができます
   - 正の値から負の値への移行は弱気圧力の増加を示し、売りシグナルと見なすことができます

2. **極端な値**:
   - 高い正の値は、市場が買われ過ぎの状態につながる可能性のある強い強気圧力を示します
   - 高い負の値は、市場が売られ過ぎの状態につながる可能性のある強い弱気圧力を示します

3. **ダイバージェンス**:
   - 強気ダイバージェンス (価格が新安値を形成する一方で、Force Index がより高い安値を形成する) は、潜在的な上方反転を示す可能性があります
   - 弱気ダイバージェンス (価格が新高値を形成する一方で、Force Index がより低い高値を形成する) は、潜在的な下方反転を示す可能性があります

4. **トレンド確認**:
   - 一貫して正の Force Index 値は、上昇トレンドの強さを確認します
   - 一貫して負の Force Index 値は、下降トレンドの強さを確認します

5. **3 通りの使用** (Elder による):
   - 短期 Force Index (2 日): 短期的な機会を識別するため
   - 中期 Force Index (13 日): 中期的なトレンドと調整を判断するため
   - 長期 Force Index (100 日): メイントレンドを識別するため

6. **調整の識別**:
   - 上昇トレンドでは、Force Index が負の日は一時的な調整を示す場合があります
   - 下降トレンドでは、Force Index が正の日は一時的な反発を示す場合があります
