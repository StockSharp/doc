# EWO

**エリオット波動オシレーター (EWO)** は、Elliott Wave Theory に基づくテクニカル指標で、トレーダーが波動構造と潜在的な市場反転ポイントを判断するのに役立ちます。

この指標を使用するには、[ElliotWaveOscillator](xref:StockSharp.Algo.Indicators.ElliotWaveOscillator) クラスを使用する必要があります。

## 説明

エリオット波動オシレーター (EWO) は、トレーダーが市場分析で Elliott Wave Theory を適用できるように開発されました。Elliott Wave Theory では、市場はトレンド方向の 5 つの波（推進波）と、トレンドに逆らう 3 つの波（修正波）で構成される予測可能なサイクルで動くと仮定します。

EWO は高速移動平均と低速移動平均の差に基づいており、Elliott の理論に従って推進波と修正波を特定するように設計されています。市場が推進局面または修正局面のどちらにあるかを判断し、潜在的な反転ポイントを示唆するのに役立ちます。

エリオット波動オシレーター は特に次の用途に有用です。
- 現在の Elliott 波動構造の特定
- 推進波および修正波の潜在的な終了地点の判断
- 手動の波動分析の確認
- 潜在的な反転ポイントの予測

## パラメーター

この指標には次のパラメーターがあります。
- **ShortPeriod** - 短期移動平均の期間（既定値: 5）
- **LongPeriod** - 長期移動平均の期間（既定値: 35）

## 計算

エリオット波動オシレーター の計算は非常に単純です。

```
EWO = EMA(Close, ShortPeriod) - EMA(Close, LongPeriod)
```

ここで:
- EMA - 指数移動平均
- Close - 終値
- ShortPeriod - 短期期間（通常は 5）
- LongPeriod - 長期期間（通常は 35）

## 解釈

エリオット波動オシレーター は次のように解釈できます。

1. **正の値と負の値**:
   - 正の値（EWO がゼロより上）は、短期 EMA が長期 EMA を上回っていることを示し、多くの場合、強気トレンドまたは上向きの推進波に対応します
   - 負の値（EWO がゼロより下）は、短期 EMA が長期 EMA を下回っていることを示し、多くの場合、弱気トレンドまたは下向きの推進波に対応します

2. **ゼロラインのクロスオーバー**:
   - ゼロラインを下から上へ抜けることは、新しい上向きの推進波の開始を示す可能性があります
   - ゼロラインを上から下へ抜けることは、新しい下向きの推進波の開始を示す可能性があります

3. **オシレーターの極値**:
   - オシレーターのピークとボトムは、推進波の終わりに対応する可能性があります
   - 極値に到達した後には、修正局面が続くことがよくあります

4. **ダイバージェンス**:
   - 強気ダイバージェンス（価格が新安値を形成する一方で、EWO はより高い安値を形成する）は、下向き推進波の潜在的な終わりを示している可能性があります
   - 弱気ダイバージェンス（価格が新高値を形成する一方で、EWO はより低い高値を形成する）は、上向き推進波の潜在的な終わりを示している可能性があります

5. **波動構造**:
   - 推進波（波 1、3、5）では、EWO は通常、トレンド方向に強い値を示します
   - 修正波（波 2、4、A、B、C）では、EWO は通常、より弱い値を示すか、主要トレンドと反対方向に動きます

6. **第 3 波の識別**:
   - Elliott Wave Theory において通常最も強い推進波である第 3 波は、多くの場合、最も高い EWO 値によって特徴付けられます
