# Alligator

**Alligator** インジケーターは、3 つの移動平均のグループで構成されます。これらの移動平均はそれぞれ異なる期間を持ち、チャート上で前方にもシフトされます。

このインジケーターを使用するには、[Alligator](xref:StockSharp.Algo.Indicators.Alligator) クラスを使用します。
##### "Alligator" インジケーターの特徴
  
このインジケーターは、色の異なる 3 本のラインで構成されます。
  
- 青色のラインは jaw と呼ばれ、計算期間は 13、シフトは 8 バーです。価格曲線の下に位置している場合、潜在的な価格上昇を示します。"jaw" が価格曲線の上に上がると、下落が予想されます。

- 赤色のラインは alligator's teeth と呼ばれ、期間は 8、シフトは 5 バーです。高速平均に属し、時間足レンジでの価格動向を示します。
  
- 緑色のラインは lips と呼ばれ、期間は 5、シフトは 3 バーです。12 分の市場トレンドを分析します。

値はクラシックなインジケーター用のものであり、設定では常に独自のパラメーターを指定できます。
