# GMMA

**Guppy複合移動平均 (GMMA)** は、Daryl Guppy によって開発されたテクニカル指標で、2つの指数移動平均 (EMA) グループを使用して、短期トレーダーと長期投資家の相互作用を明らかにします。

この指標を使用するには、[GuppyMultipleMovingAverage](xref:StockSharp.Algo.Indicators.GuppyMultipleMovingAverage) クラスを使用する必要があります。

## 説明

Guppy複合移動平均 (GMMA) は、2つの指数移動平均 (EMA) グループで構成されます。
1. **短期グループ** (通常は 3、5、8、10、12、15 期間) - 短期トレーダーの活動を表します
2. **長期グループ** (通常は 30、35、40、45、50、60 期間) - 長期投資家の活動を表します

GMMA は、これら2つの市場参加者グループの相互作用を可視化し、市場がトレンド状態にあるのか、もみ合い状態にあるのかを判断できるようにします。また、この指標は短期トレーダーが長期投資家と同じ方向に追随し始めるタイミングを特定するのにも役立ちます。これは多くの場合、トレンドの形成または強化を示します。

GMMA は特に次の用途に役立ちます。
- 現在のトレンドの強さと方向を判断する
- 潜在的なトレンド反転を特定する
- 市場がもみ合いからトレンドへ移行するタイミングを認識する
- 既存トレンドへの最適なエントリーポイントを判断する

## 計算

GMMA の計算では、2つの指数移動平均グループを算出します。

1. 短期 EMA グループ:
   ```
   EMA_3 = EMA(Price, 3)
   EMA_5 = EMA(Price, 5)
   EMA_8 = EMA(Price, 8)
   EMA_10 = EMA(Price, 10)
   EMA_12 = EMA(Price, 12)
   EMA_15 = EMA(Price, 15)
   ```

2. 長期 EMA グループ:
   ```
   EMA_30 = EMA(Price, 30)
   EMA_35 = EMA(Price, 35)
   EMA_40 = EMA(Price, 40)
   EMA_45 = EMA(Price, 45)
   EMA_50 = EMA(Price, 50)
   EMA_60 = EMA(Price, 60)
   ```

ここで:
- EMA - 指数移動平均
- Price - 価格 (通常は終値)

## 解釈

GMMA の解釈では、個々のグループとそれらの相互作用の両方を分析します。

1. **グループの位置関係**:
   - 短期グループが長期グループより上にある場合、上昇トレンドを示します
   - 短期グループが長期グループより下にある場合、下降トレンドを示します

2. **グループ間の距離**:
   - グループ間の距離が大きい場合、強いトレンドを示します
   - 距離が小さい、またはグループが交差する場合、弱いトレンドまたはもみ合いを示します

3. **収縮と拡大**:
   - グループ内のラインの収縮 (収束) は、不確実性と、もみ合いの可能性を示します
   - グループ内のラインの拡大 (発散) は、トレンドの強化を示します

4. **クロスオーバー**:
   - 短期グループが長期グループを下から上へ抜ける - 強い強気シグナル
   - 短期グループが長期グループを上から下へ抜ける - 強い弱気シグナル

5. **方向の変化**:
   - 長期グループが方向を変え始めた場合、長期投資家のセンチメントに重大な変化があることを示します
   - 長期グループに変化がない状態での短期グループの反転は、多くの場合、一時的な調整を示します

6. **最適なエントリーポイント**:
   - 強い拡大の後、トレンド内の調整を示す収縮が発生する場合があります
   - そのような収縮の終了 (新たな拡大) は、主トレンド方向への良好なエントリーポイントになり得ます

7. **早期反転警告**:
   - 短期平均が先に方向を変え、その後、長期平均に変化が現れ始めます
   - グループ間のクロスオーバーは、トレンド反転の確認として機能する場合があります
