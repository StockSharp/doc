# Correlation

**相関** または **相関依存** は、2 つ以上の確率変数（または一定の精度でそのように見なせる変数）の間の統計的関係です。この関係では、これらの変数の 1 つまたは複数の値の変化に、別の変数または他の変数の値の体系的な変化が伴います。

2 つの確率変数間の相関の数学的尺度は、相関比または相関係数です。これは変数間の関係の強さを特徴付けます。

相関係数
1. -1 から +1 までの値を取ることができます。
2. 係数の符号は、関係の方向（正または逆）を示します。
3. 絶対値は、関係の強さを示します。
4. 常に数値のペアに基づきます。
