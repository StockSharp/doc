# MAC

**移動平均クロスオーバー (MAC)** は、短期移動平均と長期移動平均のクロスオーバーを追跡し、市場への潜在的なエントリーおよびエグジットポイントを特定するテクニカルインジケーターです。

インジケーターを使用するには、[MovingAverageCrossover](xref:StockSharp.Algo.Indicators.MovingAverageCrossover) クラスを使用する必要があります。

## 説明

移動平均クロスオーバー (MAC) インジケーターは、テクニカル分析で最も広く使用され、理解しやすいインジケーターの 1 つです。短期移動平均が長期移動平均をクロスすると、トレンド変化または重要な価格変動を示す可能性があるという概念に基づいています。

MAC は、期間の異なる 2 つの移動平均を使用します:
1. 短期移動平均 (FastMA) - 直近の価格変動を反映します
2. 長期移動平均 (SlowMA) - より長期の価格変動を反映します

このインジケーターは通常、短期移動平均と長期移動平均の差として表されます。これにより、クロスオーバーの瞬間 (インジケーター値がゼロラインをクロスする時点) を容易に識別できます。

MAC は、単独の取引戦略でも、MACD (移動平均収束拡散法) などのより複雑なシステムの一部としても広く使用されています。

## パラメーター

このインジケーターには次のパラメーターがあります:
- **ShortPeriod** - 短期移動平均の期間 (既定値: 9)
- **LongPeriod** - 長期移動平均の期間 (既定値: 26)

## 計算

移動平均クロスオーバーインジケーターの計算には、次の手順が含まれます:

1. 短期移動平均を計算します:
   ```
   FastMA = SMA(Price, ShortPeriod)
   ```

2. 長期移動平均を計算します:
   ```
   SlowMA = SMA(Price, LongPeriod)
   ```

3. 短期移動平均と長期移動平均の差として MAC 値を計算します:
   ```
   MAC = FastMA - SlowMA
   ```

ここで:
- Price - 価格 (通常は終値)
- SMA - 単純移動平均
- ShortPeriod - 短期移動平均の期間
- LongPeriod - 長期移動平均の期間

注: SMA の代わりに、EMA (指数移動平均)、WMA (加重移動平均) など、他の種類の移動平均も使用できます。

## 解釈

移動平均クロスオーバーインジケーターは次のように解釈できます:

1. **ゼロラインのクロスオーバー**:
   - MAC のゼロラインを下から上へクロスする (FastMA が SlowMA を下から上へクロスする) と、潜在的な上昇トレンドの開始を示す強気シグナルが生成されます
   - MAC のゼロラインを上から下へクロスする (FastMA が SlowMA を上から下へクロスする) と、潜在的な下降トレンドの開始を示す弱気シグナルが生成されます

2. **インジケーター値**:
   - 正の MAC 値は、短期移動平均が長期移動平均を上回っていることを示し、多くの場合、強気の市場状態として解釈されます
   - 負の MAC 値は、短期移動平均が長期移動平均を下回っていることを示し、多くの場合、弱気の市場状態として解釈されます

3. **移動平均間の距離**:
   - 移動平均間の距離が拡大する (MAC の絶対値が増加する) 場合、トレンドの強まりを示します
   - 移動平均間の距離が縮小する (MAC の絶対値が減少する) 場合、トレンドの弱まりと潜在的な反転を示す場合があります

4. **誤シグナル**:
   - 横ばいの保ち合い期間では、移動平均のクロスオーバーが頻繁に発生するため、MAC は複数の誤シグナルを生成する場合があります
   - 誤シグナルをフィルタリングするために、追加のインジケーターまたはルールがよく使用されます (例: 価格が両方の移動平均の上または下にあることを要求する)

5. **他のインジケーターとの組み合わせ**:
   - MAC は、シグナルを確認するためにモメンタムインジケーター (RSI、Stochastic) と組み合わせて使用されることがよくあります
   - より包括的な取引システムを作成するために、トレンドおよびボラティリティインジケーターと組み合わせることもできます

6. **パラメーター選択**:
   - 短い期間 (例: 5 と 20) はより敏感で、短期取引に適しています
   - 長い期間 (例: 50 と 200) は感度が低く、長期取引に適しています
