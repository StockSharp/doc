# MI

**マス指数 (MI)** は、価格レンジの拡大と収縮を分析することで潜在的なトレンド反転を特定する、Donald Dorsey によって開発されたテクニカル指標です。

この指標を使用するには、[MassIndex](xref:StockSharp.Algo.Indicators.MassIndex) クラスを使用する必要があります。

## 説明

マス指数 (MI) は、価格レンジ（最高価格と最低価格の差）の変化を追跡することで、潜在的なトレンド反転を検出するのに役立つテクニカル分析ツールです。この指標は、トレンド反転の前には通常、価格レンジの拡大とその後の収縮が先行するという仮定に基づいて、Donald Dorsey によって開発されました。

MI は、価格レンジの指数移動平均 (EMA) を使用してボラティリティを測定します。反転方向は予測せず、その確率のみを示します。そのため、MI は方向性を示す他の指標と組み合わせて使用されることがよくあります。

主な概念は、マス指数が特定のしきい値に達した後、その水準を下回ると、現在のトレンドが反転する可能性が高まるというものです。

## パラメーター

この指標には次のパラメーターがあります。
- **Length** - 主な計算期間（デフォルト値: 25）
- **EmaLength** - 価格レンジ EMA の期間（デフォルト値: 9）

## 計算

マス指数の計算には、次の手順が含まれます。

1. 各期間の 高値-安値 レンジを計算します。
   ```
   Range = High - Low
   ```

2. レンジの 9 期間 EMA を計算します。
   ```
   EMA1 = EMA(Range, EmaLength)
   ```

3. レンジの EMA の 9 期間 EMA を計算します。
   ```
   EMA2 = EMA(EMA1, EmaLength)
   ```

4. 比率を計算します。
   ```
   Ratio = EMA1 / EMA2
   ```

5. 25 期間にわたって比率を合計します。
   ```
   MI = Sum(直近 Length 期間の Ratio)
   ```

ここで:
- High - 期間の最高価格
- Low - 期間の最低価格
- EMA - 指数移動平均
- Length - 合計期間（通常 25）
- EmaLength - EMA 期間（通常 9）

## 解釈

マス指数は次のように解釈されます。

1. **"反転ハンプ"**:
   - 古典的な "反転ハンプ" シグナルは、マス指数が 27 を上回った後、26.5 を下回ると形成されます
   - このパターンはトレンド反転の可能性を示しますが、その方向は予測しません

2. **指数レベル**:
   - 27 を超える値は、価格レンジの拡大とボラティリティの増加を示します
   - 高い値の後に低下が続く場合、トレンド反転に先行する可能性があります
   - 低い値（20 未満）は、価格レンジの収縮とボラティリティの低下を示します

3. **トレンド方向**:
   - マス指数は、トレンド方向やその反転を示しません
   - 方向を判断するには、追加の指標または分析手法が必要です（例: 移動平均やサポート/レジスタンス水準）

4. **ダイバージェンス**:
   - 価格とマス指数の間のダイバージェンスは、"反転ハンプ" パターンほど重要ではありません
   - ただし、価格の新高値/新安値と、低下するマス指数の高値/安値の不一致は、トレンドの弱まりを示す可能性があります

5. **他の指標との組み合わせ**:
   - マス指数は、トレンド方向指標と組み合わせると最もよく機能します
   - 潜在的な反転方向を判断するための一般的な組み合わせには、EMA、MACD、RSI があります

6. **ボラティリティの変化**:
   - マス指数の急上昇は、価格レンジの大幅な拡大を示し、強い動きに先行する可能性があります
   - 指数の緩やかな低下は、レンジの縮小と保ち合いの可能性を示唆します

7. **パラメーター調整**:
   - 標準パラメーター（EMA は 9、合計は 25）は、ほとんどの時間枠で良好に機能します
   - 期間を短くするとシグナルは速くなりますが、ダマシのシグナルが増える可能性があります
