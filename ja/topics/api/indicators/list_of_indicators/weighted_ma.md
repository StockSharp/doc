# Weighted MA

**Weighted Moving Average (WMA)** - このインジケーターは、一定期間における加重平均価格を表示します。このインジケーターは波状のラインとして価格に追随し、価格チャートに対して一定の乖離を持ちます。

このインジケーターを使用するには、[WeightedMovingAverage](xref:StockSharp.Algo.Indicators.WeightedMovingAverage) クラスを使用する必要があります。
