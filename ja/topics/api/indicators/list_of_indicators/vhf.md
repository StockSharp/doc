# VHF

**垂直水平フィルター (VHF)** - 垂直水平フィルター インジケーターは、1991 年に Adam White によって開発されました。このインジケーターは、価格がトレンド（上昇トレンドまたは下降トレンド）にある期間、またはこのインジケーターが過熱局面（横ばいトレンド）にある期間を認識するために、テクニカル分析で使用されます。

このインジケーターを使用するには、[VerticalHorizontalFilter](xref:StockSharp.Algo.Indicators.VerticalHorizontalFilter) クラスを使用する必要があります。
