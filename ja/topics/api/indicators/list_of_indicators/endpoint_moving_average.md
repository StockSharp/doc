# EPMA

**エンドポイント移動平均 (EPMA)** は、トレンド識別における遅れを低減するように設計された、標準的な移動平均を改良したテクニカルインジケーターです。

このインジケーターを使用するには、[EndpointMovingAverage](xref:StockSharp.Algo.Indicators.EndpointMovingAverage) クラスを使用する必要があります。

## 説明

エンドポイント移動平均 (EPMA) は、終点のデータポイントに重点を置く特殊な移動平均です。指定された期間内のすべてのポイントに均等に重みを付ける標準的な移動平均とは異なり、EPMA は終点のポイントにより大きな重みを与えるため、トレンド変化により速く反応できます。

EPMA の主な目的は、市場ノイズをフィルタリングする能力を維持しながら、従来の移動平均に固有の遅れを低減することです。その計算手法により、EPMA は価格方向の変化に対してより速く反応することが多く、トレンド反転をより早期に識別したいトレーダーにとって有用なツールになります。

EPMA は特に次の用途に役立ちます:
- トレンド変化のより早期の識別
- シグナルの遅れの低減
- より感度の高い取引システムの作成
- 他のインジケーターからのシグナルを、より少ない遅延で確認すること

## パラメーター

このインジケーターには次のパラメーターがあります:
- **Length** - 計算期間 (デフォルト値: 14)

## 計算

エンドポイント移動平均の計算は、対象期間の終点に注目する線形回帰法に基づきます:

1. 期間の初期ポイントと最終ポイントの間の線形トレンドを決定します:
   ```
   Start Value = Price[current - Length + 1]
   End Value = Price[current]
   ```

2. トレンドラインの傾きを計算します:
   ```
   Slope = (End Value - Start Value) / (Length - 1)
   ```

3. トレンドラインを現在ポイントへ投影したものとして EPMA を計算します:
   ```
   EPMA = Start Value + Slope * (Length - 1)
   ```

実際には、EPMA は対象期間の最後の価格値 (End Value) と等しくなりますが、概念的には終点によって定義される線形トレンドの投影です。

## 解釈

エンドポイント移動平均は他の移動平均と同様に解釈されますが、その高い感度を考慮します:

1. **EPMA の方向**:
   - 上向きの EPMA は上昇トレンドを示します
   - 下向きの EPMA は下降トレンドを示します

2. **価格とのクロスオーバー**:
   - 価格が EPMA を下から上へクロスした場合、強気シグナルと見なすことができます
   - 価格が EPMA を上から下へクロスした場合、弱気シグナルと見なすことができます

3. **複数の EPMA のクロスオーバー**:
   - 短期 EPMA が長期 EPMA を下から上へクロスすると、上昇トレンドの開始を示す可能性があります
   - 短期 EPMA が長期 EPMA を上から下へクロスすると、下降トレンドの開始を示す可能性があります

4. **他の移動平均とのダイバージェンス**:
   - 感度が高いため、EPMA は従来の移動平均より早くトレンド変化に反応する場合があります
   - EPMA と他の種類の移動平均の間のダイバージェンスは、潜在的なトレンド変化の早期警告として機能することがあります

5. **シグナルのフィルタリング**:
   - 感度が高いため、EPMA は横ばいの保ち合い期間中により多くの誤シグナルを生成する場合があります
   - シグナルの信頼性を高めるには、追加のフィルターや他のインジケーターからの確認を使用することを推奨します
