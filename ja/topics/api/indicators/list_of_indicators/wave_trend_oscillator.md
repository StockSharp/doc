# WTO

**ウェーブトレンドオシレーター (WTO)** は、買われ過ぎおよび売られ過ぎの市場水準を特定し、周期的な価格変動を検出するために開発されたテクニカルインジケーターです。WTO はチャネルとオシレーターの要素を組み合わせており、市場モメンタムと潜在的な反転ポイントを特定するための有効なツールです。

このインジケーターを使用するには、[WaveTrendOscillator](xref:StockSharp.Algo.Indicators.WaveTrendOscillator) クラスを使用する必要があります。

## 説明

ウェーブトレンドオシレーターは、市場ノイズをフィルタリングし、主要な価格変動を強調するように設計されています。このインジケーターはゼロラインの周囲で振動し、周期的な価格変動と相関する波形パターンを形成します。

WTO の主な特徴:
- ゼロライン周辺で振動し、正の値は上昇トレンドを、負の値は下降トレンドを示します
- 買われ過ぎ水準 (通常は +60 より上) と売られ過ぎ水準 (通常は -60 より下)
- 価格ノイズをフィルタリングし、主要な変動を強調する能力

主なインジケーターシグナル:
- ゼロラインのクロス (トレンド方向の変化)
- 買われ過ぎ/売られ過ぎゾーンからの退出
- WTO と価格の間のダイバージェンス (潜在的な反転)
- 特定の波形パターン

## パラメーター

- **ESA期間** - ESA 値を計算するための EMA 期間 (通常は 10)
- **偏差期間** - 偏差を計算するための期間 (通常は 21)
- **平均期間** - 最終オシレーターの平均を計算するための期間 (通常は 4)

## 計算

ウェーブトレンドオシレーターの計算には、いくつかの手順が含まれます。

1. 典型価格を計算します。
   ```
   AP = (High + Low + Close) / 3
   ```

2. 平滑化された第1測定値と、その絶対値を作成します。
   ```
   ESA = EMA(AP, EsaPeriod)
   D = EMA(Abs(AP - ESA), DPeriod)
   ```

3. 第1オシレーターラインを計算します。
   ```
   CI = (AP - ESA) / (0.015 * D)
   ```

4. オシレーターを平滑化して最終的な WTO 値を取得します。
   ```
   WTO = EMA(CI, AveragePeriod)
   ```

インジケーターパラメーターの一般的な値は EsaPeriod = 10、DPeriod = 21、AveragePeriod = 4 ですが、異なる時間枠や銘柄に合わせて調整できます。
