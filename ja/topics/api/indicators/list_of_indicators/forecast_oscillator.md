# FOSC

**予測オシレーター (FOSC)** は、線形回帰によって得られた予測値からの価格の乖離を測定し、その乖離をパーセンテージとして表すテクニカルインジケーターです。

このインジケーターを使用するには、[ForecastOscillator](xref:StockSharp.Algo.Indicators.ForecastOscillator) クラスを使用する必要があります。

## 説明

予測オシレーター (FOSC) は線形回帰に基づいており、現在価格が予測値からどの程度乖離しているかを測定するように設計されています。これは、現在価格が期待されるトレンドにどれだけ沿っているか、またはどれだけ乖離しているかをトレーダーが評価するのに役立ちます。

このインジケーターは、指定された期間にわたって線形回帰を使用してトレンドラインを計算し、そのライン上の予測値と実際の終値を比較します。その差はパーセンテージとして表されるため、FOSC はゼロラインの周囲で変動するオシレーターになります。

予測オシレーター は特に次の用途に役立ちます:
- 価格が期待されるトレンドにどの程度一致しているかの判断
- 潜在的な反転ポイントの識別
- トレンドからの極端な価格乖離の検出
- 価格が予想より速く、または遅く動いている期間の識別

## パラメーター

このインジケーターには次のパラメーターがあります:
- **Length** - 線形回帰計算の期間 (デフォルト値: 14)

## 計算

予測オシレーター の計算には次の手順が含まれます:

1. 指定された期間にわたる線形回帰を使用して予測ラインを計算します:
   ```
   予測 = 線形回帰線(Close, Length)
   ```

2. 現在価格と予測値の間のパーセンテージ比率としてオシレーターを計算します:
   ```
   FOSC = ((Close - 予測) / 予測) * 100
   ```

ここで:
- Close - 現在の終値
- 予測 - 線形回帰によって得られた予測値
- Length - 線形回帰計算の期間

## 解釈

予測オシレーター は次のように解釈されます:

1. **ゼロからの乖離**:
   - 正の値 (FOSC > 0) は、現在価格が予測値を上回っていることを示し、予想より強い上昇の動きを示唆する場合があります
   - 負の値 (FOSC < 0) は、現在価格が予測値を下回っていることを示し、予想より強い下降の動きを示唆する場合があります

2. **極端な値**:
   - 非常に高い正の値は、トレンドに対して市場が買われ過ぎの状態にある可能性を示します
   - 非常に低い負の値は、トレンドに対して市場が売られ過ぎの状態にある可能性を示します

3. **ゼロへの回帰**:
   - FOSC が極端な値からゼロへ向かう動きは、価格がトレンドラインへ戻る可能性を示すシグナルになる場合があります

4. **ゼロラインのクロスオーバー**:
   - ゼロラインを下から上へクロスすると、強気シグナルと見なすことができます
   - ゼロラインを上から下へクロスすると、弱気シグナルと見なすことができます

5. **ダイバージェンス**:
   - 強気ダイバージェンス (価格が新安値を形成する一方で、FOSC がより高い安値を形成する) は、潜在的な上方反転を示す可能性があります
   - 弱気ダイバージェンス (価格が新高値を形成する一方で、FOSC がより低い高値を形成する) は、潜在的な下方反転を示す可能性があります

6. **トレンド確認**:
   - FOSC が価格と同じ方向に動く場合、現在のトレンドの強さを確認します
   - FOSC が価格と反対方向に動く場合、現在のトレンドの弱まりを示す可能性があります
