# HLI

**高安指数 (HLI)** は、一定期間に新高値を付けた株式数と新安値を付けた株式数の比率を測定するテクニカル指標です。

この指標を使用するには、[HighLowIndex](xref:StockSharp.Algo.Indicators.HighLowIndex) クラスを使用する必要があります。

## 説明

高安指数 (HLI) は、新高値を付けた銘柄数と新安値を付けた銘柄数を比較することで、市場全体の活動を分析する市場幅指標です。これにより、市場の内部的な強さまたは弱さを評価できます。

この指標の主な考え方は、健全な市場では新安値を付ける証券よりも新高値を付ける証券の方が多い、というものです。逆に、弱含む市場では新安値を付ける証券の方が多くなります。

HLI は特に次の用途に役立ちます。
- 市場全体の状態を評価する
- 指数と個別市場銘柄の間のダイバージェンスを特定する
- 潜在的な市場反転ポイントを判断する
- 他の指標からのシグナルを確認する

## パラメーター

この指標には次のパラメーターがあります。
- **Length** - 計算期間 (デフォルト値: 14)

## 計算

高安指数 の計算には、次の手順が含まれます。

1. Length 期間に新高値を付けた証券数を数えます。
   ```
   新高値数 = Length 期間内に新高値を付けた銘柄数
   ```

2. Length 期間に新安値を付けた証券数を数えます。
   ```
   新安値数 = Length 期間内に新安値を付けた銘柄数
   ```

3. 新高値と新安値の差をそれらの合計で割った比率として 高安指数 を計算します。
   ```
   HLI = ((新高値数 - 新安値数) / (新高値数 + 新安値数)) * 100
   ```

注: (新高値数 + 新安値数) がゼロに等しい場合、ゼロ除算を避けるために HLI はゼロに設定されます。

## 解釈

高安指数 は次のように解釈されます。

1. **値の範囲**:
   - HLI は -100 から +100 の間で振動します
   - 正の値は、新安値よりも新高値を付ける証券が多いことを示します
   - 負の値は、新高値よりも新安値を付ける証券が多いことを示します

2. **ゼロラインのクロスオーバー**:
   - 負の値から正の値への移行は、強気シグナルと見なすことができます
   - 正の値から負の値への移行は、弱気シグナルと見なすことができます

3. **極端な値**:
   - +100 に近い値は、強い強気市場 (買われ過ぎ状態の可能性) を示します
   - -100 に近い値は、強い弱気市場 (売られ過ぎ状態の可能性) を示します

4. **ダイバージェンス**:
   - 強気ダイバージェンス: 市場指数が新安値に達する一方で、HLI はより高い安値を形成します
   - 弱気ダイバージェンス: 市場指数が新高値に達する一方で、HLI はより低い高値を形成します

5. **HLI のトレンド**:
   - HLI の継続的な上昇は、強気市場の強化を示します
   - HLI の継続的な低下は、弱気市場の強化を示します

6. **市場トレンドの確認**:
   - 市場指数が上昇し、HLI も上昇している場合、これは上昇トレンドの強さを確認します
   - 市場指数が下落し、HLI も下落している場合、これは下降トレンドの強さを確認します
