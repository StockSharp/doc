# OMA

**移動平均オシレーター (OMA)** は、モメンタムと潜在的な反転ポイントを判定するために、期間の異なる 2 つの移動平均の差を測定するテクニカルインジケーターです。

インジケーターを使用するには、[OscillatorOfMovingAverage](xref:StockSharp.Algo.Indicators.OscillatorOfMovingAverage) クラスを使用する必要があります。

## 説明

移動平均オシレーター (OMA) は、短期移動平均と長期移動平均の差を表します。このインジケーターは、異なる期間の移動平均間の関係を分析することで、トレンドの強さとその潜在的な変化を判断するのに役立ちます。

OMA は MACD (移動平均収束拡散法) と似た原理で動作しますが、シグナルラインを含まないため、より単純な形式です。このインジケーターはゼロラインの周囲で振動し、正の値は短期移動平均が長期移動平均を上回っていること (強気状態) を示し、負の値は短期移動平均が長期移動平均を下回っていること (弱気状態) を示します。

OMA の主な強みは、トレンドモメンタムの変化を特定し、ゼロラインのクロスオーバーと価格ダイバージェンスに基づいて取引シグナルを生成できる点にあります。

## パラメーター

このインジケーターには次のパラメーターがあります:
- **短期期間** - 短期移動平均の期間 (既定値: 12)
- **長期期間** - 長期移動平均の期間 (既定値: 26)

## 計算

移動平均オシレーターの計算には、次の手順が含まれます:

1. 短期移動平均を計算します:
   ```
   短期移動平均 = SMA(Price, ShortPeriod)
   ```

2. 長期移動平均を計算します:
   ```
   長期移動平均 = SMA(Price, LongPeriod)
   ```

3. 短期移動平均と長期移動平均の差として OMA を計算します:
   ```
   OMA = 短期移動平均 - 長期移動平均
   ```

ここで:
- Price - 価格 (通常は終値)
- SMA - 単純移動平均
- ShortPeriod - 短期移動平均の期間
- LongPeriod - 長期移動平均の期間

注: SMA の代わりに、EMA (指数移動平均)、WMA (加重移動平均) など、他の種類の移動平均も使用できます。

## 解釈

移動平均オシレーターは次のように解釈できます:

1. **ゼロラインのクロスオーバー**:
   - OMA がゼロラインを下から上へクロスする (短期移動平均が長期移動平均を下から上へクロスする) 場合、強気シグナルと見なすことができます
   - OMA がゼロラインを上から下へクロスする (短期移動平均が長期移動平均を上から下へクロスする) 場合、弱気シグナルと見なすことができます

2. **極端な値**:
   - 高い正の OMA 値は、市場が買われ過ぎである可能性を示します
   - 高い負の OMA 値は、市場が売られ過ぎである可能性を示します
   - 極端な値は、多くの場合、調整またはトレンド反転に先行します

3. **ダイバージェンス**:
   - 強気ダイバージェンス: 価格が新しい安値を形成する一方で、OMA はより高い安値を形成します
   - 弱気ダイバージェンス: 価格が新しい高値を形成する一方で、OMA はより低い高値を形成します
   - ダイバージェンスは、多くの場合、重要なトレンド反転に先行します

4. **トレンド確認**:
   - 正の OMA 値は上昇トレンドを確認します
   - 負の OMA 値は下降トレンドを確認します
   - OMA の絶対値の増加は、現在のトレンドの強まりを示します

5. **センターライン (0)**:
   - OMA がゼロライン付近で振動する場合、明確なトレンドの不在または保ち合いを示す場合があります

6. **変化率**:
   - OMA の傾きはトレンド変化の速度を示します
   - 急な傾きは急速なトレンド変化を示します
   - 緩やかな傾きはゆっくりしたトレンド変化を示します

7. **他のインジケーターとの組み合わせ**:
   - OMA は、シグナルを確認するために他のインジケーターと組み合わせて使用されることがよくあります
   - RSI やストキャスティクスなどの買われ過ぎ/売られ過ぎインジケーターと組み合わせると特に効果的です
