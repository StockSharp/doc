# MOMA

**移動平均モメンタム (MOMA)** は、移動平均価格の変化率を測定するテクニカルインジケーターであり、モメンタムと移動平均の概念を組み合わせたものです。

インジケーターを使用するには、[MomentumOfMovingAverage](xref:StockSharp.Algo.Indicators.MomentumOfMovingAverage) クラスを使用する必要があります。

## 説明

移動平均モメンタム (MOMA) は、モメンタムインジケーターと移動平均という 2 つのインジケーターの組み合わせです。まず価格系列の移動平均を計算し、次にこの移動平均のモメンタム (変化率) を測定します。

MOMA の主な考え方は、まず移動平均を使用して価格系列を平滑化し、市場ノイズを取り除いたうえで、この平滑化された曲線の変化の速度と方向を分析することです。これにより、価格から直接モメンタムを計算するよりも、トレンドモメンタムの変化についてより明確なシグナルを得ることができます。

MOMA は、価格そのものではなく移動平均のダイナミクスの変化に注目することで、トレンドの強さと潜在的な反転ポイントの判断に役立ちます。正の MOMA 値は上向きの移動平均モメンタムを示し、負の値は下向きのモメンタムを示します。

## パラメーター

このインジケーターには次のパラメーターがあります:
- **Length** - 移動平均計算の期間 (既定値: 14)
- **MomentumPeriod** - モメンタム計算の期間 (既定値: 10)

## 計算

移動平均モメンタムの計算には、次の手順が含まれます:

1. 価格系列の移動平均を計算します:
   ```
   MA = SMA(Price, Length)
   ```

2. 移動平均のモメンタムを計算します:
   ```
   MOMA = MA[current] - MA[current - MomentumPeriod]
   ```

ここで:
- Price - 価格 (通常は終値)
- SMA - 単純移動平均
- Length - 移動平均の期間
- MomentumPeriod - モメンタム計算の期間

注: SMA の代わりに、EMA (指数移動平均)、WMA (加重移動平均) など、他の種類の移動平均も使用できます。

## 解釈

移動平均モメンタムは次のように解釈できます:

1. **ゼロラインのクロスオーバー**:
   - MOMA がゼロラインを下から上へクロスする場合、上昇トレンドの開始または強まりを示す強気シグナルと見なすことができます
   - MOMA がゼロラインを上から下へクロスする場合、下降トレンドの開始または強まりを示す弱気シグナルと見なすことができます

2. **絶対値**:
   - 高い正の MOMA 値は、強い上向きの移動平均モメンタムを示します
   - 高い負の MOMA 値は、強い下向きの移動平均モメンタムを示します
   - ゼロに近い値は、明確なモメンタムがないこと、または横ばいトレンドを示します

3. **ダイバージェンス**:
   - 強気ダイバージェンス: 価格が新しい安値を形成する一方で、MOMA はより高い安値を形成します
   - 弱気ダイバージェンス: 価格が新しい高値を形成する一方で、MOMA はより低い高値を形成します

4. **方向転換**:
   - MOMA が移動方向を変える (上昇から下落、またはその逆) と、移動平均トレンドの潜在的な変化を示す場合があります
   - このような反転は、多くの場合、価格方向の変化に先行します

5. **トレンド確認**:
   - 正の MOMA 値は上昇トレンドを確認します
   - 負の MOMA 値は下降トレンドを確認します
   - MOMA 値の増加は、現在のトレンドの強まりを示します
   - MOMA 値の減少は、現在のトレンドの弱まりを示します

6. **シグナルフィルタリング**:
   - MOMA は、他のインジケーターからのシグナルをフィルタリングするために使用できます
   - たとえば、MOMA が正の場合は強気シグナルのみを考慮し、MOMA が負の場合は弱気シグナルのみを考慮します

7. **パラメーター選択**:
   - Length と MomentumPeriod の期間を短くすると MOMA はより敏感になりますが、誤シグナルも発生しやすくなります
   - 期間を長くすると MOMA はより滑らかになりますが、シグナルが遅れる可能性があります
