# 出来高プロファイル

**出来高プロファイル** は、特定の期間および特定の価格水準における取引活動を表示する高度なインジケーターです。このインジケーターは、出来高に基づいて優勢な価格水準または重要な価格水準を示す、チャート上のヒストグラムです。

このインジケーターを使用するには、[VolumeProfileIndicator](xref:StockSharp.Algo.Indicators.VolumeProfileIndicator) クラスを使用する必要があります。
