# FR

**フィボナッチリトレースメント (FR)** は、フィボナッチ数に基づくテクニカルインジケーターで、過去の価格変動に基づいて潜在的なサポート水準とレジスタンス水準を識別するのに役立ちます。

このインジケーターを使用するには、[FibonacciRetracement](xref:StockSharp.Algo.Indicators.FibonacciRetracement) クラスを使用する必要があります。

## 説明

フィボナッチリトレースメントは、価格チャート上でサポートまたはレジスタンスとなる可能性のある領域を示すために水平線を使用する、よく使われるテクニカルツールです。これらの水準は、フィボナッチ数とそれに対応するパーセンテージ比率に基づいています。

このインジケーターはフィボナッチ数列に基づいており、各数は直前の 2 つの数の和になります (1, 1, 2, 3, 5, 8, 13, 21, 34...)。この数列から、テクニカル分析で使用される主要な比率である 23.6%、38.2%、50%、61.8%、78.6% が導かれます。

フィボナッチリトレースメントは重要な価格変動 (トレンド) に適用され、メイントレンドの方向へ継続する前に調整 (プルバック) が発生する可能性のある水準を示します。

このインジケーターは特に次の用途に役立ちます:
- 上昇トレンドにおける潜在的なサポート水準の識別
- 下降トレンドにおける潜在的なレジスタンス水準の識別
- 調整後のエントリー目標の設定
- ストップロス配置水準の決定

## パラメーター

このインジケーターには次のパラメーターがあります:
- **期間** - 重要な価格変動を決定するための期間 (デフォルト値はタイムフレームによって異なります)

## 計算

フィボナッチリトレースメント水準の計算には、次の手順が含まれます:

1. 重要な価格変動 (トレンド) を決定します:
   - 上昇トレンドの場合: 安値から高値まで
   - 下降トレンドの場合: 高値から安値まで

2. この変動の範囲に基づいて調整水準を計算します:
   ```
   Range = |High - Low|

   レベル 0% = High（上昇トレンドの場合）または Low（下降トレンドの場合）
   レベル 23.6% = High - (Range * 0.236) または Low + (Range * 0.236)
   レベル 38.2% = High - (Range * 0.382) または Low + (Range * 0.382)
   レベル 50.0% = High - (Range * 0.5) または Low + (Range * 0.5)
   レベル 61.8% = High - (Range * 0.618) または Low + (Range * 0.618)
   レベル 78.6% = High - (Range * 0.786) または Low + (Range * 0.786)
   レベル 100% = Low（上昇トレンドの場合）または High（下降トレンドの場合）
   ```

## 解釈

フィボナッチリトレースメント水準は次のように解釈されます:

1. **主な調整水準**:
   - 23.6% - 弱い水準で、強いトレンドではしばしば突破されます
   - 38.2% - 中程度の水準で、典型的な調整に対応します
   - 50.0% - 心理的に重要な水準です (フィボナッチ数ではありません)
   - 61.8% - 「黄金比」で、最も重要なフィボナッチ水準です
   - 78.6% - 深い調整で、潜在的なトレンド反転を示す場合があります

2. **上昇トレンドの場合**:
   - フィボナッチ水準は潜在的なサポート水準として機能します
   - フィボナッチ水準からの反発は、ロングポジションに入るシグナルになり得ます
   - 複数のフィボナッチ水準を下方向に突破すると、トレンドの弱まりを示す可能性があります

3. **下降トレンドの場合**:
   - フィボナッチ水準は潜在的なレジスタンス水準として機能します
   - フィボナッチ水準からの反発は、ショートポジションに入るシグナルになり得ます
   - 複数のフィボナッチ水準を上方向に突破すると、トレンドの弱まりを示す可能性があります

4. **他の水準との一致**:
   - フィボナッチ水準は、他の重要な水準 (過去の高値/安値、移動平均など) と一致すると、より重要になります

5. **異なるタイムフレームでの描画**:
   - 異なるタイムフレームで描画されたフィボナッチ水準は、反転の確率が高まるクラスタリングゾーンを形成することがあります
