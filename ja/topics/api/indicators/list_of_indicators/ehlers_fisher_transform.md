# EFT

**エーラーズ・フィッシャー変換 (EFT)** は、John Ehlers によって開発されたテクニカル指標で、Fisher の統計変換を使用して価格データを正規分布の形式に変換します。

この指標を使用するには、[EhlersFisherTransform](xref:StockSharp.Algo.Indicators.EhlersFisherTransform) クラスを使用する必要があります。

## 説明

エーラーズ・フィッシャー変換 は、市場価格が正規（ガウス）分布を持たないという概念に基づいています。代わりに、市場価格はしばしば非対称な分布を示します。この指標は、数学的な Fisher 変換式を適用し、これらの非対称分布を正規分布値へ変換します。

この変換により、極端な価格変動がより目立つようになり、市場の反転ポイントをより明確に特定しやすくなります。Fisher 変換が適用されると、ピーク値が急激に増加し、市場行動の極端な状態がより明白になります。

EFT は特に次の用途に有用です。
- 潜在的な市場反転ポイントの判断
- 買われ過ぎおよび売られ過ぎ状態の特定
- 価格と指標の間の隠れたダイバージェンスの検出
- より正確なエントリーおよびイグジットシグナルの生成

## パラメーター

この指標には次のパラメーターがあります。
- **Length** - 計算期間（既定値: 10）

## 計算

エーラーズ・フィッシャー変換 の計算には、いくつかの手順が含まれます。

1. 価格データを -1 から +1 の間の値に変換します（通常は正規化された価格ランクまたは別のオシレーターを使用します）。
   ```
   値 = (2 * ((Price - Min) / (Max - Min))) - 1
   ```
   ここで Min と Max は、Length 期間における最小価格と最大価格です。

2. Fisher 変換を適用します。
   ```
   値 >= 0.999 の場合、値 = 0.999
   値 <= -0.999 の場合、値 = -0.999

   Fisher = 0.5 * ln((1 + 値) / (1 - 値))
   ```
   ここで ln は自然対数です。

3. ノイズを低減するために平滑化します。
   ```
   EFT = EMA(Fisher, Period)
   ```
   ここで EMA は指数移動平均です。

## 解釈

エーラーズ・フィッシャー変換 は次のように解釈できます。

1. **極端な値**:
   - +2 を上回る値は、多くの場合、市場の買われ過ぎ状態を示します
   - -2 を下回る値は、多くの場合、市場の売られ過ぎ状態を示します

2. **ゼロラインのクロスオーバー**:
   - ゼロラインを下から上へ抜けることは、強気シグナルと見なすことができます
   - ゼロラインを上から下へ抜けることは、弱気シグナルと見なすことができます

3. **指標の反転**:
   - 極端な値からの指標の反転は、多くの場合、価格反転に先行します

4. **ダイバージェンス**:
   - 強気ダイバージェンス: 価格が新安値を形成する一方で、EFT はより高い安値を形成します
   - 弱気ダイバージェンス: 価格が新高値を形成する一方で、EFT はより低い高値を形成します

5. **指標ラインの傾き**:
   - 急な上向きの傾きは、強い上昇モメンタムを示します
   - 急な下向きの傾きは、強い下降モメンタムを示します

エーラーズ・フィッシャー変換 は、極端な値に達し、必ずしもすぐに反転することなくしばらくその水準にとどまることがある点で、多くの他のオシレーターと異なります。このため、強いトレンドの動きを特定するのに有用です。
