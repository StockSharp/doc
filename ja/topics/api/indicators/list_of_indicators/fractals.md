# Fractals

**Fractals** は複数のローソク足の並びであり、中央のローソク足の最大値 (最小値) が隣接するローソク足の最大値 (最小値) よりも上 (下) にあります。 

このインジケーターを使用するには、[Fractals](xref:StockSharp.Algo.Indicators.Fractals) クラスを使用する必要があります。
