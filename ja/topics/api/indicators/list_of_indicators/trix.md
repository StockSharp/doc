# TRIX

**TRIX** は、売られ過ぎおよび買われ過ぎの市場を判定するため、またはモメンタムインジケーターとして使用されるオシレーターです。多くのオシレーターと同様に、TRIX はゼロラインの周囲で振動します。オシレーターとして使用する場合、正の値は買われ過ぎの市場を示し、負の値は売られ過ぎの市場を示します。TRIX をモメンタムインジケーターとして使用する場合、正の値はモメンタムの増加を示し、負の値はモメンタムの低下を示します。

このインジケーターを使用するには、[Trix](xref:StockSharp.Algo.Indicators.Trix) クラスを使用する必要があります。
