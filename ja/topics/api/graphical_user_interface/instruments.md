# 銘柄

[S#](../../api.md) は、銘柄を扱うための多くのグラフィカルコンポーネントを提供しています。このセットには次のものが含まれます。

- 銘柄を作成するためのコンポーネント - [SecurityCreateWindow](xref:StockSharp.Xaml.SecurityCreateWindow)。
- 銘柄に関する金融情報を表示するためのコンポーネント - [SecurityGrid](xref:StockSharp.Xaml.SecurityGrid)。
- 銘柄を検索および選択するためのコンポーネント - [SecurityPicker](xref:StockSharp.Xaml.SecurityPicker)、[SecurityPickerWindow](xref:StockSharp.Xaml.SecurityPickerWindow)、および [SecurityEditor](xref:StockSharp.Xaml.PropertyGrid.SecurityEditor)。
- 連続銘柄およびインデックス銘柄を作成するためのコンポーネント - [ContinuousSecurityWindow](xref:StockSharp.Xaml.ContinuousSecurityWindow) および [IndexSecurityWindow](xref:StockSharp.Xaml.IndexSecurityWindow)。
