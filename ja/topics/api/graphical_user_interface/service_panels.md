# サービスパネル

このセクションには、マーケットデータを表示するのではなくアプリケーションの動作を設定するパネルをまとめています。各種一覧、保存先と取り込みの設定、ライセンス、アカウント、サブスクリプションです。

- 手数料ルール \- [CommissionPanel](xref:StockSharp.Xaml.CommissionPanel).
- インポート設定 \- [ImportSettingsPanel](xref:StockSharp.Xaml.ImportSettingsPanel).
- ライセンス \- [LicensePanel](xref:StockSharp.Xaml.LicensePanel).
- 銘柄検索 \- [SecurityLookupPanel](xref:StockSharp.Xaml.SecurityLookupPanel).
- 銘柄コードの対応付け \- [SecurityMappingPanel](xref:StockSharp.Xaml.SecurityMappingPanel).
- ストレージ設定 \- [StorageSettingsPanel](xref:StockSharp.Xaml.StorageSettingsPanel).
- サブスクリプション \- [SubscriptionPanel](xref:StockSharp.Xaml.SubscriptionPanel).
- 取引所 \- [ExchangesPanel](xref:StockSharp.Xaml.ExchangesPanel).
- 市場 \- [ExchangeBoardsPanel](xref:StockSharp.Xaml.ExchangeBoardsPanel).
- 営業スケジュール \- [WorkingTimeControl](xref:StockSharp.Xaml.WorkingTimeControl).
- アカウントと権限 \- [PermissionCredentialsPanel](xref:StockSharp.Xaml.PermissionCredentialsPanel).
