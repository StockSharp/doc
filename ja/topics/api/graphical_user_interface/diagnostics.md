# 診断

このセクションには、開発中や挙動の調査時に必要となるコンポーネントをまとめています。有効なルールの一覧、戦略の統計、コンパイルエラー、コードエディタです。

- 有効なルールのテーブル \- [MarketRuleGrid](xref:StockSharp.Xaml.MarketRuleGrid).
- 統計パラメーターのテーブル \- [StatisticParameterGrid](xref:StockSharp.Xaml.StatisticParameterGrid).
- コンパイルエラーのテーブル \- [ErrorsGrid](xref:StockSharp.Xaml.Code.ErrorsGrid).
- ソースコードエディタ \- [CodePanel](xref:StockSharp.Xaml.CodeEditor.CodePanel).
