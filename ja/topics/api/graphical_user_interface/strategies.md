# ストラテジー

このセクションには、ストラテジーを扱うときに使用するコンポーネントが含まれています。

- ストラテジーの統計を表示するためのテーブル - [StrategiesStatisticsPanel](xref:StockSharp.Xaml.StrategiesStatisticsPanel)。
- 同時に稼働している戦略のテーブル \- [StrategiesDashboard](xref:StockSharp.Xaml.StrategiesDashboard).
- 探索パラメーターのエディタ \- [OptimizationParametersPanel](xref:StockSharp.Xaml.OptimizationParametersPanel).
- 探索の結果 \- [OptimizationResultsPanel](xref:StockSharp.Xaml.Charting.OptimizationResultsPanel).
