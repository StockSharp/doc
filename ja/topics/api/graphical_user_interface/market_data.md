# マーケットデータ

[S#](../../api.md) には、あらゆる種類のマーケットデータを表示するためのグラフィカルコンポーネントがあります。

- ローソク足を表示するテーブル \- [CandleMessageGrid](xref:StockSharp.Xaml.CandleMessageGrid).
- 約定を表示するテーブル - [TradeGrid](xref:StockSharp.Xaml.TradeGrid)。
- Level1 を表示するテーブル - [Level1Grid](xref:StockSharp.Xaml.Level1Grid)。
- オーダーブックを表示するコンポーネント - [MarketDepthControl](xref:StockSharp.Xaml.MarketDepthControl)。
- 注文ログを表示するテーブル - [OrderLogGrid](xref:StockSharp.Xaml.OrderLogGrid)。
- ニュースを表示するテーブル - [NewsGrid](xref:StockSharp.Xaml.NewsGrid)、[NewsPanel](xref:StockSharp.Xaml.NewsPanel)。
- ニュースをメッセージとして表示するテーブル \- [NewsMessageGrid](xref:StockSharp.Xaml.NewsMessageGrid).
- トランザクションと約定を表示するテーブル \- [ExecutionGrid](xref:StockSharp.Xaml.ExecutionGrid).
