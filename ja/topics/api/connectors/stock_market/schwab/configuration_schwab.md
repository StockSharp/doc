# Charles Schwab コネクタの設定

[Charles Schwab Trader API](https://developer.schwab.com/products/trader-api--individual) を利用できるアプリケーションを作成し、OAuth トークンを取得します。

- **アクセストークン** — 有効な OAuth アクセストークン。
- **アドレス** — Trader API のアドレス。既定値は `https://api.schwabapi.com/` です。

WebSocket アドレスとリアルタイム接続の識別子は、コネクタによって自動的に取得されます。Charles Schwab の要件に従って OAuth トークンを更新してください。
