# グラフィカル設定: Groww

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- `AccessToken` - 認証用の資格情報です。
- `ApiKey` - 認証用の資格情報です。
- `ApiSecret` - 認証用の資格情報です。
- `TotpSecret` - 認証用の資格情報です。
- `DefaultProduct` - コネクターの動作モードまたは選択項目です。 既定値: `GrowwProducts.Delivery`.
