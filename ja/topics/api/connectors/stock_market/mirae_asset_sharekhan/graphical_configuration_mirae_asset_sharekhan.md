# グラフィカル設定: Mirae Asset Sharekhan

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- `ApiKey` - 認証用の資格情報です。
- `Token` - 認証用の資格情報です。
- `VendorKey` - 認証用の資格情報です。
- `CustomerId` - 口座またはクライアントの識別子です。
- `DefaultProduct` - コネクターの動作モードまたは選択項目です。 既定値: `MiraeSharekhanProducts.Investment`.
