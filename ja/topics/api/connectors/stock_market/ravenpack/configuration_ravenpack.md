# RavenPack の設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Token` - API アクセストークン。
- `Product` - 取得する RavenPack 製品。
- `DatasetId` - 取得するデータセットの識別子。
- `Address` - REST API のアドレス。
- `FeedAddress` - リアルタイムニュースフィードのエンドポイント。
