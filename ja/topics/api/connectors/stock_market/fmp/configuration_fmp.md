# Financial Modeling Prep の設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Token` - API アクセストークン。
- `Address` - REST API のアドレス。
- `StockWebSocketAddress` - WebSocket サーバーのアドレス。
- `ForexWebSocketAddress` - WebSocket サーバーのアドレス。
- `CryptoWebSocketAddress` - WebSocket サーバーのアドレス。
