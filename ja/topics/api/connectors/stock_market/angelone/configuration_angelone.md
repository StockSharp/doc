# Angel One コネクタの設定

Angel One SmartAPI に必要な認証情報、サーバーアドレス、口座識別子を取得し、次のコネクタ設定を指定します。

- **ユーザー名** - プロパティ `Login`。
- **パスワード** - プロパティ `Password`。
- **API キー** - プロパティ `ApiKey`。
- **TOTP シークレット** - プロパティ `TotpSecret`。
- **クライアントのローカル IP アドレス** - プロパティ `ClientLocalIp`。既定値は `127.0.0.1` です。
- **クライアントの公開 IP アドレス** - プロパティ `ClientPublicIp`。
- **MAC アドレス** - プロパティ `MacAddress`。
- **既定の商品区分** - プロパティ `DefaultProduct`。既定値は `Delivery` です。
