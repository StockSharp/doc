# Tradovate コネクタの設定

Tradovate で API アプリケーションを登録し、その認証情報をコネクタの設定に指定します。

- **ユーザー名** - Tradovate のユーザー名。
- **パスワード** - Tradovate のパスワード。
- **クライアント ID** - API クライアントの識別子（`cid`）。
- **シークレット** - API クライアントのシークレット（`sec`）。
- **アプリケーション ID** - 登録したアプリケーションの識別子。既定値は `StockSharp` です。
- **アプリケーションバージョン** - 登録したアプリケーションのバージョン。既定値は `1.0` です。
- **デバイス ID** - API アクセス用に登録された固定のデバイス識別子。コネクタが自動的に生成して保存します。
- **デモモード** - 実環境ではなく Tradovate のシミュレーション環境に接続します。
