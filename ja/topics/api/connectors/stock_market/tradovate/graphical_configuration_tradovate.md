# Tradovate のグラフィカル設定

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- **ユーザー名** - Tradovate のユーザー名。
- **パスワード** - Tradovate のパスワード。
- **クライアント ID** - API クライアントの識別子。
- **シークレット** - API クライアントのシークレット。
- **アプリケーション ID** - 登録したアプリケーションの識別子。
- **アプリケーションバージョン** - 登録したアプリケーションのバージョン。
- **デバイス ID** - 固定のデバイス識別子。
- **デモモード** - シミュレーション環境を使用します。
