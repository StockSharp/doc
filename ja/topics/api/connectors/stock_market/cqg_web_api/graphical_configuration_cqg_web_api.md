# CQG Web API のグラフィカル設定

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- **ユーザー名** - プロパティ `UserName`。
- **パスワード** - プロパティ `Password`。
- **ワンタイムパスワード** - プロパティ `OneTimePassword`。
- **アクセストークン** - プロパティ `AccessToken`。
- **組織識別子** - プロパティ `PrivateLabel`。既定値は `WebAPITest` です。
- **クライアント ID** - プロパティ `ClientId`。既定値は `WebAPITest` です。
- **クライアントバージョン** - プロパティ `ClientVersion`。既定値は `StockSharp 5` です。
- **エンドポイント** - プロパティ `Endpoint`。既定値は `wss://demoapi.cqg.com:443` です。
- **ポートフォリオ** - プロパティ `Portfolio`。
- **集約レベル** - プロパティ `CollapsingLevel`。既定値は `None` です。
