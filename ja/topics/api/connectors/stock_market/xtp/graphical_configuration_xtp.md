# Zhongtai XTP のグラフィカル設定

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- **ユーザー名** - プロパティ `Login`。
- **パスワード** - プロパティ `Password`。
- **クライアント ID** - プロパティ `ClientId`。既定値は `1` です。
- **気配値サーバーアドレス** - プロパティ `QuoteAddress`。
- **取引サーバーアドレス** - プロパティ `TransactionAddress`。
- **プロトコル** - プロパティ `Protocol`。既定値は `TCP` です。
- **ローカルアドレス** - プロパティ `LocalAddress`。
- **ソフトウェアキー** - プロパティ `SoftwareKey`。
- **ソフトウェアバージョン** - プロパティ `SoftwareVersion`。既定値は `1.0` です。
- **データディレクトリ** - プロパティ `DataPath`。
