# Tiger Brokers コネクタの設定

Tiger Brokers OpenAPI に必要な認証情報、サーバーアドレス、口座識別子を取得し、次のコネクタ設定を指定します。

- **Tiger ID** - プロパティ `TigerId`。
- **口座** - プロパティ `Account`。
- **ライセンス** - プロパティ `License`。既定値は `Singapore` です。
- **秘密鍵** - プロパティ `PrivateKey`。
- **トークン** - プロパティ `Token`。
- **気配値権限を自動取得** - プロパティ `AutoGrabPermission`。既定値は `true` です。
