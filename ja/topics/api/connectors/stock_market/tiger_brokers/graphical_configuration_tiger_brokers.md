# Tiger Brokers のグラフィカル設定

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- **Tiger ID** - プロパティ `TigerId`。
- **口座** - プロパティ `Account`。
- **ライセンス** - プロパティ `License`。既定値は `Singapore` です。
- **秘密鍵** - プロパティ `PrivateKey`。
- **トークン** - プロパティ `Token`。
- **気配値権限を自動取得** - プロパティ `AutoGrabPermission`。既定値は `true` です。
