# SSI

**SSI** は StockSharp を、ベトナムの HOSE、HNX、UPCOM 市場に対応する SSI FastConnect API v3 に接続します。

## 主な機能

- ソースコードで確認した機能: リアルタイムの Level 1 クォート、板情報、約定、ローソク足と履歴要求、および株式・先物のポートフォリオと注文操作。
- プロバイダー固有の通信、セッション、データ形式は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

ベトナム市場の銘柄監視、市場データ分析、履歴取得、対応する取引処理に利用できます。

利用可能な銘柄、履歴の範囲、取引権限、要求制限、サービス状況は SSI と接続口座によって決まります。
