# CQG Continuum のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

![API GUI 設定 CQG Continuum](../../../../../images/api_gui_settings_cqg_continuum.png)

- **ログイン** - ログイン。
- **パスワード** - パスワード。
- **アドレス** - サーバーアドレス。
- **ソフトウェア ID** - 一意のソフトウェア ID。
- **ハートビート** - 接続が有効かどうかを追跡するためのサーバーチェック間隔。既定では 1 分です。
- **再接続設定** - 取引システムとの接続を追跡するための設定メカニズム。([再接続設定](../../reconnection_settings.md))
