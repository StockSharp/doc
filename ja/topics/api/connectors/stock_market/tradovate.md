# Tradovate

**Tradovate** は、先物取引向けのブローカーおよび取引プラットフォームです。

このコネクタは、先物銘柄の検索、リアルタイムの気配値、約定、板情報、履歴およびリアルタイムのローソク足、口座、残高、ポジション、注文、約定情報をサポートします。実環境とデモ環境で注文の登録、変更、取消ができます。

Tradovate 向けの取引ロボットを開発する前に、[コネクタ](../../connectors.md) セクションのリンクを確認してください。
