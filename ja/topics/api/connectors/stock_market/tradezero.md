# TradeZero

**TradeZero** は、米国株式と単一レッグオプションを取引するためのブローカーです。

このコネクタは、注文の登録、取消、取消と再発注、口座データ、ポジション、現在の注文、損益をサポートします。口座の更新は WebSocket で配信されます。TradeZero は公開の市場データ用 WebSocket を提供していないため、気配値、板情報、ローソク足は有限の REST スナップショットとして返されます。

TradeZero 向けの取引ロボットを開発する前に、[コネクタ](../../connectors.md) セクションのリンクを確認してください。
