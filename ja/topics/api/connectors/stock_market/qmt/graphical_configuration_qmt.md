# グラフィカル設定: QMT

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- `GatewayHost` - サービスのアドレスです。 既定値: `127.0.0.1`.
- `GatewayPort` - コネクターの数値パラメーターです。 既定値: `58630`.
- `GatewayToken` - 認証用の資格情報です。
- `ReconnectAttempts` - コネクターの数値パラメーターです。 既定値: `10`.
- `RequestTimeout` - 時間間隔です。 既定値: `30`.
