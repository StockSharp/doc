# Webull のグラフィカル設定

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- **キー** — アプリケーションキー。
- **シークレット** — アプリケーションのシークレット。
- **アクセストークン** — 任意のアクセストークン。
- **口座** — 取引口座の識別子。
- **デモモード** — テスト環境を使用します。
