# Phillip POEMS の設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `ClientId` - OAuth クライアント識別子。
- `ClientSecret` - OAuth クライアントシークレット。
- `ApiKey` - API キー。
- `AccessToken` - OAuth アクセストークン。
- `RefreshToken` - OAuth 更新トークン。
- `AccountNo` - 証券口座番号。
