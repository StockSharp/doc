# グラフィカル設定: Fubon Neo

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- `SdkPath` - ローカルファイルまたはディレクトリへのパスです。
- `PersonalId` - 口座またはクライアントの識別子です。
- `Password` - 認証用の資格情報です。
- `ApiKey` - 認証用の資格情報です。
- `IsApiKeyLogin` - コネクターの動作を制御する切り替え項目です。
- `CertificatePath` - ローカルファイルまたはディレクトリへのパスです。
- `CertificatePassword` - 認証用の資格情報です。
- `EnvironmentUrl` - サービスのアドレスです。
- `RealtimeMode` - コネクターの動作モードまたは選択項目です。 既定値: `FubonNeoRealtimeModes.Normal`.
- `ReconnectAttempts` - コネクターの数値パラメーターです。 既定値: `10`.
