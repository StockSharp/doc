# IEX

**Investors Exchange (IEX)** は、株式相場、Forex、ニュース、先物契約などのリアルタイムマーケットデータプロバイダーです。

現在の取引プラットフォーム向けに取引ロボットを書き始める前に、[コネクター](../../connectors.md) のリンクを読むことを推奨します。 

> [!CAUTION]
> コネクターはマーケットデータフィードのみをサポートし、トランザクションはサポートしていません。
