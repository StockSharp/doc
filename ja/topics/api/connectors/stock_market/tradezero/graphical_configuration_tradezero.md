# TradeZero のグラフィカル設定

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- **キー** - TradeZero API キーの識別子。
- **シークレット** - TradeZero API のシークレット。
- **既定ルート** - 優先する注文ルート。互換性のあるルートを自動選択する場合は空にします。
