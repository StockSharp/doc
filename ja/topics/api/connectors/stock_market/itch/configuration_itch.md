# ITCH の設定

コネクタを使用するには、**ログイン** と **パスワード** を指定する必要があります。**ログイン** と **パスワード** はブローカーから提供されます。API アクセスを取得するには、ブローカーに問い合わせることを推奨します。

[ITCH](../itch.md) は、TCP および UDP プロトコルで接続できる直接データフィードプロトコルです。[ITCH](../itch.md) は、任意の注文に対するすべての変更を追跡するための注文ログを提供します。このプロトコルは NASDAQ（[TotalView-ITCH](https://www.nasdaqtrader.com/Trader.aspx?id=Totalview2) を参照）および LSE（[MITCH](https://www.londonstockexchange.com/) を参照）で使用されています。
