# OpenMarkets

**OpenMarkets** は StockSharp を公式の **OpenMarkets APIs** に接続します。

このコネクターは、銘柄検索、市場データ、ポートフォリオ情報、注文操作に対応します。

取引ロボットを開発する前に、[コネクター](../../connectors.md) セクションの資料を確認してください。
