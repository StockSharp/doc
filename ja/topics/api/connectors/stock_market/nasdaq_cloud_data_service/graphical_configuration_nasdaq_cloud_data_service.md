# Nasdaq Cloud Data Service のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

- `Login` - 口座のログイン名。
- `Password` - 口座のパスワード。
- `Address` - REST API のアドレス。
- `Source` - Nasdaq Cloud Data Service のソース識別子。
- `Offset` - 市場データのモード（リアルタイムまたは遅延）。
