# Nasdaq Cloud Data Service の設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Login` - 口座のログイン名。
- `Password` - 口座のパスワード。
- `Address` - REST API のアドレス。
- `Source` - Nasdaq Cloud Data Service のソース識別子。
- `Offset` - 市場データのモード（リアルタイムまたは遅延）。
