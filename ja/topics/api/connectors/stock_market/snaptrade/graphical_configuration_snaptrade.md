# グラフィカル設定: SnapTrade

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- `ClientId` - 口座またはクライアントの識別子です。
- `ConsumerKey` - 認証用の資格情報です。
- `UserId` - 口座またはクライアントの識別子です。
- `UserSecret` - 認証用の資格情報です。
- `AccountId` - 口座またはクライアントの識別子です。
- `PollingInterval` - 時間間隔です。 既定値: `TimeSpan.FromMinutes(1)`.
