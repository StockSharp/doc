# グラフィカル設定: TWSE

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

接続エディターの基本セクションには、次の項目があります。

- `Address`

残りのプロパティは詳細表示で設定し、[コネクタ設定](configuration_twse_openapi.md)ページで確認します。プロバイダーから別の値を指定されていない限り、入力済みの接続先は変更しないでください。
