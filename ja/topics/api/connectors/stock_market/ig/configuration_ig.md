# IG Markets コネクタの設定

IG REST・ストリーミング API に必要な認証情報、サーバーアドレス、口座識別子を取得し、次のコネクタ設定を指定します。

- **API キー** - プロパティ `ApiKey`。
- **ユーザー名** - プロパティ `UserName`。
- **パスワード** - プロパティ `Password`。
- **口座 ID** - プロパティ `AccountId`。
- **環境** - プロパティ `Environment`。既定値は `Demo` です。
- **パスワードを暗号化** - プロパティ `EncryptPassword`。
