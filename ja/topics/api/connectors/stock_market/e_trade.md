# E\*TRADE

**E-Trade Financial Corporation (E\*TRADE)** は、普通株、優先株、上場投資信託、先物契約、オプション、投資信託、債券投資などの金融資産を取引するための取引プラットフォームです。 

現在の取引プラットフォーム向けに取引ロボットを書き始める前に、[コネクター](../../connectors.md) のリンクを読むことを推奨します。
