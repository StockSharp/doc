# Intrinio の設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Token` - API アクセストークン。
- `Address` - REST API のアドレス。
- `EquityProvider` - Intrinio の株式データプロバイダー。
- `OptionProvider` - Intrinio のオプションデータプロバイダー。
- `IsDelayedOptions` - 遅延オプションデータを使用するかどうか。
