# EOD Historical Data のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

- `Token` - API アクセストークン。
- `Address` - REST API のアドレス。
- `StockTradeWebSocketAddress` - WebSocket サーバーのアドレス。
- `StockQuoteWebSocketAddress` - WebSocket サーバーのアドレス。
- `ForexWebSocketAddress` - WebSocket サーバーのアドレス。
- `CryptoWebSocketAddress` - WebSocket サーバーのアドレス。
- `StockExchange` - リクエストで使用する証券取引所コード。
