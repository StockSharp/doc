# DhanHQ

**DhanHQ** は、市場データの取得と取引のために **DhanHQ API v2** を StockSharp に統合します。

このコネクタは、銘柄検索、気配値、約定データ、板情報、履歴ローソク足、口座、残高、ポジション、注文管理、口座と注文のリアルタイム更新をサポートします。

DhanHQ 向けの取引ロボットを開発する前に、[コネクタ](../../connectors.md) セクションのリンクを確認してください。
