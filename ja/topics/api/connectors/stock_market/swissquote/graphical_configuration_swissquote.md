# グラフィカル設定: Swissquote OpenWealth

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- `Token` - 認証用の資格情報です。
- `CustomerId` - 口座またはクライアントの識別子です。
- `SafekeepingAccountId` - 口座またはクライアントの識別子です。
- `CashAccountId` - 口座またはクライアントの識別子です。
- `AccountCurrency` - 接続パラメーターです。 既定値: `CHF`.
- `IsDemo` - コネクターの動作を制御する切り替え項目です。 既定値: `true`.
- `IsDryRun` - コネクターの動作を制御する切り替え項目です。
- `IsBestEffort` - コネクターの動作を制御する切り替え項目です。
