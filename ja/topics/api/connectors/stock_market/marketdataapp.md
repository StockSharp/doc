# MarketData.app

**MarketData.app** は StockSharp を、米国の株式、ファンド、指数、オプションを扱う MarketData.app に接続します。

## 主な機能

- ソースコードで確認した機能: 銘柄とオプション契約の検索、Level 1 データ、時間外取引と株式分割調整に対応する履歴ローソク足。取引操作は提供しません。
- プロバイダー固有の通信、セッション、データ形式は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

米国銘柄の検索、クォート取得、株式またはオプションのローソク足履歴取得に利用できます。

データ範囲、遅延、履歴の深さ、契約数制限、利用可否は MarketData.app の契約プランによって決まります。
