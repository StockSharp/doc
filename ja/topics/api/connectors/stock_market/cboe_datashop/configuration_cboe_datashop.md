# Cboe DataShop / LiveVol の設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Login` - 口座のログイン名。
- `Password` - 口座のパスワード。
- `Address` - REST API のアドレス。
- `TokenAddress` - OAuth トークン取得エンドポイント。
- `DataMode` - データ取得モード。
