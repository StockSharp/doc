# ACTIV Financial の設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Login` - 口座のログイン名。
- `Password` - 口座のパスワード。
- `Host` - ACTIV ゲートウェイのホスト。
- `DataSource` - 使用する市場データソース。
- `NodePath` - ACTIV ゲートウェイノードのパス。
- `GatewayDirectory` - ACTIV ゲートウェイのインストールディレクトリへのパス。
