# NinjaTrader のグラフィカル設定

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- **ユーザー名** - プロパティ `Login`。
- **パスワード** - プロパティ `Password`。
- **クライアント ID** - プロパティ `ClientId`。
- **シークレット** - プロパティ `Secret`。
- **アプリケーション ID** - プロパティ `AppId`。既定値は `StockSharp` です。
- **アプリケーションバージョン** - プロパティ `AppVersion`。既定値は `1.0` です。
- **デバイス ID** - プロパティ `DeviceId`。
- **デモモード** - プロパティ `IsDemo`。
