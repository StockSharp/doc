# J.P. Morgan DataQuery の設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `ClientId` - OAuth クライアント識別子。
- `ClientSecret` - OAuth クライアントシークレット。
- `GroupId` - DataQuery グループの識別子。
- `Attribute` - 取得する DataQuery 属性。
