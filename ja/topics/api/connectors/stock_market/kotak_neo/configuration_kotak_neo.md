# Kotak Neo コネクタの設定

Kotak Neo 取引 API v2 に必要な認証情報、サーバーアドレス、口座識別子を取得し、次のコネクタ設定を指定します。

- **コンシューマーキー** - プロパティ `ConsumerKey`。
- **携帯電話番号** - プロパティ `MobileNumber`。
- **ユーザーコード** - プロパティ `UserCode`。
- **MPIN** - プロパティ `Mpin`。
- **TOTP シークレット** - プロパティ `TotpSecret`。
- **既定の商品区分** - プロパティ `DefaultProduct`。既定値は `Intraday` です。
