# Saxo OpenAPI のグラフィカル設定

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- **アクセストークン** - プロパティ `AccessToken`。
- **更新トークン** - プロパティ `RefreshToken`。
- **クライアント ID** - プロパティ `ClientId`。
- **クライアントシークレット** - プロパティ `ClientSecret`。
- **リダイレクト URI** - プロパティ `RedirectUri`。
- **口座キー** - プロパティ `AccountKey`。
- **環境** - プロパティ `Environment`。既定値は `Simulation` です。
