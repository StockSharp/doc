# Rithmic のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

![API GUI Settings Rithmic](../../../../../images/api_gui_settings_rithmic.png)

- **ログイン** - Login。
- **パスワード** - Password。
- **証明書** - 証明書ファイルへのパス。Rithmic システムへの接続に必要です。
- **File log** - ログファイルへのパス。
- **Server type** - サーバータイプ。
- **Point (admin)** - 管理機能用の接続ポイント（初期化\/終了処理）。
- **Point (data)** - マーケットデータへの接続ポイント。
- **ログイン（トランザクション）** - 追加ログイン。トランザクション送信が別のサーバーに対して実行される場合に使用されます。
- **Point (transactions)** - トランザクション実行システムへの接続ポイント。
- **パスワード（トランザクション）** - 追加パスワード。トランザクション送信が別のサーバーに対して実行される場合に使用されます。
- **Point (positions)** - ポートフォリオおよびポジション情報へアクセスするための接続ポイント。
- **Point (history)** - 履歴データへアクセスするための接続ポイント。
- **ドメイン（アドレス）** - ドメインアドレス。
- **ドメイン（名前）** - ドメイン名。
- **Licenses** - ライセンスサーバーアドレス。
- **Broker** - ブローカーアドレス。
- **Log (address)** - ロガーアドレス。
- **User name (hist)** - 追加ログイン。履歴プラントでの認証に使用されるユーザー ID。
- **パスワード（履歴）** - 追加パスワード。履歴プラントでの認証に使用されるパスワード
- **ハートビート** - 接続が有効であることを追跡するためのサーバーチェック間隔。既定では 1 分です。
- **再接続設定** - 取引システム設定との接続を追跡するためのメカニズム。([再接続設定](../../reconnection_settings.md))
