# Rithmic のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

![API GUI 設定 Rithmic](../../../../../images/api_gui_settings_rithmic.png)

- **ログイン** - ログイン名。
- **パスワード** - パスワード。
- **証明書** - 証明書ファイルへのパス。Rithmic システムへの接続に必要です。
- **ログファイル** - ログファイルへのパス。
- **サーバータイプ** - サーバータイプ。
- **ポイント（管理）** - 管理機能用の接続ポイント（初期化\/終了処理）。
- **ポイント（データ）** - マーケットデータへの接続ポイント。
- **ログイン（トランザクション）** - 追加ログイン。トランザクション送信が別のサーバーに対して実行される場合に使用されます。
- **ポイント（トランザクション）** - トランザクション実行システムへの接続ポイント。
- **パスワード（トランザクション）** - 追加パスワード。トランザクション送信が別のサーバーに対して実行される場合に使用されます。
- **ポイント（ポジション）** - ポートフォリオおよびポジション情報へアクセスするための接続ポイント。
- **ポイント（履歴）** - 履歴データへアクセスするための接続ポイント。
- **ドメイン（アドレス）** - ドメインアドレス。
- **ドメイン（名前）** - ドメイン名。
- **ライセンス** - ライセンスサーバーアドレス。
- **ブローカー** - ブローカーアドレス。
- **ログ（アドレス）** - ロガーアドレス。
- **ユーザー名 (hist)** - 追加ログイン。履歴プラントでの認証に使用されるユーザー ID。
- **パスワード（履歴）** - 追加パスワード。履歴プラントでの認証に使用されるパスワード
- **ハートビート** - 接続が有効であることを追跡するためのサーバーチェック間隔。既定では 1 分です。
- **再接続設定** - 取引システム設定との接続を追跡するためのメカニズム。([再接続設定](../../reconnection_settings.md))
