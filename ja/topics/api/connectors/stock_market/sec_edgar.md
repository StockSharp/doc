# SEC EDGAR

**SEC EDGAR** は StockSharp を、SEC EDGAR の公式データおよび提出書類サービスに接続します。

## 主な機能

- ソースコードで確認した機能: 公開企業の検索、提出書類ニュース、過去の提出ファイル、`SecEdgarDataTypes.CompanyFacts` による構造化企業情報。取引操作は提供しません。
- プロバイダー固有の通信、セッション、データ形式は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

SEC 登録企業を検索し、調査用に提出書類、ニュース、XBRL 企業情報を収集できます。

対象範囲と利用可否は SEC EDGAR のデータ、適正アクセス規則、設定した要求制限に従います。
