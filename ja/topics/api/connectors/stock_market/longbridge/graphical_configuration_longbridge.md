# Longbridge OpenAPI のグラフィカル設定

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- **アプリケーションキー** - プロパティ `AppKey`。
- **アプリケーションシークレット** - プロパティ `AppSecret`。
- **アクセストークン** - プロパティ `AccessToken`。
- **ポートフォリオ** - プロパティ `Portfolio`。既定値は `Longbridge` です。
- **API アドレス** - プロパティ `ApiUrl`。既定値は `https://openapi.longbridge.com` です。
- **気配値サーバーアドレス** - プロパティ `QuoteUrl`。既定値は `wss://openapi-quote.longbridge.com/v2` です。
- **取引サーバーアドレス** - プロパティ `TradeUrl`。既定値は `wss://openapi-trade.longbridge.com/v2` です。
