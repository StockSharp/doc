# QUODD の設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `AuthenticationMode` - 認証方式。
- `Token` - API アクセストークン。
- `Login` - 口座のログイン名。
- `Password` - 口座のパスワード。
- `Address` - REST API のアドレス。
