# uSMART OpenAPI の設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `AccessToken` - OAuth アクセストークン。
- `ChannelId` - uSMART 接続チャネルの識別子。
- `PrivateKey` - トランザクションの署名に使用する秘密鍵。
- `FundAccount` - uSMART の資金口座識別子。
