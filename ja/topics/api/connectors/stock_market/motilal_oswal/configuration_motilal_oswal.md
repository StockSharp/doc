# コネクターの設定: Motilal Oswal

プロバイダーから認証情報を取得し、接続パラメーターを指定します。

- `Key` - 認証用の資格情報です。
- `Secret` - 認証用の資格情報です。
- `Token` - 認証用の資格情報です。
- `AccessToken` - 認証用の資格情報です。
- `ClientCode` - 口座またはクライアントの識別子です。
- `LocalIp` - 接続パラメーターです。 既定値: `127.0.0.1`.
- `PublicIp` - 接続パラメーターです。 既定値: `127.0.0.1`.
- `MacAddress` - サービスのアドレスです。 既定値: `00:00:00:00:00:00`.
- `VendorInfo` - 接続パラメーターです。
- `InstalledAppId` - 口座またはクライアントの識別子です。
- `IsDemo` - コネクターの動作を制御する切り替え項目です。
- `DefaultProduct` - コネクターの動作モードまたは選択項目です。 既定値: `MotilalOswalProducts.Normal`.
- `AlgoId` - 口座またはクライアントの識別子です。
- `ReconnectAttempts` - コネクターの数値パラメーターです。 既定値: `10`.
