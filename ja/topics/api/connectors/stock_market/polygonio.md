# PolygonIO

**PolygonIO** は、株式、外国為替（FX）、デジタル通貨および暗号通貨のリアルタイムデータと履歴データを提供するマーケットデータプロバイダーです。

現在の取引プラットフォーム向けに取引ロボットの作成を開始する前に、[コネクタ](../../connectors.md) のリンクを読むことを推奨します。

> [!CAUTION]
> コネクタはマーケットデータフィードのみをサポートし、トランザクションはサポートしていません。
