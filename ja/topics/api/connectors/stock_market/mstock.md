# m.Stock

**m.Stock** は StockSharp を、インドの現物・デリバティブ市場に対応する m.Stock API に接続します。

## 主な機能

- ソースコードで確認した機能: 銘柄検索、リアルタイムの Level 1 クォート、板情報、約定、履歴ローソク足、および株式・先物・オプションのポートフォリオと注文操作。
- プロバイダー固有の通信、セッション、データ形式は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

インド市場の銘柄監視、クォート、板情報、ローソク足の分析、履歴取得、対応する注文処理に利用できます。

利用可能な取引所と銘柄、履歴の範囲、取引権限、要求制限は m.Stock と接続口座によって決まります。
