# コネクターの設定: IQFeed

プロバイダーのローカルゲートウェイまたはクライアントを準備し、接続パラメーターを指定します。

- `Login` - 口座またはクライアントの識別子です。
- `Password` - 認証用の資格情報です。
- `Level1Address` - サービスのアドレスです。
- `Level2Address` - サービスのアドレスです。
- `LookupAddress` - サービスのアドレスです。
- `AdminAddress` - サービスのアドレスです。
- `DerivativeAddress` - サービスのアドレスです。
- `Level1Columns` - 接続パラメーターです。
- `IsDownloadSecurityFromSite` - コネクターの動作を制御する切り替え項目です。
- `SecuritiesFile` - ローカルファイルまたはディレクトリへのパスです。
- `Version` - 接続パラメーターです。 既定値: `6.2`.
