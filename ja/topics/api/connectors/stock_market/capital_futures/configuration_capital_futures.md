# コネクターの設定: Capital Futures

公式の開発者向けパッケージをインストールし、そのパス、認証情報、その他の接続パラメーターを指定します。

- `SdkPath` - ローカルファイルまたはディレクトリへのパスです。
- `Login` - 口座またはクライアントの識別子です。
- `Password` - 認証用の資格情報です。
- `Account` - 口座またはクライアントの識別子です。
- `Environment` - コネクターの動作モードまたは選択項目です。 既定値: `CapitalFuturesEnvironments.Production`.
- `IsTradingEnabled` - コネクターの動作を制御する切り替え項目です。 既定値: `true`.
- `LogPath` - ローカルファイルまたはディレクトリへのパスです。
