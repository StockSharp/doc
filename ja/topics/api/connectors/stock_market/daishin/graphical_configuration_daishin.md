# グラフィカル設定: Daishin CYBOS Plus

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- `Account` - 口座またはクライアントの識別子です。
- `Market` - コネクターの動作モードまたは選択項目です。 既定値: `DaishinStockMarkets.Consolidated`.
- `IsTradingEnabled` - コネクターの動作を制御する切り替え項目です。 既定値: `true`.
