# TradeLocker の設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Login` - 口座のログイン名。
- `Password` - 口座のパスワード。
- `Server` - TradeLocker サーバーのアドレス。
- `AccountId` - サービスから割り当てられた口座識別子。
- `IsDemo` - デモ環境モード。
