# FactSet の設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `AuthenticationMode` - 認証方式。
- `Login` - 口座のログイン名。
- `Password` - 口座のパスワード。
- `OAuthConfigFile` - OAuth 設定ファイルへのパス。
