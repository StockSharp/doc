# グラフィカル設定: Capital.com

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- `ApiKey` - 認証用の資格情報です。
- `Login` - 口座またはクライアントの識別子です。
- `Password` - 認証用の資格情報です。
- `AccountId` - 口座またはクライアントの識別子です。
- `IsDemo` - コネクターの動作を制御する切り替え項目です。 既定値: `true`.
- `IsPasswordEncryptionEnabled` - コネクターの動作を制御する切り替え項目です。
