# コネクターの設定: kabu Station

プロバイダーのローカルゲートウェイまたはクライアントを準備し、接続パラメーターを指定します。

- `ApiPassword` - 認証用の資格情報です。
- `IsDemo` - コネクターの動作を制御する切り替え項目です。 既定値: `true`.
- `DefaultAccountType` - コネクターの動作モードまたは選択項目です。 既定値: `KabuStationAccountTypes.Specified`.
- `DefaultStockOrderExchange` - 接続パラメーターです。 既定値: `KabuStationExchanges.Sor`.
