# BMLL の設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `AuthenticationMode` - 認証方式。
- `Login` - 口座のログイン名。
- `PrivateKeyPath` - 秘密鍵ファイルへのパス。
- `Password` - 口座のパスワード。
- `Token` - API アクセストークン。
- `ApiKey` - API キー。
- `Address` - REST API のアドレス。
- `AuthenticationAddress` - 認証サービスのエンドポイント。
- `TradesDataset` - BMLL 約定データセットの名前。
- `Level3Dataset` - BMLL レベル 3 データセットの名前。
