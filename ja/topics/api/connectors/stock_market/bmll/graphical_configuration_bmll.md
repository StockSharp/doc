# BMLL のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

- `AuthenticationMode` - 認証方式。
- `Login` - 口座のログイン名。
- `PrivateKeyPath` - 秘密鍵ファイルへのパス。
- `Password` - 口座のパスワード。
- `Token` - API アクセストークン。
- `ApiKey` - API キー。
- `Address` - REST API のアドレス。
- `AuthenticationAddress` - 認証サービスのエンドポイント。
- `TradesDataset` - BMLL 約定データセットの名前。
- `Level3Dataset` - BMLL レベル 3 データセットの名前。
