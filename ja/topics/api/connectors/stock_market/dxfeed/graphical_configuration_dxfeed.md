# グラフィカル設定: dxFeed

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- `Address` - サービスのアドレスです。 既定値: `wss://demo.dxfeed.com/dxlink-ws`.
- `Token` - 認証用の資格情報です。
- `AggregationPeriod` - 時間間隔です。
- `MarketDepthLevels` - コネクターの数値パラメーターです。 既定値: `20`.
- `MarketDepthSources` - 接続パラメーターです。 既定値: `NTV`.
