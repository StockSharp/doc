# Kalshi のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

- `ApiKey` - API キー。
- `PrivateKey` - リクエストとトランザクションのローカル署名に使用する秘密鍵。
- `IsDemo` - Kalshi のデモ環境を使用する。
- `Subaccount` - 0 から 63 までの Kalshi サブアカウント番号。
