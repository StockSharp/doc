# コネクターの設定: Alice Blue

プロバイダーから認証情報を取得し、接続パラメーターを指定します。

- `UserId` - 口座またはクライアントの識別子です。
- `ClientId` - 口座またはクライアントの識別子です。
- `Token` - 認証用の資格情報です。
- `DeviceId` - 口座またはクライアントの識別子です。
- `DefaultProduct` - コネクターの動作モードまたは選択項目です。 既定値: `AliceBlueProducts.LongTerm`.
- `ReconnectAttempts` - コネクターの数値パラメーターです。 既定値: `10`.
