# コネクターの設定: 5paisa Xstream

プロバイダーから認証情報を取得し、接続パラメーターを指定します。

- `AppKey` - 認証用の資格情報です。
- `ClientCode` - 口座またはクライアントの識別子です。
- `Token` - 認証用の資格情報です。
- `DefaultProduct` - コネクターの動作モードまたは選択項目です。 既定値: `FivePaisaProducts.Intraday`.
- `AlgoId` - コネクターの数値パラメーターです。
- `ReconnectAttempts` - コネクターの数値パラメーターです。 既定値: `10`.
