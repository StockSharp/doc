# グラフィカル設定: LSEG Real-Time

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- `AuthenticationMode` - コネクターの動作モードまたは選択項目です。
- `Address` - サービスのアドレスです。
- `StandbyAddress` - サービスのアドレスです。
- `IsHotStandby` - コネクターの動作を制御する切り替え項目です。
- `Login` - 口座またはクライアントの識別子です。
- `Password` - 認証用の資格情報です。
- `ClientId` - 口座またはクライアントの識別子です。
- `Secret` - 認証用の資格情報です。
- `ApplicationId` - 口座またはクライアントの識別子です。 既定値: `256`.
- `Service` - 接続パラメーターです。 既定値: `ELEKTRON_DD`.
- `Region` - 接続パラメーターです。 既定値: `us-east-1`.
- `Position` - 接続パラメーターです。
- `Scope` - 接続パラメーターです。 既定値: `trapi.streaming.pricing.read`.
- `AuthUrl` - サービスのアドレスです。
- `DiscoveryUrl` - サービスのアドレスです。 既定値: `https://api.refinitiv.com/streaming/pricing/v1/`.
