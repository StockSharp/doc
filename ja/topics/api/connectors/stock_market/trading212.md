# 取引 212

**取引 212** は StockSharp を公式の **取引 212 公開 API** に接続します。

このコネクターは、口座情報の取得と注文操作に対応します。

取引ロボットを開発する前に、[コネクター](../../connectors.md) セクションの資料を確認してください。
