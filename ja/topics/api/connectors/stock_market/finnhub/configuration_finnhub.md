# Finnhub の設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Token` - API アクセストークン。
- `Address` - REST API のアドレス。
- `WebSocketAddress` - WebSocket サーバーのアドレス。
- `StockExchange` - リクエストで使用する証券取引所コード。
- `ForexExchange` - Finnhub の外国為替市場コード。
- `CryptoExchange` - Finnhub の暗号資産取引所コード。
