# グラフィカル設定: Finam Trade API

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

接続エディターの基本セクションには、次の項目があります。

- `Token`
- `AccountId`

詳細表示では、`AppId`、`PollingInterval`、`LookupLimit`、`RestAddress`、`WebSocketAddress` を設定します。各フィールドの用途と既定値は、[コネクタ設定](configuration_finam_trade.md)ページに記載されています。

Finam Trade コネクターのソースに実際の製品スクリーンショットがないため、コネクター専用の画像は掲載していません。上記のフィールド一覧と標準の接続設定ウィンドウを使用してください。
