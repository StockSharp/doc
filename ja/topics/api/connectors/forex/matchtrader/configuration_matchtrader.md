# Match-Trader コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Address` - REST API のアドレス。
- `Login` - 口座のログイン名。
- `Password` - 口座のパスワード。
- `BrokerId` - ブローカー識別子。
- `AccountId` - サービスから割り当てられた口座識別子。
