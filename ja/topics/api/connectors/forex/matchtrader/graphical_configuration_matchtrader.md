# Match-Trader のグラフィカル設定

すべての StockSharp 製品では、グラフィカルな接続設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) 画面フォームで行います。

- `Address` - REST API のアドレス。
- `Login` - 口座のログイン名。
- `Password` - 口座のパスワード。
- `BrokerId` - ブローカー識別子。
- `AccountId` - サービスから割り当てられた口座識別子。
