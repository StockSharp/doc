# グラフィカル設定: FXOpen TickTrader

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

Web API トークンの ID、キー、シークレットを入力します。デモ口座では `IsDemo` を有効にします。`OneTimePassword` は口座で 2 要素認証が要求される場合のみ指定します。FXOpen から別の接続先が指定されない限り、REST、Feed WebSocket、Trade WebSocket の既定アドレスを使用してください。
