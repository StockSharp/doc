# Deriv

**Deriv** は StockSharp を公式 Deriv Options REST および WebSocket API に接続します。

このコネクタは有効銘柄の検索、Level 1、ティック履歴、ティックのストリーミング、履歴およびリアルタイムのタイムフレームローソク足をサポートします。取引では契約の見積提示、購入、早期売却またはキャンセル、契約のリアルタイム更新、残高、ポートフォリオ、保有契約、トランザクションのストリーミングに対応します。

市場データは認証情報なしで利用できます。認証が必要なデモ口座または実口座では、パーソナルアクセストークンまたは OAuth トークンとアプリケーション ID を作成してください。
