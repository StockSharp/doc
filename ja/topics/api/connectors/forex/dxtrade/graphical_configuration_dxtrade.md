# DXtrade のグラフィカル設定

すべての [S\\#](../../../../api.md) 製品では、接続のグラフィカル設定は [Connection Settings Window](../../../graphical_user_interface/connection_settings_window.md) で行います。

![API GUI Settings DXtrade](../../../../../images/api_gui_settings_dxtrade.png)

- **Key** - Key。
- **Secret** - Secret。
- **Demo** - デモ取引への接続。
