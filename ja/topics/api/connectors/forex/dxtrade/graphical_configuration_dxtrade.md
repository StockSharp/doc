# DXtrade のグラフィカル設定

すべての [S\\#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

![API GUI 設定 DXtrade](../../../../../images/api_gui_settings_dxtrade.png)

- **キー** - Key。
- **シークレット** - シークレットキー。
- **デモ** - デモ取引への接続。
