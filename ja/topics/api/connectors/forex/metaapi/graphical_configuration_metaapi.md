# グラフィカル設定: MetaApi

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

トークンとデプロイ済み口座の識別子を入力します。`Region` は口座スコープのトークンの場合のみ入力します。MetaApi から別のドメインが指定されない限り既定のドメインを使用し、履歴の長い口座では `SynchronizationTimeout` を大きくしてください。
