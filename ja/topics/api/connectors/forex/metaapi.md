# MetaApi

**MetaApi** は StockSharp を MetaTrader 4 および MetaTrader 5 口座向けの MetaApi クラウド REST およびストリーミング API に接続します。

このコネクタは銘柄仕様、Level 1、ティック、板情報、ローソク足、履歴のティックとローソク足をサポートします。取引では成行注文、指値注文、ストップ注文、注文の変更とキャンセル、ポジションのクローズ、同期されたポートフォリオ、ポジション、注文、約定に対応します。

接続する前に、MetaApi で取引口座をデプロイし、API トークンを作成してください。ストリームの再接続、ターミナル状態の再同期、サブスクリプションの復元は自動的に行われます。
