# TraderMade

**TraderMade** は StockSharp を、外国為替と対応する暗号資産ペア向けの TraderMade REST および WebSocket API に接続します。

## 主な機能

- ソースコードで確認した機能: リアルタイム Level 1 クォート、任意の TraderLadder 板情報、銘柄検索、履歴ローソク足。市場データ専用です。
- プロバイダー固有の通信、セッション、データ形式は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

FX のリアルタイム監視、任意の板分析、履歴ローソク足の取得に利用できます。

シンボル、TraderLadder アクセス、週末データ、要求制限、利用可否は TraderMade の契約プランによって決まります。
