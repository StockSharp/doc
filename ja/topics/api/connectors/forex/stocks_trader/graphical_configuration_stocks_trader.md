# グラフィカル設定: StocksTrader

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

Web ターミナルで発行されたトークンを入力します。デモ口座では `IsDemo` を有効にします。選択したモードでトークンが口座を 1 つだけ保持している場合は、`AccountId` を空のままにします。StocksTrader から別の接続先が指定されない限り既定のアドレスを使用し、必要な更新頻度に合わせて `PollingInterval` を調整してください。
