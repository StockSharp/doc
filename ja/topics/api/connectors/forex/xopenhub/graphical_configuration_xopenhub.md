# X Open Hub のグラフィカル設定

すべての StockSharp 製品では、グラフィカルな接続設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) 画面フォームで行います。

- `Login` - 口座のログイン名。
- `Password` - 口座のパスワード。
- `IsDemo` - デモ環境モード。
