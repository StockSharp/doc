# X Open Hub コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Login` - 口座のログイン名。
- `Password` - 口座のパスワード。
- `IsDemo` - デモ環境モード。
