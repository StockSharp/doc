# FXOpen TickTrader

**FXOpen TickTrader** は StockSharp を公式 TickTrader Web API に接続します。

このコネクタは銘柄検索、Level 1、板情報、履歴およびリアルタイム足、ポートフォリオ、ポジション、注文、約定をサポートします。市場データには Feed WebSocket、口座と約定更新には Trade WebSocket を使用します。

ストリーミングと取引には、事前に FXOpen で Web API トークンを作成してください。公開 REST データは認証情報なしでも利用できます。
