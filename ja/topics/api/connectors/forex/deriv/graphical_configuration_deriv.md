# グラフィカル設定: Deriv

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

トークンとアプリケーション識別子を入力します。デモ口座では `IsDemo` を有効にします。選択したモードでトークンが有効な口座を 1 つだけ保持している場合は、`AccountId` を空のままにします。Deriv から別の接続先が指定されない限り、REST と WebSocket の既定アドレスを使用してください。
