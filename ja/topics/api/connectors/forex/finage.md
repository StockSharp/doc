# Finage

**Finage** は StockSharp を Finage Forex の REST および WebSocket API に接続します。

## 主な機能

- ソースコードで確認した機能: 銘柄検索、リアルタイム Level 1 クォート、履歴ローソク足。市場データ専用で取引操作は提供しません。
- プロバイダー固有の通信、セッション、データ形式は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

通貨ペアの検索、ライブクォートの監視、FX ローソク足履歴の取得に利用できます。

シンボル範囲、リアルタイムアクセス、履歴の深さ、要求制限、利用可否は Finage の契約プランによって決まります。
