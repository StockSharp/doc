# LMAX

**LMAX Global** - LMAX Global は、FCA の規制を受けた FX 向けブローカーです。LMAX Global は、ブローカーおよびプロのトレーダーに、LMAX Exchange の中央指値注文板で取引する機能を提供し、大手銀行や自己勘定取引会社からのストリーミング型の確定流動性に対して、より狭いスプレッドを提供します。

現在の取引プラットフォーム向けに取引ロボットを書き始める前に、[コネクタ](../../connectors.md)のリンクを読むことをお勧めします。
