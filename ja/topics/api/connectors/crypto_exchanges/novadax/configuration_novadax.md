# コネクタ設定: NovaDAX

NovaDAX に接続する前に、次のアダプタープロパティを設定します。この一覧は [NovaDaxMessageAdapter](xref:StockSharp.NovaDax.NovaDaxMessageAdapter) の実装で確認されています。

## 基本設定

接続エディターでは、これらの設定が最初に表示されます。

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `AccountId` (`string`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `EngineIoVersion` (`int`)
