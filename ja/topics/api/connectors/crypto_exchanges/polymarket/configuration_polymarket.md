# Polymarket コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `ApiKey` - API キー。
- `ApiSecret` - API シークレット。
- `Passphrase` - API パスフレーズ。
- `SignerAddress` - 注文に署名するアドレス。
- `FunderAddress` - 取引口座に資金を供給するアドレス。
- `PrivateKey` - リクエストとトランザクションのローカル署名に使用する秘密鍵。
- `SignatureType` - 注文に使用する署名方式。
