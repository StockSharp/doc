# Uniswap のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

- `Token` - API アクセストークン。
- `GraphApiKey` - The Graph の API キー。
- `WalletAddress` - ブロックチェーンウォレットのアドレス。
- `PrivateKey` - トランザクションの署名に使用する秘密鍵。
- `Chain` - リクエストで使用するブロックチェーンネットワーク。
- `RouterVersion` - 分散型取引所ルーターのバージョン。
- `RpcEndpoint` - ブロックチェーンの RPC エンドポイント。
- `TradingEndpoint` - 取引 API のエンドポイント。
