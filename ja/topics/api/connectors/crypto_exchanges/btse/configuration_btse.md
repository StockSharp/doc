# BTSE コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Key` - API キー。
- `Secret` - API シークレット。
- `SpotRestEndpoint` - REST API のアドレス。
- `SpotWebSocketEndpoint` - WebSocket サーバーのアドレス。
- `SpotOrderBookWebSocketEndpoint` - WebSocket サーバーのアドレス。
- `FuturesRestEndpoint` - REST API のアドレス。
- `FuturesWebSocketEndpoint` - WebSocket サーバーのアドレス。
- `FuturesOrderBookWebSocketEndpoint` - WebSocket サーバーのアドレス。
