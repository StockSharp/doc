# ProBit Global のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定を[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で行います。

- `Key` - OAuth クライアント ID。
- `Secret` - OAuth クライアントシークレット。
- `RestEndpoint` - REST API のアドレス。
- `AuthEndpoint` - OAuth トークンエンドポイントのアドレス。
- `WebSocketEndpoint` - WebSocket サーバーのアドレス。

認証情報は公開市場データでは任意ですが、取引と非公開口座データでは必須です。
