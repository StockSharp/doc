# STON.fi

**STON.fi** は StockSharp を TON ネットワーク上の自動マーケットメーカープロトコル STON.fi に接続します。アダプターは、対応する市場データとトランザクション操作を標準の StockSharp メッセージモデルを通じて提供します。

## 主な機能

- ソースコードで確認したアダプター機能: リアルタイムデータ更新、Level 1 クォート、約定データ、ローソク足データ、履歴データ要求、ポートフォリオと注文の操作。
- プロバイダー固有の通信、セッション、データ形式は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

STON.fi プールの監視、実行可能クォート、約定、ローソク足の分析、履歴データの取得、および対応する交換処理に利用できます。

利用可能なプール、データの深さ、トランザクション権限、要求制限、サービス提供状況は、STON.fi、TON サービス、接続したウォレットによって決まります。
