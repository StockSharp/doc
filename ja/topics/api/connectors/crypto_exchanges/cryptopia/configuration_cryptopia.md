# Cryptopia の設定

コネクタを使用するには、取引所の個人アカウントで **Key (API Key)** と **Secret** を生成し、それらを接続設定で指定する必要があります。

> [!TIP]
> **Key** と **Secret** は **Login** および **Password** ではないことに注意してください。**Key** と **Secret** は個人アカウントで別途生成されます。コネクタを使用するために **Login** と **Password** は不要であり、どこにも指定する必要はありません。
