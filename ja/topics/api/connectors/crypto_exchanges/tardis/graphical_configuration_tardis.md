# Tardis のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

- `Token` - API アクセストークン。
- `Exchange` - データを取得する取引所コード。
- `ApiEndpoint` - REST API エンドポイント。
- `MachineHttpEndpoint` - Tardis Machine のローカル HTTP エンドポイント。
- `MachineSocketEndpoint` - Tardis Machine のローカル WebSocket エンドポイント。
