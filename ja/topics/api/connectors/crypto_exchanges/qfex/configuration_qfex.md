# QFEX コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `RestEndpoint` - REST API エンドポイント。
- `Key` - API キー。
- `Secret` - API シークレット。
- `AccountId` - 取引口座の識別子。
