# BW のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います:

![API GUI 設定 BW](../../../../../images/api_gui_settings_bw.png)

- **キー** - Key。
- **シークレット** - シークレットキー。
- **残高** - 残高確認間隔。入金および出金操作の場合に必要です。
- **ハートビート** - 接続が有効であることを追跡するためのサーバー確認間隔。既定では 1 分です。
- **再接続設定** - 取引システムとの接続を設定に基づいて追跡するメカニズム。([再接続設定](../../reconnection_settings.md))
