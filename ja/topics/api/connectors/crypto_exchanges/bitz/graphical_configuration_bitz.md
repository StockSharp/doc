# BitZ のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

![API GUI 設定 Bit-Z](../../../../../images/api_gui_settings_bit-z.png)

- **キー** - キー。
- **シークレット** - シークレット。
- **ドメイン（アドレス）** - ドメインアドレス。
- **Balance** - 残高確認間隔。入金および出金操作の場合に必要です。
- **パスワード** - 管理者パスワード。
- **ハートビート** - 接続が生きていることを追跡するためのサーバーチェック間隔。既定では 1 分です。
- **再接続設定** - 取引システム設定で接続を追跡するためのメカニズム。([再接続設定](../../reconnection_settings.md))
