# FalconX コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `ApiKey` - API キー。
- `Secret` - API シークレット。
- `Passphrase` - API パスフレーズ。
- `ApiEndpoint` - サービス API のエンドポイント。
- `PriceSocketEndpoint` - FalconX の価格用 WebSocket エンドポイント。
- `OrderSocketEndpoint` - FalconX の注文用 WebSocket エンドポイント。
