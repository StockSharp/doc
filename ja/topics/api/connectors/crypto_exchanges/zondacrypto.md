# zondacrypto

**zondacrypto** は StockSharp を暗号資産プラットフォーム zondacrypto に接続します。アダプターは標準 StockSharp メッセージモデルを通じてプロバイダー API を公開します。

## 主な機能

- ソースコードで確認したアダプター機能：リアルタイム更新、Level 1 クォート、Level 2 板情報、約定データ、履歴データ要求、ポートフォリオと注文操作。
- プロバイダー固有の通信、セッション、データ形式は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

取引ロボット、端末、データ収集、注文管理サービス、暗号資産市場の監視に利用できます。

利用可能な銘柄、データ深度、トランザクション権限、要求制限、サービス状況は zondacrypto、API プラン、接続口座の権限によって決まります。
