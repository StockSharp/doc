# Orderly Network コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `AccountId` - 取引口座の識別子。
- `Secret` - API シークレット。
- `RestEndpoint` - REST API エンドポイント。
- `PublicWebSocketEndpoint` - 公開市場データ用 WebSocket エンドポイント。
