# Orderly Network のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

- `AccountId` - 取引口座の識別子。
- `Secret` - API シークレット。
- `RestEndpoint` - REST API エンドポイント。
- `PublicWebSocketEndpoint` - 公開市場データ用 WebSocket エンドポイント。
