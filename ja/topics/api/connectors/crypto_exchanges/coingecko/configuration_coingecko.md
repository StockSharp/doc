# CoinGecko コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Tier` - CoinGecko API の契約プラン。
- `Token` - API アクセストークン。
- `ApiEndpoint` - REST API エンドポイント。
- `SocketEndpoint` - WebSocket API エンドポイント。
- `QuoteCurrency` - 市場価格の表示に使用する決済通貨。
- `IsStreamingEnabled` - WebSocket のリアルタイムデータを有効にする。
