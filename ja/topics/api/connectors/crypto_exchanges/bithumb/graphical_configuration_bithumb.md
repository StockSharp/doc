# Bithumb のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

![API GUI 設定 Bithumb](../../../../../images/api_gui_settings_bithumb.png)

- **キー** - Key。
- **シークレット** - Secret。
- **Balance** - 残高確認間隔です。入金および出金操作の場合に必要です。
- **ハートビート** - 接続が維持されていることを追跡するためのサーバー確認間隔です。デフォルトでは 1 分です。
- **再接続設定** - 取引システム設定で接続を追跡するためのメカニズムです。([再接続設定](../../reconnection_settings.md))
- **IsPrime** - IsPrime
