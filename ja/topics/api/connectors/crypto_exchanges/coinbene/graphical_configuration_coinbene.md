# CoinBene のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います:

![API GUI Settings CoinBene](../../../../../images/api_gui_settings_coinbene.png)

- **Key** - キー。
- **Secret** - シークレット。
- **Balance** - 残高チェック間隔。入金および出金アクションの場合に必要です。
- **ハートビート** - 接続が生存しているかを追跡するためのサーバーチェック間隔。既定では 1 分です。
- **再接続設定** - 取引システムとの接続を設定付きで追跡するための仕組み。([再接続設定](../../reconnection_settings.md))
