# VALR コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Key` - API キー。
- `Secret` - API シークレット。
- `SubAccountId` - サブ口座の識別子。
- `RestEndpoint` - REST API のアドレス。
- `TradeWebSocketEndpoint` - WebSocket サーバーのアドレス。
- `AccountWebSocketEndpoint` - WebSocket サーバーのアドレス。
