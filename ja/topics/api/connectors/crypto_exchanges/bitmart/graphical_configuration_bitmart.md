# Bitmart のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

![API GUI 設定 Bitmart](../../../../../images/api_gui_settings_bitmart.png)

- **キー** - キー。
- **シークレット** - シークレット。
- **Board** - 接続するセクション (Spot、Futures)。
- **パスフレーズ** - 管理者パスワード。
