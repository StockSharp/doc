# Bullish のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

- `Key` - API キー。
- `Secret` - API シークレット。
- `TradingAccountId` - 取引口座の識別子。
- `RateLimitToken` - API リクエスト制限の識別に使用する Bullish トークン。
- `RestEndpoint` - REST API のアドレス。
- `WsEndpoint` - WebSocket サーバーのアドレス。
