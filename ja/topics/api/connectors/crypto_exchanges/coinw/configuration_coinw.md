# CoinW コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Key` - API キー。
- `Secret` - API シークレット。
- `SpotRestEndpoint` - REST API のアドレス。
- `FuturesRestEndpoint` - REST API のアドレス。
- `SpotPublicWsEndpoint` - WebSocket サーバーのアドレス。
- `SpotPrivateWsEndpoint` - WebSocket サーバーのアドレス。
- `FuturesPublicWsEndpoint` - WebSocket サーバーのアドレス。
- `FuturesPrivateWsEndpoint` - WebSocket サーバーのアドレス。
