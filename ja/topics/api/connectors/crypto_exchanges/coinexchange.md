# CoinExchange

**CoinExchange** - 暗号通貨のリアルタイムデータを提供するマーケットデータプロバイダーです。

この取引プラットフォーム向けの取引ロボットを書き始める前に、[コネクター](../../connectors.md) セクションのリンクを読むことを推奨します。

> [!CAUTION]
> コネクターはマーケットデータフィードのみをサポートし、トランザクションはサポートされていません。
