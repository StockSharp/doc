# Hyperliquid の設定

コネクタを使用するには、ウォレットレベルの取引認証情報を指定します。

主な設定:

 - **ウォレットアドレス**。
 - **秘密鍵**。
 - **Vault アドレス** (任意)。
 - **有効期限** (任意)。
- **セクション**: `Spot` または `Derivatives`。
- **テストネット** モード。
 - **Info エンドポイント / Exchange エンドポイント / WS エンドポイント**。
- **成行スリッページ** (成行注文用)。

- [Hyperliquid API](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api)

- [Websocket](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/websocket)
