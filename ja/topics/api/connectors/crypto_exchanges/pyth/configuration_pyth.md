# Pyth コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Token` - API アクセストークン。
- `HistoryEndpoint` - 履歴データ API のエンドポイント。
- `RouterEndpoint` - 最新価格 REST API のエンドポイント。
- `WebSocketEndpoint1` - リアルタイムデータの主 WebSocket エンドポイント。
- `WebSocketEndpoint2` - リアルタイムデータの副 WebSocket エンドポイント。
- `WebSocketEndpoint3` - リアルタイムデータの第 3 WebSocket エンドポイント。
- `Channel` - Pyth データチャネル。
