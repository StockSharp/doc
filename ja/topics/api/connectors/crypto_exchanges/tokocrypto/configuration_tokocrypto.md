# コネクタ設定: Tokocrypto

Tokocrypto に接続する前に、次のアダプタープロパティを設定します。この一覧は [TokocryptoMessageAdapter](xref:StockSharp.Tokocrypto.TokocryptoMessageAdapter) の実装で確認されています。

## 基本設定

接続エディターでは、これらの設定が最初に表示されます。

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `AccountRestEndpoint` (`string`)
- `MarketDataRestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
