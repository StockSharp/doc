# MEXC のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [Connection Settings Window](../../../graphical_user_interface/connection_settings_window.md) で行います。

![API GUI Settings MEXC](../../../../../images/api_gui_settings_mexc.png)

- **Key** - Key。
- **Secret** - Secret。
- **Demo** - デモモード。
- **Reconnection settings** - 取引システムとの再接続メカニズムのパラメーター（[再接続設定](../../reconnection_settings.md)）。
