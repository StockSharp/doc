# グラフィカル設定 Gopax

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

![API GUI 設定 Gopax](../../../../../images/api_gui_settings_gopax.png)

- **キー** - Key。
- **シークレット** - Secret。
- **残高** - 残高確認間隔です。入金および出金操作の場合に必要です。
- **ドメイン（アドレス）** - ドメインアドレスです。
- **ハートビート** - 接続が有効であることを追跡するためのサーバー確認間隔です。既定では 1 分です。
- **再接続設定** - 取引システムへの接続を設定とともに追跡するメカニズムです。（[再接続設定](../../reconnection_settings.md)）
