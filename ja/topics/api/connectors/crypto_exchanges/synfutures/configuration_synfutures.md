# SynFutures コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `WalletAddress` - 口座操作に使用する公開ブロックチェーンウォレットアドレス。
- `PrivateKey` - リクエストとトランザクションのローカル署名に使用する秘密鍵。
