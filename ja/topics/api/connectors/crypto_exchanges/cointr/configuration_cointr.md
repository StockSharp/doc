# コネクタ設定: CoinTR

CoinTR に接続する前に、次のアダプタープロパティを設定します。この一覧は [CoinTRMessageAdapter](xref:StockSharp.CoinTR.CoinTRMessageAdapter) の実装で確認されています。

## 基本設定

接続エディターでは、これらの設定が最初に表示されます。

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `Passphrase` (`SecureString`)
- `RestEndpoint` (`string`)
- `PublicWebSocketEndpoint` (`string`)
- `PrivateWebSocketEndpoint` (`string`)
