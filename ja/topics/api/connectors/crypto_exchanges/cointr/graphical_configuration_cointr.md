# グラフィカル設定: CoinTR

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

接続エディターの基本セクションには、次の項目があります。

- `Key`
- `Secret`
- `Passphrase`
- `RestEndpoint`
- `PublicWebSocketEndpoint`
- `PrivateWebSocketEndpoint`

アダプター固有のプロパティはすべて上に記載されています。プロバイダーから別の値を指定されていない限り、入力済みの接続先は変更しないでください。
