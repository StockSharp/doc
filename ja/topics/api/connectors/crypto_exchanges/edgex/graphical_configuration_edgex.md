# edgeX のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、グラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

主なフィールド:

- **キー** - API キー。
- **シークレット** - API シークレット。
- **清算口座** - 清算アカウントの値。
- **パスフレーズ** - パスフレーズの値。
- **セクション** - 取引セクション（`Spot` または `Derivatives`）。
- **スポットを有効化** - スポットセクションを有効にします。
- **デモ** - デモ環境モード。
- **Spot REST / Derivatives REST** - REST エンドポイント。
- **Spot WS / Derivatives public WS / Derivatives private WS** - websocket エンドポイント。
