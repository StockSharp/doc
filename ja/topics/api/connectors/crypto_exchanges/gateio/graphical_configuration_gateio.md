# Gate.io のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

![API GUI 設定 Gate.io](../../../../../images/api_gui_settings_gateio.png)

- **キー** - キー。
- **シークレット** - シークレット。
- **セクション** - 取引セクション。
- **デモ** - デモ取引への接続。
