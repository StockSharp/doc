# Bit2Me のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で設定します。

- `Key` — プライベート操作用の Bit2Me API キー。
- `Secret` — Bit2Me API シークレット。
- `RestEndpoint` — REST API アドレス。
- `WebSocketEndpoint` — WebSocket アドレス。

公開市場データのみを使用する場合は `Key` と `Secret` を空のままにします。取引と口座データには両方を設定してください。
