# BloFin コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Key` - API キー。
- `Secret` - API シークレット。
- `Passphrase` - API パスフレーズ。
- `IsDemo` - デモ環境モード。
- `RestEndpoint` - REST API のアドレス。
- `PublicWsEndpoint` - WebSocket サーバーのアドレス。
- `PrivateWsEndpoint` - WebSocket サーバーのアドレス。
