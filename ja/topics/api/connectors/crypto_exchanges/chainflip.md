# Chainflip

**Chainflip** は StockSharp を Chainflip クロスチェーン流動性ネットワークに接続します。アダプターは、対応する市場データとトランザクション操作を標準の StockSharp メッセージモデルを通じて提供します。

## 主な機能

- ソースコードで確認したアダプター機能: リアルタイムデータ更新、Level 1 クォート、約定データ、板情報、ポートフォリオと注文の操作。
- プロバイダー固有の通信、セッション、データ形式は標準 StockSharp API の背後に隠蔽されます。

## 主な用途

Chainflip 流動性プールの監視、実行可能クォートと板情報の分析、およびアダプターが実装するクロスチェーン交換に利用できます。

利用可能な資産と宛先チェーン、トランザクション権限、要求制限、サービス提供状況は、Chainflip と接続したウォレットによって決まります。
