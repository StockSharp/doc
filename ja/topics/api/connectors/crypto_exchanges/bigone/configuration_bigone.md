# コネクタ設定: BigONE

BigONE に接続する前に、次のアダプタープロパティを設定します。この一覧は [BigOneMessageAdapter](xref:StockSharp.BigOne.BigOneMessageAdapter) の実装で確認されています。

## 基本設定

接続エディターでは、これらの設定が最初に表示されます。

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `SpotRestEndpoint` (`string`)
- `SpotWebSocketEndpoint` (`string`)
- `ContractRestEndpoint` (`string`)
- `ContractWebSocketEndpoint` (`string`)
- `ContractPrivateWebSocketEndpoint` (`string`)
