# ApeX Omni コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Key` - API キー。
- `Secret` - API シークレット。
- `Passphrase` - API パスフレーズ。
- `Seeds` - 注文の署名に使用する zkLink シード。
- `Environment` - 接続環境（本番ネットワークまたはテストネットワーク）。
- `RestEndpoint` - REST API エンドポイント。
- `WebSocketEndpoint` - WebSocket API エンドポイント。
- `MarketDepth` - 取得する板情報のレベル数。
