# Velo Data コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Token` - API アクセストークン。
- `ApiEndpoint` - REST API エンドポイント。
- `NewsEndpoint` - ニュース履歴 API のエンドポイント。
- `WebSocketEndpoint` - WebSocket API エンドポイント。
