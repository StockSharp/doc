# Talos コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Address` - Talos から提供された FIX サーバーのアドレスとポート。
- `SenderCompId` - FIX 送信者識別子。
- `TargetCompId` - FIX 受信者識別子。
- `Login` - FIX セッションのログイン名。
- `Password` - FIX セッションのパスワード。
- `ClientCode` - 口座ルーティング用の顧客コード。
- `TargetHost` - TLS 証明書のホスト名。
