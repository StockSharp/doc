# Kaiko のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

- `Token` - API アクセストークン。
- `Region` - Kaiko API の地域エンドポイント。
- `ReferenceEndpoint` - 参照データ API のエンドポイント。
- `MarketEndpoint` - 過去の市場データ API のエンドポイント。
- `StreamEndpoint` - リアルタイム市場データのエンドポイント。
- `IsStreamingEnabled` - WebSocket のリアルタイムデータを有効にする。
