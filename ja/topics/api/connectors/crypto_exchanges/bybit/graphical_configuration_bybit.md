# ByBit のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います:

![API GUI Settings ByBit](../../../../../images/api_gui_settings_bybit.png)

- **Key** - Key。
- **Secret** - Secret。
- **Sections** - 取引セクション。
- **Demo** - デモ取引への接続。
