# Bit2Me

**Bit2Me** は、暗号資産現物取引所 Bit2Me Pro 用のコネクターです。REST および WebSocket API を通じて、公開市場データ、過去のローソク足、口座残高、取引操作を提供します。

この市場向けの取引ロボットを作成する前に、[コネクター](../../connectors.md) セクションを確認してください。
