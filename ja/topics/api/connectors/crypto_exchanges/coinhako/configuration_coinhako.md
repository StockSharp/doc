# Coinhako コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Key` - API キー。
- `Secret` - API シークレット。
- `RestEndpoint` - REST API のアドレス。
- `CounterCurrencies` - 市場の取得対象とする建値通貨。
- `PollingInterval` - サービスへのポーリング間隔。
