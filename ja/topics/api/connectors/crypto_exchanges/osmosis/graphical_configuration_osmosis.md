# Osmosis のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

- `WalletAddress` - 残高の照会と注文の送信に使用する公開ブロックチェーンウォレットアドレス。
- `PrivateKey` - トランザクションのローカル署名に使用する秘密鍵。
- `SqsEndpoint` - Osmosis SQS API のエンドポイント。
- `LcdEndpoint` - Cosmos LCD API のエンドポイント。
- `RpcEndpoint` - ブロックチェーンの RPC エンドポイント。
- `StreamingEndpoint` - リアルタイムイベント用ブロックチェーン WebSocket エンドポイント。
