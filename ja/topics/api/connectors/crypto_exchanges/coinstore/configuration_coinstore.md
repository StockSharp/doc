# コネクタ設定: Coinstore

Coinstore に接続する前に、次のアダプタープロパティを設定します。この一覧は [CoinstoreMessageAdapter](xref:StockSharp.Coinstore.CoinstoreMessageAdapter) の実装で確認されています。

## 基本設定

接続エディターでは、これらの設定が最初に表示されます。

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
