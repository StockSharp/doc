# NDAX コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Key` - API キー。
- `Secret` - API シークレット。
- `UserId` - サービスから割り当てられたユーザー識別子。
- `AccountId` - サービスから割り当てられた口座識別子。
- `OmsId` - NDAX 注文管理システムの識別子。
- `RestEndpoint` - REST API のアドレス。
- `WebSocketEndpoint` - WebSocket サーバーのアドレス。
