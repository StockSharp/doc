# コネクタ設定: Delta Exchange India

Delta Exchange India に接続する前に、次のアダプタープロパティを設定します。この一覧は [DeltaExchangeIndiaMessageAdapter](xref:StockSharp.DeltaExchangeIndia.DeltaExchangeIndiaMessageAdapter) の実装で確認されています。

## 基本設定

接続エディターでは、これらの設定が最初に表示されます。

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `PublicWebSocketEndpoint` (`string`)
- `PrivateWebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
