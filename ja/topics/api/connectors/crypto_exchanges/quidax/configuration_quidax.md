# コネクタ設定: Quidax

Quidax に接続する前に、次のアダプタープロパティを設定します。この一覧は [QuidaxMessageAdapter](xref:StockSharp.Quidax.QuidaxMessageAdapter) の実装で確認されています。

## 基本設定

接続エディターでは、これらの設定が最初に表示されます。

- `Token` (`SecureString`)
- `UserId` (`string`)
- `RestEndpoint` (`string`)
- `PollingInterval` (`TimeSpan`)
