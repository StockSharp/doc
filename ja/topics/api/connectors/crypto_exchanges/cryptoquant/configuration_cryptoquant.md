# CryptoQuant コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Token` - API アクセストークン。
- `ApiEndpoint` - REST API エンドポイント。
- `PriceTimeFrame` - 価格ローソク足の取得に使用する時間枠。
