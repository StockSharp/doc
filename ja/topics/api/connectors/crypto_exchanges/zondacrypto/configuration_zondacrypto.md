# コネクタ設定: zondacrypto

zondacrypto に接続する前に、次のアダプタープロパティを設定します。この一覧は [ZondaCryptoMessageAdapter](xref:StockSharp.ZondaCrypto.ZondaCryptoMessageAdapter) の実装で確認されています。

## 基本設定

接続エディターでは、これらの設定が最初に表示されます。

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
