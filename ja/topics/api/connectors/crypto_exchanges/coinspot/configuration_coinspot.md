# コネクタ設定: CoinSpot

CoinSpot に接続する前に、次のアダプタープロパティを設定します。この一覧は [CoinSpotMessageAdapter](xref:StockSharp.CoinSpot.CoinSpotMessageAdapter) の実装で確認されています。

## 基本設定

接続エディターでは、これらの設定が最初に表示されます。

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `PublicEndpoint` (`string`)
- `TradingEndpoint` (`string`)
- `ReadOnlyEndpoint` (`string`)
- `PollingInterval` (`TimeSpan`)
