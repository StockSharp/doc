# CoinJar コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Token` - API アクセストークン。
- `TradingEndpoint` - 取引 API のエンドポイント。
- `DataEndpoint` - 市場データ API のエンドポイント。
- `WebSocketEndpoint` - WebSocket サーバーのアドレス。
