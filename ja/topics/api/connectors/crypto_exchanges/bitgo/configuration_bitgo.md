# BitGo コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Token` - API アクセストークン。
- `Account` - 口座識別子。
- `ApiEndpoint` - REST API エンドポイント。
- `SocketEndpoint` - WebSocket API エンドポイント。
