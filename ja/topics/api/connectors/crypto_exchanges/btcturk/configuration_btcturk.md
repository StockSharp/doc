# コネクタ設定: BtcTurk

BtcTurk に接続する前に、次のアダプタープロパティを設定します。この一覧は [BtcTurkMessageAdapter](xref:StockSharp.BtcTurk.BtcTurkMessageAdapter) の実装で確認されています。

## 基本設定

接続エディターでは、これらの設定が最初に表示されます。

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `GraphEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
