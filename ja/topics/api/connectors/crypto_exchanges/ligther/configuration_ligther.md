# Ligther 設定

コネクタを使用するには、取引所アカウントで **APIキー** と **シークレット** を生成し、接続設定で指定します。

主な設定:

- **キー** と **シークレット**。
- **アカウントインデックス** と **API キーインデックス**。
- **Section**: `Spot` または `Derivatives`。
- **Demo** モード。
- **Spot REST / Derivatives REST** エンドポイント。
- **Spot WS / Derivatives WS** エンドポイント。
 - **WS 読み取り専用モード**。
