# Ligther 設定

コネクタを使用するには、取引所アカウントで **API Key** と **Secret** を生成し、接続設定で指定します。

主な設定:

- **Key** と **Secret**。
- **Account index** と **API key index**。
- **Section**: `Spot` または `Derivatives`。
- **Demo** モード。
- **Spot REST / Derivatives REST** エンドポイント。
- **Spot WS / Derivatives WS** エンドポイント。
- **WS read-only mode**。
