# Ligther グラフィカル設定

すべての [S#](../../../../api.md) 製品では、グラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

主なフィールド:

- **キー** - API キー。
- **シークレット** - API シークレット。
- **Account index** - アカウント インデックス。
- **API key index** - API キー インデックス。
- **Section** - 取引セクション (`Spot` または `Derivatives`)。
- **Demo** - デモ環境モード。
- **Spot REST / Derivatives REST** - REST エンドポイント。
- **Spot WS / Derivatives WS** - websocket エンドポイント。
 - **WS 読み取り専用モード** - WebSocket 読み取り専用モードのフラグ。
