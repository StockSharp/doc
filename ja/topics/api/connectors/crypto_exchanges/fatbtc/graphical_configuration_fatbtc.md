# FatBTC のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

![API GUI 設定 FatBTC](../../../../../images/api_gui_settings_fatbtc.png)

- **キー** - キー。
- **シークレット** - シークレット。
- **残高** - 残高確認間隔。入金および出金操作の場合に必要です。
- **ドメイン（アドレス）** - ドメインアドレス。
- **ハートビート** - 接続が生存していることを追跡するためのサーバーチェック間隔。既定では 1 分です。
- **再接続設定** - 取引システム設定との接続を追跡するためのメカニズム。([再接続設定](../../reconnection_settings.md))
