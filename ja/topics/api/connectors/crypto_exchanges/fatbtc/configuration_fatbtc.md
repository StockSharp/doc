# FatBTC の設定

コネクターを使用するには、取引所の個人アカウントで **Key (API Key)** と **Secret** を生成し、接続設定で指定する必要があります。

> [!TIP]
> **Key** と **Secret** は **Login** および **Password** ではないことに注意してください。**Key** と **Secret** は個人アカウントで別途生成されます。コネクターを使用するために **Login** と **Password** は不要であり、どこにも指定する必要はありません。
