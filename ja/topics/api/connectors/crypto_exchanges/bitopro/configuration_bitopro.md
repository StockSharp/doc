# コネクタ設定: BitoPro

BitoPro に接続する前に、次のアダプタープロパティを設定します。この一覧は [BitoProMessageAdapter](xref:StockSharp.BitoPro.BitoProMessageAdapter) の実装で確認されています。

## 基本設定

接続エディターでは、これらの設定が最初に表示されます。

- `Email` (`string`)
- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
