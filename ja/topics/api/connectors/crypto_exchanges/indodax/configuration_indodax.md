# Indodax コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Key` - API キー。
- `Secret` - API シークレット。
- `RestEndpoint` - REST API のアドレス。
- `HistoryEndpoint` - REST API のアドレス。
- `MarketDataWebSocketEndpoint` - WebSocket サーバーのアドレス。
- `PrivateWebSocketEndpoint` - WebSocket サーバーのアドレス。
