# Quoinex の設定

コネクタを使用するには、取引所の個人アカウントで **キー（API Key）** と **シークレット** を生成し、それらを接続設定で指定する必要があります。

> [!TIP]
> **キー** と **シークレット** は **ログイン** と **パスワード** ではない点に注意してください。**キー** と **シークレット** は個人アカウントで別途生成されます。コネクタを使用するために **ログイン** と **パスワード** は不要であり、どこにも指定する必要はありません。
