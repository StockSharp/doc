# Aevo コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Environment` - 接続環境（本番ネットワークまたはテストネットワーク）。
- `ApiKey` - API キー。
- `ApiSecret` - API シークレット。
- `WalletAddress` - 口座操作に使用する公開ブロックチェーンウォレットアドレス。
- `SigningKey` - 取引リクエストの署名に使用する秘密鍵。
