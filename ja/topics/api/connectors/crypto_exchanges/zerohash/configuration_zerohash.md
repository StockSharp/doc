# Zero Hash コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `ApiKey` - API キー。
- `Secret` - API シークレット。
- `Passphrase` - API パスフレーズ。
- `Account` - 口座識別子。
- `User` - ユーザー識別子。
- `ApiEndpoint` - REST API エンドポイント。
