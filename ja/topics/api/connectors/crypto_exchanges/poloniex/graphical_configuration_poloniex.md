# Poloniex のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

![API GUI Settings Poloniex](../../../../../images/api_gui_settings_poloniex.png)

- **Key** - キー。
- **Secret** - シークレット。
- **Balance** - 残高確認間隔。入金および出金操作を行う場合に必要です。
- **ハートビート** - 接続が維持されていることを追跡するためのサーバー確認間隔。既定では 1 分です。
- **再接続設定** - 取引システムとの接続を追跡するための設定メカニズム。([再接続設定](../../reconnection_settings.md))
