# Gemini コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Key` - API キー。
- `Secret` - API シークレット。
- `Account` - 取引口座の識別子。
- `IsCancelOnDisconnect` - 接続が失われたときに有効な注文を取り消すかどうか。
- `RestEndpoint` - REST API のアドレス。
- `WebSocketEndpoint` - WebSocket サーバーのアドレス。
