# Gemini のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

- `Key` - API キー。
- `Secret` - API シークレット。
- `Account` - 取引口座の識別子。
- `IsCancelOnDisconnect` - 接続が失われたときに有効な注文を取り消すかどうか。
- `RestEndpoint` - REST API のアドレス。
- `WebSocketEndpoint` - WebSocket サーバーのアドレス。
