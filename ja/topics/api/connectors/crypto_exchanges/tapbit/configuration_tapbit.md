# Tapbit コネクタ設定

サービスから発行された接続パラメーターをコネクター設定に指定します。

## 接続パラメーター

- `Key` - API キー。
- `Secret` - API シークレット。
- `Sections` - API リクエストで有効にする市場セクション。
- `SpotRestEndpoint` - REST API のアドレス。
- `FuturesRestEndpoint` - REST API のアドレス。
- `WebSocketEndpoint` - WebSocket サーバーのアドレス。
