# SBE のグラフィカル設定

StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で SBE 接続を設定します。

- `Address` - SBE サーバーの TCP エンドポイント。
- `SenderCompId` - クライアント識別子。
- `TargetCompId` - 接続先サーバーの識別子。
- `Password` - 認証情報。
- `IsSupportNativeCandles` - ネイティブローソク足の購読を有効にします。
