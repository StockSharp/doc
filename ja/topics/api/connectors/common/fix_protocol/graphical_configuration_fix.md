# FIX のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

![API GUI 設定 FIX](../../../../../images/api_gui_settings_fix.png)

- **アドレス** - アドレス。
- **ダイアレクト** - FIX プロトコルのダイアレクト。
- **送信者** - 送信者識別子。
- **宛先** - 宛先識別子。
- **ログイン** - ログイン。
- **パスワード** - パスワード。
- **ポートフォリオ** - 起動時にすべてのポートフォリオを要求します。
- **銘柄** - 接続時にすべての銘柄を要求します。
- **エンコーディング** - データ転送に使用されるエンコーディング。
- **シーケンスリセット** - 識別子カウンターをリセットするかどうか。
- **日付形式** - 日付形式。
- **日時形式** - 日時形式。
- **時刻形式** - 時刻形式。
- **受信タイムアウト** - データ受信タイムアウト。
- **送信タイムアウト** - データ送信タイムアウト。
- **不明なトランザクション** - サードパーティによって生成された不明な約定を処理します。
- **プロトコル** - 接続確立用の SSL プロトコル。
- **証明書** - SSL 証明書。
- **パスワード** - SSL 証明書のパスワード。
- **失効チェック** - 証明書失効チェック。
- **リモート証明書の確認** - リモート証明書を確認します。
- **サーバー名** - SSL 接続を使用するサーバー名。
- **再接続設定** - 取引システムとの接続を追跡するメカニズムの設定（[再接続設定](../../reconnection_settings.md)）。
- **ハートビート間隔** - 接続がまだ有効であることをサーバーへ通知する間隔。既定値は 1 分です。
- **統一ボードコード** - 統一銘柄用のボードコード。
