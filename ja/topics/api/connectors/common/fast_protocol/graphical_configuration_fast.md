# FAST のグラフィカル設定

すべての [S#](../../../../api.md) 製品では、接続のグラフィカル設定は [接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md) で行います。

![API GUI Settings FAST](../../../../../images/api_gui_settings_fast.png)

- **ダイアレクト** - FAST プロトコルのダイアレクト。最初のパラメーターとして設定する必要があります。選択後、次のパラメーター (**FAST 設定**) には指定したダイアレクトの IP アドレスが含まれます。
- **FAST 設定** - ダイアレクト (前のパラメーターで選択) の IP アドレスとポート。設定をすばやく読み込むために、次のオプションを使用できます。
- **Settings file** - 取引所の設定ファイルからダイアレクト設定を読み込むための簡易オプション。
- **ログイン** - ログイン (TCP リカバリーサービスで使用)。
- **パスワード** - パスワード (TCP リカバリーサービスで使用)。
