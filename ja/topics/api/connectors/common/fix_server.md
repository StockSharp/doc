# FIX Server

[FixServer](xref:StockSharp.Server.Fix.FixServer) を使用すると、国際的な [FIX](https://en.wikipedia.org/wiki/Financial_Information_eXchange)\/[FAST](https://en.wikipedia.org/wiki/FAST_protocol) プロトコルを使用する独自の FIX サーバーを作成できます。トランザクションには FIX 4.4 を使用し、マーケットデータには FAST を使用します。サーバーのスキームを次の図に示します。
