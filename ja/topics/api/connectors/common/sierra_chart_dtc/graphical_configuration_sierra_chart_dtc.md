# グラフィカル設定: Sierra Chart DTC

すべての StockSharp 製品では、[接続設定ウィンドウ](../../../graphical_user_interface/connection_settings_window.md)で接続を設定します。

- `Address` - サービスのアドレスです。 既定値: `DefaultAddress`.
- `HistoryAddress` - サービスのアドレスです。 既定値: `DefaultHistoryAddress`.
- `Login` - 口座またはクライアントの識別子です。
- `Password` - 認証用の資格情報です。
- `TradeAccount` - 口座またはクライアントの識別子です。
- `MarketDataTransmissionInterval` - 時間間隔です。
- `MarketDepthLevels` - コネクターの数値パラメーターです。 既定値: `20`.
- `SslProtocol` - コネクターの動作モードまたは選択項目です。
- `HistorySslProtocol` - コネクターの動作モードまたは選択項目です。
- `IsCertificateValidation` - コネクターの動作を制御する切り替え項目です。 既定値: `true`.
- `TargetHost` - サービスのアドレスです。
