# ベストプラクティス

StockSharp プラットフォーム内で多くの取引所向けコネクターを開発する場合は、機能をいくつかの主要コンポーネントに分割する確立されたアプローチに従うことを推奨します。

1. [認証](authentication.md) - API キー管理とリクエスト署名生成を処理します。
2. [REST クライアント](rest_client.md) - 取引所の REST API との相互作用を支援します。
3. [WebSocket クライアント](websocket_client.md) - WebSocket 接続を通じてリアルタイムデータを管理します。
4. [型変換](type_conversion.md) - StockSharp データ型と取引所固有形式の間で変換するメソッドを提供します。

この分割により、コード構造をよりモジュール化して保守しやすくでき、テストが容易になり、他のプロジェクトでコンポーネントを再利用できるようになります。

これら各コンポーネントを実装する際には、対象となる取引所固有の事情を考慮することが重要ですが、一般的な構造はほとんどの取引所で類似しています。
