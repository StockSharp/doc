# 3 Inside Down と 3 Inside Up パターン

3 Inside Down および 3 Inside Up という用語は、ローソク足チャートに表示される一対の反転ローソク足パターン (それぞれ 3 本の個別のローソク足を含む) を指します。このパターンでは、3 本のローソク足が特定の順序で形成される必要があり、現在のトレンドが勢いを失い、反対方向へ動き始めている可能性を示します。

##### 主な特徴:

- 3 Inside Up パターンは、大きな下降ローソク足、その前のローソク足内に収まる小さな上昇ローソク足、続いて 2 本目のローソク足の終値を上回って終わるもう 1 本の上昇ローソク足で構成される強気の反転パターンです。
- 3 Inside Down パターンは、大きな上昇ローソク足、その前のローソク足内に収まる小さな下降ローソク足、続いて 2 本目のローソク足の終値を下回って終わるもう 1 本の下降ローソク足で構成される弱気の反転パターンです。
- これらのパターンは短期的な性質を持ち、常に大きな、または小さなトレンド変化につながるとは限りません。
- これらのパターンは、全体的なトレンドの文脈で使用することを検討してください。たとえば、全体的な上昇トレンド内の押し目で 3 Inside Up を使用します。

### 3 Inside Up

このパターンの上向きバージョンは強気であり、価格の下落が終わりつつあり、上昇が始まっていることを示します。このパターンの特徴は次のとおりです。

1. 市場は下降トレンドにあるか、下方向へ動いています。
2. 1 本目のローソク足は、大きな実体を持つ黒 (下降) のローソク足です。
3. 2 本目のローソク足は、小さな実体を持つ白 (上昇) のローソク足で、1 本目のローソク足の実体内で始まり、終わります。
4. 3 本目のローソク足は白 (上昇) のローソク足で、2 本目のローソク足の終値を上回って終わります。

### 3 Inside Down

このパターンの下向きバージョンは弱気です。上昇の値動きが終わり、価格が下がり始めることを示します。このパターンの特徴は次のとおりです。

1. 市場は上昇トレンドにあるか、上方向へ動いています。
2. 1 本目のローソク足は、大きな実体を持つ白のローソク足です。
3. 2 本目のローソク足は、小さな実体を持つ黒のローソク足で、1 本目のローソク足の実体内で始まり、終わります。
4. 3 本目のローソク足は黒のローソク足で、2 本目のローソク足の終値を下回って終わります。

これらのパターンは本質的には、確認用のローソク足が続くハラミ パターンであり、多くのトレーダーはハラミの場合にこの確認を待ちます。
