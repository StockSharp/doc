# 黒丸坊主 パターン

黒丸坊主 は、ローソク足の両端にヒゲがないことを特徴とする弱気ローソク足パターンです。「marubozu」という用語は「丸坊主」または「剃られた」を意味する日本語に由来し、ヒゲのないローソク足の外観を表しています。

##### 主な特徴:

- 始値が終値より高い（O > C）。
- ローソク足の実体が完全に塗りつぶされており、上ヒゲと下ヒゲがない。
- 始値はローソク足の高値に等しく、終値はローソク足の安値に等しい。
- 売り手が期間全体を通じて価格を支配していた、強い弱気の動きを表す。

![黒丸坊主 パターン](../../../images/blackmarubozu.png)

### 解釈

黒丸坊主 は、強い弱気シグナルと考えられます。

- ヒゲがないことは売り手の完全な支配を示します。価格は高値で始まり、期間の終了まで継続的に下落しました。
- 長い 黒丸坊主 は、非常に強い弱気圧力を示します。
- このパターンが上昇トレンド後に現れると、反転を示す場合があります。
- 下降トレンドの中では、動きの強さを確認します。

### 取引戦略

黒丸坊主 は、通常の黒ローソク足よりも強いシグナルを提供します。

- 黒丸坊主 の形成後、特に重要なレジスタンス水準で現れた場合、ショートポジションに入る機会になります。
- ストップロスを設定する際に、黒丸坊主 の終値をレジスタンス水準として使用します。
- シグナルを確認するために、他のテクニカル指標と組み合わせます。
- 出来高に注意します。出来高が多いほど、シグナルの重要性が高まります。
