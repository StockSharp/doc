# 下落三法 パターン

下落三法 は、下降トレンドで形成される、5 本のローソク足で構成される弱気トレンド継続パターンです。このパターンは、既存の下降トレンドが継続する前に、一時的な保ち合いまたは休止が発生することを示します。

##### 主な特徴:

- 最初のローソク足は黒（弱気）で、始値が終値より高く（O > C）、長い実体を持つ。
- 次の 3 本のローソク足は白（強気）で、始値が終値より低く（O < C）、小さな実体を持つ: （B < pB * 0.5m）、（B < ppB * 0.5m）、（B < pppB * 0.5m）。
- 中央の 3 本のローソク足の実体は、1 本目のローソク足の範囲を超えない。
- 5 本目のローソク足は黒（弱気）で、始値が終値より高く（O > C）、長い実体を持つ（B > pB * 2）。
- 5 本目のローソク足は 1 本目のローソク足の安値を下抜け、より低い位置で終わる。
- 下降トレンドで形成される。

![下落三法 パターン](../../../images/fallingthreemethodspattern.png)

### 解釈

下落三法 は、下降トレンド継続の信頼性の高いシグナルと考えられます。

- 最初の長い黒ローソク足は、下降トレンドの強さを示します。
- 3 本の小さな白ローソク足は、一時的な保ち合いまたは調整を表し、その間、買い手はトレンドを大きく変えることができませんでした。
- 5 本目の長い黒ローソク足は、主導権が売り手へ戻ったことと、下降トレンドの継続を確認します。
- このパターンは、古典的なテクニカル分析におけるフラッグまたはペナントと見なすことができます。
- このようなローソク足の並びは、下落の継続前に、調整がショートポジションの蓄積に利用されたことを示します。

### 取引戦略

下落三法 は、ショートポジションに入る、または強化する良い機会を提供します。

- 5 本目のローソク足の後の始値、または 1 本目のローソク足の安値を下抜けたときにショートポジションに入ります。
- ストップロスを、調整ローソク足の高値より上、または 1 本目のローソク足の高値より上に置きます。
- 利益目標は、トレンドの開始からパターンの 1 本目のローソク足までの距離に等しい投影を使用して設定できます。
- 出来高に注意します。理想的には、中央の 3 本のローソク足で出来高が減少し、5 本目のローソク足で大きく増加します。
- シグナルを確認するために、他のテクニカル指標と組み合わせます。
- 値動きの展開に影響する可能性がある、現在価格より下の重要なサポート水準を考慮します。
