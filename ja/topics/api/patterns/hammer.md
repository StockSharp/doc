# ハンマー パターン

ハンマーは、下降トレンド中に形成される強気のローソク足パターンです。ローソク足は上部に小さな実体を持ち、長い下ヒゲがあり、上ヒゲはないか非常に短くなります。名前は、このローソク足がハンマーに似ていることに由来します。

##### 主な特徴:

- 始値が終値より低い (O < C)。ただし逆の場合もあります。
- 価格範囲の上部に小さなローソク足の実体がある。
- 長い下ヒゲ。通常は実体の 2-3 倍の長さ。
- 上ヒゲがない、または非常に短い。
- 下降トレンドで形成される。

![ハンマー パターン](../../../images/hammerpattern.png)

### 解釈

ハンマーは、下降トレンドの潜在的な反転を示す強いシグナルと見なされます。

- 長い下ヒゲは、その期間中に価格が大きく下落したものの、その後買い手が介入して価格を押し戻したことを示します。
- これは、市場が安値圏の価格を拒否し、センチメントが弱気から強気へ移行する可能性を示します。
- 下ヒゲが長いほど、潜在的な反転シグナルは強くなります。
- ローソク足の実体の色はそれほど重要ではありませんが、白/緑のハンマーは黒/赤のものより強気と見なされます。

### 取引戦略

ハンマーは、ロングポジションに入る機会を提供します。

- 次のローソク足による確認を待ちます。ハンマー の後の強気ローソク足は反転シグナルを強めます。
- ハンマー の安値の下にストップロス水準を置きます。
- 以前のレジスタンス水準またはリスク/リワード比率に基づいて目標利益を設定します。
- RSI や MACD などの他のテクニカルインジケーターと組み合わせて、トレンド反転を確認します。
- ハンマー の形成中に取引出来高が高いと、シグナルの信頼性が高まります。
