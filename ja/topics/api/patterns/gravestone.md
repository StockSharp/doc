# 墓石 パターン

墓石は、始値と終値が等しく、長い上ヒゲを持ち、下ヒゲがないことを特徴とするローソク足パターンです。このローソク足は逆さの文字「T」の形に似ており、それが「墓石」という名前の由来です。

##### 主な特徴:

- 始値が終値と等しい (O == C)。
- 長い上ヒゲ。
- 下ヒゲがない (BS == 0)。
- 流れ星 に似ているが、実体が中立的 (doji)。

![墓石 パターン](../../../images/gravestonepattern.png)

### 解釈

墓石 Doji は、特に上昇トレンドにおいて、潜在的な反転シグナルと見なされます。

- 長い上ヒゲは、期間の大半で買い手が市場を支配していたものの、その後売り手が価格を始値の水準まで戻したことを示します。
- 高値圏の価格が拒否されたことは、強気モメンタムの終わりを示唆する場合があります。
- 通常の流れ星 とは異なり、始値と終値が等しいこと (doji) は、より顕著な力関係の均衡を示します。
- 上昇トレンドでは、このパターンは弱気の意味合いを持ち、反転を予兆する場合があります。
- 下降トレンドでは、一時的な抵抗またはトレンド継続を示す場合があります。

### 取引戦略

墓石は、取引判断を行うために追加の確認を必要とします。

- ショートポジションに入る前に、次の期間で確認となる弱気ローソク足を待ちます。
- ストップロスを 墓石 の高値の上に置きます。
- レジスタンス水準や、インジケーター上の買われ過ぎ状態と組み合わせて使用します。
- 出来高に注意します。墓石 の形成中に出来高が高いと、シグナルの信頼性が高まります。
- ショートポジションに入らない場合でも、ロングポジションからの退出ポイントを判断するために使用できます。
