# 白丸坊主 パターン

白丸坊主 は、ローソク足の両端にヒゲがないことを特徴とする強気のローソク足パターンです。「marubozu」という用語は、「丸坊主」または「剃られた」を意味する日本語に由来し、ヒゲのないローソク足の外観を表しています。

##### 主な特徴:

- 始値が終値より低い（O < C）。
- ローソク足の実体は完全に埋まっており、上ヒゲと下ヒゲがありません。
- 始値はローソク足の安値と等しく、終値はローソク足の高値と等しい。
- 買い手が期間を通じて価格を支配した、強い強気の動きを表します。

![白丸坊主 パターン](../../../images/whitemarubozu.png)

### 解釈

白丸坊主 は強い強気シグナルと見なされます。

- ヒゲがないことは、買い手の完全な支配を示します。価格は安値で始まり、期間の終了まで継続的に上昇しました。
- 長い 白丸坊主 は、非常に強い強気圧力を示します。
- このパターンが下降トレンド後に現れると、反転を示す場合があります。
- 上昇トレンド内では、動きの強さを確認します。

### 取引戦略

白丸坊主 は、通常の白いローソク足より強いシグナルを提供します。

- 白丸坊主 の形成後、特に重要なサポートレベルで現れた場合に、ロングポジションへ入る機会があります。
- ストップロスを設定する際に、白丸坊主 の終値をサポートレベルとして使用します。
- シグナルを確認するために、他のテクニカル指標と組み合わせます。
- 出来高に注意します。高い出来高はシグナルの重要性を高めます。
