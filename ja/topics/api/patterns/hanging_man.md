# Hanging Man パターン

Hanging Man は、上昇トレンドで形成される弱気の反転ローソク足パターンです。ローソク足は上部に小さな実体を持ち、長い下ヒゲがあり、上ヒゲはないか非常に短くなります。ローソク足の形が、脚を吊られた人物の姿に似ているため、この名前が付けられています。

##### 主な特徴:

- 始値が終値より高い (O > C)。ただし逆の場合もあります。
- 価格範囲の上部に小さなローソク足の実体がある。
- 長い下ヒゲ。通常は実体の 2-3 倍の長さ。
- 上ヒゲがない、または非常に短い (TS == 0)。
- 上昇トレンドで形成される。

![Hanging Man パターン](../../../images/hangingmanpattern.png)

### 解釈

Hanging Man は、上昇トレンドが終わる可能性への警告と見なされます。

- 長い下ヒゲは、取引セッション中に価格が大きく下落したことを示し、売り手の出現を示唆します。
- 買い手が価格をレンジ上部まで押し戻せたとしても、上昇トレンド中に大幅な価格下落が発生したという事実自体が警告シグナルです。
- ローソク足の実体の色はそれほど重要ではありませんが、黒/赤の実体は白/緑のものより弱気と見なされます。
- 下ヒゲが長く、ローソク足の実体が小さいほど、シグナルは強くなります。
- このパターンは後続のローソク足による確認を必要とします。

### 取引戦略

Hanging Man は通常、取引判断を行う前に追加の確認を必要とします。

- ショートポジションに入る前に、Hanging Man 形成後の確認となる弱気ローソク足を待ちます。
- Hanging Man の高値の上にストップロスを置きます。
- 取引出来高を考慮します。パターン形成中および確認ローソク足での高い出来高は、弱気シグナルを強めます。
- 買われ過ぎゾーンの RSI やオシレーターのダイバージェンスなど、他のテクニカルインジケーターと組み合わせます。
- ショートポジションを開かない場合でも、既存のロングポジションを部分的に手仕舞うために使用できます。
- 重要なレジスタンス水準、または長期の上昇後にこのパターンが形成された場合は、特に注意します。
