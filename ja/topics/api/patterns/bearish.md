# Bearish Candle パターン

Bearish Candle は、終値が始値より低いことを特徴とするローソク足パターンです。このパターンは弱気の市場センチメントを示します。

##### 主な特徴:

- 始値が終値より高い (O > C)。
- 市場における弱気圧力を示します。

![Bearish Candle Pattern](../../../images/bearishcandlepattern.png)

### 解釈

Bearish Candle は、いくつかの特徴を伴って弱気の市場センチメントを示します。

- 長い上ヒゲは、買い手が価格を押し上げようとしたものの、売り手が主導権を握ったことを示します。
- 始値を下回る終値は、期間の終盤で売り手が優勢だったことを示します。
- ローソク足の実体と上ヒゲの比率は、上位水準を試した後の売り手の強さを示します。
- 上昇トレンドでは、潜在的な反転または調整を示す場合があります。
- 下降トレンドでは、特に反発後にトレンドの強さを確認します。

### 取引戦略

Bearish Candle は、さまざまな取引戦略で使用できます。

- レジスタンス水準または買われ過ぎのゾーンで Bearish Candle が形成された後に、ショート ポジションを建てます。
- さらなる上昇から保護するために、ローソク足の高値の上にストップ ロスを設定します。
- 成功する取引の確率を高めるために、他のテクニカル インジケーターまたはパターンと組み合わせます。
- MACD や Moving Averages などのインジケーターからの下降トレンド シグナルを確認するために使用します。
- 取引量に注意します。高い出来高はシグナルの重要性を高めます。
- このパターンが上昇トレンド内に現れた場合、ロング ポジションの決済または部分的な利益確定に使用できます。
