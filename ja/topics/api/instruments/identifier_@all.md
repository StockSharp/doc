# 識別子 \*@ALL

金融商品が複数のボードで取引されている場合、ボードコードとして "ALL" を使用できます。たとえば、AAPL@ALL 識別子を持つ金融商品は、ティッカー AAPL のすべてのボード（AAPL@BATS、AAPL@ICE など）からデータを収集し、これらのデータは共通の板情報も持つことを意味します。 

ボードコードは、特定の取引システムに注文を送信するために使用されます。"ALL" を指定すると、ブローカーまたは取引所が注文ルートを決定します。この場合、ブローカーまたは取引所は、どのボードで注文をマッチングするのがよいかを独自に判断します。逆に、BATS などの特定のボードを指定した場合、注文は BATS のみに送信されます。
