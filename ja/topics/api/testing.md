# バックテスト\/エミュレーション

[Strategy](xref:StockSharp.Algo.Strategies.Strategy) を使用して記述されたストラテジーは、次の 3 つのモードでテストできます。 

1. [履歴データ](testing/historical_data.md)によるテスト。この種のデータを使用すると、パターンを見つけるための市場分析と、ストラテジーパラメーターの最適化の両方を実行できます。 
2. [ランダムデータ](testing/random_data.md)によるテスト。アルゴリズム内のエラーを特定するための初期ストラテジーテストに便利なツールです。または、スケジュールに従って実行される自動テストにも使用できます。 
3. [シミュレーター](testing/simulator.md)テスト。これは、取引システムへの実接続（たとえば [OpenECry](connectors/stock_market/openecry.md) から）で受信したデータに基づきますが、実際の注文登録は行いません（約定は受信した板情報に基づいてエミュレートされます）。 

3 つのモードすべてにおいて、最大の重点は、[Strategy](xref:StockSharp.Algo.Strategies.Strategy) を使用して記述されたストラテジーコードが、実取引からテストへ、またその逆へ切り替える際に変更されないという点に置かれています。これは、取引システムへのゲートウェイであるメインインターフェイス [IConnector](xref:StockSharp.BusinessEntities.IConnector) の実装によって実現されます。このインターフェイスの使用方法は、すでに [API](../api.md) セクションで示されています。テストモードでは、実際の取引システムではなく、選択されたモードに応じてエミュレーションが取引システムとして動作します。したがって、ストラテジーコードは、実際の取引所で取引しているのか、エミュレーションで取引しているのかを知ることはありません。
