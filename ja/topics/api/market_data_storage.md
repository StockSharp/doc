# 市場データストレージ

[S#](../api.md) は、データの保存と読み込みの機能を提供します。データ保存は、いくつかの場合に必要になることがあります。

1. 取引ストラテジーの動作中に、状態（注文、ポジション、設定など）を保存する必要がある場合。
2. リアルタイムでのアルゴリズムテストのために、取引端末から市場データを保存する場合。
3. 分析およびデータマイニングのためにデータを蓄積する場合。

[S#](../api.md) は、高水準アクセスと技術的詳細の隠蔽により、保存メカニズムを明確にします（詳細は [API](market_data_storage/api.md) を参照してください）。また、サポートされるストレージの種類を拡張できるため、汎用性もあります。
