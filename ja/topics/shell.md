# Shell

**Shell** は、取引ロボット向けの既製のグラフィカルフレームワークです。ニーズに合わせてカスタマイズでき、完全な C# ソースコードが含まれています。

GUI（Graphical User Interface）をゼロから構築する必要はありません。Shell には、テスト、取引、データソースへの接続、チャート、ポートフォリオ、ポジション、注文、取引の表示に必要な基本機能が含まれています。

![Shell のスクリーンショット](../images/shell_title_00.png)

取引ロボットシェルの主な機能:

1. カスタム取引ロボットやカスタムソリューションに適した完全なソースコード。
2. [コネクター](api/connectors.md) を通じた取引所およびブローカーへの **70 を超える接続のサポート**。
3. 柔軟なユーザーインターフェイス。
4. ストラテジーテストツール: 統計、エクイティ、レポート。
5. ストラテジー設定の保存と復元。
6. ストラテジーの同時実行。
7. 注文、取引、ポジション、利益、ログなど、詳細なストラテジーステータス。
8. スケジュールされたストラテジー起動。
