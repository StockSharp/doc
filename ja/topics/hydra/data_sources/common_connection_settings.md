# 共通接続設定

すべてのソースに共通する接続プロパティです。

![hydra settings connectionparams](../../../images/hydra_settings_connectionparams.png)

**接続**

- **接続** - 接続設定。
- **タイトル** - タスクのタイトル。
- **開始日（ティック）** - データのダウンロードを開始する日付。
- **開始時刻** - 開始時刻。
- **終了時刻** - 終了時刻。
- **作業間隔** - 動作間隔。
- **データディレクトリ** - StockSharp 形式の最終ファイルを保存するデータ ディレクトリ。
- **形式** - データ形式: BIN\/CSV。
- **最大エラー数** - タスクを停止するまでの最大エラー数。既定値は 0 で、エラー数を無視することを意味します。
- **ニュース** - ニュースをダウンロードします。
- **依存関係** - 現在のタスクを開始する前に完了している必要があるタスク。
- **銘柄を更新** - 接続時に銘柄を更新します。
