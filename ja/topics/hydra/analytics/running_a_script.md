# スクリプトの実行

新しい分析スクリプトを作成するには、メインウィンドウのデータソースパネルで **分析** タブを選択し、すぐに開始できるようにドロップダウンメニューから目的のテンプレートを選択します。

![スクリプトの実行 00](../../../images/hydra_analytics_main_00.png)

スクリーンショットには、この機能のメインインターフェイスが示されており、いくつかの主要コンポーネントで構成されています。

- **ナビゲーションツリー**: 日中出来高分析、ボリュームプロファイル、チャート、インジケーター、その他の分析ツールなど、さまざまな分析機能と作成済みの分析スクリプトへすばやくアクセスできます。
- **コードウィンドウ**: コードウィンドウには、選択された分析スクリプトのソースコードが表示されます。ユーザーはコードを直接編集して、分析計算や戦略をカスタマイズまたは作成できます。
- **パラメーターパネル**: 右側にはパラメーターパネルがあり、銘柄の選択、分析期間、データパス、その他の設定など、分析スクリプトのパラメーターを設定できます。
- **エラー一覧**: インターフェイス下部には、分析スクリプトのコンパイルまたは実行中に検出されたエラーの一覧があります。

分析スクリプトは、[IAnalyticsScript](xref:StockSharp.Algo.Analytics.IAnalyticsScript) から継承したクラスとして記述されます。

パラメーターを設定する場合:

- **銘柄** は、スクリプトのロジックに応じて 1 つから複数の銘柄に設定できます。

![スクリプトの実行 01](../../../images/hydra_analytics_main_01.png)

- 日付範囲。
- データを取得するストレージ。
- スクリプトが時間枠を使用する場合、その作業時間枠。

**開始** ボタン ![スクリプトの実行 のスクリーンショット](../../../images/hydra_analytics_compile.png) をクリックすると、スクリプトの実行結果を表示する新しいタブが開きます。
