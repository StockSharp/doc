# バックアップ

[S#](../../api.md) は、ダウンロードしたデータを [Amazon Web Services (AWS)](https://aws.amazon.com/s3/) クラウドストレージへバックアップするための機能を提供します。

バックアップを行うには、AWS でアカウントを作成して設定し、その後 "Backup task" を作成して設定する必要があります。
