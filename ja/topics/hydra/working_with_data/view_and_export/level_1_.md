# Level 1 

表示されるウィンドウで、銘柄と必要な時間間隔を選択し、![hydra find](../../../../images/hydra_find.png) ボタンをクリックします。

![hydra export level1](../../../../images/hydra_export_level1.png)

どの種類の変更をエクスポートするかも選択できます。これは、以下に示すドロップダウンリストを使用して行います。

![hydra export security change selected](../../../../images/hydra_export_security_change_selected.png)

取得した値は、[必要な形式にエクスポート](../export_data.md)できます。
