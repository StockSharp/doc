# オプションデスク

表示されるウィンドウで、必要な時間範囲を選択し、原資産を選択して、その原資産のオプションを追加し、![Hydra 検索ボタン](../../../../images/hydra_find.png) ボタンをクリックします。

履歴がない場合でも、スプレッドのデータがある場合は、主要なギリシャ指標（Delta、Gamma、Vega、Theta、Rho、インプライド・ボラティリティ）を計算できます。これを行うには、**ギリシャ指標を計算** フィールドでそれらを選択する必要があります。

![hydra option desk](../../../../images/hydra_option_desk.png)

**ボラティリティ・スマイル** を表示するには、**ボラティリティ・スマイル** タブに移動する必要があります。

![hydra オプションのボラティリティスマイル](../../../../images/hydra_option_smile_of_volatility.png)

計算された値は、[必要な形式にエクスポート](../export_data.md)できます。
