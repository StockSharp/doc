# インジケーター

表示されたパネルで、銘柄と対象の時間範囲を選択し、インジケーターを構築する元となるデータ型を指定し、[インジケーター](../../../api/indicators/list_of_indicators.md) とそのパラメーターを設定してから、![hydra find](../../../../images/hydra_find.png) ボタンをクリックします: :

![hydra export indicator](../../../../images/hydra_export_indicator.png)

値のチャートを表示するには、![hydra candles](../../../../images/hydra_candles.png) ボタンをクリックするだけです。

![hydra export indicator view](../../../../images/hydra_export_indicator_view.png)

受信した値は [必要な形式へエクスポート](../export_data.md) できます。
