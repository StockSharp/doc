# データ ソース

[Hydra](../hydra.md) は、さまざまなデータ ソースへの接続を備えています。履歴データの受信に加えて、プログラムはブローカーからマーケット データを受信でき、そのマーケット データはリアルタイムで受信されます。ソースへの接続は、ユーザーに提供されるコネクタを使用して行われます。

ユーザーには無料コネクタが提供されます。また、有料ソースからマーケット データを受信できる有料コネクタを購入することもできます。

現時点で、[Hydra](../hydra.md) は次のソースをサポートしています。
