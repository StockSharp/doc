# 学習用リソース

このドキュメントは、「Designer」プログラムの学習と利用のために StockSharp が提供する主要なリソースを紹介することを目的としています。これらの資料は、ユーザーがすばやく作業を開始し、プログラムを効果的に利用するのに役立ちます。

## 教育用動画

StockSharp の YouTube チャンネルでは、「Designer」の操作方法を示すチュートリアル動画を見つけることができます。これには、パラメーターの設定、ストラテジーの作成、およびそれらのテストが含まれます。

- **YouTube の「Designer」プレイリスト**: [プレイリストを表示](https://www.youtube.com/playlist?list=PLpwmSw294KYrfM1ALrONIz9MLpRQ1Uwfe)

## ストラテジー例

StockSharp 公式 Web サイトの Strategy Gallery には、「Designer」を使用して開発されたさまざまな取引ストラテジーが掲載されています。これらの例は、独自のストラテジーを作成するための優れた出発点になります。

- **「Designer」Strategy Gallery**: [ストラテジーギャラリーにアクセス](strategy_gallery.md)

## GitHub リポジトリ

「Designer」で使用されるストラテジーやその他のコンポーネントのソースコードは GitHub で利用できます。このリソースは、コード例を学習し、自分のニーズに合わせて適用するのに適しています。

- **GitHub 上の StockSharp リポジトリ**: [リポジトリにアクセス](https://github.com/StockSharp/algotrading)

## サポートチャット

他のユーザーと交流し、「Designer」の使用方法について迅速なサポートを受けるには、Telegram のチャットに参加してください。

- **Telegram の「Designer」チャット**: [チャットに参加](https://t.me/stocksharpchat/361)

これらのリソースは、「Designer」プログラムを効果的に学習し利用するために必要なものをすべて提供します。取引で最良の結果を得るために、提供されているすべての資料を活用することをお勧めします。
