# プログラミング言語

[Designer](../../designer.md) は、取引ストラテジーを作成するために 3 つのプログラミング言語をサポートしています。

- [C#](using_code/csharp.md)
- [F#](using_code/fsharp.md) 
- [Python](using_code/python.md)

C# と Python の豊富なストラテジーサンプルは、[AlgoTrading API folder](https://github.com/StockSharp/AlgoTrading/tree/main/API) で入手できます。これらはすべて [Designer](../../designer.md) で動作します。

## C#

C# は、取引ストラテジーを開発するための主要な言語です。すべてのコンポーネント、例、およびコアコードは C# で記述されています。C# では、[S#](../../api.md) プラットフォームアーキテクチャ全体に完全にアクセスできます。

## F#

F# は Microsoft の関数型プログラミング言語です。F# の取引ストラテジーは、すべての API 機能に完全にアクセスでき、テストとライブ取引の両方に使用できます。

## Python 

Python 統合により、Python プログラミング言語を使用して取引ストラテジーを記述できるため、Python 開発者がプラットフォームで作業しやすくなります。
