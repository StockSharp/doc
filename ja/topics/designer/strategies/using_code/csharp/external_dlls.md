# 外部 DLL

**ソースコード** からコンテンツを作成する場合、[API](../../../../api.md) ライブラリに加えて、独自のものを含む他の C# ライブラリを使用できます。これらのライブラリは .NET 10 と互換性がある必要があります。ライブラリへの参照を追加するには、コードパネルの **参照** ボタンをクリックする必要があります。その後、**追加ライブラリ** ウィンドウが開き、必要なライブラリを追加または削除できます。

- **アセンブリ** \- ライブラリファイルへの参照を追加します。
- **プロジェクト** \- Designer で作成した独自のコードまたはインジケーターへの参照を追加します。
- **削除** \- 選択した参照を削除します。

参照テーブルには、各参照の名前、パス、状態が表示されます。テーブル上部の **検索** 行を使うと、長いリストの中から参照を見つけられます。参照を追加できない場合は、その理由がテーブルの下に赤字で表示されます。
