# 外部 DLL

**Source Code** からコンテンツを作成する場合、[API](../../../../api.md) ライブラリに加えて、独自のものを含む他の C# ライブラリを使用できます。これらのライブラリは .NET 6.0 と互換性がある必要があります。ライブラリへの参照を追加するには、**Backtest** タブの **References** ボタンをクリックする必要があります。その後、**Extra references** ウィンドウが開き、必要なライブラリを追加または削除できます。
