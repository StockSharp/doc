# 外部 DLL

**ソースコード** からコンテンツを作成する場合、[API](../../../../api.md) ライブラリに加えて、独自のものを含む他の C# ライブラリを使用できます。これらのライブラリは .NET 6.0 と互換性がある必要があります。ライブラリへの参照を追加するには、**バックテスト** タブの **参照** ボタンをクリックする必要があります。その後、**追加参照** ウィンドウが開き、必要なライブラリを追加または削除できます。
