# Visual Studio または Rider の使用

**Visual Studio** と **JetBrains Rider** を使用して **Designer** で実行するコードを作成する場合、唯一の選択肢は継続的な[ファイルインポート](../../../export_import/import.md)です。これは **Designer** が作成するファイルの特殊なファイル構造によるもので、C# で作成されたストラテジーの場合であっても、ファイルを直接変更することはできません。したがって、コードの記述に外部プログラムが必要な場合は、[dll ファイル](../../using_dll.md)を使用する方法を推奨します。
