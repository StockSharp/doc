# 権利行使価格

![Designer Derivatives 00](../../../../../../images/designer_derivatives_00.png)

このキューブは、指定されたフィルターに基づいてオプションの一覧を取得するために使用します。

### 入力ソケット

入力ソケット

- **銘柄** - 原資産となる銘柄。

### 出力ソケット

出力ソケット

- **オプション** - 原資産に基づくオプションの一覧。

### パラメーター

パラメーター

- **オプションタイプ** - オプションタイプ。Call option または Put option を指定できます。
- **満期日** - オプションの満期日。
- **権利行使価格（小）** - 中央ストライクから左側（小さい方向）へのシフト。価格が設定されていない場合、中央値より低いすべてのストライクが使用されます。シフトはストライク刻みで計算されます。たとえば、ストライク刻みが 500 c.u. の場合、3 のシフトは 1,500 c.u. になります。
- **権利行使価格（大）** - 中央ストライクから右側（大きい方向）へのシフト。価格が設定されていない場合、中央値より高いすべてのストライクが使用されます。シフトはストライク刻みで計算されます。たとえば、ストライク刻みが 500 c.u. の場合、3 のシフトは 1,500 c.u. になります。
