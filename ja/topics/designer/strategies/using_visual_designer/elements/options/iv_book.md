# IV 板情報

![Designer 板情報のインプライドボラティリティ 00](../../../../../../images/designer_orderbook_implied_volatility_00.png)

このキューブは、インプライド・ボラティリティの板情報を計算するために使用します。

### 入力ソケット

入力ソケット

- **モデル** - 計算モデル（例: Black-Scholes）。
- **板情報** - 板情報。

### 出力ソケット

出力ソケット

- **板情報** - インプライド・ボラティリティの板情報の値。
