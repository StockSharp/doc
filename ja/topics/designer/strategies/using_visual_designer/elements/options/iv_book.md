# IV book

![Designer Glass implied volatility 00](../../../../../../images/designer_orderbook_implied_volatility_00.png)

このキューブは、インプライド・ボラティリティの板情報を計算するために使用します。

### 入力ソケット

入力ソケット

- **Model** - 計算モデル（例: Black-Scholes）。
- **Order book** - 板情報。

### 出力ソケット

出力ソケット

- **Order book** - インプライド・ボラティリティの板情報の値。
