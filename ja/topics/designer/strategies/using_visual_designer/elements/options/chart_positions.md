# ポジションチャート

![Designer ポジショングラフオプション 00](../../../../../../images/designer_graph_options_positions_00.png)

このキューブは、**オプションポジションチャート** を表示するために使用します。

**オプションポジションチャート** を表示するには、**オプションポジションチャート** グラフィックコンポーネントを追加する必要があります。

### 入力ソケット

入力ソケット

- **モデル** - 計算モデル（例: Black-Scholes）。
- **原資産価格** - 原資産の価格。
