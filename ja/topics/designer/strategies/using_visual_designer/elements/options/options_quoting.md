# Options quoting

![Designer Quoting 00](../../../../../../images/designer_quoting_00.png)

このキューブは、指定されたパラメーターに従ってオプションをクォートするために使用します。

### 入力ソケット

入力ソケット

- **Model** - 計算モデル（例: Black-Scholes）。
- **Volume** - クォートの数量。

### 出力ソケット

出力ソケット

- **Order** - 登録された注文。この注文は、注文別に **Trades** 要素を使用して約定を取得したり、**Chart panel** キューブを使用してチャートに表示したりするために使用できます。

### パラメーター

パラメーター

- **Quoting** - クォートの基準となるパラメーター。**Volatility**（クォート数量が指定されたボラティリティ制限に従う）または **Theoretical price**（クォート数量が指定された理論価格の制限に従う）の値を取ることができます。
- **Direction** - クォート方向。Purchase と Sell の値を取ることができます。
- **Minimum** - ボラティリティまたは理論価格の最小値。
- **Maximum** - ボラティリティまたは理論価格の最大値。
