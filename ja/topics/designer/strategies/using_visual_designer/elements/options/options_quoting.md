# オプションのクォーティング

![Designer Quoting 00](../../../../../../images/designer_quoting_00.png)

このキューブは、指定されたパラメーターに従ってオプションをクォートするために使用します。

### 入力ソケット

入力ソケット

- **モデル** - 計算モデル（例: Black-Scholes）。
- **数量** - クォートの数量。

### 出力ソケット

出力ソケット

- **注文** - 登録された注文。この注文は、注文別に **約定** 要素を使用して約定を取得したり、**チャートパネル** キューブを使用してチャートに表示したりするために使用できます。

### パラメーター

パラメーター

- **クォーティング** - クォートの基準となるパラメーター。**ボラティリティ**（クォート数量が指定されたボラティリティ制限に従う）または **理論価格**（クォート数量が指定された理論価格の制限に従う）の値を取ることができます。
- **方向** - クォート方向。買いと売りの値を取ることができます。
- **最小** - ボラティリティまたは理論価格の最小値。
- **最大** - ボラティリティまたは理論価格の最大値。
