# グリークス

![Designer Greek 00](../../../../../../images/designer_greek_00.png)

このブロックは、現在時点の主要な「グリークス」である Delta、Gamma、Vega、Theta、Rho を計算するために使用します。

### 入力ソケット

入力ソケット

- **モデル** - 計算モデル（例: Black-Scholes）。
- **原資産価格** - 原資産の価格。
- **最大偏差** - 最大偏差。

### 出力ソケット

出力ソケット

- **結果** - 現在時点の主要な「グリークス」である Delta、Gamma、Vega、Theta、Rho の計算結果。

### パラメーター

パラメーター

- **値** - 「グリーク」の種類である Delta、Gamma、Vega、Theta、Rho を取ることができ、このブロックからどの値を出力するかを決定します。
