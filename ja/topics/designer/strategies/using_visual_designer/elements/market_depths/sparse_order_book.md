# 間引き板情報

![Designer 疎な板情報 01](../../../../../../images/designer_sparse_orderbook_01.png)

![Designer 疎な板情報 00](../../../../../../images/designer_sparse_orderbook_00.png)

このキューブは、指定された銘柄の間引きされた板情報を取得するために使用します。

### 入力ソケット

- 板情報 - 間引く必要がある板情報。

### 出力ソケット

- 板情報 - 間引きされた板情報。

### パラメーター

- **価格範囲** - 板情報を間引くステップを含む価格範囲。
