# 注文キャンセル

![Designer Cancellations 00](../../../../../../images/designer_cancellations_00.png)

このブロックは、銘柄の注文をキャンセルするために使用します。

### 入力ソケット

入力ソケット

- **Trigger** - 注文キャンセルを起動するイベント。
- **Order** - 注文をキャンセルする必要があるタイミングを判定するために使用されるシグナル。

### 出力ソケット

出力ソケット

- **Order** - キャンセルされた注文。この注文は、**Transactions** 要素を使用してその取引を取得したり、**Chart Panel** ブロックを使用してチャートに表示したりするために使用できます。
- **Error** - 注文キャンセル時のエラー（たとえば、注文がすでに約定済み、または以前にキャンセル済みの場合）。
