# 注文キャンセル

![注文キャンセル のスクリーンショット](../../../../../../images/designer_cancellations_00.png)

このブロックは、銘柄の注文をキャンセルするために使用します。

### 入力ソケット

入力ソケット

- **トリガー** - 注文キャンセルを起動するイベント。
- **注文** - 注文をキャンセルする必要があるタイミングを判定するために使用されるシグナル。

### 出力ソケット

出力ソケット

- **注文** - キャンセルされた注文。この注文は、**トランザクション** 要素を使用してその取引を取得したり、**チャートパネル** ブロックを使用してチャートに表示したりするために使用できます。
- **エラー** - 注文キャンセル時のエラー（たとえば、注文がすでに約定済み、または以前にキャンセル済みの場合）。
