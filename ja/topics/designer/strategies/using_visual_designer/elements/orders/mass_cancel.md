# 注文一括キャンセル

![Designer Mass Cancellations 00](../../../../../../images/designer_mass_cancellations_00.png)

このブロックは、銘柄のすべての注文をキャンセルするために使用します。

### 入力ソケット

入力ソケット

- **トリガー** - 注文をキャンセルする必要があるタイミングを判定するシグナル。
- **ポートフォリオ** - すべての注文をキャンセルする対象のポートフォリオ。
- **銘柄** - すべての注文をキャンセルする対象の銘柄。

### 出力ソケット

出力ソケット

- **結果** - 操作の成功を通知するフラグ。

### パラメーター

パラメーター

- **方向** - キャンセル対象の注文方向（買いまたは売り）。注文のキャンセルシグナルとして機能します。
