# 注文変更

![Designer Moving applications 00](../../../../../../images/designer_moving_applications_00.png)

このブロックは、銘柄の注文を変更するために使用します。

### 入力ソケット

入力ソケット

- **トリガー** - 注文を移動するタイミングを判定するシグナル。
- **注文** - 変更される注文。
- **価格** - 新しい価格の数値。
- **数量** - 新しい数量の数値。

### 出力ソケット

出力ソケット

- **注文** - 変更された注文。この注文は、**注文別トランザクション** 要素を使用してその取引を取得したり、**チャートパネル** ブロックを使用してチャートに表示したりするために使用できます。
- **エラー** - 注文移動時のエラー。
- **約定** - 発注された注文の約定。

パラメーター

- **ゼロ価格** - ゼロ価格は成行注文を登録します。
