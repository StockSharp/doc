# ポジション変更

![Designer position modify 00](../../../../../../images/designer_position_modify_00.png)

"Modify Position" コンポーネントは、指定された条件に基づいて取引ポジションを変更するために使用します。

## 入力ソケット

- **Security**: ポジションを変更する対象の銘柄。
- **Trigger**: ポジション変更をアクティブ化するシグナル。
- **Portfolio**: 操作が行われるポートフォリオ。
- **Volume** (任意): "Increase" および "Decrease" 操作の数量。"Reverse" および "Close Position" では使用されません。
- **Last Price** および **Last Volume**: "VWAP" および "Iceberg" アルゴリズムでは、取引の直近価格と数量に関するデータが必要です。
- **Cancel**: ポジション設定をキャンセルするシグナル。たとえば、タイムアウトによるキャンセルです。

## 出力ソケット

- **Order**: 発注された注文に関する情報。
- **Transaction**: 注文で実行された取引に関する情報。
- **Balance**: このソケットは、ポジション変更操作の終了時に実現されなかったポジション部分に関する情報を送信します。ソケットから返される値は、操作の結果を示します。
  - `0` は、コンポーネントがポジション変更操作を正常に完了し、予定されたすべてのアクションが実行されたことを意味します。
  - `-1` は、現在のポジションと指定された条件が一致しないため、コンポーネントがポジション変更を開始しなかったことを示します（たとえば、現在のポジションがゼロではなく、条件が "OpenPosition" だった場合）。
  - `0` より大きい任意の値は、ポジション変更プロセスが完了前に中断されたことを示します。これは、スキームロジックによるキャンセル、または注文登録中のエラーによって発生する可能性があります。

## パラメーター

- **Condition**: ポジション変更条件:
  - `None`: 何も実行しません。
  - `OpenPosition`: 指定された方向にポジションを開きます。
  - `ClosePosition`: 現在のポジションを閉じます。
  - `Decrease`: 現在のポジションのサイズを減らします。
  - `Increase`: 現在のポジションのサイズを増やします。
  - `Reverse`: 現在のポジションを閉じ、反対方向に新しいポジションを開きます。
- **Direction**: "OpenPosition" および "None" の方向を指定し、他の条件では任意のフィルターとして機能します。
- **Algorithm**: オプションには "Market Order"、"VWAP"、"Iceberg" が含まれます。
- **Part**: "VWAP" や "Iceberg" のようなアルゴリズムを使用する場合に、合計数量をより小さい部分に分割する割合。

コンポーネントがすでに数量変更を開始している間にトリガーを受け取った場合、新しいトリガーは無視されます。変更条件がポジションの現在状態と互換性がない場合（たとえば、ポジションがすでに開いているときに "OpenPosition" を試みる場合）、コンポーネントは出力ソケット **Balance** を通じてただちに `-1` を返し、操作が不要で開始されなかったことを示します。

## 注記

低レベルの注文管理には、[注文登録](../orders/register.md) コンポーネントを使用できます。より高レベルのポジション管理には、この "Modify Position" コンポーネントを推奨します。
