# ポジション変更

![Designer ポジション変更 00](../../../../../../images/designer_position_modify_00.png)

「ポジション変更」コンポーネントは、指定された条件に基づいて取引ポジションを変更するために使用します。

## 入力ソケット

- **銘柄**: ポジションを変更する対象の銘柄。
- **トリガー**: ポジション変更をアクティブ化するシグナル。
- **ポートフォリオ**: 操作が行われるポートフォリオ。
- **数量** (任意): 「増やす」および「減らす」操作の数量。「反転」および「ポジションを閉じる」では使用されません。
- **最終価格** および **最終数量**: "VWAP" および "Iceberg" アルゴリズムでは、取引の直近価格と数量に関するデータが必要です。
- **キャンセル**: ポジション設定をキャンセルするシグナル。たとえば、タイムアウトによるキャンセルです。

## 出力ソケット

- **注文**: 発注された注文に関する情報。
- **トランザクション**: 注文で実行された取引に関する情報。
- **残高**: このソケットは、ポジション変更操作の終了時に実現されなかったポジション部分に関する情報を送信します。ソケットから返される値は、操作の結果を示します。
  - `0` は、コンポーネントがポジション変更操作を正常に完了し、予定されたすべてのアクションが実行されたことを意味します。
  - `-1` は、現在のポジションと指定された条件が一致しないため、コンポーネントがポジション変更を開始しなかったことを示します（たとえば、現在のポジションがゼロではなく、条件が「ポジションを開く」だった場合）。
  - `0` より大きい任意の値は、ポジション変更プロセスが完了前に中断されたことを示します。これは、スキームロジックによるキャンセル、または注文登録中のエラーによって発生する可能性があります。

## パラメーター

- **条件**: ポジション変更条件:
  - `なし`: 何も実行しません。
  - `ポジションを開く`: 指定された方向にポジションを開きます。
  - `ポジションを閉じる`: 現在のポジションを閉じます。
  - `減らす`: 現在のポジションのサイズを減らします。
  - `増やす`: 現在のポジションのサイズを増やします。
  - `反転`: 現在のポジションを閉じ、反対方向に新しいポジションを開きます。
- **方向**: 「ポジションを開く」および「なし」の方向を指定し、他の条件では任意のフィルターとして機能します。
- **アルゴリズム**: オプションには「成行注文」、「VWAP」、「Iceberg」が含まれます。
- **部分**: "VWAP" や "Iceberg" のようなアルゴリズムを使用する場合に、合計数量をより小さい部分に分割する割合。

コンポーネントがすでに数量変更を開始している間にトリガーを受け取った場合、新しいトリガーは無視されます。変更条件がポジションの現在状態と互換性がない場合（たとえば、ポジションがすでに開いているときに「ポジションを開く」を試みる場合）、コンポーネントは出力ソケット **残高** を通じてただちに `-1` を返し、操作が不要で開始されなかったことを示します。

## 注記

低レベルの注文管理には、[注文登録](../orders/register.md) コンポーネントを使用できます。より高レベルのポジション管理には、この「ポジション変更」コンポーネントを推奨します。
