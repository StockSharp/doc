# 文字列連結

![Designer String Concat 00](../../../../../../images/designer_string_concat_00.png)

このキューブは、波括弧内のプレースホルダーを含むテンプレートに従って、複数の入力値を 1 つのテキスト文字列に連結します。各プレースホルダー名によって、同じ名前の入力ソケットが追加されます。ドットを使用してネストされたプロパティを参照し、コロンの後に書式を指定できます。

### 入力ソケット

入力ソケット

- プレースホルダー名から動的に作成されます。各ソケットは任意の型のデータを受け入れます。

### 出力ソケット

出力ソケット

- **Text** - 連結および書式設定された文字列。

### パラメーター

パラメーター

- **Template** - 文字列の連結および書式設定のテンプレート。テンプレートを編集すると、
  入力ソケットの一覧が更新されます。

### 例

- テンプレート `Price: {price:0.00}, Qty: {qty}` は、`price = 10.5` および `qty = 2` の場合、
  `Price: 10.50, Qty: 2` を生成します。
- テンプレート `{time:HH:mm:ss} - {trade.Price}` は、ソケット `time` および `trade`
  （`trade.Price = 100`）の場合、`09:15:00 - 100` を生成します。
- テンプレート `{side} {volume} @ {trade.Price}` は、ソケット `side = Buy`、
  `volume = 1`、`trade.Price = 100` の場合、`Buy 1 @ 100` を生成します。
