# String format

![Designer String Format 00](../../../../../../images/designer_string_format_00.png)

このキューブは、任意の型の入力値をテキスト文字列に変換します。変換は、波括弧内のプレースホルダーを含むテンプレートに従って実行されます。各プレースホルダーは、値全体（`{0}`）またはそのプロパティの 1 つ（`{Price}`、`{Trade.Price}` など）を参照します。数値、日付、またはその他のオブジェクトをテキストでどのように表示するかを制御するために、コロンの後に書式を指定できます。

### 入力ソケット

入力ソケット

- **Input** - 書式設定する値。ソケットは任意の型のデータを受け入れます。

### 出力ソケット

出力ソケット

- **Text** - 入力値にテンプレートを適用した結果。

### パラメーター

パラメーター

- **Template** - 入力値に適用される文字列書式設定テンプレート。既定のテンプレートは `{0}` で、追加の書式設定なしで値が挿入されることを意味します。プレースホルダーには、プロパティ名と書式文字列を含めることができます。たとえば、`Price: {0:0.00}` や `{Price:0.00}` です。

### 例

- テンプレート `Price: {0:0.00}` は、入力 `10.5` の場合、`Price: 10.50` を生成します。
- テンプレート `{Price} - {Volume}` は、入力の取引オブジェクト `{ Price = 100,
  Volume = 2 }` の場合、`100 - 2` を生成します。
- テンプレート `{Trade.Price} - {Trade.Volume}` は、入力オブジェクト
  `{ Trade = { Price = 100, Volume = 2 } }` の場合、`100 - 2` を生成します。
- テンプレート `Time: {Time:HH:mm:ss}` は、`Time =
  2024-05-01T09:15:00` を持つ入力オブジェクトの場合、`Time: 09:15:00` を生成します。
