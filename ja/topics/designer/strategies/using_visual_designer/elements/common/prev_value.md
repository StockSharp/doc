# 前回値

![Designer The previous value 00](../../../../../../images/designer_previous_value_00.png)

このキューブは、入力に渡された前の値を、指定されたオフセットで取得するために使用されます。

## 入力ソケット

- **任意のデータ** - 受信され、渡される特定のデータ型。

## 出力ソケット

- **任意のデータ** - 受信され、渡される特定のデータ型で、パラメーターで指定されたオフセットの入力値。

## パラメーター

- **データ型** - 入力ソケットから入力できるデータ型。このパラメーターを変更すると、パラメーター用のデータ型も自動的に変更されます。
- **オフセット** - オフセットのサイズ。出力値が入力値から何回分の変更だけ遅れるかを示します。
