# フラグ

![Designer フラグ](../../../../../../images/designer_flag_00.png)

"Flag" コンポーネントは、入力シグナルに基づいて設定またはリセットできるバイナリフラグを管理するために使用します。

## 入力ソケット

- **トリガー**: `False` 以外の任意の値を受け取ります。最初の適切な値を受信するとフラグを設定します。フラグがすでに設定されている場合、リセットされるまで後続のシグナルは無視されます。
- **リセット**: `False` 以外の任意の値を受け取ります。フラグをリセットし、後続のトリガーに応答できるようにします。

## 出力ソケット

- **シグナル**: フラグが設定されたときにシグナルを出力します。
