# フラグ

![Designer Flag](../../../../../../images/designer_flag_00.png)

"Flag" コンポーネントは、入力シグナルに基づいて設定またはリセットできるバイナリフラグを管理するために使用します。

## 入力ソケット

- **Trigger**: `False` 以外の任意の値を受け取ります。最初の適切な値を受信するとフラグを設定します。フラグがすでに設定されている場合、リセットされるまで後続のシグナルは無視されます。
- **Reset**: `False` 以外の任意の値を受け取ります。フラグをリセットし、後続のトリガーに応答できるようにします。

## 出力ソケット

- **Signal**: フラグが設定されたときにシグナルを出力します。
