# 値の遅延

![Designer Delay 00](../../../../../../images/designer_delay_00.png)

このコンポーネントは、指定した反復回数だけ値の送信を遅延させるために使用します。

## 入力ソケット

- **トリガー** - 内部カウンターを初期化し、遅延のカウントダウンを開始するシグナル（`False` 以外の任意の値）。
- **入力** - 内部カウンターを減少させる任意の入力値（[未完成のローソク足](../data_sources/candles.md)または[非最終のインジケーター値](indicator.md)を除く）。カウンターがゼロに達すると、カウンターは非アクティブ化され、出力ソケットがアクティブ化されます。カウンターが **トリガー** によってアクティブ化されていなかった場合、入力値は無視されます。

## 出力ソケット

- **シグナル** - カウンターがゼロに達したときにシグナルを出力し、遅延の終了を示します。

## パラメーター

- **期間** - 反復回数で遅延期間を指定します。
