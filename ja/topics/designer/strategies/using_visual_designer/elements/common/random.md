# ランダム値

![Designer Random 00](../../../../../../images/designer_random_00.png)

このブロックは、ランダム値を生成するために使用されます。

## 入力ソケット

- **Trigger** - 生成されたランダム値を出力ソケット経由で渡すタイミングを決定するシグナル（`False` 以外の任意の値）。

## 出力ソケット

- **Value** - ランダム値。

## パラメーター

- **Min** - 許容される最小値の境界。
- **Max** - 許容される最大値の境界。
