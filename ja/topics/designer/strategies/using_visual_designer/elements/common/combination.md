# 組み合わせ

![Designer Association 00](../../../../../../images/designer_association_00.png)

このキューブは、異なるキューブから来る同じ型のデータを 1 つの出力パラメーターに結合して別の要素へ渡すため、または受け取ったデータを複数の要素に分割するために使用します。

## 入力ソケット

- **Any data** - 受信および渡されるデータの型を指定します。

## 出力ソケット

- **Any data** - 受信および渡されるデータの型を指定します。

## パラメーター

- **Type** - 受信および渡されるデータの型を指定します。
