# ティック

![Designer Ticks](../../../../../../images/designer_ticks_00.png)

このブロックは、銘柄の **ティック** データを受信するために使用されます。

### 入力ソケット

入力ソケット

- **銘柄** - **レベル1** データを受信する必要がある銘柄。

### 出力ソケット

出力ソケット

- **ティック** - ティック取引。

### パラメーター

パラメーター

- **シグナルで購読** - トリガーが到着した後にのみデータを購読します。
