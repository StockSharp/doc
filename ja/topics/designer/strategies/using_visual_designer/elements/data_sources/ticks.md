# Ticks

![Designer Ticks](../../../../../../images/designer_ticks_00.png)

このブロックは、銘柄の **Tick** データを受信するために使用されます。

### 入力ソケット

入力ソケット

- **Instrument** - **Level1** データを受信する必要がある銘柄。

### 出力ソケット

出力ソケット

- **Tick** - ティック取引。

### パラメーター

パラメーター

- **Subscribe on Signal** - トリガーが到着した後にのみデータを購読します。
