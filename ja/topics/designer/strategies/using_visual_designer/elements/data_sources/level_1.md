# Level 1

![Designer Level 1 00](../../../../../../images/designer_level_1_00.png)

このブロックは、銘柄の **Level1** データを受信するために使用されます。

### 入力ソケット

入力ソケット

- **Instrument** - **Level1** データを受信する必要がある銘柄。

### 出力ソケット

出力ソケット

- **Change** - 追跡対象パラメーターの **Level1** 値。

### パラメーター

パラメーター

- **Value** - 追跡する必要がある **Level1** パラメーター。
- **Subscribe on Signal** - トリガーが到着した後にのみデータを購読します。
