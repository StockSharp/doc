# 変数

![Designer Variable 00](../../../../../../images/designer_variable_00.png)

このキューブは、値を保存し、以前に保存された値を要素のチェーンに沿ってさらに渡すために使用されます。

### 入力ソケット

入力ソケット

- **Any data** – 選択された型の値で、既定値の代わりに保存されます。
- **Trigger** – 保存された値を出力ソケット経由で渡す時点を決定するシグナル（`False` 以外の任意の値）。

### 出力ソケット

出力ソケット

- **Any data** – 渡されるデータの選択された型の値。

### パラメーター

パラメーター

- **Data type** - 変数内に保存されるデータの型。入力および出力パラメーターの型は、選択されたデータ型に依存します。
- **Value** - 変数に保存される既定値。この値は、要素の入力で他の値を受信しなかった場合に使用されます。
- **Raise on start** - チェックボックスが選択されている場合、ストラテジーの開始時に値が渡されます。

**Instrument** または **Portfolio** データ型が選択されている場合、既定値が存在しないことがあります。この場合、プロパティで **Parameters** フラグが設定されていると、ストラテジーの実行時に、これらのデータはストラテジーの対応するプロパティから取得されます。
