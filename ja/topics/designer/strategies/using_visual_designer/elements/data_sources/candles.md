# ローソク足

![Designer Candles 00](../../../../../../images/designer_candles_00.png)

このブロックは、指定された銘柄のローソク足を構築するために使用されます。

### 入力ソケット

入力ソケット

- **Security** - 指定されたパラメーターでローソク足を構築する対象の銘柄。

### 出力ソケット

出力ソケット

- **Candles** - 構築されたローソク足。

### パラメーター

パラメーター

- **Series** - ローソク足シリーズの種類と、指定された種類のパラメーター。
- **Only Formed** - 完全に形成されたローソク足のみを出力に渡すか、任意の変更を渡すか。
- **Smaller Timeframe** - より小さい時間枠からローソク足を構築します。
- **Subscribe on Signal** - トリガーを受信した後にのみデータを購読します。
