# 設定のリセット

> [!CAUTION]
> **設定をリセットする前に、このセクションを注意深く読んでください。**

**クイックアクセスパネル** は既定でプログラムウィンドウの上部にあり、設定ボタン ![Designer The quick access toolbar 02](../../../images/designer_quick_access_toolbar_02.png) を含んでいます。![Designer The quick access toolbar 02](../../../images/designer_quick_access_toolbar_02.png) をクリックすると、起動モードの変更、インターフェイス言語の変更、またはすべての設定のリセットを行えます。

![Designer Reset language settings 00](../../../images/designer_reset_language_settings_00.png)

**設定のリセット** を選択すると、確認ウィンドウが開きます。

![Designer Reset language settings 01](../../../images/designer_reset_language_settings_01.png)

**OK** をクリックすると、すべての設定が既定値にリセットされます。プログラム設定ディレクトリは完全にクリアされます。**作成済みのすべてのストラテジー、ダウンロード済みの銘柄、および設定ディレクトリに保存されているその他の情報は削除されます。**
