# ポートフォリオ

ポートフォリオを操作するために **Portfolios** パネルがあります。**Common** タブの Portfolios ボタンをクリックすると開くことができます。

![Designer Panel A Portfolios 00](../../../images/designer_panel_portfolios_00.png)

**Portfolios** パネルは、ポートフォリオの基本データと、それらのポートフォリオの現在ポジションを表示するテーブルです。ポートフォリオまたはポジションをダブルクリックすると、**Creating portfolio** ウィンドウまたは **Creating position** ウィンドウが表示され、選択したポートフォリオまたはポジションを編集できます。新しいポートフォリオまたは新しいポジションを作成するには、![Designer Panel Circuits 01](../../../images/designer_panel_circuits_01.png) ボタンをクリックし、ドロップダウン メニューで該当する項目を選択する必要があります。

![Designer Panel A Portfolios 01](../../../images/designer_panel_portfolios_01.png)

![Designer Alert Bell](../../../images/designer_alert_bell.png) ボタンをクリックすると、[通知設定](../../terminal/notifications.md) ウィンドウが開きます。
