# ライブ設定

ライブ取引でストラテジーが扱う対象は、リボンの **ライブ** タブの **ストラテジー** グループで指定します。

- **ポートフォリオ** \- ストラテジーが注文を出すポートフォリオ。
- **銘柄** \- ストラテジーが取引する銘柄。

同じ場所に **更新**、**スタート**、**停止** ボタンがあり、**コンポーネント** グループには、ストラテジータブに追加できるコンポーネントがあります。

スキーム自体のパラメーター（たとえば移動平均の期間や注文数量）は、**ストラテジーパラメーター** パネルで設定します。既定では、このパネルは折りたたまれ、ストラテジータブの右側に固定されています。

ストラテジーのリモート管理の設定は、[ライブパネル](../../live_execution/strategies_dashboard.md) のストラテジーの行にある **設定** ボタンで開きます。
