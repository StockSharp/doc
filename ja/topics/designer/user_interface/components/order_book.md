# 板情報

**Order book** コンポーネントは、売買の指値注文のテーブルです。コンポーネントの上部で、データを受信するデータソースを選択する必要があります。データのソースは [Order book panel](../../strategies/using_visual_designer/elements/market_depths/order_book_panel.md) キューブです。

ストラテジーでは、複数の異なる種類の板情報（または異なる銘柄の板情報）を同時に使用し、それらを異なるパネルに表示できます。
