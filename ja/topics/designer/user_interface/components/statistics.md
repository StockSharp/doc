# 統計

**統計** コンポーネントは、P/L、約定、ポジション、注文のカテゴリでグループ化されたテーブルです。統計は、ストラテジーの正確性とパフォーマンスを評価するのに役立ちます。たとえば、サンプルストラテジー SMA は 1 つを超えるポジションを持つことはできません。統計は、最大ドローダウン、相対ドローダウン、リカバリーファクターなど、他の定性的なパラメーターによってストラテジーのパフォーマンスを評価するのにも役立ちます。
