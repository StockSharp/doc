# ボード

**ボードエディター** パネルでは、**ボード** と **取引所** を作成し、既存のものを表示またはカスタマイズできます。

![Designer Boards](../../../images/designer_boards.png)

[S#](../../api.md) では、異なるソースの銘柄は、銘柄コードとボードコードで構成される統一識別子を使用します。構文は [**銘柄コード**]@[ボードコード] です。たとえば、**NASDAQ** 取引所の **AAPL** 株式の場合、識別子は **AAPL@NASDAQ** です。各銘柄は、取引される特定のボードに関連付けられます。ただし、銘柄は異なるボードで取引されることがあります。この場合、ボードコードは異なります。各ボードには、営業日と休日を含む稼働スケジュールを設定できます。

取引所には、取引条件（セッション時間、手数料など）が異なる複数のボードが存在する場合があります。ただし、各ボードは特定の取引所に関連付けられます。そのため、**ボードエディター** でボードを選択すると、取引所に関する情報は、そのボードが属する取引所へ自動的に変更されます。各取引所には、取引所コード、国、ロシア語名、英語名を設定できます。
