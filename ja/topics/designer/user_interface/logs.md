# Logs パネル

プログラムの動作監視を簡単にするために、専用の **Logs** パネルがあります。このパネルには、すべてのソース、ストラテジー、および接続からのメッセージが表示されます。**Logs** パネルでは、ソースの入れ子構造がツリーとして表示されます。各親ノードには、最下位レベルに至るまで、すべての入れ子になったソースのメッセージが含まれます。ストラテジーでは、この階層により子ストラテジーを確認できます。**Logs** パネルを開くには、**Common** タブの **Logs** ボタンを押す必要があります。
