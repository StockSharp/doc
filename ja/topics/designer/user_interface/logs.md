# ログパネル

プログラムの動作監視を簡単にするために、専用の **ログ** パネルがあります。このパネルには、すべてのソース、ストラテジー、および接続からのメッセージが表示されます。**ログ** パネルでは、ソースの入れ子構造がツリーとして表示されます。各親ノードには、最下位レベルに至るまで、すべての入れ子になったソースのメッセージが含まれます。ストラテジーでは、この階層により子ストラテジーを確認できます。**ログ** パネルを開くには、**共通** タブの **ログ** ボタンを押す必要があります。
