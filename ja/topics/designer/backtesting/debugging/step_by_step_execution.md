# ステップごとの実行

ステップごとの実行を開始するには、最初に実行を停止したい要素にブレークポイントを設定します。[Designer](../../../designer.md) がその要素で停止したら、![Designer Debug 03](../../../../images/designer_debug_03.png)**Next element** ボタンをクリックします。Designer は要素から次の要素へ移動し、ストラテジーがステップごとにどのように実行されるかを表示します。

**Composite element** に入るには、ステップごとの実行がそこに到達するまで待ってから、![Designer Debug 04](../../../../images/designer_debug_04.png)**Step in** をクリックします。次のステップは **Composite element** の内部で実行されます。**Composite element** から出るには、![Designer Debug 05](../../../../images/designer_debug_05.png)**Step out** をクリックします。
