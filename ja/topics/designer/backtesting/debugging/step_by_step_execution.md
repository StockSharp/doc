# ステップごとの実行

ステップごとの実行を開始するには、最初に実行を停止したい要素にブレークポイントを設定します。[Designer](../../../designer.md) がその要素で停止したら、![Designer Debug 03](../../../../images/designer_debug_03.png)**次の要素** ボタンをクリックします。Designer は要素から次の要素へ移動し、ストラテジーがステップごとにどのように実行されるかを表示します。

**複合要素** に入るには、ステップごとの実行がそこに到達するまで待ってから、![Designer Debug 04](../../../../images/designer_debug_04.png)**ステップイン** をクリックします。次のステップは **複合要素** の内部で実行されます。**複合要素** から出るには、![Designer Debug 05](../../../../images/designer_debug_05.png)**ステップアウト** をクリックします。
