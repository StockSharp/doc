# Runner

**Runner** は、StockSharp プラットフォーム向けに作成されたストラテジーを起動するためのアプリケーションです。以下を提供します。

- クロスプラットフォーム - Windows と Linux の両方のシステムで実行できます。

- [Telegram](telegram_services.md) と統合されており、取引アクティビティをリモートで制御できます。

- 重いグラフィカルインターフェイスがないため、コンピューターリソースの消費を最小限に抑えます。

- C# コード、[Designer](designer.md) スキーマ、または既製の DLL アセンブリからストラテジーを起動できます。

- ライブ取引モード、または履歴データを使用したバックテストでストラテジーを実行できます。
