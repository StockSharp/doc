# Terminal

**Terminal** は無料の取引ターミナルです。主な利点は、独自のターミナルを提供していない取引場所を含め、複数の取引所、ブローカー、データソースに同時に接続できることです。

![Terminal メイン 00](../images/terminal_main_00.png)

## Terminal の利点と機能:

1. **多数のデータソースをサポート:** [コネクター](api/connectors.md)。
2. **チャートからの取引**。
3. **カスタム時間足**。
4. **Volume、Tick、Range、PnF、Renko ローソク足**。
5. **クラスターおよびボックスチャート**。
6. **複数の市場:** 株式、先物、Forex、暗号資産。
