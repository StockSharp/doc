# Designer

**Designer** は、取引ストラテジーの作成、履歴データでのバックテスト、ライブ取引でのストラテジー管理を行うためのアプリケーションです。Designer は、ストラテジーを作成する 2 つの方法をサポートしています。

1. [ビジュアルデザイナー](designer/strategies/using_visual_designer.md)はプログラミングスキルを必要としません。ストラテジーはブロックを組み合わせ、それらを線で接続して構築するため、ワークフロー全体が視覚的に表示されます。
2. [コードベースのストラテジー](designer/strategies/using_code.md) は、経験豊富なプログラマー向けです。**C#**、**F#**、または **Python** で書かれたストラテジーは通常、ビジュアルストラテジーより高速に実行され、利用可能なビジュアルブロックに制限されません。ストラテジーは **Designer** 内で直接記述することも、プロフェッショナルな取引アルゴリズム開発用の [API](api.md) ライブラリを使用して、**Microsoft Visual Studio** などの C# 開発環境で記述することもできます。
