# Servicios de Telegram

La integración con Telegram está disponible para la gestión remota de robots de trading, por ejemplo cuando se ejecutan en servidores virtuales.

Esta integración funciona tanto con programas preparados (como [Designer](designer.md)) como con su propio software desarrollado usando la [API](api.md).

Hay dos servicios disponibles:

- [Alertas](telegram_services/alerts.md) - recibir notificaciones desde un robot de trading.
- [Panel de control](telegram_services/control_panel.md) - iniciar, detener y controlar robots de trading mediante un bot de Telegram.
