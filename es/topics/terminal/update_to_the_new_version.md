# Actualización a la nueva versión

Actualice Terminal mediante StockSharp Installer. La guía explica cómo buscar versiones disponibles e instalar las actualizaciones de las aplicaciones.

[Actualizar aplicaciones](../installer/update_apps.md)

El nuevo Terminal multiplataforma, al iniciarse por primera vez en la carpeta de configuración del Terminal anterior, organiza los paneles tal como los dejó el anterior. Después guarda su propia disposición.
