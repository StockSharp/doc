# Panel de notificaciones

El panel **Notificaciones** es una tabla que muestra información sobre todas las notificaciones configuradas actualmente.

![Terminal Panel de notificaciones](../../../images/terminal_notifications_panel.png)

En el panel **Notificaciones**, puede editar ![Designer Creación de un repositorio de datos históricos 01](../../../images/designer_creating_repository_of_historical_data_01.png) una notificación existente, eliminarla ![Designer Creación de un repositorio de datos históricos 02](../../../images/designer_creating_repository_of_historical_data_02.png) o establecer una nueva notificación ![Designer Creación de un repositorio de datos históricos 00](../../../images/designer_creating_repository_of_historical_data_00.png).
