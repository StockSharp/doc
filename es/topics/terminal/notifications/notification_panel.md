# Panel de notificaciones

El panel **Notifications** es una tabla que muestra información sobre todas las notificaciones configuradas actualmente.

![Terminal Notifications Panel](../../../images/terminal_notifications_panel.png)

En el panel **Notifications**, puede editar ![Designer Creating a repository of historical data 01](../../../images/designer_creating_repository_of_historical_data_01.png) una notificación existente, eliminarla ![Designer Creating a repository of historical data 02](../../../images/designer_creating_repository_of_historical_data_02.png) o establecer una nueva notificación ![Designer Creating a repository of historical data 00](../../../images/designer_creating_repository_of_historical_data_00.png).
