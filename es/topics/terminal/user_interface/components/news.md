# Noticias

El componente **Noticias** muestra noticias recibidas desde conexiones.

Para empezar a recibir noticias, haga clic en el botón **Recibir noticias**.

El panel Noticias permite configurar notificaciones para eventos seleccionados; consulte [Configuración de notificaciones](../../notifications.md).
