# Noticias

El componente **News** muestra noticias recibidas desde conexiones.

Para empezar a recibir noticias, haga clic en el botón **Receive news**.

El panel News permite configurar notificaciones para eventos seleccionados; consulte [Configuración de notificaciones](../../notifications.md).
