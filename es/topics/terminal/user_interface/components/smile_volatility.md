# Smile volatility

El componente **Smile volatility** es una representación gráfica del nivel esperado de volatilidad para opciones con el mismo activo subyacente y distintos strikes.

Para mostrar la sonrisa de volatilidad, debe seleccionar el activo subyacente y las opciones con base en cuyos precios se construirá la sonrisa de volatilidad.

Además, puede especificar un filtro para la fecha exacta de vencimiento de las opciones y filtros para strikes mínimos\/máximos.
