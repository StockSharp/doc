# Tiempo real

La pestaña **Tiempo real** permite gestionar estrategias lanzadas en trading.

![Shell realtime 00](../../../images/shell_realtime_00.png)

Al hacer clic en el botón **Añadir** ![Designer Creation tool 00](../../../images/designer_creation_tool_00.png), puede añadir una estrategia para iniciar trading. Cada estrategia añadida se abre en una pestaña separada y se añade a la lista de estrategias en la pestaña **Estrategias**.

En la pestaña **Estrategias**, puede eliminar, iniciar, detener y configurar estrategias. Lo mismo puede hacerse en una pestaña individual de estrategia. La pestaña individual de estrategia tiene información más extensa sobre la estrategia, estadísticas, una lista de órdenes registradas y operaciones de la estrategia, etc.
