# Identificador \*@ALL

Si el instrumento se negocia en varias plazas, como código de plaza puede usar "ALL". Por ejemplo, el instrumento con el identificador AAPL@ALL significa que recopila datos de todas las plazas para el ticker AAPL (AAPL@BATS, AAPL@ICE, etc.) y estos datos también tienen un libro de órdenes común.

El código de plaza se usa para enviar la orden a un sistema de negociación concreto. Si especifica "ALL", el broker o la bolsa determinará la ruta de la orden. En este caso, el broker o la bolsa decide de forma independiente en qué plaza es mejor casar una orden. Por el contrario, si especifica una plaza concreta, como BATS, la orden se enviará solo a BATS.
