# Ejemplos de S#

Puede encontrar ejemplos de uso de la biblioteca StockSharp API en nuestro repositorio de GitHub en la siguiente ruta: [StockSharp Samples](https://github.com/StockSharp/StockSharp/tree/master/Samples/).

Estos ejemplos proporcionan soluciones listas para usar y demostraciones de distintas capacidades de la biblioteca StockSharp API. Encontrará ejemplos de código útiles que le ayudarán a familiarizarse rápidamente con el uso de nuestra plataforma.

## Documentación

El código proporcionado en la documentación se toma de estos ejemplos. Puede explorarlos con más detalle siguiendo el enlace anterior. Use estos ejemplos como base para crear sus propias soluciones y para comprender cómo trabajar con distintos aspectos de la biblioteca StockSharp API.

Recomendamos estudiar cuidadosamente los ejemplos y la documentación para aprovechar al máximo las capacidades de nuestra plataforma.

Si tiene alguna pregunta, siempre puede buscar ayuda en nuestro [chat de Telegram](https://t.me/stocksharpchat/361).
