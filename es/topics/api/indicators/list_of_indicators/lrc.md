# LRC

**Linear Regression Curve (LRC)** es un tipo de media móvil basada en la ecuación de regresión lineal. El resultado del cálculo es una línea recta con el mejor ajuste para los diferentes precios del período. El punto final de esta línea se utiliza para trazar el LRC. 

Para utilizar el indicador, debe utilizar la clase [LinearReg](xref:StockSharp.Algo.Indicators.LinearReg).
