# RSI

**Índice de fuerza relativa (RSI)** es un indicador de impulso que mide la cantidad de cambios de precios recientes para evaluar las condiciones de precios de sobrecompra o sobreventa de una acción u otro activo.

Para utilizar el indicador, debe utilizar la clase [RelativeStrengthIndex](xref:StockSharp.Algo.Indicators.RelativeStrengthIndex).
