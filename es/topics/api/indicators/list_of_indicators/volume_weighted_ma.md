# Media móvil ponderada por volumen

**Media móvil ponderada por volumen (VWMA)**: el indicador muestra el precio ponderado por volumen durante un período de tiempo determinado. Este indicador sigue el precio como una línea ondulada y tiene una cierta desviación con respecto al gráfico de precios.

Para utilizar el indicador, debe utilizar la clase [VolumeWeightedMovingAverage](xref:StockSharp.Algo.Indicators.VolumeWeightedMovingAverage).
