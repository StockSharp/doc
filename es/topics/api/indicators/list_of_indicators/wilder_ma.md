# media móvil de Wilder

**La media móvil más salvaje (WilderMA)** es un indicador de media móvil ponderada. Como todos los demás indicadores de media móvil, el indicador WMA suaviza los ruidos del mercado y muestra las tendencias del mercado con mayor claridad. Para lograr este objetivo, el indicador filtra las fluctuaciones (ruidos) del mercado, promediando los valores de los precios de los períodos en los que se calcula. Al mismo tiempo, se agrega algún valor adicional (peso) a los precios promedio, como se hace al calcular todos los indicadores ponderados como EMA, LWMA y SMMA.

Para utilizar el indicador, debe utilizar la clase [WilderMovingAverage](xref:StockSharp.Algo.Indicators.WilderMovingAverage).
