# Oscilador estocástico

**Oscilador estocástico** es un indicador de impulso que compara un precio de cierre específico de un valor con un rango de sus precios durante un período de tiempo determinado. La sensibilidad del oscilador a los movimientos del mercado se puede reducir ajustando este período de tiempo o tomando la media móvil del resultado.

Para utilizar el indicador, debe utilizar la clase [StochasticOscillator](xref:StockSharp.Algo.Indicators.StochasticOscillator).
