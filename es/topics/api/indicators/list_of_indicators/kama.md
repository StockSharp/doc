# KAMA

**La media móvil adaptativa de Kaufman (AMA, KAMA, AMkA)** fue desarrollada por Perry Kaufman para tener en cuenta el ruido y la volatilidad del mercado. El indicador KAMA se puede utilizar para identificar puntos de reversión en el tiempo, determinar la tendencia general y filtrar los movimientos de precios.

Para utilizar el indicador, se debe utilizar la clase [KaufmanAdaptiveMovingAverage](xref:StockSharp.Algo.Indicators.KaufmanAdaptiveMovingAverage).

##### Configuración del indicador.

- MA rápida: la constante de suavizado rápido;
- MA lenta: la constante de suavizado lento;
- Period: el período de la media móvil de Kaufman.
