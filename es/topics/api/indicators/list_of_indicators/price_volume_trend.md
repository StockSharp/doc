# PVT

**Tendencia precio-volumen (PVT)** es un indicador acumulativo que multiplica el cambio de precio por volumen para mostrar la presión de compra o venta.

Para utilizar el indicador, debe utilizar la clase [PriceVolumeTrend](xref:StockSharp.Algo.Indicators.PriceVolumeTrend).
