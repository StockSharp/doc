# Fractales

**Fractales** es una secuencia de varias velas; el máximo (mínimo) de la vela central está por encima de los máximos (mínimos) de las adyacentes.

Para utilizar el indicador, debe utilizar la clase [Fractals](xref:StockSharp.Algo.Indicators.Fractals).
