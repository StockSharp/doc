# ZigZag

**ZigZag** — el indicador muestra puntos en el gráfico cada vez que los precios cambian en un porcentaje que excede el valor preestablecido. Luego se dibujan líneas rectas que conectan estos puntos. El indicador se utiliza para determinar las tendencias de los precios. 

Para utilizar el indicador, debe utilizar la clase [ZigZag](xref:StockSharp.Algo.Indicators.ZigZag).
