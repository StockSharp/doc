# Linear Regression Slope

La interpretación del indicador **Linear Regression Slope** muestra el valor de la pendiente de las líneas de regresión, que incluyen la barra de precios actual y la barra de precios n-1 anterior (donde n \= períodos de regresión). 

Para utilizar el indicador, debe utilizar la clase [LinearRegSlope](xref:StockSharp.Algo.Indicators.LinearRegSlope).
