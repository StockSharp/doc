# pendiente de regresión lineal

La interpretación del indicador **pendiente de regresión lineal** muestra el valor de la pendiente de las líneas de regresión, que incluyen la barra de precios actual y la barra de precios n-1 anterior (donde n \= períodos de regresión).

Para utilizar el indicador, debe utilizar la clase [LinearRegSlope](xref:StockSharp.Algo.Indicators.LinearRegSlope).
