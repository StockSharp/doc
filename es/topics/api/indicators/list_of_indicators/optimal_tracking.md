# seguimiento óptimo

El **filtro de seguimiento óptimo** ajusta los cambios rápidos de precios y es relativamente fluido cuando el precio se mueve lateralmente. El efecto de este filtro es similar al de la media móvil adaptativa de Kaufman.

Para utilizar el indicador, debe utilizar la clase [OptimalTracking](xref:StockSharp.Algo.Indicators.OptimalTracking).
