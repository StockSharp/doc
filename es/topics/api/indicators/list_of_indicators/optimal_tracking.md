# Optimal Tracking

El indicador **Optimal Tracking Filter** ajusta los cambios rápidos de precios y es relativamente fluido cuando el precio tiene un efecto secundario. El efecto de este filtro es similar al de la media móvil adaptativa de Kaufman. 

Para utilizar el indicador, debe utilizar la clase [OptimalTracking](xref:StockSharp.Algo.Indicators.OptimalTracking).
