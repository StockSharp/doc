# ADX

**Welles Wilder's ADX (índice direccional medio)** es un grupo de indicadores de movimiento direccional. Las líneas componen el Directional Movement Index (DMI): ADX, DI+ y DI-. ADX indica la fuerza de la tendencia, DI+ y DI- indican la dirección actual del precio.

Para utilizar el indicador, debe utilizar el [AverageDirectionalIndex](xref:StockSharp.Algo.Indicators.AverageDirectionalIndex).
