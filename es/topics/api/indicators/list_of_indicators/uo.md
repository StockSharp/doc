# UO

**oscilador definitivo (UO)** es un indicador técnico desarrollado por Larry Williams en 1976 para medir el impulso en múltiples períodos de tiempo. Al utilizar un promedio ponderado para tres períodos de tiempo diferentes, el indicador tiene menos volatilidad y menos señales de trading en comparación con otros indicadores que se basan en un solo período de tiempo.

Para utilizar el indicador, debe utilizar la clase [UltimateOscillator](xref:StockSharp.Algo.Indicators.UltimateOscillator).
