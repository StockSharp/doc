# Desviación estándar

**Desviación estándar** es un indicador que muestra el rango de precios de los valores, caracterizando su volatilidad. Normalmente, el valor del indicador se expresa en unidades de precio del activo analizado. La desviación estándar es una función de desviación estándar del precio, que se utiliza activamente en estadística matemática.

Para utilizar el indicador, debe utilizar la clase [StandardDeviation](xref:StockSharp.Algo.Indicators.StandardDeviation).
