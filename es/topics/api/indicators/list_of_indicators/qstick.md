# QStick

**Qstick** es un indicador técnico utilizado para determinar tendencias en gráficos de velas. Se calcula tomando la media móvil de N períodos de la diferencia entre los precios de apertura y cierre. El valor positivo de Qstick significa que la presión de compra aumenta.

Para utilizar el indicador, debe utilizar la clase [QStick](xref:StockSharp.Algo.Indicators.QStick).
