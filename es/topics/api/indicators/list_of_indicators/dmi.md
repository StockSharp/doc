# DMI

El indicador **Directional Movement Index (DMI)** es una herramienta técnica para determinar el inicio y la dirección de una tendencia. Es la primera versión del famoso ADX. 

Para utilizar el indicador, debe utilizar la clase [DirectionalIndex](xref:StockSharp.Algo.Indicators.DirectionalIndex).
