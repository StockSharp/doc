# Índice de flujo de dinero

**Índice de flujo de dinero (MFI)** calcula la diferencia entre los flujos de dinero entrantes y salientes. Si el valor base del activo está por debajo de la diferencia, indica un aumento en la masa de dinero entrante, lo que significa que el mercado es alcista. Si se observa lo contrario, significa que los inversores están abandonando el instrumento y el mercado es bajista.
El indicador es un oscilador técnico para determinar las condiciones de sobrecompra o sobreventa de un activo. También se puede utilizar para identificar divergencias que advierten de un cambio de tendencia en el precio. El oscilador se mueve entre 0 y 100.

Para utilizar el indicador, se debe utilizar la clase [MoneyFlowIndex](xref:StockSharp.Algo.Indicators.MoneyFlowIndex).
