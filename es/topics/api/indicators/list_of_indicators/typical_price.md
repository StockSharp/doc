# Precio típico

**Precio típico** calcula el promedio de los valores máximo, mínimo y de cierre de una vela.

Para utilizar el indicador, debe utilizar la clase [TypicalPrice](xref:StockSharp.Algo.Indicators.TypicalPrice).
