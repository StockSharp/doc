# JMA

**Media móvil de Jurik (JMA)** es un indicador que es una variación de la media móvil. La curva del indicador se caracteriza por un buen suavizado, así como por un tiempo de espera mínimo después del final de los movimientos de precios y un retraso mínimo ante movimientos fuertes de precios.

Para utilizar el indicador, se debe utilizar la clase [JurikMovingAverage](xref:StockSharp.Algo.Indicators.JurikMovingAverage).

##### Configuración del indicador.

- Fase: determina la velocidad a la que se desarrollará la media móvil;
- Period: determina el período de la media móvil.
