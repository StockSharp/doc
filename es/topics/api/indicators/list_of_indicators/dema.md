# DEMA

**Double Exponential Moving Average (DEMA)** utiliza múltiples (dobles) Exponential Moving Average (EMA) para eliminar retrasos al pronosticar precios. 

Para utilizar el indicador, debe utilizar la clase [DoubleExponentialMovingAverage](xref:StockSharp.Algo.Indicators.DoubleExponentialMovingAverage).
