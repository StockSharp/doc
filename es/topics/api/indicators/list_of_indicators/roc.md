# RoC

El indicador **Tasa de cambio (RoC)** muestra la diferencia entre el precio actual y el precio de n velas atrás.

Para utilizar el indicador, debe utilizar la clase [RateOfChange](xref:StockSharp.Algo.Indicators.RateOfChange).
