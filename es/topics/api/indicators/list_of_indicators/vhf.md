# VHF

**Filtro vertical-horizontal (VHF)** - El indicador de filtro horizontal vertical fue desarrollado por Adam White en 1991. Este indicador se utiliza en el análisis técnico para reconocer períodos en los que el precio está en una tendencia (tendencia alcista o bajista) o este indicador está en una fase de sobrecarga (tendencia lateral).

Para utilizar el indicador, debe utilizar la clase [VerticalHorizontalFilter](xref:StockSharp.Algo.Indicators.VerticalHorizontalFilter).
