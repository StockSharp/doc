# VIDYA

**media dinámica de índice variable (VIDYA)** es un indicador con el método original de calcular la media móvil exponencial (EMA) con un período de promediación que cambia dinámicamente. El período promedio depende de la volatilidad del mercado; Se eligió un oscilador de impulso (CMO) como medida de volatilidad.

Para utilizar el indicador, debe utilizar la clase [Vidya](xref:StockSharp.Algo.Indicators.Vidya).
