# CCI

**Commodity Channel Index (CCI)** es un indicador técnico basado en el análisis de la desviación del precio actual de su valor promedio y el valor absoluto promedio estadístico. 

Para utilizar el indicador, debe utilizar la clase [CommodityChannelIndex](xref:StockSharp.Algo.Indicators.CommodityChannelIndex).
