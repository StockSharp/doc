# MACD con línea de señal

**Convergencia/Divergencia de Medias Móviles (MACD)** es un indicador de impulso que muestra la relación entre dos promedios móviles del precio de un valor, presentado con una línea de señal.

Para obtener una descripción detallada del cálculo del indicador, consulte [Histograma MACD](macd_histogram.md).

Para utilizar el indicador, se debe utilizar la clase [MovingAverageConvergenceDivergenceSignal](xref:StockSharp.Algo.Indicators.MovingAverageConvergenceDivergenceSignal).
