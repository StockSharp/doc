# Deriv

**Deriv** conecta StockSharp con las API REST y WebSocket oficiales de Deriv Options.

El conector ofrece la búsqueda de símbolos activos, cotizaciones de nivel 1, historial de ticks, ticks en tiempo real y velas de marco temporal históricas y en tiempo real. La negociación abarca propuestas de contrato, compras, venta o cancelación anticipada, actualizaciones de contratos en tiempo real, saldos, carteras, contratos abiertos y transacciones en tiempo real.

Los datos de mercado están disponibles sin credenciales. Para las cuentas demo o reales autenticadas, cree un token de acceso personal o de OAuth y un identificador de aplicación.
