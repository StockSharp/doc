# Configuración gráfica: Deriv

En todos los productos StockSharp, configure la conexión en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

Introduzca el token y el identificador de aplicación. Active `IsDemo` para una cuenta de demostración. Deje `AccountId` vacío cuando el token contenga una sola cuenta activa para el modo seleccionado. Mantenga las direcciones predeterminadas de REST y del WebSocket salvo que Deriv le asigne otras.
