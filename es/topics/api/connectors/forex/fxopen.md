# FXOpen TickTrader

**FXOpen TickTrader** conecta StockSharp con la API web oficial de TickTrader.

El conector ofrece búsqueda de instrumentos, cotizaciones de nivel 1, profundidad de mercado, velas históricas y en tiempo real, carteras, posiciones, órdenes y ejecuciones. Los datos de mercado usan el WebSocket de flujo de datos y las actualizaciones de cuenta y ejecución usan el WebSocket de operaciones.

Para datos en tiempo real y negociación, cree primero un token Web API en FXOpen. Los datos REST públicos están disponibles sin credenciales.
