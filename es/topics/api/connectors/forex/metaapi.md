# MetaApi

**MetaApi** conecta StockSharp con las API REST y en tiempo real de la nube de MetaApi para cuentas de MetaTrader 4 y MetaTrader 5.

El conector ofrece especificaciones de instrumentos, cotizaciones de nivel 1, ticks, profundidad de mercado, velas e historial de ticks y velas. La negociación abarca órdenes de mercado, limitadas y stop, la modificación y cancelación de órdenes, el cierre de posiciones y la sincronización de carteras, posiciones, órdenes y operaciones.

Antes de conectarse, despliegue una cuenta de negociación en MetaApi y cree un token de API. Las conexiones en tiempo real se restablecen, el estado del terminal se vuelve a sincronizar y las suscripciones se restauran automáticamente.
