# Configuración gráfica: FXOpen TickTrader

En todos los productos StockSharp, configure la conexión en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

Introduzca el identificador, la clave y el secreto del token Web API. Active `IsDemo` para una cuenta de demostración. Indique `OneTimePassword` solo si la cuenta requiere autenticación de dos factores. Mantenga las direcciones predeterminadas de REST, del WebSocket de flujo de datos y del WebSocket de operaciones salvo que FXOpen le asigne otras.
