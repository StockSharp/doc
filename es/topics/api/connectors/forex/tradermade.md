# TraderMade

**TraderMade** conecta StockSharp con las API REST y WebSocket de TraderMade para divisas y pares de criptomonedas compatibles.

## Funciones principales

- Funciones verificadas en el código fuente: cotizaciones de nivel 1 en tiempo real, libros TraderLadder opcionales, búsqueda de instrumentos y velas históricas. El adaptador solo ofrece datos de mercado.
- El transporte, las sesiones y los formatos del proveedor quedan ocultos tras la API estándar de StockSharp.

## Uso habitual

Utilice este conector para supervisar divisas en vivo, analizar profundidad opcional y descargar velas históricas.

Los símbolos, el acceso a TraderLadder, los datos de fin de semana, los límites y la disponibilidad dependen del plan de TraderMade.
