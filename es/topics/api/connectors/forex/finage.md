# Finage

**Finage** conecta StockSharp con las API REST y WebSocket de Finage Forex.

## Funciones principales

- Funciones verificadas en el código fuente: búsqueda de instrumentos, cotizaciones de nivel 1 en tiempo real y velas históricas. El adaptador solo ofrece datos de mercado y no admite transacciones.
- El transporte, las sesiones y los formatos del proveedor quedan ocultos tras la API estándar de StockSharp.

## Uso habitual

Utilice este conector para descubrir pares de divisas, supervisar cotizaciones en vivo y descargar velas históricas de Forex.

La cobertura de símbolos, el acceso en tiempo real, el historial, los límites y la disponibilidad dependen del plan de Finage.
