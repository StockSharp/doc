# Configuración gráfica: StocksTrader

En todos los productos StockSharp, configure la conexión en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

Introduzca el token emitido por el terminal web. Active `IsDemo` para una cuenta de demostración. Deje `AccountId` vacío cuando el token contenga una sola cuenta para el modo seleccionado. Mantenga la dirección predeterminada salvo que StocksTrader le asigne otro punto de conexión y ajuste `PollingInterval` a la frecuencia de actualización necesaria.
