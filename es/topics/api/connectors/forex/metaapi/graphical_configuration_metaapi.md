# Configuración gráfica: MetaApi

En todos los productos StockSharp, configure la conexión en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

Introduzca el token y el identificador de la cuenta desplegada. Rellene `Region` solo para un token asociado a una cuenta. Mantenga el dominio predeterminado salvo que MetaApi le asigne otro y aumente `SynchronizationTimeout` para las cuentas con un historial extenso.
