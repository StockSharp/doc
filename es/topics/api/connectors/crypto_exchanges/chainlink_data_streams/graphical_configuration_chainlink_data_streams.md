# Configuración gráfica de Chainlink Data Streams

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

- `Key` - clave de la API.
- `Secret` - secreto de la API.
- `RestEndpoint` - punto de acceso de la API REST.
- `WebSocketEndpoint` - punto de acceso de la API WebSocket.
