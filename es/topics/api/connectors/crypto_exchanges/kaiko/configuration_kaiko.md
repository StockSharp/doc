# Configuración del conector Kaiko

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `Token` - token de acceso a la API.
- `Region` - punto de acceso regional de la API de Kaiko.
- `ReferenceEndpoint` - punto de acceso de la API de datos de referencia.
- `MarketEndpoint` - punto de acceso de la API de datos históricos de mercado.
- `StreamEndpoint` - punto de acceso de datos de mercado en tiempo real.
- `IsStreamingEnabled` - activar los datos WebSocket en tiempo real.
