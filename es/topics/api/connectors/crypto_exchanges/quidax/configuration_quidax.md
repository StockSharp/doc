# Configuración del conector: Quidax

Configure las siguientes propiedades antes de conectarse a Quidax. La lista se ha verificado con [QuidaxMessageAdapter](xref:StockSharp.Quidax.QuidaxMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Token` (`SecureString`)
- `UserId` (`string`)
- `RestEndpoint` (`string`)
- `PollingInterval` (`TimeSpan`)
