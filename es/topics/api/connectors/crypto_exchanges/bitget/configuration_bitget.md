# Configuración del conector Bitget

Para trabajar con el conector, es necesario generar una **clave API** y un **secreto** en la cuenta personal de la bolsa y especificarlos al configurar la conexión.

> [!TIP]
> Tenga en cuenta que la **clave API y secreto** no son el **usuario y contraseña**. La **clave API y secreto** se generan por separado en la cuenta personal. El usuario y la contraseña no son necesarios para el conector y no deben especificarse en ningún lugar.
