# Configuración gráfica Bitalong

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

![Configuración de API GUI Bitalong](../../../../../images/api_gui_settings_bitalong.png)

- **clave** - Clave.
- **secreto** - Secreto.
- **Intervalo de comprobación** - Intervalo de comprobación del servidor para verificar que la conexión está activa. Por defecto es 1 minuto.
- **Configuración de reconexión** - Mecanismo para el seguimiento de las conexiones con la configuración del sistema de trading. ([Configuración de reconexión](../../reconnection_settings.md))
