# Configuración gráfica BW

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

![API GUI Settings BW](../../../../../images/api_gui_settings_bw.png)

- **Key** - Clave.
- **Secret** - Secreto.
- **Balance** - Intervalo de comprobación del saldo. Necesario en caso de acciones de depósito y retiro.
- **Heart beat** - Intervalo de comprobación del servidor para el seguimiento de la conexión activa. Por defecto es igual a 1 minuto.
- **Reconnection settings** - Mecanismo de seguimiento de las conexiones con la configuración del sistema de trading. ([Configuración de reconexión](../../reconnection_settings.md))
