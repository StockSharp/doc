# Configuración del conector VALR

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `Key` - clave de API.
- `Secret` - secreto de la API.
- `SubAccountId` - identificador de la subcuenta.
- `RestEndpoint` - dirección de la API REST.
- `TradeWebSocketEndpoint` - dirección del servidor WebSocket.
- `AccountWebSocketEndpoint` - dirección del servidor WebSocket.
