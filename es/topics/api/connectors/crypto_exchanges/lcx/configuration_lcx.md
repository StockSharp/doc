# Configuración del conector: LCX

Configure las siguientes propiedades antes de conectarse a LCX. La lista se ha verificado con [LcxMessageAdapter](xref:StockSharp.LCX.LcxMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `KlineEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `ApiVersion` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
