# Configuración del conector: CoinTR

Configure las siguientes propiedades antes de conectarse a CoinTR. La lista se ha verificado con [CoinTRMessageAdapter](xref:StockSharp.CoinTR.CoinTRMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `Passphrase` (`SecureString`)
- `RestEndpoint` (`string`)
- `PublicWebSocketEndpoint` (`string`)
- `PrivateWebSocketEndpoint` (`string`)
