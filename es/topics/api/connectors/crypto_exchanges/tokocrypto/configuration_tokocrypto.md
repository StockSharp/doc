# Configuración del conector: Tokocrypto

Configure las siguientes propiedades antes de conectarse a Tokocrypto. La lista se ha verificado con [TokocryptoMessageAdapter](xref:StockSharp.Tokocrypto.TokocryptoMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `AccountRestEndpoint` (`string`)
- `MarketDataRestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
