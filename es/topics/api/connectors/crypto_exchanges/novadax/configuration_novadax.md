# Configuración del conector: NovaDAX

Configure las siguientes propiedades antes de conectarse a NovaDAX. La lista se ha verificado con [NovaDaxMessageAdapter](xref:StockSharp.NovaDax.NovaDaxMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `AccountId` (`string`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `EngineIoVersion` (`int`)
