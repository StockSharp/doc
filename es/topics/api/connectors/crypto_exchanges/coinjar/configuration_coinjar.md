# Configuración del conector CoinJar

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `Token` - token de acceso a la API.
- `TradingEndpoint` - punto de acceso de la API de negociación.
- `DataEndpoint` - punto de acceso de la API de datos de mercado.
- `WebSocketEndpoint` - dirección del servidor WebSocket.
