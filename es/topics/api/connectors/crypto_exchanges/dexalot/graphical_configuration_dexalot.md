# Configuración gráfica: Dexalot

En todos los productos StockSharp, configure la conexión en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

La sección básica del editor de conexiones contiene:

- `RestEndpoint`
- `WebSocketEndpoint`
- `RpcEndpoint`
- `WalletAddress`
- `PrivateKey`

Use la vista avanzada para las propiedades restantes descritas en la página de [Configuración del conector](configuration_dexalot.md). Mantenga los puntos de conexión predefinidos salvo que el proveedor le haya asignado otros valores.
