# Configuración gráfica de GRVT

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

- `Key` - clave de la API para la autenticación.
- `Secret` - secreto de la API para la autenticación.
- `SubAccountId` - identificador de la subcuenta de negociación.
- `Environment` - entorno del servicio: red de producción o de prueba.
- `EdgeEndpoint` - punto de acceso de la API de autenticación.
- `MarketDataEndpoint` - punto de acceso de la API de datos de mercado.
- `TradingEndpoint` - punto de acceso de la API de negociación.
- `MarketWebSocketEndpoint` - punto de acceso WebSocket de datos de mercado.
- `TradingWebSocketEndpoint` - punto de acceso WebSocket de negociación.
- `SnapshotInterval` - intervalo de las instantáneas de datos de mercado, en milisegundos.
- `MarketDepth` - número de niveles solicitados del libro de órdenes.
