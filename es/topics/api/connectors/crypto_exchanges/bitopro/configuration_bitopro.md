# Configuración del conector: BitoPro

Configure las siguientes propiedades antes de conectarse a BitoPro. La lista se ha verificado con [BitoProMessageAdapter](xref:StockSharp.BitoPro.BitoProMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Email` (`string`)
- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
