# Configuración del conector WEEX

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `Key` - clave de API.
- `Secret` - secreto de la API.
- `Passphrase` - frase de contraseña de la API.
- `SpotRestEndpoint` - dirección de la API REST.
- `FuturesRestEndpoint` - dirección de la API REST.
- `SpotPublicWsEndpoint` - dirección del servidor WebSocket.
- `SpotPrivateWsEndpoint` - dirección del servidor WebSocket.
- `FuturesPublicWsEndpoint` - dirección del servidor WebSocket.
- `FuturesPrivateWsEndpoint` - dirección del servidor WebSocket.
