# Configuración gráfica Hyperliquid

Para todos los productos [S#](../../../../api.md), la configuración gráfica se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md).

Campos principales:

- **Wallet address** - dirección de wallet (`0x...`).
- **Private key** - clave privada para acciones firmadas.
- **Vault address** - dirección opcional de vault o subcuenta.
- **Expires after** - marca de tiempo opcional de expiración de la firma.
- **Section** - sección de trading (`Spot` o `Derivatives`).
- **Testnet** - endpoints de testnet.
- **Info endpoint / Exchange endpoint / WS endpoint** - URL de endpoints.
- **Market slippage** - deslizamiento predeterminado para órdenes de mercado.
