# Configuración gráfica de Bitmart

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

![Configuración de API GUI Bitmart](../../../../../images/api_gui_settings_bitmart.png)

- **clave** - Clave.
- **secreto** - Secreto.
- **Board** - Sección a conectar (Spot, Futures).
- **frase de acceso** - Contraseña administrativa.
