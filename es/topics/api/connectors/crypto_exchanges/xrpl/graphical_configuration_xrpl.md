# Configuración gráfica: XRPL DEX

En todos los productos StockSharp, configure la conexión en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

La sección básica del editor de conexiones contiene:

- `RpcEndpoint`
- `StreamingEndpoint`
- `Account`
- `Seed`

Use la vista avanzada para las propiedades restantes descritas en la página de [Configuración del conector](configuration_xrpl.md). Mantenga los puntos de conexión predefinidos salvo que el proveedor le haya asignado otros valores.
