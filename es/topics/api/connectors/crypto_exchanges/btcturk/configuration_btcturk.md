# Configuración del conector: BtcTurk

Configure las siguientes propiedades antes de conectarse a BtcTurk. La lista se ha verificado con [BtcTurkMessageAdapter](xref:StockSharp.BtcTurk.BtcTurkMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `GraphEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
