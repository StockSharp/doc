# Configuración del conector BTSE

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `Key` - clave de API.
- `Secret` - secreto de la API.
- `SpotRestEndpoint` - dirección de la API REST.
- `SpotWebSocketEndpoint` - dirección del servidor WebSocket.
- `SpotOrderBookWebSocketEndpoint` - dirección del servidor WebSocket.
- `FuturesRestEndpoint` - dirección de la API REST.
- `FuturesWebSocketEndpoint` - dirección del servidor WebSocket.
- `FuturesOrderBookWebSocketEndpoint` - dirección del servidor WebSocket.
