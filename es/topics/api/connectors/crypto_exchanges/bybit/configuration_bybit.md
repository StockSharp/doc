# Configuración del conector ByBit

Para trabajar con el conector, es necesario generar una **clave API** y un **secreto** en la cuenta personal del exchange y especificarlos al configurar la conexión.

> [!TIP]
> Tenga en cuenta que **clave API y secreto** no son **usuario y contraseña**. **clave API y secreto** se generan por separado en la cuenta personal. El usuario y la contraseña no son necesarios para el conector y no deben especificarse en ningún lugar.
