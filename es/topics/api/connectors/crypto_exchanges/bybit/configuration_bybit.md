# Configuración del conector ByBit

Para trabajar con el conector, es necesario generar una **API Key** y un **Secret** en la cuenta personal del exchange y especificarlos al configurar la conexión.

> [!TIP]
> Tenga en cuenta que **API Key y Secret** no son **Login y Password**. **API Key y Secret** se generan por separado en la cuenta personal. Login y Password no son necesarios para el conector y no deben especificarse en ningún lugar.
