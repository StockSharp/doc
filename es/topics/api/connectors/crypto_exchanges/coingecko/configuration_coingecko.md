# Configuración del conector CoinGecko

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `Tier` - plan de suscripción de la API de CoinGecko.
- `Token` - token de acceso a la API.
- `ApiEndpoint` - punto de acceso de la API REST.
- `SocketEndpoint` - punto de acceso de la API WebSocket.
- `QuoteCurrency` - moneda utilizada para cotizar los precios de mercado.
- `IsStreamingEnabled` - activar los datos WebSocket en tiempo real.
