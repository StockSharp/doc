# Configuración gráfica de Coinone

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

- `Key` - clave de API.
- `Secret` - secreto de la API.
- `QuoteCurrency` - moneda de cotización utilizada para solicitar mercados.
- `RestEndpoint` - dirección de la API REST.
- `PublicWebSocketEndpoint` - dirección del servidor WebSocket.
- `PrivateWebSocketEndpoint` - dirección del servidor WebSocket.
