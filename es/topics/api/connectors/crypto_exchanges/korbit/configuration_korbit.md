# Configuración del conector Korbit

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `Key` - clave de API.
- `Secret` - secreto de la API.
- `AccountSequence` - número de secuencia de la cuenta de Korbit; la cuenta principal utiliza `1`.
- `RestEndpoint` - dirección de la API REST.
- `PublicWebSocketEndpoint` - dirección del servidor WebSocket.
- `PrivateWebSocketEndpoint` - dirección del servidor WebSocket.
