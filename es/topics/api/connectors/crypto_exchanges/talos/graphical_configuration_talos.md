# Configuración gráfica de Talos

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

- `Address` - dirección y puerto del servidor FIX proporcionados por Talos.
- `SenderCompId` - identificador del remitente FIX.
- `TargetCompId` - identificador del destinatario FIX.
- `Login` - usuario de la sesión FIX.
- `Password` - contraseña de la sesión FIX.
- `ClientCode` - código de cliente para el enrutamiento de cuentas.
- `TargetHost` - nombre de host del certificado TLS.
