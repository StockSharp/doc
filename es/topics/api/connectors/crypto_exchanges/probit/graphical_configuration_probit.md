# Configuración gráfica de ProBit Global

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

- `Key` - identificador de cliente OAuth.
- `Secret` - secreto de cliente OAuth.
- `RestEndpoint` - dirección de la API REST.
- `AuthEndpoint` - dirección del punto de acceso de tokens OAuth.
- `WebSocketEndpoint` - dirección del servidor WebSocket.

Las credenciales son opcionales para datos públicos de mercado y obligatorias para negociar y consultar datos privados de la cuenta.
