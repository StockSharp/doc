# Configuración del conector Toobit

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `Key` - clave de API.
- `Secret` - secreto de la API.
- `RestEndpoint` - dirección de la API REST.
- `WsEndpoint` - dirección del servidor WebSocket.
