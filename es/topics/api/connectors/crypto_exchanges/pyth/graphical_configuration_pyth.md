# Configuración gráfica de Pyth

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

- `Token` - token de acceso a la API.
- `HistoryEndpoint` - punto de acceso de la API de datos históricos.
- `RouterEndpoint` - punto de acceso de la API REST de precios recientes.
- `WebSocketEndpoint1` - punto de acceso WebSocket principal para datos en tiempo real.
- `WebSocketEndpoint2` - punto de acceso WebSocket secundario para datos en tiempo real.
- `WebSocketEndpoint3` - tercer punto de acceso WebSocket para datos en tiempo real.
- `Channel` - canal de datos de Pyth.
