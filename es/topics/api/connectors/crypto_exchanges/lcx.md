# LCX

**LCX** conecta StockSharp con la plataforma de criptomonedas LCX. El adaptador expone la API del proveedor mediante el modelo estándar de mensajes de StockSharp.

## Funciones principales

- Funciones del adaptador verificadas en el código fuente: actualizaciones de datos en tiempo real, cotizaciones de nivel 1, libros de órdenes de nivel 2, operaciones ejecutadas, datos de velas, solicitudes de datos históricos, operaciones de cartera y órdenes.
- El transporte, las sesiones y los formatos del proveedor quedan ocultos tras la API estándar de StockSharp.

## Uso habitual

Utilice este conector en robots de negociación, terminales, recopiladores de datos, servicios de gestión de órdenes y supervisión de mercados de criptomonedas.

Los instrumentos, la profundidad de datos, los permisos de transacción, los límites de solicitudes y la disponibilidad dependen de LCX, del plan de API y de la cuenta conectada.
