# Configuración del conector: Buda

Configure las siguientes propiedades antes de conectarse a Buda. La lista se ha verificado con [BudaMessageAdapter](xref:StockSharp.Buda.BudaMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
