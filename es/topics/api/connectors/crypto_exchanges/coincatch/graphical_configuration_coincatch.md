# Configuración gráfica: CoinCatch

En todos los productos StockSharp, configure la conexión en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

La sección básica del editor de conexiones contiene:

- `Key`
- `Secret`
- `Passphrase`
- `ProductType`
- `RestEndpoint`
- `PublicWebSocketEndpoint`
- `PrivateWebSocketEndpoint`
- `PollingInterval`

Todas las propiedades específicas del adaptador aparecen arriba. Mantenga las direcciones predefinidas salvo que el proveedor haya asignado valores diferentes.
