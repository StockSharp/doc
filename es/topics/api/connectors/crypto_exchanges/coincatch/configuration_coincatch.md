# Configuración del conector: CoinCatch

Configure las siguientes propiedades antes de conectarse a CoinCatch. La lista se ha verificado con [CoinCatchMessageAdapter](xref:StockSharp.CoinCatch.CoinCatchMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `Passphrase` (`SecureString`)
- `ProductType` (`CoinCatchProductTypes`)
- `RestEndpoint` (`string`)
- `PublicWebSocketEndpoint` (`string`)
- `PrivateWebSocketEndpoint` (`string`)
- `PollingInterval` (`TimeSpan`)
