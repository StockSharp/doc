# Configuración gráfica de BingX

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

![API GUI Settings BingX](../../../../../images/api_gui_settings_bingx.png)

- **Key** - Clave.
- **Secret** - Secreto.
- **Demo** - Modo demo.
- **Reconnection settings** - Parámetros del mecanismo de reconexión con el sistema de trading ([Configuración de reconexión](../../reconnection_settings.md)).
