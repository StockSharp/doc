# Configuración del conector: BigONE

Configure las siguientes propiedades antes de conectarse a BigONE. La lista se ha verificado con [BigOneMessageAdapter](xref:StockSharp.BigOne.BigOneMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `SpotRestEndpoint` (`string`)
- `SpotWebSocketEndpoint` (`string`)
- `ContractRestEndpoint` (`string`)
- `ContractWebSocketEndpoint` (`string`)
- `ContractPrivateWebSocketEndpoint` (`string`)
