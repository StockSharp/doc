# Configuración del conector: Coinmetro

Configure las siguientes propiedades antes de conectarse a Coinmetro. La lista se ha verificado con [CoinmetroMessageAdapter](xref:StockSharp.Coinmetro.CoinmetroMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Token` (`SecureString`)
- `IsDemo` (`bool`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `DemoRestEndpoint` (`string`)
- `DemoWebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
