# Configuración gráfica de QuickSwap

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

- `GraphApiKey` - clave de la API de la puerta de enlace The Graph.
- `WalletAddress` - dirección pública de la cartera de cadena de bloques para consultar saldos y enviar órdenes.
- `PrivateKey` - clave privada utilizada localmente para firmar transacciones.
- `Chain` - red de cadena de bloques utilizada para las solicitudes.
- `RpcEndpoint` - punto de acceso RPC de la cadena de bloques.
