# Configuración gráfica Ligther

Para todos los productos [S#](../../../../api.md), la configuración gráfica se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md).

Campos principales:

- **Key** - clave API.
- **Secret** - secreto API.
- **Account index** - índice de cuenta.
- **API key index** - índice de clave API.
- **Section** - sección de trading (`Spot` o `Derivatives`).
- **Demo** - modo de entorno demo.
- **Spot REST / Derivatives REST** - endpoints REST.
- **Spot WS / Derivatives WS** - endpoints WebSocket.
- **WS read-only mode** - indicador de modo de solo lectura WebSocket.
