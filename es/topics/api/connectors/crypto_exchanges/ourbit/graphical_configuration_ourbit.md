# Configuración gráfica de Ourbit

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

- `Key` - clave de API.
- `Secret` - secreto de la API.
- `SpotRestEndpoint` - dirección de la API REST.
- `SpotWsEndpoint` - dirección del servidor WebSocket.
- `FuturesRestEndpoint` - dirección de la API REST.
- `FuturesWsEndpoint` - dirección del servidor WebSocket.
