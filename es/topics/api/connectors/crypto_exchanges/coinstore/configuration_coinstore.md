# Configuración del conector: Coinstore

Configure las siguientes propiedades antes de conectarse a Coinstore. La lista se ha verificado con [CoinstoreMessageAdapter](xref:StockSharp.Coinstore.CoinstoreMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
