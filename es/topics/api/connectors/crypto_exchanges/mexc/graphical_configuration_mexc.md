# Configuración gráfica de MEXC

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

![API GUI Settings MEXC](../../../../../images/api_gui_settings_mexc.png)

- **Key** - Clave.
- **Secret** - Secreto.
- **Demo** - Modo demo.
- **Configuración de reconexión** - Parámetros del mecanismo de reconexión con el sistema de trading ([Configuración de reconexión](../../reconnection_settings.md)).
