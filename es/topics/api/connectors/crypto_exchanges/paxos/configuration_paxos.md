# Configuración del conector Paxos

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `Environment` - entorno de conexión: producción, demostración o prueba.
- `ClientId` - identificador del cliente OAuth.
- `ClientSecret` - secreto del cliente OAuth.
- `ApiEndpoint` - punto de acceso de la API REST.
- `OAuthEndpoint` - punto de acceso del token OAuth.
- `SocketEndpoint` - punto de acceso de la API WebSocket.
