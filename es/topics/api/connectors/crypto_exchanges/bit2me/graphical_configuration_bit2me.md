# Configuración gráfica de Bit2Me

En todos los productos [S#](../../../../api.md), la configuración gráfica se realiza en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md):

- `Key` — clave API de Bit2Me para operaciones privadas.
- `Secret` — secreto API de Bit2Me.
- `RestEndpoint` — dirección de la API REST.
- `WebSocketEndpoint` — dirección WebSocket.

Deje `Key` y `Secret` vacíos si solo necesita datos públicos. Para la negociación y los datos de cuenta, configure ambos valores.
