# Configuración gráfica de Aevo

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

- `Environment` - entorno de conexión: red de producción o de prueba.
- `ApiKey` - clave de la API.
- `ApiSecret` - secreto de la API.
- `WalletAddress` - dirección pública de la cartera de cadena de bloques para operaciones de cuenta.
- `SigningKey` - clave privada para firmar solicitudes de negociación.
