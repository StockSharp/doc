# Configuración del conector Jupiter

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `ApiKey` - clave de la API para acceder al servicio.
- `WalletAddress` - dirección pública de la cartera de cadena de bloques para consultar saldos y enviar órdenes.
- `PrivateKey` - clave privada utilizada localmente para firmar transacciones.
