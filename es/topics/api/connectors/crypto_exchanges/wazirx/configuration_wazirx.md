# Configuración del conector: WazirX

Configure las siguientes propiedades antes de conectarse a WazirX. La lista se ha verificado con [WazirXMessageAdapter](xref:StockSharp.WazirX.WazirXMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `ReceiveWindow` (`long`)
- `PrivatePollingInterval` (`TimeSpan`)
