# Configuración del conector Polymarket

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `ApiKey` - clave de la API.
- `ApiSecret` - secreto de la API.
- `Passphrase` - frase de contraseña de la API.
- `SignerAddress` - dirección que firma las órdenes.
- `FunderAddress` - dirección que financia la cuenta de negociación.
- `PrivateKey` - clave privada utilizada localmente para firmar solicitudes y transacciones.
- `SignatureType` - esquema de firma utilizado para las órdenes.
