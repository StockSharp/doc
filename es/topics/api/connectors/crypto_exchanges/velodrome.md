# Velodrome

**Velodrome** conecta StockSharp con el protocolo descentralizado Velodrome. El adaptador expone los datos de mercado y las operaciones de transacción admitidas mediante el modelo estándar de mensajes de StockSharp.

## Funciones principales

- Funciones del adaptador verificadas en el código fuente: actualizaciones de datos en tiempo real, cotizaciones de nivel 1, operaciones ejecutadas, datos de velas, solicitudes de datos históricos, operaciones de cartera y órdenes.
- El transporte, las sesiones y los formatos del proveedor quedan ocultos tras la API estándar de StockSharp.

## Uso habitual

Utilice este conector para supervisar mercados descentralizados, analizar cotizaciones y ejecutar los flujos de transacción implementados por el adaptador.

Los instrumentos, la profundidad de datos, los permisos de transacción, los límites de solicitudes y la disponibilidad dependen de Velodrome, del plan de API y de la cuenta conectada.
