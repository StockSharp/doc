# Coinalyze

**Coinalyze** conecta StockSharp con el servicio de datos del mercado de criptomonedas Coinalyze. El adaptador expone los datos del proveedor mediante el modelo estándar de mensajes de StockSharp.

## Funciones principales

- Funciones del adaptador verificadas en el código fuente: datos de velas, solicitudes de datos históricos, mercados de futuros.
- El transporte, las sesiones y los formatos del proveedor quedan ocultos tras la API estándar de StockSharp.
- Este adaptador está destinado al acceso a datos y no enruta órdenes.

## Uso habitual

Utilice este conector para alimentar gráficos, almacenamiento de datos de mercado, análisis, investigación y pruebas de estrategias.

Los instrumentos, la profundidad de datos, los permisos de transacción, los límites de solicitudes y la disponibilidad dependen de Coinalyze, del plan de API y de la cuenta conectada.
