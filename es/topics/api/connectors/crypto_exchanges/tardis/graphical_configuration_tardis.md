# Configuración gráfica de Tardis

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

- `Token` - token de acceso a la API.
- `Exchange` - código de la bolsa cuyos datos se solicitan.
- `ApiEndpoint` - punto de acceso de la API REST.
- `MachineHttpEndpoint` - punto de acceso HTTP local de Tardis Machine.
- `MachineSocketEndpoint` - punto de acceso WebSocket local de Tardis Machine.
