# Configuración del conector WOO X

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `Key` - clave de API.
- `Secret` - secreto de la API.
- `ApplicationId` - identificador de la aplicación registrada.
- `RestEndpoint` - dirección de la API REST.
- `HistoricalRestEndpoint` - dirección de la API REST.
- `PublicWsEndpoint` - dirección del servidor WebSocket.
- `PrivateWsEndpoint` - dirección del servidor WebSocket.
