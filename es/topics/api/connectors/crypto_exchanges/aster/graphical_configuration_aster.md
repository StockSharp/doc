# Configuración gráfica Aster

Para todos los productos [S#](../../../../api.md), la configuración gráfica se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md).

Campos principales:

- **clave** - clave de la API.
- **secreto** - secreto de la API.
- **Sección** - sección de negociación (`Spot` o `Derivatives`).
- **Modo de derivados** - familia de protocolo de derivados.
- **Demostración** - modo de entorno de demostración.
- **Spot REST / Derivatives REST** - endpoints REST.
- **Spot WS / Derivatives WS** - endpoints de websocket.
