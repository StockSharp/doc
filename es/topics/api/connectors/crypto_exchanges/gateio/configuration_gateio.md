# Configuración del conector Gate.io

Para trabajar con el conector, debe generar una **clave API** y un **secreto** en la cuenta personal de la bolsa y especificarlos al configurar la conexión.

> [!TIP]
> Tenga en cuenta que la **clave API y secreto** no son el **usuario y contraseña**. La **clave API y secreto** se generan por separado en la cuenta personal. El Login y la Password no son necesarios para el conector y no deben especificarse en ningún lugar.
