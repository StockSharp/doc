# Configuración del conector Bluefin

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `Environment` - entorno de conexión: red de producción o de prueba.
- `WalletAddress` - dirección pública de la cartera de cadena de bloques para operaciones de cuenta.
- `PrivateKey` - clave privada utilizada localmente para firmar solicitudes y transacciones.
