# Configuración del conector: CoinSpot

Configure las siguientes propiedades antes de conectarse a CoinSpot. La lista se ha verificado con [CoinSpotMessageAdapter](xref:StockSharp.CoinSpot.CoinSpotMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `PublicEndpoint` (`string`)
- `TradingEndpoint` (`string`)
- `ReadOnlyEndpoint` (`string`)
- `PollingInterval` (`TimeSpan`)
