# Configuración del conector Variational Omni

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `Endpoint` - punto de acceso de la API de datos de mercado.
- `PollingInterval` - intervalo de consulta de datos.
