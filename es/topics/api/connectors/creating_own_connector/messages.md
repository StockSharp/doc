# Lista de mensajes

Un mensaje transporta información sobre datos de mercado, transacciones o un comando. A continuación se muestra una lista de los principales mensajes utilizados en los conectores.

| Mensaje                                                                             | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Message](xref:StockSharp.Messages.Message)                                         | Una clase de mensaje abstracta de la que heredan otras clases de mensajes. Contiene información sobre el tiempo, el tipo [MessageTypes](xref:StockSharp.Messages.MessageTypes) y el adaptador que creó el mensaje.                                                                                                                                                                                                                                                                                                                                                          |
| [BoardMessage](xref:StockSharp.Messages.BoardMessage)                               | Contiene información sobre el mercado electrónico de negociación.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| [CandleMessage](xref:StockSharp.Messages.CandleMessage)                             | Una clase de mensaje abstracta que contiene información general sobre una vela. De esta clase heredan las clases de mensajes para tipos de velas específicos: [TimeFrameCandleMessage](xref:StockSharp.Messages.TimeFrameCandleMessage), [TickCandleMessage](xref:StockSharp.Messages.TickCandleMessage), [VolumeCandleMessage](xref:StockSharp.Messages.VolumeCandleMessage), [RangeCandleMessage](xref:StockSharp.Messages.RangeCandleMessage), [PnFCandleMessage](xref:StockSharp.Messages.PnFCandleMessage) y [RenkoCandleMessage](xref:StockSharp.Messages.RenkoCandleMessage). |
| [ConnectMessage](xref:StockSharp.Messages.ConnectMessage)                           | Se utiliza como comando para establecer una conexión, así como para un mensaje entrante sobre una conexión exitosa o un error de conexión.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| [DisconnectMessage](xref:StockSharp.Messages.DisconnectMessage)                     | Se utiliza como comando para interrumpir una conexión, así como para un mensaje entrante sobre una interrupción de conexión.                                                                                                                                                                                                                                                                                                                                                                                                                                                |

| [ExecutionMessage](xref:StockSharp.Messages.ExecutionMessage)                       | Descripción a continuación.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| [Level1ChangeMessage](xref:StockSharp.Messages.Level1ChangeMessage)                 | El mensaje contiene información sobre el valor de un campo Level1 de un tipo determinado. | [PortfolioMessage](xref:StockSharp.Messages.PortfolioMessage)                       | Contiene información sobre una cartera.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

El [ExecutionMessage](xref:StockSharp.Messages.ExecutionMessage) es un mensaje universal que permite transmitir diversa información de intercambio relacionada con órdenes y operaciones: operaciones tick, registros de órdenes, órdenes propias y operaciones propias.

El tipo de información en el mensaje se determina por el valor de la propiedad [ExecutionMessage.ExecutionType](xref:StockSharp.Messages.ExecutionMessage.ExecutionType):

- [ExecutionTypes.Tick](xref:StockSharp.Messages.ExecutionTypes.Tick): operación tick.
- [ExecutionTypes.Transaction](xref:StockSharp.Messages.ExecutionTypes.Transaction): transacción (información sobre una operación u orden propia).
- [ExecutionTypes.OrderLog](xref:StockSharp.Messages.ExecutionTypes.OrderLog): registro de órdenes.

Si se utiliza el tipo [ExecutionTypes.Transaction](xref:StockSharp.Messages.ExecutionTypes.Transaction), entonces se refiere a órdenes u operaciones propias. En este caso, si el mensaje contiene información sobre una orden, la propiedad [ExecutionMessage.HasOrderInfo](xref:StockSharp.Messages.ExecutionMessage.HasOrderInfo) = true; si hay información sobre una operación, la propiedad [ExecutionMessage.HasTradeInfo](xref:StockSharp.Messages.ExecutionMessage.HasTradeInfo) = true. Tenga en cuenta que una *operación propia* contiene información tanto sobre la operación en sí como sobre la orden asociada a esa operación. Por lo tanto, en este caso, las propiedades anteriores tienen un valor de true. Estas propiedades permiten diferenciar los mensajes con operaciones y órdenes propias.
