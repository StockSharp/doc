# Configuración gráfica BMLL

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

- `AuthenticationMode` - método de autenticación.
- `Login` - nombre de usuario de la cuenta.
- `PrivateKeyPath` - ruta al archivo de la clave privada.
- `Password` - contraseña de la cuenta.
- `Token` - token de acceso a la API.
- `ApiKey` - clave de API.
- `Address` - dirección de la API REST.
- `AuthenticationAddress` - punto de acceso del servicio de autenticación.
- `TradesDataset` - nombre del conjunto de datos de operaciones de BMLL.
- `Level3Dataset` - nombre del conjunto de datos de nivel 3 de BMLL.
