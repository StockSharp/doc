# Configuración Goldman Sachs Marquee

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `ClientId` - identificador del cliente de OAuth.
- `ClientSecret` - secreto del cliente de OAuth.
- `IsDemo` - modo del entorno de demostración.
