# Configuración gráfica: dxFeed

En todos los productos StockSharp, la conexión se configura en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

- `Address` - dirección del servicio. Valor predeterminado: `wss://demo.dxfeed.com/dxlink-ws`.
- `Token` - credencial de autenticación.
- `AggregationPeriod` - intervalo de tiempo.
- `MarketDepthLevels` - parámetro numérico del conector. Valor predeterminado: `20`.
- `MarketDepthSources` - parámetro de conexión. Valor predeterminado: `NTV`.
