# Configuración gráfica: Korea Investment & Securities

En todos los productos StockSharp, la conexión se configura en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

- `AppKey` - credencial de autenticación.
- `AppSecret` - credencial de autenticación.
- `AccountNumber` - parámetro de conexión.
- `ProductCode` - identificador de cuenta o cliente. Valor predeterminado: `01`.
- `HtsId` - identificador de cuenta o cliente.
- `IsDemo` - interruptor que controla el comportamiento del conector. Valor predeterminado: `true`.
