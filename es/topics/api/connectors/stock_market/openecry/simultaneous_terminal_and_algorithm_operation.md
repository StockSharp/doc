# Operación simultánea del terminal y el algoritmo

Si es necesario, puede configurar el terminal OEC Trader para operar en modo [Primary](xref:StockSharp.OpenECry.OpenECryRemoting.Primary) y luego ejecutar el algoritmo [S#](../../../../api.md) en modo [Primary](xref:StockSharp.OpenECry.OpenECryRemoting.Primary). En este caso, el terminal y el algoritmo usarán la misma conexión al servidor OEC. Para configurarlo, debe marcar el elemento de menú **Archivo → Permitir remoting** en el terminal OEC Trader:
