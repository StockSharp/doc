# Configuración gráfica de Longbridge OpenAPI

En todos los productos StockSharp, configure la conexión en la [ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md).

- **Clave de aplicación** - propiedad `AppKey`.
- **Secreto de aplicación** - propiedad `AppSecret`.
- **Token de acceso** - propiedad `AccessToken`.
- **Cartera** - propiedad `Portfolio`. Valor predeterminado: `Longbridge`.
- **Dirección de API** - propiedad `ApiUrl`. Valor predeterminado: `https://openapi.longbridge.com`.
- **Dirección de cotizaciones** - propiedad `QuoteUrl`. Valor predeterminado: `wss://openapi-quote.longbridge.com/v2`.
- **Dirección del servidor de negociación** - propiedad `TradeUrl`. Valor predeterminado: `wss://openapi-trade.longbridge.com/v2`.
