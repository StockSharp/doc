# Configuración gráfica: Fubon Neo

En todos los productos StockSharp, la conexión se configura en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

- `SdkPath` - ruta de un archivo o directorio local.
- `PersonalId` - identificador de cuenta o cliente.
- `Password` - credencial de autenticación.
- `ApiKey` - credencial de autenticación.
- `IsApiKeyLogin` - interruptor que controla el comportamiento del conector.
- `CertificatePath` - ruta de un archivo o directorio local.
- `CertificatePassword` - credencial de autenticación.
- `EnvironmentUrl` - dirección del servicio.
- `RealtimeMode` - modo u opción del conector. Valor predeterminado: `FubonNeoRealtimeModes.Normal`.
- `ReconnectAttempts` - parámetro numérico del conector. Valor predeterminado: `10`.
