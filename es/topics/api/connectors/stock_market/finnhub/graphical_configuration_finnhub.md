# Configuración gráfica Finnhub

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

- `Token` - token de acceso a la API.
- `Address` - dirección de la API REST.
- `WebSocketAddress` - dirección del servidor WebSocket.
- `StockExchange` - código de la bolsa de valores utilizado en las solicitudes.
- `ForexExchange` - código del mercado de divisas en Finnhub.
- `CryptoExchange` - código del mercado de criptomonedas en Finnhub.
