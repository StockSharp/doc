# Configuración gráfica: Mirae Asset Sharekhan

En todos los productos StockSharp, la conexión se configura en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

- `ApiKey` - credencial de autenticación.
- `Token` - credencial de autenticación.
- `VendorKey` - credencial de autenticación.
- `CustomerId` - identificador de cuenta o cliente.
- `DefaultProduct` - modo u opción del conector. Valor predeterminado: `MiraeSharekhanProducts.Investment`.
