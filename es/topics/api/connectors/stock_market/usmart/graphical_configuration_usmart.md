# Configuración gráfica uSMART OpenAPI

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

- `AccessToken` - token de acceso de OAuth.
- `ChannelId` - identificador del canal de conexión de uSMART.
- `PrivateKey` - clave privada utilizada para firmar transacciones.
- `FundAccount` - identificador de la cuenta de fondos de uSMART.
