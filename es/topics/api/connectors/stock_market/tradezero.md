# TradeZero

**TradeZero** es un bróker para operar con acciones estadounidenses y opciones de una sola pata.

El conector permite registrar, cancelar y sustituir órdenes, y obtener datos de cuentas, posiciones, órdenes actuales y pérdidas y ganancias. Las actualizaciones de cuenta se transmiten mediante WebSocket. Las cotizaciones, el libro de órdenes y las velas se devuelven como instantáneas REST finitas porque TradeZero no ofrece un WebSocket público de datos de mercado.

Antes de desarrollar robots de negociación para TradeZero, consulte los enlaces de la sección [Conectores](../../connectors.md).
