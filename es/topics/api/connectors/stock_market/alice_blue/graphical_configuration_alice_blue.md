# Configuración gráfica: Alice Blue

En todos los productos StockSharp, la conexión se configura en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

- `UserId` - identificador de cuenta o cliente.
- `ClientId` - identificador de cuenta o cliente.
- `Token` - credencial de autenticación.
- `DeviceId` - identificador de cuenta o cliente.
- `DefaultProduct` - modo u opción del conector. Valor predeterminado: `AliceBlueProducts.LongTerm`.
- `ReconnectAttempts` - parámetro numérico del conector. Valor predeterminado: `10`.
