# Configuración del conector DhanHQ

Obtenga las credenciales, direcciones de servidores e identificadores de cuenta necesarios para DhanHQ API v2 y especifique los siguientes ajustes del conector.

- **Identificador de cliente** - propiedad `ClientId`.
- **Token** - propiedad `Token`.
- **Producto predeterminado** - propiedad `DefaultProduct`. Valor predeterminado: `Intraday`.
