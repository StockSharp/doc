# SEC EDGAR

**SEC EDGAR** conecta StockSharp con los servicios oficiales de datos y presentaciones de SEC EDGAR.

## Funciones principales

- Funciones verificadas en el código fuente: búsqueda de empresas públicas, noticias de presentaciones, archivos históricos y datos estructurados mediante `SecEdgarDataTypes.CompanyFacts`. No admite operaciones de negociación.
- El transporte, las sesiones y los formatos del proveedor quedan ocultos tras la API estándar de StockSharp.

## Uso habitual

Utilice este conector para descubrir entidades registradas en la SEC y recopilar presentaciones, noticias y datos XBRL para análisis.

La cobertura y la disponibilidad siguen los datos de SEC EDGAR, sus reglas de acceso justo y los límites configurados.
