# Configuración del conector IG Markets

Obtenga las credenciales, direcciones de servidores e identificadores de cuenta necesarios para API REST y de transmisión de IG y especifique los siguientes ajustes del conector.

- **Clave de API** - propiedad `ApiKey`.
- **Nombre de usuario** - propiedad `UserName`.
- **Contraseña** - propiedad `Password`.
- **Identificador de cuenta** - propiedad `AccountId`.
- **Entorno** - propiedad `Environment`. Valor predeterminado: `Demo`.
- **Cifrar contraseña** - propiedad `EncryptPassword`.
