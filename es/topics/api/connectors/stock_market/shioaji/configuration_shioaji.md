# Configuración del conector: SinoPac Shioaji

Prepare la pasarela local o el cliente del proveedor e indique los parámetros de conexión.

- `Address` - dirección del servicio. Valor predeterminado: `http://localhost:8080/`.
- `Key` - credencial de autenticación.
- `Secret` - credencial de autenticación.
- `ReconnectAttempts` - parámetro numérico del conector. Valor predeterminado: `10`.
