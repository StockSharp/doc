# J-Quants

**J-Quants** conecta StockSharp con J-Quants API V2 para obtener datos de la Bolsa de Tokio.

## Funciones principales

- Funciones verificadas en el código fuente: búsqueda de acciones, futuros y opciones de TSE, valores de nivel 1, operaciones y velas históricas. El adaptador solo ofrece datos de mercado y no admite transacciones.
- El transporte, las sesiones y los formatos del proveedor quedan ocultos tras la API estándar de StockSharp.

## Uso habitual

Utilice este conector para descubrir instrumentos japoneses y descargar cotizaciones, operaciones y velas históricas para investigación y análisis.

La cobertura, la profundidad histórica, los límites y la disponibilidad dependen del plan de J-Quants.
