# MarketData.app

**MarketData.app** conecta StockSharp con MarketData.app para acciones, fondos, índices y opciones de Estados Unidos.

## Funciones principales

- Funciones verificadas en el código fuente: búsqueda de instrumentos y contratos de opciones, datos de nivel 1 y velas históricas con opciones de horario ampliado y ajuste por desdoblamientos. No admite operaciones de negociación.
- El transporte, las sesiones y los formatos del proveedor quedan ocultos tras la API estándar de StockSharp.

## Uso habitual

Utilice este conector para buscar instrumentos estadounidenses, obtener cotizaciones y descargar velas de acciones u opciones.

La cobertura, el retraso, la profundidad histórica, los límites de contratos y la disponibilidad dependen del plan de MarketData.app.
