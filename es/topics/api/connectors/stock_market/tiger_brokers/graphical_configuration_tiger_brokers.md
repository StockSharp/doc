# Configuración gráfica de Tiger Brokers

En todos los productos StockSharp, configure la conexión en la [ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md).

- **Identificador de Tiger** - propiedad `TigerId`.
- **Cuenta** - propiedad `Account`.
- **Licencia** - propiedad `License`. Valor predeterminado: `Singapore`.
- **Clave privada** - propiedad `PrivateKey`.
- **Token** - propiedad `Token`.
- **Obtener automáticamente el permiso de cotizaciones** - propiedad `AutoGrabPermission`. Valor predeterminado: `true`.
