# Configuración gráfica: Swissquote OpenWealth

En todos los productos StockSharp, la conexión se configura en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

- `Token` - credencial de autenticación.
- `CustomerId` - identificador de cuenta o cliente.
- `SafekeepingAccountId` - identificador de cuenta o cliente.
- `CashAccountId` - identificador de cuenta o cliente.
- `AccountCurrency` - parámetro de conexión. Valor predeterminado: `CHF`.
- `IsDemo` - interruptor que controla el comportamiento del conector. Valor predeterminado: `true`.
- `IsDryRun` - interruptor que controla el comportamiento del conector.
- `IsBestEffort` - interruptor que controla el comportamiento del conector.
