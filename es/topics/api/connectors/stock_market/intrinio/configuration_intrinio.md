# Configuración Intrinio

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `Token` - token de acceso a la API.
- `Address` - dirección de la API REST.
- `EquityProvider` - proveedor de datos de acciones de Intrinio.
- `OptionProvider` - proveedor de datos de opciones de Intrinio.
- `IsDelayedOptions` - indica si se utilizan datos de opciones con retraso.
