# Configuración ITCH

Para trabajar con un conector, debe especificar **usuario** y **contraseña**. **usuario** y **contraseña** los proporciona el bróker. Para obtener acceso API, se recomienda contactar con el bróker.

[ITCH](../itch.md) - protocolo de flujo de datos directo que permite conectarse mediante protocolos TCP y UDP. [ITCH](../itch.md) proporciona el registro de órdenes para rastrear todos los cambios de cualquier orden. Este protocolo lo usa NASDAQ (consulte [TotalView-ITCH](https://www.nasdaqtrader.com/Trader.aspx?id=Totalview2) ) y LSE (consulte [MITCH](https://www.londonstockexchange.com/) ).
