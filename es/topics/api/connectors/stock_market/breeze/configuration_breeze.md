# Configuración del conector ICICI Direct Breeze

Obtenga las credenciales, direcciones de servidores e identificadores de cuenta necesarios para ICICI Direct Breeze API y especifique los siguientes ajustes del conector.

- **Clave de API** - propiedad `ApiKey`.
- **Clave secreta** - propiedad `SecretKey`.
- **Sesión de API** - propiedad `ApiSession`.
