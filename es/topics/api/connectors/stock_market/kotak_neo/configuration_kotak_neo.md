# Configuración del conector Kotak Neo

Obtenga las credenciales, direcciones de servidores e identificadores de cuenta necesarios para API v2 de negociación Kotak Neo y especifique los siguientes ajustes del conector.

- **Clave de consumidor** - propiedad `ConsumerKey`.
- **Número de móvil** - propiedad `MobileNumber`.
- **Código de usuario** - propiedad `UserCode`.
- **MPIN** - propiedad `Mpin`.
- **Secreto TOTP** - propiedad `TotpSecret`.
- **Producto predeterminado** - propiedad `DefaultProduct`. Valor predeterminado: `Intraday`.
