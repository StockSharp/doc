# Configuración del conector: GLEIF

Configure las siguientes propiedades antes de conectarse a GLEIF. La lista se ha verificado con [GleifMessageAdapter](xref:StockSharp.Gleif.GleifMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Address` (`Uri`)

## Configuración avanzada

Estas propiedades controlan los puntos de conexión, filtros, límites y otras opciones específicas del proveedor.

- `ActiveOnly` (`bool`)
- `ExpandIsins` (`bool`)
- `PageSize` (`int`)
- `MaxPages` (`int`)
