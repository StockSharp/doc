# Configuración gráfica: Motilal Oswal

En todos los productos StockSharp, la conexión se configura en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

- `Key` - credencial de autenticación.
- `Secret` - credencial de autenticación.
- `Token` - credencial de autenticación.
- `AccessToken` - credencial de autenticación.
- `ClientCode` - identificador de cuenta o cliente.
- `LocalIp` - parámetro de conexión. Valor predeterminado: `127.0.0.1`.
- `PublicIp` - parámetro de conexión. Valor predeterminado: `127.0.0.1`.
- `MacAddress` - dirección del servicio. Valor predeterminado: `00:00:00:00:00:00`.
- `VendorInfo` - parámetro de conexión.
- `InstalledAppId` - identificador de cuenta o cliente.
- `IsDemo` - interruptor que controla el comportamiento del conector.
- `DefaultProduct` - modo u opción del conector. Valor predeterminado: `MotilalOswalProducts.Normal`.
- `AlgoId` - identificador de cuenta o cliente.
- `ReconnectAttempts` - parámetro numérico del conector. Valor predeterminado: `10`.
