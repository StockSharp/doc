# Configuración EOD Historical Data

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `Token` - token de acceso a la API.
- `Address` - dirección de la API REST.
- `StockTradeWebSocketAddress` - dirección del servidor WebSocket.
- `StockQuoteWebSocketAddress` - dirección del servidor WebSocket.
- `ForexWebSocketAddress` - dirección del servidor WebSocket.
- `CryptoWebSocketAddress` - dirección del servidor WebSocket.
- `StockExchange` - código de la bolsa de valores utilizado en las solicitudes.
