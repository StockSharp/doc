# Configuración del conector Questrade

Obtenga las credenciales, direcciones de servidores e identificadores de cuenta necesarios para Questrade API y especifique los siguientes ajustes del conector.

- **Token de acceso** - propiedad `AccessToken`.
- **Token de actualización** - propiedad `RefreshToken`.
- **Servidor de API** - propiedad `ApiServer`.
- **Cuenta** - propiedad `Account`.
