# Configuración del conector Moomoo

Obtenga las credenciales, direcciones de servidores e identificadores de cuenta necesarios para Moomoo OpenAPI y OpenD y especifique los siguientes ajustes del conector.

- **Dirección** - propiedad `Address`. Valor predeterminado: `127.0.0.1:11111`.
- **Contraseña** - propiedad `Password`.
- **Modo de demostración** - propiedad `IsDemo`. Valor predeterminado: `true`.
