# Configuración del conector Robinhood

Obtenga las credenciales, direcciones de servidores e identificadores de cuenta necesarios para negociación mediante agentes de Robinhood y especifique los siguientes ajustes del conector.

- **Token** - propiedad `Token`.
- **Dirección** - propiedad `Address`. Valor predeterminado: `https://agent.robinhood.com/mcp/trading`.
- **Intervalo de consulta** - propiedad `PollingInterval`. Valor predeterminado: `2 s`.
