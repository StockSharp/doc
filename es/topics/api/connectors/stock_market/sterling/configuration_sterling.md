# Configuración Sterling

Para trabajar con el conector **Sterling**, debe usar el terminal local **Sterling Trader Pro**, instalado directamente en el equipo desde el que se realizará la conexión. Para conectarse a **Sterling Trader Pro**, debe especificar **usuario** y **contraseña**.

![Inicio de sesión Sterling](../../../../../images/sterling_login.png)

**Sterling Trader Pro, usuario, contraseña** y la dirección del servidor los proporciona el bróker. Para obtener acceso API, se recomienda contactar con el bróker.

> [!TIP]
> Para que Sterling API funcione correctamente, debe ejecutar Visual Studio como administrador.
