# Configuración del conector Saxo OpenAPI

Obtenga las credenciales, direcciones de servidores e identificadores de cuenta necesarios para Saxo OpenAPI y especifique los siguientes ajustes del conector.

- **Token de acceso** - propiedad `AccessToken`.
- **Token de actualización** - propiedad `RefreshToken`.
- **Identificador de cliente** - propiedad `ClientId`.
- **Secreto del cliente** - propiedad `ClientSecret`.
- **URI de redirección** - propiedad `RedirectUri`.
- **Clave de cuenta** - propiedad `AccountKey`.
- **Entorno** - propiedad `Environment`. Valor predeterminado: `Simulation`.
