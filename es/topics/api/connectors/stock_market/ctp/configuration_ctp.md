# Configuración del conector CTP

Obtenga las credenciales, direcciones de servidores e identificadores de cuenta necesarios para API de negociación y datos de mercado CTP y especifique los siguientes ajustes del conector.

- **Nombre de usuario** - propiedad `Login`.
- **Contraseña** - propiedad `Password`.
- **Identificador del bróker** - propiedad `BrokerId`.
- **Identificador del inversor** - propiedad `InvestorId`.
- **Dirección de datos de mercado** - propiedad `MarketDataAddress`.
- **Dirección del servidor de negociación** - propiedad `TraderAddress`.
- **Identificador de aplicación** - propiedad `AppId`.
- **Código de autenticación** - propiedad `AuthCode`.
- **Información del producto** - propiedad `ProductInfo`. Valor predeterminado: `StockSharp`.
- **Modo de recuperación** - propiedad `ResumeType`. Valor predeterminado: `Quick`.
- **Modo de producción** - propiedad `ProductionMode`. Valor predeterminado: `true`.
- **Directorio de datos** - propiedad `DataPath`.
- **Intervalo de consultas** - propiedad `QueryInterval`. Valor predeterminado: `1 s`.
- **Tiempo de espera de conexión** - propiedad `ConnectionTimeout`. Valor predeterminado: `30 s`.
