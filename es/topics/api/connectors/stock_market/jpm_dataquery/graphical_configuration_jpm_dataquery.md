# Configuración gráfica J.P. Morgan DataQuery

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

- `ClientId` - identificador del cliente de OAuth.
- `ClientSecret` - secreto del cliente de OAuth.
- `GroupId` - identificador del grupo de DataQuery.
- `Attribute` - atributo de DataQuery que se va a solicitar.
