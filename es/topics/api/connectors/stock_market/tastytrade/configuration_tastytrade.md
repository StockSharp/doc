# Configuración del conector tastytrade

Obtenga las credenciales, direcciones de servidores e identificadores de cuenta necesarios para tastytrade Open API y especifique los siguientes ajustes del conector.

- **Token** - propiedad `Token`.
- **Secreto del cliente** - propiedad `ClientSecret`.
- **Ámbitos de acceso** - propiedad `Scopes`.
- **Modo de demostración** - propiedad `IsDemo`.
