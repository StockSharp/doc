# Configuración del conector: TWSE

Configure las siguientes propiedades antes de conectarse a TWSE. La lista se ha verificado con [TwseMessageAdapter](xref:StockSharp.Twse.TwseMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Address` (`Uri`)

## Configuración avanzada

Estas propiedades controlan los puntos de conexión, filtros, límites y otras opciones específicas del proveedor.

- `IncludeProfiles` (`bool`)
- `IncludeValuations` (`bool`)
- `CacheTimeout` (`TimeSpan`)
