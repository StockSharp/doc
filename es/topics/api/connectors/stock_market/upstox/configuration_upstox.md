# Configuración del conector Upstox

Obtenga las credenciales, direcciones de servidores e identificadores de cuenta necesarios para Upstox API v3 y especifique los siguientes ajustes del conector.

- **Token** - propiedad `Token`.
- **Modo de demostración** - propiedad `IsDemo`.
- **Producto predeterminado** - propiedad `DefaultProduct`. Valor predeterminado: `Delivery`.
