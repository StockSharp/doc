# Configuración gráfica de TradeZero

En todos los productos StockSharp, configure la conexión en la [ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md).

- **Clave** - el identificador de la clave de API de TradeZero.
- **Secreto** - el secreto de API de TradeZero.
- **Ruta predeterminada** - la ruta de órdenes preferida. Déjela vacía para seleccionar automáticamente una ruta compatible.
