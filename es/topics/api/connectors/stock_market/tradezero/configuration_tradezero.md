# Configuración del conector TradeZero

Cree credenciales de API en el portal de TradeZero e indíquelas en la configuración del conector.

- **Clave** - el valor `TZ-API-KEY-ID`.
- **Secreto** - el valor `TZ-API-SECRET-KEY`.
- **Ruta predeterminada** - una ruta de órdenes preferida y opcional devuelta por el punto de acceso de rutas de la cuenta.

Si la ruta predeterminada está vacía, el conector selecciona automáticamente una ruta activa compatible. Las cuentas de demostración y reales utilizan el mismo servidor de API; las credenciales determinan el entorno de la cuenta.
