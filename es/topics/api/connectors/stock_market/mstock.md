# m.Stock

**m.Stock** conecta StockSharp con m.Stock API para los mercados indios al contado y de derivados.

## Funciones principales

- Funciones verificadas en el código fuente: búsqueda de instrumentos, cotizaciones de nivel 1, libros de órdenes y operaciones en tiempo real, velas históricas, además de operaciones de cartera y órdenes para acciones, futuros y opciones.
- El transporte, las sesiones y los formatos del proveedor quedan ocultos tras la API estándar de StockSharp.

## Uso habitual

Utilice este conector para supervisar instrumentos indios, analizar cotizaciones, libros de órdenes y velas, solicitar datos históricos y ejecutar los flujos de órdenes admitidos.

Las bolsas, los instrumentos, la profundidad histórica, los permisos y los límites dependen de m.Stock y de la cuenta conectada.
