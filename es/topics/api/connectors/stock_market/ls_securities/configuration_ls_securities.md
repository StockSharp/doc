# Configuración del conector: LS Securities

Obtenga las credenciales del proveedor e indique los parámetros de conexión.

- `AppKey` - credencial de autenticación.
- `AppSecret` - credencial de autenticación.
- `Account` - identificador de cuenta o cliente.
- `IsDemo` - interruptor que controla el comportamiento del conector. Valor predeterminado: `true`.
