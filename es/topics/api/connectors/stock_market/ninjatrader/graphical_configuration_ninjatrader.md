# Configuración gráfica de NinjaTrader

En todos los productos StockSharp, configure la conexión en la [ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md).

- **Nombre de usuario** - propiedad `Login`.
- **Contraseña** - propiedad `Password`.
- **Identificador de cliente** - propiedad `ClientId`.
- **Secreto** - propiedad `Secret`.
- **Identificador de aplicación** - propiedad `AppId`. Valor predeterminado: `StockSharp`.
- **Versión de la aplicación** - propiedad `AppVersion`. Valor predeterminado: `1.0`.
- **Identificador del dispositivo** - propiedad `DeviceId`.
- **Modo de demostración** - propiedad `IsDemo`.
