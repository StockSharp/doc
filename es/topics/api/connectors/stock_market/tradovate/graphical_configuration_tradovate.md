# Configuración gráfica de Tradovate

En todos los productos StockSharp, configure la conexión en la [ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md).

- **Nombre de usuario** - el nombre de usuario de Tradovate.
- **Contraseña** - la contraseña de Tradovate.
- **Identificador de cliente** - el identificador del cliente de API.
- **Secreto** - el secreto del cliente de API.
- **Identificador de aplicación** - el identificador registrado de la aplicación.
- **Versión de la aplicación** - la versión registrada de la aplicación.
- **Identificador del dispositivo** - el identificador estable del dispositivo.
- **Modo de demostración** - utilizar el entorno de simulación.
