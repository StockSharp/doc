# Configuración del conector Tradovate

Registre una aplicación de API en Tradovate e indique sus credenciales en la configuración del conector.

- **Nombre de usuario** - el nombre de usuario de Tradovate.
- **Contraseña** - la contraseña de Tradovate.
- **Identificador de cliente** - el identificador del cliente de API (`cid`).
- **Secreto** - el secreto del cliente de API (`sec`).
- **Identificador de aplicación** - el identificador registrado de la aplicación. El valor predeterminado es `StockSharp`.
- **Versión de la aplicación** - la versión registrada de la aplicación. El valor predeterminado es `1.0`.
- **Identificador del dispositivo** - un identificador estable del dispositivo registrado para acceder a la API. El conector lo genera y guarda automáticamente.
- **Modo de demostración** - conectarse al entorno de simulación de Tradovate en lugar del entorno real.
