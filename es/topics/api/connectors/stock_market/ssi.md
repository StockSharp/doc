# SSI

**SSI** conecta StockSharp con SSI FastConnect API v3 para los mercados vietnamitas HOSE, HNX y UPCOM.

## Funciones principales

- Funciones verificadas en el código fuente: cotizaciones de nivel 1, libros de órdenes y operaciones en tiempo real, velas y solicitudes históricas, además de operaciones de cartera y órdenes para acciones y futuros.
- El transporte, las sesiones y los formatos del proveedor quedan ocultos tras la API estándar de StockSharp.

## Uso habitual

Utilice este conector para supervisar instrumentos vietnamitas, analizar datos de mercado, solicitar datos históricos y ejecutar los flujos de negociación admitidos.

Los instrumentos disponibles, la profundidad histórica, los permisos de negociación, los límites y la disponibilidad dependen de SSI y de la cuenta conectada.
