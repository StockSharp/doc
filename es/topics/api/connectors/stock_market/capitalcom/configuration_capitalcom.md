# Configuración del conector: Capital.com

Obtenga las credenciales del proveedor e indique los parámetros de conexión.

- `ApiKey` - credencial de autenticación.
- `Login` - identificador de cuenta o cliente.
- `Password` - credencial de autenticación.
- `AccountId` - identificador de cuenta o cliente.
- `IsDemo` - interruptor que controla el comportamiento del conector. Valor predeterminado: `true`.
- `IsPasswordEncryptionEnabled` - interruptor que controla el comportamiento del conector.
