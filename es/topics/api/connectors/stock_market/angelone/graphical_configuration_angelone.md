# Configuración gráfica de Angel One

En todos los productos StockSharp, configure la conexión en la [ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md).

- **Nombre de usuario** - propiedad `Login`.
- **Contraseña** - propiedad `Password`.
- **Clave de API** - propiedad `ApiKey`.
- **Secreto TOTP** - propiedad `TotpSecret`.
- **Dirección IP local del cliente** - propiedad `ClientLocalIp`. Valor predeterminado: `127.0.0.1`.
- **Dirección IP pública del cliente** - propiedad `ClientPublicIp`.
- **Dirección MAC** - propiedad `MacAddress`.
- **Producto predeterminado** - propiedad `DefaultProduct`. Valor predeterminado: `Delivery`.
