# Configuración del conector Lime

Obtenga las credenciales, direcciones de servidores e identificadores de cuenta necesarios para API de Lime y especifique los siguientes ajustes del conector.

- **Nombre de usuario** - propiedad `Login`.
- **Contraseña** - propiedad `Password`.
- **Identificador de cliente** - propiedad `ClientId`.
- **Secreto del cliente** - propiedad `ClientSecret`.
