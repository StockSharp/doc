# Configuración del conector: ESMA FIRDS

Configure las siguientes propiedades antes de conectarse a ESMA FIRDS. La lista se ha verificado con [EsmaFirdsMessageAdapter](xref:StockSharp.EsmaFirds.EsmaFirdsMessageAdapter).

## Configuración básica

El editor de conexiones muestra primero estos parámetros.

- `Address` (`Uri`)

## Configuración avanzada

Estas propiedades controlan los puntos de conexión, filtros, límites y otras opciones específicas del proveedor.

- `CfiCategories` (`string`)
- `ActiveOnly` (`bool`)
- `MaxResults` (`int`)
