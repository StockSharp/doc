# Configuración del conector Webull

Cree una aplicación en [Webull OpenAPI](https://developer.webull.com/apis/docs/) y obtenga sus credenciales.

- **Clave** — la clave de la aplicación Webull OpenAPI.
- **Secreto** — el secreto de la aplicación.
- **Token de acceso** — un token de acceso opcional.
- **Cuenta** — el identificador de la cuenta de negociación. Si se omite, el conector solicita automáticamente la lista de cuentas.
- **Modo de demostración** — uso del entorno de pruebas de Webull.

Los parámetros `Token` y `Account` pueden omitirse si no son necesarios para su aplicación y cuenta de Webull.
