# Configuración RavenPack

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `Token` - token de acceso a la API.
- `Product` - producto de RavenPack que se solicitará.
- `DatasetId` - identificador del conjunto de datos solicitado.
- `Address` - dirección de la API REST.
- `FeedAddress` - punto de acceso del flujo de noticias en tiempo real.
