# Configuración del conector: IQFeed

Prepare la pasarela local o el cliente del proveedor e indique los parámetros de conexión.

- `Login` - identificador de cuenta o cliente.
- `Password` - credencial de autenticación.
- `Level1Address` - dirección del servicio.
- `Level2Address` - dirección del servicio.
- `LookupAddress` - dirección del servicio.
- `AdminAddress` - dirección del servicio.
- `DerivativeAddress` - dirección del servicio.
- `Level1Columns` - parámetro de conexión.
- `IsDownloadSecurityFromSite` - interruptor que controla el comportamiento del conector.
- `SecuritiesFile` - ruta de un archivo o directorio local.
- `Version` - parámetro de conexión. Valor predeterminado: `6.2`.
