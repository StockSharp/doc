# Configuración del conector: Groww

Obtenga las credenciales del proveedor e indique los parámetros de conexión.

- `AccessToken` - credencial de autenticación.
- `ApiKey` - credencial de autenticación.
- `ApiSecret` - credencial de autenticación.
- `TotpSecret` - credencial de autenticación.
- `DefaultProduct` - modo u opción del conector. Valor predeterminado: `GrowwProducts.Delivery`.
