# Configuración del conector TradeStation

Obtenga las credenciales, direcciones de servidores e identificadores de cuenta necesarios para TradeStation API v3 y especifique los siguientes ajustes del conector.

- **Token** - propiedad `Token`.
- **Modo de demostración** - propiedad `IsDemo`.
- **Ruta predeterminada** - propiedad `DefaultRoute`. Valor predeterminado: `Intelligent`.
