# Configuración gráfica de Zhongtai XTP

En todos los productos StockSharp, configure la conexión en la [ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md).

- **Nombre de usuario** - propiedad `Login`.
- **Contraseña** - propiedad `Password`.
- **Identificador de cliente** - propiedad `ClientId`. Valor predeterminado: `1`.
- **Dirección de cotizaciones** - propiedad `QuoteAddress`.
- **Dirección del servidor de negociación** - propiedad `TransactionAddress`.
- **Protocolo** - propiedad `Protocol`. Valor predeterminado: `TCP`.
- **Dirección local** - propiedad `LocalAddress`.
- **Clave del software** - propiedad `SoftwareKey`.
- **Versión del software** - propiedad `SoftwareVersion`. Valor predeterminado: `1.0`.
- **Directorio de datos** - propiedad `DataPath`.
