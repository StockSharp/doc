# Configuración Dow Jones

Indique en la configuración del conector los parámetros de conexión proporcionados por el servicio.

## Parámetros de conexión

- `AuthenticationMode` - método de autenticación.
- `Token` - token de acceso a la API.
- `ClientId` - identificador del cliente de OAuth.
- `Login` - nombre de usuario de la cuenta.
- `Password` - contraseña de la cuenta.
- `Address` - dirección de la API REST.
- `OAuthAddress` - punto de acceso del servicio OAuth.
