# Configuración del conector: kabu Station

Prepare la pasarela local o el cliente del proveedor e indique los parámetros de conexión.

- `ApiPassword` - credencial de autenticación.
- `IsDemo` - interruptor que controla el comportamiento del conector. Valor predeterminado: `true`.
- `DefaultAccountType` - modo u opción del conector. Valor predeterminado: `KabuStationAccountTypes.Specified`.
- `DefaultStockOrderExchange` - parámetro de conexión. Valor predeterminado: `KabuStationExchanges.Sor`.
