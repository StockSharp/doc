# Configuración gráfica: QMT

En todos los productos StockSharp, la conexión se configura en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

- `GatewayHost` - dirección del servicio. Valor predeterminado: `127.0.0.1`.
- `GatewayPort` - parámetro numérico del conector. Valor predeterminado: `58630`.
- `GatewayToken` - credencial de autenticación.
- `ReconnectAttempts` - parámetro numérico del conector. Valor predeterminado: `10`.
- `RequestTimeout` - intervalo de tiempo. Valor predeterminado: `30`.
