# Configuración del conector: Zerodha Kite Connect

Obtenga las credenciales del proveedor e indique los parámetros de conexión.

- `ApiKey` - credencial de autenticación.
- `ApiSecret` - credencial de autenticación.
- `Token` - credencial de autenticación.
- `RequestToken` - credencial de autenticación.
- `DefaultProduct` - modo u opción del conector. Valor predeterminado: `ZerodhaProducts.Intraday`.
