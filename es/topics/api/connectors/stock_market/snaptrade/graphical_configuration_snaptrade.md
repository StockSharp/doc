# Configuración gráfica: SnapTrade

En todos los productos StockSharp, la conexión se configura en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

- `ClientId` - identificador de cuenta o cliente.
- `ConsumerKey` - credencial de autenticación.
- `UserId` - identificador de cuenta o cliente.
- `UserSecret` - credencial de autenticación.
- `AccountId` - identificador de cuenta o cliente.
- `PollingInterval` - intervalo de tiempo. Valor predeterminado: `TimeSpan.FromMinutes(1)`.
