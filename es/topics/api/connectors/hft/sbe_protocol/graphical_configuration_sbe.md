# Configuración gráfica de SBE

En los productos StockSharp, configure la conexión SBE en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

- `Address` - extremo TCP del servidor SBE.
- `SenderCompId` - identificador del cliente.
- `TargetCompId` - identificador del servidor de destino.
- `Password` - credencial de autenticación.
- `IsSupportNativeCandles` - habilita las suscripciones a velas nativas.
