# Configuración FIX

El conector utiliza una conexión directa que requiere una **VPN** o un **canal cifrado**.

Para trabajar con un conector, es necesario especificar el **usuario** y la **contraseña**. El **usuario** y la **contraseña** son proporcionados por el bróker. Para obtener acceso a la API se recomienda contactar al bróker.
