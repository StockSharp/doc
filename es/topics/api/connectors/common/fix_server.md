# Servidor FIX

[FixServer](xref:StockSharp.Server.Fix.FixServer) le permite crear sus propios servidores FIX que utilizan los protocolos internacionales [FIX](https://en.wikipedia.org/wiki/Financial_Information_eXchange)\/[FAST](https://en.wikipedia.org/wiki/FAST_protocol). Utiliza FIX 4.4 para las transacciones y FAST para los datos de mercado. El esquema del servidor se muestra en la siguiente figura:
