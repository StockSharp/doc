# Configuración gráfica: Sierra Chart DTC

En todos los productos StockSharp, la conexión se configura en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

- `Address` - dirección del servicio. Valor predeterminado: `DefaultAddress`.
- `HistoryAddress` - dirección del servicio. Valor predeterminado: `DefaultHistoryAddress`.
- `Login` - identificador de cuenta o cliente.
- `Password` - credencial de autenticación.
- `TradeAccount` - identificador de cuenta o cliente.
- `MarketDataTransmissionInterval` - intervalo de tiempo.
- `MarketDepthLevels` - parámetro numérico del conector. Valor predeterminado: `20`.
- `SslProtocol` - modo u opción del conector.
- `HistorySslProtocol` - modo u opción del conector.
- `IsCertificateValidation` - interruptor que controla el comportamiento del conector. Valor predeterminado: `true`.
- `TargetHost` - dirección del servicio.
