# Configuración gráfica RSS

Para todos los productos [S#](../../../../api.md), la configuración gráfica de la conexión se realiza en la [Ventana de configuración de conexión](../../../graphical_user_interface/connection_settings_window.md):

![Configuración de API GUI RSS](../../../../../images/api_gui_settings_rss.png)

- **dirección** - Dirección de la fuente RSS.
- **Formato de fechas** - Formato de fechas. Requerido si el formato del stream RSS es diferente de `ddd, dd MMM yyyy HH:mm:ss zzzz`.
- **Intervalo de comprobación** - Intervalo de verificación del servidor para comprobar que la conexión sigue activa. Por defecto es igual a 1 minuto.
- **Configuración de reconexión** - Mecanismo de configuración para el seguimiento de conexiones con el sistema de negociación. ([Configuración de reconexión](../../reconnection_settings.md))
