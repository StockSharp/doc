# Configuración gráfica: API de negociación de Finam

En todos los productos StockSharp, configure la conexión en la [ventana de configuración de conexiones](../../../graphical_user_interface/connection_settings_window.md).

La sección básica del editor de conexiones contiene:

- `Token`
- `AccountId`

En la vista avanzada se configuran `AppId`, `PollingInterval`, `LookupLimit`, `RestAddress` y `WebSocketAddress`. La función y el valor predeterminado de cada campo se describen en la página de [Configuración del conector](configuration_finam_trade.md).

No se incluye una captura específica del conector porque su código fuente no contiene una captura real del producto. Utilice la lista de campos anterior y la ventana estándar de configuración de conexiones.
