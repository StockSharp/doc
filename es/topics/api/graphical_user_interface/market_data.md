# Datos de mercado

En [S#](../../api.md) hay componentes gráficos para mostrar todo tipo de datos de mercado:

- Tabla para mostrar velas \- [CandleMessageGrid](xref:StockSharp.Xaml.CandleMessageGrid).
- Tabla para mostrar operaciones - [TradeGrid](xref:StockSharp.Xaml.TradeGrid).
- Tabla para mostrar Level1 - [Level1Grid](xref:StockSharp.Xaml.Level1Grid).
- Componente para mostrar un libro de órdenes - [MarketDepthControl](xref:StockSharp.Xaml.MarketDepthControl).
- Tabla para mostrar un registro de órdenes - [OrderLogGrid](xref:StockSharp.Xaml.OrderLogGrid).
- Tablas para mostrar noticias - [NewsGrid](xref:StockSharp.Xaml.NewsGrid), [NewsPanel](xref:StockSharp.Xaml.NewsPanel).
- Tabla para mostrar noticias como mensajes \- [NewsMessageGrid](xref:StockSharp.Xaml.NewsMessageGrid).
- Tabla para mostrar transacciones y operaciones \- [ExecutionGrid](xref:StockSharp.Xaml.ExecutionGrid).
