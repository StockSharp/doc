# Paneles de servicio

Esta sección reúne los paneles que no muestran datos de mercado sino que configuran el funcionamiento de la aplicación: catálogos, ajustes de almacenamiento e importación, licencias, cuentas y suscripciones.

- Reglas de comisión \- [CommissionPanel](xref:StockSharp.Xaml.CommissionPanel).
- Ajustes de importación \- [ImportSettingsPanel](xref:StockSharp.Xaml.ImportSettingsPanel).
- Licencias \- [LicensePanel](xref:StockSharp.Xaml.LicensePanel).
- Búsqueda de instrumentos \- [SecurityLookupPanel](xref:StockSharp.Xaml.SecurityLookupPanel).
- Correspondencia de códigos de instrumentos \- [SecurityMappingPanel](xref:StockSharp.Xaml.SecurityMappingPanel).
- Ajustes del almacenamiento \- [StorageSettingsPanel](xref:StockSharp.Xaml.StorageSettingsPanel).
- Suscripciones \- [SubscriptionPanel](xref:StockSharp.Xaml.SubscriptionPanel).
- Bolsas \- [ExchangesPanel](xref:StockSharp.Xaml.ExchangesPanel).
- Plazas \- [ExchangeBoardsPanel](xref:StockSharp.Xaml.ExchangeBoardsPanel).
- Horario de funcionamiento \- [WorkingTimeControl](xref:StockSharp.Xaml.WorkingTimeControl).
- Cuentas y permisos \- [PermissionCredentialsPanel](xref:StockSharp.Xaml.PermissionCredentialsPanel).
