# Temas de los componentes gráficos de S#

Para todos los elementos gráficos de S#, existen varios temas distintos. A continuación se muestran los dos temas más populares.

![API GUI Thems 01](../../../images/api_gui_thems_01.png)

![API GUI Thems 02](../../../images/api_gui_thems_02.png)

Para instalar el tema de la aplicación, basta con escribir una línea. Por ejemplo, para establecer el tema oscuro VisualStudio 2017, debe especificar la línea:

```cs
...
ThemeExtensions.ApplyDefaultTheme();
...
```

Dado que todos los elementos gráficos de S# se basan en elementos gráficos de **DevExpress**, debe agregar las bibliotecas **DevExpress** correspondientes (**DevExpress.Xpf.Core**, **DevExpress.Xpf.Themes.VS2017Dark**, etc.)
