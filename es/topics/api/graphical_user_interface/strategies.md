# Estrategias

Esta sección contiene los componentes que se usan al trabajar con estrategias.

- Tabla para mostrar las estadísticas de la estrategia - [StrategiesStatisticsPanel](xref:StockSharp.Xaml.StrategiesStatisticsPanel).
- Tabla de estrategias en ejecución simultánea \- [StrategiesDashboard](xref:StockSharp.Xaml.StrategiesDashboard).
- Editor de los parámetros de optimización \- [OptimizationParametersPanel](xref:StockSharp.Xaml.OptimizationParametersPanel).
- Resultados de la optimización \- [OptimizationResultsPanel](xref:StockSharp.Xaml.Charting.OptimizationResultsPanel).
