# Instrumentos

[S#](../../api.md) ofrece un amplio conjunto de componentes gráficos para trabajar con instrumentos. Este conjunto incluye:

- El componente para crear el instrumento - [SecurityCreateWindow](xref:StockSharp.Xaml.SecurityCreateWindow). 
- El componente para mostrar información financiera del instrumento - [SecurityGrid](xref:StockSharp.Xaml.SecurityGrid). 
- Componentes para buscar y seleccionar instrumentos - [SecurityPicker](xref:StockSharp.Xaml.SecurityPicker), [SecurityPickerWindow](xref:StockSharp.Xaml.SecurityPickerWindow) y [SecurityEditor](xref:StockSharp.Xaml.PropertyGrid.SecurityEditor). 
- Componentes para crear instrumentos continuos e índices - [ContinuousSecurityWindow](xref:StockSharp.Xaml.ContinuousSecurityWindow) y [IndexSecurityWindow](xref:StockSharp.Xaml.IndexSecurityWindow).
