# Installer

**Installer** es el centro de control para todos los programas y aplicaciones de **StockSharp**. Permite:

- Descargar e instalar [Designer](designer.md), [Terminal](terminal.md), [Hydra](hydra.md)
- Instalar plugins de conectores como [MetaTrader](api/connectors/forex/metatrader.md)
- Comprar e instalar componentes de pago como [Shell](shell.md), [MATLAB](matlab.md)
- Comprar y descomprimir el código fuente de programas como [Designer](designer.md).
- Instalar programas junto con conectores comprados
- Supervisar el proceso de actualización del programa
- Descargar la biblioteca [API](api.md) y seguir automáticamente sus actualizaciones
