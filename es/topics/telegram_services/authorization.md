# Autorización

Para activar [StockSharpBot](https://t.me/StockSharpBot), debe iniciarlo y completar la autorización para que el bot pueda reconocer su login en el sitio web de StockSharp. Para ello, seleccione el comando **/login** en el menú:

![Captura de Autorización 1](../../images/telegramactivating.png)

El bot le pedirá visitar su perfil en [https://stocksharp.com/es/profile/](https://stocksharp.com/es/profile/) y copiar el token desde allí.

![Perfil](../../images/profile.png)

Después, envíelo de vuelta al bot en el chat en el formato **token: %your_token%**. Si todo va bien, el bot se dirigirá a usted por el nombre que usó para registrarse en el sitio web de StockSharp.

![Captura de Autorización 2](../../images/telegramactivated.png)
