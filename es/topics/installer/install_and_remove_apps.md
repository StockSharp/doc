# Instalar y eliminar aplicaciones

El programa [Installer](../installer.md) permite seleccionar el tipo de aplicación para encontrar el producto que necesita.

![choose installer](../../images/choose_installer.png)

Para instalar la aplicación requerida, debe:

1. Seleccionar una aplicación, hacer clic en **Install**, aceptar el contrato de licencia y hacer clic en **Continue**.![download installer](../../images/download_installer.png)
2. Después debe seleccionar la ruta de instalación.

   **¡IMPORTANTE\!** La carpeta en la que se instalará el programa debe estar vacía.

   Haga clic en **Continue**.![direction installer](../../images/direction_installer.png)
3. Seleccione **Run** y espere a que finalice la instalación.

Cuando la instalación finaliza, el programa está listo para usarse.

Para desinstalar el programa, seleccione **Uninstall** y haga clic en el botón **Continue**.

![del installer](../../images/del_installer.png)

Para restaurar, seleccione **Restore** y haga clic en **Continue**.

![repair installer](../../images/repair_installer.png)
