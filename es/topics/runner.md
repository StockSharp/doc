# Runner

**Runner** es una aplicación para lanzar estrategias escritas para la plataforma StockSharp. Proporciona:

- Multiplataforma: puede ejecutarse tanto en sistemas Windows como Linux.

- Integración con [Telegram](telegram_services.md), lo que permite controlar remotamente la actividad de trading.

- Consumo mínimo de recursos del ordenador gracias a la ausencia de una interfaz gráfica pesada.

- Lanzamiento de estrategias desde código C#, esquemas de [Designer](designer.md) o ensamblados DLL preparados.

- Ejecución de estrategias en modo de trading real o en pruebas históricas con datos históricos.
