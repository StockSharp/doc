# Recursos para el aprendizaje

Esta documentación está pensada para familiarizarle con los recursos clave que StockSharp proporciona para aprender y trabajar con el programa "Designer". Estos materiales ayudan a los usuarios a empezar rápidamente y a usar el programa de forma eficaz.

## Vídeos educativos

En el canal de YouTube de StockSharp puede encontrar vídeos tutoriales que muestran cómo trabajar con "Designer", incluyendo la configuración de parámetros, la creación de estrategias y sus pruebas.

- **Lista de reproducción "Designer" en YouTube**: [Ver lista de reproducción](https://www.youtube.com/playlist?list=PLpwmSw294KYrfM1ALrONIz9MLpRQ1Uwfe)

## Ejemplos de estrategias

La galería de estrategias del sitio web oficial de StockSharp contiene distintas estrategias de trading desarrolladas con "Designer". Estos ejemplos pueden servir como un excelente punto de partida para crear sus propias estrategias.

- **Galería de estrategias "Designer"**: [Visitar la galería de estrategias](strategy_gallery.md)

## Repositorio de GitHub

Los códigos fuente de estrategias y otros componentes usados en "Designer" están disponibles en GitHub. Este recurso es ideal para estudiar ejemplos de código y adaptarlos a sus necesidades.

- **Repositorio StockSharp en GitHub**: [Visitar el repositorio](https://github.com/StockSharp/algotrading)

## Chat de soporte

Para interactuar con otros usuarios y obtener ayuda rápida sobre el uso de "Designer", únase a nuestro chat en Telegram.

- **Chat "Designer" en Telegram**: [Unirse al chat](https://t.me/stocksharpchat/361)

Estos recursos proporcionan todo lo necesario para aprender y usar eficazmente el programa "Designer". Recomendamos aprovechar todos los materiales proporcionados para lograr los mejores resultados en trading.
