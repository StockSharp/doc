# Operaciones tick

El componente **Trades feed** es una tabla con operaciones que muestra información completa sobre todas las operaciones de los instrumentos seleccionados.

El **Trades feed** tiene un filtro para seleccionar los instrumentos necesarios. También puede configurar notificaciones para eventos relacionados con los instrumentos seleccionados en la ventana [Configuración de notificaciones](../../../terminal/notifications.md).
