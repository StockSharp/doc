# Panel de logs

Para simplificar el monitoreo del funcionamiento del programa, existe un panel especial **Logs**. Este panel muestra mensajes de todas las fuentes, estrategias y conexiones. En el panel **Logs**, la anidación de fuentes se muestra como un árbol. Cada nodo padre contiene mensajes de todas las fuentes anidadas, y así sucesivamente hasta el nivel más bajo. Para las estrategias, esta jerarquía permite ver estrategias hijas. Para abrir el panel **Logs**, debe pulsar el botón **Logs** en la pestaña **Common**.
