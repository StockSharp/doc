# Panel de registros

Para simplificar el monitoreo del funcionamiento del programa, existe un panel especial **Registros**. Este panel muestra mensajes de todas las fuentes, estrategias y conexiones. En el panel **Registros**, la anidación de fuentes se muestra como un árbol. Cada nodo padre contiene mensajes de todas las fuentes anidadas, y así sucesivamente hasta el nivel más bajo. Para las estrategias, esta jerarquía permite ver estrategias hijas. Para abrir el panel **Registros**, debe pulsar el botón **Registros** en la pestaña **Común**.
