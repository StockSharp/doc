# Importar

Designer permite importar cualquier tipo de dato: estrategias, bloques e indicadores. Hay varias formas de importar:

- En el panel **Schemes**, haga clic con el botón derecho en la carpeta de estrategias y, en el menú que aparece, seleccione **Import**.
- En la pestaña **Common**, pulse el botón **Import** y, en el menú que aparece, seleccione **Strategy**, **Own element** o **Indicator**:

![Designer Import strategies 00](../../../images/designer_import_strategies_00.png)

Si ya existen datos con el mismo nombre, aparecerá una ventana que ofrece sobrescribirlos o añadirlos con otro nombre:

![Designer Import strategies 01](../../../images/designer_import_strategies_01.png)
