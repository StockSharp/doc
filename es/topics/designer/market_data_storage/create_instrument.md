# Crear instrumento

Al hacer clic en el botón **Crear instrumento** ![Designer botón Añadir 00](../../../images/designer_creation_tool_00.png), se abre la ventana **Edición**. Para crear un instrumento, debe rellenar sus propiedades y hacer clic en el botón **Aceptar**:

![Designer botón Añadir 01](../../../images/designer_creation_tool_01.png)

Los instrumentos de distintas fuentes tienen identificadores unificados. Esto se hace para que el código del robot de negociación no dependa del tipo de conexión ([Conectores](../../api/connectors.md)). Para el identificador del instrumento se usa la siguiente sintaxis: **\[código del instrumento\]@\[código del mercado\]**. Por ejemplo, para las acciones de Apple en la bolsa NASDAQ el identificador será **AAPL@NASDAQ**.
