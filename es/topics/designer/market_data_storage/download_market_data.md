# Descargar datos de mercado

Para obtener los datos históricos del instrumento, seleccione el instrumento requerido en la lista **All securities** y muévalo a la lista de instrumentos **Active**. Defina el período de datos históricos, seleccione el tipo y Time Frame para las velas y haga clic en el botón **Start**. Todos los datos se guardarán en el [Almacenamiento de datos de mercado](../market_data_storage.md).
