# Lenguajes de programación

[Designer](../../designer.md) admite tres lenguajes de programación para crear estrategias de trading:

- [C#](using_code/csharp.md)
- [F#](using_code/fsharp.md) 
- [Python](using_code/python.md)

Hay ejemplos extensos de estrategias en C# y Python disponibles en la [carpeta AlgoTrading API](https://github.com/StockSharp/AlgoTrading/tree/main/API). Todos funcionan con [Designer](../../designer.md).

## C#

C# es el lenguaje principal para desarrollar estrategias de trading. Todos los componentes, ejemplos y código central están escritos en C#. C# proporciona acceso completo a toda la arquitectura de la plataforma [S#](../../api.md).

## F#

F# es un lenguaje de programación funcional de Microsoft. Las estrategias de trading en F# tienen acceso completo a todas las capacidades de la API y pueden usarse tanto para pruebas como para trading en vivo.

## Python 

La integración con Python permite escribir estrategias de trading usando el lenguaje de programación Python, facilitando el trabajo con la plataforma a los desarrolladores de Python.
