# Uso de Visual Studio o Rider

Al usar **Visual Studio** y **JetBrains Rider** para crear código que se ejecutará en **Designer**, la única opción es la [importación de archivos](../../../export_import/import.md) constante. Esto se debe a la estructura especial de los archivos creados por **Designer**, que hace imposible modificarlos directamente, incluso en el caso de estrategias creadas en C#. Por lo tanto, si se necesitan programas externos para escribir código, se recomienda usar el enfoque con [archivos dll](../../using_dll.md).
