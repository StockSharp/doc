# DLL externas

Al crear contenido desde **Source Code**, junto con las bibliotecas de la [API](../../../../api.md), puede usar otras bibliotecas C#, incluidas las propias. Estas bibliotecas deben ser compatibles con .NET 6.0. Para añadir una referencia a una biblioteca, debe hacer clic en el botón **References** en la pestaña **Backtest**. Después se abrirá la ventana **Extra references**, donde puede añadir o eliminar las bibliotecas necesarias:
