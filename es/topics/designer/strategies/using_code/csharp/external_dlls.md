# DLL externas

Al crear contenido desde **Código fuente**, junto con las bibliotecas de la [API](../../../../api.md), puede usar otras bibliotecas C#, incluidas las propias. Estas bibliotecas deben ser compatibles con .NET 10. Para añadir una referencia a una biblioteca, debe hacer clic en el botón **Referencias** del panel de código. Después se abrirá la ventana **Referencias adicionales**, donde puede añadir o eliminar las bibliotecas necesarias:

- **Ensamblado** \- añadir una referencia a un archivo de biblioteca;
- **Proyecto** \- añadir una referencia a código propio o a un indicador creado en Designer;
- **Eliminar** \- eliminar la referencia seleccionada.

La tabla de referencias muestra el nombre, la ruta y el estado de cada referencia, y la línea **Búsqueda** situada encima encuentra una referencia en una lista larga. Si no se puede añadir una referencia, la causa se escribe en rojo debajo de la tabla.
