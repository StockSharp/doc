# Indexador

![Designer Indexer 00](../../../../../../images/designer_indexer_00.png)

El elemento se usa para obtener un elemento de una colección con el índice especificado. 

### Sockets de entrada

Sockets de entrada

- **Any data** – colección de elementos.

### Sockets de salida

Sockets de salida

- **Any data** - elemento de la colección con el índice especificado en los parámetros.

### Parámetros

Parámetros

- **Index** - índice del elemento requerido.
