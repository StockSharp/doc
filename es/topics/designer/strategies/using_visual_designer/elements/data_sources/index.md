# Índice

![Designer Índice 00](../../../../../../images/designer_index_00.png)

El cubo se usa para crear su propio índice.

### Conectores de salida

Conectores de salida

- **Instrumento** - índice calculado, representado como **Instrumento**.

### Parámetros

Parámetros

- **Índice** - fórmula matemática de una combinación de varios instrumentos (por ejemplo, (AAPL@NASDAQ+10)\*(abs(20\/GOOG@NYSE)).
- **Ignorar errores** - la bandera establecida indica que los errores se ignorarán al calcular el índice.
- **Calcular información ampliada** - la bandera establecida indica que, al calcular el índice, además de la información básica (volumen total, precio de apertura, precio de cierre, precio máximo, precio mínimo), se calculará la información extendida (volumen total negociado, volumen de apertura, volumen de cierre, volumen máximo, volumen mínimo).

Las fórmulas matemáticas disponibles son similares a las del cubo [Fórmula](../common/formula.md).
