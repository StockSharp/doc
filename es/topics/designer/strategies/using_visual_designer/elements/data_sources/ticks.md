# Ticks

![Designer fuente de ticks](../../../../../../images/designer_ticks_00.png)

Este bloque se usa para recibir datos **Tick** para un instrumento.

### Conectores de entrada

Conectores de entrada

- **Instrumento** – instrumento para el que deben recibirse datos **Nivel 1**.

### Conectores de salida

Conectores de salida

- **Tick** – una transacción tick.

### Parámetros

Parámetros

- **Suscribirse por señal** – suscribirse a datos solo después de que llegue un disparador.
