# Libro de órdenes

![Designer Order Book 00](../../../../../../images/designer_orderbook_00.png)

El cubo se usa para obtener el libro de órdenes del instrumento especificado.

### Sockets de entrada

- **Instrumento** - instrumento para el que necesita obtener un libro de órdenes.

### Sockets de salida

- **Order book** - cambios del libro de órdenes desde el momento en que se suscribe a la recepción de datos (entrada del instrumento en la entrada del elemento).
