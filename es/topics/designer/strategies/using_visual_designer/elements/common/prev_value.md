# Valor anterior

![Designer Valor anterior 00](../../../../../../images/designer_previous_value_00.png)

El cubo se usa para obtener el valor anterior pasado a la entrada, con el desplazamiento especificado.

## Conectores de entrada

- **Cualquier dato** - cierto tipo de dato recibido y pasado.

## Conectores de salida

- **Cualquier dato** - cierto tipo de dato recibido y pasado, introducido en la entrada con el desplazamiento especificado en los parámetros.

## Parámetros

- **Tipo de datos** - tipo de dato que puede introducirse a través del conector de entrada. Si cambia este parámetro, el tipo de dato de los parámetros se cambia automáticamente.
- **Desplazamiento** - tamaño del desplazamiento; indica cuántos cambios se retrasará el valor de salida respecto al de entrada.
