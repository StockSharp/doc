# Valor anterior

![Designer The previous value 00](../../../../../../images/designer_previous_value_00.png)

El cubo se usa para obtener el valor anterior pasado a la entrada, con el desplazamiento especificado.

## Sockets de entrada

- **Any data** - cierto tipo de dato recibido y pasado.

## Sockets de salida

- **Any data** - cierto tipo de dato recibido y pasado, introducido en la entrada con el desplazamiento especificado en los parámetros.

## Parámetros

- **Data type** - tipo de dato que puede introducirse a través del socket de entrada. Si cambia este parámetro, el tipo de dato de los parámetros se cambia automáticamente.
- **Offset** - tamaño del desplazamiento; indica cuántos cambios se retrasará el valor de salida respecto al de entrada.
