# Condición lógica

![Designer The logical condition 00](../../../../../../images/designer_logical_condition_00.png)

Este elemento se usa para calcular una fórmula lógica con dos argumentos.

## Sockets de entrada

- **Flag** – valor de bandera (caracteriza el estado y tiene dos valores: levantada (true) y bajada (false)).
- **Flag** – valor de bandera (caracteriza el estado y tiene dos valores: levantada (true) y bajada (false)).

## Sockets de salida

- **Flag** – valor de bandera (caracteriza el estado y tiene dos valores: levantada (true) y bajada (false)).

## Parámetros

- **Operator** - conjunto predefinido de fórmulas lógicas AND, OR, Exclusive OR.
