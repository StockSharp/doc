# Valor aleatorio

![Designer Random 00](../../../../../../images/designer_random_00.png)

Este bloque se usa para generar un valor aleatorio.

## Sockets de entrada

- **Trigger** - señal (cualquier valor excepto `False`) que determina el momento en que debe pasarse un valor aleatorio generado por el socket de salida.

## Sockets de salida

- **Value** - valor aleatorio.

## Parámetros

- **Min** - límite mínimo permisible del valor.
- **Max** - límite máximo permisible del valor.
