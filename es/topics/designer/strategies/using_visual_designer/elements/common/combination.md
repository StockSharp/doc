# Combinación

![Designer Association 00](../../../../../../images/designer_association_00.png)

El cubo se usa para combinar datos del mismo tipo procedentes de distintos cubos en un único parámetro de salida para pasarlos a otro elemento, o para dividir los datos recibidos en varios elementos.

## Sockets de entrada

- **Cualquier dato** - especifica el tipo de datos recibidos y pasados.

## Sockets de salida

- **Cualquier dato** - especifica el tipo de datos recibidos y pasados.

## Parámetros

- **Tipo** - especifica el tipo de datos recibidos y pasados.
