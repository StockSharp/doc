# Cesta

![Designer Black Basket 00](../../../../../../images/designer_black_basket_00.png)

Este bloque se usa para crear un modelo de valoración de opciones.

### Sockets de entrada

Sockets de entrada

- **Options** – strikes para los que debe crearse el modelo.

### Sockets de salida

Sockets de salida

- **Model** – modelo de valoración (por ejemplo, Black-Scholes).

### Parámetros

Parámetros

- **Black Model** – bandera que indica si se debe crear un modelo Black-Scholes.
