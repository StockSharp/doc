# Black-Scholes

![Designer Black Sols 00](../../../../../../images/designer_black_scholes_00.png)

Este bloque se usa para crear un modelo de valoración de opciones.

### Sockets de entrada

Sockets de entrada

- **Option** – strike para el que debe crearse el modelo.

### Sockets de salida

Sockets de salida

- **Model** – modelo de valoración (por ejemplo, Black-Scholes).

### Parámetros

Parámetros

- **Black Model** – bandera que indica si se debe crear un modelo Black-Scholes.
