# Libro IV

![Designer Glass implied volatility 00](../../../../../../images/designer_orderbook_implied_volatility_00.png)

El cubo se usa para calcular un libro de órdenes de volatilidad implícita.

### Sockets de entrada

Sockets de entrada

- **Model** – modelo de cálculo (por ejemplo, Black-Scholes).
- **Order book** – libro de órdenes.

### Sockets de salida

Sockets de salida

- **Order book** - valores del libro de órdenes de volatilidad implícita.
