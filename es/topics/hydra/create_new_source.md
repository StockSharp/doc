# Crear nueva fuente

Para añadir su propia fuente, debe crear su propio [IMessageAdapter](xref:StockSharp.Messages.IMessageAdapter). Cómo hacerlo se describe en [Crear su propio conector](../api/connectors/creating_own_connector.md). Después de crearlo, debe añadir el archivo dll resultante a la carpeta de [Hydra](../hydra.md).
