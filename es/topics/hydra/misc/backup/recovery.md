# Recuperación

Puede restaurar los datos desde el almacenamiento de dos formas:

- Descargar los objetos almacenados desde la consola de AWS. Para ello, haga clic derecho sobre el objeto y seleccione **Download** en el menú contextual.![Aws3 download](../../../../images/aws3_download.png)

  > [!TIP]
  > Este método permite descargar solo un objeto (archivo) a la vez.
- Usar la aplicación gratuita [S3 Browser](https://s3browser.com/) para descargar los datos.
