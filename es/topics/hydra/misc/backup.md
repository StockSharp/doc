# Copia de seguridad

[S#](../../api.md) proporciona funcionalidad para realizar copias de seguridad de los datos descargados en el almacenamiento en la nube [Amazon Web Services (AWS)](https://aws.amazon.com/s3/).

Para crear copias de seguridad, es necesario crear y configurar una cuenta en AWS y después crear y configurar la "tarea de copia de seguridad".
