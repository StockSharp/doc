# Fuentes de datos

[Hydra](../hydra.md) tiene conexiones a distintas fuentes de datos. Además de recibir datos históricos, el programa puede recibir datos de mercado desde brokers en tiempo real. La conexión a las fuentes se realiza mediante los conectores proporcionados al usuario.

El usuario dispone de conectores gratuitos y también puede adquirir conectores de pago, que permiten recibir datos de mercado desde fuentes de pago.

Actualmente, [Hydra](../hydra.md) admite las siguientes fuentes:
