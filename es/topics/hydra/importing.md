# Importación

[Hydra](../hydra.md) permite importar datos propios guardados en formato .csv. Para importar, abra la pestaña **Importar** y seleccione el tipo de datos bursátiles que desea importar.

![hydra import menu](../../images/hydra_import_menu.png)

Se pueden importar los siguientes tipos:

- [Velas](importing/candles.md)
- [Instrumentos](importing/instruments.md)
- [Operaciones](importing/ticks.md)
- [Libros de órdenes](importing/order_books.md)
- [Registro de órdenes](importing/order_log.md)
- [Level 1](importing/level_1.md)
- [Noticias](importing/news.md)
- [Transacciones propias](importing/transactions.md)
