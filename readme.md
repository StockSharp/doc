## English

This repository contains the public source files for the StockSharp documentation.

Help us make the documentation clearer and more useful. If you find a typo, an outdated article, a broken link, or a missing translation, please open an issue or send a pull request. When reporting a problem, include the page URL, the language, and a short description of what should be fixed.
