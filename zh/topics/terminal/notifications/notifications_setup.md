# 通知设置

要设置通知，请单击 ![Designer Creation tool 00](../../../images/designer_creation_tool_00.png) 按钮（位于[通知面板](notification_panel.md)中），或者直接单击支持通知的面板中的 ![Designer Alert Bell](../../../images/designer_alert_bell.png) 按钮（这些面板包括[投资组合](../user_interface/portfolios.md)、[成交流](../user_interface/components/trades_feed.md)、[新闻](../user_interface/components/news.md)和 [Level 1](../user_interface/components/level_1.md)）。

![Designer Notifications Setting](../../../images/designer_notifications_setting.png)

可以针对以下数据类型的变化配置通知：投资组合、客户代码、经纪商、存管机构、服务器时间、成交、数据类型、撤销、订单 ID、订单 ID（字符串）、订单 ID（交易板）、衍生品、衍生品（字符串）、价格、成交量（订单）、成交量（成交）、可见数量、方向、剩余数量、订单类型、状态、备注、订单消息、系统订单、订单到期时间、执行条件、订单 ID、订单 ID（字符串）、价格、成交发起方、未平仓量、错误、条件、上升趋势、佣金、延迟、滑点、ID（用户）、货币、盈亏、持仓、做市商。

通知可以采用以下形式：

- **Window** — 在屏幕角落显示一个小型消息弹窗。
- **Melody** — 播放提示音。
- **SMS** — 通过短信发送消息。
- **Email** — 通过电子邮件发送消息。
- **Speech** — 使用计算机合成语音朗读消息。
- **Log** — 将消息发送到 Designer 日志窗口。
- **Off** — 不显示通知。
