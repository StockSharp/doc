# 通知面板

**Notifications** 面板是一个表格，用于显示当前已设置的所有通知。

![Terminal Notifications Panel](../../../images/terminal_notifications_panel.png)

在 **Notifications** 面板中，可以编辑 ![Designer Creating a repository of historical data 01](../../../images/designer_creating_repository_of_historical_data_01.png) 现有通知、删除 ![Designer Creating a repository of historical data 02](../../../images/designer_creating_repository_of_historical_data_02.png) 通知，或设置新的通知 ![Designer Creating a repository of historical data 00](../../../images/designer_creating_repository_of_historical_data_00.png)。
