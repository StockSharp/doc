# 组件

在交易过程中，您可能需要全面控制整个流程。为了实现完整的控制和分析，**Terminal** 提供了多种图形组件。可以在**功能区**的 **Components** 组中选择并添加这些组件：

![Designer Components](../../../images/designer_components.png)

- [交易品种](components/instruments.md) — 显示所有已选交易品种信息的表格。
- [Level 1](components/level_1.md) — 显示所选交易品种 Level 1 数据变更历史的表格。
- [买入\/卖出](components/buy_sell.md) — 一组面板，用于显示所选交易品种的最优价格，并按指定数量买入或卖出所选交易品种。
- [订单簿](components/order_book.md) — 显示买卖限价订单的表格。
- [图表](components/chart.md) — 用于绘制所选交易品种的K线和指标。
- [盈亏曲线](../../designer/user_interface/components/pnl_equity.md) — 显示未实现盈亏、已实现盈亏和佣金的图表。
- [成交](../../designer/user_interface/components/trades.md) — 显示策略全部成交详细信息的表格。
- [订单](../../designer/user_interface/components/orders.md) — 显示策略全部订单详细信息的表格。
- [条件订单](components/conditional_orders.md) — 显示策略全部条件订单详细信息的表格。
- [持仓](../../designer/user_interface/components/positions.md) — 显示当前持仓的表格。
- [逐笔成交](../../designer/user_interface/components/tick_trades.md) — 显示所选交易品种全部成交详细信息的表格。
- [持仓](../../designer/user_interface/components/positions.md) — 显示持仓的图表。
- [新闻](components/news.md) — 显示通过连接接收到的新闻。
- [持仓（期权）](components/positions_options.md) — 以图形方式显示期权持仓。
- [期权面板](components/option_desk.md) — 显示所选标的资产期权主要参数的表格。
- [波动率微笑](components/smile_volatility.md) — 以图形方式显示具有相同标的资产、不同执行价的期权预期波动率水平。
- [订单日志](components/order_log.md) — 显示所选交易品种全部订单详细信息的表格。
