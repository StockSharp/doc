# 交易品种

**Instruments** 组件是一个交易品种表格，用于显示所有已选交易品种的信息。

要添加新的交易品种，请单击 ![Designer Creation tool 00](../../../../images/designer_creation_tool_00.png) 按钮。

还可以为所选交易品种的事件配置通知，详见[通知设置](../../notifications.md)。
