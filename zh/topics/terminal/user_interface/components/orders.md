# 订单

**Orders** 组件是一个订单表格，用于显示全部订单的详细信息。右键单击某个订单时，会出现一个面板，可以通过该面板登记新订单、撤销订单或修改所选订单。

![Terminal Quick start 04](../../../../images/terminal_quick_start_04.png)

单击 **Order Registration** 按钮后会出现一个窗口。要登记新订单，请填写该窗口并单击 **Send** 按钮。

![Terminal OrderPanel 01](../../../../images/terminal_orderpanel_01.png)

单击 **Change Order** 按钮后会出现一个窗口。要修改订单，请完成所需更改并单击 **Send** 按钮。

![Terminal OrderPanel 02](../../../../images/terminal_orderpanel_02.png)
