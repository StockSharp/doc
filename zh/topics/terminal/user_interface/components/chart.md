# 图表

**图表** 组件用于绘制所选交易品种的K线和指标。

![Terminal 图形面板 00](../../../../images/terminal_panel_graphics_00.png)

要添加新的图表区域，请单击 ![Designer Creation tool 00](../../../../images/designer_creation_tool_00.png) 按钮。

要向图表添加新元素，请右键单击图表区域中的任意位置并选择所需元素。可选元素包括K线、指标、订单和自有成交。

单击 ![Designer Schedule 00](../../../../images/designer_schedule_00.png)，然后单击 ![Designer Schedule 01](../../../../images/designer_schedule_01.png) 可打开图形元素的设置。

![Designer Schedule 02](../../../../images/designer_schedule_02.png)

可以直接从图表登记订单。首先需要指定用于登记订单的 **交易品种** 和 **投资组合**。

按 **Ctrl+鼠标左键** 登记买入订单。

按 **Ctrl+鼠标右键** 登记卖出订单。

![Terminal 图形面板 01](../../../../images/terminal_panel_graphics_01.png)

在图形元素设置中，可以选择所需的图表样式，例如日本K线、柱状图、箱形图、聚类轮廓图等。

![Designer Schedule 04](../../../../images/designer_schedule_04.png)

对于箱形图，还可以对K线进行分组。分组顺序通过“第二时间周期倍数”和“第三时间周期倍数”字段设置。

![Designer Schedule 05](../../../../images/designer_schedule_05.png)

图表上方设有工具栏，可以在其中选择自动滚动、自动缩放、图例模式以及其他通用图表设置。还可以选择要绘制到图表上的元素，包括线条、水平线、指针、矩形和文本。

![Designer Schedule 03](../../../../images/designer_schedule_03.png)
