# 状态栏

[Terminal](../../terminal.md) 窗口底部是状态栏。从左到右依次为：

- **状态** — **已断开**、**正在连接**、**已连接**、**断开连接** 或连接错误文本。Terminal 还会在这里显示最近一次操作的结果，例如“布局已保存。”或“已创建合约：…”；
- **StockSharp 新闻** — 网站新闻的标题，可以使用箭头按钮翻阅；
- 日志的 **警告和错误计数器** — 日志中有警告或错误时显示；
- **最近一条日志消息** — 右键单击它会将其文本复制到剪贴板。完整日志位于[日志](logs.md)面板中；
- **每秒逐笔成交数**（tps）— Terminal 在最近一秒内收到的市场成交（逐笔成交）数量；
- **延迟**（ms）— 最近一笔逐笔成交或最近一次 Level 1 变化比其在交易场所的时间晚到达多少毫秒；
- Terminal 数据占用的 **内存**，单位为兆字节；
- 程序自启动以来的 **运行时间**；
- **日志目录** 按钮 — 打开 Terminal 写入日志的文件夹。

![Terminal 状态栏 00](../../../images/terminal_status_bar_00.png)

Terminal 未连接时，不会统计逐笔成交和延迟：状态栏中显示 **0 tps** 和 **— ms**。
