# 入门

要将策略添加到 **实盘交易**，请在[策略图面板](../user_interface/schemas.md)的 **策略** 文件夹中右键单击所需策略，然后选择 ![Designer 交易 00](../../../images/designer_live_trade_00.png) **交易**。该策略会被添加到 **策略图面板** 的 **实盘** 文件夹中。

![Designer 交易 01](../../../images/designer_live_trade_01.png)

也可以在 **回测** 选项卡中单击 ![Designer 交易 00](../../../images/designer_live_trade_00.png) **交易** 按钮，将策略添加到实盘交易。

![Designer 交易 02](../../../images/designer_live_trade_02.png)

**实盘** 文件夹包含已添加并准备在实盘交易中运行的策略。正在运行的策略以 ![Designer 线路面板 02](../../../images/designer_panel_circuits_02.png) 图标标记，已停止的策略则以 ![Designer 线路面板 03](../../../images/designer_panel_circuits_03.png) 图标标记。
