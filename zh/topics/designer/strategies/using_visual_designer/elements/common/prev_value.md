# 前一个值

![Designer The previous value 00](../../../../../../images/designer_previous_value_00.png)

该模块用于获取此前传入输入端的值，并可指定偏移量。

## 输入端口

- **任意数据** \- 接收并传递的某种数据类型。

## 输出端口

- **任意数据** \- 接收并传递的某种数据类型。输出的是此前传入输入端、与当前值相差参数所指定偏移量的值。

## 参数

- **数据类型** \- 可通过输入端口传入的数据类型。更改此参数后，端口的数据类型会自动更新。
- **偏移** \- 偏移量大小，即输出值比输入值滞后的变更次数。
