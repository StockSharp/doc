# 比较

![比较 截图](../../../../../../images/designer_comparison_00.png)

该元素用于比较两个输入对象。

## 输入端口

- **值 1** – 可比较的值（例如数值、字符串、指标值等）。
- **值 2** – 可比较的值（例如数值、字符串、指标值等）。

## 输出端口

- **标志** – 标志值（表示状态，包含两个值：上（true）和下（false））。

## 参数

- **左侧** – 值将用于比较运算左侧的参数。
- **运算符** – 用于比较传入值的运算符。
- **右侧** – 值将用于比较运算右侧的参数。

更改运算符后，模块名称会自动变为该运算符的名称。
