# 随机值

![Designer 随机 00](../../../../../../images/designer_random_00.png)

该模块用于生成随机值。

## 输入端口

- **触发器** - 用于确定何时通过输出端口传递所生成随机值的信号（除 `False` 以外的任意值）。

## 输出端口

- **值** - 随机值。

## 参数

- **最小值** - 允许的最小值边界。
- **最大值** - 允许的最大值边界。
