# 随机值

![Designer Random 00](../../../../../../images/designer_random_00.png)

该模块用于生成随机值。

## 输入端口

- **Trigger** - 用于确定何时通过输出端口传递所生成随机值的信号（除 `False` 以外的任意值）。

## 输出端口

- **Value** - 随机值。

## 参数

- **Min** - 允许的最小值边界。
- **Max** - 允许的最大值边界。
