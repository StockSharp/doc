# 修改订单

![Designer 移动应用程序 00](../../../../../../images/designer_moving_applications_00.png)

该模块用于修改交易品种的订单。

### 输入端口

输入端口

- **触发器** - 用于确定何时移动订单的信号。
- **订单** - 要修改的订单。
- **价格** - 新价格的数值。
- **数量** - 新数量的数值。

### 输出端口

输出端口

- **订单** - 修改后的订单。可以使用 **按订单成交** 元素获取该订单的成交，也可以使用 **图表面板** 模块将其显示在图表上。
- **错误** - 移动订单时发生的错误。
- **成交** - 已提交订单的成交。

参数

- **零价格** – 使用零价格注册市价订单。
