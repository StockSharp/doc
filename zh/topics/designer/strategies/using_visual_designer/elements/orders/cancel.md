# 撤销订单

![撤销订单 截图](../../../../../../images/designer_cancellations_00.png)

该模块用于撤销交易品种的订单。

### 输入端口

输入端口

- **触发器** – 触发订单撤销的事件。
- **订单** – 用于确定何时需要撤销订单的信号。

### 输出端口

输出端口

- **订单** – 已撤销的订单。可以使用 **交易事务** 元素获取该订单的成交，也可以使用 **图表面板** 模块将其显示在图表上。
- **错误** – 撤销订单时发生的错误（例如订单此前已经成交或撤销）。
