# Black-Scholes

![Designer Black Sols 00](../../../../../../images/designer_black_scholes_00.png)

该模块用于创建期权定价模型。

### 输入端口

输入端口

- **Option** – 要为其创建模型的执行价。

### 输出端口

输出端口

- **Model** – 定价模型（例如 Black-Scholes）。

### 参数

参数

- **Black Model** – 指定是否创建 Black-Scholes 模型的标志。
