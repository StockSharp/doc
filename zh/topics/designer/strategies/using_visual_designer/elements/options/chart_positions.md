# 期权持仓图表

![Designer Graph options positions 00](../../../../../../images/designer_graph_options_positions_00.png)

该模块用于显示 **期权持仓图表**。

要显示 **期权持仓图表**，需要添加 **期权持仓图表** 图形组件。

### 输入端口

输入端口

- **模型** – 计算模型（例如 Black-Scholes）。
- **标的资产价格** \- 标的资产的价格。
