# 行权价

![Designer Derivatives 00](../../../../../../images/designer_derivatives_00.png)

该模块用于按照指定筛选条件获取期权列表。

### 输入端口

输入端口

- **Instrument** – 作为标的资产的交易品种。

### 输出端口

输出端口

- **Options** \- 以指定资产为标的的期权列表。

### 参数

参数

- **Option type** – 期权类型，可以是 Call option 或 Put option。
- **Expiry date** \- 期权到期日。
- **Strike (less)** – 相对于中心行权价向左（更低）的偏移量。如果未设置价格，则使用所有低于中心值的行权价。偏移量按行权价步长计算。例如，行权价步长为 500 c.u. 时，偏移量 3 等于 1,500 c.u.。
- **Strike (more)** – 相对于中心行权价向右（更高）的偏移量。如果未设置价格，则使用所有高于中心值的行权价。偏移量按行权价步长计算。例如，行权价步长为 500 c.u. 时，偏移量 3 等于 1,500 c.u.。
