# 隐含波动率市场深度

![Designer Glass implied volatility 00](../../../../../../images/designer_orderbook_implied_volatility_00.png)

该模块用于计算隐含波动率市场深度。

### 输入端口

输入端口

- **Model** – 计算模型（例如 Black-Scholes）。
- **Order book** – 市场深度。

### 输出端口

输出端口

- **Order book** \- 隐含波动率市场深度的数值。
