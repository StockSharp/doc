# 期权做市

![Designer Quoting 00](../../../../../../images/designer_quoting_00.png)

该模块用于按照指定参数对期权进行报价。

### 输入端口

输入端口

- **模型** – 计算模型（例如 Black-Scholes）。
- **数量** \- 报价数量。

### 输出端口

输出端口

- **订单** \- 已注册的订单。可以使用按订单筛选的 **成交** 元素获取该订单的成交，并通过 **图表面板** 模块将其显示在图表上。

### 参数

参数

- **报价** \- 用于执行报价的参数。可取 **波动率**（报价数量将遵循指定的波动率限制）或 **理论价格**（报价数量将遵循指定的理论价格限制）。
- **方向** \- 报价方向，可取 Purchase 或 Sell。
- **最小值** – 波动率或理论价格的最小值。
- **最大值** \- 波动率或理论价格的最大值。
