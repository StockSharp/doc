# 转换器

![Designer Converter 00](../../../../../../images/designer_converter_00.png)

该模块用于将复杂对象转换为简单数据类型。例如，可以用它获取交易品种的价格步长值。

### 输入端口

输入端口

- **任意数据** \- 接收到的某种复杂对象类型。

### 输出端口

输出端口

- **任意数据** \- 接收对象中所选属性的值。

### 参数

参数

- **数据类型** \- 输入数据的类型。输入参数的类型取决于所选值。
- **属性** – 所选类型的属性树，可从中选择要由模块输出的属性。可用属性集合取决于所选数据类型，并且只有选择所需数据类型后才会显示。
