# 截断市场深度

![Designer MarketDepthTruncateDiagramElement 00](../../../../../../images/designer_marketdepthtruncatediagramelement_00.png)

该模块用于获取截断到指定深度的市场深度。

### 输入端口

- **Order book** 是需要截断的市场深度。

### 输出端口

- **Order book** 是截断后的市场深度。

### 参数

- **Depth** – 市场深度的最大档数。
