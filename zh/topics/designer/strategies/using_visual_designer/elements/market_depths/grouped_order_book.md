# 分组市场深度

![Designer 分组订单簿 01](../../../../../../images/designer_grouped_orderbook_01.png)

![Designer 分组订单簿 00](../../../../../../images/designer_grouped_orderbook_00.png)

该模块用于生成经过分组的市场深度。

### 输入端口

- **订单簿** \- 要进行分组的市场深度。

### 输出端口

- **订单簿** \- 分组后的市场深度。

### 参数

- **价格区间** \- 对订单进行分组时采用的价格区间。
