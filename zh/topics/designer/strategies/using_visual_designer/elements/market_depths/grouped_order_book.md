# 分组市场深度

![Designer Grouped order book 01](../../../../../../images/designer_grouped_orderbook_01.png)

![Designer Grouped order book 00](../../../../../../images/designer_grouped_orderbook_00.png)

该模块用于生成经过分组的市场深度。

### 输入端口

- **Order book** \- 要进行分组的市场深度。

### 输出端口

- **Order book** \- 分组后的市场深度。

### 参数

- **Price range** \- 对订单进行分组时采用的价格区间。
