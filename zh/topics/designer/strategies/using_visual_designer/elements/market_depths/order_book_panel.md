# 市场深度面板

![Designer Order Book Panel](../../../../../../images/designer_orderbook_panel.png)

该模块用于在专用图形组件 [市场深度](../../../../user_interface/components/order_book.md) 中显示市场深度。

[市场深度](../../../../user_interface/components/order_book.md) 组件需要从 **Simulation** 或 **Trading** 选项卡的 [组件](../../../../user_interface/components.md) 组中添加。有关 [市场深度](../../../../user_interface/components/order_book.md) 组件的详细信息，请参阅 [市场深度](../../../../user_interface/components/order_book.md) 章节。

### 输入端口

- **Order Book** - 要显示的市场深度。
- **Order** - 其数量需要显示在 *Own Volume* 列中的订单。
- **Order Error** - 注册或撤销订单时发生的错误，需要为其显示动画。
