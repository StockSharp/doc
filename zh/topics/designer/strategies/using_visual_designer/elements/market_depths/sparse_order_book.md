# 稀疏市场深度

![Designer Sparse order book 01](../../../../../../images/designer_sparse_orderbook_01.png)

![Designer Sparse order book 00](../../../../../../images/designer_sparse_orderbook_00.png)

该模块用于获取指定证券的稀疏市场深度。

### 输入端口

- 市场深度 \- 需要进行稀疏化处理的市场深度。

### 输出端口

- 市场深度 \- 稀疏化后的市场深度。

### 参数

- **Price Range** - 对市场深度进行稀疏化时采用的价格范围和步长。
