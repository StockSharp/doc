# 变量

![变量 截图](../../../../../../images/designer_variable_00.png)

该模块用于保存值，并将此前保存的值继续传递给元素链中的后续元素。

### 输入端口

输入端口

- **任意数据** – 所选类型的值，用于替换并保存默认值。
- **触发器** – 用于确定何时通过输出端口传递已保存值的信号（除 `False` 以外的任意值）。

### 输出端口

输出端口

- **任意数据** – 所选数据类型的值。

### 参数

参数

- **数据类型** \- 变量中保存的数据类型。输入和输出参数的类型取决于所选数据类型。
- **值** \- 变量中保存的默认值。如果元素的输入端未收到其他值，则使用此值。
- **启动时触发** \- 选中此复选框后，策略启动时会传递该值。

如果选择 **交易品种** 或 **投资组合** 数据类型，可以不指定默认值。在这种情况下，如果属性中设置了 **参数** 标志，策略执行时会从策略的相应属性中获取这些数据。
