# Level 1

![Designer Level 1 00](../../../../../../images/designer_level_1_00.png)

该模块用于接收交易品种的 **Level1** 数据。

### 输入端口

输入端口

- **Instrument** – 要接收 **Level1** 数据的交易品种。

### 输出端口

输出端口

- **Change** – 所跟踪参数的 **Level1** 值。

### 参数

参数

- **Value** – 要跟踪的 **Level1** 参数。
- **Subscribe on Signal** – 仅在收到触发信号后订阅数据。
