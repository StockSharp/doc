# Level 1

![Designer 一级 00](../../../../../../images/designer_level_1_00.png)

该模块用于接收交易品种的 **一级行情** 数据。

### 输入端口

输入端口

- **交易品种** – 要接收 **一级行情** 数据的交易品种。

### 输出端口

输出端口

- **变化** – 所跟踪参数的 **一级行情** 值。

### 参数

参数

- **值** – 要跟踪的 **一级行情** 参数。
- **按信号订阅** – 仅在收到触发信号后订阅数据。
