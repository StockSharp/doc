# 持仓

![Designer Position 00](../../../../../../images/designer_position_00.png)

该元素用于获取指定交易品种和投资组合的持仓变化信息。

### 输入端口

输入端口

- **交易品种** \- 要获取其持仓的交易品种。
- **投资组合** \- 要获取其持仓的投资组合。

### 输出端口

输出端口

- **持仓** \- 交易品种持仓的数值，或账户当前可用资金的金额。持仓或资金发生变化时，以及策略启动后，都会生成该值。

### 参数

参数

- **资金** \- 设置此标志后，元素只接收投资组合，并将所选投资组合的资金余额传递到输出端。
