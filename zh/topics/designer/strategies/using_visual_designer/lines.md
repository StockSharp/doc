# 连接线

Designer 中的策略是由一组元素及其之间的链接构成的策略图，这些链接称为连接。每条连接都从一个模块的输出参数指向另一个模块的输入参数。通常，所有连接线都显示为灰色；将鼠标指针移到连接所属的模块上时，连接线会变为黑色。

![Designer Line 00](../../../../images/designer_line_00.png)

将鼠标指针移到连接线上并单击鼠标左键，可以选中该连接。选中的连接线两端会显示圆形标记，拖动这些标记可以将连接线重定向到其他端口。选中连接线后按 Del 键即可将其删除。

可以连接颜色相同（即数据类型相同）的参数，但以下参数类型除外：

- **黑色**参数可以接收任意数据。这类参数通常用于传递触发元素内部操作的信号。例如，[Variable](elements/data_sources/variable.md) 元素会保存某个值，并在收到信号时将该值传递到输出端。
- **绿色**参数可以接收不同的可比较数据类型，例如数值、指标值和字符串等。
