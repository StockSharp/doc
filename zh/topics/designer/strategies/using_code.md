# 编程语言

[Designer](../../designer.md) 支持三种用于创建交易策略的编程语言：

- [C#](using_code/csharp.md)
- [F#](using_code/fsharp.md) 
- [Python](using_code/python.md)

[AlgoTrading API 文件夹](https://github.com/StockSharp/AlgoTrading/tree/main/API)中提供了大量 C# 和 Python 策略示例，所有示例都可以在 [Designer](../../designer.md) 中使用。

## C#

C# 是开发交易策略的主要语言。所有组件、示例和核心代码均使用 C# 编写。通过 C# 可以完整访问 [S#](../../api.md) 平台的全部架构。

## F#

F# 是 Microsoft 推出的函数式编程语言。使用 F# 编写的交易策略可以访问全部 API 功能，并可用于测试和实盘交易。

## Python

Python 集成支持使用 Python 编写交易策略，使 Python 开发者能够更方便地使用该平台。
