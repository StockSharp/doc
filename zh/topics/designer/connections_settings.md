# 连接设置

1. 单击 **Connect** ![Designer The quick access toolbar 00](../../images/designer_quick_access_toolbar_00.png) 按钮旁的箭头，会显示 **Connection settings** 按钮：

![Designer The connection settings 00](../../images/designer_connection_settings_00.png)

2. 单击 **Connection settings** 按钮，会打开分为三个区域的 **Connection settings** 窗口：

![Designer The connection settings 01](../../images/designer_connection_settings_01.png)

3. 单击 ![Designer The connection settings 02](../../images/designer_connection_settings_02.png) 按钮，会打开受支持连接器的下拉列表。所选连接器显示在区域 1 中。单击 ![Designer The connection settings 03](../../images/designer_connection_settings_03.png) 按钮可删除选中的连接器。区域 1 的第一列显示单击 Connect ![Designer The connection settings 04](../../images/designer_connection_settings_04.png) 按钮时，该连接器是会连接，还是不会连接 ![Designer The connection settings 05](../../images/designer_connection_settings_05.png)。使用 ![Designer The connection settings 06](../../images/designer_connection_settings_06.png) 和 ![Designer The connection settings 07](../../images/designer_connection_settings_07.png) 按钮设置这些值。

**Market data** 和 **Trades** 字段显示连接器是否支持市场数据和订单操作。

4. 选中 **Auto\-connect** 复选框后，[Designer](../designer.md) 启动时会自动建立连接。

5. 区域 2 显示所选连接器的设置。单击 ![Designer The connection settings 09](../../images/designer_connection_settings_09.png) 后，程序会打开相关文档（[API](../api.md)），其中介绍如何配置所选连接器。

  > [!IMPORTANT]
  > **Advanced settings** 仅用于特殊情况，不建议修改。

6. 单击 **Check** 按钮可检查当前连接器的连接。如果检查失败，会显示错误窗口并说明连接失败的原因；如果检查成功，则会显示以下窗口：

![Designer The connection settings 10](../../images/designer_connection_settings_10.png)

7. 区域 3 显示连接器将接收或传输的数据类型。单击 ![Designer The connection settings 11](../../images/designer_connection_settings_11.png)\/ ![Designer The connection settings 12](../../images/designer_connection_settings_12.png) 复选框，可以为相应数据类型启用或禁用发送或接收。

8. 单击 **Network settings** 按钮会打开 **Proxy\-server settings** 窗口：

![Designer The connection settings 13](../../images/designer_connection_settings_13.png)
