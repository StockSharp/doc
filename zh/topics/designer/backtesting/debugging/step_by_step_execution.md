# 逐步执行

要跟踪逐步执行过程，请在希望开始逐步执行的模块上设置断点。在目标模块处停止后，单击 ![Designer Debug 03](../../../../images/designer_debug_03.png)**Next element** 按钮。Designer 会依次从一个模块移动到下一个模块，展示策略的逐步执行过程。如果需要进入 **Composite element**，请在执行到该复合元素时单击 ![Designer Debug 04](../../../../images/designer_debug_04.png)**Step in** 按钮。下一步将在 **Composite element** 内部执行。要退出复合元素，请单击 ![Designer Debug 05](../../../../images/designer_debug_05.png)**Step out** 按钮。
