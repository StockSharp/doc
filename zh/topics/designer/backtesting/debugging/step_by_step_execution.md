# 逐步执行

要跟踪逐步执行过程，请在 [Designer](../../../designer.md) 中希望开始逐步执行的模块上设置断点。在目标模块处停止后，单击 ![Designer 调试控件 03](../../../../images/designer_debug_03.png)**下一个元素** 按钮。Designer 会依次从一个模块移动到下一个模块，展示策略的逐步执行过程。如果需要进入 **复合元素**，请在执行到该复合元素时单击 ![Designer 调试控件 04](../../../../images/designer_debug_04.png)**单步进入** 按钮。下一步将在 **复合元素** 内部执行。要退出复合元素，请单击 ![Designer 调试控件 05](../../../../images/designer_debug_05.png)**单步跳出** 按钮。
