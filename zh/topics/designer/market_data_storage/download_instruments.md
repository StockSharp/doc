# 下载交易品种

单击 **下载交易品种** 按钮 ![Designer_Download_instruments_button](../../../images/designer_download_instruments_button.png) 会打开 **下载交易品种** 窗口。要下载交易品种，请输入交易品种代码和类型，选择数据源，然后单击 **确定** 按钮。[Designer](../../designer.md) 会开始在该数据源中搜索交易品种，并将找到的全部交易品种添加到 **全部交易品种** 面板的交易品种列表中。如果选择存储作为数据源，并且其中已经包含下载过的交易品种，[Designer](../../designer.md) 会找到该存储中的所有可用交易品种。当交易品种历史数据已经下载并复制到 [Designer](../../designer.md) 存储文件夹时，此功能非常有用。

![Designer Download the tools 00](../../../images/designer_download_instruments_00.png)

单击 **添加连接** 按钮会打开[连接设置](../connections_settings.md)窗口。
