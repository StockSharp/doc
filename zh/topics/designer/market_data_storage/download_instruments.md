# 下载证券

单击 **Download securities** 按钮会打开 **Download securities** 窗口。要下载证券，请输入证券代码和类型，选择数据源，然后单击 **OK** 按钮。[Designer](../../designer.md) 会开始在该数据源中搜索证券，并将找到的全部证券添加到 **All securities** 面板的证券列表中。如果选择存储作为数据源，并且其中已经包含下载过的证券，[Designer](../../designer.md) 会找到该存储中的所有可用证券。当证券历史数据已经下载并复制到存储文件夹时，此功能非常有用。

![Designer Download the tools 00](../../../images/designer_download_instruments_00.png)

单击 **Add connection** 按钮会打开[连接设置](../connections_settings.md)窗口。
