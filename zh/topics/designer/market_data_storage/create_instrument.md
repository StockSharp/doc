# 创建证券

单击 **Create security** ![Designer Creation tool 00](../../../images/designer_creation_tool_00.png) 按钮会打开 **Editing** 窗口。要创建证券，请填写证券属性，然后单击 **OK** 按钮：

![Designer Creation tool 01](../../../images/designer_creation_tool_01.png)

来自不同数据源的证券使用统一标识符。这样，交易机器人代码便不会依赖连接类型（参阅[连接器](../../api/connectors.md)）。证券标识符采用以下格式：**\[证券代码\]@\[交易板块代码\]**。例如，NASDAQ 交易所的 Apple 股票标识符为 **AAPL@NASDAQ**。
