# 交易板

在 **交易板编辑器** 面板中，可以创建 **交易板** 和 **交易所**，也可以查看或自定义现有项目。

![Designer Boards](../../../images/designer_boards.png)

在 [S#](../../api.md) 中，来自不同数据源的交易品种使用统一标识符，该标识符由交易品种代码和交易板代码组成。语法为 [**交易品种代码**]@[board code]。例如，**NASDAQ** 交易所的 **AAPL** 股票标识符为 **AAPL@NASDAQ**。每个交易品种都关联到其进行交易的特定交易板，但同一交易品种也可以在不同交易板上交易，此时交易板代码会有所不同。可以为每个交易板设置包含工作日和休息日的工作时间表。

一个交易所可以包含多个交易条件不同的交易板，例如交易时段和佣金不同，但每个交易板都只关联到一个特定交易所。因此，在 **交易板编辑器** 中选择交易板时，交易所信息会自动切换为该交易板所属的交易所。可以为每个交易所设置交易所代码、国家以及俄文和英文名称。
