# 盈亏曲线

P\/L 组件以图表形式显示未实现盈亏、已实现盈亏和佣金。图表左上角会显示添加到图表中的所有图形元素。清除图形元素旁的 ![Designer Schedule 00](../../../../images/designer_schedule_00.png) 复选框后，该元素也会从图表中隐藏。单击 ![Designer Schedule 01](../../../../images/designer_schedule_01.png) 按钮可以打开图形元素设置。
