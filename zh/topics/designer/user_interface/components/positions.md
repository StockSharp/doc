# 持仓

**持仓（图表）** 组件以图表形式显示持仓。图表左上角会显示添加到图表中的所有图形元素。清除图形元素旁的 ![Designer 图形元素 00](../../../../images/designer_schedule_00.png) 复选框后，该元素会从图表中隐藏。单击 ![Designer 图形元素 01](../../../../images/designer_schedule_01.png) 按钮可以打开图形元素设置。

![Designer 持仓图表 00](../../../../images/designer_chart_position_00.png)

**持仓** 组件以表格形式显示策略所用交易品种的持仓。

![Designer 持仓表 00](../../../../images/designer_table_position_00.png)
