# 实盘设置

默认情况下，**属性** 面板会最小化显示在策略选项卡的右侧。该面板以表格形式列出仿真属性或实盘设置。选中某个属性后，表格底部会显示该属性的详细说明。所有属性按以下分组排列：

![Designer Properties Live 00](../../../../images/designer_properties_live_00.png)

**日志**

- **日志级别** – 此元素的日志记录级别。

**初始化**

- **数据类型** \- 数据类型。
- **时间周期** \- 使用指定时间周期的K线。
- **历史数据天数** \- 用于初始化策略的历史数据天数。

**设置**

- [风险管理](../risk_management.md) \- 风险管理设置。

**策略图参数**

- **交易品种** \- 交易品种。
- **投资组合** \- 投资组合。

如果未填写 **策略图参数**，仿真时将使用 **仿真** 选项卡的 **交易品种** 字段中指定的交易品种，并默认使用测试投资组合作为投资组合。
