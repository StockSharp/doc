# 实盘设置

策略在实盘交易中使用哪些对象，在功能区 **实时** 选项卡的 **策略** 组中设置：

- **组合** \- 策略用于下单的投资组合。
- **交易品种** \- 策略交易的交易品种。

该选项卡上还有 **刷新**、**开始** 和 **停止** 按钮；**组件** 组中则是可添加到策略选项卡的组件。

策略图本身的参数（例如移动平均线的长度或订单数量）在 **策略参数** 面板中设置。默认情况下，该面板处于折叠状态，并停靠在策略选项卡的右侧。

策略的远程控制设置可以通过[实时面板](../../live_execution/strategies_dashboard.md)中策略行上的 **设置** 按钮打开。
