# 导入

Designer 支持导入任意类型的数据，包括策略、模块和指标。可以通过以下方式导入：

- 在 **Schemes** 面板中右键单击策略文件夹，然后在显示的菜单中选择 **Import**。
- 在 **Common** 选项卡中单击 **Import** 按钮，然后在显示的菜单中选择 **Strategy**、**Own element** 或 **Indicator**：

![Designer Import strategies 00](../../../images/designer_import_strategies_00.png)

如果已存在同名数据，程序会显示一个窗口，询问是覆盖现有数据，还是使用其他名称添加：

![Designer Import strategies 01](../../../images/designer_import_strategies_01.png)
