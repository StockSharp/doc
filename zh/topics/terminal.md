# Terminal

**Terminal** 是一款免费的交易终端。它的主要优势是可以同时连接多个交易平台，包括未提供自有交易终端的平台。

![Terminal main 00](../images/terminal_main_00.png)

## Terminal 的优势和功能

1. **支持多种数据源：**详见[连接器](api/connectors.md)。
2. **可直接在图表上交易**。
3. **支持任意时间周期**。
4. **支持 Volume、Tick、Range、PnF 和 Renko K线**。
5. **支持聚类图和箱形图**。
6. **覆盖各类市场：**股票、期货、外汇和比特币。
