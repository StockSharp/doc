# 常规

**常规** 选项卡显示通过连接收到的内容：投资组合、持仓、订单、自有成交和交易品种。

![Shell 通用 00](../../../images/shell_common_00.png)

该区域由多个独立面板组成。可以拖动任意面板的标题将其移到其他位置，可以垂直或水平拆分区域，可以将面板拆离到单独的窗口，也可以将其重新停靠。布局通过命令栏中的 **保存布局** 按钮保存，并在下次启动时恢复。

| 面板 | 显示内容 |
|---|---|
| **投资组合** | 投资组合及其持仓 |
| **委托** | 订单及注册失败的记录 |
| **我的成交** | 自有成交 |
| **交易品种** | 连接已知的交易品种或从本地存储加载的交易品种 |

在建立连接之前，各面板为空，窗口底部的状态栏会提示需要建立连接。

命令栏右侧显示该区域当前有多少交易品种、投资组合、订单和成交。

命令栏中带交易品种图标的按钮用于从历史数据文件夹添加交易品种：它会询问文件夹，将其中找到的交易品种添加到交易品种列表中，并在按钮旁边显示添加了多少个。这些交易品种在建立连接后才会显示在表格中，因为该区域的面板显示的是连接发送的内容。
