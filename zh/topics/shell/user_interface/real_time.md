# 实盘

在**实盘**选项卡中，可以管理已启动用于交易的策略。

![Shell realtime 00](../../../images/shell_realtime_00.png)

单击 **添加** 按钮 ![Designer Creation tool 00](../../../images/designer_creation_tool_00.png)，可以添加策略并开始交易。每个新增策略都会在单独的选项卡中打开，同时添加到 **策略** 选项卡的策略列表中。

在 **策略** 选项卡中，可以删除、启动、停止和配置策略。也可以在各个策略自己的选项卡中执行相同操作。单独的策略选项卡会显示更详细的策略信息，包括统计数据、已登记订单和策略成交列表等。
