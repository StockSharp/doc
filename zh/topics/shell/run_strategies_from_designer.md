# 运行 Designer 策略

[Shell](../shell.md) 可以运行在 [Designer](../designer.md) 中创建的策略。

要启动在 [Designer](../designer.md) 中创建的策略，请在[实盘](user_interface/real_time.md)选项卡中选择策略，并单击 **添加 Designer 策略** 按钮。在打开的窗口中，选择从 [Designer](../designer.md) 导出的策略文件。

![Shell 运行 Designer 策略 00](../../images/shell_run_designer_strategy_00.png)

随后，该策略会出现在可用策略列表中。

![Shell 运行 Designer 策略 01](../../images/shell_run_designer_strategy_01.png)

选择已添加的策略后，可以设置所需参数并启动实盘交易。

![Shell 运行 Designer 策略 02](../../images/shell_run_designer_strategy_02.png)
