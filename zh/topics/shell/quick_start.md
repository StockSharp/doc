# 快速入门

[Shell](../shell.md) 主要面向在 Visual Studio 或类似开发环境中使用 [C\#](https://en.wikipedia.org/wiki/C_Sharp_(programming_language)) 进行编程的开发人员。

启动 [Shell](../shell.md) 项目后，可以在解决方案资源管理器中看到 Shell 项目：

![Shell 快速入门 00](../../images/shell_quick_start_00.png)

**策略** 文件夹中包含 [Shell](../shell.md) 自带的三个策略、默认策略使用的基础 Shell 类，以及一些辅助接口。

无需进行任何预先配置即可启动项目，查看 [Shell](../shell.md) 中内置策略的运行方式。

启动后会显示类似以下内容的窗口：

![Shell 快速入门 01](../../images/shell_quick_start_01.png)

屏幕顶部包含连接设置、连接按钮和用于保存当前 Shell 配置的按钮，主要选项卡也位于此处。

打开连接设置并选择所需连接。有关连接配置方法，请参阅[连接设置](connections_settings.md)。

下一步，单击 **连接** 按钮 ![Designer 快速访问工具栏 00](../../images/designer_quick_access_toolbar_00.png) 建立连接。

连接成功后，可以在[常规](user_interface/common.md)选项卡中查看通过连接接收到的投资组合、交易品种、订单和自有成交。

![Shell 快速入门 02](../../images/shell_quick_start_02.png)

打开实盘选项卡，单击 **添加** 按钮 ![Designer 添加按钮 00](../../images/designer_creation_tool_00.png)，添加用于交易的策略。

![Shell 快速入门 03](../../images/shell_quick_start_03.png)

添加策略后，填写 **交易品种**、**投资组合** 等基本参数，然后单击 **启动策略** 按钮启动策略。

![Shell 快速入门 04](../../images/shell_quick_start_04.png)

与[实盘](user_interface/real_time.md)选项卡类似，也可以在[模拟](user_interface/emulation.md)选项卡中使用历史数据运行策略测试。

![Shell 快速入门 05](../../images/shell_quick_start_05.png)
