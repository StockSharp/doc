# Installer

**Installer** 是 **StockSharp** 所有程序和应用程序的管理中心，可用于：

- 下载并安装 [Designer](designer.md)、[Terminal](terminal.md) 和 [Hydra](hydra.md)。
- 安装 [MetaTrader](api/connectors/forex/metatrader.md) 插件连接器。
- 购买并安装 [Shell](shell.md)、[MATLAB](matlab.md) 等付费组件。
- 购买并解压 [Designer](designer.md) 等程序的源代码。
- 将程序与已购买的连接器一并安装。
- 监控程序更新过程。
- 下载 [API](api.md) 程序库并自动跟踪其更新。
