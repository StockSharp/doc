# MAR

**移动平均带 (MAR)** 是一种技术指标，它显示多个具有逐渐增加周期的移动平均线，以可视化趋势的强弱和方向。

使用该指标时，需要使用 [MovingAverageRibbon](xref:StockSharp.Algo.Indicators.MovingAverageRibbon) 类。

## 描述

移动平均线带 (MAR) 是一组在图表上以“带状”或“扇形”形式显示的多条移动平均线。该指标帮助交易者比使用一两条移动平均线更直观地观察当前趋势状态及其强度。

MAR 包括几条移动平均线（通常为 5 到 10 条），其周期逐步增加。周期之间的间隔可以是均匀的（例如 10、20、30、40……）或指数式的（例如 5、10、20、40……）。

主要观点是，这些移动平均线的相互位置和形状可以提供关于当前趋势状态和强度的有价值信息，并有助于识别潜在的反转点。

## 参数

该指标具有以下参数：
- **短周期** - 移动平均的初始（最小）周期（默认值：10）
- **长周期** - 移动平均线的最终（最大）周期（默认值：100）
- **RibbonCount** - 均线带中移动平均线的数量（默认值：10）

## 计算

移动平均带的计算包括以下步骤：

1. 确定移动平均线的周期序列：
   ```
   Step = (LongPeriod - ShortPeriod) / (RibbonCount - 1)
   Periods = [ShortPeriod, ShortPeriod + Step, ShortPeriod + 2*Step, ..., LongPeriod]
   ```

2. 计算每个周期的移动平均值：
   ```
   MAs = [对每个周期执行 SMA(价格, 周期)]
   ```

其中：
- Price - 价格（通常指收盘价）
- SMA - 简单移动平均
- ShortPeriod - 初始周期
- LongPeriod - 最终周期
- RibbonCount - 移动平均线的数量

注意：其他类型的移动平均线，如 EMA（指数移动平均线）、WMA（加权移动平均线）等，可以用来替代 SMA。

## 解释

移动平均带可以解释如下：

1. **移动平均线的相对位置**：
   - 当所有线条按周期升序排列（最短在上，最长在下）时，这表明强烈的上升趋势
   - 当所有线条按周期降序排列（最短在底部，最长在顶部）时，这表明强烈的下跌趋势
   - 当线条相交且没有明确顺序时，这表示横向趋势或不确定性

2. **均线带形状**：
   - 扩张的带状线（增加线间距）表示趋势增强
   - 缠缩线（行间距减小）表示趋势减弱
   - 线条紧密排列表示盘整或缺乏明显趋势

3. **移动平均交叉**：
   - 线条交叉的开始可能预示潜在的趋势变化
   - 当短期移动平均线开始穿越长期移动平均线时，这可能是趋势反转的早期信号

4. **均线带斜率**：
   - 陡峭的角度表示强烈的趋势
   - 浅角表示趋势疲软
   - 水平带状位置表示横向趋势

5. **价格相对于带状指标的位置**:
   - 当价格高于整个均线带时，这确认了强劲的上升趋势
   - 当价格低于整个均线带时，这确认了强烈的下跌趋势
   - 当价格在带状区域内波动时，这可能表明一种过渡状态或盘整

6. **交易策略**：
   - 当价格从趋势方向的带边反弹时开仓
   - 当移动平均线开始向相反方向交叉时退出持仓
   - 使用均线带宽度来设定止损和止盈
