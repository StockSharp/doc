# NRTR

**Nick Rypock 反向尾随 (NRTR)** — 该指标的本质是它始终位于已达到价格极值的区段上。这里实现的思想是：对主趋势的小幅修正性移动应被忽略，而高于某个水平的反主趋势移动则预示着逆向趋势。

要使用该指标，必须使用 [NickRypockTrailingReverse](xref:StockSharp.Algo.Indicators.NickRypockTrailingReverse) 类。
