# 决定系数

**线性回归中的R平方（线性回归R平方）**是一个技术指标，用于衡量线性回归对价格数据的拟合程度，并确定市场趋势的强度。

使用该指标需要使用 [LinearRegRSquared](xref:StockSharp.Algo.Indicators.LinearRegRSquared) 类。

## 描述

线性回归中的R平方（R²）是一种统计度量，用于评估价格数据与通过这些数据绘制的线性回归线之间的对应程度。在技术分析的背景下，R²显示当前价格走势与线性趋势的符合程度。

R²的取值范围从0到1（或0%到100%）：
- 接近1（100%）的值表明价格与趋势线非常吻合，意味着趋势强劲
- 接近0的数值表示缺乏线性趋势，这一特征通常出现在横盘、混乱或周期性市场中

该指标帮助交易者区分强趋势时期和盘整或横盘时期，从而使他们能够选择合适的交易策略。

## 参数

该指标具有以下参数：
- **Length** - 线性回归计算周期（默认值：14）

## 计算

线性回归中R平方的计算涉及以下步骤：

1. 在长度期间内为价格数据构建线性回归线：
   ```
   y = a + b*x
   ```
   在哪里：
   - y - 价格（因变量）
   - x - 期数序列号（自变量）
   - a - 自由项（y轴截距）
   - b - 斜率系数

2. 计算回归平方偏差和（SSE）:
   ```
   SSE = Sum((实际价格 - 预测价格)^2)
   ```
   在哪里：
   - 实际价格 - 实际价格
   - 预测价格 - 回归方程预测的价格

3. 计算平方和总和 (SST)：
   ```
   SST = Sum((实际价格 - 平均价格)^2)
   ```
平均价格是指在长度周期内的平均价格

4. 计算 R²：
   ```
   R² = 1 - (SSE / SST)
   ```

## 解释

线性回归中的R平方可以解释如下：

1. **趋势强度评估**:
   - 高于0.7（70%）的数值表示趋势强劲
   - 介于0.3到0.7（30-70%）之间的数值表示中等趋势
   - 低于0.3（30%）的数值表示趋势弱或没有趋势

2. **交易策略选择**：
   - 在高R²值（强趋势）下，趋势跟随策略是有效的
   - 在低R²值（横向波动）时，区间交易策略是有效的

3. **过渡点搜索**:
   - R² 的增加可能表明新趋势的形成
   - R²下降可能表示趋势减弱以及可能的盘整或反转

4. **信号过滤**：
   - 趋势指标的信号在高R²值时更可靠
   - 在低 R² 值下，振荡器信号更可靠

5. **与其他指标结合**：
   - R² 通常用于确定市场模式，之后应用适当的指标
   - 例如，使用 R² 高的移动平均线，以及 R² 低的随机振荡器

6. **市场可预测性评估**：
   - 高 R² 值表明短期内价格走势更可预测
   - 低 R² 值表示运动更加混乱和不可预测

7. **时间框架**：
   - R² 在不同的时间框架上可能产生不同的结果
   - 比较不同时期的R²可以提供关于市场结构的额外信息
