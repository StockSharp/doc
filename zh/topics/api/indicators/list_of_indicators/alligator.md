# 鳄鱼

**鳄鱼**指标由一组三条移动平均线组成。这些移动平均线的周期不同，并且在图表上向前移动。

要使用该指标，应使用[鳄鱼](xref:StockSharp.Algo.Indicators.Alligator)类。
##### "鳄鱼"指标的特征

指标由三条不同颜色的线组成：

- 蓝色，称为下颚，计算周期为13，移动8根柱。当它位于价格曲线下方时，表示潜在的价格上涨。如果“下颚”升到其上方，则预计会出现下跌。

- 红色，称为鳄鱼的牙齿，周期为8，偏移5个柱。它属于快速均线，显示小时范围内的价格行为。
  
- 绿色，称为唇线，周期为5，移动3个柱。它分析十二分钟的市场趋势。

这些数值是针对经典指标获取的，在设置中，总是可以指定您自己的参数。
