# DC

**唐奇安通道 (DC)** 是由交易员理查德·唐奇安开发的一种技术指标，由一个上轨和下轨（通道边界）组成，基于特定时期内的最高价和最低价。

要使用该指标，您需要使用 [DonchianChannels](xref:StockSharp.Algo.Indicators.DonchianChannels) 类。

## 描述

唐奇安通道是一种简单但有效的波动性和趋势指标。该指标由三条线组成：
- 上方线：所选期间的最高高点
- 下线：所选期间的最低低点
- 中线：上线和下线之间的平均值

根据理查德·唐奇安在他的四周通道规则中首次使用的这一指标，当价格超过四周内的最高点时产生买入信号，当价格跌破四周内的最低点时产生卖出信号。

唐奇安通道的用途包括：
- 识别市场波动
- 确定支撑和阻力位
- 生成突破信号
- 定义当前交易区间

## 参数

该指标具有以下参数：
- **长度** - 计算周期（默认值：20）

## 计算

唐奇安通道的计算非常简单：

1. 上通道线：
   ```
   Upper = Length 周期内 最高高点
   ```

2. 下通道线：
   ```
   Lower = Length 周期内 最低低点
   ```

3. 中通道线：
   ```
   Middle = (Upper + Lower) / 2
   ```

## 解释

唐奇安通道可以用多种方式使用：

1. **突破策略**：
   - 突破上通道线可以被视为买入信号
   - 跌破下通道线可以被视为卖出信号

2. **趋势判断**：
   - 如果价格位于通道的上半部分（中线上方），可以推断出一个上升趋势
   - 如果价格位于通道的下半部分（中线以下），可以推断出下行趋势

3. **支撑和阻力位**：
   - 上轨线可以作为阻力位
   - 下通道线可以作为支撑位

4. **波动性测量**:
   - 通道宽度（上下线之间的差异）表示市场波动性
   - 通道扩张表示波动性增加
   - 通道收缩表示波动性下降

5. **逆势策略**：
   - 一些交易者使用相反的信号，期望价格在到达通道边缘后回到中线
