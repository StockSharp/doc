# 自适应拉盖尔滤波器 (ALF)

**自适应拉盖尔滤波器（ALF）** 是一种指标，基于拉盖尔滤波器的数学原理开发，用于以最小延迟平滑价格数据。

要使用该指标，你需要使用 [AdaptiveLaguerreFilter](xref:StockSharp.Algo.Indicators.AdaptiveLaguerreFilter) 类。

## 描述

自适应拉盖尔滤波器是一种先进的市场噪声过滤工具。它在保持对真实趋势变化快速反应的同时，提供了更平滑的价格走势表现。该滤波器在减少传统平滑指标中常遇到的滞后方面特别有用。

ALF 相比经典移动平均的主要优势在于它能够更有效地将市场噪声与真实价格走势分离，对于希望减少虚假信号的交易者来说，这是一个有价值的工具。

## 参数

该指标具有以下参数：
- **伽玛** - 滤波系数（通常在0.1到0.9的范围内）

伽马参数决定平滑的程度：较低的值会产生更平滑但滞后更多的线条，而较高的值则会减少平滑，但对价格变化的反应更快。

## 计算

自适应拉盖尔滤波器基于拉盖尔多项式，并表示为有限脉冲响应（FIR）滤波系统。计算使用以下公式：

1. 中间值 L0、L1、L2 和 L3 的计算如下：
   ```
   L0(t) = (1 - γ) * price(t) + γ * L0(t-1)
   L1(t) = -γ * L0(t) + L0(t-1) + γ * L1(t-1)
   L2(t) = -γ * L1(t) + L1(t-1) + γ * L2(t-1)
   L3(t) = -γ * L2(t) + L2(t-1) + γ * L3(t-1)
   ```

2. 最终 ALF 值计算为平均值：
   ```
   ALF = (L0 + L1 + L2 + L3) / 4
   ```

地点：
- γ（伽马）- 过滤系数
- price(t) - 当前价格
- L0、L1、L2、L3 - 中间滤波器值
