# MCO

**麦克莱伦振荡器（MCO）** 是由Sherman和Marian McClellan开发的一种技术指标，通过分析上涨和下跌股票的移动平均差异来衡量市场广度。

使用该指标时，需要使用 [McClellanOscillator](xref:StockSharp.Algo.Indicators.McClellanOscillator) 类。

## 描述

麦克莱兰振荡器（MCO）是最著名的市场宽度指标之一，有助于评估整体市场状况并识别潜在的反转点。该指标于1969年开发，自此成为许多技术分析师的重要工具。

MCO 基于分析市场中上涨股票与下跌股票的比例。该指标计算净上涨股数（上涨股数与下跌股数之差）的19周期和39周期指数移动平均值之间的差值。

麦克莱兰振荡器特别适用于：
- 确定整体市场方向
- 识别超买和超卖条件
- 识别潜在的反转点
- 确认当前趋势的强弱

## 计算

McClellan 振荡器的计算涉及以下步骤：

1. 计算每个交易日的净增额：
   ```
   Net Advances = Advances - Declines
   ```
其中 Advances 是上涨股票的数量，Declines 是下跌股票的数量。

2. 计算净增值的19周期指数移动平均:
   ```
   EMA19 = EMA(Net Advances, 19)
   ```

3. 计算净增值的39周期指数移动平均:
   ```
   EMA39 = EMA(Net Advances, 39)
   ```

4. 将麦克莱伦振荡器计算为这两个指数移动平均线（EMA）之间的差值：
   ```
   MCO = EMA19 - EMA39
   ```

## 解释

麦克莱兰振荡器可以解释如下：

1. **零线交叉**：
   - MCO从下向上穿越零线可以被视为看涨信号，表明可能的上升趋势开始
   - MCO从上向下穿过零线可以被视为看跌信号，表明可能的下行趋势开始

2. **极端值**：
   - 高于 +100 的数值通常表示市场超买状态
   - 低于-100的数值通常表示市场超卖状态
   - 极端值（+150/-150及以上/以下）可能预示潜在的市场反转

3. **分歧**：
   - 看涨背离：指数创出新低，而MCO形成更高的低点
   - 看跌背离：指数创出新高，而MCO形成较低高点

4. **市场广度状态**：
   - 正的MCO值表明市场上大多数股票在上涨
   - 负的MCO值表明市场上大多数股票都在下跌

5. **移动加速/减速**：
   - MCO 值（正或负）的增加表示当前市场走势的加速
   - MCO 值下降表明当前市场走势放缓

6. **结合麦克莱兰累积指数**：
   - 麦克莱兰总结指数（MSI）是MCO值的累积和
   - MSI 越过零点可以确认 MCO 信号并指示长期趋势变化

7. **看涨/看跌形态**：
   - “看涨尾巴”——MCO快速下跌后迅速反弹，通常表示潜在的市场底部
   - “看跌尾巴”——快速的MCO上涨后紧随快速下跌，通常表示潜在的市场顶部
