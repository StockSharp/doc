# BV

**平衡成交量 (BV)** 是一个技术指标，用于根据价格变动跟踪成交量的累积和分配。

要使用该指标，您需要使用 [BalanceVolume](xref:StockSharp.Algo.Indicators.BalanceVolume) 类。

## 描述

平衡交易量（BV）指标旨在分析价格变动与交易量之间的关系。它帮助交易者判断交易量的变化如何对应价格的变动，这可以指示当前趋势的强弱。

BV 的主要理念是交易量应当确认价格方向。如果价格在交易量增加的情况下上升，则表明上涨趋势强劲。相反，如果价格在交易量增加的情况下下跌，则表明下跌趋势强劲。

BV 指标尤其适用于：
- 确认当前趋势的强度
- 识别潜在的趋势反转
- 检测价格与成交量之间的背离
- 确定积累和分配水平

## 计算

平衡量指标的计算基于将收盘价与前一个收盘价进行比较，并对交易量进行加权：

```
如果 Close > 前一收盘价：
	BV = 前一 BV + Volume
如果 Close < 前一收盘价：
	BV = 前一 BV - Volume
如果 Close = 前一收盘价：
	BV = 前一 BV
```

其中：
- 收盘价 - 当前收盘价格
- 前收盘价 - 前一交易日的收盘价
- 成交量 - 当前交易量
- 前BV - 前一余额量指标值

## 解释

- **随着价格上涨而上升的BV** - 确认上涨趋势，表明买方兴趣强烈
- **BV 随价格下跌** - 确认下降趋势，表明卖方兴趣强烈
- **账面价值上升而价格稳定或下降** - 潜在的积累，可能预示价格将反转向上
- **BV在价格稳定或上涨时下跌** - 潜在分布，可能预示价格即将下跌
- **BV与价格的背离** - 警示可能的趋势逆转：
  - 如果价格上涨而账面价值下降，可能很快会出现下跌反转
  - 如果价格下跌而账面价值上升，可能很快会出现向上的反转
