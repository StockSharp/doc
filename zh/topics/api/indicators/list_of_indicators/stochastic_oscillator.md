# 随机振荡器

**随机振荡器** 是一种动量指标，用于将某一交易品种的特定收盘价与其在某一时间段内的价格范围进行比较。通过调整此时间段或对结果取移动平均，可以降低振荡器对市场波动的敏感性。

要使用该指标，您必须使用 [StochasticOscillator](xref:StockSharp.Algo.Indicators.StochasticOscillator) 类。
