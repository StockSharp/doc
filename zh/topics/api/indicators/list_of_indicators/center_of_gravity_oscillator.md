# CGO

**重心振荡器（CGO）** 是由 John Ehlers 开发的一种技术指标，基于物理学中的重心概念，并应用于分析市场中的价格走势。

使用该指标时，需要使用 [CenterOfGravityOscillator](xref:StockSharp.Algo.Indicators.CenterOfGravityOscillator) 类。

## 描述

重心振荡器（CGO）是一种领先指标，通过将价格序列视为物理系统并确定其“重心”，试图识别市场反转点。该指标计算当前价格走势中的“平衡点”，并利用这些信息预测未来趋势方向的变化。

CGO 特别适用于：
- 在价格图表上显示之前识别潜在的反转点
- 揭示当前趋势的优势与劣势
- 检测价格与指标之间的隐藏背离
- 基于领先信号创建交易系统

## 参数

该指标具有以下参数：
- **Length** - 计算周期（默认值：10）

## 计算

重心振荡器（CGO）的计算基于以下公式：

```
CGO = - Sum(Price(i) * (i + 1)) / Sum(Price(i))
```

其中：
- i - 在从 0 到 (Length-1) 的期间的价格值指数
- Price(i) - 对应指数 i 的价格（通常为收盘价）
- 总和 - 长度周期内所有值的总和

在这个公式中，每个价格按其在时间序列中的位置加权，然后除以价格的总和进行标准化。公式前的负号是为了使指标在价格上涨时上升，从而更直观。

## 解释

- **零线穿越**：当 CGO 从下向上穿越零线时，这可以被视为看涨信号。从上向下穿越可能表示看跌信号。

- **指标极值**：当CGO达到极值（最大值或最小值）时，这可能表明潜在的趋势反转。

- **分歧**: 
  - 看涨背离：当价格形成新低点，但CGO未确认，形成更高的低点。
  - 看跌背离：当价格达到新高时，但CGO形成了一个较低的高点。

- **指标运动**：CGO快速朝一个方向移动可能表示新趋势的开始。如果指标缓慢移动或围绕零线震荡，这可能表示市场整合。

由于CGO是一个领先指标，它的信号通常出现在价格图表相应变化之前，为交易者在做出交易决策时提供了优势。
