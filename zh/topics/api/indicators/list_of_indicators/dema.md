# 双指数移动平均

**双重指数移动平均线 (DEMA)** 使用多个（双重）指数移动平均线（EMA）来消除预测价格时的滞后。

要使用该指标，您必须使用 [DoubleExponentialMovingAverage](xref:StockSharp.Algo.Indicators.DoubleExponentialMovingAverage) 类。
