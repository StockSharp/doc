# 移动中位数

“移动中位数”指标计算最近 N 个值的中位数。与移动平均线相比，它不易受异常值影响，同时能保留价格的突然变化，因此适用于噪声较大的市场环境。

使用 [Median](xref:StockSharp.Algo.Indicators.Median) 类以访问指标。

## 描述

中值滤波器对移动窗口内的价格进行排序，并选择中间值。因此：

- 单个尖峰或下降不会扭曲输出。
- 滞后比许多平滑滤波器要小。
- 信号的形状保持较为角状，有助于捕捉反转。

## 参数

- **长度** — 用于计算中位数的窗口大小。较大的窗口提供更强的平滑效果，但会增加延迟。

## 使用

- 当价格数据包含显著噪声时，将移动中位数作为移动平均的替代方法。
- 价格与中位数之间的交叉可以被视为趋势变化信号。
- 将中位数与其他滤波器结合使用，以提取趋势，同时保留重要的价格跳跃。
