# 标准差

**标准差** 是一个显示交易品种价格波动范围的指标，用于表征其波动性。通常，该指标的数值以所分析资产的价格单位表示。标准差是标准价格偏差的函数，该函数在数理统计中被广泛使用。

使用该指标，必须使用 [StandardDeviation](xref:StockSharp.Algo.Indicators.StandardDeviation) 类。
