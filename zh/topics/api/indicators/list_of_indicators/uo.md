# UO

**终极振荡器 (UO)** 是由拉里·威廉姆斯（Larry Williams）于1976年开发的一种技术指标，用于衡量多时间框架的动量。通过对三个不同时间框架使用加权平均，该指标与依赖单一时间框架的其他指标相比，波动较小，交易信号也较少。

要使用该指标，您必须使用 [UltimateOscillator](xref:StockSharp.Algo.Indicators.UltimateOscillator) 类。
