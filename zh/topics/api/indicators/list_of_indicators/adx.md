# ADX

**韦尔斯·威尔德的ADX（平均趋向指数）**是一组方向性移动指标。构成方向性移动指标（DMI）的线包括：ADX、DI+ 和 DI-。ADX表示趋势强度，DI+ 和 DI- 表示当前价格方向。

要使用该指标，必须使用 [AverageDirectionalIndex](xref:StockSharp.Algo.Indicators.AverageDirectionalIndex)。
