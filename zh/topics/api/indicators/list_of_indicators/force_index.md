# FI

**力度指标（FI）** 是由亚历山大·埃尔德博士开发的技术指标，用于根据价格变动的方向、幅度和交易量来衡量每次价格变动的强度。

要使用该指标，您需要使用 [ForceIndex](xref:StockSharp.Algo.Indicators.ForceIndex) 类。

## 描述

动力指数是一种振荡器，用于衡量每次价格变动中“多头”（买方）或“空头”（卖方）的力量。它结合了市场信息的三个重要要素：价格变动方向、变动幅度和交易量。

该指标的主要理念是，价格变化越大且交易量越大，市场运动就越强。正的动力指数值表示买方占主导（看涨压力），而负值表示卖方占主导（看跌压力）。

动力指数尤其适用于：
- 确定当前趋势的强度
- 识别潜在的反转点
- 确认突破
- 检测价格与走势强度之间的背离

## 参数

该指标具有以下参数：
- **周期** - 平滑周期（默认值：13）

## 计算

力量指数计算涉及以下步骤：

1. 计算单周期力量指数：
   ```
   单周期力量指数 = (Close[current] - Close[previous]) * Volume[current]
   ```

2. 使用指数移动平均（EMA）进行平滑：
   ```
   力量指数 = EMA(单周期力量指数, Length)
   ```

其中：
- 收盘价
- 成交量 - 交易量
- EMA - 指数移动平均
- 长度 - 平滑期

## 解释

力量指数可以有多种解读方式：

1. **零线交叉**：
   - 从负值转向正值表明看涨压力增加，可以被视为买入信号
   - 从正值转为负值表明看跌压力增加，可以被视为卖出信号

2. **极端值**：
   - 高正值表示强劲的看涨压力，可能导致市场超买状况
   - 高负值表示强烈的看跌压力，可能导致市场超卖状态

3. **分歧**：
   - 看涨背离（价格形成新低，而能量指数形成更高的低点）可能预示潜在的向上反转
   - 看跌背离（价格形成新高，而能量指标形成较低的高点）可能预示潜在的下跌反转

4. **趋势确认**:
   - 持续为正的力度指标数值证实了上升趋势的强度
   - 持续为负的力度指数数值证实了下跌趋势的强度

5. **三重用途**（根据长老的说法）：
   - 短期能量指数（2天）：用于识别短期机会
   - 中期强弱指数（13天）：用于确定中期趋势和调整
   - 长期力量指数（100天）：用于识别主要趋势

6. **纠正识别**：
   - 在上升趋势中，负的力量指数日可能表示暂时的回调
   - 在下行趋势中，正的力量指数日可能表示短暂反弹
