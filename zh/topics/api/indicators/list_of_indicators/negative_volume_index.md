# 新国际版

**负量指标（NVI）** 是由保罗·迪萨特（Paul Dysart）开发的技术指标，侧重于交易量相比前一天下降时的价格变化。

要使用该指标，需要使用 [NegativeVolumeIndex](xref:StockSharp.Algo.Indicators.NegativeVolumeIndex) 类。

## 描述

负成交量指数（NVI）基于这样的观点：在低成交量的日子里，“聪明资金”更活跃，而“群众”（非专业交易者）在高成交量的日子里更活跃。NVI 仅在当天成交量低于前一天成交量时才发生变化。

该指标的概念表明，成交量减少时的价格变动更为重要，通常反映了有信息的投资者的行为。NVI 旨在追踪这些变动，而忽略成交量增加日的价格变化。

NVI 通常与互补的正成交量指数（PVI）一起使用，相反，PVI 仅考虑成交量增加的日子。

## 计算

负量指数的计算包括以下步骤：

1. 设置初始 NVI 值（通常为 1000）：
   ```
   NVI[initial] = 1000
   ```

2. 对于每一个后续时期：
   ```
   If Volume[current] < Volume[previous], then:
       NVI[current] = NVI[previous] * (1 + (Price[current] - Price[previous]) / Price[previous])
   Otherwise:
       NVI[current] = NVI[previous]
   ```

地点：
- 价格 - 价格（通常指收盘价）
- 成交量 - 交易量

换句话说，NVI 仅在交易量减少的日子发生变化，而在交易量增加或保持不变的日子则保持不变。

## 解释

负成交量指标可以解释如下：

1. **趋势分析**:
   - NVI上升表明“聪明资金”正在买入，这可能预示未来价格上涨
   - NVI下降表明“聪明资金”正在抛售，这可能预示未来价格下跌

2. **移动平均交叉**：
   - NVI 通常与其 255 日移动平均线（大约一年的交易时间）进行比较
   - 当NVI高于其255天SMA时，被视为看涨信号
   - 当NVI低于其255天SMA时，被视为看跌信号

3. **分歧**：
   - 看涨背离：价格形成新低，而NVI形成更高的低点
   - 看跌背离：价格形成新高，而NVI形成较低的新高

4. **结合 PVI**：
   - 当 NVI 和 PVI 都在上升时，这是一个强烈的看涨信号
   - 当 NVI 和 PVI 都在下降时，这是一个强烈的看跌信号
   - 当 NVI 上升而 PVI 下降时，可能表明“聪明资金”在买入，而“大众”在卖出（潜在的看涨情景）
   - 当 NVI 下降而 PVI 上升时，可能表明“聪明资金”在抛售，而“大众”在购买（可能的看跌情景）

5. **长期变化**：
   - NVI 通常被视为长期指标
   - NVI方向的持续变化可能预示市场情绪的重大转变

6. **确认其他指标**：
   - NVI 在与其他技术指标和分析方法结合使用时效果最佳
   - 当其他指标确认时，NVI信号变得更可靠

7. **设置阈值**：
   - 一些交易者为NVI（e.g.，高于或低于移动平均线5%）设定阈值水平
   - 穿越这些门槛可能被认为比简单的交叉更强的信号
