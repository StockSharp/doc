# 成交量加权移动平均

**成交量加权移动平均线 (VWMA)** - 该指标显示某一时间段的成交量加权价格。该指标以波浪线形式跟随价格，相对于价格图表具有一定的偏差。

使用该指标，必须使用 [VolumeWeightedMovingAverage](xref:StockSharp.Algo.Indicators.VolumeWeightedMovingAverage) 类。
