# 一目均衡表

**一目均衡表** 是一个由五条线组成的指标，其中三条是移动平均线，两条是它们的衍生线。一目均衡表可以识别趋势的存在，并指出支撑/阻力区域及趋势回调。

要使用该指标，应使用 [Ichimoku](xref:StockSharp.Algo.Indicators.Ichimoku) 类。
##### 一目均衡表指标简介

图形上，该指标由五条彩色线组成，类似于简单移动平均线：

- 转换线（Tenkan）——最快的线，对价格变化反应最先。其主要目的是确定短期趋势的方向。在经典版本中，它取回9个周期的区间。它的构建方法是将最高价与最低价的和除以二。
  
- 基准线（Kijun）——表示中期趋势，周期为26。
  
- 先行A线和先行B线——向未来26个周期进行投影和显示，它们共同形成所谓的云（Kumo），显示支撑和阻力区域，并且是该指标的关键组成部分。
  
- 遲行線（Chikou）——表示最后的收盘价，向回移动26个周期。它有助于确认信号：如果它从下向上穿过图表，这是买入信号；如果从上向下穿过图表，则是卖出信号。本质上，遲行線起到趋势过滤器的作用。
