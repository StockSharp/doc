# GMMA

**古比多重移动平均线（GMMA）** 是由 Daryl Guppy 开发的一种技术指标，它使用两组指数移动平均线（EMA）来揭示短期交易者与长期投资者之间的互动。

要使用该指标，您需要使用 [GuppyMultipleMovingAverage](xref:StockSharp.Algo.Indicators.GuppyMultipleMovingAverage) 类。

## 描述

古比多重移动平均线（GMMA）由两组指数移动平均线（EMA）组成：
1. **短期组**（通常为3、5、8、10、12和15周期）——代表短期交易者的活动
2. **长期组**（通常为30、35、40、45、50和60周期）——代表长期投资者的活动

GMMA 允许可视化这两个市场参与者群体之间的互动，并确定市场是处于趋势状态还是盘整状态。该指标还帮助识别短期交易者开始跟随长期投资者相同方向的时刻，这通常表示趋势的形成或强化。

GMMA 尤其适用于：
- 确定当前趋势的强度和方向
- 识别潜在的趋势反转
- 识别市场何时从盘整转向趋势
- 确定进入现有趋势的最佳时机

## 计算

GMMA 计算涉及计算两组指数移动平均线：

1. 短期EMA组：
   ```
   EMA_3 = EMA(Price, 3)
   EMA_5 = EMA(Price, 5)
   EMA_8 = EMA(Price, 8)
   EMA_10 = EMA(Price, 10)
   EMA_12 = EMA(Price, 12)
   EMA_15 = EMA(Price, 15)
   ```

2. 长期 EMA 组：
   ```
   EMA_30 = EMA(Price, 30)
   EMA_35 = EMA(Price, 35)
   EMA_40 = EMA(Price, 40)
   EMA_45 = EMA(Price, 45)
   EMA_50 = EMA(Price, 50)
   EMA_60 = EMA(Price, 60)
   ```

地点：
- EMA - 指数移动平均
- 价格 - 价格（通常指收盘价）

## 解释

GMMA的解读包括分析各个独立组别及它们的相互作用：

1. **团队定位**：
   - 当短期组高于长期组时，表示上升趋势
   - 当短期组低于长期组时，表示下行趋势

2. **组间距离**：
   - 组间距离大表明趋势强
   - 小距离或小组交叉表示趋势疲弱或盘整

3. **压缩与扩展**:
   - 一组内的线路压缩（汇聚）表示不确定性和可能的整合
   - 组内线条的扩展（发散）表明趋势增强

4. **交叉**：
   - 短期均线从下向上穿过长期均线——强烈看涨信号
   - 短期群体从上到下穿越长期群体——强烈看跌信号

5. **方向变化**：
   - 当长期群体开始改变方向时，这表明长期投资者情绪发生了重大变化
   - 短期的群体反转而长期群体不变通常表示暂时的调整

6. **最佳入市点**:
   - 在强烈扩张之后，可能会发生压缩，表明趋势内的修正
   - 这种压缩结束时（新的扩展）可以成为顺应主要趋势的良好入场点

7. **早期反转警告**：
   - 短期均线先改变方向，然后长期均线开始出现变化
   - 组间交叉可以作为趋势反转的确认
