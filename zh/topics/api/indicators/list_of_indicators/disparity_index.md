# DPI

**差异指数 (DPI)** 是一个技术指标，用于衡量当前价格相对于特定时期移动平均线的相对偏离，以百分比表示。

使用该指标需要使用 [DisparityIndex](xref:StockSharp.Algo.Indicators.DisparityIndex) 类。

## 描述

差距指数（DPI）旨在衡量价格偏离其移动平均线的程度。该指标有助于确定价格相对于其平均值的“拉伸”程度，可用于识别潜在的超买或超卖情况。

DPI 基于价格在显著偏离后倾向于回归其平均值的假设。偏离越大，随后价格向相反方向运动的概率越高，从而使其更接近平均值。

差距指数的用途包括：
- 识别价格偏离其均值的极端情况
- 检测潜在的反转点
- 衡量当前趋势的强度
- 基于均值回归的交易策略创建

## 参数

该指标具有以下参数：
- **长度** - 用于计算移动平均的周期（默认值：14）

## 计算

差异指数的计算公式非常简单：

```
DPI = ((Price / MA) - 1) * 100
```

其中：
- 价格 - 当前价格（通常是收盘价）
- MA - 在长度周期内的价格移动平均
- 结果以百分比表示

正DPI值表示价格高于其移动平均线，而负值则表示价格低于其移动平均线。

## 解释

差异指数可以解释如下：

1. **极端水平**：
   - 高正值（e.g.，高于 +10%）可能表明市场超买状况
   - 高负值（e.g.，低于 -10%）可能表示市场超卖状态

2. **零线交叉**：
   - 从下向上穿越（从负值到正值）表示价格已经从下向上穿过其移动平均线，这可以被视为看涨信号
   - 从上到下穿越（从正值到负值）表示价格已经从上方穿过其移动平均线，这可以被视为看跌信号

3. **分歧**：
   - 看涨背离：价格创出新低，但DPI形成更高的低点
   - 看跌背离：价格达到新高，但DPI形成了较低的高点

4. **趋势分析**:
   - 持续为正的DPI值表明强劲的上升趋势
   - 持续为负的DPI值表明存在明显的下降趋势
   - 围绕零的振荡可能表明横向趋势或盘整

5. **均值回归策略**：
   - 极端 DPI 值可以用来开立与当前价格走势相反的持仓，期望回归均值
