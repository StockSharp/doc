# III

**日内强度指数（III）** 是由David Bostian开发的一个技术指标，用于评估交易日内收盘价、价格区间和交易量之间的关系。

要使用该指标，您需要使用[IntradayIntensityIndex](xref:StockSharp.Algo.Indicators.IntradayIntensityIndex)类。

## 描述

日内强度指数（III）结合了价格变动和交易量的信息，以评估交易日内买卖压力的强度。该指标基于这样一种假设：收盘价相对于当天价格区间的位置，结合交易量，可以指示市场运动的方向和强度。

III 对于识别日内市场情绪的变化和确定潜在反转点尤其有用。指标为正值表示买盘压力（收盘价接近当日最高价），而指标为负值表示卖压（收盘价接近当日最低价）。

日内强度指数特别适用于：
- 识别盘中市场情绪的变化
- 确定潜在的反转点
- 确认其他指标的信号
- 评估当前趋势的强度

## 参数

该指标具有以下参数：
- **Length** - 平滑周期（默认值：14）

## 计算

日内强度指数的计算涉及以下步骤：

1. 计算每个时期的个体 III 值：
   ```
   原始 III = ((2 * Close - High - Low) / ((High - Low) * Volume)) * Volume
   ```

2. 使用简单移动平均进行平滑处理：
   ```
   III = SMA(原始 III, Length)
   ```

其中：
- 收盘价
- 最高价 - 期间最高价格
- 最低价 - 本周期最低价格
- 成交量 - 交易量
- SMA - 简单移动平均
- 长度 - 平滑期

## 解释

日内强度指数可以解释如下：

1. **零线交叉**：
   - 从负值转向正值可以被视为看涨信号，表明买入压力增加
   - 从正值转为负值可以被视为看跌信号，表明卖压增加

2. **极端值**：
   - 高正值表示强劲的买入压力
   - 高负值表示强烈的卖压
   - 极端值可能表明市场超买或超卖状况

3. **分歧**：
   - 看涨背离：价格创出新低，而III形成更高的低点
   - 看跌背离：价格创出新高，而 III 创出较低高点

4. **三、趋势**：
   - 持续为正的 III 值确认了上升趋势
   - 持续为负的 III 值证实了下降趋势
   - 围绕零线的振荡可能表明横向趋势或不确定性

5. **与其他指标结合**：
   - III 常常与其他技术指标结合使用以确认信号
   - 尤其在与趋势和成交量指标结合时效果显著

6. **价值观的变化**：
   - 从负值迅速变化到正值可能表明市场情绪发生了急剧转变
   - 逐渐接近零线可能表明当前动量正在减弱
