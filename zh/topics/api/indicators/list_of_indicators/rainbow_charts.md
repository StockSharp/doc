# RC

**彩虹图表（RC）** 是一种技术分析指标，由一组不同周期的移动平均线组成，并显示在同一张图表上。从视觉上看，该指标类似彩虹，因此得名。

要使用该指标，你需要使用 [RainbowCharts](xref:StockSharp.Algo.Indicators.RainbowCharts) 类。

## 描述

彩虹图是基于使用多个移动平均线（通常是简单移动平均线SMA）且周期逐步增加来构建的。不同的移动平均线用不同的颜色表示，在图表上形成彩虹效果。

该指标有助于确定趋势的方向和强度：
- 当线条发散时，这表明趋势在加强
- 当线条汇聚时，这可能表示趋势减弱或潜在的反转
- 当价格高于所有线时，表明有强烈的上升趋势
- 当价格低于所有线时，表明有强烈的下跌趋势

## 参数

- **线条** - 彩虹图中使用的SMA移动平均线的数量。

## 计算

彩虹图由多条移动平均线（SMA）组成，每条后续线的周期按一定步长增加。对于基周期为 p 的 n 条线，周期计算如下：

```
Period(i) = p + i * step
```

其中：
- i - 行号（从 0 到 n-1）
- 步长 - 周期增加步长（通常为1）
