# FOSC

**预测振荡器 (FOSC)** 是一种技术指标，用于测量价格与通过线性回归获得的预测值之间的偏差，并将该偏差表示为百分比。

要使用该指标，需要使用 [ForecastOscillator](xref:StockSharp.Algo.Indicators.ForecastOscillator) 类。

## 描述

预测振荡器（FOSC）基于线性回归，旨在测量当前价格与其预测值的偏离程度。它帮助交易者评估当前价格与预期趋势的吻合程度或偏离程度。

该指标通过在指定周期内进行线性回归计算趋势线，然后将实际收盘价与该趋势线的预测值进行比较。差异以百分比表示，使FOSC成为围绕零线波动的振荡器。

预测振荡器特别适用于：
- 确定价格与预期趋势的一致程度
- 识别潜在的反转点
- 检测价格偏离趋势的极端情况
- 识别价格变动快于或慢于预期的时期

## 参数

该指标具有以下参数：
- **长度** - 线性回归计算周期（默认值：14）

## 计算

预测振荡器的计算涉及以下步骤：

1. 使用线性回归在指定期间计算预测线：
   ```
   预测值 = 线性回归线(Close, Length)
   ```

2. 将振荡器计算为当前价格与预测值之间的百分比比率：
   ```
   FOSC = ((Close - 预测值) / 预测值) * 100
   ```

其中：
- 收盘价 - 当前收盘价格
- 预测 - 通过线性回归得到的预测值
- 长度 - 线性回归计算周期

## 解释

预测振荡器的解释如下：

1. **偏离零**：
   - 正值（FOSC > 0）表示当前价格高于预测值，这可能表明上涨走势比预期更强
   - 负值（FOSC < 0）表示当前价格低于预测值，这可能表明下跌幅度比预期更大

2. **极端值**：
   - 非常高的正值可能表明相对于趋势市场处于超买状态
   - 非常低的负值可能表明相对于趋势市场处于超卖状态

3. **回到零**：
   - FOSC从极值向零移动可能预示价格有可能回到其趋势线

4. **零线交叉**：
   - 从下向上穿越零线可以被视为看涨信号
   - 从上向下穿越零线可以被视为看跌信号

5. **分歧**：
   - 看涨背离（价格形成新低，而FOSC形成更高的低点）可能表明潜在的向上反转
   - 看跌背离（价格形成新高，而FOSC形成较低的高点）可能表明潜在的向下反转

6. **趋势确认**:
   - 如果FOSC与价格同方向移动，这确认了当前趋势的强度
   - 如果 FOSC 的移动方向与价格相反，这可能表明当前趋势正在减弱
