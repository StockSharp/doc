# MOMA

**移动平均动量 (MOMA)** 是一种技术指标，用于衡量移动平均价格的变化速度，结合了动量和移动平均的概念。

要使用该指标，您需要使用 [MomentumOfMovingAverage](xref:StockSharp.Algo.Indicators.MomentumOfMovingAverage) 类。

## 描述

移动平均动量（MOMA）是两种指标的组合——动量指标和移动平均线。首先，计算价格序列的移动平均线，然后测量该移动平均线的动量（变化率）。

MOMA的主要思想是首先使用移动平均线平滑价格序列，从而去除市场噪音，然后分析该平滑曲线的变化速度和方向。这比直接从价格计算动量能获得更清晰的趋势动量变化信号。

MOMA通过关注移动平均线动态的变化，而不是价格本身，帮助确定趋势强度和潜在的反转点。正的MOMA值表示移动平均线向上的动量，而负值表示向下的动量。

## 参数

该指标具有以下参数：
- **长度** - 移动平均计算周期（默认值：14）
- **MomentumPeriod** - 动量计算周期（默认值：10）

## 计算

移动平均动量的计算涉及以下步骤：

1. 计算价格序列的移动平均值：
   ```
   MA = SMA(Price, Length)
   ```

2. 计算移动平均动量：
   ```
   MOMA = MA[current] - MA[current - MomentumPeriod]
   ```

其中：
- 价格 - 价格（通常指收盘价）
- SMA - 简单移动平均
- 长度 - 移动平均周期
- MomentumPeriod - 动量计算周期

注意：其他类型的移动平均线，例如EMA（指数移动平均线）、WMA（加权移动平均线）等，也可以替代SMA使用。

## 解释

移动平均的动量可以解释如下：

1. **零线交叉**：
   - MOMA 从下向上穿越零线可以被视为看涨信号，表明上升趋势的开始或加强
   - MOMA 从上向下穿越零线可以被视为看跌信号，表明下降趋势的开始或增强

2. **绝对值**：
   - 高正 MOMA 值表示强劲的向上移动平均动量
   - 高负MOMA值表示强烈的向下移动平均动量
   - 接近零的数值表示没有明显的动量或呈横盘趋势

3. **分歧**：
   - 看涨背离：价格形成新低，而MOMA形成更高的低点
   - 看跌背离：价格形成新高，而MOMA形成较低的高点

4. **方向改变**:
   - 当 MOMA 改变移动方向（从上升变为下降或反之），这可能预示着移动平均趋势的潜在变化
   - 这种反转通常预示价格方向的变化

5. **趋势确认**:
   - 正的MOMA值确认了上升趋势
   - 负的MOMA值确认了下降趋势
   - MOMA 值的增加表明当前趋势正在加强
   - MOMA 值下降表明当前趋势正在减弱

6. **信号过滤**：
   - MOMA 可用于过滤来自其他指标的信号
   - 例如，当 MOMA 为正时只考虑看涨信号，当 MOMA 为负时只考虑看跌信号

7. **参数选择**：
   - 较短的长度周期和动量周期会使MOMA更敏感，但也更容易产生虚假信号
   - 较长的周期使 MOMA 更平滑，但可能导致信号滞后
