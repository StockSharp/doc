# EMV

**运动轻松度 (EMV)** 是由 Richard Arms 开发的一个技术指标，它将价格变化与成交量相关联，以评估价格向上或向下移动的难易程度。

要使用该指标，您需要使用 [EaseOfMovement](xref:StockSharp.Algo.Indicators.EaseOfMovement) 类。

## 描述

易动性 (EMV) 指标是用于衡量价格变动与成交量之间关系的工具。该指标的主要概念是，在上涨趋势中，价格应在较少的成交量下轻松上升；而在下跌趋势中，价格也应在较少的成交量下轻松下跌。

EMV 将价格区间、价格变化和成交量的信息结合起来，创建一个衡量价格运动“轻松度”的指标。EMV 为正值意味着价格相对轻松地上涨，而负值则表示价格相对轻松地下跌。

该指标特别适用于：
- 确认当前趋势的强弱
- 识别潜在的反转点
- 使用价格检测背离
- 考虑成交量评估价格走势的“质量”

## 参数

该指标具有以下参数：
- **周期** - 平滑周期（默认值：14）

## 计算

易动指标的计算涉及以下步骤：

1. 计算中点移动：
   ```
   中点 = (High + Low) / 2
   中点移动 = 中点[current] - 中点[previous]
   ```

2. 计算箱体比（体积-距离系数）：
   ```
   箱体比率 = Volume / (High - Low)
   ```

3. 计算单期期望货币价值（EMV）:
   ```
   单周期 EMV = 中点移动 / 箱体比率
   ```

4. 平滑以获得最终 EMV：
   ```
   EMV = SMA(单周期 EMV, Length)
   ```

其中：
- 最高价 - K线的最高价格
- 最低价 - K线的最低价格
- 成交量 - 交易量
- SMA - 简单移动平均

## 解释

EMV指标可以解释如下：

1. **零线交叉**：
   - 从下向上穿越（从负值到正值）可以被视为看涨信号，表明价格开始轻松上升
   - 从上到下穿越（从正值到负值）可以被视为看跌信号，表明价格开始轻松下跌

2. **极端值**：
   - 高正值表示价格非常容易上涨（成交量很小）
   - 高负值表示价格非常容易下跌（成交量很小）

3. **分歧**：
   - 看涨背离：价格创出新低，而EMV形成更高的低点（可能表明潜在的向上反转）
   - 看跌背离：价格创出新高，而EMV形成较低的高点（可能预示潜在的下跌反转）

4. **EMV趋势**：
   - 持续的正值确认了上升趋势
   - 持续的负值证实了下降趋势
   - 围绕零的振荡可能表明横向趋势或盘整

5. **成交量分析**：
   - 如果价格在正的EMV下上涨，这确认了上涨走势的力量
   - 如果价格在负的EMV下下跌，这确认了下行趋势的强度
   - 如果价格在负的期望货币价值（EMV）下上涨，或在正的期望货币价值（EMV）下下跌，这可能表明当前走势的不稳定性
