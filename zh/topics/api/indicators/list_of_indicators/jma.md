# JMA

**Jurik 移动平均线 (JMA)** 是一种移动平均线的变体。该指标的曲线特点是平滑度良好，同时在价格走势结束后前导时间最小，并且在强价格走势中滞后最小。

要使用该指标，应使用 [JurikMovingAverage](xref:StockSharp.Algo.Indicators.JurikMovingAverage) 类。

##### 指标设置

- 相位 - 决定移动平均展开的速度；
- 周期 - 决定移动平均线的周期。
