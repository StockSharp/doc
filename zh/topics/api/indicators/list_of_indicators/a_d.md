# 加速/减速指标 (A/D)

**加速/减速指标 (A/D)** 是由比尔·威廉姆斯创建的振荡器。它测量趋势动量的加速和减速。

要使用该指标，应使用 [Acceleration](xref:StockSharp.Algo.Indicators.Acceleration) 类。
##### 计算

A/D柱状图是驱动力的5/34柱状图的值与从该柱状图中取出的5周期简单移动平均值之间的差值。数值用于经典振荡器，并且在设置中总是可以指定您自己的参数。

中值价格 = (最高价 + 最低价) / 2
AO = SMA(中值价格, 5) - SMA(中值价格, 34)
A/D = AO - SMA(AO, 5)

其中：

中值价格 — 中间价格;
最高价 — 该柱的最高价格;
最低价 — 该柱的最低价格;
SMA — 简单移动平均;
AO — [超级振荡器](ao.md)指标.

参数设置为SMA周期值。
