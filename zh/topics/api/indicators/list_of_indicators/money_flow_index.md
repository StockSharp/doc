# 资金流向指数

**资金流量指标 (MFI)** 计算流入和流出资金的差额。如果资产的基础值低于该差额，说明流入资金增加，意味着市场看涨。如果观察到相反情况，则表示投资者正在撤离该工具，市场呈现看跌。
该指标是一种技术振荡器，用于确定资产的超买或超卖情况。它还可以用于识别发出价格趋势变化警告的背离。振荡器在 0 到 100 之间波动。

要使用该指标，应使用 [MoneyFlowIndex](xref:StockSharp.Algo.Indicators.MoneyFlowIndex) 类。
