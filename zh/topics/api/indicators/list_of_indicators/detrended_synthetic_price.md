# DSP

**去趋势合成价格 (DSP)** 是一种技术指标，用于从价格序列中去除整体趋势，使交易者能够专注于短期价格波动。

要使用该指标，您需要使用 [DetrendedSyntheticPrice](xref:StockSharp.Algo.Indicators.DetrendedSyntheticPrice) 类。

## 描述

DSP 指标的开发目的是从价格图表中消除长期趋势，使交易者能够更清楚地看到短期周期和振荡。它对于识别可能被主导趋势掩盖的短期交易机会尤其有用。

DSP 的主要思想是，通过消除价格序列中的趋势，可以更容易地识别价格运动的周期性成分。这使得该指标对于专注于短期交易并使用周期性模式的交易者特别有价值。

DSP 的用途包括：
- 识别短期市场周期
- 确定潜在的反转点
- 使用价格检测背离
- 基于市场周期性创建交易系统

## 参数

该指标具有以下参数：
- **长度** - 计算周期（默认值：10-20周期）

## 计算

计算去趋势合成价格涉及以下步骤：

1. 计算指定周期内的价格移动平均值：
   ```
   MA = SMA(Price, Length)
   ```

2. 确定合成价格计算的偏移量：
   ```
   Offset = (Length / 2) + 1
   ```

3. 通过从当前价格中减去平移移动平均线来计算合成价格：
   ```
   DSP = Price - MA[向前回溯 (Length/2) + 1 个周期]
   ```

其中：
- 价格 - 当前价格（通常是收盘价）
- MA - 简单移动平均
- 长度 - 选定的计算周期

## 解释

DSP 指标在零线附近振荡，可以解释如下：

1. **零线交叉**：
   - 当DSP从下向上穿过零线时，可以视为看涨信号
   - 当DSP从上向下穿过零线时，可以视为看跌信号

2. **指标极值**：
   - 当DSP达到极高值时，可能表明市场处于超买状态
   - 当DSP达到极低值时，可能表示市场超卖状况

3. **周期分析**：
   - 常规DSP振荡可用于确定市场周期周期性
   - 振幅变化可能表明市场动态的变化

4. **分歧**：
   - 看涨背离：价格创出新低，而 DSP 创出更高的低点
   - 看跌背离：价格创出新高，而 DSP 创出较低高点

5. **图案形成**：
   - 技术形态（头肩顶、双底等）可以在DSP图表上形成，可能提供额外的交易信号
