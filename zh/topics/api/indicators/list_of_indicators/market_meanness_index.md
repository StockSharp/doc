# MMI

**市场“刻薄”指数（MMI）** 是一个技术指标，用于判断市场是否处于趋势状态或横盘（混乱）状态。

要使用该指标，您需要使用 [MarketMeannessIndex](xref:StockSharp.Algo.Indicators.MarketMeannessIndex) 类。

## 描述

市场“刻薄”指数（MMI）是一种帮助交易者判断当前市场性质的工具——无论是趋势市场还是横盘市场。“刻薄”这个名字反映了市场有时会对交易者表现得“刻薄”或不可预测，尤其是在横盘运动时。

MMI 基于计算不遵循简单线性模式的价格值对（通常是收盘价）的数量，以及它们与分析总对数的比率。该指标衡量特定时期内价格运动的“混乱”或“随机性”。

指数在 0 到 100 之间波动：
- 低值（通常低于50）表示趋势运动占主导
- 高值（通常超过50）表示横向或混乱运动占主导

## 参数

该指标具有以下参数：
- **长度** - 计算周期（默认值：20）

## 计算

市场“刻薄”指数的计算包括以下步骤：

1. 在给定的长度周期内创建一组连续的收盘价（Close）对。

2. 计算“非连续”对的数量。如果一对不遵循趋势的线性模式，则认为该对是非连续的。如果两个连续的对（P1, P2）和（P2, P3）方向相反（差值符号不同），则该对被认为是非连续的。

3. 将 MMI 计算为百分比比率：
   ```
   MMI = (Number of non-sequential pairs / Total number of pairs) * 100
   ```

形式上，这可以表示为：
1. 对于每组三个连续的价格（Close[i-2]，Close[i-1]，Close[i]），检查：
   - 如果 (Close[i-1] - Close[i-2]) * (Close[i] - Close[i-1]) < 0，该对被认为是非连续的
   - 计算此类配对的总数

2. MMI = （非连续对的数量 / （长度 - 2）） * 100

## 解释

市场“刻薄”指数可以解释如下：

1. **指标水平**：
   - MMI > 50：市场处于横盘或混乱状态
   - MMI < 50：市场处于趋势状态
   - MMI 越接近 100，市场就越混乱
   - MMI 越接近 0，趋势越明显

2. **交易策略应用**：
   - 当 MMI 较高（>50）时，使用针对横盘市场的策略（例如区间交易、振荡指标）
   - 当 MMI 较低（<50）时，使用趋势策略（例如趋势跟随）

3. **变化的动态**：
   - MMI 从高位下降可能预示着新趋势的形成
   - MMI 从低水平的上升可能表明趋势已完成并转向盘整

4. **极端值**：
   - 非常低的数值（MMI < 20）可能表示强烈的趋势，但也可能意味着超买或超卖状态
   - 非常高的数值（MMI > 80）表明市场极为混乱，很难应用任何策略

5. **信号过滤**：
   - MMI 常被用作其他指标的筛选工具：
     - 趋势指标信号（MA、MACD）在低 MMI 时更可靠
     - 振荡器信号（RSI、Stochastic）在高 MMI 时更可靠

6. **与其他指标结合**：
   - MMI 与 ADX（平均方向指数）结合时效果良好
   - 低 MMI 和高 ADX 确认了强烈的趋势
   - 高 MMI 和低 ADX 确认了横盘市场

7. **时间框架**：
   - MMI 可以在不同的时间框架上用于确定市场特性
   - 长期 MMI 有助于确定市场的主要状态
   - 短期 MMI 有助于为当前情况选择合适的策略
