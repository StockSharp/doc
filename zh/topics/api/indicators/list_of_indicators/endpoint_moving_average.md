# EPMA

**端点移动平均线（EPMA）** 是一种技术指标，是标准移动平均线的改进，旨在减少趋势识别的滞后。

要使用该指标，您需要使用 [EndpointMovingAverage](xref:StockSharp.Algo.Indicators.EndpointMovingAverage) 类。

## 描述

端点移动平均线（EPMA）是一种侧重于端点数据点的特殊形式的移动平均线。与标准移动平均线对给定周期内的所有点均等加权不同，EPMA 对端点数据点赋予更大权重，从而能够更快速地响应趋势变化。

EPMA 的主要目的是在保持过滤市场噪音能力的同时，减少传统移动平均线固有的滞后。由于其计算方法，EPMA 通常对价格方向变化反应更快，使其成为希望更早识别趋势反转的交易者的有价值工具。

EPMA 特别适用于：
- 趋势变化的早期识别
- 减少信号延迟
- 创建更敏感的交易系统
- 确认来自其他指标的信号，以减少延迟

## 参数

该指标具有以下参数：
- **周期** - 计算周期（默认值：14）

## 计算

终点移动平均计算基于线性回归方法，重点关注所考虑期间的终点点：

1. 确定期间初始点和终点之间的线性趋势：
   ```
   起始值 = Price[current - Length + 1]
   结束值 = Price[current]
   ```

2. 计算趋势线的斜率：
   ```
   Slope = (结束值 - 起始值) / (Length - 1)
   ```

3. 将 EPMA 计算为趋势线在当前点的投影：
   ```
   EPMA = 起始值 + Slope * (Length - 1)
   ```

实际上，EPMA 等于所考虑期间的最后价格值（期末值），但从概念上讲，它是由端点定义的线性趋势的投射。

## 解释

端点移动平均线的解读与其他移动平均线类似，但需要考虑其敏感度的增加：

1. **EPMA 方向**:
   - 向上的EPMA表明上升趋势
   - 下降的EPMA表明了下降的趋势

2. **与价格的交叉**：
   - 当价格从下方穿过EPMA向上时，可以视为看涨信号
   - 当价格从上方穿过EPMA向下时，可以视为看跌信号

3. **多重EPMA交叉**:
   - 从下向上短期EPMA与长期EPMA的交叉可能表示上升趋势的开始
   - 从上到下短期EPMA与长期EPMA的交叉可能表示下行趋势的开始

4. **与其他移动平均线的背离**：
   - 由于其灵敏度提高，EPMA 可能比传统移动平均线更早对趋势变化作出反应
   - EPMA 与其他类型移动平均线之间的偏离可以作为潜在趋势变化的早期预警

5. **信号过滤**：
   - 由于其灵敏度增加，EPMA 在横向盘整期间可能会产生更多的虚假信号
   - 建议使用额外的过滤器或来自其他指标的确认来提高信号的可靠性
