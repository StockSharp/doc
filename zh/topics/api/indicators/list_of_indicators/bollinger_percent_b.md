# BBP

**布林带百分比B（BBP）**是由约翰·布林格开发的一个指标，用于补充布林带指标。BBP显示价格相对于上轨和下轨的位置。

使用该指标，需要使用[BollingerPercentB](xref:StockSharp.Algo.Indicators.BollingerPercentB)类。

## 描述

布林百分比B指标确定价格相对于上轨和下轨的布林带位置，以0到1（或0%到100%）的百分比值表示。这允许在布林带的背景下更精确地确定价格位置：

- 值为1（或100%）表示价格位于布林带上轨。
- 值为0（或0%）表示价格位于布林带下轨。
- 0.5（或50%）的值意味着价格位于布林带中轨（简单移动平均线）上。

BBP 也可以取 0-1 范围之外的值：
- 数值高于1表示价格高于布林带上轨。
- 低于 0 的数值表示价格低于下布林带。

## 参数

该指标具有以下参数：
- **Length** - SMA 计算周期（默认值：20）
- **StdDevMultiplier** - 用于计算布林带的标准差乘数（默认值：2）

## 计算

布林格百分比B的计算基于以下公式：

```
BBP = (Price - 布林带下轨) / (布林带上轨 - 布林带下轨)
```

其中：
- 价格 - 当前价格（通常是收盘价）
- 下布林带 = 简单移动平均 - (标准差倍数 * 标准差)
- 布林带上轨 = 简单移动平均 + (标准差乘数 * 标准差)
- SMA - 在长度周期上的简单移动平均
- 标准差 - 在长度期间的价格标准差

## 使用

布林格百分比B可以以各种方式使用：

1. **识别超买/超卖情况**：
   - 大于 1 的数值表示市场超买
   - 低于0的数值表示市场超卖

2. **反转信号**:
   - 当 BBP 在超出 0-1 范围后返回到该范围内时
   - BBP 与价格之间的差异

3. **趋势判断**：
   - BBP 值持续高于 0.5 表明上升趋势
   - BBP 值持续低于 0.5 表明下降趋势

4. **寻找隐藏的支撑和阻力位**:
   - 0.8 和 0.2 水平通常被用作额外的支撑和阻力水平
