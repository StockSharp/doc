# 外国直接投资

**分形维数指数（FDI）**量化价格序列的粗糙度。

要使用该指标，您需要使用[FractalDimension](xref:StockSharp.Algo.Indicators.FractalDimension)类。

## 描述

FDI 范围从 1 到 2，反映市场行为：
- 接近1的值表示趋势持续（路径更平滑）。
- 大约 1.5 的值对应于随机游走。
- 接近 2 的数值表示市场处于横盘或噪声状态。

该指标基于分形几何，用于衡量价格路径的复杂程度。

## 参数

该指标具有以下参数：
- **长度** – 计算周期（默认值：30）

## 计算

FDI 是通过将总价格路径长度与整体高低范围进行比较来计算的：

1. 在整个期间，将连续价格之间的绝对差值相加，以获得价格路径长度。
2. 找出该期间的最高价与最低价之间的差值。
3. 使用以下方法计算外国直接投资（FDI）:
   ```
   FDI = 1 + (log(PathLength) - log(Range)) / log(2 * (Length - 1))
   ```
4. 将结果限制在1到2之间。

## 解释

- **FDI 接近 1** – 强劲的趋势行为。
- **FDI 约为1.5** – 随机漫步；趋势强度为中性。
- **FDI 接近 2** – 波动或横盘的市场。
