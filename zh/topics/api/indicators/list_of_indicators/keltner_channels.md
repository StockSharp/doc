# KC

**凯特纳通道（KC）** 是一个技术指标，由一组波动性通道组成，使用指数移动平均线（EMA）作为中线，并采用平均真实波幅（ATR）来确定通道宽度。

使用该指标时，需要使用 [KeltnerChannels](xref:StockSharp.Algo.Indicators.KeltnerChannels) 类。

## 描述

凯尔特纳通道由三条线组成：
1. **中间线**：通常用20周期EMA表示
2. **上轨**：中线加上ATR的乘数
3. **下轨**：中线减去相同的ATR倍数

该指标由切斯特·凯特纳（Chester Keltner）在20世纪60年代开发，后来由琳达·拉什克（Linda Raschke）修改，她用指数移动平均线（EMA）替代了简单移动平均线（SMA），并开始使用平均真实波幅（ATR）而不是最高-最低价差来计算通道宽度。

凯特纳通道帮助交易者判断趋势方向以及潜在的支撑和阻力水平。当价格触及或突破上轨或下轨时，它们也用于识别超买和超卖状态。

## 参数

该指标具有以下参数：
- **长度** - 用于计算EMA和ATR的周期（默认值：20）
- **乘数** - ATR 的乘数，用于确定通道宽度（默认值：2.0）

## 计算

凯尔特纳通道的计算涉及以下步骤：

1. 计算指数移动平均值：
   ```
   Middle Line = EMA(Price, Length)
   ```

2. 计算平均真实波幅：
   ```
   ATR = Length 周期内平均真实波幅
   ```

3. 计算上轨和下轨：
   ```
   Upper Band = Middle Line + (Multiplier * ATR)
   Lower Band = Middle Line - (Multiplier * ATR)
   ```

其中：
- 价格 - 通常为收盘价
- EMA - 指数移动平均
- ATR - 平均真实波幅
- 长度 - EMA 和 ATR 计算周期
- 倍增器 - 决定通道宽度的倍增器

## 解释

凯尔特纳通道可以解释如下：

1. **趋势方向**:
   - 当所有三条线都指向上方时，这表明上升趋势
   - 当所有三条线都指向下方时，这表明下降趋势
   - 水平线运动表示横向趋势

2. **突破**：
   - 价格突破上轨可能表明强劲的上行动能
   - 价格跌破下轨可能表明强劲的下行动力
   - 突破常被用作沿突破方向的入场信号

3. **返回中线**：
   - 在突破上轨或下轨后，价格往往会回到中线
   - 中线可以作为支撑位或阻力位

4. **超买和超卖状况**：
   - 价格接近或超过上轨可能表示超买状况
   - 价格接近或超过下轨可能表示超卖状态
   - 在趋势市场中，价格可以在“极端”区域维持较长时间

5. **通道收缩和扩张**：
   - 通道收窄（带宽距离减小）表示波动性降低，通常预示着强烈的价格波动即将发生
   - 通道扩张表示波动性增加

6. **交易策略**：
   - “边缘到中间”策略：当价格触及上轨或下轨时开仓，目标是中轨
   - 突破策略：当价格突破上轨或下轨时开仓，期望价格在相同方向上继续移动
   - “中线到边缘”策略：当价格从中线反弹时开仓，目标是上轨或下轨
