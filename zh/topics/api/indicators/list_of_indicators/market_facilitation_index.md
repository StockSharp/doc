# 市场便利化指数

**市场便利指数（MFI）** 是一个评估市场价格变动准备情况的指标。它分析一定时期内价格变化与成交量变化的比率，以衡量市场对成交量变化的反应。它通过公式 (最高价 — 最低价) / 成交量 来计算 MFI，从而提供对市场动态的理解。
指标的绝对值不能提供任何交易信号，只有其相对于成交量动态的变化才能提供信息。

使用该指标时，应使用 [MarketFacilitationIndex](xref:StockSharp.Algo.Indicators.MarketFacilitationIndex) 类。
