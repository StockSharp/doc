# 相关性

**相关**或**相关依赖**是两个或多个随机变量（或可以在一定程度上被视为随机变量的变量）之间的统计关系，其中一个或几个变量的数值变化伴随另一个或其他变量的数值系统性变化。

两个随机变量之间相关性的数学度量是相关比或相关系数。它表征变量之间关系的强度。

相关系数
1. 可以取从 -1 到 +1 的值。
2. 系数的符号表示关系的方向（正向或反向）。
3. 绝对值表示关系的强度。
4. 始终基于数字对。
