# 怀尔德 MA

**Wilder 移动平均线 (WilderMA)** 是一种加权移动平均指标。像所有其他移动平均指标一样，WMA 指标能够平滑市场噪音，更清晰地显示市场趋势。为了实现这一目标，该指标会过滤掉市场波动（噪音），并对计算周期的价格值进行平均。与此同时，会向平均价格中添加一些附加值（权重），正如计算所有加权指标（如 EMA、LWMA 和 SMMA）时所做的那样。

要使用该指标，必须使用 [WilderMovingAverage](xref:StockSharp.Algo.Indicators.WilderMovingAverage) 类。
