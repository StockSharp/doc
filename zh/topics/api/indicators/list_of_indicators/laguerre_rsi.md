# LRSI

**拉盖尔RSI (LRSI)** 是一个基于拉盖尔滤波器数学原理的技术指标，由约翰·埃勒斯（John Ehlers）开发，是传统相对强弱指数（RSI）的高级版本。

要使用该指标，您需要使用 [LaguerreRSI](xref:StockSharp.Algo.Indicators.LaguerreRSI) 类。

## 描述

拉盖尔RSI（LRSI）是一种创新型振荡器，它利用拉盖尔滤波数学创造出比传统RSI更敏感且滞后性更小的指标。约翰·艾勒斯（John Ehlers）开发了这一指标，以解决许多技术指标固有的信号延迟问题。

LRSI将拉盖尔多项式原理与相对强弱指数（RSI）概念相结合。这使得该指标能够更快速地响应趋势变化，并形成更明确的交易信号。与传统RSI一样，LRSI在0到1之间（或乘以100后为0到100）振荡，但其结构噪音更低，转折更明显。

LRSI的主要优势在于能够快速识别趋势变化，同时保持信号稳定性。这使其在短期交易以及确定入场和退出点时尤为有用。

## 参数

该指标具有以下参数：
- **Gamma** - 滤波系数（默认值：0.4，范围从0.1到0.9）

伽玛参数决定了滤波的程度，并影响指标的敏感性。较低的伽玛值会使指标更加平滑且不那么敏感，而较高的值则会使指标对价格变化更敏感，但可能更嘈杂。

## 计算

拉盖尔 RSI 计算涉及几个步骤：

1. 在第一次运行时初始化四个拉盖尔滤波器值（L0、L1、L2、L3）:
   ```
   L0 = L1 = L2 = L3 = 0
   ```

2. 为每个新价格更新筛选器值：
   ```
   L0_new = (1 - Gamma) * Price + Gamma * L0_old
   L1_new = -Gamma * L0_new + L0_old + Gamma * L1_old
   L2_new = -Gamma * L1_new + L1_old + Gamma * L2_old
   L3_new = -Gamma * L2_new + L2_old + Gamma * L3_old
   ```

3. 计算筛选值的“累积乘积”:
   ```
   CU = (L0_new + L1_new + L2_new + L3_new) / 4
   ```

4. 分成“上”和“下”部分：
   ```
   如果 CU >= CU_old，则：
     UP = CU - CU_old
     DN = 0
   Otherwise:
     UP = 0
     DN = CU_old - CU
   ```

5. 最终 LRSI 计算：
   ```
   LRSI = UP / (UP + DN)
   ```

如果 (UP + DN) 为零，LRSI 设置为上一个值。

其中：
- 价格 - 输入价格（通常为收盘价）
- 伽马 - 过滤参数
- CU - “累计乘法”

## 解释

拉盖尔 RSI 的解释类似于传统 RSI，但其灵敏度有所提高：

1. **超买和超卖水平**：
   - 通常认为，高于0.8（或80）的数值表示超买
   - 通常认为低于0.2（或20）的数值属于超卖
   - 由于拉盖尔滤波器的特性，这些水平可以根据市场波动性进行调整

2. **中心线交叉**：
   - 从下向上穿越0.5（或50）水平可以被视为看涨信号
   - 从上方向下穿过0.5（或50）水平可以被视为看跌信号

3. **分歧**：
   - 看涨背离：价格创出新低，而LRSI形成更高的低点
   - 看跌背离：价格创出新高，而LRSI形成较低高点

4. **从极端反弹**：
   - LRSI从超买或超卖水平的反转可以作为市场进入信号

5. **趋势确认**:
   - LRSI 值高于 0.5 确认了上升趋势
   - LRSI 值低于 0.5 确认下行趋势

6. **伽马参数调优**：
   - 为了更快的信号 - 增大 Gamma（接近 0.9）
   - 为了信号更平滑 - 减小伽马（更接近0.1）
