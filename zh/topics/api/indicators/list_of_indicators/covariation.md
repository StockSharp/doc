# 协变

**协方差**或随机变量的**相关矩**——在概率论和数理统计中，是衡量两个随机变量之间依赖性的一种度量。

在概率论和统计学中，协方差是衡量两个随机变量联合变动性的指标。如果一个变量的较大值通常对应另一个变量的较大值，且较小值也同样对应（即变量倾向于同向变化），则协方差为正。对于负协方差，一个变量的较大值通常对应另一个变量的较小值，反之亦然（即变量倾向于反向变化）。协方差的大小较难解释，因为它没有标准化，因此取决于变量的量纲。协方差的标准化版本——[相关系数](correlation.md)——通过其大小指出线性依赖的强度。
