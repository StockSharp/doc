# PP

**枢轴点（PP）** 是一种技术指标，它使用前一交易期的最高价、最低价和收盘价来确定当前交易期的潜在支撑位和阻力位。

要使用该指标，您需要使用 [PivotPoints](xref:StockSharp.Algo.Indicators.PivotPoints) 类。

## 描述

枢轴点（枢轴点）是识别关键市场水平的最古老且最广泛使用的方法之一。该指标根据上一时期的数据计算中央枢轴点（PP）以及若干支撑（S1、S2、S3）和阻力（R1、R2、R3）水平。

最初，枢轴点被交易所交易员用于根据前一天的数据确定当日交易的关键水平。如今，这种方法已经被应用于各种时间框架——从日内到月度。

枢轴点的主要理念是，市场倾向于对这些预先计算的水平做出反应，将其作为反转点或可能出现整合的区域。交易者利用这些水平来做出市场买入和卖出的决策，以及设置目标水平和止损。

## 计算

计算枢轴点有几种方法，包括标准法、斐波那契法、伍迪法、卡玛里拉法和德马克法。以下是标准计算方法：

1. 计算主要支点（PP）:
   ```
   PP = (High + Low + Close) / 3
   ```

2. 计算第一个阻力位 (R1) 和支撑位 (S1)：
   ```
   R1 = (2 * PP) - Low
   S1 = (2 * PP) - High
   ```

3. 计算第二阻力位（R2）和支撑位（S2）:
   ```
   R2 = PP + (High - Low)
   S2 = PP - (High - Low)
   ```

4. 计算第三阻力位（R3）和支撑位（S3）:
   ```
   R3 = High + 2 * (PP - Low)
   S3 = Low - 2 * (High - PP)
   ```

其中：
- 前一时期的最高价
- 最低点 - 上一周期的最低价格
- 收盘价 - 上一周期的收盘价

## 解释

枢轴点可以解释如下：

1. **主要枢轴点 (PP)**:
   - PP作为确定整体市场情绪的主要参考
   - 如果价格高于 PP，这表明看涨情绪
   - 如果价格低于 PP，这表明看跌情绪
   - PP 也可以作为支撑位或阻力位

2. **阻力位 (R1, R2, R3)**：
   - 这些水平代表牛市中的潜在阻力区
   - 一个水平的突破可能导致继续移动到下一个水平
   - 从一个水平反弹可能导致向下反转

3. **支撑位 (S1, S2, S3)**：
   - 这些水平代表熊市中的潜在支撑区
   - 一个水平的突破可能导致继续移动到下一个水平
   - 从一个水平反弹可能导致向上的反转

4. **交易策略**：
   - **反弹交易**：当价格从支撑位或阻力位反弹时建仓
   - **突破交易**：在确认级别突破后入场
   - **区间交易**：在支撑位买入，在阻力位卖出
   - **目标设定**：将下一级作为获利目标
   - **止损设置**：将止损置于相应水平之外

5. **与其他指标结合**：
   - 枢轴点常常与其他技术指标结合使用以确认信号
   - 在与动量指标（RSI、随机指标）和趋势指标（均线、MACD）结合使用时特别有效

6. **时间框架**：
   - 每日枢轴点是根据前一个交易日计算的
   - 每周枢轴点是根据前一周计算的
   - 月度枢轴点是基于上个月计算的
   - 时间框架的选择取决于交易风格和时间周期
