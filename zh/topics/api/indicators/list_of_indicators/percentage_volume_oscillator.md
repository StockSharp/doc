# PVO

**百分比成交量振荡器 (PVO)** 是一种技术指标，类似于 MACD，但应用于交易量而非价格，表示成交量快慢指数移动平均线之间的差异，以百分比形式表示。

使用该指标，需要使用 [PercentageVolumeOscillator](xref:StockSharp.Algo.Indicators.PercentageVolumeOscillator) 类。

## 描述

百分比成交量振荡器（PVO）是对MACD（指数平滑异同移动平均线）指标的改进，应用于交易量而非价格。类似于PPO（百分比价格振荡器），PVO将快速和慢速指数移动平均线之间的差异表示为百分比，而不是绝对数值。这使得PVO在比较不同成交量水平的不同工具或分析单一工具的长期走势时特别有用。

PVO由三个组成部分构成：
1. **PVO线** - 快速和慢速成交量指数移动平均线之间的百分比差异
2. **信号线** - PVO线的EMA
3. **直方图** - PVO线和信号线之间的差异

PVO 指标有助于识别可能预示重大价格变动的成交量异常。它还用于确认价格趋势和识别潜在的反转点。

## 参数

该指标具有以下参数：
- **ShortPeriod** - 用于计算空头成交量指数移动平均的周期（默认值：12）
- **LongPeriod** - 用于计算长期成交量指数移动平均线的周期（默认值：26）

## 计算

百分比成交量振荡器的计算涉及以下步骤：

1. 计算成交量的短期和长期指数移动平均线：
   ```
   Short EMA = EMA(Volume, ShortPeriod)
   Long EMA = EMA(Volume, LongPeriod)
   ```

2. 将PVO线计算为短期和长期EMA之间的百分比差异：
   ```
   PVO Line = ((Short EMA - Long EMA) / Long EMA) * 100
   ```

3. 计算信号线（通常为PVO线的9周期EMA）:
   ```
   Signal Line = EMA(PVO Line, 9)
   ```

4. 计算直方图：
   ```
   Histogram = PVO Line - Signal Line
   ```

其中：
- 成交量 - 交易量
- EMA - 指数移动平均
- ShortPeriod - 短期EMA的周期
- LongPeriod - 长期EMA的周期

## 解释

百分比体积振荡器可以解释如下：

1. **零线交叉**：
   - PVO线从下向上穿过零线表示成交量加速高于平均水平，这可能预示着看涨走势
   - PVO线从上向下穿过零线表示成交量低于平均水平减速，这可能预示看跌走势

2. **信号线交叉**：
   - PVO线从下向上穿过信号线可以被视为看涨信号
   - PVO线从上向下穿过信号线可以被视为看跌信号

3. **分歧**：
   - 看涨背离：价格形成新低，而PVO形成更高的低点
   - 看跌背离：价格形成新高，而PVO形成较低的高点

4. **极端值**：
   - 非常高的 PVO 值可能表明成交量过大，这通常发生在市场高峰期或恐慌期间
   - 非常低的PVO值可能表示成交量不足，通常发生在市场清淡期间

5. **直方图分析**：
   - 正直方图增加表明看涨成交量动能增强
   - 负直方图增加表明看跌成交量动能增强
   - 直方图收缩表示当前成交量动能减弱

6. **价格趋势确认**：
   - 上升的PVO确认了价格上涨的趋势
   - PVO下降确认价格下跌趋势
   - PVO方向与价格之间的背离可能预示潜在的反转

7. **成交量激增**：
   - 尖锐的PVO跳跃表示显著的成交量变化，通常伴随重要的市场事件
   - 这种尖峰可能出现在关键价格水平的突破之前或伴随其发生
