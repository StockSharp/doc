# MI

**质量指数 (MI)** 是由 Donald Dorsey 开发的一种技术指标，通过分析价格区间的扩展和收缩来识别潜在的趋势反转。

要使用该指标，您需要使用 [MassIndex](xref:StockSharp.Algo.Indicators.MassIndex) 类。

## 描述

质量指数（MI）是一种技术分析工具，通过追踪价格区间（最高价与最低价之间的差额）的变化来帮助检测潜在的趋势反转。该指标由唐纳德·多尔西（Donald Dorsey）开发，其假设是趋势反转通常先于价格区间的扩张和随后的收缩。

MI 使用价格区间的指数移动平均线（EMA）来衡量波动性。它不预测反转方向，只衡量其发生的可能性。这就是为什么 MI 常常与其他方向性指标一起使用的原因。

其主要概念是，当质量指数达到某一阈值然后跌破该水平时，当前趋势反转的可能性增加。

## 参数

该指标具有以下参数：
- **长度** - 主要计算周期（默认值：25）
- **EmaLength** - 价格区间EMA的周期（默认值：9）

## 计算

质量指数计算涉及以下步骤：

1. 计算每个周期的最高-最低范围：
   ```
   Range = High - Low
   ```

2. 计算范围的9周期EMA：
   ```
   EMA1 = EMA(Range, EmaLength)
   ```

3. 计算范围 EMA 的 9 周期 EMA：
   ```
   EMA2 = EMA(EMA1, EmaLength)
   ```

4. 计算比率：
   ```
   Ratio = EMA1 / EMA2
   ```

5. 在25个周期内求比率之和：
   ```
   MI = Sum(最近 Length 个周期内的 Ratio)
   ```

其中：
- 最高价 - 期间最高价格
- 最低价 - 本周期最低价格
- EMA - 指数移动平均
- 长度 - 求和周期（通常为25）
- EmaLength - EMA周期（通常为9）

## 解释

质量指数的解释如下：

1. **“反转驼峰”**：
   - 当质量指数上升超过27然后下降到26.5以下时，经典的“反转驼峰”信号就会形成。
   - 这个形态表明可能出现趋势反转，尽管它并不预测反转的方向

2. **指数水平**：
   - 高于27的数值表示价格区间扩大且波动性增加
   - 高值随后下降可能预示趋势反转
   - 低值（低于20）表示价格区间收缩和波动性降低

3. **趋势方向**:
   - 质量指数不指示趋势方向或其反转
   - 确定方向需要额外的指标或分析方法（例如，移动平均线或支撑/阻力水平）

4. **分歧**：
   - 价格与大宗指数之间的分歧不如“反转驼峰”模式显著
   - 然而，价格的新高/新低与下降的总指数高点/低点之间的差异可能表明趋势正在减弱

5. **与其他指标结合**：
   - 质量指数在结合趋势方向指标时效果最佳
   - 常见的组合包括EMA、MACD或RSI，用于确定潜在的反转方向

6. **波动性变化**：
   - 急剧的质量指数上升表明价格范围显著扩大，这可能预示着强烈的市场波动
   - 指数逐步下跌表明区间缩小并可能出现盘整

7. **参数调优**：
   - 标准参数（EMA 为 9，求和为 25）在大多数时间框架上效果良好
   - 减少周期可以产生更快的信号，但可能会增加错误信号
