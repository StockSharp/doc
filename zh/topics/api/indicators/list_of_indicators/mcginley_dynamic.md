# MGD

**McGinley Dynamic（MGD）** 是由 John R. McGinley 开发的一种技术指标，代表了移动平均线的一种高级形式，会根据市场速度的变化自动调整其速度。

使用该指标，你需要使用 [McGinleyDynamic](xref:StockSharp.Algo.Indicators.McGinleyDynamic) 类。

## 描述

McGinley动态指标（MGD）由John McGinley创建，旨在克服传统移动平均线的一些缺点，例如滞后和无法适应市场速度变化。该指标会根据价格运动速度自动调整反应周期，使其对快速变化更敏感，并且不容易产生错误信号。

不同于简单和指数移动平均线，MGD引入了调节常数以及价格与前一个指标值的比率。这使得MGD在价格发生显著变化时能够更快速地响应，同时在价格波动较慢时保持稳定。

其主要理念是，MGD在市场快速波动时“加速”，在盘整期“减速”，与传统移动平均线相比提供更准确的价格跟踪。

## 参数

该指标具有以下参数：
- **周期** - 计算周期（默认值：14）

## 计算

McGinley 动态计算是使用以下公式递归执行的：

```
MGD = MGD[previous] + (Price - MGD[previous]) / (Length * ((Price / MGD[previous])^4))
```

其中：
- 价格 - 当前价格（通常是收盘价）
- MGD[previous] - 前一个指标值
- 长度 - 周期参数

对于初始 MGD 值，通常使用指定时期的简单移动平均值：

```
For first calculation: MGD = SMA(Price, Length)
```

## 解释

麦金利动态可以类似于其他移动平均线进行解释，但具有其改进的特性：

1. **趋势判断**：
   - 当价格高于MGD时，表示上升趋势
   - 当价格低于MGD时，表示下行趋势
   - 陡峭的MGD斜率表示趋势强劲

2. **价格交叉**：
   - 价格从下向上穿越MGD可以被视为看涨信号
   - 价格从上向下穿越MGD可以被视为看跌信号
   - 由于其自适应特性，这些交叉通常比传统移动平均线形成得更早

3. **多次MGD交叉**:
   - 可以使用不同周期的多个MGD（例如， MGD(14)和MGD(30)）
   - 短期MGD自下而上穿越长期MGD可以被视为看涨趋势确认
   - 从上到下短期MGD穿过长期MGD可以被视为看跌趋势确认

4. **支撑和阻力位**：
   - MGD 在上升趋势中常常作为一个动态支撑位
   - MGD 在下跌趋势中常常作为一个动态阻力位
   - 多次从MGD反弹确认趋势强度

5. **价格关系**：
   - 价格与MGD之间的距离可以显示市场的超买或超卖状况
   - 当价格明显偏离 MGD 时，可能预示潜在的反转或修正

6. **与其他指标结合**：
   - MGD 与振荡器（RSI，随机指标）配合良好
   - 可以作为其他交易系统的趋势过滤器

7. **长度参数选择**：
   - 较小的长度值（例如， 8-12）使MGD对价格变化更敏感，适合短期交易
   - 更大的长度值（例如， 20-50）使MGD更平滑，更适合长期交易
