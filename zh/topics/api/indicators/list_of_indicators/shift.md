# 移位

**移位** 是一个辅助指标，可将传入的数值流按指定的周期数进行偏移。它不会转换
数据；它仅将数据延迟或对齐，以便用于组合计算。

使用 [Shift](xref:StockSharp.Algo.Indicators.Shift) 类来访问该指标。

## 描述

该指标保持最近数值的缓冲区，并输出 **周期** 根K线前到达的值。如果数据历史比所需的偏移量
短，则该值被视为未定义。

## 参数

- **长度** — 数据被移动的周期数。

## 使用

- 将来自不同指标的信号在时间上对齐。
- 构建需要延迟输入的自定义指标和策略。
- 创建合成序列，例如，计算当前价格与过去价值之间的差异。
