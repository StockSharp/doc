# PGO

**漂亮震荡指标 (PGO)** 是由马克·约翰逊开发的技术指标，它通过比较当前收盘价与之前的价格，并考虑波动性，以确定市场的超买或超卖状况。

要使用该指标，您需要使用 [PrettyGoodOscillator](xref:StockSharp.Algo.Indicators.PrettyGoodOscillator) 类。

## 描述

漂亮指标振荡器（PGO）是一种评估当前收盘价相对于特定时期历史值强弱的指标。PGO 不仅考虑当前价格在历史区间中的位置，还考虑该区间的波动性，使其更能适应不断变化的市场状况。

“漂亮指标振荡器”这个名字反映了其创作者的实用主义方法——该指标并不声称是完美的工具，而是提供了一种“相当不错”的方式来评估当前的市场状况。

PGO 对识别超买和超卖状况特别有用，也可用于检测可能预示趋势反转的背离。

## 参数

该指标具有以下参数：
- **周期** - 计算周期（默认值：14）

## 计算

漂亮振荡器的计算涉及以下步骤：

1. 确定指定周期内的最高高点（最高高）和最低低点（最低低）:
   ```
   Highest High = Highest(High, Length)
   Lowest Low = Lowest(Low, Length)
   ```

2. 计算指定期间收盘价的标准差：
   ```
   标准差 = StdDev(Close, Length)
   ```

3. 计算漂亮振荡器：
   ```
   PGO = (Close - (Highest High + Lowest Low) / 2) / 标准差
   ```

其中：
- 收盘价 - 当前收盘价格
- 高 - 最高价
- 低 - 最低价
- 长度 - 计算周期
- StdDev - 标准差

## 解释

漂亮的振荡器可以解释如下：

1. **超买和超卖水平**：
   - 高于 +2 的数值通常表示市场超买状态
   - 低于-2的数值通常表示市场超卖状态
   - 极端数值（+3/-3及以上/以下）可能表示显著的超买/超卖状况以及潜在的反转

2. **零线交叉**：
   - PGO 从下向上穿过零线可以被视为看涨信号
   - PGO 从上向下穿过零线可以被视为看跌信号

3. **分歧**：
   - 看涨背离：价格形成新低，而PGO形成更高的低点
   - 看跌背离：价格形成新高，而PGO形成较低的新高
   - 背离通常出现在重要趋势反转之前

4. **趋势确认**:
   - 正的 PGO 值表明价格高于平均范围，这是上升趋势的特征
   - 负PGO值表示价格低于平均区间，这是 downward trend 的特征

5. **趋势强度评估**:
   - PGO值离零越远，当前趋势越强
   - PGO 收敛到零线可能表示趋势减弱

6. **信号过滤**：
   - PGO 可用于过滤来自其他指标的信号
   - 例如，当 PGO 为正时只考虑看涨信号，当 PGO 为负时只考虑看跌信号

7. **平仓点**：
   - 极端的 PGO 值可以用作获利的信号
   - 例如，当PGO超过+2时退出多头持仓，当PGO低于-2时退出空头持仓
