# IMI

**日内动量指数 (IMI)** 是由 Tushar Chande 开发的技术指标，它结合了日内定价原理和 RSI 概念来衡量日内动量。

要使用该指标，你需要使用 [IntradayMomentumIndex](xref:StockSharp.Algo.Indicators.IntradayMomentumIndex) 类。

## 描述

日内动量指数（IMI）是在经典相对强弱指数（RSI）的基础上进行修改而创建的，专门用于分析日内市场动态。与传统RSI使用连续收盘价不同，IMI比较每个周期的收盘价与开盘价。

IMI评估在给定周期内收盘价超过开盘价（正动量）或低于开盘价（负动量）的频率和强度。这使得能够识别日内运动的主要方向和强度。

该指标特别适用于：
- 确定日内市场方向
- 识别潜在的反转点
- 确定超买和超卖水平
- 检测价格与动量之间的背离

## 参数

该指标具有以下参数：
- **周期** - 计算周期（默认值：14）

## 计算

日内动量指数的计算包括以下步骤：

1. 确定日内价格变动：
   ```
   上涨幅度 = Close - Open，如果 Close > Open
   下跌幅度 = Open - Close，如果 Close < Open
   ```

2. 计算在长度期间正向和负向波动的总和：
   ```
   上涨幅度总和 = Length 周期内所有 上涨幅度 的总和
   下跌幅度总和 = Length 周期内所有 下跌幅度 的总和
   ```

3. 使用类似于RSI的公式计算IMI：
   ```
   IMI = 100 * (上涨幅度总和 / (上涨幅度总和 + 下跌幅度总和))
   ```

注意：如果（总收益 + 总损失）等于零，为了避免除以零，IMI 设置为 50。

## 解释

日内动量指数的解释方式与相对强弱指数（RSI）类似：

1. **数值范围**：
   - IMI 在 0 到 100 之间波动
   - 大于50的数值表示日内正向动能占主导
   - 低于50的数值表示负面日内动能占主导

2. **超买和超卖水平**：
   - 超过70的数值通常被视为市场超买状况的指示
   - 低于30的数值通常被视为市场超卖状况的指示

3. **中心线交叉**：
   - 从下向上突破50线可以被视为看涨信号
   - 从上向下穿过50线可以被视为看跌信号

4. **分歧**：
   - 看涨背离：价格形成新低，而IMI形成更高的低点
   - 看跌背离：价格形成新高，而IMI形成较低的高点

5. **挥棒失误**：
   - 如果 IMI 在上升趋势中无法达到超买水平，这可能表明趋势疲弱
   - 如果 IMI 在下跌趋势中无法达到超卖水平，这可能表明趋势疲弱

6. **趋势确认**:
   - 持续的 IMI 值高于 50 确认了上升趋势
   - 持续的 IMI 值低于 50 确认了下行趋势
