# TEMA

**三重指数移动平均线 (TEMA)** 使用多个（三重）指数移动平均线 (EMA) 来消除预测价格时的滞后。

要使用该指标，您必须使用 [TripleExponentialMovingAverage](xref:StockSharp.Algo.Indicators.TripleExponentialMovingAverage) 类。
