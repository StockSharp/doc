# KER

**考夫曼效率比率 (KER)** 是由佩里·考夫曼开发的技术指标，通过将方向性价格变动与整体波动性进行比较来衡量价格变动的效率。

要使用该指标，您需要使用 [KaufmanEfficiencyRatio](xref:StockSharp.Algo.Indicators.KaufmanEfficiencyRatio) 类。

## 描述

考夫曼效率比率（KER）评估价格在特定方向上的移动相对于其总路径的“效率”。它表示在特定时期内净方向性价格变动与所有价格变化总和的比率。

KER 由 Perry Kaufman 开发，最初用作自适应移动平均线（KAMA）的一个组成部分。然而，KER 本身是一个有价值的工具，可以帮助判断市场是处于趋势状态还是振荡状态。

KER 值在 0 和 1 之间波动：
- 接近1的数值表示价格波动非常有效（强趋势）
- 接近 0 的数值表示价格变动效率低（横盘市场或高波动性）

## 参数

该指标具有以下参数：
- **长度** - 效率计算周期（默认值：10）

## 计算

考夫曼效率比率的计算涉及以下步骤：

1. 计算期间的方向性移动（净变化）:
   ```
   Direction = |Price[current] - Price[current - Length]|
   ```

2. 计算期间的总移动量（所有变化的总和）：
   ```
   Volatility = Sum(|Price[i] - Price[i-1]|) for i from (current - Length + 1) to current
   ```

3. 计算效率比率：
   ```
   KER = Direction / Volatility
   ```

地点：
- 价格 - 通常为收盘价
- 长度 - 计算周期
- | | - 表示绝对值

如果波动率为零（这不太可能），KER 将被设为零以避免除以零。

## 解释

考夫曼效率比可以解释如下：

1. **效率等级**：
   - 高 KER 值（>0.6）表示强烈的趋势
   - 中等 KER 值（0.3-0.6）表示适度的趋势
   - 低 KER 值（<0.3）表示横盘市场或高波动性

2. **KER 变更**：
   - KER增长可能预示着趋势的形成或增强
   - KER 下降可能表示趋势减弱或转为横向移动

3. **交易策略**：
   - 在高效率期间（高 KER），趋势策略更可取
   - 在低效率时期（低 KER），区间交易策略更为可取

4. **信号过滤**：
   - KER可以用来过滤来自其他指标的信号
   - 趋势指标信号在高 KER 时更可靠
   - 在低 KER 下，振荡器信号更可靠

5. **市场条件适应**：
   - KER 允许根据变化的市场条件调整交易策略
   - 交易者可以根据 KER 值动态调整其他指标的参数

6. **更换前体**：
   - 锋利的 KER 变化通常预示着新的价格波动
   - 在高值期后 KER 的下降可能预示着潜在的趋势反转
