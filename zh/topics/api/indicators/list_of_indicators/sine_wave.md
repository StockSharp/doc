# SW

**正弦波 (SW)** 是一种技术指标，使用正弦数学函数来识别价格波动中的周期性模式。该指标旨在识别和预测周期性的市场振荡。

使用该指标需要使用 [SineWave](xref:StockSharp.Algo.Indicators.SineWave) 类。

## 描述

正弦波指标基于市场运动具有周期性特征的理念，并且可以使用正弦函数进行建模。该指标在横盘或具有可预测周期性波动的市场中特别有用。

指标的关键特征：
- 帮助识别潜在的市场反转点
- 允许确定循环中的当前位置
- 可用于预测未来价格走势

指示信号：
- 当正弦波线达到最小值并开始向上转动时，潜在买入
- 当线达到最高点并开始向下转时，可能出售

## 参数

- **Length** - 正弦波周期的时间段，定义价格条的周期长度。

## 计算

正弦波指标的计算基于使用正弦函数并确定价格波动中的主导周期：

1. 使用谱分析或其他周期识别方法来确定主导周期。

2. 将正弦函数应用于建模所识别的周期：
   ```
   SineWave(t) = A * sin(2π * t / Length + φ)
   ```
其中：
   - A - 振幅（波高）
   - t - 当前时间或条
   - 长度 - 周期长度
   - φ - 相位偏移，用于将正弦波与实际价格周期对齐

3. 此外，可以计算一个前导指标，该指标比主正弦波提前四分之一周期：
   ```
   Lead(t) = A * sin(2π * t / Length + φ + π/2)
   ```

该指标可能包括额外的组件，例如趋势线或过滤器，以提高信号的准确性。
