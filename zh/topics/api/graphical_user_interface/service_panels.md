# 服务面板

本节汇集了不用于显示行情、而用于配置应用程序工作方式的面板：各类目录、存储与导入设置、许可证、账户和订阅。

- 佣金规则 \- [CommissionPanel](xref:StockSharp.Xaml.CommissionPanel).
- 导入设置 \- [ImportSettingsPanel](xref:StockSharp.Xaml.ImportSettingsPanel).
- 许可证 \- [LicensePanel](xref:StockSharp.Xaml.LicensePanel).
- 标的检索 \- [SecurityLookupPanel](xref:StockSharp.Xaml.SecurityLookupPanel).
- 标的代码映射 \- [SecurityMappingPanel](xref:StockSharp.Xaml.SecurityMappingPanel).
- 存储设置 \- [StorageSettingsPanel](xref:StockSharp.Xaml.StorageSettingsPanel).
- 订阅 \- [SubscriptionPanel](xref:StockSharp.Xaml.SubscriptionPanel).
- 交易所 \- [ExchangesPanel](xref:StockSharp.Xaml.ExchangesPanel).
- 交易板块 \- [ExchangeBoardsPanel](xref:StockSharp.Xaml.ExchangeBoardsPanel).
- 运行时间表 \- [WorkingTimeControl](xref:StockSharp.Xaml.WorkingTimeControl).
- 账户与权限 \- [PermissionCredentialsPanel](xref:StockSharp.Xaml.PermissionCredentialsPanel).
