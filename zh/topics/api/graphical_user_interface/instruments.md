# 交易品种

[S#](../../api.md) 提供了一大套用于操作交易品种的图形组件。该套件包括：

- 用于创建工具的组件 – [SecurityCreateWindow](xref:StockSharp.Xaml.SecurityCreateWindow)。
- 用于在工具上显示财务信息的组件 - [SecurityGrid](xref:StockSharp.Xaml.SecurityGrid)。
- 用于搜索和选择工具的组件 - [SecurityPicker](xref:StockSharp.Xaml.SecurityPicker)、[SecurityPickerWindow](xref:StockSharp.Xaml.SecurityPickerWindow) 和 [SecurityEditor](xref:StockSharp.Xaml.PropertyGrid.SecurityEditor)。
- 用于创建连续和指数工具的组件 - [ContinuousSecurityWindow](xref:StockSharp.Xaml.ContinuousSecurityWindow) 和 [IndexSecurityWindow](xref:StockSharp.Xaml.IndexSecurityWindow)。
