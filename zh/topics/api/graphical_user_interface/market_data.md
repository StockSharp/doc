# 市场数据

在 [S#](../../api.md) 中有用于显示各种市场数据的图形组件：

- 显示交易的表格 - [TradeGrid](xref:StockSharp.Xaml.TradeGrid)。
- 显示 Level1 的表格 - [一级网格](xref:StockSharp.Xaml.Level1Grid).
- 显示订单簿的组件 - [MarketDepthControl](xref:StockSharp.Xaml.MarketDepthControl)。
- 显示订单日志的表格 - [OrderLogGrid](xref:StockSharp.Xaml.OrderLogGrid)。
- 用于显示新闻的表格 \- [NewsGrid](xref:StockSharp.Xaml.NewsGrid)， [NewsPanel](xref:StockSharp.Xaml.NewsPanel)。
