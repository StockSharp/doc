# 三白兵形态

三只白兵是一种强有力的看涨反转蜡烛图形态，由连续三根蜡烛组成，通常出现在下跌趋势中。该形态表明控制权从卖方转向买方的决定性转变，预示下跌趋势可能反转。

##### 主要特点：

- 连续三根白色（看涨）K线，开盘价低于收盘价（O < C）。
- 每根后续的蜡烛都在前一根蜡烛的实体内开盘（O > pO）。
- 每根蜡烛的收盘价都高于前一根蜡烛的收盘价。
- 所有三根蜡烛的实体都相对较长，而影线较短。
- 处于下降趋势的形态。

![三白兵形态](../../../images/threewhitesoldierspattern.png)

### 解释

三只白兵被认为是下跌趋势反转的最可靠信号之一：

- 三根连续上涨的烛台显示出多头压力的稳步增加。
- 在前一根蜡烛实体内，每根随后的蜡烛的开盘表明某种整合，然后是牛市走势的延续。
- 每一根蜡烛收盘价高于前一根，表明买方能够持续推高价格。
- 相对较长的蜡烛实体伴随短影线表明多头对市场有决定性的控制。
- 三根蜡烛的大小越均匀，信号就越强。

### 交易策略

三白兵提供了可靠的入场多头机会：

- 在完整形态形成后开多仓，通常在第四根蜡烛的开盘时。
- 将止损置于第三根蜡烛的最低点下方或整个形态的最低点下方。
- 目标利润可以基于斐波那契水平或先前的阻力水平来设定。
- 注意成交量——每根K线成交量的增加确认了信号的强度。
- 对于极长的蜡烛实体应采取更谨慎的态度，因为由于超买状况，可能会出现短期修正。
- 结合其他技术指标，例如 RSI，以提高交易成功的概率。
