# 颈部图案

颈上线是一种看跌趋势延续的K线形态，由两根K线组成，出现在下降趋势中。这种形态显示了多头暂时未能成功扭转趋势，之后下跌走势继续。

##### 主要特点：

- 第一根K线是黑色（看跌）的，开盘价高于收盘价（O > C），且实体相对较长。
- 第二根K线是白色的（看涨），开盘价低于收盘价 ((C > O) && (ABS(pL - C) <= 1))。
- 第二根K线的收盘价大约在（或位于）第一根K线的最低点水平。
- 处于下降趋势的形态。

### 解释

颈上形被认为是下跌趋势延续的信号：

- 第一根K线确认了现有的下跌趋势。
- 第二根K线以跳空低开开始，表明看跌压力持续。
- 然而，在本次交易中，多头试图扭转走势，但只能将价格推高到上一根K线的最低点。
- 第二根K线收盘于第一根K线的低点，表明买方无法突破该阻力位。
- 这表明下行趋势可能会继续。

### 交易策略

颈上形态提供了建立或加强空头头寸的机会：

- 在形态形成后建立空头持仓或增加现有空头持仓，通常在第三根K线开盘时进行。
- 将止损设置在第二根K线的高点之上，或者为了更高的保护，将其设置在第一根K线的高点之上。
- 目标利润可以基于之前的支撑位设定，或者使用技术测量方法，例如预测第一根K线的高度。
- 注意成交量——第二根K线的成交量下降，而随后看跌K线的成交量增加，会增强信号的可信度。
- 与其他指标和模式结合，以提高交易成功的概率。
