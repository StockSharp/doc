# 三只乌鸦和三位白兵模式

### 三只乌鸦

三只黑乌鸦是一种看跌的蜡烛图形态，可以预测上升趋势的反转。

三只黑乌鸦形态由三根连续的蜡烛组成，它们在前一根蜡烛的实体内开盘，并在前一根蜡烛下方收盘。交易者通常将这一指标与其他技术指标或图表形态结合使用，以确认反转。

##### 主要特点：

- 三只乌鸦是一种看跌的蜡烛图形态，用于预测当前上升趋势的反转。
- 交易者将其与其他技术指标一起使用，例如相对强弱指数（RSI）。
- 该形态的蜡烛大小和影线可以表明回调反转的风险。
- 与三只乌鸦相反的形态是三只白兵，表示下跌趋势的反转。

### 三白兵

三白兵是一种看涨的蜡烛图形态，用于预测价格图表上当前下跌趋势的反转。该形态由三根连续的长蜡烛组成，每根蜡烛在前一根蜡烛的实体内开盘，并以高于前一根蜡烛的收盘价收盘。这些蜡烛不应有很长的影线，并且理想情况下应在形态中前一根蜡烛的实体内开盘。

##### 主要特点

- 如果得到其他技术指标（如相对强弱指数 RSI）的确认，三只白兵被认为是一个可靠的反转模型。
- 蜡烛的大小和影子的长度被用来评估是否存在回调的风险。
- 与三白兵相反的形态是三黑乌鸦，表示上涨趋势的反转。
