# 看涨吞没形态

看涨吞没形态是一种强有力的看涨反转K线形态，由两根K线组成，出现在下跌趋势中。第一根K线为黑色（看跌），随后是一根白色（看涨）K线，其实体完全吞没（覆盖）前一根K线的实体。

##### 主要特点：

- 第一根蜡烛是黑色的，开盘价高于收盘价（O > C）。
- 第二根蜡烛是白色的，开盘价低于收盘价 (O < C)。
- 第二根K线的开盘价低于第一根K线的收盘价（O < pC）。
- 第二根K线的收盘价高于第一根K线的开盘价（C > pO）。
- 第二根蜡烛的实体完全吞没了第一根蜡烛的实体。
- 处于下降趋势的形态。

![看涨吞没形态](../../../images/bullishengulfingpattern.png)

### 解释

看涨吞没被认为是下跌趋势反转最可靠的信号之一：

- 第一根蜡烛确认了现有的下跌趋势，并显示了卖方的控制力。
- 第二根蜡烛显示了控制权向买方的急剧转移，买方不仅扭转了上一时期的亏损，还创造了显著的收益。
- 前一根蜡烛实体的完全吞没象征着市场情绪从看跌完全转向看涨。
- 与第一根蜡烛相比，第二根蜡烛的尺寸越大，信号就越强。
- 如果该形态出现在支撑位或经过长时间下跌之后，其重要性会增加。

### 交易策略

看涨吞没形态为建立多头仓位提供了极好的机会：

- 在形态形成后进入多头仓位，通常在下一根K线开盘时。
- 将止损放在该形态第二根蜡烛的低点以下。
- 目标利润可以基于先前的阻力位、风险/回报比率或使用技术指标来设定。
- 在第二根蜡烛形成期间的高交易量显著提高了信号的可靠性。
- 结合其他指标，例如超卖区的RSI或移动平均汇聚，以提高交易成功的概率。
