# 晚星形态

晚星是一种看跌反转的K线形态，由三根K线组成，出现在上升趋势中。该形态显示了从看涨到看跌的情绪转变，通常伴随着一段不确定或盘整的时期。

##### 主要特点：

- 第一根K线是白色的（看涨），开盘价低于收盘价（O < C）。
- 第二根K线实体较小（可以是看涨或看跌），并从第一根K线跳空向上。其实体明显小于第一根K线的实体（B < pB * 0.5m）。
- 第三根K线是黑色（看跌），开盘价高于收盘价，实体较大（（O > C）&&（B > pB * 2）），并且收盘价深深位于第一根K线的实体之内。
- 处于上升趋势的形态。

![晚星形态](../../../images/eveningstarpattern.png)

### 解释

晚星被认为是潜在上涨趋势反转的强烈信号：

- 第一根K线确认了牛市趋势的强度。
- 第二根K线（星星）显示多头压力减弱以及市场的不确定性。
- 第三根K线显示卖方回归以及控制权从多头转向空头。
- 第三根K线深入第一根K线实体的越深，反转信号就越强。
- 如果第二根K线是一根十字星（实体非常小），该形态被称为“黄昏十字星”，并被认为是更强的信号。

### 交易策略

暮星形态提供了建立空头持仓的良好机会：

- 在形态形成后开空头持仓，通常在第四根K线开盘时或当第三根K线的最低点被突破时进行。
- 将止损置于第二根K线的高点之上或整个形态的高点之上。
- 目标利润可以根据相对于先前上升运动的斐波那契水平或先前支撑水平来设定。
- 注意成交量——第三根K线的成交量增加确认了看跌反转的力度。
- 结合其他技术指标，例如超买区的RSI或阻力线，以提高信号的可靠性。
- 也可用作退出现有多头持仓的信号。
