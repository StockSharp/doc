# 三内部下跌和三内部上涨

术语“3 Inside Down”和“3 Inside Up”指的是一对反转蜡烛图形态（每个图形包含三根独立的蜡烛），显示在蜡烛图上。该形态要求按照特定顺序形成三根蜡烛，表明当前趋势已失去动力，可能开始向相反方向移动。

##### 主要特点：

- 三只内升形态是一种看涨反转形态，由一根大幅下跌的蜡烛、一根位于前一根蜡烛内部的小幅上涨蜡烛组成，随后是一根收盘价高于第二根蜡烛的上涨蜡烛。
- 三只向下吞没形态是一种看跌反转形态，由一根大阳线、一根包含在前一根烛的较小阴线组成，接着是另一根收盘低于第二根蜡烛收盘价的阴线。
- 这些模式具有短期性质，可能并不总是会导致显著甚至轻微的趋势变化。
- 考虑在整体趋势的背景下使用这些形态。例如，在整体上升趋势中的回调期间使用3 Inside Up。

### 3 内侧上

该形态的向上版本是看涨的，表明价格的下跌可能正在结束，并且上升趋势正在开始。以下是该形态的特征：

1. 市场处于下行趋势或正在下跌。
2. 第一根蜡烛是一根有大实体的黑色（向下）蜡烛。
3. 第二根蜡烛是一根白色（向上）的蜡烛，实体很小，其开盘价和收盘价都在第一根蜡烛的实体范围内。
4. 第三根蜡烛是一根白色（向上）蜡烛，其收盘价高于第二根蜡烛的收盘价。

### 3 内侧下

该图形的向下版本是看跌的。它表明向上的价格走势正在结束，价格开始下跌。以下是该图形的特点：

1. 市场处于上升趋势或正在上涨。
2. 第一根蜡烛是一根大身的白色蜡烛。
3. 第二根蜡烛是一根小实体的黑色蜡烛，它在第一根蜡烛的实体范围内开盘和收盘。
4. 第三根蜡烛是黑色蜡烛，其收盘价低于第二根蜡烛的收盘价。

这些形态本质上是孕线形态，后面跟随一个确认烛线，许多交易者在孕线情况下会等待这一确认。
