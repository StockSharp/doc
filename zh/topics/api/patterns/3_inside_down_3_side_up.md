# 三内部下跌和三内部上涨

术语“三内下跌”和“三内上涨”指的是一对反转K线形态（每个图形包含三根独立的K线），显示在K线上。该形态要求按照特定顺序形成三根K线，表明当前趋势已失去动力，可能开始向相反方向移动。

##### 主要特点：

- 三只内升形态是一种看涨反转形态，由一根大幅下跌的K线、一根位于前一根K线内部的小幅上涨K线组成，随后是一根收盘价高于第二根K线的上涨K线。
- 三只向下吞没形态是一种看跌反转形态，由一根大阳线、一根包含在前一根K线内的较小阴线组成，接着是另一根收盘价低于第二根K线收盘价的阴线。
- 这些模式具有短期性质，可能并不总是会导致显著甚至轻微的趋势变化。
- 考虑在整体趋势的背景下使用这些形态。例如，在整体上升趋势中的回调期间使用三内上涨。

### 3 内侧上

该形态的向上版本是看涨的，表明价格的下跌可能正在结束，并且上升趋势正在开始。以下是该形态的特征：

1. 市场处于下行趋势或正在下跌。
2. 第一根K线是一根有大实体的黑色（向下）K线。
3. 第二根K线是一根白色（向上）的K线，实体很小，其开盘价和收盘价都在第一根K线的实体范围内。
4. 第三根K线是一根白色（向上）K线，其收盘价高于第二根K线的收盘价。

### 3 内侧下

该图形的向下版本是看跌的。它表明向上的价格走势正在结束，价格开始下跌。以下是该图形的特点：

1. 市场处于上升趋势或正在上涨。
2. 第一根K线是一根大身的白色K线。
3. 第二根K线是一根小实体的黑色K线，它在第一根K线的实体范围内开盘和收盘。
4. 第三根K线是黑色K线，其收盘价低于第二根K线的收盘价。

这些形态本质上是孕线形态，后面跟随一根确认K线，许多交易者会等待这根K线确认孕线信号。
