# 看跌孕线

看跌孕线是一种由两根蜡烛组成的反转蜡烛图形态，出现在上升趋势中。“孕线”一词来自日语，意思是“怀孕”，因为小蜡烛（子）被包含在大蜡烛（母）之内。

##### 主要特点：

- 第一根蜡烛是白色（看涨），开盘价低于收盘价（O < C），并且实体较长。
- 第二根蜡烛是黑色（看跌），开盘价高于收盘价（开盘 > 收盘），且实体较小。
- 第二根蜡烛的实体完全包含在第一根蜡烛的实体内（O < pC）且（C > pO）。
- 处于上升趋势的形态。

![看跌孕线形态](../../../images/bearishharamipattern.png)

### 解释

看跌孕线预示着上涨趋势可能结束：

- 第一根蜡烛确认了现有的上升趋势和买方的力量。
- 第二根蜡烛完全包含在第一根蜡烛内，表示多头动能的丧失以及卖方可能出现。
- 与第一根蜡烛相比，第二根蜡烛的实体越小，不确定性和反转的可能性就越明显。
- 如果第二根蜡烛是一根十字星（实体非常小），该形态被称为“孕线十字”，并被认为是更强的不确定性信号。
- 与看跌吞没形态相比，这种形态通常被认为是较弱的信号，但可能是潜在反转的较早指标。

### 交易策略

看跌孕线通常需要额外确认才能进行建仓：

- 在模式形成后，等待一个确认的看跌蜡烛再进入空头仓位。
- 将止损置于形态高点或第一根蜡烛的高点之上。
- 使用交易量作为额外确认——第二根蜡烛的成交量下降，而随后的看跌蜡烛成交量增加，会加强信号。
- 结合其他技术指标，例如处于超买区的RSI或振荡器背离。
- 在阻力位或超买区考虑这种模式，以提高交易成功的概率。
- 可能用于平掉现有的多头仓位，即使信号不足以开立空头仓位。
