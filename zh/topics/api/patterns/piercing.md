# 图案穿刺

刺透形态是一种看涨反转烛线形态，由两根K线组成，出现在下跌趋势中。第一根K线为黑色（看跌），随后是一根白色（看涨）K线，其开盘价低于前一根K线的最低价，并收盘在前一根K线实体中点之上。

##### 主要特点：

- 第一根K线是黑色的，开盘价高于收盘价（O > C）。
- 第二根K线是白色的，开盘价低于收盘价 (O < C)。
- 第二根K线的收盘价深度穿透第一根K线的实体，收盘价高于第一根K线的中点 (C > (pB / 2 + pC))。
- 处于下降趋势的形态。

![穿透形态](../../../images/piercingpattern.png)

### 解释

穿刺线被认为是潜在下跌趋势反转的可靠信号：

- 第二根K线开盘低于第一根K线的最低点（跳空下跌）显示持续的看跌压力。
- 然而，在交易时段内，多头掌控局面，将价格大幅推高，使K线收盘高于前一根K线实体的中点。
- 这表明市场情绪从看跌急剧转向看涨。
- 越深入穿透第一根K线实体的后半部分，信号就越强。
- 如果第二根K线的收盘价高于第一根K线的开盘价，该形态将转变为“看涨吞没”类别，这被认为是一个更强的信号。

### 交易策略

刺透形态提供了建立多头头寸的良好机会：

- 在确认形态后进入持仓（通常在第三根K线的开盘时或当第二根K线的高点被突破时）。
- 将止损置于第二根K线的最低点以下或整个形态的最低点以下。
- 目标利润可以根据之前的阻力位或斐波那契水平来设定。
- 考虑交易量——在第二根K线形成期间交易量高会增强信号的可信度。
- 来自超卖指标的额外确认，例如 RSI 或随机指标，会增加交易成功的可能性。
