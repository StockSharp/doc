# 倒锤形图案

倒锤线是一种看涨的K线形态，出现在下跌趋势中。该K线下方实体较小，上影线较长，下影线缺失或非常短，看起来像倒置的锤子。

##### 主要特点：

- 开盘价低于收盘价（O < C），尽管情况也可能相反。
- 价格区间下部的小实体烛身。
- 长上影线，通常比实体长2-3倍。
- 没有下影线或下影线很短。
- 处于下降趋势的形态。

![倒锤线形态](../../../images/invertedhammer.png)

### 解释

倒锤线被认为是可能的下跌趋势反转信号：

- 长上影线表明买方试图将价格大幅推高，但无法维持在高位。
- 尽管无法在高位收盘，但在长时间下跌后买方的出现可能预示着情绪的变化。
- 这种形态没有经典锤子线那么强，需要后续K线确认。
- 实体的颜色不那么重要，尽管白色/绿色的倒锤头被认为更看涨。

### 交易策略

倒锤形态需要谨慎的操作和确认：

- 必须等待下一个K线确认——在倒锤形之后出现一根强劲的看涨K线会显著增加反转的可能性。
- 将止损位设在倒锤头低点以下。
- 与更可靠的反转形态相比，使用较小的持仓规模。
- 结合超卖指标，例如 RSI 或随机指标，以提高交易成功的概率。
- 注意交易量——高交易量会增加信号的重要性。
