# 图案黑色蜡烛

黑色蜡烛（看跌蜡烛）是一种经典的蜡烛图形态，当收盘价低于开盘价时形成。这种蜡烛反映出看跌的市场情绪，即在蜡烛形成期间卖方控制了价格。

##### 主要特点：

- 开盘价高于收盘价（O > C）。
- 蜡烛实体通常为黑色（在现代图表中为红色）。
- 表示卖方相对于买方的占优势。
- 蜡烛实体的大小显示了看跌走势的强度。

![黑色蜡烛图形](../../../images/blackcandlepattern.png)

### 解释

黑色蜡烛表示市场的看跌压力：

- 蜡烛实体越长，看跌压力越强。
- 在上涨趋势之后出现的一根长黑蜡烛可能表示潜在的反转。
- 短影线的存在表明在整个期间内，空头控制了价格。
- 连续的黑色蜡烛表示稳定的下跌趋势。

### 交易策略

虽然单根黑色蜡烛通常不是独立的交易信号，但它可以作为更广泛策略的一部分使用：

- 在上涨后的下跌趋势或反转确认。
- 在阻力位寻找长黑烛以寻找潜在的做空机会。
- 与其他蜡烛图形态结合使用，例如，在看跌吞没之后出现一根黑色蜡烛。
- 在连续的阴线之后识别支撑位。
