# 图案流星

流星是一种看跌反转K线形态，出现在上升趋势中。该K线在下部有一个小实体，上影线很长，下影线不存在或非常短。它看起来像一颗尾部向上的星星。

##### 主要特点：

- 开盘价高于收盘价（O > C），尽管情况也可能相反。
- 价格区间下部的小实体烛身。
- 长上影线，通常比实体长2-3倍。
- 没有下影线或下影线非常短（BS == 0）。
- 处于上升趋势的形态。

![流星图案](../../../images/shootingstarpattern.png)

### 解释

流星被认为是潜在上涨趋势反转的强烈信号：

- 长上影线表明价格在交易时段内显著上涨，但随后卖方介入并将价格压低。
- 这表明市场对更高价格的拒绝，以及情绪可能从看涨转向看跌。
- 上影线越长，潜在反转信号越强。
- K线主体的颜色不那么重要，尽管黑色/红色的流星比白色/绿色的更被认为是看跌的。
- 这个形态类似倒锤头，但出现在上升趋势中，并且具有相反的含义。

### 交易策略

射击之星提供了建立空头持仓的机会：

- 等待下一根K线的确认——在射击之星之后出现的看跌K线会加强反转信号。
- 将止损水平设置在射击之星的高点之上。
- 根据之前的支撑位或风险/回报比率设定目标利润。
- 结合其他技术指标，例如超买区的RSI或出现看跌背离的MACD，以确认趋势反转。
- 在形成射击之星期间，较高的交易量会增加该信号的可靠性。
- 如果流星在重要阻力位形成或快速价格上涨后形成，则信号特别强烈。
