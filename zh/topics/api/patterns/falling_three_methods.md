# 式落三法

跌落三法是一种看跌趋势延续形态，由五根K线组成，形成于下跌趋势中。该形态显示在现有下跌趋势中出现暂时的整合或休整，然后继续下行。

##### 主要特点：

- 第一根K线是黑色（看跌），开盘价高于收盘价（开盘 > 收盘），且实体很长。
- 接下来的三根K线是白色的（看涨），开盘价低于收盘价（O < C），实体较小：(B < pB * 0.5m)，(B < ppB * 0.5m)，(B < pppB * 0.5m)。
- 三根中间K线的实体没有超出第一根K线的范围。
- 第五根K线是黑色（看跌），开盘价高于收盘价（O > C），且实体较长（B > pB * 2）。
- 第五根K线突破了第一根K线的低点并收于更低的位置。
- 处于下降趋势的形态。

![下跌三法形态](../../../images/fallingthreemethodspattern.png)

### 解释

下跌三法被认为是下跌趋势延续的可靠信号：

- 第一根长黑K线显示了下跌趋势的力度。
- 三根小白K线代表一个暂时的整合或回调，在此期间买方未能显著改变趋势。
- 第五根长黑K线确认了控制权回到卖方手中，并且下跌趋势将继续。
- 在经典技术分析中，这种形态可以被看作是旗形或小旗形。
- 这样的一系列K线表明，在继续下行之前，利用调整来积累空头持仓。

### 交易策略

下跌三法为建立或加强空头持仓提供了良好的机会：

- 在第五根K线开盘后或第一根K线的最低点被突破时开空仓。
- 将止损置于回调K线的高点上方或第一根K线的高点上方。
- 目标利润可以使用从趋势开始到形态第一个K线的距离的投影来设定。
- 注意成交量——理想情况下，中间三根K线的成交量下降，而第五根K线的成交量显著增加。
- 结合其他技术指标来确认信号。
- 考虑当前价格下方可能影响走势发展的重要支撑位。
