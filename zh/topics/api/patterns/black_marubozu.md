# 黑色光头吞没线形态

黑色光头阳线是一种看跌的烛线形态，其特征是在烛线的两端没有影线。术语“marubozu”来源于日语，意为“光头”或“剃光头”，反映了烛线没有影线的外观。

##### 主要特点：

- 开盘价高于收盘价（O > C）。
- K线实体完全充满，没有上下影线。
- 开盘价等于K线的最高价，收盘价等于K线的最低价。
- 表示强烈的看跌走势，期间卖方控制了价格。

![黑圆光烛模式](../../../images/blackmarubozu.png)

### 解释

黑色光头线被认为是一个强烈的看跌信号：

- 影线的缺失表明卖方完全占据主导——价格从高点开盘并持续下跌直到本周期收盘。
- 一根长黑实体阳烛表示非常强的空方压力。
- 在上涨趋势之后出现这种形态可能预示着趋势反转。
- 在下跌趋势中，它确认了走势的强度。

### 交易策略

黑色光头烛比普通的黑色K线提供更强的信号：

- 在形成黑色光头光脚K线后有机会建立空头持仓，特别是当它出现在重要阻力位时。
- 在设置止损时使用黑吞没的收盘价作为阻力位。
- 结合其他技术指标来确认信号。
- 注意交易量——高交易量增强信号的重要性。
