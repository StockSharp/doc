# 图案陀螺

陀螺转是一个烛台形态，其特点是小的实体和大致相等长度的上下影线。这个形态表明市场犹豫不决以及买卖双方的斗争。

##### 主要特点：

- 小蜡烛主体（可以是白色/绿色或黑色/红色）。
- 上下影线长度大致相等的长影线。
- 表示多方和空方之间的平衡。
- 反映市场犹豫不决和潜在的趋势变化。

![陀螺图案](../../../images/spinningtop.png)

### 解释

陀螺形态显示市场上的犹豫不决：

- 长影线显示，在此期间，价格上下波动显著。
- 小实体意味着尽管波动性很高，收盘价与开盘价的差距并不大。
- 在上升趋势中，它可能预示着多头动力的减弱。
- 在下跌趋势中，这可能表明看跌压力已经耗尽。
- 在趋势的顶部或重要阻力位之前，它可能预示着反转。

### 交易策略

单独的陀螺形态并不是一个强烈的交易信号，但可以与其他因素结合使用：

- 在做交易决策之前，观察后续的蜡烛图以寻求额外的确认。
- 用作更复杂的蜡烛图形态的一部分，例如早晨之星或黄昏之星。
- 在关键支撑或阻力位形成陀螺十字星后，应增加对随后的价格走势的关注。
- 在长期趋势之后出现纺锤形蜡烛时，可能会收紧止损。
