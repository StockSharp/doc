# 图案锤

锤子是一种在下跌趋势中形成的看涨K线形态。该K线在上部有一个小实体，下影线很长，上影线则不存在或非常短。名称来源于其形状像一把锤子。

##### 主要特点：

- 开盘价低于收盘价（O < C），尽管情况也可能相反。
- 价格区间上部的小阳烛实体。
- 下影线长，通常比实体长2-3倍。
- 没有上影线或上影线很短。
- 处于下降趋势的形态。

![锤子形态](../../../images/hammerpattern.png)

### 解释

锤子被认为是可能出现下跌趋势反转的强烈信号：

- 长下影线表明价格在此期间大幅下跌，但随后买方介入并将价格推回上升。
- 这表明市场对低价格的拒绝以及情绪可能从看跌转为看涨。
- 下影线越长，潜在反转信号越强。
- K线实体的颜色不那么重要，尽管白色/绿色的锤子被认为比黑色/红色的更看涨。

### 交易策略

锤头提供了建立多头头寸的机会：

- 等待下一根K线确认——锤子线之后的看涨K线会加强反转信号。
- 在锤形线的低点下方设置止损位。
- 根据之前的阻力位或风险/回报比率设定目标利润。
- 结合其他技术指标，如RSI或MACD，以确认趋势反转。
- 在锤子形态形成期间，较高的交易量会增加该信号的可靠性。
