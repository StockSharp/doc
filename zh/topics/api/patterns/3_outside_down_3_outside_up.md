# 三外下和三外上模式

术语“3外向下”和“3外向上”指的是三根蜡烛的反转形态。要形成一个形态，必须按特定顺序出现三根蜡烛，这表明当前趋势已失去动力，并可能预示现有趋势的反转。具体来说，当一根看跌蜡烛（收盘价低于开盘价）之后连续出现两根看涨蜡烛（收盘价高于开盘价），或反之时，就会形成一个形态。

##### 主要特点：

- 三外倒/起模式是由三根蜡烛组成的模式，通常预示趋势反转。
- 三外下和三外上形态的特点是一个蜡烛紧跟着两根相反颜色的蜡烛。
- 每个人都旨在利用市场心理学来理解短期情绪变化。

### 3 外向上

这个看涨的蜡烛图形态具有以下特征：

1. 市场处于下跌趋势。
2. 第一根蜡烛是看跌的。
3. 第二根蜡烛是看涨的，实体较长，并完全包住了第一根蜡烛。
4. 第三根蜡烛是看涨的，收盘价高于第二根蜡烛。

### 3 外侧向下

这种形态变化是一种看跌的蜡烛图模型，具有以下特征：

1. 市场处于上升趋势。
2. 第一根蜡烛是看涨的。
3. 第二根蜡烛是看跌的，实体较长，完全覆盖了第一根蜡烛。
4. 第三根蜡烛是看跌的，收盘价低于第二根蜡烛。

第一根蜡烛表示当第二根蜡烛吞没第一根蜡烛时，现有趋势的结束开始。第三根蜡烛则表示反转的加速。
