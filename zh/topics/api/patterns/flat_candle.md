# 模式平（中性）蜡烛

平（中性）蜡烛是一种蜡烛图形态，当开盘价和收盘价相同或非常接近时形成。这种蜡烛反映了市场的不确定性，即买卖双方的力量平衡时。

##### 主要特点：

- 开盘价等于收盘价 (O == C)。
- 上下影线可以有不同的长度。
- 表示市场的中立或犹豫不决。
- 可能表示在现有趋势继续之前的整合，或可能的反转。

![平蜡烛图形](../../../images/flatcandlepattern.png)

### 解释

单独一根平头蜡烛并不能明确显示市场方向，但在结合之前的蜡烛和整体趋势的情况下可能有用：

- 在强烈的向上或向下运动之后，一个平盘蜡烛可能表示动能减弱和可能的反转。
- 在横向移动过程中，一根平头蜡烛确认了盘整的继续。
- 影线的长度可以提供关于市场情绪的额外信息——长影线表示价格变动尝试被拒绝，而短影线表示低波动性。

### 交易策略

平坦的蜡烛很少被用作单独的仓位进入信号，但可以帮助做出交易决策：

- 在进行交易之前，请观察后续K线或其他技术指标以确认信号。
- 使用平头烛结合其他分析方法来识别支撑或阻力位。
- 如果趋势中出现平蜡烛，可能表示走势减弱，则增加止损幅度或获利了结。
