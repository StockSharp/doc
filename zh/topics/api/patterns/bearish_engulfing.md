# 看跌吞没形态

看跌吞没是一个强力的看跌反转蜡烛图形态，由两个蜡烛组成，形成于上升趋势中。第一根蜡烛是白色（看涨）的，随后是一根黑色（看跌）的蜡烛，其实体完全吞没（覆盖）前一根蜡烛的实体。

##### 主要特点：

- 第一根蜡烛是白色的，开盘价低于收盘价 (O < C)。
- 第二根蜡烛是黑色的，开盘价高于收盘价（O > C）。
- 第二根K线的开盘价高于第一根K线的收盘价（O > pC）。
- 第二根K线的收盘价低于第一根K线的开盘价（C < pO）。
- 第二根蜡烛的实体完全吞没了第一根蜡烛的实体。
- 处于上升趋势的形态。

![看跌吞没形态](../../../images/bearishengulfingpattern.png)

### 解释

看跌吞没被认为是上升趋势反转最可靠的信号之一：

- 第一根蜡烛确认了现有的上升趋势，并显示了买方的控制力。
- 第二根蜡烛显示了控制权向卖方的急剧转移，卖方不仅抹去了上一周期的利润，还造成了显著的下跌。
- 前一根蜡烛实体的完全吞没象征着市场情绪从多头完全转向空头。
- 与第一根蜡烛相比，第二根蜡烛的尺寸越大，信号就越强。
- 如果该形态出现在阻力位或经过长时间的上涨趋势之后，其意义会增加。

### 交易策略

看跌吞没形态为建立空头头寸提供了极好的机会：

- 在形态形成后建立空头仓位，通常在下一根K线开盘时进行。
- 在该形态第二根蜡烛的高点上方设置止损。
- 目标利润可以基于先前的支撑位、风险/回报比率或使用技术指标来设定。
- 在第二根蜡烛形成期间的高交易量显著提高了信号的可靠性。
- 结合其他指标，例如处于超买区的RSI或振荡器上的背离，以提高交易成功的概率。
- 也可用作平掉现有多头仓位的信号。
