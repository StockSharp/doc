# 图案吊人

上吊线是一种看跌的反转烛线形态，出现在上升趋势中。K线的实体位于上部，较小，下影线较长，上影线不存在或非常短。K线的形状类似一个双腿悬挂的人，因此得名。

##### 主要特点：

- 开盘价高于收盘价（O > C），尽管情况也可能相反。
- 价格区间上部的小阳烛实体。
- 下影线长，通常比实体长2-3倍。
- 没有上影线或上影线非常短（TS == 0）。
- 处于上升趋势的形态。

![上吊线形态](../../../images/hangingmanpattern.png)

### 解释

吊人线被认为是上涨趋势可能结束的警告：

- 长下影线表明价格在交易时段内大幅下跌，显示出卖方的出现。
- 尽管买家能够将价格推回到区间的上方，但在上涨趋势中价格出现大幅下跌的事实本身就是一个警告信号。
- K线实体的颜色不那么重要，尽管黑色/红色的实体被认为比白色/绿色的更偏空。
- 下影线越长，K线实体越小，信号越强。
- 这个形态需要后续的K线线确认。

### 交易策略

悬挂线通常需要额外确认才能做出交易决策：

- 在悬挂线形态出现后，等待确认的看跌K线再进入空头持仓。
- 在上吊线的高点上方设置止损。
- 考虑交易量——在形态形成期间和确认K线上高交易量会加强看跌信号。
- 与其他技术指标结合使用，例如处于超买区的 RSI 或振荡指标上的背离。
- 即使不建立空头持仓，也可能用于部分平掉现有的多头持仓。
- 如果该形态在重要阻力位形成或在长时间上涨之后出现，请特别注意。
