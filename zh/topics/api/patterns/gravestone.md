# 图案墓碑

墓碑线是一种蜡烛图形态，其特点是开盘价和收盘价相等，且上影线很长，下影线为零。该蜡烛的形状类似于倒置的“T”字，因此得名“墓碑”。

##### 主要特点：

- 开盘价等于收盘价 (O == C)。
- 长上影线。
- 没有下影线 (BS == 0)。
- 类似流星，但主体为中性（十字星）。

![墓碑图案](../../../images/gravestonepattern.png)

### 解释

墓碑十字星被认为是潜在的反转信号，尤其是在上升趋势中：

- 长上影线表明买方在大部分时间内控制了市场，但随后卖方将价格回拉至开盘水平。
- 对更高价格的拒绝可能预示着上涨势头的结束。
- 与普通的流星形态不同，开盘价和收盘价相等（十字星）表明力量平衡更加明显。
- 在上升趋势中，这种形态具有看跌意义，可能预示着反转。
- 在下跌趋势中，它可能表示暂时的阻力或趋势的延续。

### 交易策略

墓碑形态在做交易决策时需要额外确认：

- 在下一周期等待确认的看跌K线，然后再开空头仓位。
- 在墓碑的最高点上方设置止损。
- 与阻力位或指标上的超买情况结合使用。
- 注意成交量——墓碑形态形成期间的高成交量会增加信号的可信度。
- 可能用于确定多头头寸的退出点，即使没有建立空头头寸。
