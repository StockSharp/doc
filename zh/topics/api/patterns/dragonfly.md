# 花纹蜻蜓

蜻蜓线是一种K线形态，其特征是开盘价和收盘价相等，没有上影线，并且有长下影线。这种蜡烛呈现出字母“T”的形状，因此得名“蜻蜓”。

##### 主要特点：

- 开盘价等于收盘价 (O == C)。
- 没有上影线 (TS == 0)。
- 长下影线。
- 类似锤子，但主体中性（十字星）。

![蜻蜓图案](../../../images/dragonflypattern.png)

### 解释

蜻蜓十字星被认为是一个潜在的反转信号，尤其是在下跌趋势中：

- 长下影线表明卖方在大部分时间内控制了市场，但随后买方将价格拉回到开盘水平。
- 拒绝更低的价格可能预示着看跌压力的结束。
- 与普通的锤子不同，开盘价和收盘价相等（十字星）表明力量的平衡更为明显。
- 在下跌趋势中，这种形态具有看涨意义，可能预示着反转。
- 在上涨趋势中，它可能预示着潜在的回调。

### 交易策略

蜻蜓在做交易决策时需要额外确认：

- 在下一周期等待确认的看涨K线，然后再开多仓。
- 在蜻蜓线的最低点下方设置止损。
- 与支撑位或指标上的超卖条件结合使用。
- 注意成交量——蜻蜓十字形态形成时的高成交量会增加信号的可信度。
- 可能用于确定空头头寸的退出点，即使没有建立多头头寸。
