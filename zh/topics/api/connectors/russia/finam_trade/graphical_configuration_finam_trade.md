# 图形化配置：Finam Trade API

在所有 StockSharp 产品中，请通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

连接编辑器的基本部分包含：

- `Token`
- `AccountId`

在高级视图中可配置 `AppId`、`PollingInterval`、`LookupLimit`、`RestAddress` 和 `WebSocketAddress`。每个字段的用途和默认值均在[连接器配置](configuration_finam_trade.md)页面中说明。

此处未提供连接器专用截图，因为 Finam Trade 连接器源代码中没有真实的产品截图。请按照上述字段列表使用标准连接设置窗口。
