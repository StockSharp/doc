# IIFL

**IIFL** 将 StockSharp 连接到面向印度现货和衍生品市场的 IIFL Markets Open API。

## 主要功能

- 已根据源代码核实的功能：品种搜索、实时 Level 1 行情、订单簿和成交数据、历史 K 线，以及股票、期货和期权的资产组合与订单操作。
- 服务商特有的传输、会话和数据格式均封装在标准 StockSharp API 之后。

## 适用场景

可用于监控印度市场品种、分析行情、订单簿和 K 线、请求历史数据，以及执行受支持的订单流程。

可用交易所和品种、历史深度、交易权限及请求限制由 IIFL 和所连接的账户决定。
