# Zhongtai XTP 图形化配置

在所有 StockSharp 产品中，请在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中配置连接。

- **用户名** - 属性 `Login`。
- **密码** - 属性 `Password`。
- **客户端标识符** - 属性 `ClientId`。默认值为 `1`。
- **行情服务器地址** - 属性 `QuoteAddress`。
- **交易服务器地址** - 属性 `TransactionAddress`。
- **协议** - 属性 `Protocol`。默认值为 `TCP`。
- **本地地址** - 属性 `LocalAddress`。
- **软件密钥** - 属性 `SoftwareKey`。
- **软件版本** - 属性 `SoftwareVersion`。默认值为 `1.0`。
- **数据目录** - 属性 `DataPath`。
