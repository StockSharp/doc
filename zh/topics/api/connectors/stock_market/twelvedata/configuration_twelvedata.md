# Twelve Data 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Token` - API 访问令牌。
- `Address` - REST API 地址。
- `WebSocketAddress` - WebSocket 服务器地址。
- `Country` - 用于筛选市场数据的国家或地区。
