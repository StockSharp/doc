# uSMART OpenAPI 图形化配置

对于所有[S#](../../../../api.md) 产品，连接的图形化配置在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md) 上进行：

- `AccessToken` - OAuth 访问令牌。
- `ChannelId` - uSMART 连接通道标识符。
- `PrivateKey` - 用于签署交易的私钥。
- `FundAccount` - uSMART 资金账户标识符。
