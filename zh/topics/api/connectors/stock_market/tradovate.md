# Tradovate

**Tradovate** 是一家期货经纪商和交易平台。

该连接器支持期货合约搜索、实时行情、逐笔成交和订单簿、历史和实时 K 线，以及账户、余额、持仓、订单和成交。可以在实盘或模拟环境中注册、修改和撤销订单。

在为 Tradovate 开发交易机器人之前，请先查看[连接器](../../connectors.md)部分中的链接。
