# 连接器配置: Motilal Oswal

从服务提供商获取身份验证凭据，并指定连接参数。

- `Key` - 身份验证凭据。
- `Secret` - 身份验证凭据。
- `Token` - 身份验证凭据。
- `AccessToken` - 身份验证凭据。
- `ClientCode` - 账户或客户端标识符。
- `LocalIp` - 连接参数。 默认值: `127.0.0.1`.
- `PublicIp` - 连接参数。 默认值: `127.0.0.1`.
- `MacAddress` - 服务地址。 默认值: `00:00:00:00:00:00`.
- `VendorInfo` - 连接参数。
- `InstalledAppId` - 账户或客户端标识符。
- `IsDemo` - 控制连接器行为的开关。
- `DefaultProduct` - 连接器的运行模式或选项。 默认值: `MotilalOswalProducts.Normal`.
- `AlgoId` - 账户或客户端标识符。
- `ReconnectAttempts` - 连接器的数值参数。 默认值: `10`.
