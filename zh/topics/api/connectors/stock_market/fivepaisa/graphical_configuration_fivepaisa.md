# 图形化配置: 5paisa Xstream

在所有 StockSharp 产品中，均通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

- `AppKey` - 身份验证凭据。
- `ClientCode` - 账户或客户端标识符。
- `Token` - 身份验证凭据。
- `DefaultProduct` - 连接器的运行模式或选项。 默认值: `FivePaisaProducts.Intraday`.
- `AlgoId` - 连接器的数值参数。
- `ReconnectAttempts` - 连接器的数值参数。 默认值: `10`.
