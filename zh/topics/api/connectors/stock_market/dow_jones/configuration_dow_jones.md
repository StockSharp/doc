# Dow Jones 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `AuthenticationMode` - 身份验证方式。
- `Token` - API 访问令牌。
- `ClientId` - OAuth 客户端标识符。
- `Login` - 账户登录名。
- `Password` - 账户密码。
- `Address` - REST API 地址。
- `OAuthAddress` - OAuth 服务端点。
