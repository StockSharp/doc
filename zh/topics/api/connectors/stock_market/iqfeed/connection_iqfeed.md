# 连接 IQFeed

使用 IQConnect 应用程序建立与 IQ 服务器的连接，该应用程序可以安装在本地计算机或远程计算机上。客户端应用程序与 IQConnect 之间，以及 IQConnect 与服务器之间的通信均通过 TCP/IP 协议进行。

为获取数据，客户端应用程序通过多个端口使用四个连接：

1. Level1（端口5009）——用于仪器的实时数据（行情、开盘价、收盘价、波动率等）和新闻。
2. Level2（端口 9200）—用于获取工具的扩展报价，每个 ECN 可以获得的最佳几条报价。
3. 查找（端口 9100）——用于仪器搜索、获取历史数据、获取新闻的扩展信息。
4. 管理员（端口 9300）——用于获取有关连接的一般信息和更改设置。

括号内的端口数量默认用于连接 IQConnect。对于客户端连接，你可以更改注册表中的端口号，例如，Level1的端口号路径如下：\[HKEY\_CURRENT\_USER\SOFTWARE\\DTN\\IQFEED\\\Startup\\Level1Port\]。连接 IQ 服务器的端口号无法更改。
