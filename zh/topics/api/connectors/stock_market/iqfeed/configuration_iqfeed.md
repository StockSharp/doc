# 连接器配置: IQFeed

准备服务提供商的本地网关或客户端，并指定连接参数。

- `Login` - 账户或客户端标识符。
- `Password` - 身份验证凭据。
- `Level1Address` - 服务地址。
- `Level2Address` - 服务地址。
- `LookupAddress` - 服务地址。
- `AdminAddress` - 服务地址。
- `DerivativeAddress` - 服务地址。
- `Level1Columns` - 连接参数。
- `IsDownloadSecurityFromSite` - 控制连接器行为的开关。
- `SecuritiesFile` - 本地文件或目录的路径。
- `Version` - 连接参数。 默认值: `6.2`.
