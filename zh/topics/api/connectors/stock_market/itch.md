# 瘙痒

**ITCH** - 实时市场数据提供商，提供股票报价、外汇、新闻、期货合约等。

在开始为当前交易平台编写交易机器人之前，建议先阅读[连接器](../../connectors.md)中的链接。

> [!TIP]
> 连接器仅支持市场数据馈送，不支持交易。
