# 配置 ITCH

要使用连接器，你需要指定**登录**和**密码**。**登录**和**密码**由经纪人提供。要获得API访问权限，建议联系经纪人。

[ITCH](../itch.md) \- 直接数据/馈送协议，允许通过TCP和UDP协议连接。[ITCH](../itch.md)提供订单日志，用于跟踪任何订单的所有变更。该协议被纳斯达克（见[TotalView\-ITCH](https://www.nasdaqtrader.com/Trader.aspx?id=Totalview2)）和伦敦证券交易所（见[MITCH](https://www.londonstockexchange.com/)）使用。
