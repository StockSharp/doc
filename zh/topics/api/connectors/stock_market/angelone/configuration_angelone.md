# Angel One 连接器配置

获取 Angel One SmartAPI 所需的凭据、服务器地址和账户标识符，然后指定以下连接器设置。

- **用户名** - 属性 `Login`。
- **密码** - 属性 `Password`。
- **API 密钥** - 属性 `ApiKey`。
- **TOTP 密钥** - 属性 `TotpSecret`。
- **客户端本地 IP 地址** - 属性 `ClientLocalIp`。默认值为 `127.0.0.1`。
- **客户端公共 IP 地址** - 属性 `ClientPublicIp`。
- **MAC 地址** - 属性 `MacAddress`。
- **默认产品** - 属性 `DefaultProduct`。默认值为 `Delivery`。
