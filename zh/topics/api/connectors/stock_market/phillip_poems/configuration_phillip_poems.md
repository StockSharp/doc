# Phillip POEMS 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `ClientId` - OAuth 客户端标识符。
- `ClientSecret` - OAuth 客户端密钥。
- `ApiKey` - API 密钥。
- `AccessToken` - OAuth 访问令牌。
- `RefreshToken` - OAuth 刷新令牌。
- `AccountNo` - 经纪账户号码。
