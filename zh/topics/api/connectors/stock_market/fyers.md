# FYERS

**FYERS** 将 **FYERS API v3** 集成到 StockSharp，用于获取市场数据和进行交易。

该连接器支持交易品种搜索、行情、逐笔成交数据、订单簿、历史 K 线、账户、余额和持仓、订单管理、账户和订单的实时更新。

在为 FYERS 开发交易机器人之前，请先查看[连接器](../../connectors.md)部分中的链接。
