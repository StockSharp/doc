# 图形化配置: Capital.com

在所有 StockSharp 产品中，均通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

- `ApiKey` - 身份验证凭据。
- `Login` - 账户或客户端标识符。
- `Password` - 身份验证凭据。
- `AccountId` - 账户或客户端标识符。
- `IsDemo` - 控制连接器行为的开关。 默认值: `true`.
- `IsPasswordEncryptionEnabled` - 控制连接器行为的开关。
