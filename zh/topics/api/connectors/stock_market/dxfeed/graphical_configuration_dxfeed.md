# 图形化配置: dxFeed

在所有 StockSharp 产品中，均通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

- `Address` - 服务地址。 默认值: `wss://demo.dxfeed.com/dxlink-ws`.
- `Token` - 身份验证凭据。
- `AggregationPeriod` - 时间间隔。
- `MarketDepthLevels` - 连接器的数值参数。 默认值: `20`.
- `MarketDepthSources` - 连接参数。 默认值: `NTV`.
