# PolygonIO

**PolygonIO** - 股票、外汇（FX）和数字/加密货币的实时和历史市场数据提供商。

在开始为当前交易平台编写交易机器人之前，建议先阅读[连接器](../../connectors.md)中的链接。

> [!CAUTION]
> 连接器仅支持市场数据馈送，不支持交易。
