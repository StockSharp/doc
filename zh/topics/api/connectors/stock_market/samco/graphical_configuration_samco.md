# 图形化配置：Samco

在所有 StockSharp 产品中，请通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

连接编辑器的基本部分包含：

- `Key`

其余属性可在高级视图中设置，并在[连接器配置](configuration_samco.md)页面中说明。除非服务商分配了其他值，否则请保留预填的服务端点。
