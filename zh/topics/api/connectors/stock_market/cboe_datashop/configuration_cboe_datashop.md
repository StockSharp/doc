# Cboe DataShop / LiveVol 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Login` - 账户登录名。
- `Password` - 账户密码。
- `Address` - REST API 地址。
- `TokenAddress` - OAuth 令牌获取端点。
- `DataMode` - 数据获取模式。
