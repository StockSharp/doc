# Kalshi 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `ApiKey` - API 密钥。
- `PrivateKey` - 用于在本地签署请求和交易的私钥。
- `IsDemo` - 使用 Kalshi 演示环境。
- `Subaccount` - Kalshi 子账户编号，取值为 0 到 63。
