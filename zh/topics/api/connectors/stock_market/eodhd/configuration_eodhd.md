# EOD Historical Data 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Token` - API 访问令牌。
- `Address` - REST API 地址。
- `StockTradeWebSocketAddress` - WebSocket 服务器地址。
- `StockQuoteWebSocketAddress` - WebSocket 服务器地址。
- `ForexWebSocketAddress` - WebSocket 服务器地址。
- `CryptoWebSocketAddress` - WebSocket 服务器地址。
- `StockExchange` - 请求交易品种时使用的交易所代码。
