# BMLL 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `AuthenticationMode` - 身份验证方式。
- `Login` - 账户登录名。
- `PrivateKeyPath` - 私钥文件路径。
- `Password` - 账户密码。
- `Token` - API 访问令牌。
- `ApiKey` - API 密钥。
- `Address` - REST API 地址。
- `AuthenticationAddress` - 身份验证服务端点。
- `TradesDataset` - BMLL 成交数据集名称。
- `Level3Dataset` - BMLL 三级数据集名称。
