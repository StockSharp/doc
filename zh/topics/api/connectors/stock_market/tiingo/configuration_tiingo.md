# Tiingo 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Token` - API 访问令牌。
- `Address` - REST API 地址。
- `IexWebSocketAddress` - WebSocket 服务器地址。
- `ForexWebSocketAddress` - WebSocket 服务器地址。
- `CryptoWebSocketAddress` - WebSocket 服务器地址。
- `EquityStreamingMode` - 实时股票数据的流式传输模式。
