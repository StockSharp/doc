# MarketData.app

**MarketData.app** 将 StockSharp 连接到覆盖美国股票、基金、指数和期权的 MarketData.app。

## 主要功能

- 已根据源代码核实的功能：品种和期权合约搜索、Level 1 市场数据，以及支持盘前盘后和拆股调整的历史 K 线。该适配器不提供交易操作。
- 服务商特有的传输、会话和数据格式均封装在标准 StockSharp API 之后。

## 适用场景

可用于查找美国市场品种、获取行情，并下载股票或期权 K 线历史数据。

数据覆盖、延迟、历史深度、合约限制和可用性取决于 MarketData.app 订阅方案。
