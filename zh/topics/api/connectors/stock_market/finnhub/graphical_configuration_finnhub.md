# Finnhub 图形化配置

对于所有[S#](../../../../api.md) 产品，连接的图形化配置在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md) 上进行：

- `Token` - API 访问令牌。
- `Address` - REST API 地址。
- `WebSocketAddress` - WebSocket 服务器地址。
- `StockExchange` - 请求交易品种时使用的交易所代码。
- `ForexExchange` - Finnhub 外汇交易场所代码。
- `CryptoExchange` - Finnhub 加密货币交易场所代码。
