# Finnhub 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Token` - API 访问令牌。
- `Address` - REST API 地址。
- `WebSocketAddress` - WebSocket 服务器地址。
- `StockExchange` - 请求交易品种时使用的交易所代码。
- `ForexExchange` - Finnhub 外汇交易场所代码。
- `CryptoExchange` - Finnhub 加密货币交易场所代码。
