# TradeLocker 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Login` - 账户登录名。
- `Password` - 账户密码。
- `Server` - TradeLocker 服务器地址。
- `AccountId` - 服务分配的账户标识符。
- `IsDemo` - 模拟环境模式。
