# Charles Schwab 连接器配置

创建可访问 [Charles Schwab Trader API](https://developer.schwab.com/products/trader-api--individual) 的应用程序，并获取 OAuth 令牌。

- **访问令牌** (`Token`) — 有效的 OAuth 访问令牌。
- **地址** (`Address`) — Trader API 地址。默认值为 `https://api.schwabapi.com/`。

连接器会自动获取 WebSocket 地址和实时连接标识符。请按照 Charles Schwab 的要求更新 OAuth 令牌。
