# 连接器配置: LSEG Real-Time

从服务提供商获取身份验证凭据，并指定连接参数。

- `AuthenticationMode` - 连接器的运行模式或选项。
- `Address` - 服务地址。
- `StandbyAddress` - 服务地址。
- `IsHotStandby` - 控制连接器行为的开关。
- `Login` - 账户或客户端标识符。
- `Password` - 身份验证凭据。
- `ClientId` - 账户或客户端标识符。
- `Secret` - 身份验证凭据。
- `ApplicationId` - 账户或客户端标识符。 默认值: `256`.
- `Service` - 连接参数。 默认值: `ELEKTRON_DD`.
- `Region` - 连接参数。 默认值: `us-east-1`.
- `Position` - 连接参数。
- `Scope` - 连接参数。 默认值: `trapi.streaming.pricing.read`.
- `AuthUrl` - 服务地址。
- `DiscoveryUrl` - 服务地址。 默认值: `https://api.refinitiv.com/streaming/pricing/v1/`.
