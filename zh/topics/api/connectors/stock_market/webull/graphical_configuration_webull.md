# Webull 图形化配置

在所有 StockSharp 产品中，都可以通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

- **访问密钥** (`Key`) — 应用程序密钥。
- **私密密钥** (`Secret`) — 应用程序私密密钥。
- **访问令牌** (`Token`) — 可选的访问令牌。
- **账户** (`Account`) — 交易账户标识符。
- **模拟模式** (`IsDemo`) — 使用测试环境。
