# 图形化配置: kabu Station

在所有 StockSharp 产品中，均通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

- `ApiPassword` - 身份验证凭据。
- `IsDemo` - 控制连接器行为的开关。 默认值: `true`.
- `DefaultAccountType` - 连接器的运行模式或选项。 默认值: `KabuStationAccountTypes.Specified`.
- `DefaultStockOrderExchange` - 连接参数。 默认值: `KabuStationExchanges.Sor`.
