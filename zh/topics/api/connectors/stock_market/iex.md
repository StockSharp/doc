# IEX

**Investors Exchange (IEX)** - 为股票报价、外汇、新闻、期货合约等提供实时市场数据。

在开始为当前交易平台编写交易机器人之前，建议阅读[连接器](../../connectors.md)中的链接。

> [!CAUTION]
> 连接器仅支持市场数据馈送，不支持交易。
