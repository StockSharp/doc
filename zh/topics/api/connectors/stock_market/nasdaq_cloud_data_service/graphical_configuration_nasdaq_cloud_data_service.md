# Nasdaq Cloud Data Service 图形化配置

对于所有[S#](../../../../api.md) 产品，连接的图形化配置在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md) 上进行：

- `Login` - 账户登录名。
- `Password` - 账户密码。
- `Address` - REST API 地址。
- `Source` - Nasdaq Cloud Data Service 数据源标识符。
- `Offset` - 市场数据模式：实时或延迟。
