# Nasdaq Cloud Data Service 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Login` - 账户登录名。
- `Password` - 账户密码。
- `Address` - REST API 地址。
- `Source` - Nasdaq Cloud Data Service 数据源标识符。
- `Offset` - 市场数据模式：实时或延迟。
