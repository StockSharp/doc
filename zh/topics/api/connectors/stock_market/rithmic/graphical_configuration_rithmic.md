# Rithmic 图形配置

对于所有 [S\#](../../../../api.md) 产品，连接的图形配置在 [连接设置窗口](../../../graphical_user_interface/connection_settings_window.md) 上进行：

![API GUI 设置 Rithmic](../../../../../images/api_gui_settings_rithmic.png)

- **登录** \- 登录。
- **密码** \- 密码。
- **证书** - 证书文件的路径，连接到 Rithmic 系统所必需。
- **文件日志** - 日志文件的路径。
- **服务器类型** - 服务器类型。
- **点（管理员）** - 用于管理功能的连接点（初始化/反初始化）。
- **点（数据）** - 与市场数据的连接点。
- **登录 (trans)** - 额外登录。用于将交易发送到单独服务器时。
- **点（交易）** - 与交易执行系统的连接点。
- **密码（传输）** - 额外密码。当交易发送到单独服务器时使用。
- **点（持仓）** - 用于访问投资组合和持仓信息的连接点。
- **点（历史）** - 用于访问历史数据的连接点。
- **域名（地址）** - 域名地址。
- **域名 (name)** - 域名。
- **许可证** - 许可证服务器地址。
- **经纪人** - 经纪人地址。
- **日志（地址）** - 日志记录器地址。
- **用户名（历史）** - 额外登录。用于历史工厂认证的用户ID。
- **密码（hist）** - 附加密码。用于与历史工厂进行身份验证的密码
- **心跳** - 服务器检查间隔，用于跟踪连接是否活跃。默认值为1分钟。
- **重新连接设置** - 用于跟踪与交易系统设置连接的机制。([重新连接设置](../../reconnection_settings.md))
