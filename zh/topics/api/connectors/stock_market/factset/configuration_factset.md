# FactSet 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `AuthenticationMode` - 身份验证方式。
- `Login` - 账户登录名。
- `Password` - 账户密码。
- `OAuthConfigFile` - OAuth 配置文件的路径。
