# 图形化配置: Swissquote OpenWealth

在所有 StockSharp 产品中，均通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

- `Token` - 身份验证凭据。
- `CustomerId` - 账户或客户端标识符。
- `SafekeepingAccountId` - 账户或客户端标识符。
- `CashAccountId` - 账户或客户端标识符。
- `AccountCurrency` - 连接参数。 默认值: `CHF`.
- `IsDemo` - 控制连接器行为的开关。 默认值: `true`.
- `IsDryRun` - 控制连接器行为的开关。
- `IsBestEffort` - 控制连接器行为的开关。
