# Tradovate 图形化配置

在所有 StockSharp 产品中，请在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中配置连接。

- **用户名** - Tradovate 用户名。
- **密码** - Tradovate 密码。
- **客户端标识符** - API 客户端标识符。
- **密钥** - API 客户端密钥。
- **应用程序标识符** - 已注册的应用程序标识符。
- **应用程序版本** - 已注册的应用程序版本。
- **设备标识符** - 固定的设备标识符。
- **模拟模式** - 使用模拟环境。
