# Tradovate 连接器配置

在 Tradovate 注册 API 应用程序，并在连接器设置中指定其凭据。

- **用户名** - Tradovate 用户名。
- **密码** - Tradovate 密码。
- **客户端标识符** - API 客户端标识符（`cid`）。
- **密钥** - API 客户端密钥（`sec`）。
- **应用程序标识符** - 已注册的应用程序标识符。默认值为 `StockSharp`。
- **应用程序版本** - 已注册的应用程序版本。默认值为 `1.0`。
- **设备标识符** - 为 API 访问注册的固定设备标识符。连接器会自动生成并保存该标识符。
- **模拟模式** - 连接到 Tradovate 模拟环境，而不是实盘环境。
