# Tiger Brokers 图形化配置

在所有 StockSharp 产品中，请在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中配置连接。

- **Tiger 标识符** - 属性 `TigerId`。
- **账户** - 属性 `Account`。
- **许可证** - 属性 `License`。默认值为 `Singapore`。
- **私钥** - 属性 `PrivateKey`。
- **令牌** - 属性 `Token`。
- **自动获取行情权限** - 属性 `AutoGrabPermission`。默认值为 `true`。
