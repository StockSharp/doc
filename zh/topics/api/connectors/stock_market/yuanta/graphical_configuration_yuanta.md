# 图形化配置: Yuanta SPARK

在所有 StockSharp 产品中，均通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

- `SdkPath` - 本地文件或目录的路径。
- `Account` - 账户或客户端标识符。
- `Password` - 身份验证凭据。
- `CertificatePath` - 本地文件或目录的路径。
- `CertificatePassword` - 身份验证凭据。
- `Environment` - 连接器的运行模式或选项。 默认值: `YuantaEnvironments.Production`.
- `LogPath` - 本地文件或目录的路径。
- `ReconnectAttempts` - 连接器的数值参数。 默认值: `10`.
