# J.P. Morgan DataQuery 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `ClientId` - OAuth 客户端标识符。
- `ClientSecret` - OAuth 客户端密钥。
- `GroupId` - DataQuery 组标识符。
- `Attribute` - 要请求的 DataQuery 属性。
