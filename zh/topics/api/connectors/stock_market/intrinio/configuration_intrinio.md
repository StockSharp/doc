# Intrinio 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Token` - API 访问令牌。
- `Address` - REST API 地址。
- `EquityProvider` - Intrinio 股票数据提供商。
- `OptionProvider` - Intrinio 期权数据提供商。
- `IsDelayedOptions` - 是否使用延迟期权数据。
