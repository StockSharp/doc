# 连接器配置: Fubon Neo

安装官方开发工具包，并指定其路径、身份验证凭据和其他连接参数。

- `SdkPath` - 本地文件或目录的路径。
- `PersonalId` - 账户或客户端标识符。
- `Password` - 身份验证凭据。
- `ApiKey` - 身份验证凭据。
- `IsApiKeyLogin` - 控制连接器行为的开关。
- `CertificatePath` - 本地文件或目录的路径。
- `CertificatePassword` - 身份验证凭据。
- `EnvironmentUrl` - 服务地址。
- `RealtimeMode` - 连接器的运行模式或选项。 默认值: `FubonNeoRealtimeModes.Normal`.
- `ReconnectAttempts` - 连接器的数值参数。 默认值: `10`.
