# Longbridge OpenAPI 图形化配置

在所有 StockSharp 产品中，请在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中配置连接。

- **应用程序密钥** - 属性 `AppKey`。
- **应用程序秘密** - 属性 `AppSecret`。
- **访问令牌** - 属性 `AccessToken`。
- **投资组合** - 属性 `Portfolio`。默认值为 `Longbridge`。
- **API 地址** - 属性 `ApiUrl`。默认值为 `https://openapi.longbridge.com`。
- **行情服务器地址** - 属性 `QuoteUrl`。默认值为 `wss://openapi-quote.longbridge.com/v2`。
- **交易服务器地址** - 属性 `TradeUrl`。默认值为 `wss://openapi-trade.longbridge.com/v2`。
