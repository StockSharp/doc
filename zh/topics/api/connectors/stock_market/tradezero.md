# TradeZero

**TradeZero** 是一家用于交易美国股票和单腿期权的经纪商。

该连接器支持订单注册、撤销和撤单重报，以及账户数据、持仓、当前订单和盈亏。账户更新通过 WebSocket 推送。由于 TradeZero 不提供公共市场数据 WebSocket，行情、订单簿和 K 线以有限的 REST 快照形式返回。

在为 TradeZero 开发交易机器人之前，请先查看[连接器](../../connectors.md)部分中的链接。
