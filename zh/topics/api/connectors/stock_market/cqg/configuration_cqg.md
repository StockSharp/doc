# CQG 配置

有两种方法可以使用 **CQG** 连接器：

1. **CQG COM**，通过本地 **CQG 集成客户端** 进行连接，该客户端直接安装在将用于连接的计算机上。**CQG 集成客户端** 可以从[开发者网站](https://www.cqg.com/products/cqg-integrated-client)下载。要连接到 **CQG 集成客户端**，您必须指定 **登录名** 和 **密码**。

2. **CQG Continuum**，直接连接到服务器，要连接你必须指定**登录名**、**密码**和**服务器地址**。

**登录名**、**密码**和**服务器地址**由经纪商提供。要获取 API 访问权限，建议联系经纪商。
