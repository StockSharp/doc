# SSI

**SSI** 将 StockSharp 连接到面向越南 HOSE、HNX 和 UPCOM 市场的 SSI FastConnect API v3。

## 主要功能

- 已根据源代码核实的功能：实时 Level 1 行情、订单簿和成交数据、K 线与历史请求，以及股票和期货的资产组合与订单操作。
- 服务商特有的传输、会话和数据格式均封装在标准 StockSharp API 之后。

## 适用场景

可用于监控越南市场品种、分析市场数据、请求历史数据，以及执行受支持的交易流程。

可用品种、历史深度、交易权限、请求限制和服务可用性由 SSI 及所连接的账户决定。
