# Saxo OpenAPI 图形化配置

在所有 StockSharp 产品中，请在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中配置连接。

- **访问令牌** - 属性 `AccessToken`。
- **刷新令牌** - 属性 `RefreshToken`。
- **客户端标识符** - 属性 `ClientId`。
- **客户端密钥** - 属性 `ClientSecret`。
- **重定向 URI** - 属性 `RedirectUri`。
- **账户密钥** - 属性 `AccountKey`。
- **环境** - 属性 `Environment`。默认值为 `Simulation`。
