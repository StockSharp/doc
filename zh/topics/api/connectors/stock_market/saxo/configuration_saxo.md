# Saxo OpenAPI 连接器配置

获取 Saxo OpenAPI 所需的凭据、服务器地址和账户标识符，然后指定以下连接器设置。

- **访问令牌** - 属性 `AccessToken`。
- **刷新令牌** - 属性 `RefreshToken`。
- **客户端标识符** - 属性 `ClientId`。
- **客户端密钥** - 属性 `ClientSecret`。
- **重定向 URI** - 属性 `RedirectUri`。
- **账户密钥** - 属性 `AccountKey`。
- **环境** - 属性 `Environment`。默认值为 `Simulation`。
