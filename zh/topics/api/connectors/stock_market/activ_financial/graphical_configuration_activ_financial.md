# ACTIV Financial 图形化配置

对于所有[S#](../../../../api.md) 产品，连接的图形化配置在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md) 上进行：

- `Login` - 账户登录名。
- `Password` - 账户密码。
- `Host` - ACTIV 网关主机。
- `DataSource` - 要使用的市场数据源。
- `NodePath` - ACTIV 网关节点路径。
- `GatewayDirectory` - ACTIV 网关安装目录的路径。
