# ACTIV Financial 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Login` - 账户登录名。
- `Password` - 账户密码。
- `Host` - ACTIV 网关主机。
- `DataSource` - 要使用的市场数据源。
- `NodePath` - ACTIV 网关节点路径。
- `GatewayDirectory` - ACTIV 网关安装目录的路径。
