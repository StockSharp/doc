# 图形化配置: Zerodha Kite Connect

在所有 StockSharp 产品中，均通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

- `ApiKey` - 身份验证凭据。
- `ApiSecret` - 身份验证凭据。
- `Token` - 身份验证凭据。
- `RequestToken` - 身份验证凭据。
- `DefaultProduct` - 连接器的运行模式或选项。 默认值: `ZerodhaProducts.Intraday`.
