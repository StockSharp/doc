# NinjaTrader 连接器配置

获取 NinjaTrader REST 和 WebSocket API 所需的凭据、服务器地址和账户标识符，然后指定以下连接器设置。

- **用户名** - 属性 `Login`。
- **密码** - 属性 `Password`。
- **客户端标识符** - 属性 `ClientId`。
- **密钥** - 属性 `Secret`。
- **应用程序标识符** - 属性 `AppId`。默认值为 `StockSharp`。
- **应用程序版本** - 属性 `AppVersion`。默认值为 `1.0`。
- **设备标识符** - 属性 `DeviceId`。
- **模拟模式** - 属性 `IsDemo`。
