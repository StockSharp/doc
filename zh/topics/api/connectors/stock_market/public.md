# Public.com

**Public.com** 将 **Public.com API** 集成到 StockSharp，用于获取市场数据和进行交易。

该连接器支持交易品种搜索、行情、历史 K 线、账户、余额和持仓、订单管理、用于订阅的 REST 轮询、多腿期权订单。

在为 Public.com 开发交易机器人之前，请先查看[连接器](../../connectors.md)部分中的链接。
