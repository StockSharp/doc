# RavenPack 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Token` - API 访问令牌。
- `Product` - 要请求的 RavenPack 产品。
- `DatasetId` - 要请求的数据集标识符。
- `Address` - REST API 地址。
- `FeedAddress` - 实时新闻数据流端点。
