# 图形化配置: SnapTrade

在所有 StockSharp 产品中，均通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

- `ClientId` - 账户或客户端标识符。
- `ConsumerKey` - 身份验证凭据。
- `UserId` - 账户或客户端标识符。
- `UserSecret` - 身份验证凭据。
- `AccountId` - 账户或客户端标识符。
- `PollingInterval` - 时间间隔。 默认值: `TimeSpan.FromMinutes(1)`.
