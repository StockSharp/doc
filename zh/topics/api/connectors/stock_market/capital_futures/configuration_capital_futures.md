# 连接器配置: Capital Futures

安装官方开发工具包，并指定其路径、身份验证凭据和其他连接参数。

- `SdkPath` - 本地文件或目录的路径。
- `Login` - 账户或客户端标识符。
- `Password` - 身份验证凭据。
- `Account` - 账户或客户端标识符。
- `Environment` - 连接器的运行模式或选项。 默认值: `CapitalFuturesEnvironments.Production`.
- `IsTradingEnabled` - 控制连接器行为的开关。 默认值: `true`.
- `LogPath` - 本地文件或目录的路径。
