# 图形化配置: Capital Futures

在所有 StockSharp 产品中，均通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

- `SdkPath` - 本地文件或目录的路径。
- `Login` - 账户或客户端标识符。
- `Password` - 身份验证凭据。
- `Account` - 账户或客户端标识符。
- `Environment` - 连接器的运行模式或选项。 默认值: `CapitalFuturesEnvironments.Production`.
- `IsTradingEnabled` - 控制连接器行为的开关。 默认值: `true`.
- `LogPath` - 本地文件或目录的路径。
