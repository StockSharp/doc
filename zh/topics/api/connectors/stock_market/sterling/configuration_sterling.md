# Sterling 配置

要使用 **Sterling** 连接器，您需要使用本地的 **Sterling Trader Pro** 终端，该终端直接安装在将用于连接的计算机上。要连接到 **Sterling Trader Pro**，您必须指定 **登录名** 和 **密码**。

![Sterling 登录](../../../../../images/sterling_login.png)

**Sterling Trader Pro、登录名、密码** 以及服务器地址由经纪商提供。建议联系经纪商以获取 API 访问权限。

> [!TIP]
> 为了让 Sterling API 正常工作，您需要以管理员身份运行 Visual Studio。
