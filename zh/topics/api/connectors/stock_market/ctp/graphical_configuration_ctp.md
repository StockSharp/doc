# CTP 图形化配置

在所有 StockSharp 产品中，请在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中配置连接。

- **用户名** - 属性 `Login`。
- **密码** - 属性 `Password`。
- **经纪商标识符** - 属性 `BrokerId`。
- **投资者标识符** - 属性 `InvestorId`。
- **市场数据地址** - 属性 `MarketDataAddress`。
- **交易服务器地址** - 属性 `TraderAddress`。
- **应用程序标识符** - 属性 `AppId`。
- **身份验证代码** - 属性 `AuthCode`。
- **产品信息** - 属性 `ProductInfo`。默认值为 `StockSharp`。
- **恢复模式** - 属性 `ResumeType`。默认值为 `Quick`。
- **生产模式** - 属性 `ProductionMode`。默认值为 `true`。
- **数据目录** - 属性 `DataPath`。
- **查询间隔** - 属性 `QueryInterval`。默认值为 `1 s`。
- **连接超时** - 属性 `ConnectionTimeout`。默认值为 `30 s`。
