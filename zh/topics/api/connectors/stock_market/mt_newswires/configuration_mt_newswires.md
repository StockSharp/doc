# MT Newswires 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Token` - API 访问令牌。
- `Address` - REST API 地址。
- `DataSource` - 要使用的市场数据源。
- `DatasetId` - 要请求的数据集标识符。
