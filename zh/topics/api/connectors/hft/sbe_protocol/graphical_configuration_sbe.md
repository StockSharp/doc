# SBE 图形化配置

在 StockSharp 产品中，通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置 SBE 连接。

- `Address` - SBE 服务器的 TCP 端点。
- `SenderCompId` - 客户端标识符。
- `TargetCompId` - 目标服务器标识符。
- `Password` - 身份验证凭据。
- `IsSupportNativeCandles` - 启用原生 K线订阅。
