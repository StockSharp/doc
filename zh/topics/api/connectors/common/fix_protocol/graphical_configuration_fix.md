# FIX 图形化配置

对于所有 [S#](../../../../api.md) 产品，连接的图形化配置都在 [连接设置窗口](../../../graphical_user_interface/connection_settings_window.md) 中进行：

![API GUI 设置 FIX](../../../../../images/api_gui_settings_fix.png)

- **地址** - 地址。
- **协议方言** - FIX 协议方言。
- **发送方** - 发送方标识符。
- **目标** - 接收方标识符。
- **登录名** - 登录名。
- **密码** - 密码。
- **投资组合** - 启动时请求所有投资组合。
- **交易品种** - 连接时请求所有交易品种。
- **编码** - 数据传输所用的编码。
- **重置序列号** - 是否重置序号计数器。
- **日期格式** - 日期格式。
- **日期和时间格式** - 日期和时间格式。
- **时间格式** - 时间格式。
- **接收超时** - 数据接收超时。
- **发送超时** - 数据发送超时。
- **未知交易** - 处理由第三方生成的未知执行回报。
- **协议** - 用于建立连接的 SSL 协议。
- **证书** - SSL 证书。
- **密码** - SSL 证书密码。
- **撤销检查** - 证书吊销检查。
- **检查远程证书** - 检查远程证书。
- **服务器名称** - 使用 SSL 连接的服务器名称。
- **重新连接设置** - 用于跟踪与交易系统连接状态的机制设置（[重新连接设置](../../reconnection_settings.md)）。
- **心跳间隔** - 向服务器通知连接仍然存活的间隔时间。默认值为 1 分钟。
- **统一交易板代码** - 统一交易品种的交易板代码。
