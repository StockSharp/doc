# 图形配置修复

对于所有 [S\#](../../../../api.md) 产品，连接的图形配置在 [连接设置窗口](../../../graphical_user_interface/connection_settings_window.md) 上进行：

![API GUI 设置 FIX](../../../../../images/api_gui_settings_fix.png)

- **方言** - 方言 FIX 协议。
- **登录** \- 登录。
- **密码** \- 密码。
- **名称** - 来源名称（用于在日志文件中区分）。
- **日志级别** - 日志级别。
- **最大恢复** - 最大恢复
- **最大恢复错误** - 最大恢复错误
- **最大增量错误顺序** - MaxIncrementalWrongOrder
- **最大恢复次数** - MaxRestoreCount
- **最大暂停** - 最大暂停
- **设置文件** - 设置文件
- **心跳** - 服务器检查间隔，用于跟踪连接是否仍然存活。默认情况下为1分钟。
- **重新连接设置** - 用于跟踪与交易系统设置连接的机制。([重新连接设置](../../reconnection_settings.md))
