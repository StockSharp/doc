# 图形化配置: Sierra Chart DTC

在所有 StockSharp 产品中，均通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

- `Address` - 服务地址。 默认值: `DefaultAddress`.
- `HistoryAddress` - 服务地址。 默认值: `DefaultHistoryAddress`.
- `Login` - 账户或客户端标识符。
- `Password` - 身份验证凭据。
- `TradeAccount` - 账户或客户端标识符。
- `MarketDataTransmissionInterval` - 时间间隔。
- `MarketDepthLevels` - 连接器的数值参数。 默认值: `20`.
- `SslProtocol` - 连接器的运行模式或选项。
- `HistorySslProtocol` - 连接器的运行模式或选项。
- `IsCertificateValidation` - 控制连接器行为的开关。 默认值: `true`.
- `TargetHost` - 服务地址。
