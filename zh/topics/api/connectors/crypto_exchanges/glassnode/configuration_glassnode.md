# Glassnode 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Token` - API 访问令牌。
- `ApiEndpoint` - REST API 端点。
- `PriceTimeFrame` - 请求价格 K线时使用的时间周期。
