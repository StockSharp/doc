# Ourbit 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Key` - API 密钥。
- `Secret` - API 密钥。
- `SpotRestEndpoint` - REST API 地址。
- `SpotWsEndpoint` - WebSocket 服务器地址。
- `FuturesRestEndpoint` - REST API 地址。
- `FuturesWsEndpoint` - WebSocket 服务器地址。
