# 图形化配置：CoinGlass

在所有 StockSharp 产品中，请通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

连接编辑器的基本部分包含：

- `Token`
- `RestEndpoint`
- `MarketType`
- `CandleMetric`
- `Exchange`
- `Symbol`

其余属性可在高级视图中设置，并在[连接器配置](configuration_coinglass.md)页面中说明。除非提供商分配了其他值，否则请保留预填的服务端点。
