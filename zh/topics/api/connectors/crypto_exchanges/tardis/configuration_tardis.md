# Tardis 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Token` - API 访问令牌。
- `Exchange` - 要请求数据的交易所代码。
- `ApiEndpoint` - REST API 端点。
- `MachineHttpEndpoint` - Tardis Machine 本地 HTTP 端点。
- `MachineSocketEndpoint` - Tardis Machine 本地 WebSocket 端点。
