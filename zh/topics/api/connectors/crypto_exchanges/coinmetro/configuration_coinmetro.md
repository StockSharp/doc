# 连接器配置：Coinmetro

连接 Coinmetro 前，请配置以下适配器属性。该列表已根据 [CoinmetroMessageAdapter](xref:StockSharp.Coinmetro.CoinmetroMessageAdapter) 的实现进行核对。

## 基本设置

连接编辑器会优先显示这些设置。

- `Token` (`SecureString`)
- `IsDemo` (`bool`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `DemoRestEndpoint` (`string`)
- `DemoWebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
