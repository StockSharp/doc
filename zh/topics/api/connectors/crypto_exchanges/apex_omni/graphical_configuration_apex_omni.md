# ApeX Omni 图形化配置

对于所有 [S#](../../../../api.md) 产品，连接的图形化配置都在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中完成：

- `Key` - API 密钥。
- `Secret` - API 密钥密码。
- `Passphrase` - API 口令。
- `Seeds` - 用于签署订单的 zkLink 种子。
- `Environment` - 连接环境：生产网络或测试网络。
- `RestEndpoint` - REST API 端点。
- `WebSocketEndpoint` - WebSocket API 端点。
- `MarketDepth` - 请求的订单簿档位数。
