# ApeX Omni 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Key` - API 密钥。
- `Secret` - API 密钥密码。
- `Passphrase` - API 口令。
- `Seeds` - 用于签署订单的 zkLink 种子。
- `Environment` - 连接环境：生产网络或测试网络。
- `RestEndpoint` - REST API 端点。
- `WebSocketEndpoint` - WebSocket API 端点。
- `MarketDepth` - 请求的订单簿档位数。
