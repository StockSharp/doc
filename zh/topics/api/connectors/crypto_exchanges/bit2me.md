# Bit2Me

**Bit2Me** 是用于 Bit2Me Pro 加密货币现货交易所的连接器。它通过 REST 和 WebSocket API 提供公开市场数据、历史 K 线、账户余额和交易操作。

在为该平台开发交易机器人之前，请先阅读[连接器](../../connectors.md)章节。
