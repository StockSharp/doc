# Coinhako 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Key` - API 密钥。
- `Secret` - API 密钥。
- `RestEndpoint` - REST API 地址。
- `CounterCurrencies` - 请求市场时使用的计价货币。
- `PollingInterval` - 两次服务轮询之间的间隔。
