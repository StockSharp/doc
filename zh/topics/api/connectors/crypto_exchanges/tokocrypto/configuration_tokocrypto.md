# 连接器配置：Tokocrypto

连接 Tokocrypto 前，请配置以下适配器属性。该列表已根据 [TokocryptoMessageAdapter](xref:StockSharp.Tokocrypto.TokocryptoMessageAdapter) 的实现进行核对。

## 基本设置

连接编辑器会优先显示这些设置。

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `AccountRestEndpoint` (`string`)
- `MarketDataRestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
