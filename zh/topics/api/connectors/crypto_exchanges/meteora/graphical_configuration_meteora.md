# Meteora DLMM 图形化配置

对于所有 [S#](../../../../api.md) 产品，连接的图形化配置都在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中完成：

- `Cluster` - 用于请求的区块链集群。
- `RpcEndpoint` - 区块链 RPC 端点。
- `StreamingEndpoint` - 用于实时事件的区块链 WebSocket 端点。
- `WalletAddress` - 用于查询余额和提交订单的公开区块链钱包地址。
- `PrivateKey` - 用于在本地签署交易的私钥。
