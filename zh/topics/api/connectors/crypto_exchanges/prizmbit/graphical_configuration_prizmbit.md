# 图形配置 PrizmBit

对于所有 [S\#](../../../../api.md) 产品，连接的图形配置在 [连接设置窗口](../../../graphical_user_interface/connection_settings_window.md) 中进行：

![API GUI 设置 PrizmBit](../../../../../images/api_gui_settings_prizmbit.png)

- **钥匙** - 钥匙。
- **秘密** \- 秘密。
- **心跳** - 服务器检查间隔，用于跟踪连接是否活跃。默认值为1分钟。
- **重新连接设置** - 用于跟踪与交易系统设置连接的机制。([重新连接设置](../../reconnection_settings.md))
