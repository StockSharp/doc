# Crypto.com 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Key` - API 密钥。
- `Secret` - API 密钥。
- `IsDemo` - 模拟环境模式。
- `RestEndpoint` - REST API 地址。
- `MarketWsEndpoint` - WebSocket 服务器地址。
- `UserWsEndpoint` - WebSocket 服务器地址。
