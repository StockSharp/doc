# Talos 图形化配置

对于所有 [S#](../../../../api.md) 产品，连接的图形化配置都在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中完成：

- `Address` - Talos 提供的 FIX 服务器地址和端口。
- `SenderCompId` - FIX 发送方标识符。
- `TargetCompId` - FIX 接收方标识符。
- `Login` - FIX 会话登录名。
- `Password` - FIX 会话密码。
- `ClientCode` - 用于账户路由的客户代码。
- `TargetHost` - TLS 证书中的主机名。
