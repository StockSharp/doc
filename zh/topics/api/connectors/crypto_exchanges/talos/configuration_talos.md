# Talos 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Address` - Talos 提供的 FIX 服务器地址和端口。
- `SenderCompId` - FIX 发送方标识符。
- `TargetCompId` - FIX 接收方标识符。
- `Login` - FIX 会话登录名。
- `Password` - FIX 会话密码。
- `ClientCode` - 用于账户路由的客户代码。
- `TargetHost` - TLS 证书中的主机名。
