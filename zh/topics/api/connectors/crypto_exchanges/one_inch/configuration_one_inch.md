# 1inch 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `ApiKey` - 用于访问服务的 API 密钥。
- `Chain` - 用于请求的区块链网络。
- `WalletAddress` - 用于查询余额和提交订单的公开区块链钱包地址。
- `PrivateKey` - 用于在本地签署交易的私钥。
- `ApiEndpoint` - 服务 API 端点。
- `RpcEndpoint` - 区块链 RPC 端点。
