# Zero Hash 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `ApiKey` - API 密钥。
- `Secret` - API 密钥密码。
- `Passphrase` - API 口令。
- `Account` - 账户标识符。
- `User` - 用户标识符。
- `ApiEndpoint` - REST API 端点。
