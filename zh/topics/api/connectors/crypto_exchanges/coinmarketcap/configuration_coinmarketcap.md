# CoinMarketCap 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `AccessMode` - CoinMarketCap 访问模式：无密钥或 API 密钥。
- `Token` - API 访问令牌。
- `ApiEndpoint` - REST API 端点。
- `SocketEndpoint` - WebSocket API 端点。
- `QuoteCurrency` - 用于表示市场价格的报价货币。
- `IsStreamingEnabled` - 启用 WebSocket 实时数据。
