# THORChain 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `WalletAddress` - 用于查询余额和提交订单的公开区块链钱包地址。
- `PrivateKey` - 用于在本地签署交易的私钥。
- `MidgardEndpoint` - THORChain Midgard API 端点。
- `ThornodeEndpoint` - THORChain Thornode REST API 端点。
