# GRVT 图形化配置

对于所有 [S#](../../../../api.md) 产品，连接的图形化配置都在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中完成：

- `Key` - 用于身份验证的 API 密钥。
- `Secret` - 用于身份验证的 API 密钥密码。
- `SubAccountId` - 交易子账户标识符。
- `Environment` - 服务环境：生产网络或测试网络。
- `EdgeEndpoint` - 身份验证 API 端点。
- `MarketDataEndpoint` - 市场数据 API 端点。
- `TradingEndpoint` - 交易 API 端点。
- `MarketWebSocketEndpoint` - 市场数据 WebSocket 端点。
- `TradingWebSocketEndpoint` - 交易 WebSocket 端点。
- `SnapshotInterval` - 市场数据快照间隔（毫秒）。
- `MarketDepth` - 请求的订单簿档位数。
