# Anchorage 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Environment` - 连接环境：生产、演示或测试。
- `ApiKey` - API 密钥。
- `SigningKey` - 用于签署 API 请求的私钥。
- `ApiEndpoint` - REST API 端点。
- `SocketEndpoint` - WebSocket API 端点。
