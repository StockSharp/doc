# Orderly Network 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `AccountId` - 交易账户标识符。
- `Secret` - API 密钥密码。
- `RestEndpoint` - REST API 端点。
- `PublicWebSocketEndpoint` - 公共市场数据 WebSocket 端点。
