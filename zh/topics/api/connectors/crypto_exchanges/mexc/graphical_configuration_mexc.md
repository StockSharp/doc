# MEXC 图形化配置

对于所有 [S#](../../../../api.md) 产品，连接的图形化配置在 [连接设置窗口](../../../graphical_user_interface/connection_settings_window.md) 中进行：

![API GUI 设置 MEXC](../../../../../images/api_gui_settings_mexc.png)

- **Key** - API key。
- **Secret** - API secret。
- **Demo** - 演示模式。
- **重连设置** - 与交易系统的重连机制参数 ([重连设置](../../reconnection_settings.md))。
