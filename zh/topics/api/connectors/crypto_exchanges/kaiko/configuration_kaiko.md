# Kaiko 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Token` - API 访问令牌。
- `Region` - Kaiko API 区域端点。
- `ReferenceEndpoint` - 参考数据 API 端点。
- `MarketEndpoint` - 历史市场数据 API 端点。
- `StreamEndpoint` - 实时市场数据端点。
- `IsStreamingEnabled` - 启用 WebSocket 实时数据。
