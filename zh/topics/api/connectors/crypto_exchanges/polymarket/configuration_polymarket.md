# Polymarket 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `ApiKey` - API 密钥。
- `ApiSecret` - API 密钥密码。
- `Passphrase` - API 口令。
- `SignerAddress` - 签署订单的地址。
- `FunderAddress` - 为交易账户提供资金的地址。
- `PrivateKey` - 用于在本地签署请求和交易的私钥。
- `SignatureType` - 订单使用的签名方案。
