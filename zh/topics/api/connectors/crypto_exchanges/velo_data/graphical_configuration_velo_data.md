# Velo Data 图形化配置

对于所有 [S#](../../../../api.md) 产品，连接的图形化配置都在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中完成：

- `Token` - API 访问令牌。
- `ApiEndpoint` - REST API 端点。
- `NewsEndpoint` - 新闻历史 API 端点。
- `WebSocketEndpoint` - WebSocket API 端点。
