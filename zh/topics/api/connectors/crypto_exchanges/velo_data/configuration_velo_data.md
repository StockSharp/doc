# Velo Data 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Token` - API 访问令牌。
- `ApiEndpoint` - REST API 端点。
- `NewsEndpoint` - 新闻历史 API 端点。
- `WebSocketEndpoint` - WebSocket API 端点。
