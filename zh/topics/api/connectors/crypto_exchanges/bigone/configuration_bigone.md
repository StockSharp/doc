# 连接器配置：BigONE

连接 BigONE 前，请配置以下适配器属性。该列表已根据 [BigOneMessageAdapter](xref:StockSharp.BigOne.BigOneMessageAdapter) 的实现进行核对。

## 基本设置

连接编辑器会优先显示这些设置。

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `SpotRestEndpoint` (`string`)
- `SpotWebSocketEndpoint` (`string`)
- `ContractRestEndpoint` (`string`)
- `ContractWebSocketEndpoint` (`string`)
- `ContractPrivateWebSocketEndpoint` (`string`)
