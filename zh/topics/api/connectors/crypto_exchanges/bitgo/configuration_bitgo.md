# BitGo 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Token` - API 访问令牌。
- `Account` - 账户标识符。
- `ApiEndpoint` - REST API 端点。
- `SocketEndpoint` - WebSocket API 端点。
