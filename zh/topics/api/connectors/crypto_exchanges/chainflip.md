# Chainflip

**Chainflip** 将 StockSharp 连接到 Chainflip 跨链流动性网络。适配器通过标准 StockSharp 消息模型提供受支持的市场数据和交易操作。

## 主要功能

- 已根据源代码核实的适配器功能：实时数据更新、Level 1 行情、成交数据、订单簿、资产组合与订单操作。
- 服务商特有的传输、会话和数据格式均封装在标准 StockSharp API 之后。

## 适用场景

可用于监控 Chainflip 流动性池、分析可执行行情和订单簿，以及执行适配器实现的跨链兑换流程。

可用资产与目标链、交易权限、请求限制和服务可用性由 Chainflip 及所连接的钱包决定。
