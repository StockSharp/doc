# VALR 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Key` - API 密钥。
- `Secret` - API 密钥。
- `SubAccountId` - 子账户标识符。
- `RestEndpoint` - REST API 地址。
- `TradeWebSocketEndpoint` - WebSocket 服务器地址。
- `AccountWebSocketEndpoint` - WebSocket 服务器地址。
