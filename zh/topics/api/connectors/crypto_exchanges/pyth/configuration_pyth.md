# Pyth 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Token` - API 访问令牌。
- `HistoryEndpoint` - 历史数据 API 端点。
- `RouterEndpoint` - 最新价格 REST API 端点。
- `WebSocketEndpoint1` - 实时数据主 WebSocket 端点。
- `WebSocketEndpoint2` - 实时数据辅助 WebSocket 端点。
- `WebSocketEndpoint3` - 实时数据第三 WebSocket 端点。
- `Channel` - Pyth 数据频道。
