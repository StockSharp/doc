# XRPL DEX

**XRPL DEX** 将 StockSharp 连接到 XRP Ledger 内置的去中心化交易所。适配器通过标准 StockSharp 消息模型提供受支持的市场数据和交易操作。

## 主要功能

- 已根据源代码核实的适配器功能：实时数据更新、Level 1 行情、成交数据、订单簿、K 线数据、历史数据请求、资产组合与订单操作。
- 服务商特有的传输、会话和数据格式均封装在标准 StockSharp API 之后。

## 适用场景

可用于监控 XRPL 市场、分析行情、成交、订单簿和 K 线、请求历史数据，以及提交受支持的报价。

可用市场、数据深度、交易权限、请求限制和服务可用性由 XRP Ledger 接入端点及所连接的账户决定。
