# Aevo 图形化配置

对于所有 [S#](../../../../api.md) 产品，连接的图形化配置都在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中完成：

- `Environment` - 连接环境：生产网络或测试网络。
- `ApiKey` - API 密钥。
- `ApiSecret` - API 密钥密码。
- `WalletAddress` - 用于账户操作的公开区块链钱包地址。
- `SigningKey` - 用于签署交易请求的私钥。
