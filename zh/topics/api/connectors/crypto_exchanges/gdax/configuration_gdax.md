# GDAX 配置

要使用连接器，需要在交易所的个人账户中生成**密钥（API Key）**和**Secret**，并在连接设置中指定它们。

> [!TIP]
> 值得注意的是，**Key** 和 **Secret** 并不是 **Login** 和 **Password**。**Key** 和 **Secret** 是在您的个人账户中单独生成的。使用连接器时，您不需要 **Login** 和 **Password**，也不需要在任何地方指定它们。
