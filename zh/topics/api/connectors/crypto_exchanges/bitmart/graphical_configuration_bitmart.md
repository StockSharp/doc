# Bitmart 图形化配置

对于所有 [S#](../../../../api.md) 产品，连接的图形化配置都在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中完成：

![API GUI 设置 Bitmart](../../../../../images/api_gui_settings_bitmart.png)

- **访问密钥** - API 密钥。
- **密钥** - API 私钥。
- **交易板** - 要连接的板块（现货、期货）。
- **口令** - 管理员密码。
