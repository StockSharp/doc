# 图形配置 Bitmart

对于所有[S\#](../../../../api.md) 产品，连接的图形配置在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md) 上进行：

![API GUI 设置 Bitmart](../../../../../images/api_gui_settings_bitmart.png)

- **钥匙** - 钥匙。
- **秘密** \- 秘密。
- **板块** - 连接的部分（现货，期货）。
- **口令** - 管理员密码。
