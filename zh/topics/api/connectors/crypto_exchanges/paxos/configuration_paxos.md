# Paxos 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Environment` - 连接环境：生产、演示或测试。
- `ClientId` - OAuth 客户端标识符。
- `ClientSecret` - OAuth 客户端密钥。
- `ApiEndpoint` - REST API 端点。
- `OAuthEndpoint` - OAuth 令牌端点。
- `SocketEndpoint` - WebSocket API 端点。
