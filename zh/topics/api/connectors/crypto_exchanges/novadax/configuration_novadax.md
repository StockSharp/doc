# 连接器配置：NovaDAX

连接 NovaDAX 前，请配置以下适配器属性。该列表已根据 [NovaDaxMessageAdapter](xref:StockSharp.NovaDax.NovaDaxMessageAdapter) 的实现进行核对。

## 基本设置

连接编辑器会优先显示这些设置。

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `AccountId` (`string`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `EngineIoVersion` (`int`)
