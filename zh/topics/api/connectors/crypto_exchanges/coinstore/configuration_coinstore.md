# 连接器配置：Coinstore

连接 Coinstore 前，请配置以下适配器属性。该列表已根据 [CoinstoreMessageAdapter](xref:StockSharp.Coinstore.CoinstoreMessageAdapter) 的实现进行核对。

## 基本设置

连接编辑器会优先显示这些设置。

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
