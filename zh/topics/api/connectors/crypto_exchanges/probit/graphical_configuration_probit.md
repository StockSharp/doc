# ProBit Global 图形化配置

对于所有 [S#](../../../../api.md) 产品，连接的图形化配置均在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中完成：

- `Key` - OAuth 客户端标识符。
- `Secret` - OAuth 客户端密钥。
- `RestEndpoint` - REST API 地址。
- `AuthEndpoint` - OAuth 令牌端点地址。
- `WebSocketEndpoint` - WebSocket 服务器地址。

凭据对于公共市场数据是可选的，但对于交易和私有账户数据是必需的。
