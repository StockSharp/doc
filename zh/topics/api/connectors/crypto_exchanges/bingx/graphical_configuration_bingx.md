# BingX 的图形配置

对于所有 [S#](../../../../api.md) 产品，连接的图形配置在 [连接设置窗口](../../../graphical_user_interface/connection_settings_window.md) 中进行：

![API GUI 设置 BingX](../../../../../images/api_gui_settings_bingx.png)

- **关键** - 钥匙。
- **秘密** - 秘密。
- **演示** - 演示模式。
- **重连设置** - 与交易系统的重连机制参数 ([重连设置](../../reconnection_settings.md))。
