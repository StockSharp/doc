# Fireblocks 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Environment` - 连接环境：生产网络或测试网络。
- `ApiKey` - API 密钥。
- `PrivateKey` - 用于在本地签署请求和交易的私钥。
- `ApiEndpoint` - 服务 API 端点。
