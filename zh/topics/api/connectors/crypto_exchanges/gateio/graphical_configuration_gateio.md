# Gate.io 图形化配置

对于所有 [S#](../../../../api.md) 产品，连接的图形化配置都在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中完成：

![API GUI 设置 Gate.io](../../../../../images/api_gui_settings_gateio.png)

- **Key** - API key。
- **Secret** - API secret。
- **部分** - 交易部分。
- **演示** - 连接到模拟交易。
