# Zoomex 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Key` - API 密钥。
- `Secret` - API 密钥。
- `Sections` - API 请求启用的市场分区。
- `AccountType` - API 请求使用的账户类型。
- `RestEndpoint` - REST API 地址。
- `WebSocketEndpoint` - WebSocket 服务器地址。
