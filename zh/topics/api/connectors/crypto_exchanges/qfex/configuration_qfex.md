# QFEX 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `RestEndpoint` - REST API 端点。
- `Key` - API 密钥。
- `Secret` - API 密钥密码。
- `AccountId` - 交易账户标识符。
