# WOO X 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Key` - API 密钥。
- `Secret` - API 密钥。
- `ApplicationId` - 已注册应用程序的标识符。
- `RestEndpoint` - REST API 地址。
- `HistoricalRestEndpoint` - REST API 地址。
- `PublicWsEndpoint` - WebSocket 服务器地址。
- `PrivateWsEndpoint` - WebSocket 服务器地址。
