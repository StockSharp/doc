# Pacifica 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `RestEndpoint` - REST API 端点。
- `WalletAddress` - 用于账户操作的公开区块链钱包地址。
- `PrivateKey` - 用于在本地签署请求和交易的私钥。
