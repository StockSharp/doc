# Chainlink Data Streams 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Key` - API 密钥。
- `Secret` - API 密钥密码。
- `RestEndpoint` - REST API 端点。
- `WebSocketEndpoint` - WebSocket API 端点。
