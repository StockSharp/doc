# Bullish 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Key` - API 密钥。
- `Secret` - API 密钥。
- `TradingAccountId` - 交易账户标识符。
- `RateLimitToken` - 用于标识 API 请求限制的 Bullish 令牌。
- `RestEndpoint` - REST API 地址。
- `WsEndpoint` - WebSocket 服务器地址。
