# Gemini 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Key` - API 密钥。
- `Secret` - API 密钥。
- `Account` - 交易账户标识符。
- `IsCancelOnDisconnect` - 连接中断时是否撤销活动订单。
- `RestEndpoint` - REST API 地址。
- `WebSocketEndpoint` - WebSocket 服务器地址。
