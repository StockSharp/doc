# 连接器配置：CoinTR

连接 CoinTR 前，请配置以下适配器属性。该列表已根据 [CoinTRMessageAdapter](xref:StockSharp.CoinTR.CoinTRMessageAdapter) 的实现进行核对。

## 基本设置

连接编辑器会优先显示这些设置。

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `Passphrase` (`SecureString`)
- `RestEndpoint` (`string`)
- `PublicWebSocketEndpoint` (`string`)
- `PrivateWebSocketEndpoint` (`string`)
