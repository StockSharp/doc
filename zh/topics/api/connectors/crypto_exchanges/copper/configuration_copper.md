# Copper 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Environment` - 连接环境：生产、演示或测试。
- `ApiKey` - API 密钥。
- `ApiSecret` - API 密钥密码。
- `ApiEndpoint` - REST API 端点。
