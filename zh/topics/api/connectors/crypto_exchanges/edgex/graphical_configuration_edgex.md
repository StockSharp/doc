# edgeX 图形化配置

对于所有 [S#](../../../../api.md) 产品，图形化配置在 [连接设置窗口](../../../graphical_user_interface/connection_settings_window.md) 中进行。

主要字段：

- **访问密钥** - API 密钥。
- **密钥** - API 私钥。
- **清算账户** - 清算账户的价值。
- **口令** - 口令值。
- **交易分区** - 交易部分 (`现货` 或 `衍生品`)。
- **启用现货** - 启用现货部分。
- **模拟模式** - 演示环境模式。
- **现货 REST / 衍生品 REST** - REST 端点。
- **现货 WS / 衍生品公共 WS / 衍生品私有 WS** - WebSocket 端点。
