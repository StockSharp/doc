# Uniswap 图形化配置

对于所有 [S#](../../../../api.md) 产品，连接的图形化配置都在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中完成：

- `Token` - API 访问令牌。
- `GraphApiKey` - The Graph API 密钥。
- `WalletAddress` - 区块链钱包地址。
- `PrivateKey` - 用于签署交易的私钥。
- `Chain` - 请求所使用的区块链网络。
- `RouterVersion` - 去中心化交易所路由器版本。
- `RpcEndpoint` - 区块链 RPC 端点。
- `TradingEndpoint` - 交易 API 端点。
