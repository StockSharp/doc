# 图形配置 Hyperliquid

对于所有 [S#](../../../../api.md) 产品，图形配置在 [连接设置窗口](../../../graphical_user_interface/connection_settings_window.md) 中进行。

主要字段：

- **钱包地址** - 钱包地址 (`0x...`)。
- **私钥** - 用于签署操作的私钥。
- **保险库地址** - 可选的保险库或子账户地址。
- **过期时间** - 可选的签名过期时间戳。
- **部分** - 交易部分 (`Spot` 或 `Derivatives`)。
- **测试网** - 测试网端点。
- **信息端点 / 交易所端点 / WS端点** - 端点网址。
- **市场滑点** - 市价单的默认滑点。
