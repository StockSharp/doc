# 连接器配置：Quidax

连接 Quidax 前，请配置以下适配器属性。该列表已根据 [QuidaxMessageAdapter](xref:StockSharp.Quidax.QuidaxMessageAdapter) 的实现进行核对。

## 基本设置

连接编辑器会优先显示这些设置。

- `Token` (`SecureString`)
- `UserId` (`string`)
- `RestEndpoint` (`string`)
- `PollingInterval` (`TimeSpan`)
