# FalconX 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `ApiKey` - API 密钥。
- `Secret` - API 密钥密码。
- `Passphrase` - API 口令。
- `ApiEndpoint` - 服务 API 端点。
- `PriceSocketEndpoint` - FalconX 价格 WebSocket 端点。
- `OrderSocketEndpoint` - FalconX 订单 WebSocket 端点。
