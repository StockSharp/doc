# PancakeSwap 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `GraphApiKey` - The Graph API 密钥。
- `WalletAddress` - 区块链钱包地址。
- `PrivateKey` - 用于签署交易的私钥。
- `Chain` - 请求所使用的区块链网络。
- `RpcEndpoint` - 区块链 RPC 端点。
