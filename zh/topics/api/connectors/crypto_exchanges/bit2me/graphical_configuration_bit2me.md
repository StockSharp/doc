# Bit2Me 图形化配置

所有 [S#](../../../../api.md) 产品都通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)进行图形化配置：

- `Key` — 用于私有操作的 Bit2Me API 密钥。
- `Secret` — Bit2Me API Secret。
- `RestEndpoint` — REST API 地址。
- `WebSocketEndpoint` — WebSocket 地址。

仅使用公开市场数据时，将 `Key` 和 `Secret` 留空。交易和账户数据需要同时配置这两个值。
