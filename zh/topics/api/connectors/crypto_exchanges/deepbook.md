# DeepBook

**DeepBook** 将 StockSharp 连接到 DeepBook 去中心化协议。适配器通过标准 StockSharp 消息模型提供受支持的市场数据和交易操作。

## 主要功能

- 已根据源代码核实的适配器功能：实时数据更新、Level 1 行情、Level 2 订单簿、成交数据、资产组合与订单操作。
- 服务商特有的传输、会话和数据格式均封装在标准 StockSharp API 之后。

## 适用场景

适用于去中心化市场监控、报价分析以及协议适配器实现的交易流程。

可用交易品种、数据深度、交易权限、请求限制和服务可用性由 DeepBook、API 套餐及所连接账户的权限决定。
