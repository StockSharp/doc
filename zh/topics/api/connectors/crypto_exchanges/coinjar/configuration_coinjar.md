# CoinJar 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Token` - API 访问令牌。
- `TradingEndpoint` - 交易 API 端点。
- `DataEndpoint` - 市场数据 API 端点。
- `WebSocketEndpoint` - WebSocket 服务器地址。
