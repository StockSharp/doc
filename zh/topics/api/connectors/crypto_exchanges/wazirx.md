# WazirX

**WazirX** 将 StockSharp 连接到 WazirX 加密货币平台。适配器通过标准 StockSharp 消息模型提供服务商 API。

## 主要功能

- 已根据源代码核实的适配器功能：实时数据更新、Level 1 行情、Level 2 订单簿、成交数据、K 线数据、历史数据请求、资产组合与订单操作。
- 服务商特有的传输、会话和数据格式均封装在标准 StockSharp API 之后。

## 适用场景

适用于交易机器人、终端、数据采集器、订单管理服务和加密货币市场监控。

可用交易品种、数据深度、交易权限、请求限制和服务可用性由 WazirX、API 套餐及所连接账户的权限决定。
