# Pionex 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Key` - API 密钥。
- `Secret` - API 密钥。
- `RestEndpoint` - REST API 地址。
- `PublicWsEndpoint` - WebSocket 服务器地址。
- `SpotPrivateWsEndpoint` - WebSocket 服务器地址。
- `FuturesPrivateWsEndpoint` - WebSocket 服务器地址。
