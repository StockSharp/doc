# ByBit 图形化配置

对于所有 [S#](../../../../api.md) 产品，连接的图形化配置都在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中完成：

![API GUI 设置 ByBit](../../../../../images/api_gui_settings_bybit.png)

- **访问密钥** - API 密钥。
- **密钥** - API 私钥。
- **交易分区** - 交易板块。
- **模拟模式** - 连接到模拟交易。
