# Reya 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `WalletAddress` - 用于账户操作的公开区块链钱包地址。
- `AccountId` - 交易账户标识符。
- `PrivateKey` - 用于在本地签署请求和交易的私钥。
- `RestEndpoint` - REST API 端点。
- `WebSocketEndpoint` - WebSocket API 端点。
