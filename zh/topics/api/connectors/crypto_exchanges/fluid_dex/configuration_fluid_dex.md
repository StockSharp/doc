# Fluid DEX 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Chain` - 用于请求的区块链网络。
- `WalletAddress` - 用于查询余额和提交订单的公开区块链钱包地址。
- `PrivateKey` - 用于在本地签署交易的私钥。
- `RpcEndpoint` - 区块链 RPC 端点。
- `WebSocketEndpoint` - 区块链 WebSocket 端点。
