# 图形配置调光器

对于所有 [S#](../../../../api.md) 产品，图形配置在 [连接设置窗口](../../../graphical_user_interface/connection_settings_window.md) 中进行。

主要字段：

- **密钥** - API 密钥。
- **密钥** - API 密钥。
- **账户索引** - 账户索引。
- **API 密钥索引** - API 密钥索引。
- **部分** - 交易部分 (`Spot` 或 `Derivatives`)。
- **演示** - 演示环境模式。
- **现货 REST / 衍生品 REST** - REST 端点。
- **现货 WS / 衍生品 WS** - websocket 端点。
- **WS 只读模式** - websocket 只读模式标志。
