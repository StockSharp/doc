# 配置轻器

要使用连接器，请在交易所账户中生成 **API 密钥** 和 **Secret**，并在连接设置中指定它们。

主要设置：

- **密钥** 和 **秘密**。
- **账户索引** 和 **API 密钥索引**。
- **部分**：`Spot` 或 `Derivatives`。
- **演示** 模式。
- **现货 REST / 衍生品 REST** 端点。
- **现货 WS / 衍生品 WS** 端点。
- **WS 只读模式**。
