# 连接器配置：BitoPro

连接 BitoPro 前，请配置以下适配器属性。该列表已根据 [BitoProMessageAdapter](xref:StockSharp.BitoPro.BitoProMessageAdapter) 的实现进行核对。

## 基本设置

连接编辑器会优先显示这些设置。

- `Email` (`string`)
- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
