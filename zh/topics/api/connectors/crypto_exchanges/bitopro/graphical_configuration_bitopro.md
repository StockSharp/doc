# 图形化配置：BitoPro

在所有 StockSharp 产品中，请通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

连接编辑器的基本部分包含：

- `Email`
- `Key`
- `Secret`
- `RestEndpoint`
- `WebSocketEndpoint`

适配器专用属性已全部列在上方。除非服务商指定了其他值，否则请保留预设地址。
