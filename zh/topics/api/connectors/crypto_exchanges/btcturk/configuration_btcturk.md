# 连接器配置：BtcTurk

连接 BtcTurk 前，请配置以下适配器属性。该列表已根据 [BtcTurkMessageAdapter](xref:StockSharp.BtcTurk.BtcTurkMessageAdapter) 的实现进行核对。

## 基本设置

连接编辑器会优先显示这些设置。

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `GraphEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
