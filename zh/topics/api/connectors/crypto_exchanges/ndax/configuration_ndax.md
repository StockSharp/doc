# NDAX 配置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Key` - API 密钥。
- `Secret` - API 密钥。
- `UserId` - 服务分配的用户标识符。
- `AccountId` - 服务分配的账户标识符。
- `OmsId` - NDAX 订单管理系统标识符。
- `RestEndpoint` - REST API 地址。
- `WebSocketEndpoint` - WebSocket 服务器地址。
