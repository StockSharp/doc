# 图形化配置：Deriv

在所有 StockSharp 产品中，请通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

输入令牌和应用程序标识符。模拟账户请启用 `IsDemo`。当令牌在所选模式下仅持有一个活跃账户时，`AccountId` 可以留空。除非 Deriv 分配了其他端点，否则请保留默认的 REST 和 WebSocket 地址。
