# 图形化配置：StocksTrader

在所有 StockSharp 产品中，请通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

输入网页终端签发的令牌。模拟账户请启用 `IsDemo`。当令牌在所选模式下仅持有一个账户时，`AccountId` 可以留空。除非 StocksTrader 分配了其他端点，否则请保留默认地址；并根据所需的更新频率调整 `PollingInterval`。
