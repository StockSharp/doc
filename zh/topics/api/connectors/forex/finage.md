# Finage

**Finage** 将 StockSharp 连接到 Finage Forex REST 与 WebSocket API。

## 主要功能

- 已根据源代码核实的功能：品种搜索、实时 Level 1 行情和历史 K 线。该适配器仅提供市场数据，不支持交易操作。
- 服务商特有的传输、会话和数据格式均封装在标准 StockSharp API 之后。

## 适用场景

可用于查找货币对、监控实时行情，并下载外汇 K 线历史数据。

交易对覆盖、实时权限、历史深度、请求限制和可用性取决于 Finage 订阅方案。
