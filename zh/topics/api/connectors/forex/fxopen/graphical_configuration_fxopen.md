# 图形化配置：FXOpen TickTrader

在所有 StockSharp 产品中，请通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

输入 Web API 令牌 ID、密钥和密钥密码。模拟账户请启用 `IsDemo`。仅当账户策略要求双重身份验证时填写 `OneTimePassword`。除非 FXOpen 分配了其他端点，否则请保留默认的 REST、Feed WebSocket 和 Trade WebSocket 地址。
