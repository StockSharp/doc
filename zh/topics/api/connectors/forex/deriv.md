# Deriv

**Deriv** 将 StockSharp 连接到官方 Deriv Options REST 和 WebSocket API。

该连接器支持活跃交易品种搜索、Level 1、逐笔成交历史、逐笔成交实时推送，以及历史与实时时间框架 K线。交易功能涵盖合约报价、买入、提前卖出或取消、合约实时更新、余额、投资组合、未平仓合约和交易流水推送。

市场数据无需凭据即可访问。若要在模拟或实盘账户上进行身份验证，请创建个人访问令牌或 OAuth 令牌以及应用程序 ID。
