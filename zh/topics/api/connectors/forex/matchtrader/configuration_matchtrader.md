# Match-Trader 连接器设置

请在连接器设置中填写服务提供的连接参数。

## 连接参数

- `Address` - REST API 地址。
- `Login` - 账户登录名。
- `Password` - 账户密码。
- `BrokerId` - 经纪商标识符。
- `AccountId` - 服务分配的账户标识符。
