# TraderMade

**TraderMade** 将 StockSharp 连接到面向外汇和受支持加密货币对的 TraderMade REST 与 WebSocket API。

## 主要功能

- 已根据源代码核实的功能：实时 Level 1 行情、可选 TraderLadder 订单簿、品种搜索和历史 K 线。该适配器仅提供市场数据。
- 服务商特有的传输、会话和数据格式均封装在标准 StockSharp API 之后。

## 适用场景

可用于实时监控外汇、按需分析深度，并下载历史 K 线。

交易对、TraderLadder 权限、周末数据、请求限制和可用性取决于 TraderMade 订阅方案。
