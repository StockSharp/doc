# MetaApi

**MetaApi** 将 StockSharp 连接到面向 MetaTrader 4 和 MetaTrader 5 账户的 MetaApi 云端 REST 和流式 API。

该连接器支持交易品种规格、Level 1、逐笔成交、市场深度、K线，以及历史逐笔成交和 K线。交易功能涵盖市价单、限价单和止损单、订单修改与撤销、平仓，以及同步的投资组合、持仓、订单和成交。

连接之前，请在 MetaApi 中部署交易账户并创建 API 令牌。数据流会自动重连，终端状态会重新同步，订阅也会自动恢复。
