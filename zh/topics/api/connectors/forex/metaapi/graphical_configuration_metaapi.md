# 图形化配置：MetaApi

在所有 StockSharp 产品中，请通过[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)配置连接。

输入令牌和已部署账户的标识符。仅当使用账户范围的令牌时才填写 `Region`。除非 MetaApi 分配了其他域名，否则请保留默认域名；对于历史较长的账户，请提高 `SynchronizationTimeout`。
