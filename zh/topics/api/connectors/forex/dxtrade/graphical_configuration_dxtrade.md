# DXtrade 图形化配置

对于所有[S#](../../../../api.md) 产品，连接的图形化配置在[连接设置窗口](../../../graphical_user_interface/connection_settings_window.md)中进行：

![API GUI 设置 DXtrade](../../../../../images/api_gui_settings_dxtrade.png)

- **访问密钥** - API 密钥。
- **密钥** - API 私钥。
- **模拟模式** - 连接到模拟交易。
