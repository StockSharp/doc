# Dukascopy JForex

**Dukascopy JForex** 将 StockSharp 连接到官方 **JForex SDK**。

该连接器支持交易品种搜索、市场数据、投资组合信息和订单操作。

在开发交易机器人之前，请先阅读[连接器](../../connectors.md)部分的资料。
