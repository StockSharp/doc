# FXOpen TickTrader

**FXOpen TickTrader** 将 StockSharp 连接到官方 TickTrader Web API。

该连接器支持交易品种搜索、Level 1、市场深度、历史与实时 K线、投资组合、持仓、订单和成交。市场数据通过 Feed WebSocket 传输，账户和成交更新通过 Trade WebSocket 传输。

使用实时订阅和交易功能之前，请在 FXOpen 创建 Web API 令牌。公共 REST 数据无需凭据即可访问。
