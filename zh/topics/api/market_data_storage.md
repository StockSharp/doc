# 市场数据存储

[S\#](../api.md) 提供数据存储和加载的功能。在某些情况下，可能需要进行数据存储：

1. 在交易策略运行过程中，当有必要保存状态（订单、仓位、设置等）时；
2. 从交易终端保存市场数据以进行实时算法测试；
3. 用于分析和数据挖掘的数据积累。

[S#](../api.md) 阐明了由于高级访问权限而实现的存储机制以及技术细节隐藏（更多详情请参见 [API](market_data_storage/api.md)）。同时，它也非常多功能，可以扩展支持的存储类型。
