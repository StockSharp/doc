# 交易事务

要导入自有交易事务，请在应用程序主菜单中选择 **Import \=\> Own Transactions**。

![hydra import executions](../../../images/hydra_import_executions.png)

## 自有交易事务导入过程

1. 配置 **CSV Import Settings**。

   请参阅[K线](candles.md)导入说明。
2. 配置 [S#](../../api.md) 字段的导入参数。

   请参阅[K线](candles.md)导入说明。
3. 要预览数据，请单击 **预览** 按钮。
4. 单击 **Import** 按钮。
