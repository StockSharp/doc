# 任务

实用工具是在指定时间重复执行的操作。

要查看实用工具列表，请在左侧面板中选择 **Tools**。实用工具的操作方式与数据源相同：可以添加、删除、编辑、启用或禁用。要添加实用工具，请在 **Common** 选项卡中选择 **Add \=\> Tools**。随后会出现相应窗口，可以在其中选择所需的 **Tool**。

![hydra tasks](../../images/hydra_tasks.png)

目前，[Hydra](../hydra.md) 中提供四类任务：

- [自动导入](tasks/import_auto.md) — 从 CSV 格式导入数据。
- [转换器](tasks/converter.md) — 将交易所数据转换为逐笔成交、K线或订单簿。
- [自动导出](tasks/export_auto.md) — 将K线导出为不同格式。
- [备份](misc/backup.md) — 将数据备份到云服务。
