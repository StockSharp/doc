# 编辑交易品种

要编辑交易品种（例如，创建交易品种时未填写全部必需数据），请双击该交易品种，或单击 ![hydra edit](../../../images/hydra_edit.png) 按钮，打开用于进行必要修改的窗口：

进入 **交易品种** 窗口。

![hydra security edit 00](../../../images/hydra_security_edit_00.png)

随后将打开编辑窗口。

![hydra security edit](../../../images/hydra_security_edit.png)

如有需要，还可以批量编辑一组交易品种。选择一组交易品种，然后单击 ![hydra edit](../../../images/hydra_edit.png) 按钮。

![hydra securities edit 00](../../../images/hydra_securities_edit_00.png)

根据需要编辑该组交易品种。

![hydra securities edit](../../../images/hydra_securities_edit.png)

如果所有选中交易品种的某个字段具有相同值，界面将显示该值；如果值不同，该字段将留空。例如，两个交易品种的价格步长都为 1，但其中一个的手数为 10，另一个为 100，则价格步长字段会显示 1，而数量步长字段会留空。
