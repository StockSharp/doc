# 分析

**Analytics** 功能为用户提供市场数据分析工具。通过可插拔的 C#、F# 和 Python [脚本](analytics/running_a_script.md)，可以深入分析价格数据、成交量及其他市场指标。

> [!Video https://www.youtube.com/embed/wp_l0VBfY2o]

## 主要功能

- **历史数据分析**：Analytics 功能支持加载、查看和分析不同时间段的历史交易数据。

- **数据可视化**：Hydra 提供多种数据可视化工具，包括图形和图表，可用于分析趋势和识别模式。

- **金融指标计算**：程序可以计算移动平均线、RSI、MACD 等多种金融指标，从而支持全面的技术分析。
