# 数据源

[Hydra](../hydra.md) 可以连接多种数据源。除接收历史数据外，程序还可以从经纪商实时接收市场数据。用户通过系统提供的连接器连接这些数据源。

系统提供免费连接器；用户也可以购买付费连接器，以便从收费数据源接收市场数据。

目前，[Hydra](../hydra.md) 支持以下数据源：
