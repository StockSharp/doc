# 自动导出

该任务用于将交易所数据导出为 Excel、xml、sql、bin、Json 或 txt 等格式。

![Hydra 导出任务](../../../images/hydra_tasks_export.png)

**数据库**

- **连接** — 数据库连接，用于通过 SQL 导出。
- **数据包** — 传输数据包的大小，默认值为 50 个元素，用于通过 SQL 导出。
- **唯一性** — 检查数据库中数据的唯一性。该选项会影响性能，默认启用，用于通过 SQL 导出。

> [!TIP]
> 使用 SQL 导出时，需要设置连接字符串参数。

**新连接字符串**

![自动导出 截图](../../../images/hydra_tasks_connstring.png)

- **提供程序** — 数据库提供程序设置。
- **服务器** — 服务器地址或数据库路径。
- **数据库** — 数据库名称。SQLite 不使用此参数。
- **登录名** — 访问数据库的登录名。匿名访问不使用此参数。
- **密码** — 访问数据库的密码。匿名访问不使用此参数。
- **Windows** — 使用当前 Windows 账户连接数据库。
- **连接** — 完整的连接字符串。

> [!TIP]
> 可以使用 **检查** 按钮检查数据库连接。

**常规**

- **标题** — 任务标题。
- **工作时间** — 配置交易板的工作时间表。![Hydra 备份任务](../../../images/hydra_tasks_backup_desk.png)
- **操作间隔** — 任务的运行间隔。
- **数据目录** — 用于接收待转换数据的数据目录。
- **格式** — 转换后的数据格式：BIN\/CSV。
- **最大错误数** — 任务停止前允许出现的最大错误数。默认值为 0，表示忽略错误数量。
- **依赖任务** — 启动当前任务前必须完成的任务。

**CSV**

- **模板** — 各种导出数据类型使用的模板。
- **标题** — 文件第一行中的标题。如果传入空字符串，则不会向文件添加标题。
- **名称格式** — 导出文件名的记录格式。

**导出（自动）**

- **类型** — 导出类型（格式）。
- **开始日期** — 开始导出数据的日期。
- **时间偏移** — 以天为单位的时间偏移。
- **导出目录** — 数据导出目录。
- **格式** — 数据格式。
- **拆分** — 拆分类型。

**日志**

- **标识符** — 标识符。
- **日志级别** — 日志记录级别。

下面以自动导出为例说明操作过程：

1. 选择交易品种。
2. 配置需要导出的市场数据。![Hydra 导出任务 00](../../../images/hydra_tasks_export_00.png)
3. 设置导出时间范围。如果已经配置实时下载市场数据，可以不指定结束日期。在这种情况下，数据会按照运行间隔（数据更新间隔）实时导出。![Hydra 导出任务 01](../../../images/hydra_tasks_export_01.png)
4. 配置目录、运行间隔、数据类型和数据格式。
5. 启动导出。![Hydra 导出任务 02](../../../images/hydra_tasks_export_02.png)
