# Service panels

This section collects the panels that do not show market data but configure how the application works: references, storage and import settings, licenses, accounts and subscriptions.

- Commission rules \- [CommissionPanel](xref:StockSharp.Xaml.CommissionPanel).
- Import settings \- [ImportSettingsPanel](xref:StockSharp.Xaml.ImportSettingsPanel).
- Licenses \- [LicensePanel](xref:StockSharp.Xaml.LicensePanel).
- Security lookup \- [SecurityLookupPanel](xref:StockSharp.Xaml.SecurityLookupPanel).
- Security code mapping \- [SecurityMappingPanel](xref:StockSharp.Xaml.SecurityMappingPanel).
- Storage settings \- [StorageSettingsPanel](xref:StockSharp.Xaml.StorageSettingsPanel).
- Subscriptions \- [SubscriptionPanel](xref:StockSharp.Xaml.SubscriptionPanel).
- Exchanges \- [ExchangesPanel](xref:StockSharp.Xaml.ExchangesPanel).
- Boards \- [ExchangeBoardsPanel](xref:StockSharp.Xaml.ExchangeBoardsPanel).
- Working schedule \- [WorkingTimeControl](xref:StockSharp.Xaml.WorkingTimeControl).
- Accounts and permissions \- [PermissionCredentialsPanel](xref:StockSharp.Xaml.PermissionCredentialsPanel).
