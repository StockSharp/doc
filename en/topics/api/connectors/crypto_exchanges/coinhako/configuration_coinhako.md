# Coinhako Connector Settings

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `Key` - API key.
- `Secret` - API secret.
- `RestEndpoint` - REST API address.
- `CounterCurrencies` - quote currencies requested when markets are polled.
- `PollingInterval` - interval between service polling requests.
