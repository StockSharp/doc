# Graphical Configuration of Talos

For all [S#](../../../../api.md) products, graphical configuration of the connection is performed in the [Connection Settings Window](../../../graphical_user_interface/connection_settings_window.md):

- `Address` - FIX server address and port issued by Talos.
- `SenderCompId` - FIX sender identifier.
- `TargetCompId` - FIX target identifier.
- `Login` - FIX session login.
- `Password` - FIX session password.
- `ClientCode` - client code used for account routing.
- `TargetHost` - TLS certificate host name.
