# Crypto.com Connector Settings

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `Key` - API key.
- `Secret` - API secret.
- `IsDemo` - demo environment mode.
- `RestEndpoint` - REST API address.
- `MarketWsEndpoint` - WebSocket server address.
- `UserWsEndpoint` - WebSocket server address.
