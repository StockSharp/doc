# Graphical Configuration of Polymarket

For all [S#](../../../../api.md) products, graphical configuration of the connection is performed in the [Connection Settings Window](../../../graphical_user_interface/connection_settings_window.md):

- `ApiKey` - API key.
- `ApiSecret` - API secret.
- `Passphrase` - API passphrase.
- `SignerAddress` - address that signs orders.
- `FunderAddress` - address that funds the trading account.
- `PrivateKey` - private key used locally to sign requests and transactions.
- `SignatureType` - signature scheme used for orders.
