# Connector configuration: BitoPro

Configure the following properties before connecting to BitoPro. The list is verified against [BitoProMessageAdapter](xref:StockSharp.BitoPro.BitoProMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Email` (`string`)
- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
