# Connector configuration: NovaDAX

Configure the following properties before connecting to NovaDAX. The list is verified against [NovaDaxMessageAdapter](xref:StockSharp.NovaDax.NovaDaxMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `AccountId` (`string`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `EngineIoVersion` (`int`)
