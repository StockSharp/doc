# Anchorage Connector Settings

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `Environment` - connection environment: production, demo, or test.
- `ApiKey` - API key.
- `SigningKey` - private key used to sign API requests.
- `ApiEndpoint` - REST API endpoint.
- `SocketEndpoint` - WebSocket API endpoint.
