# Connector configuration: Tokocrypto

Configure the following properties before connecting to Tokocrypto. The list is verified against [TokocryptoMessageAdapter](xref:StockSharp.Tokocrypto.TokocryptoMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `AccountRestEndpoint` (`string`)
- `MarketDataRestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
