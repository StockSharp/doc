# Connector configuration: Coinmetro

Configure the following properties before connecting to Coinmetro. The list is verified against [CoinmetroMessageAdapter](xref:StockSharp.Coinmetro.CoinmetroMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Token` (`SecureString`)
- `IsDemo` (`bool`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `DemoRestEndpoint` (`string`)
- `DemoWebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
