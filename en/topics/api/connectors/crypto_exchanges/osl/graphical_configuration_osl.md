# Graphical Configuration of OSL Global

For all [S#](../../../../api.md) products, graphical configuration of the connection is performed in the [Connection Settings Window](../../../graphical_user_interface/connection_settings_window.md):

- `Key` - API key.
- `Secret` - API secret.
- `Passphrase` - API passphrase.
- `RestEndpoint` - REST API address.
- `PublicWsEndpoint` - WebSocket server address.
- `PrivateWsEndpoint` - WebSocket server address.
- `CandleWsEndpoint` - WebSocket server address.
