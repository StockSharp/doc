# BTSE Connector Settings

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `Key` - API key.
- `Secret` - API secret.
- `SpotRestEndpoint` - REST API address.
- `SpotWebSocketEndpoint` - WebSocket server address.
- `SpotOrderBookWebSocketEndpoint` - WebSocket server address.
- `FuturesRestEndpoint` - REST API address.
- `FuturesWebSocketEndpoint` - WebSocket server address.
- `FuturesOrderBookWebSocketEndpoint` - WebSocket server address.
