# Graphical Configuration of FalconX

For all [S#](../../../../api.md) products, graphical configuration of the connection is performed in the [Connection Settings Window](../../../graphical_user_interface/connection_settings_window.md):

- `ApiKey` - API key.
- `Secret` - API secret.
- `Passphrase` - API passphrase.
- `ApiEndpoint` - service API endpoint.
- `PriceSocketEndpoint` - FalconX price WebSocket endpoint.
- `OrderSocketEndpoint` - FalconX order WebSocket endpoint.
