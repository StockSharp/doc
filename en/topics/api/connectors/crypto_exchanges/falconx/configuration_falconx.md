# FalconX Connector Settings

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `ApiKey` - API key.
- `Secret` - API secret.
- `Passphrase` - API passphrase.
- `ApiEndpoint` - service API endpoint.
- `PriceSocketEndpoint` - FalconX price WebSocket endpoint.
- `OrderSocketEndpoint` - FalconX order WebSocket endpoint.
