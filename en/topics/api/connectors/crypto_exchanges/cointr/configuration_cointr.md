# Connector configuration: CoinTR

Configure the following properties before connecting to CoinTR. The list is verified against [CoinTRMessageAdapter](xref:StockSharp.CoinTR.CoinTRMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `Passphrase` (`SecureString`)
- `RestEndpoint` (`string`)
- `PublicWebSocketEndpoint` (`string`)
- `PrivateWebSocketEndpoint` (`string`)
