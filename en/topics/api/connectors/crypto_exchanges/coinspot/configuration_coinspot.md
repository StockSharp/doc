# Connector configuration: CoinSpot

Configure the following properties before connecting to CoinSpot. The list is verified against [CoinSpotMessageAdapter](xref:StockSharp.CoinSpot.CoinSpotMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `PublicEndpoint` (`string`)
- `TradingEndpoint` (`string`)
- `ReadOnlyEndpoint` (`string`)
- `PollingInterval` (`TimeSpan`)
