# Connector configuration: BigONE

Configure the following properties before connecting to BigONE. The list is verified against [BigOneMessageAdapter](xref:StockSharp.BigOne.BigOneMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `SpotRestEndpoint` (`string`)
- `SpotWebSocketEndpoint` (`string`)
- `ContractRestEndpoint` (`string`)
- `ContractWebSocketEndpoint` (`string`)
- `ContractPrivateWebSocketEndpoint` (`string`)
