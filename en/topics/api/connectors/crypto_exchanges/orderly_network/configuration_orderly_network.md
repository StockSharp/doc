# Orderly Network Connector Settings

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `AccountId` - trading account identifier.
- `Secret` - API secret.
- `RestEndpoint` - REST API endpoint.
- `PublicWebSocketEndpoint` - public market data WebSocket endpoint.
