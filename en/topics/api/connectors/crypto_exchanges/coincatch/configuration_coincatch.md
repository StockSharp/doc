# Connector configuration: CoinCatch

Configure the following properties before connecting to CoinCatch. The list is verified against [CoinCatchMessageAdapter](xref:StockSharp.CoinCatch.CoinCatchMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `Passphrase` (`SecureString`)
- `ProductType` (`CoinCatchProductTypes`)
- `RestEndpoint` (`string`)
- `PublicWebSocketEndpoint` (`string`)
- `PrivateWebSocketEndpoint` (`string`)
- `PollingInterval` (`TimeSpan`)
