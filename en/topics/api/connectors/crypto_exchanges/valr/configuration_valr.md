# VALR Connector Settings

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `Key` - API key.
- `Secret` - API secret.
- `SubAccountId` - subaccount identifier.
- `RestEndpoint` - REST API address.
- `TradeWebSocketEndpoint` - WebSocket server address.
- `AccountWebSocketEndpoint` - WebSocket server address.
