# Ourbit Connector Settings

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `Key` - API key.
- `Secret` - API secret.
- `SpotRestEndpoint` - REST API address.
- `SpotWsEndpoint` - WebSocket server address.
- `FuturesRestEndpoint` - REST API address.
- `FuturesWsEndpoint` - WebSocket server address.
