# Connector configuration: Coinstore

Configure the following properties before connecting to Coinstore. The list is verified against [CoinstoreMessageAdapter](xref:StockSharp.Coinstore.CoinstoreMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
