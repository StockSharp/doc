# Graphical Configuration of Bit2Me

For all [S#](../../../../api.md) products, graphical configuration is performed in the [Connection Settings Window](../../../graphical_user_interface/connection_settings_window.md):

- `Key` - Bit2Me API key for private operations.
- `Secret` - Bit2Me API secret.
- `RestEndpoint` - REST API address.
- `WebSocketEndpoint` - WebSocket address.

Leave `Key` and `Secret` empty for public market data only. Configure both values together for trading and account data.
