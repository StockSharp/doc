# Connector configuration: Quidax

Configure the following properties before connecting to Quidax. The list is verified against [QuidaxMessageAdapter](xref:StockSharp.Quidax.QuidaxMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Token` (`SecureString`)
- `UserId` (`string`)
- `RestEndpoint` (`string`)
- `PollingInterval` (`TimeSpan`)
