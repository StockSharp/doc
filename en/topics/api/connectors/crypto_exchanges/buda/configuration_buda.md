# Connector configuration: Buda

Configure the following properties before connecting to Buda. The list is verified against [BudaMessageAdapter](xref:StockSharp.Buda.BudaMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
