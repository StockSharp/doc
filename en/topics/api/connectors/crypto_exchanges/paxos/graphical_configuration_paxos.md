# Graphical Configuration of Paxos

For all [S#](../../../../api.md) products, graphical configuration of the connection is performed in the [Connection Settings Window](../../../graphical_user_interface/connection_settings_window.md):

- `Environment` - connection environment: production, demo, or test.
- `ClientId` - OAuth client identifier.
- `ClientSecret` - OAuth client secret.
- `ApiEndpoint` - REST API endpoint.
- `OAuthEndpoint` - OAuth token endpoint.
- `SocketEndpoint` - WebSocket API endpoint.
