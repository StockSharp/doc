# Pionex Connector Settings

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `Key` - API key.
- `Secret` - API secret.
- `RestEndpoint` - REST API address.
- `PublicWsEndpoint` - WebSocket server address.
- `SpotPrivateWsEndpoint` - WebSocket server address.
- `FuturesPrivateWsEndpoint` - WebSocket server address.
