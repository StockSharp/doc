# Graphical Configuration of SUN.io

For all [S#](../../../../api.md) products, graphical configuration of the connection is performed in the [Connection Settings Window](../../../graphical_user_interface/connection_settings_window.md):

- `WalletAddress` - public blockchain wallet address used to request balances and place orders.
- `PrivateKey` - private key used locally to sign transactions.
- `DataEndpoint` - market data API endpoint.
- `RouterEndpoint` - swap router API endpoint.
- `NodeEndpoint` - TRON FullNode API endpoint.
