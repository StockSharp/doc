# NDAX Connector Settings

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `Key` - API key.
- `Secret` - API secret.
- `UserId` - user identifier assigned by the service.
- `AccountId` - account identifier assigned by the service.
- `OmsId` - NDAX order management system identifier.
- `RestEndpoint` - REST API address.
- `WebSocketEndpoint` - WebSocket server address.
