# ApeX Omni Connector Settings

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `Key` - API key.
- `Secret` - API secret.
- `Passphrase` - API passphrase.
- `Seeds` - zkLink seed used to sign orders.
- `Environment` - connection environment: production or test network.
- `RestEndpoint` - REST API endpoint.
- `WebSocketEndpoint` - WebSocket API endpoint.
- `MarketDepth` - number of order book levels requested.
