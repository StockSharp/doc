# Graphical Configuration of Zoomex

For all [S#](../../../../api.md) products, graphical configuration of the connection is performed in the [Connection Settings Window](../../../graphical_user_interface/connection_settings_window.md):

- `Key` - API key.
- `Secret` - API secret.
- `Sections` - market sections enabled for API requests.
- `AccountType` - account type used for API requests.
- `RestEndpoint` - REST API address.
- `WebSocketEndpoint` - WebSocket server address.
