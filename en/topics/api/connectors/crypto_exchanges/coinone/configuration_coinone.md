# Coinone Connector Settings

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `Key` - API key.
- `Secret` - API secret.
- `QuoteCurrency` - quote currency used to request markets.
- `RestEndpoint` - REST API address.
- `PublicWebSocketEndpoint` - WebSocket server address.
- `PrivateWebSocketEndpoint` - WebSocket server address.
