# Uniswap Connector Settings

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `Token` - API access token.
- `GraphApiKey` - the Graph API key.
- `WalletAddress` - blockchain wallet address.
- `PrivateKey` - private key used to sign transactions.
- `Chain` - blockchain network used for requests.
- `RouterVersion` - version of the decentralized exchange router.
- `RpcEndpoint` - blockchain RPC endpoint.
- `TradingEndpoint` - trading API endpoint.
