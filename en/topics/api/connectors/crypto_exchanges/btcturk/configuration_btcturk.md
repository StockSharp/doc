# Connector configuration: BtcTurk

Configure the following properties before connecting to BtcTurk. The list is verified against [BtcTurkMessageAdapter](xref:StockSharp.BtcTurk.BtcTurkMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `GraphEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
