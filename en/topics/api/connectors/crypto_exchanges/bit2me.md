# Bit2Me

**Bit2Me** is a connector for the Bit2Me Pro cryptocurrency spot exchange. It supports public market data, historical candles, account balances, and trading operations through REST and WebSocket APIs.

Before writing trading robots for this platform, review the [Connectors](../../connectors.md) section.
