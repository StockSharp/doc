# Connector configuration: WazirX

Configure the following properties before connecting to WazirX. The list is verified against [WazirXMessageAdapter](xref:StockSharp.WazirX.WazirXMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `ReceiveWindow` (`long`)
- `PrivatePollingInterval` (`TimeSpan`)
