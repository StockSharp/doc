# Graphical Configuration of Bullish

For all [S#](../../../../api.md) products, graphical configuration of the connection is performed in the [Connection Settings Window](../../../graphical_user_interface/connection_settings_window.md):

- `Key` - API key.
- `Secret` - API secret.
- `TradingAccountId` - trading account identifier.
- `RateLimitToken` - bullish token used to identify API request limits.
- `RestEndpoint` - REST API address.
- `WsEndpoint` - WebSocket server address.
