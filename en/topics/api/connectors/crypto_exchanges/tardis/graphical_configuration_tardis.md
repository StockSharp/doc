# Graphical Configuration of Tardis

For all [S#](../../../../api.md) products, graphical configuration of the connection is performed in the [Connection Settings Window](../../../graphical_user_interface/connection_settings_window.md):

- `Token` - API access token.
- `Exchange` - exchange code whose data is requested.
- `ApiEndpoint` - REST API endpoint.
- `MachineHttpEndpoint` - local Tardis Machine HTTP endpoint.
- `MachineSocketEndpoint` - local Tardis Machine WebSocket endpoint.
