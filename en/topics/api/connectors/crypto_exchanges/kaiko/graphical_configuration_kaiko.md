# Graphical Configuration of Kaiko

For all [S#](../../../../api.md) products, graphical configuration of the connection is performed in the [Connection Settings Window](../../../graphical_user_interface/connection_settings_window.md):

- `Token` - API access token.
- `Region` - regional Kaiko API endpoint.
- `ReferenceEndpoint` - reference data API endpoint.
- `MarketEndpoint` - historical market data API endpoint.
- `StreamEndpoint` - real-time market data endpoint.
- `IsStreamingEnabled` - enable real-time WebSocket data.
