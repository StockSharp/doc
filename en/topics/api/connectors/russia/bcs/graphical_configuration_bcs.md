# Graphical configuration: BCS

For all StockSharp products, configure the connection in the [Connection settings window](../../../graphical_user_interface/connection_settings_window.md).

The basic section of the connection editor contains:

- `Token`
- `IsReadOnly`
- `PortfolioName`
- `PollingInterval`

Use the advanced view for the remaining properties described on the [Connector configuration](configuration_bcs.md) page. Keep prefilled provider endpoints unless the provider assigned different values.
