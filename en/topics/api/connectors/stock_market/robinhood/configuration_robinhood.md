# Robinhood connector configuration

Obtain the credentials, endpoints, and account identifiers required by Robinhood Agentic Trading, then specify the following connector settings.

- **Token** - property `Token`.
- **Address** - property `Address`. Default value: `https://agent.robinhood.com/mcp/trading`.
- **Polling interval** - property `PollingInterval`. Default value: `2 s`.
