# Public.com

**Public.com** integrates StockSharp with **Public Investing API** for market data and trading.

The connector supports security lookup, quotes, historical candles, accounts, balances, and positions, order management, REST polling for subscriptions, multi-leg option orders.

Before developing trading robots for Public.com, review the links in the [Connectors](../../connectors.md) section.
