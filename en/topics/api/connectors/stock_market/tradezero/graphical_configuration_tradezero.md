# TradeZero graphical configuration

For all StockSharp products, configure the connection in the [connection settings window](../../../graphical_user_interface/connection_settings_window.md).

- **Key** - the TradeZero API key identifier.
- **Secret** - the TradeZero API secret.
- **Default route** - the preferred order route. Leave it empty to select a compatible route automatically.
