# Connector configuration: Bloomberg BLPAPI and EMSX

Install the official client SDK and specify its path, credentials, and other connection parameters.

- `ServerAddress` - service address. Default value: `new DnsEndPoint("localhost", 8194)`.
- `SdkPath` - path to a local file or directory.
- `IsEmsxEnabled` - switch controlling connector behavior.
- `EmsxService` - connection parameter. Default value: `//blp/emapisvc`.
- `Broker` - connection parameter.
