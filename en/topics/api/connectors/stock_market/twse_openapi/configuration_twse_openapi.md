# Connector configuration: TWSE

Configure the following properties before connecting to TWSE. The list is verified against [TwseMessageAdapter](xref:StockSharp.Twse.TwseMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Address` (`Uri`)

## Advanced settings

These properties control endpoints, filters, limits, and other provider-specific behavior.

- `IncludeProfiles` (`bool`)
- `IncludeValuations` (`bool`)
- `CacheTimeout` (`TimeSpan`)
