# Angel One connector configuration

Obtain the credentials, endpoints, and account identifiers required by Angel One SmartAPI, then specify the following connector settings.

- **Login** - property `Login`.
- **Password** - property `Password`.
- **API key** - property `ApiKey`.
- **TOTP secret** - property `TotpSecret`.
- **Client local IP address** - property `ClientLocalIp`. Default value: `127.0.0.1`.
- **Client public IP address** - property `ClientPublicIp`.
- **MAC address** - property `MacAddress`.
- **Default product** - property `DefaultProduct`. Default value: `Delivery`.
