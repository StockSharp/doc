# Configuration Nasdaq Cloud Data Service

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `Login` - account login.
- `Password` - account password.
- `Address` - REST API address.
- `Source` - Nasdaq Cloud Data Service source identifier.
- `Offset` - market data mode: real-time or delayed.
