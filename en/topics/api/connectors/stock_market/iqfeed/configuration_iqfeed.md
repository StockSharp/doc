# Connector configuration: IQFeed

Prepare the provider's local gateway or client and specify the connection parameters.

- `Login` - account or client identifier.
- `Password` - authentication credential.
- `Level1Address` - service address.
- `Level2Address` - service address.
- `LookupAddress` - service address.
- `AdminAddress` - service address.
- `DerivativeAddress` - service address.
- `Level1Columns` - connection parameter.
- `IsDownloadSecurityFromSite` - switch controlling connector behavior.
- `SecuritiesFile` - path to a local file or directory.
- `Version` - connection parameter. Default value: `6.2`.
