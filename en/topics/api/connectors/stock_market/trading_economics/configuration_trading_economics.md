# Connector configuration: Trading Economics

Configure the following properties before connecting to Trading Economics. The list is verified against [TradingEconomicsMessageAdapter](xref:StockSharp.TradingEconomics.TradingEconomicsMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Token` (`SecureString`)
- `Address` (`Uri`)

## Advanced settings

These properties control endpoints, filters, limits, and other provider-specific behavior.

- `DefaultMarket` (`string`)
- `DefaultSearch` (`string`)
- `NewsLimit` (`int`)
