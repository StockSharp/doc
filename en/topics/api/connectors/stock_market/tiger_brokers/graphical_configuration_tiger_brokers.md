# Tiger Brokers graphical configuration

For all StockSharp products, configure the connection in the [connection settings window](../../../graphical_user_interface/connection_settings_window.md).

- **Tiger ID** - property `TigerId`.
- **Account** - property `Account`.
- **License** - property `License`. Default value: `Singapore`.
- **Private key** - property `PrivateKey`.
- **Token** - property `Token`.
- **Acquire quote permission automatically** - property `AutoGrabPermission`. Default value: `true`.
