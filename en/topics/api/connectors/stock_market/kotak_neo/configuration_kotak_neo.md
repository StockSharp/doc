# Kotak Neo connector configuration

Obtain the credentials, endpoints, and account identifiers required by Kotak Neo Trade API v2, then specify the following connector settings.

- **Consumer key** - property `ConsumerKey`.
- **Mobile number** - property `MobileNumber`.
- **User code** - property `UserCode`.
- **MPIN** - property `Mpin`.
- **TOTP secret** - property `TotpSecret`.
- **Default product** - property `DefaultProduct`. Default value: `Intraday`.
