# Graphical configuration: Motilal Oswal

For all StockSharp products, configure the connection in the [Connection settings window](../../../graphical_user_interface/connection_settings_window.md).

- `Key` - authentication credential.
- `Secret` - authentication credential.
- `Token` - authentication credential.
- `AccessToken` - authentication credential.
- `ClientCode` - account or client identifier.
- `LocalIp` - connection parameter. Default value: `127.0.0.1`.
- `PublicIp` - connection parameter. Default value: `127.0.0.1`.
- `MacAddress` - service address. Default value: `00:00:00:00:00:00`.
- `VendorInfo` - connection parameter.
- `InstalledAppId` - account or client identifier.
- `IsDemo` - switch controlling connector behavior.
- `DefaultProduct` - connector mode or option. Default value: `MotilalOswalProducts.Normal`.
- `AlgoId` - account or client identifier.
- `ReconnectAttempts` - numeric connector parameter. Default value: `10`.
