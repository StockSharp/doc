# Graphical configuration: Mirae Asset Sharekhan

For all StockSharp products, configure the connection in the [Connection settings window](../../../graphical_user_interface/connection_settings_window.md).

- `ApiKey` - authentication credential.
- `Token` - authentication credential.
- `VendorKey` - authentication credential.
- `CustomerId` - account or client identifier.
- `DefaultProduct` - connector mode or option. Default value: `MiraeSharekhanProducts.Investment`.
