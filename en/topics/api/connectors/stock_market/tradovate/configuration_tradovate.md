# Tradovate connector configuration

Register an API application with Tradovate and specify its credentials in the connector settings.

- **Login** - the Tradovate user name.
- **Password** - the Tradovate password.
- **Client ID** - the API client identifier (`cid`).
- **Secret** - the API client secret (`sec`).
- **Application ID** - the registered application identifier. The default value is `StockSharp`.
- **Application version** - the registered application version. The default value is `1.0`.
- **Device ID** - a stable device identifier registered for API access. The connector generates and saves it automatically.
- **Demo mode** - connect to the Tradovate simulation environment instead of the live environment.
