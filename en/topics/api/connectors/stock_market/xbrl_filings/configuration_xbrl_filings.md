# Connector configuration: XBRL Filings

Configure the following properties before connecting to XBRL Filings. The list is verified against [XbrlFilingsMessageAdapter](xref:StockSharp.XbrlFilings.XbrlFilingsMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Address` (`Uri`)

## Advanced settings

These properties control endpoints, filters, limits, and other provider-specific behavior.

- `PublicAddress` (`Uri`)
- `Country` (`string`)
- `PageSize` (`int`)
- `MaxPages` (`int`)
