# Connector configuration: Swissquote OpenWealth

Obtain the credentials from the provider and specify the connection parameters.

- `Token` - authentication credential.
- `CustomerId` - account or client identifier.
- `SafekeepingAccountId` - account or client identifier.
- `CashAccountId` - account or client identifier.
- `AccountCurrency` - connection parameter. Default value: `CHF`.
- `IsDemo` - switch controlling connector behavior. Default value: `true`.
- `IsDryRun` - switch controlling connector behavior.
- `IsBestEffort` - switch controlling connector behavior.
