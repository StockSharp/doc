# Configuration EOD Historical Data

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `Token` - API access token.
- `Address` - REST API address.
- `StockTradeWebSocketAddress` - WebSocket server address.
- `StockQuoteWebSocketAddress` - WebSocket server address.
- `ForexWebSocketAddress` - WebSocket server address.
- `CryptoWebSocketAddress` - WebSocket server address.
- `StockExchange` - stock exchange code used for requests.
