# Connector configuration: Korea Investment & Securities

Obtain the credentials from the provider and specify the connection parameters.

- `AppKey` - authentication credential.
- `AppSecret` - authentication credential.
- `AccountNumber` - connection parameter.
- `ProductCode` - account or client identifier. Default value: `01`.
- `HtsId` - account or client identifier.
- `IsDemo` - switch controlling connector behavior. Default value: `true`.
