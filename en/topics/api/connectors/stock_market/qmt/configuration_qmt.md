# Connector configuration: QMT

Prepare the provider's local gateway or client and specify the connection parameters.

- `GatewayHost` - service address. Default value: `127.0.0.1`.
- `GatewayPort` - numeric connector parameter. Default value: `58630`.
- `GatewayToken` - authentication credential.
- `ReconnectAttempts` - numeric connector parameter. Default value: `10`.
- `RequestTimeout` - time interval. Default value: `30`.
