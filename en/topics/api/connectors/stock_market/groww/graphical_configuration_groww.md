# Graphical configuration: Groww

For all StockSharp products, configure the connection in the [Connection settings window](../../../graphical_user_interface/connection_settings_window.md).

- `AccessToken` - authentication credential.
- `ApiKey` - authentication credential.
- `ApiSecret` - authentication credential.
- `TotpSecret` - authentication credential.
- `DefaultProduct` - connector mode or option. Default value: `GrowwProducts.Delivery`.
