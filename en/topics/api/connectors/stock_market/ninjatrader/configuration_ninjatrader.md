# NinjaTrader connector configuration

Obtain the credentials, endpoints, and account identifiers required by NinjaTrader REST and WebSocket APIs, then specify the following connector settings.

- **Login** - property `Login`.
- **Password** - property `Password`.
- **Client ID** - property `ClientId`.
- **Secret** - property `Secret`.
- **Application ID** - property `AppId`. Default value: `StockSharp`.
- **Application version** - property `AppVersion`. Default value: `1.0`.
- **Device ID** - property `DeviceId`.
- **Demo mode** - property `IsDemo`.
