# Kalshi Connector Settings

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `ApiKey` - API key.
- `PrivateKey` - private key used locally to sign requests and transactions.
- `IsDemo` - use the Kalshi demo environment.
- `Subaccount` - Kalshi subaccount number, from 0 to 63.
