# Questrade

**Questrade** integrates StockSharp with **Questrade API** for market data and trading.

The connector supports security lookup, quotes, historical candles, accounts, balances, and positions, order management, real-time account and order updates.

Before developing trading robots for Questrade, review the links in the [Connectors](../../connectors.md) section.
