# Connector configuration: LSEG Real-Time

Obtain the credentials from the provider and specify the connection parameters.

- `AuthenticationMode` - connector mode or option.
- `Address` - service address.
- `StandbyAddress` - service address.
- `IsHotStandby` - switch controlling connector behavior.
- `Login` - account or client identifier.
- `Password` - authentication credential.
- `ClientId` - account or client identifier.
- `Secret` - authentication credential.
- `ApplicationId` - account or client identifier. Default value: `256`.
- `Service` - connection parameter. Default value: `ELEKTRON_DD`.
- `Region` - connection parameter. Default value: `us-east-1`.
- `Position` - connection parameter.
- `Scope` - connection parameter. Default value: `trapi.streaming.pricing.read`.
- `AuthUrl` - service address.
- `DiscoveryUrl` - service address. Default value: `https://api.refinitiv.com/streaming/pricing/v1/`.
