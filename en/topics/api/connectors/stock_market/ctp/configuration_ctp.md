# CTP connector configuration

Obtain the credentials, endpoints, and account identifiers required by CTP Trader and Market Data APIs, then specify the following connector settings.

- **Login** - property `Login`.
- **Password** - property `Password`.
- **Broker ID** - property `BrokerId`.
- **Investor ID** - property `InvestorId`.
- **Market-data address** - property `MarketDataAddress`.
- **Trader address** - property `TraderAddress`.
- **Application ID** - property `AppId`.
- **Authentication code** - property `AuthCode`.
- **Product information** - property `ProductInfo`. Default value: `StockSharp`.
- **Recovery mode** - property `ResumeType`. Default value: `Quick`.
- **Production mode** - property `ProductionMode`. Default value: `true`.
- **Data directory** - property `DataPath`.
- **Query interval** - property `QueryInterval`. Default value: `1 s`.
- **Connection timeout** - property `ConnectionTimeout`. Default value: `30 s`.
