# Connector configuration: Capital.com

Obtain the credentials from the provider and specify the connection parameters.

- `ApiKey` - authentication credential.
- `Login` - account or client identifier.
- `Password` - authentication credential.
- `AccountId` - account or client identifier.
- `IsDemo` - switch controlling connector behavior. Default value: `true`.
- `IsPasswordEncryptionEnabled` - switch controlling connector behavior.
