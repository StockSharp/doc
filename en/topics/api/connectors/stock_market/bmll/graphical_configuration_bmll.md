# Graphical configuration BMLL

For all [S#](../../../../api.md) products, graphical configuration of the connection is performed on the [Connection settings window](../../../graphical_user_interface/connection_settings_window.md):

- `AuthenticationMode` - authentication method.
- `Login` - account login.
- `PrivateKeyPath` - path to the private key file.
- `Password` - account password.
- `Token` - API access token.
- `ApiKey` - API key.
- `Address` - REST API address.
- `AuthenticationAddress` - authentication service endpoint.
- `TradesDataset` - name of the BMLL trades dataset.
- `Level3Dataset` - name of the BMLL Level 3 dataset.
