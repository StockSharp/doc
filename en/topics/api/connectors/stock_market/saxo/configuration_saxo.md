# Saxo OpenAPI connector configuration

Obtain the credentials, endpoints, and account identifiers required by Saxo OpenAPI, then specify the following connector settings.

- **Access token** - property `AccessToken`.
- **Refresh token** - property `RefreshToken`.
- **Client ID** - property `ClientId`.
- **Client secret** - property `ClientSecret`.
- **Redirect URI** - property `RedirectUri`.
- **Account key** - property `AccountKey`.
- **Environment** - property `Environment`. Default value: `Simulation`.
