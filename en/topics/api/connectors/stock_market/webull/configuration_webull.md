# Webull connector configuration

Create an application in [Webull OpenAPI](https://developer.webull.com/apis/docs/) and obtain its credentials.

- **Key** — the Webull OpenAPI application key.
- **Secret** — the application secret.
- **Token** — an optional access token.
- **Account** — the trading account identifier. When omitted, the connector requests the account list automatically.
- **Demo mode** — use the Webull sandbox environment.

The `Token` and `Account` settings can be omitted when they are not required for your Webull application and account.
