# IG Markets graphical configuration

For all StockSharp products, configure the connection in the [connection settings window](../../../graphical_user_interface/connection_settings_window.md).

- **API key** - property `ApiKey`.
- **User name** - property `UserName`.
- **Password** - property `Password`.
- **Account ID** - property `AccountId`.
- **Environment** - property `Environment`. Default value: `Demo`.
- **Encrypt password** - property `EncryptPassword`.
