# Connector configuration: SnapTrade

Obtain the credentials from the provider and specify the connection parameters.

- `ClientId` - account or client identifier.
- `ConsumerKey` - authentication credential.
- `UserId` - account or client identifier.
- `UserSecret` - authentication credential.
- `AccountId` - account or client identifier.
- `PollingInterval` - time interval. Default value: `TimeSpan.FromMinutes(1)`.
