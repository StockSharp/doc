# Longbridge OpenAPI graphical configuration

For all StockSharp products, configure the connection in the [connection settings window](../../../graphical_user_interface/connection_settings_window.md).

- **Application key** - property `AppKey`.
- **Application secret** - property `AppSecret`.
- **Access token** - property `AccessToken`.
- **Portfolio** - property `Portfolio`. Default value: `Longbridge`.
- **API address** - property `ApiUrl`. Default value: `https://openapi.longbridge.com`.
- **Quote server address** - property `QuoteUrl`. Default value: `wss://openapi-quote.longbridge.com/v2`.
- **Trading server address** - property `TradeUrl`. Default value: `wss://openapi-trade.longbridge.com/v2`.
