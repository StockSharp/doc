# Charles Schwab connector configuration

Create an application with access to the [Charles Schwab Trader API](https://developer.schwab.com/products/trader-api--individual) and obtain an OAuth token.

- **Token** — an active OAuth access token.
- **Address** — the Trader API address. The default is `https://api.schwabapi.com/`.

The connector obtains the WebSocket address and streaming connection identifiers automatically. Refresh the OAuth token according to the Charles Schwab requirements.
