# Connector configuration: Fubon Neo

Install the official client SDK and specify its path, credentials, and other connection parameters.

- `SdkPath` - path to a local file or directory.
- `PersonalId` - account or client identifier.
- `Password` - authentication credential.
- `ApiKey` - authentication credential.
- `IsApiKeyLogin` - switch controlling connector behavior.
- `CertificatePath` - path to a local file or directory.
- `CertificatePassword` - authentication credential.
- `EnvironmentUrl` - service address.
- `RealtimeMode` - connector mode or option. Default value: `FubonNeoRealtimeModes.Normal`.
- `ReconnectAttempts` - numeric connector parameter. Default value: `10`.
