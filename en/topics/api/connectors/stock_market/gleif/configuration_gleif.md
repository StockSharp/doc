# Connector configuration: GLEIF

Configure the following properties before connecting to GLEIF. The list is verified against [GleifMessageAdapter](xref:StockSharp.Gleif.GleifMessageAdapter).

## Basic settings

The connection editor shows these settings first.

- `Address` (`Uri`)

## Advanced settings

These properties control endpoints, filters, limits, and other provider-specific behavior.

- `ActiveOnly` (`bool`)
- `ExpandIsins` (`bool`)
- `PageSize` (`int`)
- `MaxPages` (`int`)
