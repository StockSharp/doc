# Graphical configuration: Mastertrust

For all StockSharp products, configure the connection in the [Connection settings window](../../../graphical_user_interface/connection_settings_window.md).

The basic section of the connection editor contains:

- `ClientId`
- `OAuthClientId`
- `OAuthClientSecret`
- `AuthorizationCode`
- `RedirectUri`
- `Token`

Use the advanced view for the remaining properties described on the [Connector configuration](configuration_mastertrust.md) page. Keep prefilled provider endpoints unless the provider assigned different values.
