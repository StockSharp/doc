# Connector configuration: kabu Station

Prepare the provider's local gateway or client and specify the connection parameters.

- `ApiPassword` - authentication credential.
- `IsDemo` - switch controlling connector behavior. Default value: `true`.
- `DefaultAccountType` - connector mode or option. Default value: `KabuStationAccountTypes.Specified`.
- `DefaultStockOrderExchange` - connection parameter. Default value: `KabuStationExchanges.Sor`.
