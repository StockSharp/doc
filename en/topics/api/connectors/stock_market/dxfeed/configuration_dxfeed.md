# Connector configuration: dxFeed

Obtain the credentials from the provider and specify the connection parameters.

- `Address` - service address. Default value: `wss://demo.dxfeed.com/dxlink-ws`.
- `Token` - authentication credential.
- `AggregationPeriod` - time interval.
- `MarketDepthLevels` - numeric connector parameter. Default value: `20`.
- `MarketDepthSources` - connection parameter. Default value: `NTV`.
