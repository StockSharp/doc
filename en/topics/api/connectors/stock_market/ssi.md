# SSI

**SSI** connects StockSharp to SSI FastConnect API v3 for the Vietnamese HOSE, HNX, and UPCOM markets.

## Key capabilities

- Source-verified capabilities: real-time Level 1 quotes, order books, tick data, candles and historical requests, plus portfolio and order operations for stocks and futures.
- Provider-specific transport, sessions, and data formats are hidden behind the standard StockSharp API.

## Typical use

Use this connector to monitor Vietnamese exchange instruments, analyze market data, request history, and execute the supported trading workflows.

Available instruments, history depth, trading permissions, request limits, and service availability are controlled by SSI and the connected account.
