# Configuration Dow Jones

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `AuthenticationMode` - authentication method.
- `Token` - API access token.
- `ClientId` - OAuth client identifier.
- `Login` - account login.
- `Password` - account password.
- `Address` - REST API address.
- `OAuthAddress` - OAuth service endpoint.
