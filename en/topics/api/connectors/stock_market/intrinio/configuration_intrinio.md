# Configuration Intrinio

Specify the connection parameters issued by the service in the connector settings.

## Connection parameters

- `Token` - API access token.
- `Address` - REST API address.
- `EquityProvider` - Intrinio equities data provider.
- `OptionProvider` - Intrinio options data provider.
- `IsDelayedOptions` - whether to use delayed options data.
