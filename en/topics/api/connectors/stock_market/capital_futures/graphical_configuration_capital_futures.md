# Graphical configuration: Capital Futures

For all StockSharp products, configure the connection in the [Connection settings window](../../../graphical_user_interface/connection_settings_window.md).

- `SdkPath` - path to a local file or directory.
- `Login` - account or client identifier.
- `Password` - authentication credential.
- `Account` - account or client identifier.
- `Environment` - connector mode or option. Default value: `CapitalFuturesEnvironments.Production`.
- `IsTradingEnabled` - switch controlling connector behavior. Default value: `true`.
- `LogPath` - path to a local file or directory.
