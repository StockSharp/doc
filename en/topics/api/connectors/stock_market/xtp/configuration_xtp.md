# Zhongtai XTP connector configuration

Obtain the credentials, endpoints, and account identifiers required by Zhongtai Securities XTP, then specify the following connector settings.

- **Login** - property `Login`.
- **Password** - property `Password`.
- **Client ID** - property `ClientId`. Default value: `1`.
- **Quote address** - property `QuoteAddress`.
- **Trading server address** - property `TransactionAddress`.
- **Protocol** - property `Protocol`. Default value: `TCP`.
- **Local address** - property `LocalAddress`.
- **Software key** - property `SoftwareKey`.
- **Software version** - property `SoftwareVersion`. Default value: `1.0`.
- **Data directory** - property `DataPath`.
