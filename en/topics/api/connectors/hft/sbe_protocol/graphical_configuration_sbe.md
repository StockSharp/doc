# Graphical configuration SBE

For StockSharp products, configure the SBE connection in the [Connection settings window](../../../graphical_user_interface/connection_settings_window.md).

- `Address` - TCP endpoint of the SBE server.
- `SenderCompId` - client identifier.
- `TargetCompId` - target server identifier.
- `Password` - authentication credential.
- `IsSupportNativeCandles` - enables native candle subscriptions.
