# TraderMade

**TraderMade** connects StockSharp to TraderMade REST and WebSocket APIs for foreign-exchange and supported cryptocurrency pairs.

## Key capabilities

- Source-verified capabilities: real-time Level 1 quotes, optional TraderLadder order books, instrument lookup, and historical candles. The adapter is market-data only.
- Provider-specific transport, sessions, and data formats are hidden behind the standard StockSharp API.

## Typical use

Use this connector for live FX monitoring, optional depth analysis, and historical candle downloads.

Symbols, ladder access, weekend data, request limits, and availability depend on the TraderMade subscription plan.
