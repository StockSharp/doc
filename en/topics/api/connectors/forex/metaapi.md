# MetaApi

**MetaApi** connects StockSharp to the MetaApi cloud REST and streaming APIs for MetaTrader 4 and MetaTrader 5 accounts.

The connector provides symbol specifications, Level 1 quotes, ticks, market depth, candles, and historical ticks and candles. Trading covers market, limit, and stop orders, order modification and cancellation, position closing, and synchronized portfolios, positions, orders, and deals.

Deploy a trading account in MetaApi and create an API token before connecting. Streams reconnect, the terminal state resynchronizes, and subscriptions are restored automatically.
