# Finage

**Finage** connects StockSharp to Finage Forex REST and WebSocket APIs.

## Key capabilities

- Source-verified capabilities: instrument lookup, real-time Level 1 quotes, and historical candles. The adapter is market-data only and does not expose transaction operations.
- Provider-specific transport, sessions, and data formats are hidden behind the standard StockSharp API.

## Typical use

Use this connector to discover currency pairs, monitor live quotes, and download FX candle history.

Symbol coverage, real-time access, history depth, request limits, and availability depend on the Finage subscription plan.
