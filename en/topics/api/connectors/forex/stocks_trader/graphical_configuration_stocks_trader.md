# Graphical configuration: StocksTrader

For all StockSharp products, configure the connection in the [Connection settings window](../../../graphical_user_interface/connection_settings_window.md).

Enter the token issued by the web terminal. Enable `IsDemo` for a demo account. Leave `AccountId` empty when the token holds a single account for the selected mode. Keep the default address unless StocksTrader assigned another endpoint, and adjust `PollingInterval` to the required update rate.
