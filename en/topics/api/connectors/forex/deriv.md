# Deriv

**Deriv** connects StockSharp to the official Deriv Options REST and WebSocket APIs.

The connector provides active symbol lookup, Level 1 quotes, tick history, tick streaming, and historical and live time-frame candles. Trading covers contract proposals, purchases, early sell or cancellation, live contract updates, balances, portfolios, open contracts, and transaction streaming.

Market data is available without credentials. Create a personal access or OAuth token and an application ID for authenticated demo or real accounts.
