# Graphical configuration: Deriv

For all StockSharp products, configure the connection in the [Connection settings window](../../../graphical_user_interface/connection_settings_window.md).

Enter the token and the application identifier. Enable `IsDemo` for a demo account. Leave `AccountId` empty when the token holds a single active account for the selected mode. Keep the REST and WebSocket addresses at their defaults unless Deriv assigned different endpoints.
