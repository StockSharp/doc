# Graphical configuration Oanda

For all [S#](../../../../api.md) products, graphical configuration of the connection is performed in the [Connection settings window](../../../graphical_user_interface/connection_settings_window.md):

![API GUI Settings OANDA](../../../../../images/api_gui_settings_oanda.png)

- **Server** - Server.
- **Token** - Token.
- **Compression** - Compression.
- **Transactions only** - Write log messages only for transaction stream.
- **Reconnection settings** - Settings of the mechanism for tracking the connection with the trading system ([Reconnection settings](../../reconnection_settings.md)).
- **Heartbeat interval** - Interval for notifying the server that the connection is still alive. The default value is 1 minute.
- **Unified board code** - Board code for the unified instrument.
