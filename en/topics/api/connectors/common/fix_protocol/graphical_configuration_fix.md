# Graphical configuration FIX

For all [S#](../../../../api.md) products, graphical configuration of the connection is performed on the [Connection settings window](../../../graphical_user_interface/connection_settings_window.md):

![API GUI Settings FIX](../../../../../images/api_gui_settings_fix.png)

- **Address** - Address.
- **Dialect** - FIX protocol dialect.
- **Sender** - Sender identifier.
- **Target** - Target identifier.
- **Login** - Login.
- **Password** - Password.
- **Portfolios** - Request all portfolios on start.
- **Instruments** - Request all instruments on connection.
- **Encoding** - Encoding used for data transfer.
- **Sequence reset** - Whether to reset the identifier counter.
- **Date format** - Date format.
- **Date and time format** - Date and time format.
- **Time format** - Time format.
- **Receive timeout** - Data receive timeout.
- **Send timeout** - Data send timeout.
- **Unknown transactions** - Process unknown executions generated by a third party.
- **Protocol** - SSL protocol for establishing the connection.
- **Certificate** - SSL certificate.
- **Password** - SSL certificate password.
- **Revocation check** - Certificate revocation check.
- **Check remote** - Check remote certificates.
- **Server name** - Server name that uses the SSL connection.
- **Reconnection settings** - Settings of the mechanism for tracking the connection with the trading system ([Reconnection settings](../../reconnection_settings.md)).
- **Heartbeat interval** - Interval for notifying the server that the connection is still alive. The default value is 1 minute.
- **Unified board code** - Board code for the unified instrument.
