# FIX Server

[FixServer](xref:StockSharp.Server.Fix.FixServer) allows you to create your own FIX servers that use the international [FIX](https://en.wikipedia.org/wiki/Financial_Information_eXchange)\/[FAST](https://en.wikipedia.org/wiki/FAST_protocol) protocols. It uses FIX 4.4 for transactions and FAST for market data. The server scheme is shown in the following figure:
