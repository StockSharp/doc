# Settings Directory

The following directories are important for [Designer](../../designer.md):

1. The directory where [Designer](../../designer.md) is installed. From this folder, you can start [Designer](../../designer.md) by running **Designer.exe**, or update [Designer](../../designer.md) by running **Designer.Update.exe**. Deleting this directory removes [Designer](../../designer.md), but [Designer](../../designer.md) settings are not deleted.

2. The **Designer** settings directory is located under the user's documents folder: …\\StockSharp\\Designer\\ (for example, c:\\Users\\User\\Documents\\StockSharp\\Designer\\). Deleting this directory resets all [Designer](../../designer.md) settings to their defaults. **All created strategies, downloaded instruments, and other information stored in the settings directory will be DESTROYED.**

![Designer Directory and edit the data manually 00](../../../images/designer_directory_and_edit_data_manually_00.png)

This directory contains the following folders and files:

- **Compositions** stores, as XML files, all blocks from the **Composite elements** folder on the [Schemas](../user_interface/schemas.md) panel. Deleting files from this directory removes the corresponding **Composite element** from the **Composite elements** folder on the [Schemas](../user_interface/schemas.md) panel. Do not edit these files manually; doing so may break the corresponding **Composite elements** block.
- **LiveStrategies** stores, as XML files, all blocks from the **Trading** folder on the [Schemas](../user_interface/schemas.md) panel. Deleting files from this directory removes the strategy from the **Trading** folder on the [Schemas](../user_interface/schemas.md) panel. Do not edit these files manually; doing so may break the corresponding strategy.
- **Logs** contains all [Designer](../../designer.md) crash logs, which simplifies troubleshooting [Designer](../../designer.md).
- **SourceCode** stores, as XML files, all blocks from the **Source code** folder on the [Schemas](../user_interface/schemas.md) panel. Deleting files from this directory removes the **Source code** block from the **Source code** folder on the [Schemas](../user_interface/schemas.md) panel. Do not edit these files manually; doing so may break the corresponding **Source code** block.
- **Strategies** stores, as XML files, all blocks from the **Strategies** folder on the [Schemas](../user_interface/schemas.md) panel. Deleting files from this directory removes the strategy from the **Strategies** folder on the Schemas panel. Do not edit these files manually; doing so may break the corresponding strategy. If you manually add a strategy file to this folder and restart [Designer](../../designer.md), the strategy appears in the **Strategies** folder on the [Schemas](../user_interface/schemas.md) panel.
- **Storage** contains market data downloaded by [Designer](../../designer.md) to the corresponding [Market data storage](../market_data_storage.md). The folder is created when [Market data storage](../market_data_storage.md) is created, and the default path points to this folder. Deleting this folder removes all downloaded market data from the corresponding storage. If the storage contains CSV files, they can be edited in a standard text editor or MS Excel. BIN files cannot be edited manually.
- **exchange.csv** and **exchangeboard.csv** contain the list of **exchanges**, instrument codes, and trading modes. These files can be edited in a standard text editor or MS Excel.
- **security.csv** contains all received and created instruments across all sources. Deleting this file removes all instruments from [Designer](../../designer.md). Adding new instruments is described in [Download instruments](../market_data_storage/download_instruments.md) and [Create instrument](../market_data_storage/create_instrument.md). This file can be edited in a standard text editor or MS Excel.
- **portfolio.csv** and **position.csv** contain all received and created portfolios and their current positions. Deleting these files removes the corresponding data from [Designer](../../designer.md). If [Designer](../../designer.md) receives portfolio information on each connection, position information can still be lost permanently. These files can be edited in a standard text editor or MS Excel.
- **settings.json** contains current settings. [Designer](../../designer.md) creates this file when settings change or when the program closes. Deleting this file resets current settings to defaults. Do not edit this file manually; doing so may break [Designer](../../designer.md).

Before manually editing individual files or resetting [Designer](../../designer.md) settings, make backup copies of the files you change or of the entire directory.
