# Update to the new version

Update Terminal through StockSharp Installer. The update guide explains how to check for available releases and apply application updates.

[Update apps](../installer/update_apps.md)

The new cross-platform Terminal, started for the first time in the settings folder of the previous Terminal, arranges the panels the way the previous one left them. After that, it keeps its own layout.
