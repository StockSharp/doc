# General settings

The **Settings** window is opened with the **File \=\> Settings** item or with the settings button on the [Hydra](../../hydra.md) command bar. Its settings are divided into groups:

- **Appearance**:
  - **Dark** \- the dark theme;
  - **Time Zone** \- the time zone in which the market data time is shown;
  - **Language** \- the program language.
- **General**:
  - **Autostart** \- start downloading when the program starts;
  - **Tray** \- minimize the window to the tray;
  - **Time for autostop** \- the time at which Hydra stops downloading;
  - **Index** \- the interval of rebuilding the storage index (see [Synchronization](synchronization.md));
  - **Dialogs** \- show a window with an error that the program has not handled itself; if the check box is cleared, such an error is only written to the log.
- **CSV**:
  - **Template** \- the templates by which data is written to CSV files.
- **Email**:
  - **Errors (quantity)** \- the number of errors after which an email with an error message will be sent; the value 0 disables sending;
  - **Email** \- the address to which the email is sent;
  - **From** \- the sender address of the email.
