# Criar instrumento

Ao clicar no botão **Criar instrumento** ![Designer botão Adicionar 00](../../../images/designer_creation_tool_00.png), abre-se a janela **Edição**. Para criar um instrumento, deve preencher as propriedades do instrumento e clicar no botão **Confirmar**:

![Designer botão Adicionar 01](../../../images/designer_creation_tool_01.png)

Os instrumentos de diferentes fontes têm identificadores unificados. Isto é feito para que o código do robô de negociação não dependa do tipo de ligação ([Conectores](../../api/connectors.md)). É usada a seguinte sintaxe para o identificador do instrumento - **\[código do instrumento\]@\[código da bolsa\]**. Por exemplo, para ações da Apple na bolsa NASDAQ, o identificador será **AAPL@NASDAQ**.
