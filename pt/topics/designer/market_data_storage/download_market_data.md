# Transferir dados de mercado

Para obter os dados históricos do título, selecione o título necessário na lista **Todos os instrumentos** e mova-o para a lista de títulos **Ativo**. Defina o período dos dados históricos, selecione o tipo e o período para candles e clique no botão **Iniciar**. Todos os dados serão guardados no [Armazenamento de dados de mercado](../market_data_storage.md).
