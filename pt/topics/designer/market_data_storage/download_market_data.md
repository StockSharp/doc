# Transferir dados de mercado

Para obter os dados históricos do título, selecione o título necessário na lista **All securities** e mova-o para a lista de títulos **Active**. Defina o período dos dados históricos, selecione o tipo e o Time Frame para candles e clique no botão **Start**. Todos os dados serão guardados no [Armazenamento de dados de mercado](../market_data_storage.md).
