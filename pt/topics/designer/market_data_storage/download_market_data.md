# Transferir dados de mercado

Para obter os dados históricos do instrumento, selecione o instrumento necessário na lista **Todos os instrumentos** e mova-o para a lista **Ativo**. Defina o período dos dados históricos, selecione o tipo e o período para velas e clique no botão **Iniciar**. Todos os dados serão guardados no [Armazenamento de dados de mercado](../market_data_storage.md).
