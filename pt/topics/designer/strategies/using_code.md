# Linguagens de programação

O [Designer](../../designer.md) suporta três linguagens de programação para criar estratégias de negociação:

- [C#](using_code/csharp.md)
- [F#](using_code/fsharp.md) 
- [Python](using_code/python.md)

Estão disponíveis exemplos extensos de estratégias em C# e Python na [pasta AlgoTrading API](https://github.com/StockSharp/AlgoTrading/tree/main/API). Todos funcionam com o [Designer](../../designer.md).

## C#

C# é a principal linguagem para desenvolver estratégias de negociação. Todos os componentes, exemplos e código principal são escritos em C#. C# fornece acesso completo a toda a arquitetura da plataforma [S#](../../api.md).

## F#

F# é uma linguagem de programação funcional da Microsoft. As estratégias de negociação em F# têm acesso completo a todas as capacidades da API e podem ser usadas tanto para testes como para negociação ao vivo.

## Python 

A integração com Python permite escrever estratégias de negociação usando a linguagem de programação Python, facilitando o trabalho dos programadores Python com a plataforma.
