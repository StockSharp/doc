# Usar Visual Studio ou Rider

Ao usar **Visual Studio** e **JetBrains Rider** para criar código que será executado no **Designer**, a única opção é a [importação de ficheiros](../../../export_import/import.md) constante. Isto deve-se à estrutura especial dos ficheiros criados pelo **Designer**, que impossibilita modificar diretamente os ficheiros, mesmo no caso de estratégias criadas em C#. Por isso, se forem necessários programas externos para escrever código, recomenda-se usar a abordagem com [ficheiros dll](../../using_dll.md).
