# DLLs externas

Ao criar conteúdo a partir de **Código-fonte**, juntamente com as bibliotecas da [API](../../../../api.md), pode usar outras bibliotecas C#, incluindo as suas próprias. Estas bibliotecas têm de ser compatíveis com .NET 10. Para adicionar uma referência a uma biblioteca, é necessário clicar no botão **Referências** do painel de código. Depois disso, será aberta a janela **Referências adicionais**, onde pode adicionar ou remover as bibliotecas necessárias:

- **Assembly** \- adicionar uma referência a um ficheiro de biblioteca;
- **Projeto** \- adicionar uma referência a código próprio ou a um indicador criado no Designer;
- **Excluir** \- eliminar a referência selecionada.

A tabela de referências mostra o nome, o caminho e o estado de cada referência, e a linha **Pesquisa** por cima dela encontra uma referência numa lista longa. Se não for possível adicionar uma referência, a causa é escrita a vermelho por baixo da tabela.
