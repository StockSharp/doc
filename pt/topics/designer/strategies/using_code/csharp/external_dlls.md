# DLLs externas

Ao criar conteúdo a partir de **Source Code**, juntamente com as bibliotecas da [API](../../../../api.md), pode usar outras bibliotecas C#, incluindo as suas próprias. Estas bibliotecas têm de ser compatíveis com .NET 6.0. Para adicionar uma referência a uma biblioteca, é necessário clicar no botão **References** no separador **Backtest**. Depois disso, será aberta a janela **Extra references**, onde pode adicionar ou remover as bibliotecas necessárias:
