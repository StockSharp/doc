# DLLs externas

Ao criar conteúdo a partir de **Código-fonte**, juntamente com as bibliotecas da [API](../../../../api.md), pode usar outras bibliotecas C#, incluindo as suas próprias. Estas bibliotecas têm de ser compatíveis com .NET 6.0. Para adicionar uma referência a uma biblioteca, é necessário clicar no botão **Referências** no separador **Teste histórico**. Depois disso, será aberta a janela **Referências adicionais**, onde pode adicionar ou remover as bibliotecas necessárias:
