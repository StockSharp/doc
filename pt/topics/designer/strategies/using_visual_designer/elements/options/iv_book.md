# Livro de IV

![Designer Volatilidade implícita no livro de ordens 00](../../../../../../images/designer_orderbook_implied_volatility_00.png)

O cubo é usado para calcular um livro de ordens de volatilidade implícita.

### Conectores de entrada

Conectores de entrada

- **Modelo** - o modelo de cálculo (por exemplo, Black-Scholes).
- **Livro de ordens** - o livro de ordens.

### Conectores de saída

Conectores de saída

- **Livro de ordens** - os valores do livro de ordens de volatilidade implícita.
