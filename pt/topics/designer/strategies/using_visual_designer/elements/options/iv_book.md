# Livro de IV

![Designer Volatilidade implícita no livro de ofertas 00](../../../../../../images/designer_orderbook_implied_volatility_00.png)

O cubo é usado para calcular um livro de ordens de volatilidade implícita.

### Sockets de entrada

Sockets de entrada

- **Modelo** - o modelo de cálculo (por exemplo, Black-Scholes).
- **Livro de ofertas** - o livro de ordens.

### Sockets de saída

Sockets de saída

- **Livro de ofertas** - os valores do livro de ordens de volatilidade implícita.
