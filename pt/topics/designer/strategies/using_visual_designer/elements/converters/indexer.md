# Indexador

![Designer Indexer 00](../../../../../../images/designer_indexer_00.png)

O elemento é usado para obter um elemento de uma coleção com o índice especificado. 

### Sockets de entrada

Sockets de entrada

- **Any data** - a coleção de elementos.

### Sockets de saída

Sockets de saída

- **Any data** - o elemento da coleção com o índice especificado nos parâmetros.

### Parâmetros

Parâmetros

- **Index** - o índice do elemento pretendido.
