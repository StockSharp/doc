# Conversor

![Designer Converter 00](../../../../../../images/designer_converter_00.png)

O cubo é usado para converter objetos complexos em tipos de dados simples. Por exemplo, permite obter o valor do passo de preço do instrumento.

### Sockets de entrada

Sockets de entrada

- **Any data** - um determinado tipo de objetos complexos que são recebidos.

### Sockets de saída

Sockets de saída

- **Any data** - o valor da propriedade selecionada para o objeto recebido.

### Parâmetros

Parâmetros

- **Data type** - o tipo de dados a introduzir. O tipo do parâmetro de entrada depende do valor selecionado.
- **Property** - a árvore de propriedades do tipo selecionado, que pode ser obtida na saída do cubo. O conjunto de propriedades disponíveis depende do tipo de dados selecionado e aparece apenas depois de selecionar o tipo de dados necessário.
