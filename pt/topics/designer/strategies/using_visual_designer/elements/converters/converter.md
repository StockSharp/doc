# Conversor

![Captura de tela de Conversor](../../../../../../images/designer_converter_00.png)

O cubo é usado para converter objetos complexos em tipos de dados simples. Por exemplo, permite obter o valor do passo de preço do instrumento.

### Conectores de entrada

Conectores de entrada

- **Quaisquer dados** - um determinado tipo de objetos complexos que são recebidos.

### Conectores de saída

Conectores de saída

- **Quaisquer dados** - o valor da propriedade selecionada para o objeto recebido.

### Parâmetros

Parâmetros

- **Tipo de dados** - o tipo de dados a introduzir. O tipo do parâmetro de entrada depende do valor selecionado.
- **Propriedade** - a árvore de propriedades do tipo selecionado, que pode ser obtida na saída do cubo. O conjunto de propriedades disponíveis depende do tipo de dados selecionado e aparece apenas depois de selecionar o tipo de dados necessário.
