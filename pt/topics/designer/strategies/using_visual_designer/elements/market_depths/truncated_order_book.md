# Truncated order book

![Designer MarketDepthTruncateDiagramElement 00](../../../../../../images/designer_marketdepthtruncatediagramelement_00.png)

O cubo é usado para obter um livro de ordens truncado até uma profundidade especificada.

### Sockets de entrada

- **Order book** é um livro de ordens que tem de ser truncado.

### Sockets de saída

- **Order book** é o livro de ordens truncado.

### Parâmetros

- **Depth** - a profundidade máxima do livro de ordens.
