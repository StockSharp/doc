# Level 1

![Designer Nível 1 00](../../../../../../images/designer_level_1_00.png)

Este bloco é usado para receber dados **Nível 1** de um instrumento.

### Sockets de entrada

Sockets de entrada

- **Instrumento** - o instrumento para o qual é necessário receber dados **Nível 1**.

### Sockets de saída

Sockets de saída

- **Alteração** - valores **Nível 1** do parâmetro monitorizado.

### Parâmetros

Parâmetros

- **Valor** - o parâmetro **Nível 1** que tem de ser monitorizado.
- **Subscrever por sinal** - subscrever dados apenas depois de chegar um trigger.
