# Level 1

![Designer Level 1 00](../../../../../../images/designer_level_1_00.png)

Este bloco é usado para receber dados **Level1** de um instrumento.

### Sockets de entrada

Sockets de entrada

- **Instrument** - o instrumento para o qual é necessário receber dados **Level1**.

### Sockets de saída

Sockets de saída

- **Change** - valores **Level1** do parâmetro monitorizado.

### Parâmetros

Parâmetros

- **Value** - o parâmetro **Level1** que tem de ser monitorizado.
- **Subscribe on Signal** - subscrever dados apenas depois de chegar um trigger.
