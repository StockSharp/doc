# Candles

![Designer Candles 00](../../../../../../images/designer_candles_00.png)

Este bloco é usado para construir candles para um instrumento especificado.

### Sockets de entrada

Sockets de entrada

- **Security** - o instrumento para o qual os candles devem ser construídos com os parâmetros indicados.

### Sockets de saída

Sockets de saída

- **Candles** - os candles construídos.

### Parâmetros

Parâmetros

- **Series** - o tipo da série de candles e os parâmetros para o tipo especificado;
- **Only Formed** - passar para a saída apenas candles totalmente formados ou qualquer alteração;
- **Smaller Timeframe** - construir candles a partir de um timeframe menor;
- **Subscribe on Signal** - subscrever dados apenas depois de receber um trigger.
