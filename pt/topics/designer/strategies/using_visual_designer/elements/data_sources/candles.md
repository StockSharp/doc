# Velas

![Captura de ecrã de Velas](../../../../../../images/designer_candles_00.png)

Este bloco é usado para construir velas para um instrumento especificado.

### Conectores de entrada

Conectores de entrada

- **Instrumento** - o instrumento para o qual as velas devem ser construídos com os parâmetros indicados.

### Conectores de saída

Conectores de saída

- **Velas** - as velas construídas.

### Parâmetros

Parâmetros

- **Série** - o tipo da série de velas e os parâmetros para o tipo especificado;
- **Apenas formadas** - passar para a saída apenas velas totalmente formadas ou qualquer alteração;
- **Período menor** - construir velas a partir de um período menor;
- **Subscrever por sinal** - subscrever dados apenas depois de receber um sinal de acionamento.
