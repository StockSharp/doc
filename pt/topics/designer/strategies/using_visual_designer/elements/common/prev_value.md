# Valor anterior

![Designer Valor anterior 00](../../../../../../images/designer_previous_value_00.png)

O cubo é usado para obter o valor anterior passado para a entrada, com o deslocamento especificado.

## Conectores de entrada

- **Quaisquer dados** - um determinado tipo de dados recebido e passado.

## Conectores de saída

- **Quaisquer dados** - um determinado tipo de dados recebido e passado, introduzido na entrada com o deslocamento especificado nos parâmetros.

## Parâmetros

- **Tipo de dados** - o tipo de dados que pode ser introduzido através do conector de entrada. Se alterar este parâmetro, o tipo de dados dos parâmetros é automaticamente alterado.
- **Desvio** - o tamanho do deslocamento, isto é, por quantas alterações o valor de saída ficará atrasado em relação ao de entrada.
