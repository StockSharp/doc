# Gráfico

![Designer Panel graphics 00](../../../../../../images/designer_panel_graphics_00.png)

O cubo foi concebido para apresentar dados no gráfico no painel [Chart](../../../../user_interface/components/chart.md). Cada elemento corresponde a uma área no gráfico e contém um conjunto de propriedades com as quais pode definir um conjunto de eixos no gráfico, um conjunto de elementos gráficos e os parâmetros da sua apresentação. A adição de qualquer elemento gráfico é feita premindo o botão ![Designer Panel graphics 01](../../../../../../images/designer_panel_graphics_01.png), e a eliminação premindo o botão ![Designer Panel graphics 02](../../../../../../images/designer_panel_graphics_02.png). Ao adicionar um elemento gráfico (uma série de velas, indicador, negócios, etc.) nas definições, é criado um parâmetro de entrada especial no cubo, através do qual os dados a apresentar serão passados para este cubo e, como resultado, serão apresentados no painel [Chart](../../../../user_interface/components/chart.md). Ao clicar no botão ![Designer Panel graphics 03](../../../../../../images/designer_panel_graphics_03.png), serão abertos os elementos gráficos filhos ou as respetivas definições.

![Designer Panel graphics 04](../../../../../../images/designer_panel_graphics_04.png)

O painel [Chart](../../../../user_interface/components/chart.md) apresenta todos os dados recebidos nos cubos **Chart panel**. Para diferentes séries de velas, tem de usar diferentes cubos **Chart panel**. Nesse caso, os gráficos serão colocados uns sobre os outros, mas apenas os elementos gráficos correspondentes (série de velas, indicador, negócios, etc.) serão apresentados em cada um. O exemplo mostra que o gráfico superior apresenta velas, dois indicadores e negócios, que correspondem a quatro parâmetros de entrada do cubo superior. No gráfico inferior são mostradas apenas velas. Para mais informações sobre o painel [Chart](../../../../user_interface/components/chart.md), consulte a secção [Chart](../../../../user_interface/components/chart.md).
