# Comparação

![Designer Comparison 00](../../../../../../images/designer_comparison_00.png)

Um elemento é usado para comparar dois objetos de entrada.

## Sockets de entrada

- **Valor 1** - valores que podem ser comparados (por exemplo, um valor numérico, uma cadeia de texto, um valor de indicador, etc.).
- **Valor 2** - valores que podem ser comparados (por exemplo, um valor numérico, uma cadeia de texto, um valor de indicador, etc.).

## Sockets de saída

- **Sinalizador** - o valor da flag (indica o estado e tem dois valores: levantada (true) e baixada (false)).

## Parâmetros

- **Esquerda** - o parâmetro cujo valor será usado no lado esquerdo da comparação.
- **Operador** - a condição pela qual os valores passados devem ser comparados.
- **Direita** - o parâmetro cujo valor será usado no lado direito da comparação.

Quando altera o operador, o nome do cubo muda automaticamente para o nome do operador.
