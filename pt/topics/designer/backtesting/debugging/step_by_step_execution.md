# Execução passo a passo

Para iniciar a execução passo a passo, coloque um breakpoint no elemento onde a execução deve parar primeiro. Depois de o [Designer](../../../designer.md) parar nesse elemento, clique no botão ![Designer Debug 03](../../../../images/designer_debug_03.png)**Next element**. O Designer passará de um elemento para o seguinte e mostrará como a estratégia é executada passo a passo.

Para entrar num **Composite element**, aguarde até que a execução passo a passo chegue a ele e clique em ![Designer Debug 04](../../../../images/designer_debug_04.png)**Step in**. O passo seguinte será executado dentro do **Composite element**. Para sair do **Composite element**, clique em ![Designer Debug 05](../../../../images/designer_debug_05.png)**Step out**.
