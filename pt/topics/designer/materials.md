# Recursos para aprendizagem

Esta documentação destina-se a familiarizá-lo com os principais recursos fornecidos pela StockSharp para aprender e trabalhar com o programa "Designer". Estes materiais ajudarão os utilizadores a começar rapidamente a trabalhar e a usar o programa de forma eficaz.

## Vídeos educativos

No canal da StockSharp no YouTube, pode encontrar vídeos tutoriais que demonstram como trabalhar com o "Designer", incluindo a definição de parâmetros, a criação de estratégias e o respetivo teste.

- **Playlist "Designer" no YouTube**: [Ver playlist](https://www.youtube.com/playlist?list=PLpwmSw294KYrfM1ALrONIz9MLpRQ1Uwfe)

## Exemplos de estratégias

A Galeria de Estratégias no site oficial da StockSharp apresenta várias estratégias de negociação desenvolvidas com o "Designer". Estes exemplos podem servir como um excelente ponto de partida para criar as suas próprias estratégias.

- **Galeria de estratégias "Designer"**: [Visitar a Galeria de Estratégias](strategy_gallery.md)

## Repositório GitHub

Os códigos-fonte das estratégias e de outros componentes usados no "Designer" estão disponíveis no GitHub. Este recurso é ideal para estudar exemplos de código e adaptá-los às suas necessidades.

- **Repositório StockSharp no GitHub**: [Visitar o repositório](https://github.com/StockSharp/algotrading)

## Chat de suporte

Para interagir com outros utilizadores e obter ajuda rápida sobre a utilização do "Designer", junte-se ao nosso chat no Telegram.

- **Chat "Designer" no Telegram**: [Entrar no chat](https://t.me/stocksharpchat/361)

Estes recursos fornecem tudo o que é necessário para uma aprendizagem e utilização eficazes do programa "Designer". Recomendamos que tire partido de todos os materiais fornecidos para alcançar os melhores resultados na negociação.
