# Executar estratégias fora do Designer

As estratégias criadas no [Designer](../../designer.md) podem ser executadas tanto nos seus próprios programas criados com a [API](../../api.md) como nas aplicações [Runner](../../runner.md) ou [Shell](../../shell.md).

- O [Runner](../../runner.md) é mais rápido e consome menos memória do que o [Designer](../../designer.md), pelo que as estratégias terão melhor desempenho. Esta abordagem é ideal para executar estratégias num servidor. Pode encontrar mais detalhes em [Exportar a partir do Designer](../../runner/export_from_designer.md).

- O [Shell](../../shell.md) é fornecido como código-fonte. Esta abordagem é ideal para distribuir estratégias com uma interface única criada especialmente para as estratégias. Pode encontrar mais detalhes em [Executar uma estratégia criada no Designer](../../shell/run_strategies_from_designer.md).
