# Negócios tick

O componente **Trades feed** é uma tabela de negócios que apresenta informações completas sobre todos os negócios dos instrumentos selecionados.

O **Trades feed** tem um filtro para selecionar os instrumentos necessários. Também pode configurar notificações para eventos relacionados com os instrumentos selecionados na janela [Notification settings](../../../terminal/notifications.md).
