# Livro de ordens

O componente **Livro de ordens** é uma tabela de ordens limitadas de compra e venda. Na parte superior do componente, deve selecionar a origem de dados a partir da qual os dados serão recebidos. A origem dos dados é o cubo [Painel de livro de ordens](../../strategies/using_visual_designer/elements/market_depths/order_book_panel.md).

Na estratégia, pode utilizar vários tipos diferentes de livros de ordens (ou de diferentes instrumentos) em simultâneo e apresentá-los em diferentes painéis.
