# Curva de P&L

O componente P/L é um gráfico do Profit/Loss (não realizado), Profit/Loss (realizado) e comissão. No canto superior esquerdo do gráfico são apresentados todos os elementos gráficos adicionados ao gráfico; se remover a caixa de verificação ![Designer elemento gráfico 00](../../../../images/designer_schedule_00.png) no elemento gráfico, o elemento também será removido do gráfico. Clicar no botão ![Designer elemento gráfico 01](../../../../images/designer_schedule_01.png) abrirá as definições do elemento gráfico.
