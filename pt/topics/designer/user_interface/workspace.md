# Área de trabalho

O **Workspace** no [Designer](../../designer.md) é uma interface em janelas com ancoragem de painéis semelhante à usada no Microsoft Visual Studio. Ao clicar no cabeçalho do painel com o botão esquerdo do rato e mantê-lo premido, pode fixar o painel num local conveniente. Ao arrastar as extremidades do painel, pode ajustar a sua altura ou largura:
