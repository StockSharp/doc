# Painel Logs

Para simplificar a monitorização do funcionamento do programa, existe um painel especial **Logs**. Este painel apresenta mensagens de todas as fontes, estratégias e ligações. No painel **Logs**, o aninhamento das fontes é apresentado como uma árvore. Cada nó pai contém mensagens de todas as fontes aninhadas, e assim sucessivamente, até ao nível mais baixo. Para estratégias, esta hierarquia permite ver estratégias filhas. Para abrir o painel **Logs**, tem de premir o botão **Logs** no separador **Common**.
