# Painel Logs

Para simplificar a monitorização do funcionamento do programa, existe um painel especial **Registos**. Este painel apresenta mensagens de todas as fontes, estratégias e ligações. No painel **Registos**, o aninhamento das fontes é apresentado como uma árvore. Cada nó pai contém mensagens de todas as fontes aninhadas, e assim sucessivamente, até ao nível mais baixo. Para estratégias, esta hierarquia permite ver estratégias filhas. Para abrir o painel **Registos**, tem de premir o botão **Registos** no separador **Geral**.
