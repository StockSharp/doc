# Friso

O principal elemento da interface de utilizador do [Designer](../../designer.md) é a **Faixa de opções**, que percorre a parte superior da janela da aplicação. A faixa de opções permite aceder rapidamente aos comandos necessários. Os comandos estão organizados em grupos lógicos, reunidos em separadores. Para navegar para o separador pretendido, basta clicar no respetivo título (nome). Cada separador está associado ao tipo de ação que está a ser executada.

1. O separador **Geral**, que abre por predefinição após o arranque, contém elementos que podem ser necessários na fase inicial de trabalho. A partir do separador **Geral**, pode abrir [Definições de ligações](../connections_settings.md), [Painel de esquemas](schemas.md), [Painel de registos](logs.md), [Carteiras](portfolios.md), [Mercados de negociação](boards.md), [Introdução](../market_data_storage/getting_started.md). Também no separador **Geral**, pode adicionar, abrir, eliminar, importar e exportar estratégias. Se quiser partilhar a sua estratégia com a comunidade, pode fazê-lo clicando no botão *Publicar*. O botão adjacente, *Estratégias disponíveis*, abre algoritmos publicados por si e por outros utilizadores. À direita, existem botões de serviço para chamar a ajuda, bem como para contactar-nos. Pode comunicar um problema ou escrever-nos no chat do Telegram.

![Designer faixa 00](../../../images/designer_tape_00.png)

2. O separador **Teste histórico** abre automaticamente ao selecionar uma estratégia no painel [Esquemas](schemas.md). O separador **Teste histórico** contém os principais elementos para criar, depurar, testar e otimizar estratégias ([Criar uma estratégia](../strategies/using_visual_designer.md), [Exemplo de backtesting](../backtesting/getting_started.md)). Também neste separador, a estratégia é iniciada para negociação real e são selecionados os componentes necessários para a sua estratégia: gráfico, livro de ordens, negócios, etc.

![Designer faixa 01](../../../images/designer_tape_01.png)

3. O separador **Ao vivo** destina-se especificamente à negociação real. Os detalhes sobre as definições de ligação estão descritos em [Definições de ligação](../connections_settings.md). A negociação real com o [Designer](../../designer.md) é descrita em [Negociação em tempo real](../live_execution/getting_started.md).

![Designer faixa 02](../../../images/designer_tape_02.png)

4. O separador **Nuvem**. O [Designer](../../designer.md) foi concebido para trabalhar com serviços de nuvem. Permite ver *Cloud Tasks* concluídas, obter informações sobre instrumentos disponíveis na Cloud e configurar o trabalho remoto com canais e robôs.

![Designer faixa 03](../../../images/designer_tape_03.png)
