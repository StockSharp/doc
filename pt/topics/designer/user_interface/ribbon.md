# Friso

O principal elemento da interface de utilizador do [Designer](../../designer.md) é o **Ribbon**, que percorre a parte superior da janela da aplicação. O Ribbon permite aceder rapidamente aos comandos necessários. Os comandos estão organizados em grupos lógicos, reunidos em separadores. Para navegar para o separador pretendido, basta clicar no respetivo título (nome). Cada separador está associado ao tipo de ação que está a ser executada.

1. O separador **Common**, que abre por predefinição após o arranque, contém elementos que podem ser necessários na fase inicial de trabalho. A partir do separador **Common**, pode abrir [Connection Settings](../connections_settings.md), [Scheme Panel](schemas.md), [Painel Logs](logs.md), [Carteiras](portfolios.md), [Board Editor](boards.md), [Creating a Repository of Historical Data](../market_data_storage/getting_started.md). Também no separador **Common**, pode adicionar, abrir, eliminar, importar e exportar estratégias. Se quiser partilhar a sua estratégia com a comunidade, pode fazê-lo clicando no botão *Publish*. O botão adjacente, *Available Strategies*, abre algoritmos publicados por si e por outros utilizadores. À direita, existem botões de serviço para chamar a ajuda, bem como para contactar-nos. Pode comunicar um problema ou escrever-nos no chat do Telegram.

![Designer Tape 00](../../../images/designer_tape_00.png)

2. O separador **Backtest** abre automaticamente ao selecionar uma estratégia no painel [Scheme](schemas.md). O separador **Backtest** contém os principais elementos para criar, depurar, testar e otimizar estratégias ([Creating a Strategy](../strategies/using_visual_designer.md), [Example of Backtesting](../backtesting/getting_started.md)). Também neste separador, a estratégia é iniciada para negociação real e são selecionados os componentes necessários para a sua estratégia: gráfico, livro de ordens, negócios, etc.

![Designer Tape 01](../../../images/designer_tape_01.png)

3. O separador **Live** destina-se especificamente à negociação real. Os detalhes sobre as definições de ligação estão descritos em [Connection Settings](../connections_settings.md). A negociação real com o [Designer](../../designer.md) é descrita em [Live Trading](../live_execution/getting_started.md).

![Designer Tape 02](../../../images/designer_tape_02.png)

4. O separador **Cloud**. O [Designer](../../designer.md) foi concebido para trabalhar com serviços de nuvem. Permite ver *Cloud Tasks* concluídas, obter informações sobre instrumentos disponíveis na Cloud e configurar o trabalho remoto com canais e robôs.

![Designer Tape 03](../../../images/designer_tape_03.png)
