# Carteiras

Para trabalhar com portefólios existe o painel **Carteiras**. Pode abri-lo clicando no botão **Carteiras** no separador **Geral**.

![Designer Painel A de carteiras 00](../../../images/designer_panel_portfolios_00.png)

O painel **Carteiras** é uma tabela que mostra os dados básicos do portefólio e as posições atuais desses portefólios. Ao fazer duplo clique no portefólio ou na posição, aparece a janela **Criação de carteira** ou a janela **Criação de posição**, onde pode editar o portefólio ou a posição selecionada. Para criar um novo portefólio ou uma nova posição, deve clicar no botão ![Designer Painel de circuitos 01](../../../images/designer_panel_circuits_01.png) e selecionar o item apropriado no menu pendente.

![Designer Painel A de carteiras 01](../../../images/designer_panel_portfolios_01.png)

Quando clica no botão ![Designer Alert Bell](../../../images/designer_alert_bell.png), abre-se a janela [Definições de notificação](../../terminal/notifications.md).
