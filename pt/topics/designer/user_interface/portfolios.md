# Carteiras

Para trabalhar com carteiras existe o painel **Carteiras**. Pode abri-lo clicando no botão **Carteiras** no separador **Geral**.

![Designer Painel A de carteiras 00](../../../images/designer_panel_portfolios_00.png)

O painel **Carteiras** é uma tabela que mostra os dados básicos das carteiras e as respetivas posições atuais. Ao fazer duplo clique numa carteira ou numa posição, aparece a janela **Criação de carteira** ou a janela **Criação de posição**, onde pode editar a carteira ou a posição selecionada. Para criar uma nova carteira ou uma nova posição, deve clicar no botão ![Designer Painel de circuitos 01](../../../images/designer_panel_circuits_01.png) e selecionar o item apropriado no menu pendente.

![Designer Painel A de carteiras 01](../../../images/designer_panel_portfolios_01.png)

Quando clica no botão ![Designer sino de alerta](../../../images/designer_alert_bell.png), abre-se a janela [Definições de notificação](../../terminal/notifications.md).
