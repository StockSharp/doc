# Armazenamento de dados de mercado

O armazenamento de dados históricos foi concebido para carregar dados de mercado (instrumentos, candles, tick trades e livros de ordens) de várias fontes e armazená-los num armazenamento local ou remoto. O [Designer](../designer.md) pode usar fontes tanto de dados históricos como de dados em tempo real ([Connectors](../api/connectors.md)). Depois, a informação armazenada fica disponível para utilização por estratégias de negociação.

Para abrir o separador **Market data**, mude para o separador **Common** e clique no botão **Market data**. A área **Market data** está dividida em três áreas. A área da esquerda contém a lista de todos os instrumentos recebidos de todas as fontes que alguma vez foram ligadas. As áreas centrais contêm os instrumentos ativos. Com estes instrumentos, pode transferir ou ver o histórico transferido. A área da direita apresenta os dados disponíveis para o instrumento selecionado na zona central, e também pode transferir dados usando o instrumento selecionado.
