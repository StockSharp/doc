# MATLAB

![Captura de tela de MATLAB](../images/matlab_stocksharp.png)

O **MATLAB** foi concebido para operadores que desenvolvem algoritmos de negociação no ambiente [MATLAB MathWorks](https://www.mathworks.com/).

O conector de integração **MATLAB** permite aos utilizadores ligar-se a todos os brokers e bolsas suportados pelo [S#](api.md) (+30 tipos de ligação em mercados globais). Os scripts MATLAB podem receber dados de mercado em tempo real e enviar ordens de negociação.

As definições detalhadas, scripts e documentação estão disponíveis para clientes que adquiriram o **MATLAB**.
