# Painel de notificações

O painel **Notificações** é uma tabela que apresenta informações sobre todas as notificações atualmente definidas.

![Terminal Painel de notificações](../../../images/terminal_notifications_panel.png)

No painel **Notificações**, pode editar ![Designer Criação de um repositório de dados históricos 01](../../../images/designer_creating_repository_of_historical_data_01.png) uma notificação existente, eliminá-la ![Designer Criação de um repositório de dados históricos 02](../../../images/designer_creating_repository_of_historical_data_02.png) ou definir uma nova notificação ![Designer Criação de um repositório de dados históricos 00](../../../images/designer_creating_repository_of_historical_data_00.png).
