# Painel de notificações

O painel **Notificações** é uma tabela que apresenta informações sobre todas as notificações atualmente definidas.

![Terminal Notifications Panel](../../../images/terminal_notifications_panel.png)

No painel **Notificações**, pode editar ![Designer Creating a repository of historical data 01](../../../images/designer_creating_repository_of_historical_data_01.png) uma notificação existente, eliminá-la ![Designer Creating a repository of historical data 02](../../../images/designer_creating_repository_of_historical_data_02.png) ou definir uma nova notificação ![Designer Creating a repository of historical data 00](../../../images/designer_creating_repository_of_historical_data_00.png).
