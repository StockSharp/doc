# Atualizar para a nova versão

Atualize o Terminal pelo StockSharp Installer. O guia explica como verificar as versões disponíveis e instalar as atualizações dos aplicativos.

[Atualizar aplicações](../installer/update_apps.md)

O novo Terminal multiplataforma, ao ser iniciado pela primeira vez na pasta de definições do Terminal anterior, organiza os painéis tal como o anterior os deixou. Depois disso, guarda a sua própria disposição.
