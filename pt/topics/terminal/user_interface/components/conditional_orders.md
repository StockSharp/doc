# Ordens condicionais

O componente de **ordens condicionais** é uma tabela com ordens, que apresenta informações completas sobre todas as ordens condicionais. Ao clicar com o botão direito do rato na ordem, aparece um painel com o qual pode registar uma nova ordem condicional, cancelar ou alterar a ordem condicional selecionada. 

![Terminal Orders conditional panel 01](../../../../images/terminal_orders_conditional_panel_01.png)

Ao clicar no botão **Registo de ordem**, aparece uma janela. Para registar uma nova ordem condicional, preencha-a e clique em **Enviar**.

![Terminal Orders conditional panel 02](../../../../images/terminal_orders_conditional_panel_02.png)

Ao clicar no botão **Alterar ordem**, aparece uma janela. Para alterar a ordem condicional, faça as alterações necessárias e clique em **Enviar**.

![Terminal Orders conditional panel 03](../../../../images/terminal_orders_conditional_panel_03.png)
