# Log de ordens

O componente **Log de ordens** é uma tabela com ordens que apresenta informações completas sobre todas as ordens dos instrumentos selecionados.

O **Log de ordens** tem um filtro para selecionar os instrumentos necessários. Também é possível configurar notificações para eventos dos instrumentos selecionados - [Definições de notificação](../../notifications.md).
