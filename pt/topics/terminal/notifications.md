# Notificações

As notificações são um sistema para alertar o utilizador sobre a ocorrência de um evento previamente especificado.

As notificações podem ser especificadas para uma ampla gama de eventos de negociação para os seguintes objetos: carteira, posição, Level 1, notícias. Por exemplo, pode criar uma notificação para quando o preço médio ponderado da posição excede um determinado valor ou para quando aparecem notícias com um título específico.

As notificações podem ter as seguintes formas:

- **Janela** - será apresentada uma pequena janela pop-up com uma mensagem no canto do ecrã.
- **Música** - será reproduzida música.
- **SMS** - a mensagem será enviada por SMS.
- **Email** - a mensagem será enviada por email.
- **Voz** - a mensagem será lida por uma voz gerada pelo computador.
- **Registo** - a mensagem será enviada para os [Registos](user_interface/logs.md).
- **Desativado** - a notificação não será apresentada.

Para definir uma notificação, tem de clicar no botão ![Designer botão Adicionar 00](../../images/designer_creation_tool_00.png) no painel de notificações ([Painel de notificações](notifications/notification_panel.md)) ou clicar no botão ![Designer sino de alerta](../../images/designer_alert_bell.png) diretamente nos painéis que suportam notificações.

Para obter informações sobre como configurar notificações, consulte a secção [Configuração de notificações](notifications/notifications_setup.md).
