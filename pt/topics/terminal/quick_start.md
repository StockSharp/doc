# Início rápido

Quando inicia o [Terminal](../terminal.md) pela primeira vez, será apresentada a seguinte janela:

![Terminal Quick start 00](../../images/terminal_quick_start_00.png)

Tem de selecionar o modo de arranque e clicar em **OK**.

Depois de selecionar o modo de arranque, a janela do terminal abre com o conjunto predefinido de componentes.

Vamos às definições de ligação e selecionamos a ligação necessária. A forma de configurar a ligação é descrita na secção [Definições de ligação](connection_settings.md).

![Terminal Quick start 011](../../images/terminal_quick_start_011.png)

O passo seguinte é estabelecer ligação clicando no botão **Connect** ![Designer The quick access toolbar 00](../../images/designer_quick_access_toolbar_00.png).

Ao clicar no botão **Add** ![Designer Creation tool 00](../../images/designer_creation_tool_00.png) no painel do gráfico, adicionamos uma nova área de gráfico. Ao clicar com o botão direito do rato na área do gráfico, adicionamos velas para o instrumento que nos interessa. Podemos adicionar indicadores, negócios próprios e ordens ao gráfico. Também existe a possibilidade de registar ordens a partir do gráfico. Para obter mais informações sobre como trabalhar com o gráfico, consulte a secção [Gráfico](user_interface/components/chart.md).

![Terminal Quick start 01](../../images/terminal_quick_start_01.png)

Ao clicar no botão **Add** ![Designer Creation tool 00](../../images/designer_creation_tool_00.png) no painel Instrument, adiciona os instrumentos que pretende acompanhar. Os dados do melhor preço serão apresentados aqui. Para obter mais informações sobre como trabalhar com o painel Instrument, consulte a secção [Instrumentos](user_interface/components/instruments.md).

![Terminal Quick start 02](../../images/terminal_quick_start_02.png)

No livro de ofertas, depois de clicar no botão **Settings** ![Designer Schedule 01](../../images/designer_schedule_01.png), aparece um painel onde pode especificar o **Instrument** e a **Portfolio** para os negócios. Aqui também pode ajustar a profundidade do livro de ofertas. Para obter mais informações sobre como trabalhar com um livro de ofertas, consulte a secção [Livro de ofertas](user_interface/components/order_book.md).

![Terminal Quick start 03](../../images/terminal_quick_start_03.png)

Vamos registar as primeiras ordens. As ordens podem ser registadas clicando nos botões **Buy/Sell** ou clicando nas células das colunas **Bid/Offer** do próprio livro de ofertas. O painel de ordens apresenta todas as suas ordens. Ao clicar com o botão direito do rato numa ordem, verá um painel que permite submeter uma nova ordem, cancelar ou alterar a ordem selecionada. Para obter mais informações sobre como trabalhar com o painel de ordens, consulte a secção [Ordens](user_interface/components/orders.md).

![Terminal Quick start 04](../../images/terminal_quick_start_04.png)

No painel Trades, pode ver negócios por instrumentos. Para obter mais informações sobre como trabalhar com o painel Trades, consulte a secção [Negócios](user_interface/components/trades.md).

![Terminal Quick start 05](../../images/terminal_quick_start_05.png)

Se necessário, pode adicionar componentes adicionais. Todos os componentes são descritos na secção [Componentes](user_interface/components.md).

![Terminal Quick start 06](../../images/terminal_quick_start_06.png)
