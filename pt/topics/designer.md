# Designer

O **Designer** é uma aplicação para criar estratégias de negociação, testá-las em dados históricos e gerir estratégias em negociação real. O Designer suporta duas formas de criar estratégias:

1. O [Designer visual](designer/strategies/using_visual_designer.md) não requer conhecimentos de programação. As estratégias são construídas combinando blocos e ligando-os com linhas, pelo que todo o fluxo de trabalho é apresentado visualmente.
2. As [estratégias baseadas em código](designer/strategies/using_code.md) destinam-se a programadores experientes. Estratégias escritas em **C#**, **F#** ou **Python** normalmente executam mais depressa do que estratégias visuais e não ficam limitadas aos blocos visuais disponíveis. Pode escrever estratégias diretamente no **Designer** ou num ambiente de desenvolvimento C#, como o **Microsoft Visual Studio**, usando a biblioteca [API](api.md) para desenvolvimento profissional de algoritmos de negociação.
