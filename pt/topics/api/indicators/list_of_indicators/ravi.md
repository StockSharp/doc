# RAVI

**índice de verificação da ação da faixa (Ravi)** é um indicador de análise técnica que determina a presença de uma tendência no mercado e a sua direção, com base num par de médias móveis simples com períodos configuráveis.

Para utilizar o indicador, deve usar a classe [RangeActionVerificationIndex](xref:StockSharp.Algo.Indicators.RangeActionVerificationIndex).
