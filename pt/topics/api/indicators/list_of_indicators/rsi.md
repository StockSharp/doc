# RSI

**Relative Strength Index (RSI)** é um indicador de momentum que mede a magnitude das variações recentes de preço para avaliar condições de sobrecompra ou sobrevenda de uma ação ou de outro ativo. 

Para utilizar o indicador, deve usar a classe [RelativeStrengthIndex](xref:StockSharp.Algo.Indicators.RelativeStrengthIndex).
