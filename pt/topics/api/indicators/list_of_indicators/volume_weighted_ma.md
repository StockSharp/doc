# Média móvel ponderada por volume

**Média móvel ponderada pelo volume (VWMA)** - o indicador apresenta o preço ponderado pelo volume durante um determinado período. Este indicador acompanha o preço como uma linha ondulada, com um certo desvio em relação ao gráfico de preços.

Para usar o indicador, deve usar a classe [VolumeWeightedMovingAverage](xref:StockSharp.Algo.Indicators.VolumeWeightedMovingAverage).
