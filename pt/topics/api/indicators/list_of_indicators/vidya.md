# VIDYA

**média dinâmica de índice variável (VIDYA)** é um indicador com um método original de cálculo da média móvel exponencial (EMA) com período de média dinamicamente variável. O período de média depende da volatilidade do mercado; foi escolhido um oscilador de momentum (CMO) como medida de volatilidade.

Para usar o indicador, deve usar a classe [Vidya](xref:StockSharp.Algo.Indicators.Vidya).
