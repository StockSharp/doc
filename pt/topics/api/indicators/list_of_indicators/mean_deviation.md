# Desvio médio

O indicador **Desvio médio** mostra o desvio médio do preço em relação à sua média móvel simples (SMA) durante um determinado período.

Para utilizar o indicador, deve ser usada a classe [MeanDeviation](xref:StockSharp.Algo.Indicators.MeanDeviation).
