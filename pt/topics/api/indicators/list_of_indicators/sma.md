# SMA

**Simple Moving Average (SMA)** é uma média móvel aritmética calculada somando os últimos preços de fecho e dividindo esse número pelo número de períodos de tempo. 

Para utilizar o indicador, deve usar a classe [SimpleMovingAverage](xref:StockSharp.Algo.Indicators.SimpleMovingAverage).
