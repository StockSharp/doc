# RoC

O indicador **Rate of Change (RoC)** mostra a diferença entre o preço atual e o preço de n velas atrás. 

Para utilizar o indicador, deve usar a classe [RateOfChange](xref:StockSharp.Algo.Indicators.RateOfChange).
