# CCI

**índice de canal de commodities (CCI)** é um indicador técnico baseado na análise do desvio do preço atual em relação ao seu valor médio e ao valor absoluto médio estatístico.

Para usar o indicador, deve usar a classe [CommodityChannelIndex](xref:StockSharp.Algo.Indicators.CommodityChannelIndex).
