# Wilder MA

**Média móvel de Wilder (WilderMA)** é um indicador de média móvel ponderada. Tal como todos os outros indicadores de média móvel, o indicador WMA suaviza o ruído do mercado e apresenta as tendências do mercado de forma mais clara. Para atingir este objetivo, o indicador filtra as flutuações do mercado (ruído), fazendo a média dos valores de preço dos períodos pelos quais é calculado. Ao mesmo tempo, é adicionado algum valor adicional (peso) aos preços médios, como acontece no cálculo de todos os indicadores ponderados, tais como EMA, LWMA e SMMA.

Para usar o indicador, deve usar a classe [WilderMovingAverage](xref:StockSharp.Algo.Indicators.WilderMovingAverage).
