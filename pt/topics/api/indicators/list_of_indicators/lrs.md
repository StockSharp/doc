# Linear Regression Slope

A interpretação do indicador **Linear Regression Slope** mostra o valor da inclinação das linhas de regressão, que incluem a barra de preço actual e a barra de preço anterior n-1 (onde n \= períodos de regressão). 

Para utilizar o indicador, deve usar a classe [LinearRegSlope](xref:StockSharp.Algo.Indicators.LinearRegSlope).
