# inclinação da regressão linear

A interpretação do indicador **inclinação da regressão linear** mostra o valor da inclinação das linhas de regressão, que incluem a barra de preço atual e a barra de preço anterior n-1 (onde n \= períodos de regressão).

Para utilizar o indicador, deve usar a classe [LinearRegSlope](xref:StockSharp.Algo.Indicators.LinearRegSlope).
