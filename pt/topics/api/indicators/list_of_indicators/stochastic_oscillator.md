# Oscilador estocástico

**Oscilador estocástico** é um indicador de momentum que compara um determinado preço de fecho de um instrumento com o intervalo dos seus preços durante um certo período de tempo. A sensibilidade do oscilador aos movimentos do mercado pode ser reduzida ajustando esse período de tempo ou aplicando uma média móvel ao resultado.

Para utilizar o indicador, deve usar a classe [StochasticOscillator](xref:StockSharp.Algo.Indicators.StochasticOscillator).
