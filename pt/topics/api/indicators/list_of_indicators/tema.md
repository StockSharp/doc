# TEMA

**Triple Exponential Moving Average (TEMA)** utiliza várias Médias Móveis Exponenciais (EMA), em triplo, para eliminar atrasos na previsão de preços. 

Para utilizar o indicador, deve usar a classe [TripleExponentialMovingAverage](xref:StockSharp.Algo.Indicators.TripleExponentialMovingAverage).
