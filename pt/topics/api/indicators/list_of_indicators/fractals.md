# Fractais

**Fractais** é uma sequência de várias velas, em que o máximo (mínimo) da vela central está acima dos máximos (mínimos) das velas adjacentes.

Para utilizar o indicador, deve usar a classe [Fractals](xref:StockSharp.Algo.Indicators.Fractals).
