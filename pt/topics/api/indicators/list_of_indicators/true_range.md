# True Range

**True Range (TR)** mostra a volatilidade atual do mercado, determinando o intervalo de flutuações dos preços máximo, mínimo e de fecho.

Para usar o indicador, deve usar a classe [TrueRange](xref:StockSharp.Algo.Indicators.TrueRange).
