# DMI

O indicador **Directional Movement Index (DMI)** é uma ferramenta técnica para determinar o início e a direção de uma tendência. É a primeira versão do famoso ADX. 

Para usar o indicador, deve ser usada a classe [DirectionalIndex](xref:StockSharp.Algo.Indicators.DirectionalIndex).
