# TRIX

**TRIX** é um oscilador utilizado para determinar mercados em sobrevenda e sobrecompra, ou como indicador de momentum. Tal como muitos osciladores, o TRIX oscila em torno da linha zero. Quando é utilizado como oscilador, um valor positivo indica um mercado em sobrecompra e um valor negativo indica um mercado em sobrevenda. Quando o TRIX é utilizado como indicador de momentum, um valor positivo indica um aumento do momentum e um valor negativo indica uma diminuição do momentum. 

Para utilizar o indicador, deve usar a classe [Trix](xref:StockSharp.Algo.Indicators.Trix).
