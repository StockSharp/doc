# LRC

**curva de regressão linear (LRC)** é um tipo de média móvel baseado na equação de regressão linear. O resultado do cálculo é uma linha recta com o melhor ajuste para diferentes preços do período. O ponto final desta linha é usado para desenhar a LRC.

Para utilizar o indicador, deve usar a classe [LinearReg](xref:StockSharp.Algo.Indicators.LinearReg).
