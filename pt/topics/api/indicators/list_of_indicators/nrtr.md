# NRTR

**reversão com seguimento de Nick Rypock (NRTR)** - a essência do indicador é estar sempre no segmento a partir dos extremos de preço alcançados. Aqui foi implementada a seguinte ideia: pequenos movimentos corretivos contra a tendência principal devem ser ignorados, e um movimento contra a tendência principal acima de determinado nível sinaliza uma tendência inversa.

Para usar o indicador, deve usar a classe [NickRypockTrailingReverse](xref:StockSharp.Algo.Indicators.NickRypockTrailingReverse).
