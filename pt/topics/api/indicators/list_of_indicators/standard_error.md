# Erro padrão

O indicador **Erro padrão** é uma estimativa do desvio quadrático médio do coeficiente de regressão relativamente ao seu valor verdadeiro.

Para utilizar o indicador, deve usar a classe [StandardError](xref:StockSharp.Algo.Indicators.StandardError).
