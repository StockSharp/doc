# Optimal Tracking

O indicador **Optimal Tracking Filter** ajusta alterações rápidas de preço e é relativamente suave quando o preço tem um movimento lateral. O efeito deste filtro é semelhante ao da Kaufman's Adaptive Moving Average. 

Para usar o indicador, deve usar a classe [OptimalTracking](xref:StockSharp.Algo.Indicators.OptimalTracking).
