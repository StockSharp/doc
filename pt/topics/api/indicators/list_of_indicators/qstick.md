# QStick

**Qstick** é um indicador técnico utilizado para determinar tendências em gráficos de velas. É calculado através da média móvel de N períodos da diferença entre os preços de abertura e de fecho. Um valor positivo do Qstick significa que a pressão compradora aumenta. 

Para utilizar o indicador, deve usar a classe [QStick](xref:StockSharp.Algo.Indicators.QStick).
