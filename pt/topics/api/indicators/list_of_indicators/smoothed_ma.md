# Smoothed MA

**Smoothed Moving Average (SMA)** - o indicador apresenta a direção suavizada do preço médio durante um determinado período de tempo. 

Para utilizar o indicador, deve usar a classe [SmoothedMovingAverage](xref:StockSharp.Algo.Indicators.SmoothedMovingAverage).
