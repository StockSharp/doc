# VHF

**Filtro vertical-horizontal (VHF)** - O indicador Filtro vertical-horizontal foi desenvolvido por Adam White em 1991. Este indicador é usado em análise técnica para reconhecer períodos em que o preço está numa tendência (tendência ascendente ou descendente) ou em que o mercado está numa fase lateral.

Para usar o indicador, deve usar a classe [VerticalHorizontalFilter](xref:StockSharp.Algo.Indicators.VerticalHorizontalFilter).
