# UO

O **Oscilador Definitivo (UO)** é um indicador técnico desenvolvido por Larry Williams em 1976 para medir o momentum em vários períodos temporais. Ao utilizar uma média ponderada de três períodos diferentes, o indicador apresenta menos volatilidade e menos sinais de negociação do que outros indicadores que dependem de um único período.

Para usar o indicador, deve usar a classe [UltimateOscillator](xref:StockSharp.Algo.Indicators.UltimateOscillator).
