# ADX

**ADX de Welles Wilder (índice direcional médio)** é um grupo de indicadores de movimento direcional. As linhas compõem o índice de movimento direcional (DMI): ADX, DI+ e DI-. O ADX indica a força da tendência, enquanto DI+ e DI- indicam a direção atual do preço.

Para usar o indicador, deve usar [AverageDirectionalIndex](xref:StockSharp.Algo.Indicators.AverageDirectionalIndex).
