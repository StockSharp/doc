# ZigZag

**ZigZag** — o indicador apresenta pontos no gráfico sempre que os preços mudam numa percentagem que excede o valor predefinido. Em seguida, são desenhadas linhas retas que ligam estes pontos. O indicador é usado para determinar tendências de preço.

Para usar o indicador, deve usar a classe [ZigZag](xref:StockSharp.Algo.Indicators.ZigZag).
