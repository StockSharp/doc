# Gator Oscillator

**Gator Oscillator** é um oscilador desenvolvido por Bill Williams. Está intimamente relacionado com o indicador semelhante Alligator. Como indicador de tendência, é mais útil em mercados que demonstram um forte movimento direcional. 

Para utilizar o indicador, deve usar a classe [GatorOscillator](xref:StockSharp.Algo.Indicators.GatorOscillator).
