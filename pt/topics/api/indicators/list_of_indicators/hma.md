# HMA

**Hull Moving Average (HMA)** - o indicador mostra a direção da tendência do mercado e representa uma média móvel melhorada. 

Para utilizar o indicador, deve usar a classe [HullMovingAverage](xref:StockSharp.Algo.Indicators.HullMovingAverage).
