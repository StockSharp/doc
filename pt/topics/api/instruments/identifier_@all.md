# Identificador \*@ALL

Se o instrumento for negociado em várias bolsas, pode utilizar "ALL" como código da bolsa. Por exemplo, o instrumento com o identificador AAPL@ALL significa que recolhe dados de todas as bolsas para o ticker AAPL (AAPL@BATS, AAPL@ICE, etc.) e que esses dados também têm um livro de ofertas comum.

O código da bolsa é utilizado para enviar a ordem para um sistema de negociação específico. Se especificar "ALL", o corretor ou a bolsa determinará a rota da ordem. Neste caso, o corretor ou a bolsa decide de forma independente em que bolsa é melhor executar a ordem. Pelo contrário, se especificar uma bolsa concreta, como BATS, a ordem será enviada apenas para a BATS.
