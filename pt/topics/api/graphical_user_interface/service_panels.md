# Painéis de serviço

Esta seção reúne os painéis que não mostram dados de mercado, mas configuram o funcionamento da aplicação: catálogos, configurações de armazenamento e importação, licenças, contas e assinaturas.

- Regras de comissão \- [CommissionPanel](xref:StockSharp.Xaml.CommissionPanel).
- Configurações de importação \- [ImportSettingsPanel](xref:StockSharp.Xaml.ImportSettingsPanel).
- Licenças \- [LicensePanel](xref:StockSharp.Xaml.LicensePanel).
- Busca de instrumentos \- [SecurityLookupPanel](xref:StockSharp.Xaml.SecurityLookupPanel).
- Correspondência de códigos de instrumentos \- [SecurityMappingPanel](xref:StockSharp.Xaml.SecurityMappingPanel).
- Configurações do armazenamento \- [StorageSettingsPanel](xref:StockSharp.Xaml.StorageSettingsPanel).
- Assinaturas \- [SubscriptionPanel](xref:StockSharp.Xaml.SubscriptionPanel).
- Bolsas \- [ExchangesPanel](xref:StockSharp.Xaml.ExchangesPanel).
- Praças \- [ExchangeBoardsPanel](xref:StockSharp.Xaml.ExchangeBoardsPanel).
- Horário de funcionamento \- [WorkingTimeControl](xref:StockSharp.Xaml.WorkingTimeControl).
- Contas e permissões \- [PermissionCredentialsPanel](xref:StockSharp.Xaml.PermissionCredentialsPanel).
