# Instrumentos

[S#](../../api.md) disponibiliza um grande conjunto de componentes gráficos para trabalhar com instrumentos. Este conjunto inclui:

- O componente para criar instrumentos - [SecurityCreateWindow](xref:StockSharp.Xaml.SecurityCreateWindow).
- O componente para apresentar informação financeira do instrumento - [SecurityGrid](xref:StockSharp.Xaml.SecurityGrid).
- Componentes para procurar e selecionar instrumentos - [SecurityPicker](xref:StockSharp.Xaml.SecurityPicker), [SecurityPickerWindow](xref:StockSharp.Xaml.SecurityPickerWindow) e [SecurityEditor](xref:StockSharp.Xaml.PropertyGrid.SecurityEditor).
- Componentes para criar instrumentos contínuos e de índice - [ContinuousSecurityWindow](xref:StockSharp.Xaml.ContinuousSecurityWindow) e [IndexSecurityWindow](xref:StockSharp.Xaml.IndexSecurityWindow).
