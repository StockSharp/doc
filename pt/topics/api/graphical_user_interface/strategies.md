# Estratégias

Esta secção contém os componentes usados ao trabalhar com estratégias.

- A tabela para apresentar as estatísticas da estratégia - [StrategiesStatisticsPanel](xref:StockSharp.Xaml.StrategiesStatisticsPanel).
- Tabela de estratégias em execução simultânea \- [StrategiesDashboard](xref:StockSharp.Xaml.StrategiesDashboard).
- Editor dos parâmetros do varrimento \- [OptimizationParametersPanel](xref:StockSharp.Xaml.OptimizationParametersPanel).
- Resultados do varrimento \- [OptimizationResultsPanel](xref:StockSharp.Xaml.Charting.OptimizationResultsPanel).
