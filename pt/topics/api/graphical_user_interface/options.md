# Opções

[S#](../../api.md) inclui vários componentes gráficos para trabalhar com opções.

- [OptionDesk](options/option_desk.md) - a mesa de opções.
- [OptionPositionChart](options/position_chart.md) - o gráfico que mostra a posição e os Greeks das opções relativamente ao ativo subjacente.
