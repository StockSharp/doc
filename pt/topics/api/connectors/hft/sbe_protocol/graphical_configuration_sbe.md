# Configuração gráfica do SBE

Nos produtos StockSharp, configure a conexão SBE na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md).

- `Address` - endpoint TCP do servidor SBE.
- `SenderCompId` - identificador do cliente.
- `TargetCompId` - identificador do servidor de destino.
- `Password` - credencial de autenticação.
- `IsSupportNativeCandles` - habilita assinaturas de velas nativas.
