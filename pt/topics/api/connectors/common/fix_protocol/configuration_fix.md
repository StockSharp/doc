# Configuração FIX

O conector usa uma conexão direta que requer uma **VPN** ou um **canal criptografado**.

Para trabalhar com o conector, você precisa especificar o **Login** e a **Senha**. O **Login** e a **Senha** são fornecidos pela corretora. Para obter acesso à API, recomenda-se entrar em contato com a corretora.
