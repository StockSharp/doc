# Configuração gráfica: MetaApi

Em todos os produtos StockSharp, configure a conexão na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md).

Informe o token e o identificador da conta implantada. Preencha `Region` somente para um token restrito a uma conta. Mantenha o domínio padrão, salvo se o MetaApi fornecer outro, e aumente `SynchronizationTimeout` para contas com histórico extenso.
