# Configuração gráfica do Match-Trader

Para todos os produtos StockSharp, a configuração gráfica da ligação é efetuada no formulário de ecrã [Janela de definições de ligação](../../../graphical_user_interface/connection_settings_window.md):

- `Address` - endereço da API REST.
- `Login` - nome de utilizador da conta.
- `Password` - palavra-passe da conta.
- `BrokerId` - identificador da corretora.
- `AccountId` - identificador da conta atribuído pelo serviço.
