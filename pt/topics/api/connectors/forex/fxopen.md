# FXOpen TickTrader

O **FXOpen TickTrader** conecta o StockSharp à API Web oficial do TickTrader.

O conector oferece pesquisa de instrumentos, cotações de nível 1, profundidade de mercado, velas históricas e em tempo real, carteiras, posições, ordens e execuções. Os dados de mercado usam o WebSocket de fluxo de dados; as atualizações de conta e execução usam o WebSocket de operações.

Para dados em tempo real e negociação, crie primeiro um token Web API na FXOpen. Os dados REST públicos podem ser acessados sem credenciais.
