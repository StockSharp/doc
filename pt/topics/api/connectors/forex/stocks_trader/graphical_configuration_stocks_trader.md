# Configuração gráfica: StocksTrader

Em todos os produtos StockSharp, configure a conexão na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md).

Informe o token emitido pelo terminal web. Ative `IsDemo` para uma conta de demonstração. Deixe `AccountId` vazio quando o token tiver uma única conta para o modo selecionado. Mantenha o endereço padrão, salvo se o StocksTrader fornecer outro ponto de conexão, e ajuste `PollingInterval` para a taxa de atualização necessária.
