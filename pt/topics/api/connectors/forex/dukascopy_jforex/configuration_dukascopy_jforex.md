# Configuração do conector: DukasCopy JForex

Prepare o gateway local ou o cliente do fornecedor e indique os parâmetros de conexão.

- `Login` - identificador da conta ou do cliente.
- `Password` - credencial de autenticação.
- `IsDemo` - interruptor que controla o comportamento do conector. Valor predefinido: `true`.
- `DemoAddress` - endereço do serviço JNLP do JForex usado no modo de demonstração.
- `LiveAddress` - endereço do serviço JNLP do JForex usado no modo de produção.
- `BridgePort` - parâmetro numérico do conector. Valor predefinido: `27431`.
- `BridgeJarPath` - caminho para um ficheiro ou diretório local.
