# Configuração gráfica: Deriv

Em todos os produtos StockSharp, configure a conexão na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md).

Informe o token e o identificador da aplicação. Ative `IsDemo` para uma conta de demonstração. Deixe `AccountId` vazio quando o token tiver uma única conta ativa para o modo selecionado. Mantenha os endereços padrão de REST e do WebSocket, salvo se a Deriv fornecer pontos de conexão diferentes.
