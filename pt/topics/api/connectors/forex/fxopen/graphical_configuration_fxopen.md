# Configuração gráfica: FXOpen TickTrader

Em todos os produtos StockSharp, configure a conexão na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md).

Informe o identificador, a chave e o segredo do token Web API. Ative `IsDemo` para uma conta de demonstração. Preencha `OneTimePassword` somente quando a conta exigir autenticação de dois fatores. Mantenha os endereços padrão de REST, do WebSocket de fluxo de dados e do WebSocket de operações, salvo se a FXOpen fornecer pontos de conexão diferentes.
