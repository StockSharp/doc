# TraderMade

**TraderMade** conecta o StockSharp às APIs REST e WebSocket da TraderMade para câmbio e pares de criptomoedas suportados.

## Principais recursos

- Recursos verificados no código-fonte: cotações de nível 1 em tempo real, livros TraderLadder opcionais, pesquisa de instrumentos e velas históricas. O adaptador fornece somente dados de mercado.
- Transportes, sessões e formatos específicos do provedor ficam ocultos atrás da API padrão do StockSharp.

## Uso típico

Use este conector para monitorar câmbio ao vivo, analisar profundidade opcional e baixar velas históricas.

Os símbolos, o acesso ao TraderLadder, os dados de fim de semana, os limites e a disponibilidade dependem do plano da TraderMade.
