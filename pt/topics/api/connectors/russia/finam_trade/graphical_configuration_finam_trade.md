# Configuração gráfica: API de negociação da Finam

Em todos os produtos StockSharp, configure a conexão na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md).

A seção básica do editor de conexões contém:

- `Token`
- `AccountId`

Na visualização avançada, configure `AppId`, `PollingInterval`, `LookupLimit`, `RestAddress` e `WebSocketAddress`. A finalidade e o valor padrão de cada campo estão descritos na página de [Configuração do conector](configuration_finam_trade.md).

Não há uma captura específica do conector porque o código-fonte não contém uma captura real do produto. Use a lista de campos acima e a janela padrão de configurações de conexão.
