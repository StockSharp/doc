# Configuração gráfica do ProBit Global

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da conexão é realizada na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md):

- `Key` - identificador de cliente OAuth.
- `Secret` - segredo de cliente OAuth.
- `RestEndpoint` - endereço da API REST.
- `AuthEndpoint` - endereço do ponto de acesso de token OAuth.
- `WebSocketEndpoint` - endereço do servidor WebSocket.

As credenciais são opcionais para dados públicos de mercado e obrigatórias para negociação e dados privados da conta.
