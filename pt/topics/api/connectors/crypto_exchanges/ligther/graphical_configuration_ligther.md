# Configuração gráfica Ligther

Para todos os produtos [S#](../../../../api.md), a configuração gráfica é efetuada na [Janela de definições de ligação](../../../graphical_user_interface/connection_settings_window.md).

Campos principais:

- **Key** - chave API.
- **Secret** - segredo API.
- **Account index** - índice da conta.
- **API key index** - índice da chave API.
- **Section** - secção de negociação (`Spot` ou `Derivatives`).
- **Demo** - modo de ambiente de demonstração.
- **Spot REST / Derivatives REST** - endpoints REST.
- **Spot WS / Derivatives WS** - endpoints websocket.
 - **Modo WS só de leitura** - sinalizador do modo WebSocket só de leitura.
