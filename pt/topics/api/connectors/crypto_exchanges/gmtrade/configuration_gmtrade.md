# Configurações do conector GMTrade

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `KeeperEndpoint` - ponto de acesso da API GMTrade Keeper.
- `WalletAddress` - endereço público da carteira de cadeia de blocos para operações da conta.
