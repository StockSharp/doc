# Configuração gráfica OKEx

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da ligação é efetuada na [Janela de definições de ligação](../../../graphical_user_interface/connection_settings_window.md):

![API GUI Settings OKEx](../../../../../images/api_gui_settings_okex.png)

- **Key** - chave.
- **Secret** - segredo.
- **Passphrase** - frase-passe.
- **Futures** - secção de futuros
- **Spot** - secção spot
- **Swap** - secção swap.
- **Password** - password administrativa.
- **Heart beat** - intervalo de verificação do servidor para controlar que a ligação está ativa. Por predefinição, é igual a 1 minuto.
- **Reconnection settings** - mecanismo para controlar as ligações com as definições do sistema de negociação. ([Definições de reconexão](../../reconnection_settings.md))
