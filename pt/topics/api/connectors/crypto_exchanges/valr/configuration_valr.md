# Configurações do conector VALR

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Key` - chave da API.
- `Secret` - segredo da API.
- `SubAccountId` - identificador da subconta.
- `RestEndpoint` - endereço da API REST.
- `TradeWebSocketEndpoint` - endereço do servidor WebSocket.
- `AccountWebSocketEndpoint` - endereço do servidor WebSocket.
