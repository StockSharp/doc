# Configurações do conector BTSE

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Key` - chave da API.
- `Secret` - segredo da API.
- `SpotRestEndpoint` - endereço da API REST.
- `SpotWebSocketEndpoint` - endereço do servidor WebSocket.
- `SpotOrderBookWebSocketEndpoint` - endereço do servidor WebSocket.
- `FuturesRestEndpoint` - endereço da API REST.
- `FuturesWebSocketEndpoint` - endereço do servidor WebSocket.
- `FuturesOrderBookWebSocketEndpoint` - endereço do servidor WebSocket.
