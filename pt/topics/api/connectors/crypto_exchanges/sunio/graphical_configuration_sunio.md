# Configuração gráfica do SUN.io

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da conexão é realizada na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md):

- `WalletAddress` - endereço público da carteira de cadeia de blocos para consultar saldos e enviar ordens.
- `PrivateKey` - chave privada utilizada localmente para assinar transações.
- `DataEndpoint` - ponto de acesso da API de dados de mercado.
- `RouterEndpoint` - ponto de acesso da API do roteador de trocas.
- `NodeEndpoint` - ponto de acesso da API FullNode da TRON.
