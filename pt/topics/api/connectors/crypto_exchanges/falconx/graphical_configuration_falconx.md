# Configuração gráfica do FalconX

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da conexão é realizada na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md):

- `ApiKey` - chave da API.
- `Secret` - segredo da API.
- `Passphrase` - frase secreta da API.
- `ApiEndpoint` - ponto de acesso da API do serviço.
- `PriceSocketEndpoint` - ponto de acesso WebSocket de preços da FalconX.
- `OrderSocketEndpoint` - ponto de acesso WebSocket de ordens da FalconX.
