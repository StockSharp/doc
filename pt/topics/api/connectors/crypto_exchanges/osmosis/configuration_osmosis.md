# Configurações do conector Osmosis

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `WalletAddress` - endereço público da carteira de cadeia de blocos para consultar saldos e enviar ordens.
- `PrivateKey` - chave privada utilizada localmente para assinar transações.
- `SqsEndpoint` - ponto de acesso da API SQS da Osmosis.
- `LcdEndpoint` - ponto de acesso da API LCD do Cosmos.
- `RpcEndpoint` - ponto de acesso RPC da cadeia de blocos.
- `StreamingEndpoint` - ponto de acesso WebSocket da cadeia de blocos para eventos em tempo real.
