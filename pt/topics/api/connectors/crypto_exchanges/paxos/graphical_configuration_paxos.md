# Configuração gráfica do Paxos

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da conexão é realizada na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md):

- `Environment` - ambiente de conexão: produção, demonstração ou teste.
- `ClientId` - identificador do cliente OAuth.
- `ClientSecret` - segredo do cliente OAuth.
- `ApiEndpoint` - ponto de acesso da API REST.
- `OAuthEndpoint` - ponto de acesso do token OAuth.
- `SocketEndpoint` - ponto de acesso da API WebSocket.
