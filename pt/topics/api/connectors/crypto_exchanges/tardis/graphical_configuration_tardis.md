# Configuração gráfica do Tardis

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da conexão é realizada na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md):

- `Token` - token de acesso à API.
- `Exchange` - código da bolsa cujos dados são solicitados.
- `ApiEndpoint` - ponto de acesso da API REST.
- `MachineHttpEndpoint` - ponto de acesso HTTP local do Tardis Machine.
- `MachineSocketEndpoint` - ponto de acesso WebSocket local do Tardis Machine.
