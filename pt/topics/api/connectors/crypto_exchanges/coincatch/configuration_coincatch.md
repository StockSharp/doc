# Configuração do conector: CoinCatch

Configure as propriedades a seguir antes de se conectar ao CoinCatch. A lista foi verificada com [CoinCatchMessageAdapter](xref:StockSharp.CoinCatch.CoinCatchMessageAdapter).

## Configurações básicas

O editor de conexões mostra primeiro estas configurações.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `Passphrase` (`SecureString`)
- `ProductType` (`CoinCatchProductTypes`)
- `RestEndpoint` (`string`)
- `PublicWebSocketEndpoint` (`string`)
- `PrivateWebSocketEndpoint` (`string`)
- `PollingInterval` (`TimeSpan`)
