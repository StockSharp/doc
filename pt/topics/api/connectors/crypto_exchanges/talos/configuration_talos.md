# Configurações do conector Talos

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Address` - endereço e porta do servidor FIX fornecidos pela Talos.
- `SenderCompId` - identificador do remetente FIX.
- `TargetCompId` - identificador do destinatário FIX.
- `Login` - usuário da sessão FIX.
- `Password` - senha da sessão FIX.
- `ClientCode` - código do cliente para roteamento de contas.
- `TargetHost` - nome do host no certificado TLS.
