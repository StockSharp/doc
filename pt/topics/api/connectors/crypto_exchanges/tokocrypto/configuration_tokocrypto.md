# Configuração do conector: Tokocrypto

Configure as propriedades a seguir antes de se conectar ao Tokocrypto. A lista foi verificada com [TokocryptoMessageAdapter](xref:StockSharp.Tokocrypto.TokocryptoMessageAdapter).

## Configurações básicas

O editor de conexões mostra primeiro estas configurações.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `AccountRestEndpoint` (`string`)
- `MarketDataRestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
