# Configuração gráfica do Polymarket

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da conexão é realizada na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md):

- `ApiKey` - chave da API.
- `ApiSecret` - segredo da API.
- `Passphrase` - frase secreta da API.
- `SignerAddress` - endereço que assina as ordens.
- `FunderAddress` - endereço que financia a conta de negociação.
- `PrivateKey` - chave privada utilizada localmente para assinar solicitações e transações.
- `SignatureType` - esquema de assinatura utilizado nas ordens.
