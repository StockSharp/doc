# Configuração do conector: CoinTR

Configure as propriedades a seguir antes de se conectar ao CoinTR. A lista foi verificada com [CoinTRMessageAdapter](xref:StockSharp.CoinTR.CoinTRMessageAdapter).

## Configurações básicas

O editor de conexões mostra primeiro estas configurações.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `Passphrase` (`SecureString`)
- `RestEndpoint` (`string`)
- `PublicWebSocketEndpoint` (`string`)
- `PrivateWebSocketEndpoint` (`string`)
