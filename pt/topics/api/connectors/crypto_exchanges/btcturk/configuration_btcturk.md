# Configuração do conector: BtcTurk

Configure as propriedades a seguir antes de se conectar ao BtcTurk. A lista foi verificada com [BtcTurkMessageAdapter](xref:StockSharp.BtcTurk.BtcTurkMessageAdapter).

## Configurações básicas

O editor de conexões mostra primeiro estas configurações.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `GraphEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
