# Configurações do conector Bitget

Para trabalhar com o conector, é necessário gerar uma **chave API** e um **segredo** na conta pessoal da bolsa e especificá-los ao configurar a conexão.

> [!TIP]
> Observe que a **chave API e o segredo** não são o **nome de utilizador e palavra-passe**. A **chave API e o segredo** são gerados separadamente na conta pessoal. O Login e a Senha não são necessários para o conector e não devem ser especificados em nenhum lugar.
