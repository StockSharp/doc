# Configuração do conector: Coinstore

Configure as propriedades a seguir antes de se conectar ao Coinstore. A lista foi verificada com [CoinstoreMessageAdapter](xref:StockSharp.Coinstore.CoinstoreMessageAdapter).

## Configurações básicas

O editor de conexões mostra primeiro estas configurações.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
