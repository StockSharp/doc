# Configurações do conector CoinJar

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Token` - token de acesso à API.
- `TradingEndpoint` - ponto de acesso da API de negociação.
- `DataEndpoint` - ponto de acesso da API de dados de mercado.
- `WebSocketEndpoint` - endereço do servidor WebSocket.
