# Configurações do conector Bullish

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Key` - chave da API.
- `Secret` - segredo da API.
- `TradingAccountId` - identificador da conta de negociação.
- `RateLimitToken` - token da Bullish para identificar os limites de pedidos à API.
- `RestEndpoint` - endereço da API REST.
- `WsEndpoint` - endereço do servidor WebSocket.
