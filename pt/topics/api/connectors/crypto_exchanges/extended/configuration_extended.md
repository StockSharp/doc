# Configurações do conector Extended

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `RestEndpoint` - ponto de acesso da API REST.
- `Key` - chave da API.
- `PrivateKey` - chave privada utilizada localmente para assinar solicitações e transações.
