# Configuração gráfica CoinBene

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da ligação é realizada na [Janela de definições de ligação](../../../graphical_user_interface/connection_settings_window.md):

![API GUI Settings CoinBene](../../../../../images/api_gui_settings_coinbene.png)

- **Key** - Key.
- **Secret** - Secret.
- **Balance** - Intervalo de verificação do saldo. Necessário em caso de ações de depósito e levantamento.
- **Heart beat** - Intervalo de verificação do servidor para monitorizar se a ligação está ativa. Por defeito é de 1 minuto.
- **Reconnection settings** - Mecanismo de monitorização das ligações com as definições do sistema de negociação. ([Definições de reconexão](../../reconnection_settings.md))
