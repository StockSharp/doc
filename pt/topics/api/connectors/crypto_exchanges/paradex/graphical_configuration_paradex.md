# Configuração gráfica Paradex

Para todos os produtos [S#](../../../../api.md), a configuração gráfica é realizada na [Janela de definições de ligação](../../../graphical_user_interface/connection_settings_window.md).

Campos principais:

- **chave** - chave da API.
- **segredo** - segredo da API.
- **Starknet account** - valor do cabeçalho da conta Starknet.
- **Starknet key** - material da chave privada Starknet.
- **Section** - secção de negociação (`Spot` ou `Derivatives`).
- **Enable spot** - ativa a secção spot.
- **Demo** - modo de ambiente de demonstração.
- **Spot REST / Derivatives REST** - endpoints REST.
- **Spot WS / Derivatives WS** - endpoints websocket.
- **Auth path** - caminho do endpoint de autenticação.
