# Velodrome

**Velodrome** conecta o StockSharp ao protocolo descentralizado Velodrome. O adaptador disponibiliza os dados de mercado e as operações de transação suportadas por meio do modelo padrão de mensagens do StockSharp.

## Principais recursos

- Recursos do adaptador verificados no código-fonte: atualizações de dados em tempo real, cotações de nível 1, negócios executados, dados de velas, solicitações de dados históricos, operações de carteira e ordens.
- Transportes, sessões e formatos específicos do provedor ficam ocultos atrás da API padrão do StockSharp.

## Uso típico

Use este conector para monitorar mercados descentralizados, analisar cotações e executar os fluxos de transação implementados pelo adaptador.

Instrumentos, profundidade de dados, permissões de transação, limites de solicitações e disponibilidade dependem de Velodrome, do plano de API e da conta conectada.
