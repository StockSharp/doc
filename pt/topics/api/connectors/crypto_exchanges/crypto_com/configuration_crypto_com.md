# Configurações do conector Crypto.com

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Key` - chave da API.
- `Secret` - segredo da API.
- `IsDemo` - modo do ambiente de demonstração.
- `RestEndpoint` - endereço da API REST.
- `MarketWsEndpoint` - endereço do servidor WebSocket.
- `UserWsEndpoint` - endereço do servidor WebSocket.
