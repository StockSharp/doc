# Configurações do conector OSL Global

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Key` - chave da API.
- `Secret` - segredo da API.
- `Passphrase` - frase secreta da API.
- `RestEndpoint` - endereço da API REST.
- `PublicWsEndpoint` - endereço do servidor WebSocket.
- `PrivateWsEndpoint` - endereço do servidor WebSocket.
- `CandleWsEndpoint` - endereço do servidor WebSocket.
