# Configurações do conector Variational Omni

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Endpoint` - ponto de acesso da API de dados de mercado.
- `PollingInterval` - intervalo de consulta de dados.
