# Configurações do conector Gemini

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Key` - chave da API.
- `Secret` - segredo da API.
- `Account` - identificador da conta de negociação.
- `IsCancelOnDisconnect` - indica se as ordens ativas são canceladas quando a ligação é perdida.
- `RestEndpoint` - endereço da API REST.
- `WebSocketEndpoint` - endereço do servidor WebSocket.
