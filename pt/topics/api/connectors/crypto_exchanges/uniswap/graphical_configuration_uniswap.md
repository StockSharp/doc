# Configuração gráfica do Uniswap

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da conexão é realizada na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md):

- `Token` - token de acesso à API.
- `GraphApiKey` - chave da API do The Graph.
- `WalletAddress` - endereço da carteira da cadeia de blocos.
- `PrivateKey` - chave privada utilizada para assinar transações.
- `Chain` - rede de cadeia de blocos utilizada nos pedidos.
- `RouterVersion` - versão do router da bolsa descentralizada.
- `RpcEndpoint` - ponto de acesso RPC da cadeia de blocos.
- `TradingEndpoint` - ponto de acesso da API de negociação.
