# Configurações do conector PancakeSwap

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `GraphApiKey` - chave da API do The Graph.
- `WalletAddress` - endereço da carteira da cadeia de blocos.
- `PrivateKey` - chave privada utilizada para assinar transações.
- `Chain` - rede de cadeia de blocos utilizada nos pedidos.
- `RpcEndpoint` - ponto de acesso RPC da cadeia de blocos.
