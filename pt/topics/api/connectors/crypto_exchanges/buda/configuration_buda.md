# Configuração do conector: Buda

Configure as propriedades a seguir antes de se conectar ao Buda. A lista foi verificada com [BudaMessageAdapter](xref:StockSharp.Buda.BudaMessageAdapter).

## Configurações básicas

O editor de conexões mostra primeiro estas configurações.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
