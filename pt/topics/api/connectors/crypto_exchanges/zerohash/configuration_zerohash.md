# Configurações do conector Zero Hash

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `ApiKey` - chave da API.
- `Secret` - segredo da API.
- `Passphrase` - frase secreta da API.
- `Account` - identificador da conta.
- `User` - identificador do usuário.
- `ApiEndpoint` - ponto de acesso da API REST.
