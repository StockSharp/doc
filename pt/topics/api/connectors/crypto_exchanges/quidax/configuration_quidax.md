# Configuração do conector: Quidax

Configure as propriedades a seguir antes de se conectar ao Quidax. A lista foi verificada com [QuidaxMessageAdapter](xref:StockSharp.Quidax.QuidaxMessageAdapter).

## Configurações básicas

O editor de conexões mostra primeiro estas configurações.

- `Token` (`SecureString`)
- `UserId` (`string`)
- `RestEndpoint` (`string`)
- `PollingInterval` (`TimeSpan`)
