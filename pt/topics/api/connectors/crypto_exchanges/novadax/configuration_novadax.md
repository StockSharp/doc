# Configuração do conector: NovaDAX

Configure as propriedades a seguir antes de se conectar ao NovaDAX. A lista foi verificada com [NovaDaxMessageAdapter](xref:StockSharp.NovaDax.NovaDaxMessageAdapter).

## Configurações básicas

O editor de conexões mostra primeiro estas configurações.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `AccountId` (`string`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `EngineIoVersion` (`int`)
