# CoinCap

**CoinCap** - fornecedor de dados de mercado em tempo real sobre moedas digitais/criptomoedas.

Antes de começar a escrever robôs de negociação para esta plataforma de negociação, recomendamos ler os links na secção [Conectores](../../connectors.md).

> [!CAUTION]
> O conector suporta apenas dados de mercado; transações não são suportadas.
