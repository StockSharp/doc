# Coinalyze

**Coinalyze** conecta o StockSharp ao serviço de dados do mercado de criptomoedas Coinalyze. O adaptador disponibiliza os dados do provedor por meio do modelo padrão de mensagens do StockSharp.

## Principais recursos

- Recursos do adaptador verificados no código-fonte: dados de velas, solicitações de dados históricos, mercados futuros.
- Transportes, sessões e formatos específicos do provedor ficam ocultos atrás da API padrão do StockSharp.
- Este adaptador é destinado ao acesso a dados e não encaminha ordens.

## Uso típico

Use este conector para alimentar gráficos, armazenamento de dados de mercado, análises, pesquisas e testes de estratégias.

Instrumentos, profundidade de dados, permissões de transação, limites de solicitações e disponibilidade dependem de Coinalyze, do plano de API e da conta conectada.
