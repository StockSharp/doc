# Configurações do conector Coinone

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Key` - chave da API.
- `Secret` - segredo da API.
- `QuoteCurrency` - moeda de cotação utilizada para solicitar mercados.
- `RestEndpoint` - endereço da API REST.
- `PublicWebSocketEndpoint` - endereço do servidor WebSocket.
- `PrivateWebSocketEndpoint` - endereço do servidor WebSocket.
