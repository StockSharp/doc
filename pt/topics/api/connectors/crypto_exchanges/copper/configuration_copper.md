# Configurações do conector Copper

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Environment` - ambiente de conexão: produção, demonstração ou teste.
- `ApiKey` - chave da API.
- `ApiSecret` - segredo da API.
- `ApiEndpoint` - ponto de acesso da API REST.
