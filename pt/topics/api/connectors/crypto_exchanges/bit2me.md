# Bit2Me

**Bit2Me** é um conector para a bolsa à vista de criptomoedas Bit2Me Pro. Ele oferece dados públicos de mercado, velas históricas, saldos de conta e operações de negociação pelas APIs REST e WebSocket.

Antes de desenvolver robôs para esta plataforma, consulte a seção [Conectores](../../connectors.md).
