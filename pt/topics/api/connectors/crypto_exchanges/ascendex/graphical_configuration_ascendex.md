# Configuração gráfica: AscendEX

Em todos os produtos StockSharp, configure a conexão na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md).

A seção básica do editor de conexões contém:

- `Key`
- `Secret`
- `AccountGroup`
- `SpotAccountType`
- `RestEndpoint`
- `SpotWebSocketEndpoint`
- `FuturesWebSocketEndpoint`

Todas as propriedades específicas do adaptador estão listadas acima. Mantenha os endereços predefinidos, salvo se o provedor tiver atribuído valores diferentes.
