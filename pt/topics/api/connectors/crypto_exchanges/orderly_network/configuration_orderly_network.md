# Configurações do conector Orderly Network

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `AccountId` - identificador da conta de negociação.
- `Secret` - segredo da API.
- `RestEndpoint` - ponto de acesso da API REST.
- `PublicWebSocketEndpoint` - ponto de acesso WebSocket público de dados de mercado.
