# Configuração gráfica do Orderly Network

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da conexão é realizada na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md):

- `AccountId` - identificador da conta de negociação.
- `Secret` - segredo da API.
- `RestEndpoint` - ponto de acesso da API REST.
- `PublicWebSocketEndpoint` - ponto de acesso WebSocket público de dados de mercado.
