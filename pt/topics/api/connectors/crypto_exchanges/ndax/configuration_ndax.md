# Configurações do conector NDAX

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Key` - chave da API.
- `Secret` - segredo da API.
- `UserId` - identificador de utilizador atribuído pelo serviço.
- `AccountId` - identificador da conta atribuído pelo serviço.
- `OmsId` - identificador do sistema de gestão de ordens da NDAX.
- `RestEndpoint` - endereço da API REST.
- `WebSocketEndpoint` - endereço do servidor WebSocket.
