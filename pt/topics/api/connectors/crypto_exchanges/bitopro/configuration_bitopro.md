# Configuração do conector: BitoPro

Configure as propriedades a seguir antes de se conectar ao BitoPro. A lista foi verificada com [BitoProMessageAdapter](xref:StockSharp.BitoPro.BitoProMessageAdapter).

## Configurações básicas

O editor de conexões mostra primeiro estas configurações.

- `Email` (`string`)
- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
