# Configurações do conector CoinW

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Key` - chave da API.
- `Secret` - segredo da API.
- `SpotRestEndpoint` - endereço da API REST.
- `FuturesRestEndpoint` - endereço da API REST.
- `SpotPublicWsEndpoint` - endereço do servidor WebSocket.
- `SpotPrivateWsEndpoint` - endereço do servidor WebSocket.
- `FuturesPublicWsEndpoint` - endereço do servidor WebSocket.
- `FuturesPrivateWsEndpoint` - endereço do servidor WebSocket.
