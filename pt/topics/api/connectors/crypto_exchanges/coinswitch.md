# CoinSwitch PRO

**CoinSwitch PRO** conecta o StockSharp à plataforma de criptomoedas CoinSwitch PRO. O adaptador disponibiliza a API do provedor por meio do modelo padrão de mensagens do StockSharp.

## Principais recursos

- Recursos do adaptador verificados no código-fonte: atualizações de dados em tempo real, cotações de nível 1, livros de ofertas de nível 2, negócios executados, dados de velas, solicitações de dados históricos, operações de carteira e ordens, mercados futuros, mercados de opções.
- Transportes, sessões e formatos específicos do provedor ficam ocultos atrás da API padrão do StockSharp.

## Uso típico

Use este conector em robôs de negociação, terminais, coletores de dados, serviços de gerenciamento de ordens e monitoramento de mercados de criptomoedas.

Instrumentos, profundidade de dados, permissões de transação, limites de solicitações e disponibilidade dependem de CoinSwitch PRO, do plano de API e da conta conectada.
