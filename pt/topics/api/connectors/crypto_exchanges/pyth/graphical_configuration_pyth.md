# Configuração gráfica do Pyth

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da conexão é realizada na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md):

- `Token` - token de acesso à API.
- `HistoryEndpoint` - ponto de acesso da API de dados históricos.
- `RouterEndpoint` - ponto de acesso da API REST de preços recentes.
- `WebSocketEndpoint1` - ponto de acesso WebSocket principal para dados em tempo real.
- `WebSocketEndpoint2` - ponto de acesso WebSocket secundário para dados em tempo real.
- `WebSocketEndpoint3` - terceiro ponto de acesso WebSocket para dados em tempo real.
- `Channel` - canal de dados da Pyth.
