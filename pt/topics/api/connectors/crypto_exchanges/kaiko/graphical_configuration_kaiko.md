# Configuração gráfica do Kaiko

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da conexão é realizada na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md):

- `Token` - token de acesso à API.
- `Region` - ponto de acesso regional da API da Kaiko.
- `ReferenceEndpoint` - ponto de acesso da API de dados de referência.
- `MarketEndpoint` - ponto de acesso da API de dados históricos de mercado.
- `StreamEndpoint` - ponto de acesso de dados de mercado em tempo real.
- `IsStreamingEnabled` - ativar dados WebSocket em tempo real.
