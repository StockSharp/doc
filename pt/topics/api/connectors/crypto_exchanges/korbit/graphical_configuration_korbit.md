# Configuração gráfica do Korbit

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da conexão é realizada na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md):

- `Key` - chave da API.
- `Secret` - segredo da API.
- `AccountSequence` - número sequencial da conta Korbit; a conta principal utiliza `1`.
- `RestEndpoint` - endereço da API REST.
- `PublicWebSocketEndpoint` - endereço do servidor WebSocket.
- `PrivateWebSocketEndpoint` - endereço do servidor WebSocket.
