# Configuração do conector: Coinmetro

Configure as propriedades a seguir antes de se conectar ao Coinmetro. A lista foi verificada com [CoinmetroMessageAdapter](xref:StockSharp.Coinmetro.CoinmetroMessageAdapter).

## Configurações básicas

O editor de conexões mostra primeiro estas configurações.

- `Token` (`SecureString`)
- `IsDemo` (`bool`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `DemoRestEndpoint` (`string`)
- `DemoWebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
