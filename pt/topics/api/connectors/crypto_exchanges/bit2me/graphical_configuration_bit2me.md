# Configuração gráfica do Bit2Me

Em todos os produtos [S#](../../../../api.md), a configuração gráfica é feita na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md):

- `Key` — chave de API do Bit2Me para operações privadas.
- `Secret` — segredo de API do Bit2Me.
- `RestEndpoint` — endereço da API REST.
- `WebSocketEndpoint` — endereço WebSocket.

Deixe `Key` e `Secret` vazios para usar apenas dados públicos. Para negociação e dados da conta, configure os dois valores.
