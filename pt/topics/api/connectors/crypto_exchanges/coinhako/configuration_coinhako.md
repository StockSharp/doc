# Configurações do conector Coinhako

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Key` - chave da API.
- `Secret` - segredo da API.
- `RestEndpoint` - endereço da API REST.
- `CounterCurrencies` - moedas de cotação cujos mercados são solicitados.
- `PollingInterval` - intervalo entre consultas ao serviço.
