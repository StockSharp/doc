# Configuração gráfica: DEX Screener

Em todos os produtos StockSharp, configure a conexão na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md).

A seção básica do editor de conexões contém:

- `RestEndpoint`
- `ChainId`
- `TokenAddress`
- `SearchQuery`
- `PriceInUsd`

Use a visualização avançada para as propriedades restantes descritas na página de [Configuração do conector](configuration_dex_screener.md). Mantenha os pontos de conexão preenchidos, salvo se o provedor tiver atribuído outros valores.
