# Definições do conector Gate.io

Para trabalhar com o conector, é necessário gerar uma **chave API** e um **segredo** na conta pessoal da bolsa e especificá-los ao configurar a ligação.

> [!TIP]
> Tenha em atenção que a **chave API e segredo** não são o **nome de utilizador e palavra-passe**. A **chave API e segredo** são gerados separadamente na conta pessoal. O Login e a Password não são necessários para o conector e não devem ser especificados em lado nenhum.
