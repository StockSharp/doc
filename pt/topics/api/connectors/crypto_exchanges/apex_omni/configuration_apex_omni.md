# Configurações do conector ApeX Omni

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Key` - chave da API.
- `Secret` - segredo da API.
- `Passphrase` - frase secreta da API.
- `Seeds` - semente zkLink utilizada para assinar ordens.
- `Environment` - ambiente de conexão: rede de produção ou de teste.
- `RestEndpoint` - ponto de acesso da API REST.
- `WebSocketEndpoint` - ponto de acesso da API WebSocket.
- `MarketDepth` - número de níveis solicitados do livro de ofertas.
