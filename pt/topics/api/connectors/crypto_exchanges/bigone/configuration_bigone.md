# Configuração do conector: BigONE

Configure as propriedades a seguir antes de se conectar ao BigONE. A lista foi verificada com [BigOneMessageAdapter](xref:StockSharp.BigOne.BigOneMessageAdapter).

## Configurações básicas

O editor de conexões mostra primeiro estas configurações.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `SpotRestEndpoint` (`string`)
- `SpotWebSocketEndpoint` (`string`)
- `ContractRestEndpoint` (`string`)
- `ContractWebSocketEndpoint` (`string`)
- `ContractPrivateWebSocketEndpoint` (`string`)
