# Configuração Blackwood (Fusion)

Para trabalhar com um conector, tem de especificar o **nome de utilizador** e a **palavra-passe**. O **nome de utilizador** e a **palavra-passe** são fornecidos pela corretora. Para obter acesso à API, recomenda-se contactar a corretora.
