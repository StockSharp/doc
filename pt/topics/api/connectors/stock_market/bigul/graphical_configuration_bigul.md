# Configuração gráfica: Bigul

Em todos os produtos StockSharp, configure a conexão na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md).

A seção básica do editor de conexões contém:

- `ClientCode`
- `ApiKey`
- `ApiSecret`
- `OneTimePassword`
- `Token`
- `Source`

Use a visualização avançada para as propriedades restantes descritas na página de [Configuração do conector](configuration_bigul.md). Mantenha os pontos de conexão preenchidos, salvo se o provedor tiver atribuído outros valores.
