# TradeStation

**TradeStation** integra a **TradeStation API v3** no StockSharp para obter dados de mercado e negociar.

O conector suporta pesquisa de instrumentos, cotações, velas históricas, contas, saldos e posições, gestão de ordens, atualizações de contas e ordens em tempo real, ambientes de simulação e reais.

Antes de desenvolver robôs de negociação para TradeStation, consulte as ligações na secção [Conectores](../../connectors.md).
