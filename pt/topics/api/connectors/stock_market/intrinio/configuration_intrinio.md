# Configuração Intrinio

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Token` - token de acesso à API.
- `Address` - endereço da API REST.
- `EquityProvider` - fornecedor de dados de ações da Intrinio.
- `OptionProvider` - fornecedor de dados de opções da Intrinio.
- `IsDelayedOptions` - indica se são utilizados dados de opções com atraso.
