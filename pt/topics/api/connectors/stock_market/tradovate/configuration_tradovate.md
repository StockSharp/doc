# Configuração do conector Tradovate

Registe uma aplicação de API na Tradovate e indique as respetivas credenciais nas definições do conector.

- **Nome de utilizador** - o nome de utilizador da Tradovate.
- **Palavra-passe** - a palavra-passe da Tradovate.
- **Identificador do cliente** - o identificador do cliente da API (`cid`).
- **Segredo** - o segredo do cliente da API (`sec`).
- **Identificador da aplicação** - o identificador da aplicação registada. O valor predefinido é `StockSharp`.
- **Versão da aplicação** - a versão da aplicação registada. O valor predefinido é `1.0`.
- **Identificador do dispositivo** - um identificador estável do dispositivo registado para acesso à API. O conector gera-o e guarda-o automaticamente.
- **Modo de demonstração** - liga ao ambiente de simulação da Tradovate em vez do ambiente real.
