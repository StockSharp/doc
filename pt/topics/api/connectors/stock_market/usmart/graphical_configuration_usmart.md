# Configuração gráfica uSMART OpenAPI

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da ligação é efetuada na [Janela de definições de ligação](../../../graphical_user_interface/connection_settings_window.md):

- `AccessToken` - token de acesso OAuth.
- `ChannelId` - identificador do canal de ligação do uSMART.
- `PrivateKey` - chave privada utilizada para assinar transações.
- `FundAccount` - identificador da conta de fundos do uSMART.
