# Configuração uSMART OpenAPI

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `AccessToken` - token de acesso OAuth.
- `ChannelId` - identificador do canal de ligação do uSMART.
- `PrivateKey` - chave privada utilizada para assinar transações.
- `FundAccount` - identificador da conta de fundos do uSMART.
