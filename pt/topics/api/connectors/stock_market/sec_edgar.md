# SEC EDGAR

**SEC EDGAR** conecta o StockSharp aos serviços oficiais de dados e registros da SEC EDGAR.

## Principais recursos

- Recursos verificados no código-fonte: pesquisa de companhias abertas, notícias de registros, arquivos históricos e fatos estruturados por `SecEdgarDataTypes.CompanyFacts`. Não oferece negociação.
- Transportes, sessões e formatos específicos do provedor ficam ocultos atrás da API padrão do StockSharp.

## Uso típico

Use este conector para localizar registrantes da SEC e coletar registros, notícias e fatos XBRL para análise.

A cobertura e a disponibilidade seguem os dados da SEC EDGAR, as regras de acesso justo e os limites configurados.
