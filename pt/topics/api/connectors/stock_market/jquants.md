# J-Quants

**J-Quants** conecta o StockSharp à J-Quants API V2 para dados da Bolsa de Tóquio.

## Principais recursos

- Recursos verificados no código-fonte: pesquisa de ações, futuros e opções da TSE, valores de nível 1, negócios e velas históricas. O adaptador fornece somente dados de mercado e não oferece transações.
- Transportes, sessões e formatos específicos do provedor ficam ocultos atrás da API padrão do StockSharp.

## Uso típico

Use este conector para descobrir instrumentos japoneses e baixar cotações, negócios e histórico de velas para pesquisa e análise.

A cobertura, a profundidade histórica, os limites e a disponibilidade dependem do plano da J-Quants.
