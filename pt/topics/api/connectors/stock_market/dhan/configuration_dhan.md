# Configuração do conector DhanHQ

Obtenha as credenciais, os endereços dos servidores e os identificadores da conta necessários para a DhanHQ API v2 e indique as seguintes definições do conector.

- **Identificador do cliente** - propriedade `ClientId`.
- **Token** - propriedade `Token`.
- **Produto predefinido** - propriedade `DefaultProduct`. Valor predefinido: `Intraday`.
