# Operação simultânea do terminal e do algoritmo

Se necessário, pode configurar o terminal OEC Trader para operar no modo [Primary](xref:StockSharp.OpenECry.OpenECryRemoting.Primary) e depois executar o algoritmo [S#](../../../../api.md) no modo [Primary](xref:StockSharp.OpenECry.OpenECryRemoting.Primary). Neste caso, o terminal e o algoritmo utilizarão a mesma ligação ao servidor OEC. Para o configurar, deve marcar o item de menu **Ficheiro → Permitir remoting** no terminal OEC Trader:
