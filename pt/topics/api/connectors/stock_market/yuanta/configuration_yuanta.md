# Configuração do conector: Yuanta SPARK

Instale o pacote de desenvolvimento oficial e indique o respetivo caminho, as credenciais e os restantes parâmetros de conexão.

- `SdkPath` - caminho para um ficheiro ou diretório local.
- `Account` - identificador da conta ou do cliente.
- `Password` - credencial de autenticação.
- `CertificatePath` - caminho para um ficheiro ou diretório local.
- `CertificatePassword` - credencial de autenticação.
- `Environment` - modo ou opção do conector. Valor predefinido: `YuantaEnvironments.Production`.
- `LogPath` - caminho para um ficheiro ou diretório local.
- `ReconnectAttempts` - parâmetro numérico do conector. Valor predefinido: `10`.
