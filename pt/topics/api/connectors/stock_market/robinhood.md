# Robinhood

**Robinhood** integra a **negociação através de agentes da Robinhood** no StockSharp para obter dados de mercado e negociar.

O conector suporta pesquisa de instrumentos, cotações, velas históricas, contas, saldos e posições, gestão de ordens, consulta REST para subscrições.

Antes de desenvolver robôs de negociação para Robinhood, consulte as ligações na secção [Conectores](../../connectors.md).
