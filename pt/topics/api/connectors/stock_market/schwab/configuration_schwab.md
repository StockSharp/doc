# Configuração do conector Charles Schwab

Crie uma aplicação com acesso à [API de negociação da Charles Schwab](https://developer.schwab.com/products/trader-api--individual) e obtenha um token OAuth.

- **Token de acesso** — um token de acesso OAuth válido.
- **Endereço** — o endereço da API de negociação. Valor predefinido: `https://api.schwabapi.com/`.

O conector obtém automaticamente o endereço WebSocket e os identificadores da ligação em tempo real. Renove o token OAuth de acordo com os requisitos da Charles Schwab.
