# Configuração do conector tastytrade

Obtenha as credenciais, os endereços dos servidores e os identificadores da conta necessários para a tastytrade Open API e indique as seguintes definições do conector.

- **Token** - propriedade `Token`.
- **Segredo do cliente** - propriedade `ClientSecret`.
- **Âmbitos de acesso** - propriedade `Scopes`.
- **Modo de demonstração** - propriedade `IsDemo`.
