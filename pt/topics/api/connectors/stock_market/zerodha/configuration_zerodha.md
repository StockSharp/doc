# Configuração do conector: Zerodha Kite Connect

Obtenha as credenciais junto do fornecedor e indique os parâmetros de conexão.

- `ApiKey` - credencial de autenticação.
- `ApiSecret` - credencial de autenticação.
- `Token` - credencial de autenticação.
- `RequestToken` - credencial de autenticação.
- `DefaultProduct` - modo ou opção do conector. Valor predefinido: `ZerodhaProducts.Intraday`.
