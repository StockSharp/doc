# Configuração EOD Historical Data

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Token` - token de acesso à API.
- `Address` - endereço da API REST.
- `StockTradeWebSocketAddress` - endereço do servidor WebSocket.
- `StockQuoteWebSocketAddress` - endereço do servidor WebSocket.
- `ForexWebSocketAddress` - endereço do servidor WebSocket.
- `CryptoWebSocketAddress` - endereço do servidor WebSocket.
- `StockExchange` - código da bolsa de valores utilizado nos pedidos.
