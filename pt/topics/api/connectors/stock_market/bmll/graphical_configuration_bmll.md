# Configuração gráfica BMLL

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da ligação é efetuada na [Janela de definições de ligação](../../../graphical_user_interface/connection_settings_window.md):

- `AuthenticationMode` - método de autenticação.
- `Login` - nome de utilizador da conta.
- `PrivateKeyPath` - caminho do ficheiro da chave privada.
- `Password` - palavra-passe da conta.
- `Token` - token de acesso à API.
- `ApiKey` - chave da API.
- `Address` - endereço da API REST.
- `AuthenticationAddress` - ponto de acesso do serviço de autenticação.
- `TradesDataset` - nome do conjunto de dados de negociações da BMLL.
- `Level3Dataset` - nome do conjunto de dados de nível 3 da BMLL.
