# Configuração ITCH

Para trabalhar com um conector, tem de especificar o **Login** e a **Password**. O **Login** e a **Password** são fornecidos pela corretora. Para obter acesso à API, recomenda-se contactar a corretora.

[ITCH](../itch.md) - protocolo direto de fluxo de dados que permite ligar através dos protocolos TCP e UDP. O [ITCH](../itch.md) fornece o registo de ordens para acompanhar todas as alterações a qualquer ordem. Este protocolo é utilizado pela NASDAQ (ver [TotalView-ITCH](https://www.nasdaqtrader.com/Trader.aspx?id=Totalview2) ) e pela LSE (ver [MITCH](https://www.londonstockexchange.com/) ).
