# Configuração Dow Jones

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `AuthenticationMode` - método de autenticação.
- `Token` - token de acesso à API.
- `ClientId` - identificador do cliente OAuth.
- `Login` - nome de utilizador da conta.
- `Password` - palavra-passe da conta.
- `Address` - endereço da API REST.
- `OAuthAddress` - ponto de acesso do serviço OAuth.
