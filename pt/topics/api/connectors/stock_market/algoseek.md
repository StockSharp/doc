# AlgoSeek

**AlgoSeek** - um conector para obter dados de mercado de um provedor.

Antes de começar a escrever robôs de negociação para a plataforma de negociação atual, recomenda-se ler os links em [Conectores](../../connectors.md).

> [!CAUTION]
> O conector fornece dados de mercado e não permite o envio de ordens.
