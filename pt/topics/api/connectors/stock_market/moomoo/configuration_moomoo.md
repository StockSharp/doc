# Configuração do conector Moomoo

Obtenha as credenciais, os endereços dos servidores e os identificadores da conta necessários para a Moomoo OpenAPI e OpenD e indique as seguintes definições do conector.

- **Endereço** - propriedade `Address`. Valor predefinido: `127.0.0.1:11111`.
- **Palavra-passe** - propriedade `Password`.
- **Modo de demonstração** - propriedade `IsDemo`. Valor predefinido: `true`.
