# Configuração do conector: SinoPac Shioaji

Prepare o gateway local ou o cliente do fornecedor e indique os parâmetros de conexão.

- `Address` - endereço do serviço. Valor predefinido: `http://localhost:8080/`.
- `Key` - credencial de autenticação.
- `Secret` - credencial de autenticação.
- `ReconnectAttempts` - parâmetro numérico do conector. Valor predefinido: `10`.
