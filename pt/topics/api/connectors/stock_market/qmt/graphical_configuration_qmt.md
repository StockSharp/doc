# Configuração gráfica: QMT

Em todos os produtos StockSharp, a conexão é configurada na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md).

- `GatewayHost` - endereço do serviço. Valor predefinido: `127.0.0.1`.
- `GatewayPort` - parâmetro numérico do conector. Valor predefinido: `58630`.
- `GatewayToken` - credencial de autenticação.
- `ReconnectAttempts` - parâmetro numérico do conector. Valor predefinido: `10`.
- `RequestTimeout` - intervalo de tempo. Valor predefinido: `30`.
