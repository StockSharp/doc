# SimFin

**SimFin** conecta o StockSharp à SimFin Web API v3 para dados de empresas, preços e fundamentos.

## Principais recursos

- Recursos verificados no código-fonte: pesquisa de empresas, preços diários de nível 1, velas diárias e fundamentos estruturados por `SimFinDataTypes.Fundamentals`. O adaptador é histórico e não oferece negociação.
- Transportes, sessões e formatos específicos do provedor ficam ocultos atrás da API padrão do StockSharp.

## Uso típico

Use este conector para baixar preços diários, demonstrações financeiras, valores derivados e indicadores opcionais das empresas suportadas.

A cobertura, o histórico, os campos, os limites e a disponibilidade dependem do plano da SimFin.
