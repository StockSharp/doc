# Configuração gráfica: kabu Station

Em todos os produtos StockSharp, a conexão é configurada na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md).

- `ApiPassword` - credencial de autenticação.
- `IsDemo` - interruptor que controla o comportamento do conector. Valor predefinido: `true`.
- `DefaultAccountType` - modo ou opção do conector. Valor predefinido: `KabuStationAccountTypes.Specified`.
- `DefaultStockOrderExchange` - parâmetro de conexão. Valor predefinido: `KabuStationExchanges.Sor`.
