# Configuração gráfica Phillip POEMS

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da ligação é efetuada na [Janela de definições de ligação](../../../graphical_user_interface/connection_settings_window.md):

- `ClientId` - identificador do cliente OAuth.
- `ClientSecret` - segredo do cliente OAuth.
- `ApiKey` - chave da API.
- `AccessToken` - token de acesso OAuth.
- `RefreshToken` - token de atualização OAuth.
- `AccountNo` - número da conta de corretagem.
