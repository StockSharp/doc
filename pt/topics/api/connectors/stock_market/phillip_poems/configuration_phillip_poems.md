# Configuração Phillip POEMS

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `ClientId` - identificador do cliente OAuth.
- `ClientSecret` - segredo do cliente OAuth.
- `ApiKey` - chave da API.
- `AccessToken` - token de acesso OAuth.
- `RefreshToken` - token de atualização OAuth.
- `AccountNo` - número da conta de corretagem.
