# Configuração gráfica Tiingo

Para todos os produtos [S#](../../../../api.md), a configuração gráfica da ligação é efetuada na [Janela de definições de ligação](../../../graphical_user_interface/connection_settings_window.md):

- `Token` - token de acesso à API.
- `Address` - endereço da API REST.
- `IexWebSocketAddress` - endereço do servidor WebSocket.
- `ForexWebSocketAddress` - endereço do servidor WebSocket.
- `CryptoWebSocketAddress` - endereço do servidor WebSocket.
- `EquityStreamingMode` - modo de transmissão de dados de ações em tempo real.
