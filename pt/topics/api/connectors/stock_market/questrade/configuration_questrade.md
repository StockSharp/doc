# Configuração do conector Questrade

Obtenha as credenciais, os endereços dos servidores e os identificadores da conta necessários para a Questrade API e indique as seguintes definições do conector.

- **Token de acesso** - propriedade `AccessToken`.
- **Token de atualização** - propriedade `RefreshToken`.
- **Servidor de API** - propriedade `ApiServer`.
- **Conta** - propriedade `Account`.
