# Configuração gráfica da TradeZero

Em todos os produtos StockSharp, configure a ligação na [janela de definições de ligação](../../../graphical_user_interface/connection_settings_window.md).

- **Chave** - o identificador da chave de API da TradeZero.
- **Segredo** - o segredo da API da TradeZero.
- **Rota predefinida** - a rota de ordens preferencial. Deixe-a vazia para selecionar automaticamente uma rota compatível.
