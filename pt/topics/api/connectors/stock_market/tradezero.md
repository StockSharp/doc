# TradeZero

**TradeZero** é uma corretora para negociar ações dos EUA e opções de uma só perna.

O conector suporta o registo e cancelamento de ordens, bem como o cancelamento com substituição, dados da conta, posições, ordens atuais e lucros e perdas. As atualizações da conta são transmitidas por WebSocket. As cotações, o livro de ofertas e as velas são devolvidos como instantâneos REST finitos, porque a TradeZero não disponibiliza um WebSocket público para dados de mercado.

Antes de desenvolver robôs de negociação para a TradeZero, consulte as ligações na secção [Conectores](../../connectors.md).
