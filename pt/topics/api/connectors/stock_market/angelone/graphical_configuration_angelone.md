# Configuração gráfica de Angel One

Em todos os produtos StockSharp, configure a ligação na [janela de definições de ligação](../../../graphical_user_interface/connection_settings_window.md).

- **Nome de utilizador** - propriedade `Login`.
- **Palavra-passe** - propriedade `Password`.
- **Chave de API** - propriedade `ApiKey`.
- **Segredo TOTP** - propriedade `TotpSecret`.
- **Endereço IP local do cliente** - propriedade `ClientLocalIp`. Valor predefinido: `127.0.0.1`.
- **Endereço IP público do cliente** - propriedade `ClientPublicIp`.
- **Endereço MAC** - propriedade `MacAddress`.
- **Produto predefinido** - propriedade `DefaultProduct`. Valor predefinido: `Delivery`.
