# SSI

**SSI** conecta o StockSharp à SSI FastConnect API v3 para os mercados vietnamitas HOSE, HNX e UPCOM.

## Principais recursos

- Recursos verificados no código-fonte: cotações de nível 1, livros de ofertas e negócios em tempo real, velas e consultas históricas, além de operações de carteira e ordens para ações e futuros.
- Transportes, sessões e formatos específicos do provedor ficam ocultos atrás da API padrão do StockSharp.

## Uso típico

Use este conector para monitorar instrumentos vietnamitas, analisar dados de mercado, solicitar histórico e executar os fluxos de negociação suportados.

Os instrumentos disponíveis, a profundidade histórica, as permissões, os limites e a disponibilidade dependem da SSI e da conta conectada.
