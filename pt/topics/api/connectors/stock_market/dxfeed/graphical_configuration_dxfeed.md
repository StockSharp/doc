# Configuração gráfica: dxFeed

Em todos os produtos StockSharp, a conexão é configurada na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md).

- `Address` - endereço do serviço. Valor predefinido: `wss://demo.dxfeed.com/dxlink-ws`.
- `Token` - credencial de autenticação.
- `AggregationPeriod` - intervalo de tempo.
- `MarketDepthLevels` - parâmetro numérico do conector. Valor predefinido: `20`.
- `MarketDepthSources` - parâmetro de conexão. Valor predefinido: `NTV`.
