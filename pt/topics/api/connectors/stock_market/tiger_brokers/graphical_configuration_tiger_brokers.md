# Configuração gráfica de Tiger Brokers

Em todos os produtos StockSharp, configure a ligação na [janela de definições de ligação](../../../graphical_user_interface/connection_settings_window.md).

- **Identificador Tiger** - propriedade `TigerId`.
- **Conta** - propriedade `Account`.
- **Licença** - propriedade `License`. Valor predefinido: `Singapore`.
- **Chave privada** - propriedade `PrivateKey`.
- **Token** - propriedade `Token`.
- **Obter automaticamente a permissão de cotações** - propriedade `AutoGrabPermission`. Valor predefinido: `true`.
