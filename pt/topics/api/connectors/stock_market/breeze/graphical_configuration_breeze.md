# Configuração gráfica de ICICI Direct Breeze

Em todos os produtos StockSharp, configure a ligação na [janela de definições de ligação](../../../graphical_user_interface/connection_settings_window.md).

- **Chave de API** - propriedade `ApiKey`.
- **Chave secreta** - propriedade `SecretKey`.
- **Sessão de API** - propriedade `ApiSession`.
