# IIFL

**IIFL** conecta o StockSharp à IIFL Markets Open API para os mercados indianos à vista e de derivativos.

## Principais recursos

- Recursos verificados no código-fonte: pesquisa de instrumentos, cotações de nível 1, livros de ofertas e negócios em tempo real, velas históricas, além de operações de carteira e ordens para ações, futuros e opções.
- Transportes, sessões e formatos específicos do provedor ficam ocultos atrás da API padrão do StockSharp.

## Uso típico

Use este conector para monitorar instrumentos indianos, analisar cotações, livros e velas, solicitar histórico e executar os fluxos de ordens suportados.

As bolsas, os instrumentos, a profundidade histórica, as permissões e os limites dependem da IIFL e da conta conectada.
