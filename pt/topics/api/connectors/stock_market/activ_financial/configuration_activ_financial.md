# Configuração ACTIV Financial

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Login` - nome de utilizador da conta.
- `Password` - palavra-passe da conta.
- `Host` - servidor do gateway ACTIV.
- `DataSource` - fonte de dados de mercado a utilizar.
- `NodePath` - caminho do nó do gateway ACTIV.
- `GatewayDirectory` - caminho do diretório de instalação do gateway ACTIV.
