# Configuração do conector: IQFeed

Prepare o gateway local ou o cliente do fornecedor e indique os parâmetros de conexão.

- `Login` - identificador da conta ou do cliente.
- `Password` - credencial de autenticação.
- `Level1Address` - endereço do serviço.
- `Level2Address` - endereço do serviço.
- `LookupAddress` - endereço do serviço.
- `AdminAddress` - endereço do serviço.
- `DerivativeAddress` - endereço do serviço.
- `Level1Columns` - parâmetro de conexão.
- `IsDownloadSecurityFromSite` - interruptor que controla o comportamento do conector.
- `SecuritiesFile` - caminho para um ficheiro ou diretório local.
- `Version` - parâmetro de conexão. Valor predefinido: `6.2`.
