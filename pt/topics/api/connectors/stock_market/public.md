# Public.com

**Public.com** integra a **API da Public.com** no StockSharp para obter dados de mercado e negociar.

O conector suporta pesquisa de instrumentos, cotações, velas históricas, contas, saldos e posições, gestão de ordens, consulta REST para subscrições, ordens de opções com várias pernas.

Antes de desenvolver robôs de negociação para Public.com, consulte as ligações na secção [Conectores](../../connectors.md).
