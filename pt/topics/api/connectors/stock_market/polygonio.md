# PolygonIO

**PolygonIO** - fornecedor de dados de mercado em tempo real e históricos sobre ações, forex (FX) e moedas digitais/criptomoedas. 

Antes de começar a escrever robôs de negociação para a plataforma de negociação atual, recomenda-se ler as ligações na secção [Conectores](../../connectors.md). 

> [!CAUTION]
> O conector suporta apenas a fonte de dados de mercado; as transações não são suportadas.
