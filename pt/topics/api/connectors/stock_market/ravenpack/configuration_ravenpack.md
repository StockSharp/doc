# Configuração RavenPack

Informe nas configurações do conector os parâmetros de conexão fornecidos pelo serviço.

## Parâmetros de conexão

- `Token` - token de acesso à API.
- `Product` - produto da RavenPack a solicitar.
- `DatasetId` - identificador do conjunto de dados solicitado.
- `Address` - endereço da API REST.
- `FeedAddress` - ponto de acesso do fluxo de notícias em tempo real.
