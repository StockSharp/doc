# Configuração gráfica: Groww

Em todos os produtos StockSharp, a conexão é configurada na [janela de configurações de conexão](../../../graphical_user_interface/connection_settings_window.md).

- `AccessToken` - credencial de autenticação.
- `ApiKey` - credencial de autenticação.
- `ApiSecret` - credencial de autenticação.
- `TotpSecret` - credencial de autenticação.
- `DefaultProduct` - modo ou opção do conector. Valor predefinido: `GrowwProducts.Delivery`.
