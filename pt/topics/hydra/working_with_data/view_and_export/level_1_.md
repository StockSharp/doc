# Level 1 

Na janela que aparece, selecione os instrumentos, o intervalo temporal necessário e clique no botão ![hydra find](../../../../images/hydra_find.png):

![hydra exportar Visualização nível1](../../../../images/hydra_export_level1.png)

Também pode escolher que tipos de alterações devem ser exportados. Isto é feito usando a lista pendente mostrada abaixo: 

![hydra export alterar instrumento selecionado](../../../../images/hydra_export_security_change_selected.png)

Os valores recebidos podem ser [exportados para o formato necessário](../export_data.md).
