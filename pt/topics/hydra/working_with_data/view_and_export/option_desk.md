# Option desk

Na janela que aparece, selecione o intervalo temporal pretendido, escolha o ativo subjacente, adicione as opções correspondentes e clique no botão ![hydra find](../../../../images/hydra_find.png):

Se não houver histórico, mas existirem dados sobre o spread, pode calcular as principais Greeks (Delta, Gamma, Vega, Theta, Rho, Volatility (implied)); para isso, é necessário selecioná-las no campo **Calculate Greeks**. 

![hydra option desk](../../../../images/hydra_option_desk.png)

Para ver o **Volatility Smile**, é necessário ir ao separador **Volatility Smile**.

![hydra option smile of volatility](../../../../images/hydra_option_smile_of_volatility.png)

Os valores calculados podem ser [exportados para o formato necessário](../export_data.md).
