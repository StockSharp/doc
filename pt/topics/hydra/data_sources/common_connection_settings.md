# Definições comuns de ligação

Propriedades de ligação comuns a todas as fontes.

![hydra settings connectionparams](../../../images/hydra_settings_connectionparams.png)

**Ligação**

- **Connection** - Definições de ligação.
- **Title** - Nome da tarefa.
- **Start date (ticks)** - Data a partir da qual iniciar a transferência dos dados.
- **Work from** - Hora de início.
- **Work until** - Hora de fim.
- **Interval of work** - Intervalo de funcionamento.
- **Data directory** - Diretório com os dados onde serão guardados os ficheiros finais no formato StockSharp.
- **Format** - Formato dos dados: BIN\/CSV.
- **Max. errors** - Número máximo de erros após o qual a tarefa será parada. A predefinição é 0, o que significa ignorar o número de erros.
- **News** - Transferir notícias.
- **Dependency** - Tarefa que deve ser concluída antes de iniciar a atual.
- **Update securities** - Atualizar instrumentos ao estabelecer ligação.
