# Fontes de dados

[Hydra](../hydra.md) tem ligações a várias fontes de dados. Para além de receber dados históricos, o programa pode receber dados de mercado de brokers, sendo esses dados recebidos em tempo real. A ligação às fontes é efetuada através dos conectores fornecidos ao utilizador.

São disponibilizados ao utilizador conectores gratuitos, e também é possível adquirir conectores pagos, que permitem receber dados de mercado a partir de fontes pagas.

Atualmente, [Hydra](../hydra.md) suporta as seguintes fontes:
