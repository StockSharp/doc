# Recuperação

Pode restaurar os dados do armazenamento de duas formas:

- Descarregar os objetos armazenados a partir da consola da AWS. Para o fazer, clique com o botão direito do rato no objeto e selecione **Download** no menu de contexto.![Aws3 download](../../../../images/aws3_download.png)

  > [!TIP]
  > Este método permite descarregar apenas um objeto (ficheiro) de cada vez.
- Utilizar a aplicação gratuita [S3 Browser](https://s3browser.com/) para descarregar os dados.
