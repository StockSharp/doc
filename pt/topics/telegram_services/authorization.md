# Autorização

Para ativar o [StockSharpBot](https://t.me/StockSharpBot), precisa de o iniciar e prosseguir com a autorização para que o bot possa reconhecer o seu login no site StockSharp. Para isso, selecione o comando **/login** no menu:

![TelegramActivating](../../images/telegramactivating.png)

O bot irá pedir-lhe que visite o seu perfil em [https://stocksharp.com/profile/](https://stocksharp.com/profile/) e copie o token a partir daí.

![Profile](../../images/profile.png)

Depois, envie-o de volta ao bot no chat no formato **token: %your_token%**. Se for bem-sucedido, o bot irá dirigir-se a si pelo nome que usou para se registar no site StockSharp.

![TelegramActivated](../../images/telegramactivated.png)
