# Códigos-fonte

Atualmente, o núcleo [S#](../api.md) é desenvolvido no âmbito da comunidade Open Source, está disponível como código-fonte e encontra-se alojado no repositório [GitHub\/StockSharp](https://github.com/StockSharp/StockSharp). 

[Instruções para usar o GitHub](https://stocksharp.com/forum/4848/rukovodstvo-po-github/)

Lista de componentes disponíveis com código-fonte:

- Classes comuns para criar as suas próprias ligações.
- Formato do armazenamento de dados de mercado.
- Simulador de negociação.
- Simulador histórico (backtester).
- Indicadores (mais de 70) de análise técnica.
- Algoritmos para calcular lucro-prejuízo, slippage e atraso.
- Algoritmos para construir candles de qualquer período, bem como candles não baseados no tempo (tick, range, etc.).
- Registo.
- Importação e exportação.

Os códigos-fonte de todos os componentes fechados, bem como dos programas prontos a usar, estão disponíveis mediante compra. Para mais informações sobre o custo dos códigos-fonte, consulte [Custo do código-fonte](https://stocksharp.com/store/?groups=22).
