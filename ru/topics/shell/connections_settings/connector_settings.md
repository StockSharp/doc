# Настройки коннекторов

Коннекторам S# Shell перед подключением может требоваться настройка параметров конкретного провайдера. Общий каталог настроек содержит ссылки на отдельные руководства по подключению и графическому конфигурированию.

См. [Настройки коннекторов](../../designer/connections_settings/connectors_settings.md).
