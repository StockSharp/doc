# Общие настройки

Окно **Настройки** открывается пунктом **Файл \=\> Настройки** или кнопкой настроек на панели команд [Hydra](../../hydra.md). Настройки в нём разделены на группы:

- **Вид**:
  - **Темная** \- тёмная тема оформления;
  - **Часовой пояс** \- в каком часовом поясе показывается время маркет\-данных;
  - **Язык** \- язык программы.
- **Основные**:
  - **Автостарт** \- запускать скачивание при запуске программы;
  - **Трей** \- сворачивать окно в трей;
  - **Время для автостопа** \- время, в которое Hydra останавливает скачивание;
  - **Индекс** \- интервал перестройки индекса хранилища (см. [Синхронизация данных](synchronization.md));
  - **Диалоги** \- показывать окно с ошибкой, которую программа не обработала сама; если флажок снят, такая ошибка только записывается в журнал.
- **CSV**:
  - **Шаблон** \- шаблоны, по которым данные записываются в файлы CSV.
- **Почта**:
  - **Ошибки (кол\-во)** \- количество ошибок, после которых будет отправлено электронное письмо с сообщением об ошибке; значение 0 отключает отправку;
  - **Почта** \- адрес, на который отправляется письмо;
  - **От** \- адрес отправителя письма.
