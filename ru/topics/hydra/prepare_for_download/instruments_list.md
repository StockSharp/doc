# Настройка инструмента для скачивания

Настройка инструмента для скачивания.

Для ряда источников существует возможность сделать настройки для скачивания нужных инструментов.

Рассмотрим на примере скачивания инструментов с источника **ByBit**:

1. Нажимаем **Скачать инструменты**. По умолчанию отмечен пункт **Все** \- будут скачаны все инструменты источника.![Hydra выбор инструментов](../../../images/hydra_choose_securitiy.png)
2. Снимаем отметку **Все** и отмечаем **Доп условия**. После этого раскроется список расширенных настроек для скачиваемого инструмента; отметка **Общее** возвращает краткий список.![Hydra выбор инструментов 00](../../../images/hydra_choose_securitiy_00.png)
3. Нужно скачать инструменты, в коде которых есть BTC. Для этого указываем BTC в поле **Код** и нажимаем **OK**.![Hydra выбор инструментов 01](../../../images/hydra_choose_securitiy_01.png)

   После этого программа [Hydra](../../hydra.md) скачает все инструменты, отвечающие установленным параметрам, и сообщит, сколько из них новых. ![Hydra выбор инструментов 02](../../../images/hydra_choose_securitiy_02.png)![Hydra выбор инструментов 03](../../../images/hydra_choose_securitiy_03.png)

Настройка позволяет пользователю выбрать различные параметры для загружаемого инструмента.

Так, например, пользователь может выбрать:

- **Шаг цены и объема**
- **Минимальный и максимальный объемы**
- **Внешний идентификатор** ![Hydra выбор инструментов 04](../../../images/hydra_choose_securitiy_04.png)
- Для опционов позволяет настроить **Базовый актив** и **Тип актива** (тип базового инструмента).![Hydra выбор инструментов 05](../../../images/hydra_choose_securitiy_05.png)
