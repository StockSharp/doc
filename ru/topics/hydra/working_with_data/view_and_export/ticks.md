# Сделки (Тики)

В появившемся окне выбрать интересуемый диапазон времени, выбрать инструмент и нажать кнопку ![Hydra кнопка поиска](../../../../images/hydra_find.png):

![hydra экспорт сделок](../../../../images/hydra_export_trades.png)

Для выгрузки внесистемных сделок необходимо установить галочку в поле **Внесистемные**.

Полученные значения можно [экспортировать в нужный формат](../export_data.md).
