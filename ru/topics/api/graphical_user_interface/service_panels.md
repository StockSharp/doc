# Служебные панели

В этом разделе собраны панели, которые не показывают рыночные данные, а настраивают работу приложения: справочники, настройки хранилища и импорта, лицензии, учётные записи и подписки.

- Правила комиссии \- [CommissionPanel](xref:StockSharp.Xaml.CommissionPanel).
- Настройки импорта \- [ImportSettingsPanel](xref:StockSharp.Xaml.ImportSettingsPanel).
- Лицензии \- [LicensePanel](xref:StockSharp.Xaml.LicensePanel).
- Поиск инструментов \- [SecurityLookupPanel](xref:StockSharp.Xaml.SecurityLookupPanel).
- Сопоставление кодов инструментов \- [SecurityMappingPanel](xref:StockSharp.Xaml.SecurityMappingPanel).
- Настройки хранилища \- [StorageSettingsPanel](xref:StockSharp.Xaml.StorageSettingsPanel).
- Подписки \- [SubscriptionPanel](xref:StockSharp.Xaml.SubscriptionPanel).
- Биржи \- [ExchangesPanel](xref:StockSharp.Xaml.ExchangesPanel).
- Площадки \- [ExchangeBoardsPanel](xref:StockSharp.Xaml.ExchangeBoardsPanel).
- Расписание работы \- [WorkingTimeControl](xref:StockSharp.Xaml.WorkingTimeControl).
- Учётные записи и права \- [PermissionCredentialsPanel](xref:StockSharp.Xaml.PermissionCredentialsPanel).
