# Диагностика

В этом разделе собраны компоненты, которые нужны при разработке и разборе поведения: список активных правил, статистика стратегии, ошибки компиляции и редактор кода.

- Таблица активных правил \- [MarketRuleGrid](xref:StockSharp.Xaml.MarketRuleGrid).
- Таблица статистических параметров \- [StatisticParameterGrid](xref:StockSharp.Xaml.StatisticParameterGrid).
- Таблица ошибок компиляции \- [ErrorsGrid](xref:StockSharp.Xaml.Code.ErrorsGrid).
- Редактор исходного кода \- [CodePanel](xref:StockSharp.Xaml.CodeEditor.CodePanel).
