# Темы графических компонентов S\#

Все графические компоненты S\# оформлены в двух темах \- светлой и тёмной. Тема задаётся один раз, на уровне приложения, и её подхватывают все компоненты сразу: цвета берутся из ресурсов, а не прописываются в каждом контроле.

Для установки темы достаточно одной строчки:

```cs
...
ThemeExtensions.ApplyDefaultTheme();
...
```

**Основные методы [ThemeExtensions](xref:StockSharp.Xaml.ThemeExtensions)**

- [ThemeExtensions.ApplyDefaultTheme](xref:StockSharp.Xaml.ThemeExtensions.ApplyDefaultTheme(System.Boolean)) \- применяет тёмную либо светлую тему.
- [ThemeExtensions.Invert](xref:StockSharp.Xaml.ThemeExtensions.Invert) \- переключает тему на противоположную.
- [ThemeExtensions.IsCurrDark](xref:StockSharp.Xaml.ThemeExtensions.IsCurrDark) \- текущая тема тёмная или нет.

Смена темы действует немедленно: перезапуск приложения не нужен, все открытые панели и графики перерисовываются в новых цветах.

Цвета, специфичные для торговых компонентов \- рост и падение, покупка и продажа, уровни стакана, сетка таблиц \- живут отдельным набором ресурсов и меняются вместе с темой. Поэтому собственный контрол, который берёт цвета из этого набора, а не задаёт их сам, будет выглядеть одинаково уместно в обеих темах.
