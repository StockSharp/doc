# Полоса (Band)

Серия-полоса рисует верхнюю и нижнюю граничные линии с заливкой канала между ними. Она естественно подходит для конвертов и полос Боллинджера, а также для любого исследования, дающего ценовой коридор.

## Живая демонстрация

```chart-demo band
```

## Настройка

Добавьте `BandSeries` и передайте ему точки `{ time, upper, lower }`:

```js
const band = chart.addSeries(SSChart.BandSeries, {
  upperColor: '#26a69a',
  lowerColor: '#ef5350',
  fillColor: 'rgba(74,158,255,0.10)',
});

band.setData(data.map(d => ({ time: d.time, upper: d.upper, lower: d.lower })));

chart.timeScale().fitContent();
```

Вычисляйте `upper`/`lower` так, как того требует исследование — для полос Боллинджера возьмите скользящую среднюю цены закрытия и прибавьте/вычтите кратное её стандартного отклонения. Наложите полосу на линейную или свечную серию, которая несёт саму цену.
