# Графическая настройка: Sierra Chart DTC

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- `Address` - адрес сервиса. Значение по умолчанию: `DefaultAddress`.
- `HistoryAddress` - адрес сервиса. Значение по умолчанию: `DefaultHistoryAddress`.
- `Login` - идентификатор счёта или клиента.
- `Password` - учётные данные для авторизации.
- `TradeAccount` - идентификатор счёта или клиента.
- `MarketDataTransmissionInterval` - временной интервал.
- `MarketDepthLevels` - количество запрашиваемых уровней стакана. Значение по умолчанию: `20`.
- `SslProtocol` - режим или вариант работы коннектора.
- `HistorySslProtocol` - режим или вариант работы коннектора.
- `IsCertificateValidation` - переключатель поведения коннектора. Значение по умолчанию: `true`.
- `TargetHost` - адрес сервиса.
