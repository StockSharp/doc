# Графическое конфигурирование Angel One

Для всех продуктов StockSharp настройка подключения выполняется в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- **Имя пользователя** - свойство `Login`.
- **Пароль** - свойство `Password`.
- **Ключ API** - свойство `ApiKey`.
- **Секрет TOTP** - свойство `TotpSecret`.
- **Локальный IP-адрес клиента** - свойство `ClientLocalIp`. Значение по умолчанию: `127.0.0.1`.
- **Публичный IP-адрес клиента** - свойство `ClientPublicIp`.
- **MAC-адрес** - свойство `MacAddress`.
- **Продукт по умолчанию** - свойство `DefaultProduct`. Значение по умолчанию: `Delivery`.
