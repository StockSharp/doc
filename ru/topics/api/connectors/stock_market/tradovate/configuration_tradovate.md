# Настройки коннектора Tradovate

Зарегистрируйте приложение API в Tradovate и укажите его учётные данные в настройках коннектора.

- **Имя пользователя** - имя пользователя Tradovate.
- **Пароль** - пароль Tradovate.
- **Идентификатор клиента** - идентификатор клиента API (`cid`).
- **Секрет** - секрет клиента API (`sec`).
- **Идентификатор приложения** - зарегистрированный идентификатор приложения. Значение по умолчанию - `StockSharp`.
- **Версия приложения** - зарегистрированная версия приложения. Значение по умолчанию - `1.0`.
- **Идентификатор устройства** - постоянный идентификатор устройства, зарегистрированный для доступа к API. Коннектор автоматически создаёт и сохраняет его.
- **Демо-режим** - подключение к демонстрационной среде Tradovate вместо реальной.
