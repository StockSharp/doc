# Графическое конфигурирование Tradovate

Для всех продуктов StockSharp настройка подключения выполняется в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- **Имя пользователя** - имя пользователя Tradovate.
- **Пароль** - пароль Tradovate.
- **Идентификатор клиента** - идентификатор клиента API.
- **Секрет** - секрет клиента API.
- **Идентификатор приложения** - зарегистрированный идентификатор приложения.
- **Версия приложения** - зарегистрированная версия приложения.
- **Идентификатор устройства** - постоянный идентификатор устройства.
- **Демо-режим** - использование демонстрационной среды.
