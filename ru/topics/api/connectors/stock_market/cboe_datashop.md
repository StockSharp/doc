# Cboe DataShop / LiveVol

**Cboe DataShop / LiveVol** - коннектор для получения рыночных данных от поставщика.

До того, как приступить к написанию торговых роботов под текущую торговую платформу, рекомендуется ознакомиться с ссылками, приведенными в пункте [Коннекторы](../../connectors.md).

> [!CAUTION]
> Коннектор предоставляет рыночные данные и не поддерживает отправку заявок.
