# Kotak Neo

**Kotak Neo** обеспечивает подключение StockSharp к **API Kotak Neo v2 для торговли** для получения рыночных данных и торговли.

Коннектор поддерживает поиск инструментов, котировки, сделки, стаканы, счета, денежные остатки и позиции, работу с заявками, обновления счетов и заявок в реальном времени.

До начала разработки торговых роботов для Kotak Neo рекомендуется ознакомиться со ссылками в разделе [Коннекторы](../../connectors.md).
