# Настройки коннектора tastytrade

Получите необходимые для tastytrade Open API учётные данные, адреса серверов и идентификаторы счёта, затем укажите следующие настройки коннектора.

- **Токен** - свойство `Token`.
- **Секрет клиента** - свойство `ClientSecret`.
- **Области доступа** - свойство `Scopes`.
- **Демо-режим** - свойство `IsDemo`.
