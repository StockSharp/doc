# Настройки коннектора: Daishin CYBOS Plus

Подготовьте локальный шлюз или клиент поставщика и укажите параметры подключения.

- `Account` - идентификатор счёта или клиента.
- `Market` - режим или вариант работы коннектора. Значение по умолчанию: `DaishinStockMarkets.Consolidated`.
- `IsTradingEnabled` - переключатель поведения коннектора. Значение по умолчанию: `true`.
