# Настройки коннектора IG Markets

Получите необходимые для REST API и потоковый API IG учётные данные, адреса серверов и идентификаторы счёта, затем укажите следующие настройки коннектора.

- **Ключ API** - свойство `ApiKey`.
- **Имя пользователя** - свойство `UserName`.
- **Пароль** - свойство `Password`.
- **Идентификатор счёта** - свойство `AccountId`.
- **Среда** - свойство `Environment`. Значение по умолчанию: `Demo`.
- **Шифрование пароля** - свойство `EncryptPassword`.
