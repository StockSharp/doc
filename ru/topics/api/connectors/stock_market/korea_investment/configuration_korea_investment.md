# Настройки коннектора: Korea Investment & Securities

Получите учётные данные у поставщика и укажите параметры подключения.

- `AppKey` - учётные данные для авторизации.
- `AppSecret` - учётные данные для авторизации.
- `AccountNumber` - параметр подключения.
- `ProductCode` - идентификатор счёта или клиента. Значение по умолчанию: `01`.
- `HtsId` - идентификатор счёта или клиента.
- `IsDemo` - переключатель поведения коннектора. Значение по умолчанию: `true`.
