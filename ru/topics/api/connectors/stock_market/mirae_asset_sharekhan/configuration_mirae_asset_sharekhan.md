# Настройки коннектора: Mirae Asset Sharekhan

Получите учётные данные у поставщика и укажите параметры подключения.

- `ApiKey` - учётные данные для авторизации.
- `Token` - учётные данные для авторизации.
- `VendorKey` - учётные данные для авторизации.
- `CustomerId` - идентификатор счёта или клиента.
- `DefaultProduct` - режим или вариант работы коннектора. Значение по умолчанию: `MiraeSharekhanProducts.Investment`.
