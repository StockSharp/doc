# Графическое конфигурирование: KRX Open API

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

Основной раздел редактора подключения содержит:

- `Token`
- `IsDemo`
- `DataSet`

Остальные свойства задаются в расширенном режиме и описаны на странице [Настройки коннектора](configuration_krx_open_api.md). Не меняйте заполненные адреса провайдера, если он не выдал другие значения.
