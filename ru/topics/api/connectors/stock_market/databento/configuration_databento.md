# Настройки коннектора: Databento

Получите учётные данные у поставщика и укажите параметры подключения.

- `Key` - учётные данные для авторизации.
- `Dataset` - параметр подключения. Значение по умолчанию: `GLBX.MDP3`.
- `LiveAddress` - адрес сервиса.
- `HistoricalAddress` - адрес сервиса. Значение по умолчанию: `https://hist.databento.com/v0/timeseries.get_range`.
- `Symbology` - режим или вариант работы коннектора. Значение по умолчанию: `DatabentoSymbologyTypes.RawSymbol`.
