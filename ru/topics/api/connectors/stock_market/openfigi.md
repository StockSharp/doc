# OpenFIGI

**OpenFIGI** подключает StockSharp к OpenFIGI API v3 для глобального поиска идентификаторов финансовых инструментов.

## Основные возможности

- Возможности, проверенные по исходному коду: поиск и фильтрация инструментов по бирже, MIC, валюте, сектору рынка и типу бумаги. Адаптер возвращает метаданные и не предоставляет котировки или торговые операции.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для сопоставления внешних идентификаторов с записями FIGI и формирования нормализованного справочника инструментов.

Покрытие результатов, лимиты и анонимный либо авторизованный доступ определяются OpenFIGI.
