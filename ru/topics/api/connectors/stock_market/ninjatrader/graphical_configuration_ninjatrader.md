# Графическое конфигурирование NinjaTrader

Для всех продуктов StockSharp настройка подключения выполняется в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- **Имя пользователя** - свойство `Login`.
- **Пароль** - свойство `Password`.
- **Идентификатор клиента** - свойство `ClientId`.
- **Секрет** - свойство `Secret`.
- **Идентификатор приложения** - свойство `AppId`. Значение по умолчанию: `StockSharp`.
- **Версия приложения** - свойство `AppVersion`. Значение по умолчанию: `1.0`.
- **Идентификатор устройства** - свойство `DeviceId`.
- **Демо-режим** - свойство `IsDemo`.
