# Настройки коннектора: Fubon Neo

Установите официальный клиентский комплект разработчика и укажите путь к нему, учётные данные и остальные параметры подключения.

- `SdkPath` - путь к локальному файлу или каталогу.
- `PersonalId` - идентификатор счёта или клиента.
- `Password` - учётные данные для авторизации.
- `ApiKey` - учётные данные для авторизации.
- `IsApiKeyLogin` - переключатель поведения коннектора.
- `CertificatePath` - путь к локальному файлу или каталогу.
- `CertificatePassword` - учётные данные для авторизации.
- `EnvironmentUrl` - адрес сервиса.
- `RealtimeMode` - режим или вариант работы коннектора. Значение по умолчанию: `FubonNeoRealtimeModes.Normal`.
- `ReconnectAttempts` - максимальное количество попыток переподключения. Значение по умолчанию: `10`.
