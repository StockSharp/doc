# Настройки коннектора BMLL

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `AuthenticationMode` - способ аутентификации.
- `Login` - логин учётной записи.
- `PrivateKeyPath` - путь к файлу закрытого ключа.
- `Password` - пароль учётной записи.
- `Token` - токен доступа к API.
- `ApiKey` - ключ API.
- `Address` - адрес REST API.
- `AuthenticationAddress` - адрес службы аутентификации.
- `TradesDataset` - имя набора данных BMLL по сделкам.
- `Level3Dataset` - имя набора данных BMLL уровня 3.
