# Графическая настройка: Swissquote OpenWealth

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- `Token` - учётные данные для авторизации.
- `CustomerId` - идентификатор счёта или клиента.
- `SafekeepingAccountId` - идентификатор счёта или клиента.
- `CashAccountId` - идентификатор счёта или клиента.
- `AccountCurrency` - параметр подключения. Значение по умолчанию: `CHF`.
- `IsDemo` - переключатель поведения коннектора. Значение по умолчанию: `true`.
- `IsDryRun` - переключатель поведения коннектора.
- `IsBestEffort` - переключатель поведения коннектора.
