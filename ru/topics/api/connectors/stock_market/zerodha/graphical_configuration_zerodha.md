# Графическая настройка: Zerodha Kite Connect

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- `ApiKey` - учётные данные для авторизации.
- `ApiSecret` - учётные данные для авторизации.
- `Token` - учётные данные для авторизации.
- `RequestToken` - учётные данные для авторизации.
- `DefaultProduct` - режим или вариант работы коннектора. Значение по умолчанию: `ZerodhaProducts.Intraday`.
