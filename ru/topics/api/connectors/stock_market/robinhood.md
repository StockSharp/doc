# Robinhood

**Robinhood** обеспечивает подключение StockSharp к **агентская торговля Robinhood** для получения рыночных данных и торговли.

Коннектор поддерживает поиск инструментов, котировки, исторические свечи, счета, денежные остатки и позиции, работу с заявками, опрос REST API для подписок.

До начала разработки торговых роботов для Robinhood рекомендуется ознакомиться со ссылками в разделе [Коннекторы](../../connectors.md).
