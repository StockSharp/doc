# Графическая настройка: Bloomberg BLPAPI and EMSX

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- `ServerAddress` - адрес сервиса. Значение по умолчанию: `new DnsEndPoint("localhost", 8194)`.
- `SdkPath` - путь к локальному файлу или каталогу.
- `IsEmsxEnabled` - переключатель поведения коннектора.
- `EmsxService` - параметр подключения. Значение по умолчанию: `//blp/emapisvc`.
- `Broker` - параметр подключения.
