# Настройки коннектора CQG Web API

Получите необходимые для CQG Web API 2.296 учётные данные, адреса серверов и идентификаторы счёта, затем укажите следующие настройки коннектора.

- **Имя пользователя** - свойство `UserName`.
- **Пароль** - свойство `Password`.
- **Одноразовый пароль** - свойство `OneTimePassword`.
- **Токен доступа** - свойство `AccessToken`.
- **Идентификатор организации** - свойство `PrivateLabel`. Значение по умолчанию: `WebAPITest`.
- **Идентификатор клиента** - свойство `ClientId`. Значение по умолчанию: `WebAPITest`.
- **Версия клиента** - свойство `ClientVersion`. Значение по умолчанию: `StockSharp 5`.
- **Конечная точка** - свойство `Endpoint`. Значение по умолчанию: `wss://demoapi.cqg.com:443`.
- **Портфель** - свойство `Portfolio`.
- **Уровень агрегации** - свойство `CollapsingLevel`. Значение по умолчанию: `None`.
