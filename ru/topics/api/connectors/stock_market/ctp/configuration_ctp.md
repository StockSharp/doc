# Настройки коннектора CTP

Получите необходимые для API CTP для торговли и рыночных данных учётные данные, адреса серверов и идентификаторы счёта, затем укажите следующие настройки коннектора.

- **Имя пользователя** - свойство `Login`.
- **Пароль** - свойство `Password`.
- **Идентификатор брокера** - свойство `BrokerId`.
- **Идентификатор инвестора** - свойство `InvestorId`.
- **Адрес сервера рыночных данных** - свойство `MarketDataAddress`.
- **Адрес торгового сервера** - свойство `TraderAddress`.
- **Идентификатор приложения** - свойство `AppId`.
- **Код аутентификации** - свойство `AuthCode`.
- **Сведения о продукте** - свойство `ProductInfo`. Значение по умолчанию: `StockSharp`.
- **Режим восстановления** - свойство `ResumeType`. Значение по умолчанию: `Quick`.
- **Рабочий режим** - свойство `ProductionMode`. Значение по умолчанию: `true`.
- **Каталог данных** - свойство `DataPath`.
- **Интервал запросов** - свойство `QueryInterval`. Значение по умолчанию: `1 s`.
- **Тайм-аут подключения** - свойство `ConnectionTimeout`. Значение по умолчанию: `30 s`.
