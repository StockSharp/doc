# CQG

**CQG Web API** обеспечивает подключение StockSharp к **CQG Web API 2.296** для получения рыночных данных и торговли.

Коннектор поддерживает поиск инструментов, котировки, сделки, стаканы, исторические свечи, свечи реального времени, счета, денежные остатки и позиции, работу с заявками, обновления счетов и заявок в реальном времени, учебную и реальную среды.

До начала разработки торговых роботов для CQG Web API рекомендуется ознакомиться со ссылками в разделе [Коннекторы](../../connectors.md).
