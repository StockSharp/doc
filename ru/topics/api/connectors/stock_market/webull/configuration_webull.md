# Настройки коннектора Webull

Для работы с коннектором создайте приложение в [Webull OpenAPI](https://developer.webull.com/apis/docs/) и получите его учетные данные.

- **Ключ** (`Key`) — ключ приложения Webull OpenAPI.
- **Секрет** (`Secret`) — секрет приложения.
- **Токен** (`Token`) — необязательный токен доступа.
- **Счет** (`Account`) — идентификатор торгового счета. Если значение не задано, коннектор запрашивает список счетов автоматически.
- **Демо-режим** (`IsDemo`) — использование тестового окружения Webull.

Параметры `Token` и `Account` можно не задавать, если они не требуются для вашего приложения и счета Webull.
