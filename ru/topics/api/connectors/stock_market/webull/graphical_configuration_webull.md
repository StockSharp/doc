# Графическое конфигурирование Webull

Для всех продуктов StockSharp графическая настройка подключения выполняется в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- **Ключ** (`Key`) — ключ приложения.
- **Секрет** (`Secret`) — секрет приложения.
- **Токен** (`Token`) — необязательный токен доступа.
- **Счет** (`Account`) — идентификатор торгового счета.
- **Демо-режим** (`IsDemo`) — использование тестового окружения.
