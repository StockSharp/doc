# Графическое конфигурирование: Jainam

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

Основной раздел редактора подключения содержит:

- `UserId`
- `AppCode`
- `ApiSecret`
- `AuthCode`
- `Token`

Остальные свойства задаются в расширенном режиме и описаны на странице [Настройки коннектора](configuration_jainam.md). Не меняйте заполненные адреса провайдера, если он не выдал другие значения.
