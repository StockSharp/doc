# SSI

**SSI** подключает StockSharp к SSI FastConnect API v3 для вьетнамских площадок HOSE, HNX и UPCOM.

## Основные возможности

- Возможности, проверенные по исходному коду: котировки Level 1, стаканы и сделки в реальном времени, свечи и исторические запросы, а также портфельные и торговые операции с акциями и фьючерсами.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для мониторинга вьетнамских инструментов, анализа рыночных данных, запроса истории и выполнения поддерживаемых торговых сценариев.

Доступные инструменты, глубина истории, торговые права, лимиты запросов и доступность определяются SSI и подключённым счётом.
