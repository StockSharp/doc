# tastytrade

**tastytrade** обеспечивает подключение StockSharp к **tastytrade Open API** для получения рыночных данных и торговли.

Коннектор поддерживает поиск инструментов, котировки, сделки, исторические свечи, свечи реального времени, счета, денежные остатки и позиции, работу с заявками, обновления счетов и заявок в реальном времени, учебную и реальную среды, многоногие опционные заявки.

До начала разработки торговых роботов для tastytrade рекомендуется ознакомиться со ссылками в разделе [Коннекторы](../../connectors.md).
