# Настройки коннектора TradeLocker

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `Login` - логин учётной записи.
- `Password` - пароль учётной записи.
- `Server` - адрес сервера TradeLocker.
- `AccountId` - идентификатор счёта, назначенный сервисом.
- `IsDemo` - режим демонстрационной среды.
