# Настройки коннектора: Motilal Oswal

Получите учётные данные у поставщика и укажите параметры подключения.

- `Key` - учётные данные для авторизации.
- `Secret` - учётные данные для авторизации.
- `Token` - учётные данные для авторизации.
- `AccessToken` - учётные данные для авторизации.
- `ClientCode` - идентификатор счёта или клиента.
- `LocalIp` - параметр подключения. Значение по умолчанию: `127.0.0.1`.
- `PublicIp` - параметр подключения. Значение по умолчанию: `127.0.0.1`.
- `MacAddress` - адрес сервиса. Значение по умолчанию: `00:00:00:00:00:00`.
- `VendorInfo` - параметр подключения.
- `InstalledAppId` - идентификатор счёта или клиента.
- `IsDemo` - переключатель поведения коннектора.
- `DefaultProduct` - режим или вариант работы коннектора. Значение по умолчанию: `MotilalOswalProducts.Normal`.
- `AlgoId` - идентификатор счёта или клиента.
- `ReconnectAttempts` - числовой параметр коннектора. Значение по умолчанию: `10`.
