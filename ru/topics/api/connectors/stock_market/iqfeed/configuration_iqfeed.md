# Настройки коннектора: IQFeed

Подготовьте локальный шлюз или клиент поставщика и укажите параметры подключения.

- `Login` - идентификатор счёта или клиента.
- `Password` - учётные данные для авторизации.
- `Level1Address` - адрес сервиса.
- `Level2Address` - адрес сервиса.
- `LookupAddress` - адрес сервиса.
- `AdminAddress` - адрес сервиса.
- `DerivativeAddress` - адрес сервиса.
- `Level1Columns` - параметр подключения.
- `IsDownloadSecurityFromSite` - переключатель поведения коннектора.
- `SecuritiesFile` - путь к локальному файлу или каталогу.
- `Version` - параметр подключения. Значение по умолчанию: `6.2`.
