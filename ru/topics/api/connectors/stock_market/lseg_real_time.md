# LSEG Real-Time

**LSEG Real-Time** подключает StockSharp к официальному интерфейсу **LSEG Real-Time WebSocket API**.

Коннектор поддерживает поиск инструментов, а также получение рыночных данных в реальном времени и за прошлые периоды.

Перед разработкой торговых роботов ознакомьтесь с материалами раздела [Коннекторы](../../connectors.md).
