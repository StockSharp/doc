# Настройки коннектора TradeZero

Создайте ключи API в личном кабинете TradeZero и укажите их в настройках коннектора.

- **Ключ** - значение `TZ-API-KEY-ID`.
- **Секрет** - значение `TZ-API-SECRET-KEY`.
- **Маршрут по умолчанию** - необязательный предпочтительный маршрут заявки, возвращаемый методом получения маршрутов счёта.

Если маршрут по умолчанию не указан, коннектор автоматически выбирает совместимый активный маршрут. Учебные и реальные счета используют один адрес API, а среда определяется учётными данными.
