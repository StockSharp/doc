# Графическое конфигурирование TradeZero

Для всех продуктов StockSharp настройка подключения выполняется в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- **Ключ** - идентификатор ключа API TradeZero.
- **Секрет** - секрет API TradeZero.
- **Маршрут по умолчанию** - предпочтительный маршрут заявки. Оставьте поле пустым для автоматического выбора совместимого маршрута.
