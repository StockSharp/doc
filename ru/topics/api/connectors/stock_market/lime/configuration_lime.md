# Настройки коннектора Lime Trader

Получите необходимые для API Lime учётные данные, адреса серверов и идентификаторы счёта, затем укажите следующие настройки коннектора.

- **Имя пользователя** - свойство `Login`.
- **Пароль** - свойство `Password`.
- **Идентификатор клиента** - свойство `ClientId`.
- **Секрет клиента** - свойство `ClientSecret`.
