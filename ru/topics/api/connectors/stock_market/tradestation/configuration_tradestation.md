# Настройки коннектора TradeStation

Получите необходимые для TradeStation API v3 учётные данные, адреса серверов и идентификаторы счёта, затем укажите следующие настройки коннектора.

- **Токен** - свойство `Token`.
- **Демо-режим** - свойство `IsDemo`.
- **Маршрут по умолчанию** - свойство `DefaultRoute`. Значение по умолчанию: `Intelligent`.
