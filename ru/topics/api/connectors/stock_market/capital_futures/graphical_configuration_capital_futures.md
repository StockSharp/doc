# Графическая настройка: Capital Futures

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- `SdkPath` - путь к локальному файлу или каталогу.
- `Login` - идентификатор счёта или клиента.
- `Password` - учётные данные для авторизации.
- `Account` - идентификатор счёта или клиента.
- `Environment` - режим или вариант работы коннектора. Значение по умолчанию: `CapitalFuturesEnvironments.Production`.
- `IsTradingEnabled` - переключатель поведения коннектора. Значение по умолчанию: `true`.
- `LogPath` - путь к локальному файлу или каталогу.
