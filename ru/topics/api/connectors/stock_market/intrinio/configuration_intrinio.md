# Настройки коннектора Intrinio

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `Token` - токен доступа к API.
- `Address` - адрес REST API.
- `EquityProvider` - поставщик данных по акциям Intrinio.
- `OptionProvider` - поставщик данных по опционам Intrinio.
- `IsDelayedOptions` - использовать ли данные по опционам с задержкой.
