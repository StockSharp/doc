# Настройки коннектора: SinoPac Shioaji

Подготовьте локальный шлюз или клиент поставщика и укажите параметры подключения.

- `Address` - адрес сервиса. Значение по умолчанию: `http://localhost:8080/`.
- `Key` - учётные данные для авторизации.
- `Secret` - учётные данные для авторизации.
- `ReconnectAttempts` - числовой параметр коннектора. Значение по умолчанию: `10`.
