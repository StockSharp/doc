# MarketData.app

**MarketData.app** подключает StockSharp к MarketData.app для американских акций, фондов, индексов и опционов.

## Основные возможности

- Возможности, проверенные по исходному коду: поиск инструментов и опционных контрактов, данные Level 1 и исторические свечи с учётом расширенных торговых часов и корректировок на сплиты. Торговые операции не поддерживаются.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для поиска инструментов США, получения котировок и загрузки свечей по акциям и опционам.

Покрытие, задержка, глубина истории, лимиты контрактов и доступность зависят от тарифа MarketData.app.
