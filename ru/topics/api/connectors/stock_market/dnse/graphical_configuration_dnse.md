# Графическое конфигурирование: DNSE

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

Основной раздел редактора подключения содержит:

- `Key`
- `Secret`
- `TradingToken`
- `Account`

Остальные свойства задаются в расширенном режиме и описаны на странице [Настройки коннектора](configuration_dnse.md). Не меняйте заполненные адреса провайдера, если он не выдал другие значения.
