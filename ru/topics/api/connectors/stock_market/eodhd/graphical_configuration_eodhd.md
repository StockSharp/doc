# Графическое конфигурирование EOD Historical Data

Для всех продуктов [S\#](../../../../api.md) графическая настройка подключения выполняется в экранной форме [Окно настройки подключений](../../../graphical_user_interface/connection_settings_window.md):

- `Token` - токен доступа к API.
- `Address` - адрес REST API.
- `StockTradeWebSocketAddress` - адрес сервера WebSocket.
- `StockQuoteWebSocketAddress` - адрес сервера WebSocket.
- `ForexWebSocketAddress` - адрес сервера WebSocket.
- `CryptoWebSocketAddress` - адрес сервера WebSocket.
- `StockExchange` - код фондовой биржи для выполнения запросов.
