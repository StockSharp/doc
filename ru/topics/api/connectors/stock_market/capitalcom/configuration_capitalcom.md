# Настройки коннектора: Capital.com

Получите учётные данные у поставщика и укажите параметры подключения.

- `ApiKey` - учётные данные для авторизации.
- `Login` - идентификатор счёта или клиента.
- `Password` - учётные данные для авторизации.
- `AccountId` - идентификатор счёта или клиента.
- `IsDemo` - переключатель поведения коннектора. Значение по умолчанию: `true`.
- `IsPasswordEncryptionEnabled` - переключатель поведения коннектора.
