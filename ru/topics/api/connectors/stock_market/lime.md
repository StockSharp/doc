# Lime Trader

**Lime Trader** обеспечивает подключение StockSharp к **API Lime** для получения рыночных данных и торговли.

Коннектор поддерживает поиск инструментов, котировки, исторические свечи, счета, денежные остатки и позиции, работу с заявками, обновления счетов и заявок в реальном времени.

До начала разработки торговых роботов для Lime Trader рекомендуется ознакомиться со ссылками в разделе [Коннекторы](../../connectors.md).
