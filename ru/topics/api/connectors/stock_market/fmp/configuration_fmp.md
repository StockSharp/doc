# Настройки коннектора Financial Modeling Prep

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `Token` - токен доступа к API.
- `Address` - адрес REST API.
- `StockWebSocketAddress` - адрес сервера WebSocket.
- `ForexWebSocketAddress` - адрес сервера WebSocket.
- `CryptoWebSocketAddress` - адрес сервера WebSocket.
