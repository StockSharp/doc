# Настройки коннектора Longbridge OpenAPI

Получите необходимые для Longbridge OpenAPI учётные данные, адреса серверов и идентификаторы счёта, затем укажите следующие настройки коннектора.

- **Ключ приложения** - свойство `AppKey`.
- **Секрет приложения** - свойство `AppSecret`.
- **Токен доступа** - свойство `AccessToken`.
- **Портфель** - свойство `Portfolio`. Значение по умолчанию: `Longbridge`.
- **Адрес API** - свойство `ApiUrl`. Значение по умолчанию: `https://openapi.longbridge.com`.
- **Адрес сервера котировок** - свойство `QuoteUrl`. Значение по умолчанию: `wss://openapi-quote.longbridge.com/v2`.
- **Адрес торгового сервера** - свойство `TradeUrl`. Значение по умолчанию: `wss://openapi-trade.longbridge.com/v2`.
