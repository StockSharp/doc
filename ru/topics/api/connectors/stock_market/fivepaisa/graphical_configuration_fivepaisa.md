# Графическая настройка: 5paisa Xstream

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- `AppKey` - учётные данные для авторизации.
- `ClientCode` - идентификатор счёта или клиента.
- `Token` - учётные данные для авторизации.
- `DefaultProduct` - режим или вариант работы коннектора. Значение по умолчанию: `FivePaisaProducts.Intraday`.
- `AlgoId` - идентификатор алгоритма, выданный брокером.
- `ReconnectAttempts` - максимальное количество попыток переподключения. Значение по умолчанию: `10`.
