# Настройки коннектора Charles Schwab

Для работы с коннектором создайте приложение с доступом к [Charles Schwab Trader API](https://developer.schwab.com/products/trader-api--individual) и получите OAuth-токен.

- **Токен** (`Token`) — действующий OAuth-токен доступа.
- **Адрес** (`Address`) — адрес Trader API. Значение по умолчанию: `https://api.schwabapi.com/`.

Адрес WebSocket и идентификаторы потокового подключения коннектор получает автоматически. OAuth-токен необходимо обновлять в соответствии с правилами Charles Schwab.
