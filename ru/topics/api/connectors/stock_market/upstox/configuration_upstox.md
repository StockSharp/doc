# Настройки коннектора Upstox

Получите необходимые для Upstox API v3 учётные данные, адреса серверов и идентификаторы счёта, затем укажите следующие настройки коннектора.

- **Токен** - свойство `Token`.
- **Демо-режим** - свойство `IsDemo`.
- **Продукт по умолчанию** - свойство `DefaultProduct`. Значение по умолчанию: `Delivery`.
