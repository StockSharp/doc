# Графическая настройка: SnapTrade

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- `ClientId` - идентификатор счёта или клиента.
- `ConsumerKey` - учётные данные для авторизации.
- `UserId` - идентификатор счёта или клиента.
- `UserSecret` - учётные данные для авторизации.
- `AccountId` - идентификатор счёта или клиента.
- `PollingInterval` - временной интервал. Значение по умолчанию: `TimeSpan.FromMinutes(1)`.
