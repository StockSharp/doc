# Настройки коннектора Moomoo

Получите необходимые для Moomoo OpenAPI и OpenD учётные данные, адреса серверов и идентификаторы счёта, затем укажите следующие настройки коннектора.

- **Адрес** - свойство `Address`. Значение по умолчанию: `127.0.0.1:11111`.
- **Пароль** - свойство `Password`.
- **Демо-режим** - свойство `IsDemo`. Значение по умолчанию: `true`.
