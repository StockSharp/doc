# TradeZero

**TradeZero** - брокер для торговли акциями США и одиночными опционами.

Коннектор поддерживает регистрацию, отмену и замену заявок через отмену и повторную регистрацию, а также получение данных счёта, позиций, текущих заявок и прибыли и убытков. Обновления счёта передаются через WebSocket. Котировки, стаканы и свечи возвращаются как конечные REST-снимки, поскольку TradeZero не предоставляет публичный WebSocket для маркет-данных.

До начала разработки торговых роботов для TradeZero рекомендуется ознакомиться со ссылками в разделе [Коннекторы](../../connectors.md).
