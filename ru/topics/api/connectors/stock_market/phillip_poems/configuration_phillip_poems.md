# Настройки коннектора Phillip POEMS

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `ClientId` - идентификатор клиента OAuth.
- `ClientSecret` - секрет клиента OAuth.
- `ApiKey` - ключ API.
- `AccessToken` - токен доступа OAuth.
- `RefreshToken` - токен обновления OAuth.
- `AccountNo` - номер брокерского счёта.
