# J-Quants

**J-Quants** подключает StockSharp к J-Quants API V2 для получения данных Токийской фондовой биржи.

## Основные возможности

- Возможности, проверенные по исходному коду: поиск акций, фьючерсов и опционов TSE, значения Level 1, сделки и исторические свечи. Адаптер предоставляет только рыночные данные и не поддерживает транзакции.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для поиска японских инструментов и загрузки котировок, сделок и истории свечей для исследований и анализа.

Покрытие, глубина истории, лимиты запросов и доступность определяются тарифом J-Quants.
