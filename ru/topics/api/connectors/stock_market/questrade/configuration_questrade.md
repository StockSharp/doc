# Настройки коннектора Questrade

Получите необходимые для Questrade API учётные данные, адреса серверов и идентификаторы счёта, затем укажите следующие настройки коннектора.

- **Токен доступа** - свойство `AccessToken`.
- **Токен обновления** - свойство `RefreshToken`.
- **Сервер API** - свойство `ApiServer`.
- **Счёт** - свойство `Account`.
