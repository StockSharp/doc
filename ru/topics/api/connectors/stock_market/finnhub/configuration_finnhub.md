# Настройки коннектора Finnhub

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `Token` - токен доступа к API.
- `Address` - адрес REST API.
- `WebSocketAddress` - адрес сервера WebSocket.
- `StockExchange` - код фондовой биржи для выполнения запросов.
- `ForexExchange` - код валютной площадки в Finnhub.
- `CryptoExchange` - код криптовалютной площадки в Finnhub.
