# Графическая настройка: dxFeed

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- `Address` - адрес сервиса. Значение по умолчанию: `wss://demo.dxfeed.com/dxlink-ws`.
- `Token` - учётные данные для авторизации.
- `AggregationPeriod` - временной интервал.
- `MarketDepthLevels` - числовой параметр коннектора. Значение по умолчанию: `20`.
- `MarketDepthSources` - параметр подключения. Значение по умолчанию: `NTV`.
