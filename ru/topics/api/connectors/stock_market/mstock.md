# m.Stock

**m.Stock** подключает StockSharp к m.Stock API для индийских спотовых и срочных рынков.

## Основные возможности

- Возможности, проверенные по исходному коду: поиск инструментов, котировки Level 1, стаканы и сделки в реальном времени, исторические свечи, а также портфельные и торговые операции с акциями, фьючерсами и опционами.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для мониторинга индийских инструментов, анализа котировок, стаканов и свечей, запроса истории и выполнения поддерживаемых торговых сценариев.

Доступные биржи и инструменты, глубина истории, торговые права и лимиты запросов определяются m.Stock и подключённым счётом.
