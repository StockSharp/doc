# Open DART

Коннектор **Open DART** подключает StockSharp к сервису финансовых данных и справочной информации. Он переводит данные провайдера в единую модель сообщений StockSharp, поэтому приложения могут использовать одинаковые подписки и рабочие процессы для разных источников данных.

## Основные возможности

- Типичные рынки и инструменты: акции и справочные данные об эмитентах.
- Поиск инструментов и получение справочных данных провайдера.
- Поддерживаемые провайдером рыночные данные, сведения о компаниях, отчётность, раскрытия и справочная информация.
- Поддерживаемые адаптером рыночные данные: котировки Level 1, финансовые новости и финансовые раскрытия.
- Запросы исторических данных для графиков, анализа и тестирования стратегий.
- Адаптер предназначен для доступа к данным и не маршрутизирует заявки.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для справочников инструментов, мониторинга раскрытий, исследования эмитентов, задач комплаенса и исторического анализа.

Доступные инструменты, глубина данных, торговые разрешения, лимиты запросов и доступность сервиса определяются Open DART, тарифом API и правами подключённого счёта.
