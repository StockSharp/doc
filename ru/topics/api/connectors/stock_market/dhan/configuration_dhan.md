# Настройки коннектора DhanHQ

Получите необходимые для DhanHQ API v2 учётные данные, адреса серверов и идентификаторы счёта, затем укажите следующие настройки коннектора.

- **Идентификатор клиента** - свойство `ClientId`.
- **Токен** - свойство `Token`.
- **Продукт по умолчанию** - свойство `DefaultProduct`. Значение по умолчанию: `Intraday`.
