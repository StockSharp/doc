# Settrade

**Settrade** подключает StockSharp к Settrade Open API v2 для акций Фондовой биржи Таиланда и деривативов TFEX. Адаптер предоставляет поддерживаемые рыночные данные и транзакционные операции через стандартную модель сообщений StockSharp.

## Основные возможности

- Возможности адаптера, проверенные по исходному коду: обновления данных в реальном времени, котировки Level 1, стаканы заявок, свечные данные, запросы исторических данных, портфельные и торговые операции для счетов акций и деривативов.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для мониторинга инструментов SET и TFEX, анализа котировок, стаканов и свечей, запроса истории и выполнения поддерживаемых торговых сценариев.

Доступные инструменты, глубина данных, торговые разрешения, лимиты запросов и доступность сервиса определяются Settrade, брокером и подключённым счётом.
