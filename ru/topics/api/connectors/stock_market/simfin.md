# SimFin

**SimFin** подключает StockSharp к SimFin Web API v3 для получения данных компаний, цен и фундаментальных показателей.

## Основные возможности

- Возможности, проверенные по исходному коду: поиск компаний, дневные значения Level 1, дневные свечи и структурированные фундаментальные данные через `SimFinDataTypes.Fundamentals`. Адаптер исторический и не поддерживает торговлю.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для загрузки дневных цен, финансовой отчётности, расчётных значений и дополнительных коэффициентов по поддерживаемым компаниям.

Покрытие компаний, история, поля, лимиты запросов и доступность зависят от тарифа SimFin.
