# SEC EDGAR

**SEC EDGAR** подключает StockSharp к официальным сервисам данных и отчётности SEC EDGAR.

## Основные возможности

- Возможности, проверенные по исходному коду: поиск публичных компаний, новости о поданных формах, исторические файлы отчётности и структурированные факты через `SecEdgarDataTypes.CompanyFacts`. Торговые операции не поддерживаются.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для поиска эмитентов SEC и сбора отчётности, новостей и фактов XBRL для исследований.

Покрытие и доступность определяются данными SEC EDGAR, правилами добросовестного доступа и заданными лимитами запросов.
