# Графическая настройка: QMT

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- `GatewayHost` - адрес сервиса. Значение по умолчанию: `127.0.0.1`.
- `GatewayPort` - числовой параметр коннектора. Значение по умолчанию: `58630`.
- `GatewayToken` - учётные данные для авторизации.
- `ReconnectAttempts` - числовой параметр коннектора. Значение по умолчанию: `10`.
- `RequestTimeout` - временной интервал. Значение по умолчанию: `30`.
