# Настройки коннектора: XBRL Filings

Перед подключением к XBRL Filings задайте перечисленные ниже свойства адаптера. Список проверен по реализации [XbrlFilingsMessageAdapter](xref:StockSharp.XbrlFilings.XbrlFilingsMessageAdapter).

## Основные настройки

Эти параметры показываются первыми в редакторе подключения.

- `Address` (`Uri`)

## Дополнительные настройки

Эти свойства управляют адресами, фильтрами, ограничениями и другими параметрами, зависящими от провайдера.

- `PublicAddress` (`Uri`)
- `Country` (`string`)
- `PageSize` (`int`)
- `MaxPages` (`int`)
