# Настройки коннектора: Flattrade

Получите учётные данные у поставщика и укажите параметры подключения.

- `UserId` - идентификатор счёта или клиента.
- `AccountId` - идентификатор счёта или клиента.
- `Token` - учётные данные для авторизации.
- `DefaultProduct` - режим или вариант работы коннектора. Значение по умолчанию: `FlattradeProducts.Delivery`.
- `ReconnectAttempts` - числовой параметр коннектора. Значение по умолчанию: `10`.
