# Графическое конфигурирование Zhongtai XTP

Для всех продуктов StockSharp настройка подключения выполняется в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- **Имя пользователя** - свойство `Login`.
- **Пароль** - свойство `Password`.
- **Идентификатор клиента** - свойство `ClientId`. Значение по умолчанию: `1`.
- **Адрес сервера котировок** - свойство `QuoteAddress`.
- **Адрес торгового сервера** - свойство `TransactionAddress`.
- **Протокол** - свойство `Protocol`. Значение по умолчанию: `TCP`.
- **Локальный адрес** - свойство `LocalAddress`.
- **Ключ программного обеспечения** - свойство `SoftwareKey`.
- **Версия программного обеспечения** - свойство `SoftwareVersion`. Значение по умолчанию: `1.0`.
- **Каталог данных** - свойство `DataPath`.
