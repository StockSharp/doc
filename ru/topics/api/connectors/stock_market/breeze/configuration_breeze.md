# Настройки коннектора ICICI Direct Breeze

Получите необходимые для ICICI Direct Breeze API учётные данные, адреса серверов и идентификаторы счёта, затем укажите следующие настройки коннектора.

- **Ключ API** - свойство `ApiKey`.
- **Секретный ключ** - свойство `SecretKey`.
- **Сессия API** - свойство `ApiSession`.
