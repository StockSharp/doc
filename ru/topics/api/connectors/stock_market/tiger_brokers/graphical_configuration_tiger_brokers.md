# Графическое конфигурирование Tiger Brokers

Для всех продуктов StockSharp настройка подключения выполняется в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- **Идентификатор Tiger** - свойство `TigerId`.
- **Счёт** - свойство `Account`.
- **Лицензия** - свойство `License`. Значение по умолчанию: `Singapore`.
- **Закрытый ключ** - свойство `PrivateKey`.
- **Токен** - свойство `Token`.
- **Автоматическое получение разрешения на котировки** - свойство `AutoGrabPermission`. Значение по умолчанию: `true`.
