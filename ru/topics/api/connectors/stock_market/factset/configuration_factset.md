# Настройки коннектора FactSet

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `AuthenticationMode` - способ аутентификации.
- `Login` - логин учётной записи.
- `Password` - пароль учётной записи.
- `OAuthConfigFile` - путь к файлу конфигурации OAuth.
