# Графическое конфигурирование Saxo OpenAPI

Для всех продуктов StockSharp настройка подключения выполняется в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- **Токен доступа** - свойство `AccessToken`.
- **Токен обновления** - свойство `RefreshToken`.
- **Идентификатор клиента** - свойство `ClientId`.
- **Секрет клиента** - свойство `ClientSecret`.
- **URI перенаправления** - свойство `RedirectUri`.
- **Ключ счёта** - свойство `AccountKey`.
- **Среда** - свойство `Environment`. Значение по умолчанию: `Simulation`.
