# Графическое конфигурирование: IIFL

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

Основной раздел редактора подключения содержит:

- `Key`
- `Secret`
- `ClientId`

Остальные свойства задаются в расширенном режиме и описаны на странице [Настройки коннектора](configuration_iifl.md). Не меняйте заполненные адреса провайдера, если он не выдал другие значения.
