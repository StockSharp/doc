# Настройки коннектора: kabu Station

Подготовьте локальный шлюз или клиент поставщика и укажите параметры подключения.

- `ApiPassword` - учётные данные для авторизации.
- `IsDemo` - переключатель поведения коннектора. Значение по умолчанию: `true`.
- `DefaultAccountType` - режим или вариант работы коннектора. Значение по умолчанию: `KabuStationAccountTypes.Specified`.
- `DefaultStockOrderExchange` - параметр подключения. Значение по умолчанию: `KabuStationExchanges.Sor`.
