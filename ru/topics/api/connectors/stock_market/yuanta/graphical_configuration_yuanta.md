# Графическая настройка: Yuanta SPARK

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- `SdkPath` - путь к локальному файлу или каталогу.
- `Account` - идентификатор счёта или клиента.
- `Password` - учётные данные для авторизации.
- `CertificatePath` - путь к локальному файлу или каталогу.
- `CertificatePassword` - учётные данные для авторизации.
- `Environment` - режим или вариант работы коннектора. Значение по умолчанию: `YuantaEnvironments.Production`.
- `LogPath` - путь к локальному файлу или каталогу.
- `ReconnectAttempts` - числовой параметр коннектора. Значение по умолчанию: `10`.
