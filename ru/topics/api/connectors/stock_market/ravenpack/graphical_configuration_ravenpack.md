# Графическое конфигурирование RavenPack

Для всех продуктов [S\#](../../../../api.md) графическая настройка подключения выполняется в экранной форме [Окно настройки подключений](../../../graphical_user_interface/connection_settings_window.md):

- `Token` - токен доступа к API.
- `Product` - запрашиваемый продукт RavenPack.
- `DatasetId` - идентификатор запрашиваемого набора данных.
- `Address` - адрес REST API.
- `FeedAddress` - адрес потока новостей в реальном времени.
