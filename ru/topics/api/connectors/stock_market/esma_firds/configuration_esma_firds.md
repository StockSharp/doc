# Настройки коннектора: ESMA FIRDS

Перед подключением к ESMA FIRDS задайте перечисленные ниже свойства адаптера. Список проверен по реализации [EsmaFirdsMessageAdapter](xref:StockSharp.EsmaFirds.EsmaFirdsMessageAdapter).

## Основные настройки

Эти параметры показываются первыми в редакторе подключения.

- `Address` (`Uri`)

## Дополнительные настройки

Эти свойства управляют адресами, фильтрами, ограничениями и другими параметрами, зависящими от провайдера.

- `CfiCategories` (`string`)
- `ActiveOnly` (`bool`)
- `MaxResults` (`int`)
