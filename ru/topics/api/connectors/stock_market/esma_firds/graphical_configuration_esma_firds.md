# Графическое конфигурирование: ESMA FIRDS

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

Основной раздел редактора подключения содержит:

- `Address`

Остальные свойства задаются в расширенном режиме и описаны на странице [Настройки коннектора](configuration_esma_firds.md). Не меняйте заполненные адреса провайдера, если он не выдал другие значения.
