# lemon.markets

**lemon.markets** подключает StockSharp к официальному интерфейсу **брокерский API lemon.markets**.

Коннектор поддерживает получение сведений о счёте и операции с заявками.

Перед разработкой торговых роботов ознакомьтесь с материалами раздела [Коннекторы](../../connectors.md).
