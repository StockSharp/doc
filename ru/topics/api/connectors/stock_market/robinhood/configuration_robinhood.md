# Настройки коннектора Robinhood

Получите необходимые для агентская торговля Robinhood учётные данные, адреса серверов и идентификаторы счёта, затем укажите следующие настройки коннектора.

- **Токен** - свойство `Token`.
- **Адрес** - свойство `Address`. Значение по умолчанию: `https://agent.robinhood.com/mcp/trading`.
- **Интервал опроса** - свойство `PollingInterval`. Значение по умолчанию: `2 s`.
