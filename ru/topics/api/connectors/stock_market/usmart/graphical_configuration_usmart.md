# Графическое конфигурирование uSMART OpenAPI

Для всех продуктов [S\#](../../../../api.md) графическая настройка подключения выполняется в экранной форме [Окно настройки подключений](../../../graphical_user_interface/connection_settings_window.md):

- `AccessToken` - токен доступа OAuth.
- `ChannelId` - идентификатор канала подключения uSMART.
- `PrivateKey` - закрытый ключ для подписи транзакций.
- `FundAccount` - идентификатор фондового счёта uSMART.
