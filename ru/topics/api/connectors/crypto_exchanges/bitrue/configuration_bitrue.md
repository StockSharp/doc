# Настройки коннектора Bitrue

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `Key` - ключ API.
- `Secret` - секретный ключ API.
- `SpotRestEndpoint` - адрес REST API.
- `SpotStreamRestEndpoint` - адрес REST API.
- `SpotPublicWsEndpoint` - адрес сервера WebSocket.
- `SpotPrivateWsEndpoint` - адрес сервера WebSocket.
- `FuturesRestEndpoint` - адрес REST API.
- `FuturesStreamRestEndpoint` - адрес REST API.
- `FuturesPublicWsEndpoint` - адрес сервера WebSocket.
- `FuturesPrivateWsEndpoint` - адрес сервера WebSocket.
