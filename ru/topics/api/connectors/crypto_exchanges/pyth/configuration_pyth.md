# Настройки коннектора Pyth

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `Token` - токен доступа к API.
- `HistoryEndpoint` - адрес API исторических данных.
- `RouterEndpoint` - адрес REST API последних цен.
- `WebSocketEndpoint1` - основной адрес WebSocket данных в реальном времени.
- `WebSocketEndpoint2` - резервный адрес WebSocket данных в реальном времени.
- `WebSocketEndpoint3` - третий адрес WebSocket данных в реальном времени.
- `Channel` - канал данных Pyth.
