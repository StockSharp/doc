# STON.fi

**STON.fi** подключает StockSharp к автоматизированному маркет-мейкеру STON.fi в сети TON. Адаптер предоставляет поддерживаемые рыночные данные и транзакционные операции через стандартную модель сообщений StockSharp.

## Основные возможности

- Возможности адаптера, проверенные по исходному коду: обновления данных в реальном времени, котировки Level 1, обезличенные сделки, свечные данные, запросы исторических данных, портфельные и торговые операции.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для мониторинга пулов STON.fi, анализа исполняемых котировок, сделок и свечей, запроса истории и выполнения поддерживаемых обменов.

Доступные пулы, глубина данных, разрешения на транзакции, лимиты запросов и доступность сервиса определяются STON.fi, сервисами TON и подключённым кошельком.
