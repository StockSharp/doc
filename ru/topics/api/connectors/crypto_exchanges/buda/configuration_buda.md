# Настройки коннектора: Buda

Перед подключением к Buda задайте перечисленные ниже свойства адаптера. Список проверен по реализации [BudaMessageAdapter](xref:StockSharp.Buda.BudaMessageAdapter).

## Основные настройки

Эти параметры показываются первыми в редакторе подключения.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
