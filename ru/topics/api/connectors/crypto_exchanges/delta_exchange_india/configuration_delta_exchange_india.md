# Настройки коннектора: Delta Exchange India

Перед подключением к Delta Exchange India задайте перечисленные ниже свойства адаптера. Список проверен по реализации [DeltaExchangeIndiaMessageAdapter](xref:StockSharp.DeltaExchangeIndia.DeltaExchangeIndiaMessageAdapter).

## Основные настройки

Эти параметры показываются первыми в редакторе подключения.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `PublicWebSocketEndpoint` (`string`)
- `PrivateWebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
