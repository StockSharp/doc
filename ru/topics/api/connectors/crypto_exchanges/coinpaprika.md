# CoinPaprika

**CoinPaprika** подключает StockSharp к сервису криптовалютных рыночных данных CoinPaprika. Адаптер предоставляет данные провайдера через стандартную модель сообщений StockSharp.

## Основные возможности

- Возможности адаптера, проверенные по исходному коду: обновления данных в реальном времени, котировки Level 1, свечные данные, запросы исторических данных.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.
- Адаптер предназначен для доступа к данным и не маршрутизирует заявки.

## Для чего подходит

Коннектор подходит для наполнения графиков и хранилищ, аналитики, исследований и тестирования стратегий на данных провайдера.

Доступные инструменты, глубина данных, разрешения на транзакции, лимиты запросов и доступность сервиса определяются CoinPaprika, тарифом API и правами подключённого счёта.
