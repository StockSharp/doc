# Настройки коннектора Injective

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `Environment` - среда подключения: основная или тестовая сеть.
- `WalletAddress` - общедоступный адрес блокчейн-кошелька для операций со счетом.
- `PrivateKey` - закрытый ключ для локальной подписи запросов и транзакций.
