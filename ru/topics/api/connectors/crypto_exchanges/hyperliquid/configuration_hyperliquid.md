# Настройки коннектора Hyperliquid

Для работы с коннектором необходимо указать данные кошелька для торговых действий.

Основные настройки:

- **Адрес кошелька**.
- **Приватный ключ**.
- **Адрес хранилища** (опционально).
- **Истекает после** (опционально).
- **Секция**: `Spot` или `Derivatives`.
- режим **тестовой сети**.
- **Конечная точка Info / Exchange / WS**.
- **Рыночное проскальзывание** для рыночных заявок.

Официальная документация API:

- [Hyperliquid API](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api)
- [Конечная точка Info](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/info-endpoint)
- [Конечная точка Exchange](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/exchange-endpoint)
- [Websocket](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/websocket)
