# Графическое конфигурирование Hyperliquid

Для всех продуктов [S\#](../../../../api.md) графическая настройка подключения выполняется в форме [Окно настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

Основные поля:

- **Адрес кошелька** - адрес кошелька (`0x...`).
- **Приватный ключ** - приватный ключ для подписанных действий.
- **Адрес хранилища** - опциональный адрес хранилища или субаккаунта.
- **Истекает после** - опциональная метка времени истечения подписи.
- **Секция** - торговая секция (`Spot` или `Derivatives`).
- **Тестовая сеть** - адреса тестовых конечных точек.
- **Конечная точка Info / Exchange / WS** - адреса конечных точек.
- **Рыночное проскальзывание** - значение проскальзывания по умолчанию для рыночных заявок.
