# Настройки коннектора: NovaDAX

Перед подключением к NovaDAX задайте перечисленные ниже свойства адаптера. Список проверен по реализации [NovaDaxMessageAdapter](xref:StockSharp.NovaDax.NovaDaxMessageAdapter).

## Основные настройки

Эти параметры показываются первыми в редакторе подключения.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `AccountId` (`string`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `EngineIoVersion` (`int`)
