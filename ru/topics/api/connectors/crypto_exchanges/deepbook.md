# DeepBook

**DeepBook** подключает StockSharp к децентрализованному протоколу DeepBook. Адаптер предоставляет поддерживаемые рыночные данные и транзакционные операции через стандартную модель сообщений StockSharp.

## Основные возможности

- Возможности адаптера, проверенные по исходному коду: обновления данных в реальном времени, котировки Level 1, стаканы Level 2, обезличенные сделки, портфельные и торговые операции.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для мониторинга децентрализованных рынков, анализа котировок и транзакционных сценариев, реализованных адаптером протокола.

Доступные инструменты, глубина данных, разрешения на транзакции, лимиты запросов и доступность сервиса определяются DeepBook, тарифом API и правами подключённого счёта.
