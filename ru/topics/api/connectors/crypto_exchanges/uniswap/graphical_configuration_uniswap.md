# Графическое конфигурирование Uniswap

Для всех продуктов [S\#](../../../../api.md) графическая настройка подключения выполняется в экранной форме [Окно настройки подключений](../../../graphical_user_interface/connection_settings_window.md):

- `Token` - токен доступа к API.
- `GraphApiKey` - ключ API The Graph.
- `WalletAddress` - адрес блокчейн-кошелька.
- `PrivateKey` - закрытый ключ для подписи транзакций.
- `Chain` - сеть блокчейна для выполнения запросов.
- `RouterVersion` - версия маршрутизатора децентрализованной биржи.
- `RpcEndpoint` - адрес RPC-узла блокчейна.
- `TradingEndpoint` - адрес торгового API.
