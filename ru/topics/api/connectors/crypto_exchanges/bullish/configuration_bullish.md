# Настройки коннектора Bullish

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `Key` - ключ API.
- `Secret` - секретный ключ API.
- `TradingAccountId` - идентификатор торгового счёта.
- `RateLimitToken` - токен Bullish для определения лимитов запросов к API.
- `RestEndpoint` - адрес REST API.
- `WsEndpoint` - адрес сервера WebSocket.
