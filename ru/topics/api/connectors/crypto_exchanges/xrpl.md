# XRPL DEX

**XRPL DEX** подключает StockSharp к децентрализованной бирже, встроенной в XRP Ledger. Адаптер предоставляет поддерживаемые рыночные данные и транзакционные операции через стандартную модель сообщений StockSharp.

## Основные возможности

- Возможности адаптера, проверенные по исходному коду: обновления данных в реальном времени, котировки Level 1, обезличенные сделки, стаканы заявок, свечные данные, запросы исторических данных, портфельные и торговые операции.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для мониторинга рынков XRPL, анализа котировок, сделок, стаканов и свечей, запроса истории и отправки поддерживаемых предложений.

Доступные рынки, глубина данных, разрешения на транзакции, лимиты запросов и доступность сервиса определяются узлами XRP Ledger и подключённым счётом.
