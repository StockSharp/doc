# Bit2Me

**Bit2Me** — коннектор для спотовой криптовалютной биржи Bit2Me Pro. Он поддерживает публичные рыночные данные, исторические свечи, балансы счёта и торговые операции через REST и WebSocket API.

Перед разработкой торговых роботов для этой площадки ознакомьтесь с разделом [Коннекторы](../../connectors.md).
