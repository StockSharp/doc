# Графическое конфигурирование CoinMarketCap

Для всех продуктов [S\#](../../../../api.md) графическая настройка подключения выполняется в экранной форме [Окно настройки подключений](../../../graphical_user_interface/connection_settings_window.md):

- `AccessMode` - режим доступа CoinMarketCap: без ключа или по ключу API.
- `Token` - токен доступа к API.
- `ApiEndpoint` - адрес REST API.
- `SocketEndpoint` - адрес WebSocket API.
- `QuoteCurrency` - валюта котирования рыночных цен.
- `IsStreamingEnabled` - получать данные в реальном времени через WebSocket.
