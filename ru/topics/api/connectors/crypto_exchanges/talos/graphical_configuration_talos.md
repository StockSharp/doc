# Графическое конфигурирование Talos

Для всех продуктов [S\#](../../../../api.md) графическая настройка подключения выполняется в экранной форме [Окно настройки подключений](../../../graphical_user_interface/connection_settings_window.md):

- `Address` - адрес и порт FIX-сервера, выданные Talos.
- `SenderCompId` - идентификатор отправителя FIX.
- `TargetCompId` - идентификатор получателя FIX.
- `Login` - имя пользователя сеанса FIX.
- `Password` - пароль сеанса FIX.
- `ClientCode` - код клиента для маршрутизации по счетам.
- `TargetHost` - имя узла в сертификате TLS.
