# Настройки коннектора PancakeSwap

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `GraphApiKey` - ключ API The Graph.
- `WalletAddress` - адрес блокчейн-кошелька.
- `PrivateKey` - закрытый ключ для подписи транзакций.
- `Chain` - сеть блокчейна для выполнения запросов.
- `RpcEndpoint` - адрес RPC-узла блокчейна.
