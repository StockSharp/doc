# Настройки коннектора Orderly Network

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `AccountId` - идентификатор торгового счета.
- `Secret` - секретный ключ API.
- `RestEndpoint` - адрес REST API.
- `PublicWebSocketEndpoint` - адрес общедоступного WebSocket рыночных данных.
