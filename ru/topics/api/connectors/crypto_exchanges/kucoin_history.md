# История Kucoin

**История Kucoin** — сервис загрузки публичных исторических рыночных данных биржи Kucoin.

Перед началом работы рекомендуется ознакомиться со ссылками в разделе [Коннекторы](../../connectors.md).

> [!CAUTION]
> Коннектор поддерживает только рыночные данные; транзакции не поддерживаются.
