# Настройки коннектора: CoinTR

Перед подключением к CoinTR задайте перечисленные ниже свойства адаптера. Список проверен по реализации [CoinTRMessageAdapter](xref:StockSharp.CoinTR.CoinTRMessageAdapter).

## Основные настройки

Эти параметры показываются первыми в редакторе подключения.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `Passphrase` (`SecureString`)
- `RestEndpoint` (`string`)
- `PublicWebSocketEndpoint` (`string`)
- `PrivateWebSocketEndpoint` (`string`)
