# Настройки коннектора Ourbit

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `Key` - ключ API.
- `Secret` - секретный ключ API.
- `SpotRestEndpoint` - адрес REST API.
- `SpotWsEndpoint` - адрес сервера WebSocket.
- `FuturesRestEndpoint` - адрес REST API.
- `FuturesWsEndpoint` - адрес сервера WebSocket.
