# Настройки коннектора: BigONE

Перед подключением к BigONE задайте перечисленные ниже свойства адаптера. Список проверен по реализации [BigOneMessageAdapter](xref:StockSharp.BigOne.BigOneMessageAdapter).

## Основные настройки

Эти параметры показываются первыми в редакторе подключения.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `SpotRestEndpoint` (`string`)
- `SpotWebSocketEndpoint` (`string`)
- `ContractRestEndpoint` (`string`)
- `ContractWebSocketEndpoint` (`string`)
- `ContractPrivateWebSocketEndpoint` (`string`)
