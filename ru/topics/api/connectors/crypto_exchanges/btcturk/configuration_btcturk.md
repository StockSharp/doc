# Настройки коннектора: BtcTurk

Перед подключением к BtcTurk задайте перечисленные ниже свойства адаптера. Список проверен по реализации [BtcTurkMessageAdapter](xref:StockSharp.BtcTurk.BtcTurkMessageAdapter).

## Основные настройки

Эти параметры показываются первыми в редакторе подключения.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `GraphEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
