# Dexalot

**Dexalot** подключает StockSharp к биржевому стакану Dexalot, работающему в блокчейне. Адаптер предоставляет поддерживаемые рыночные данные и транзакционные операции через стандартную модель сообщений StockSharp.

## Основные возможности

- Возможности адаптера, проверенные по исходному коду: обновления данных в реальном времени, котировки Level 1, обезличенные сделки, стаканы заявок, свечные данные, запросы исторических данных, портфельные и торговые операции.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для мониторинга рынков Dexalot, анализа котировок, сделок, стаканов и свечей, запроса истории и отправки поддерживаемых заявок.

Доступные пары, глубина данных, разрешения на транзакции, лимиты запросов и доступность сервиса определяются Dexalot и подключённым кошельком.
