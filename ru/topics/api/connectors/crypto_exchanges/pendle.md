# Pendle

**Pendle** подключает StockSharp к рынкам доходности Pendle в поддерживаемых сетях EVM. Адаптер предоставляет поддерживаемые рыночные данные и транзакционные операции через стандартную модель сообщений StockSharp.

## Основные возможности

- Возможности адаптера, проверенные по исходному коду: обновления данных в реальном времени, котировки Level 1, свечные данные, запросы исторических данных, портфельные и торговые операции.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для мониторинга рынков доходности Pendle, анализа котировок и свечей, запроса истории и выполнения транзакционных сценариев, реализованных адаптером протокола.

Доступные сети, рынки, разрешения на транзакции, лимиты запросов и доступность сервиса определяются Pendle и подключённым кошельком.
