# Настройки коннектора: WazirX

Перед подключением к WazirX задайте перечисленные ниже свойства адаптера. Список проверен по реализации [WazirXMessageAdapter](xref:StockSharp.WazirX.WazirXMessageAdapter).

## Основные настройки

Эти параметры показываются первыми в редакторе подключения.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `ReceiveWindow` (`long`)
- `PrivatePollingInterval` (`TimeSpan`)
