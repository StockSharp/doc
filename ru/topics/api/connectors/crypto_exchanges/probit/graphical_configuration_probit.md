# Графическая настройка ProBit Global

Во всех продуктах [S#](../../../../api.md) графическая настройка подключения выполняется в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md):

- `Key` — идентификатор клиента OAuth.
- `Secret` — секрет клиента OAuth.
- `RestEndpoint` — адрес REST API.
- `AuthEndpoint` — адрес конечной точки получения токена OAuth.
- `WebSocketEndpoint` — адрес сервера WebSocket.

Для публичных рыночных данных учётные данные необязательны, а для торговли и приватных данных счёта обязательны.
