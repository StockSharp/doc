# Настройки коннектора: Coinmetro

Перед подключением к Coinmetro задайте перечисленные ниже свойства адаптера. Список проверен по реализации [CoinmetroMessageAdapter](xref:StockSharp.Coinmetro.CoinmetroMessageAdapter).

## Основные настройки

Эти параметры показываются первыми в редакторе подключения.

- `Token` (`SecureString`)
- `IsDemo` (`bool`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `DemoRestEndpoint` (`string`)
- `DemoWebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
