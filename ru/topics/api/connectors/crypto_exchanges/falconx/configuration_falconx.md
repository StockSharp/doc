# Настройки коннектора FalconX

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `ApiKey` - ключ API.
- `Secret` - секретный ключ API.
- `Passphrase` - кодовая фраза API.
- `ApiEndpoint` - адрес API сервиса.
- `PriceSocketEndpoint` - адрес WebSocket цен FalconX.
- `OrderSocketEndpoint` - адрес WebSocket заявок FalconX.
