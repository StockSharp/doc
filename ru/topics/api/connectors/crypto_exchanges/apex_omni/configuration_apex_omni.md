# Настройки коннектора ApeX Omni

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `Key` - ключ API.
- `Secret` - секретный ключ API.
- `Passphrase` - кодовая фраза API.
- `Seeds` - начальное значение zkLink для подписи заявок.
- `Environment` - среда подключения: основная или тестовая сеть.
- `RestEndpoint` - адрес REST API.
- `WebSocketEndpoint` - адрес WebSocket API.
- `MarketDepth` - запрашиваемое количество уровней стакана.
