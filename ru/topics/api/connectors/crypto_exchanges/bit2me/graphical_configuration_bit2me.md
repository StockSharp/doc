# Графическое конфигурирование Bit2Me

Во всех продуктах [S#](../../../../api.md) графическая настройка выполняется в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md):

- `Key` — API-ключ Bit2Me для приватных операций.
- `Secret` — секрет API Bit2Me.
- `RestEndpoint` — адрес REST API.
- `WebSocketEndpoint` — адрес WebSocket.

Для получения только публичных рыночных данных оставьте `Key` и `Secret` пустыми. Для торговли и данных счёта задайте оба значения.
