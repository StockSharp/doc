# Chainflip

**Chainflip** подключает StockSharp к межсетевой сети ликвидности Chainflip. Адаптер предоставляет поддерживаемые рыночные данные и транзакционные операции через стандартную модель сообщений StockSharp.

## Основные возможности

- Возможности адаптера, проверенные по исходному коду: обновления данных в реальном времени, котировки Level 1, обезличенные сделки, стаканы заявок, портфельные и торговые операции.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для мониторинга пулов ликвидности Chainflip, анализа исполняемых котировок и стаканов заявок, а также выполнения межсетевых обменов, реализованных адаптером.

Доступные активы, целевые сети, разрешения на транзакции, лимиты запросов и доступность сервиса определяются Chainflip и подключённым кошельком.
