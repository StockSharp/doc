# Графическое конфигурирование THORChain

Для всех продуктов [S\#](../../../../api.md) графическая настройка подключения выполняется в экранной форме [Окно настройки подключений](../../../graphical_user_interface/connection_settings_window.md):

- `WalletAddress` - общедоступный адрес блокчейн-кошелька для получения балансов и выставления заявок.
- `PrivateKey` - закрытый ключ для локальной подписи транзакций.
- `MidgardEndpoint` - адрес API THORChain Midgard.
- `ThornodeEndpoint` - адрес REST API THORChain Thornode.
