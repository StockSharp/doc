# Настройки коннектора: BitoPro

Перед подключением к BitoPro задайте перечисленные ниже свойства адаптера. Список проверен по реализации [BitoProMessageAdapter](xref:StockSharp.BitoPro.BitoProMessageAdapter).

## Основные настройки

Эти параметры показываются первыми в редакторе подключения.

- `Email` (`string`)
- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
