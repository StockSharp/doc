# Настройки коннектора VALR

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `Key` - ключ API.
- `Secret` - секретный ключ API.
- `SubAccountId` - идентификатор субсчёта.
- `RestEndpoint` - адрес REST API.
- `TradeWebSocketEndpoint` - адрес сервера WebSocket.
- `AccountWebSocketEndpoint` - адрес сервера WebSocket.
