# Настройки коннектора BloFin

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `Key` - ключ API.
- `Secret` - секретный ключ API.
- `Passphrase` - кодовая фраза API.
- `IsDemo` - режим демонстрационной среды.
- `RestEndpoint` - адрес REST API.
- `PublicWsEndpoint` - адрес сервера WebSocket.
- `PrivateWsEndpoint` - адрес сервера WebSocket.
