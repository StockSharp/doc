# CoinSpot

**CoinSpot** подключает StockSharp к криптовалютной платформе CoinSpot. Адаптер предоставляет API провайдера через стандартную модель сообщений StockSharp.

## Основные возможности

- Возможности адаптера, проверенные по исходному коду: обновления данных в реальном времени, котировки Level 1, стаканы Level 2, обезличенные сделки, запросы исторических данных, портфельные и торговые операции.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для торговых роботов, терминалов, сборщиков данных, сервисов управления заявками и мониторинга криптовалютных рынков.

Доступные инструменты, глубина данных, разрешения на транзакции, лимиты запросов и доступность сервиса определяются CoinSpot, тарифом API и правами подключённого счёта.
