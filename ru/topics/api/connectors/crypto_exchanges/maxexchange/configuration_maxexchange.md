# Настройки коннектора: MAX Exchange

Перед подключением к MAX Exchange задайте перечисленные ниже свойства адаптера. Список проверен по реализации [MaxExchangeMessageAdapter](xref:StockSharp.MaxExchange.MaxExchangeMessageAdapter).

## Основные настройки

Эти параметры показываются первыми в редакторе подключения.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
