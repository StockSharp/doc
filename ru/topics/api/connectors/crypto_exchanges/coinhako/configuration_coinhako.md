# Настройки коннектора Coinhako

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `Key` - ключ API.
- `Secret` - секретный ключ API.
- `RestEndpoint` - адрес REST API.
- `CounterCurrencies` - валюты котирования, для которых запрашиваются рынки.
- `PollingInterval` - интервал между запросами к сервису.
