# Графическое конфигурирование: 0x

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

Основной раздел редактора подключения содержит:

- `ApiKey`
- `Chain`
- `WalletAddress`
- `PrivateKey`
- `ApiEndpoint`
- `RpcEndpoint`

Остальные свойства задаются в расширенном режиме и описаны на странице [Настройки коннектора](configuration_zero_x.md). Не меняйте заполненные адреса провайдера, если он не выдал другие значения.
