# Графическое конфигурирование Reya

Для всех продуктов [S\#](../../../../api.md) графическая настройка подключения выполняется в экранной форме [Окно настройки подключений](../../../graphical_user_interface/connection_settings_window.md):

- `WalletAddress` - общедоступный адрес блокчейн-кошелька для операций со счетом.
- `AccountId` - идентификатор торгового счета.
- `PrivateKey` - закрытый ключ для локальной подписи запросов и транзакций.
- `RestEndpoint` - адрес REST API.
- `WebSocketEndpoint` - адрес WebSocket API.
