# Настройки коннектора: Quidax

Перед подключением к Quidax задайте перечисленные ниже свойства адаптера. Список проверен по реализации [QuidaxMessageAdapter](xref:StockSharp.Quidax.QuidaxMessageAdapter).

## Основные настройки

Эти параметры показываются первыми в редакторе подключения.

- `Token` (`SecureString`)
- `UserId` (`string`)
- `RestEndpoint` (`string`)
- `PollingInterval` (`TimeSpan`)
