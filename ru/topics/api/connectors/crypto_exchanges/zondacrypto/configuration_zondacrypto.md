# Настройки коннектора: zondacrypto

Перед подключением к zondacrypto задайте перечисленные ниже свойства адаптера. Список проверен по реализации [ZondaCryptoMessageAdapter](xref:StockSharp.ZondaCrypto.ZondaCryptoMessageAdapter).

## Основные настройки

Эти параметры показываются первыми в редакторе подключения.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
- `PrivatePollingInterval` (`TimeSpan`)
