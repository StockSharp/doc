# Графическое конфигурирование Tapbit

Для всех продуктов [S\#](../../../../api.md) графическая настройка подключения выполняется в экранной форме [Окно настройки подключений](../../../graphical_user_interface/connection_settings_window.md):

- `Key` - ключ API.
- `Secret` - секретный ключ API.
- `Sections` - разделы рынка, включённые для запросов к API.
- `SpotRestEndpoint` - адрес REST API.
- `FuturesRestEndpoint` - адрес REST API.
- `WebSocketEndpoint` - адрес сервера WebSocket.
