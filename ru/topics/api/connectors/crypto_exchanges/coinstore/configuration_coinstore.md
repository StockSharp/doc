# Настройки коннектора: Coinstore

Перед подключением к Coinstore задайте перечисленные ниже свойства адаптера. Список проверен по реализации [CoinstoreMessageAdapter](xref:StockSharp.Coinstore.CoinstoreMessageAdapter).

## Основные настройки

Эти параметры показываются первыми в редакторе подключения.

- `Key` (`SecureString`)
- `Secret` (`SecureString`)
- `RestEndpoint` (`string`)
- `WebSocketEndpoint` (`string`)
