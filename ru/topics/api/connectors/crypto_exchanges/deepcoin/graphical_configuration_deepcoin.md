# Графическое конфигурирование Deepcoin

Для всех продуктов [S\#](../../../../api.md) графическая настройка подключения выполняется в экранной форме [Окно настройки подключений](../../../graphical_user_interface/connection_settings_window.md):

- `Key` - ключ API.
- `Secret` - секретный ключ API.
- `Passphrase` - кодовая фраза API.
- `RestEndpoint` - адрес REST API.
- `SpotWsEndpoint` - адрес сервера WebSocket.
- `SwapWsEndpoint` - адрес сервера WebSocket.
- `PrivateWsEndpoint` - адрес сервера WebSocket.
