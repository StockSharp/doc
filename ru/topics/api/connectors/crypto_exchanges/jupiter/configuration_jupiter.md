# Настройки коннектора Jupiter

В настройках коннектора укажите параметры подключения, выданные сервисом.

## Параметры подключения

- `ApiKey` - ключ API для доступа к сервису.
- `WalletAddress` - общедоступный адрес блокчейн-кошелька для получения балансов и выставления заявок.
- `PrivateKey` - закрытый ключ для локальной подписи транзакций.
