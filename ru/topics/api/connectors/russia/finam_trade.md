# Finam Trade API

**Коннектор Finam Trade API** подключает приложения StockSharp к брокерским счетам и рыночным данным Финама. Инструменты, котировки, заявки, сделки и состояние портфеля преобразуются в единую модель сообщений StockSharp.

## Основные возможности

- Поиск доступных через Финам акций, облигаций, валют, фондов, фьючерсов и опционов.
- Котировки Level 1, стаканы заявок, публичные сделки и свечи по временным интервалам.
- Запрос исторических свечей и подписки на рыночные данные в реальном времени.
- Выставление рыночных, лимитных, стоп- и стоп-лимитных заявок, а также снятие заявок.
- Обновления состояний заявок, собственных сделок, денежных остатков и позиций.
- Автоматический обмен секрета API на короткоживущий токен сессии.
- Настраиваемые адреса REST и WebSocket для совместимых шлюзов и тестовых сред.

## Для чего подходит

Коннектор можно использовать в торговых роботах, терминалах, системах контроля портфеля и сервисах управления заявками, которым нужен единый интерфейс StockSharp для рыночных данных и торговли через Финам.

Для подключения требуется секрет Finam Trade API. Торговый счёт можно указать явно или оставить идентификатор пустым, чтобы использовать первый доступный токену счёт. Инструменты задаются в формате Финама `ticker@MIC`. Доступные рынки, глубина истории, данные реального времени, торговые права и лимиты запросов зависят от подключённого счёта и условий сервиса Финама.
