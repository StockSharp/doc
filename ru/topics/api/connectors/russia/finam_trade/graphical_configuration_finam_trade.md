# Графическое конфигурирование: Finam Trade API

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

Основной раздел редактора подключения содержит:

- `Token`
- `AccountId`

В расширенном режиме задаются `AppId`, `PollingInterval`, `LookupLimit`, `RestAddress` и `WebSocketAddress`. Назначение и значение по умолчанию каждого поля описаны на странице [Настройки коннектора](configuration_finam_trade.md).

Отдельный скриншот для коннектора не приводится: в исходниках Finam Trade нет реального снимка интерфейса продукта. Используйте приведённый выше список полей и стандартное окно настройки подключений.
