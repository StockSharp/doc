# Настройки коннектора: Finam Trade API

Перед подключением к Финаму задайте перечисленные ниже свойства. Список проверен по реализации [FinamTradeMessageAdapter](xref:StockSharp.FinamTrade.FinamTradeMessageAdapter).

## Основные настройки

Эти параметры показываются первыми в редакторе подключения.

- `Token` (`SecureString`) — обязательный секрет Finam Trade API. Адаптер обменивает его на короткоживущий токен сессии.
- `AccountId` (`string`) — необязательный идентификатор торгового счёта. Если он пуст, адаптер использует первый доступный токену счёт.

## Дополнительные настройки

- `AppId` (`string`) — идентификатор приложения, передаваемый при создании сессии. Значение по умолчанию — `StockSharp`.
- `PollingInterval` (`TimeSpan`) — интервал опроса снимков счёта и заявок. По умолчанию — 30 секунд; значения меньше одной секунды не допускаются.
- `LookupLimit` (`int`) — максимальное число инструментов при поиске без ограничений. Значение по умолчанию — `10000`, оно должно быть положительным.
- `RestAddress` (`string`) — базовый адрес REST API. По умолчанию — `https://api.finam.ru/`.
- `WebSocketAddress` (`string`) — адрес WebSocket API. По умолчанию — `wss://api.finam.ru/ws`.

Не меняйте заполненные адреса, если Финам или совместимый шлюз не выдал другие значения.
