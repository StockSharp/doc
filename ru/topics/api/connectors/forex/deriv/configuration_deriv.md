# Настройки коннектора: Deriv

Создайте токен Deriv и укажите параметры подключения.

- `Token` — персональный токен доступа или OAuth-токен. Обязателен для закрытых операций.
- `AppId` — идентификатор приложения, передаваемый в авторизованных REST-запросах.
- `AccountId` — идентификатор опционного счёта. Необязателен, когда выбранному режиму соответствует ровно один активный счёт.
- `IsDemo` — выбор демо-счёта. Значение по умолчанию: `true`.
- `RestAddress` — конечная точка REST. Значение по умолчанию: `https://api.derivws.com`.
- `PublicWebSocketAddress` — публичная конечная точка WebSocket для опционов. Значение по умолчанию: `wss://api.derivws.com/trading/v1/options/ws/public`.

Публичные сессии рыночных данных работают без токена, а для контрактов, балансов и транзакций требуются токен и идентификатор приложения. Подписки восстанавливаются автоматически через новый одноразовый адрес WebSocket.

Параметры контракта передаются через [DerivOrderCondition](xref:StockSharp.Deriv.DerivOrderCondition): тип контракта, признак того, является ли сумма ставкой или выплатой, валюта контракта, длительность, барьеры, а также защитные цены стоп-лосса и тейк-профита.
