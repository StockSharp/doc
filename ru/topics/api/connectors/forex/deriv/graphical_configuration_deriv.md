# Графическое конфигурирование: Deriv

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

Введите токен и идентификатор приложения. Для демонстрационного счёта включите `IsDemo`. Оставьте поле `AccountId` пустым, если токену соответствует единственный активный счёт для выбранного режима. Оставьте стандартные адреса REST и WebSocket, если Deriv не выдал другие.
