# Настройки коннектора: DukasCopy Live

Подготовьте локальный шлюз или клиент поставщика и укажите параметры подключения.

- `Login` - идентификатор счёта или клиента.
- `Password` - учётные данные для авторизации.
- `IsDemo` - переключатель поведения коннектора. Значение по умолчанию: `true`.
- `BridgePort` - TCP-порт локального моста. Значение по умолчанию: `27431`.
- `BridgeJarPath` - путь к локальному файлу или каталогу.
