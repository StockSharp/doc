# Deriv

**Deriv** подключает StockSharp к официальным REST и WebSocket API Deriv Options.

Коннектор поддерживает поиск активных инструментов, Level 1, историю тиков, потоковые тики, а также исторические свечи и свечи реального времени по таймфреймам. Торговля включает предложения по контрактам, покупку контрактов, досрочную продажу или отмену, обновления контрактов в реальном времени, балансы, портфели, открытые контракты и поток транзакций.

Рыночные данные доступны без учётных данных. Для авторизованной работы с демо- или реальным счётом создайте персональный токен доступа или OAuth-токен и идентификатор приложения.
