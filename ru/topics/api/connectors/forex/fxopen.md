# FXOpen TickTrader

**FXOpen TickTrader** подключает StockSharp к официальному TickTrader Web API.

Коннектор поддерживает поиск инструментов, Level 1, стакан, исторические свечи и свечи реального времени, портфели, позиции, заявки и исполнения. Рыночные данные поступают через канал WebSocket рыночных данных, а изменения счёта и исполнений — через канал WebSocket торговых операций.

Для потоковых данных и торговли предварительно создайте токен Web API в FXOpen. Публичные REST-данные доступны без учётных данных.
