# Графическое конфигурирование: MetaApi

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

Введите токен и идентификатор развёрнутого счёта. Поле `Region` заполняйте только для токена, привязанного к счёту. Оставьте стандартный домен, если MetaApi не выдал другой, и увеличьте `SynchronizationTimeout` для счетов с длинной историей.
