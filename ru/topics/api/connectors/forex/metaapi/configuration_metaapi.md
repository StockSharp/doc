# Настройки коннектора: MetaApi

Создайте токен MetaApi, разверните торговый счёт и укажите параметры подключения.

- `Token` — токен доступа MetaApi.
- `AccountId` — идентификатор развёрнутого счёта MetaApi.
- `Region` — регион счёта. Для токенов API он определяется автоматически, поэтому задавайте его явно только для токенов, привязанных к счёту.
- `Domain` — домен MetaApi. Значение по умолчанию: `agiliumtrade.agiliumtrade.ai`.
- `SynchronizationTimeout` — время ожидания синхронизации терминала на стороне сервера. Значение по умолчанию: 2 минуты, меньшие значения повышаются до 10 секунд.

Подключение считается завершённым, когда MetaApi сообщает о синхронизированном состоянии терминала, поэтому времени ожидания должно хватать на первоначальную синхронизацию истории счёта.

Параметры отложенных заявок и защиты позиции передаются через [MetaApiOrderCondition](xref:StockSharp.MetaApi.MetaApiOrderCondition): цена активации, цены стоп-лосса и тейк-профита, а также магический номер, комментарий и клиентский идентификатор, сохраняемые вместе с позицией.
