# Настройки коннектора: StocksTrader

Сгенерируйте токен в веб-терминале StocksTrader и укажите параметры подключения.

- `Token` — bearer-токен, выданный веб-терминалом.
- `AccountId` — идентификатор счёта. Необязателен, когда выбранному режиму соответствует ровно один счёт.
- `IsDemo` — выбор демо-счёта. Значение по умолчанию: `true`.
- `Address` — конечная точка REST. Значение по умолчанию: `https://api.stockstrader.com/`.
- `PollingInterval` — частота запроса заявок, сделок и состояния счёта. Значение по умолчанию: 5 секунд, меньшие значения повышаются до 2 секунд.

Поскольку провайдер не предоставляет потоковых данных, `PollingInterval` определяет, насколько быстро изменения заявок и позиций доходят до стратегии. Уменьшайте его для активной торговли и увеличивайте, чтобы не выходить за лимиты запросов провайдера.

Защитные цены передаются через [StocksTraderOrderCondition](xref:StockSharp.StocksTrader.StocksTraderOrderCondition): цены стоп-лосса и тейк-профита заявки или открытой позиции.
