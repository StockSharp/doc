# Графическое конфигурирование: StocksTrader

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

Введите токен, выданный веб-терминалом. Для демонстрационного счёта включите `IsDemo`. Оставьте поле `AccountId` пустым, если токену соответствует единственный счёт для выбранного режима. Оставьте стандартный адрес, если StocksTrader не выдал другую конечную точку, и задайте в `PollingInterval` требуемую частоту обновления.
