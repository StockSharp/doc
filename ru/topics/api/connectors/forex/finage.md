# Finage

**Finage** подключает StockSharp к Forex REST- и WebSocket API Finage.

## Основные возможности

- Возможности, проверенные по исходному коду: поиск инструментов, котировки Level 1 в реальном времени и исторические свечи. Адаптер предоставляет только рыночные данные и не поддерживает транзакции.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для поиска валютных пар, мониторинга живых котировок и загрузки истории свечей Forex.

Покрытие символов, доступ к данным в реальном времени, глубина истории, лимиты запросов и доступность зависят от тарифа Finage.
