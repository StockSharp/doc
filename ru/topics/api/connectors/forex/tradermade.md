# TraderMade

**TraderMade** подключает StockSharp к REST- и WebSocket API TraderMade для валютных и поддерживаемых криптовалютных пар.

## Основные возможности

- Возможности, проверенные по исходному коду: котировки Level 1 в реальном времени, опциональные стаканы TraderLadder, поиск инструментов и исторические свечи. Адаптер предоставляет только рыночные данные.
- Транспорт, сессии и форматы данных провайдера скрыты за стандартным API StockSharp.

## Для чего подходит

Коннектор подходит для мониторинга Forex в реальном времени, анализа доступной глубины и загрузки исторических свечей.

Символы, доступ к TraderLadder, данные выходных дней, лимиты запросов и доступность зависят от тарифа TraderMade.
