# Графическая настройка: DukasCopy JForex

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- `Login` - идентификатор счёта или клиента.
- `Password` - учётные данные для авторизации.
- `IsDemo` - переключатель поведения коннектора. Значение по умолчанию: `true`.
- `DemoAddress` - адрес JNLP-службы демо-среды Dukascopy.
- `LiveAddress` - адрес JNLP-службы рабочей среды Dukascopy.
- `BridgePort` - TCP-порт локального моста. Значение по умолчанию: `27431`.
- `BridgeJarPath` - путь к собранному JAR JForex-моста. Если поле пустое, мост необходимо запустить отдельно.

Для запуска JForex-моста требуется установленная Java. Мост принимает подключения только с локального компьютера.
