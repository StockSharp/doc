# Настройки коннектора: DukasCopy JForex

Установите Java, соберите JAR моста из каталога `Bridge` и укажите параметры подключения. Мост слушает только loopback-интерфейс, а к серверам Dukascopy подключается официальный JForex SDK.

- `Login` - идентификатор счёта или клиента.
- `Password` - учётные данные для авторизации.
- `IsDemo` - переключатель поведения коннектора. Значение по умолчанию: `true`.
- `DemoAddress` - адрес JNLP-службы демо-среды Dukascopy.
- `LiveAddress` - адрес JNLP-службы рабочей среды Dukascopy.
- `BridgePort` - TCP-порт локального моста. Значение по умолчанию: `27431`.
- `BridgeJarPath` - путь к собранному JAR официального JForex-моста. Если путь не задан, адаптер подключается к уже запущенному локальному мосту.
