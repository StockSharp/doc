# Графическое конфигурирование: FXOpen TickTrader

Во всех продуктах StockSharp подключение настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

Введите идентификатор, ключ и секрет токена Web API. Для демонстрационного счёта включите `IsDemo`. Поле `OneTimePassword` заполняйте только тогда, когда политика счёта требует двухфакторную аутентификацию. Оставьте стандартные адреса REST, WebSocket рыночных данных и WebSocket торговых операций, если FXOpen не выдал другие.
