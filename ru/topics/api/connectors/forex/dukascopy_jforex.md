# DukasCopy JForex

**DukasCopy JForex** подключает StockSharp к Dukascopy через официальный Java API **JForex SDK**. SDK устанавливает защищённое авторизованное соединение с торговыми серверами брокера, а .NET-адаптер StockSharp обменивается с ним сообщениями через локальный TCP-мост, доступный только на loopback-интерфейсе.

Публично поддерживаемого нативного транспорта JForex для .NET нет, поэтому коннектор не воспроизводит внутренний протокол брокера, а использует официальный клиент Dukascopy.

Коннектор поддерживает поиск инструментов, стаканы и сделки, исторические свечи, сведения о портфеле, регистрацию и отмену заявок. Для работы нужны Java и собранный JAR моста. Адреса demo/live-служб, путь к JAR и локальный порт задаются в настройках адаптера.

Перед разработкой торговых роботов ознакомьтесь с материалами раздела [Коннекторы](../../connectors.md).
