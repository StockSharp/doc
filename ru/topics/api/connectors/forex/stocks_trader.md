# StocksTrader

**StocksTrader** подключает StockSharp к официальному REST API StocksTrader.

Коннектор поддерживает обнаружение демо- и реальных счетов, опрос состояния счёта, поиск инструментов, а также последние снимки лучшей цены покупки, лучшей цены продажи и цены последней сделки. Торговля включает рыночные, лимитные и стоп-заявки, изменение и отмену отложенных заявок, изменение стоп-лосса и тейк-профита для открытых позиций, закрытие позиций, а также историю заявок и сделок.

У StocksTrader нет потокового API рыночных данных, поэтому запрос Level 1 возвращает последний доступный снимок и сразу завершается, а заявки, сделки и состояние счёта опрашиваются периодически.

Перед подключением создайте bearer-токен в веб-терминале StocksTrader.
