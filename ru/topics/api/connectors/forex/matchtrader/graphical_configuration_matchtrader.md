# Графическое конфигурирование Match-Trader

Для всех продуктов StockSharp графическая настройка подключения выполняется в экранной форме [Окно настройки подключений](../../../graphical_user_interface/connection_settings_window.md):

- `Address` - адрес REST API.
- `Login` - логин учётной записи.
- `Password` - пароль учётной записи.
- `BrokerId` - идентификатор брокера.
- `AccountId` - идентификатор счёта, назначенный сервисом.
