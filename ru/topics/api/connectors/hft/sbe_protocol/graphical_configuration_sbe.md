# Графическая настройка SBE

В продуктах StockSharp подключение SBE настраивается в [окне настройки подключений](../../../graphical_user_interface/connection_settings_window.md).

- `Address` - TCP-адрес SBE-сервера.
- `SenderCompId` - идентификатор клиента.
- `TargetCompId` - идентификатор целевого сервера.
- `Password` - учетные данные для аутентификации.
- `IsSupportNativeCandles` - включает подписку на нативные свечи.
