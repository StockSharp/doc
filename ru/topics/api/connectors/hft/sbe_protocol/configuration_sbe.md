# Настройка SBE

Настройте клиентское подключение с помощью параметров, выданных администратором SBE-сервера:

- `Address` - TCP-адрес SBE-сервера.
- `SenderCompId` - идентификатор клиента для входа.
- `TargetCompId` - идентификатор целевого сервера.
- `Password` - учетные данные для аутентификации.
- `IsSupportNativeCandles` - включает получение готовых свечей от сервера. Если параметр отключен, свечи строятся на клиенте из рыночных данных.

Сервер использует [SbeServerSettings](xref:StockSharp.Server.Sbe.SbeServerSettings):

- `IsEnabled` - включает конечную точку SBE.
- `Address` - адрес для приема подключений. Значение по умолчанию: `127.0.0.1:5002`.
- `HeartBeat` - интервал контроля сессии. Значение по умолчанию: 60 секунд.
- `TargetCompId` - идентификатор сервера. Значение по умолчанию: `StockSharp`.

Используйте на клиенте и сервере сборки с одинаковой версией схемы SBE.
