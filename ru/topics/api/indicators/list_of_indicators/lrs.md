# наклон линейной регрессии

Интерпретация индикатора **наклон линейной регрессии** показывает значение наклона линий регрессии, которые включают текущий ценовой бар и предыдущий n\-1 ценовой бар (где n \= периоды регрессии).

Для использования индикатора необходимо использовать класс [LinearRegSlope](xref:StockSharp.Algo.Indicators.LinearRegSlope).
