# SMA

**Простая скользящая средняя (SMA)** \- это арифметическое скользящее среднее, рассчитываемое путем добавления последних цен закрытия и деления этого числа на количество периодов времени.

Для использования индикатора необходимо использовать класс [SimpleMovingAverage](xref:StockSharp.Algo.Indicators.SimpleMovingAverage).
