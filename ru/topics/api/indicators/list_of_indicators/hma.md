# HMA

**Скользящая средняя Халла (HMA)** \- индикатор показывает направление рыночного тренда и представляет собой усовершенствованную скользящую среднюю.

Для использования индикатора необходимо использовать класс [HullMovingAverage](xref:StockSharp.Algo.Indicators.HullMovingAverage).
