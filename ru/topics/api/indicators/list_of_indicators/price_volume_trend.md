# PVT

**Тренд цены и объема (PVT)** — накопительный индикатор, который умножает изменение цены на объём и показывает давление покупателей или продавцов.

Для использования индикатора необходимо использовать класс [PriceVolumeTrend](xref:StockSharp.Algo.Indicators.PriceVolumeTrend).
