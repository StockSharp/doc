# оптимальное отслеживание

**Фильтр оптимального отслеживания** корректирует быстрые изменения цены и остается относительно плавным, когда цена движется боком. Работа этого фильтра аналогична адаптивной скользящей средней Кауфмана.

Для использования индикатора необходимо использовать класс [OptimalTracking](xref:StockSharp.Algo.Indicators.OptimalTracking).
