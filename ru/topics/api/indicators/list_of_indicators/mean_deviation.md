# Среднее отклонение

Индикатор **Среднее отклонение** показывает среднее отклонение цены от ее простого скользящего среднего (SMA) за определенный период.

Для использования индикатора необходимо использовать класс [MeanDeviation](xref:StockSharp.Algo.Indicators.MeanDeviation).
