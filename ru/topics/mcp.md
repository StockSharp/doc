# Подключение ИИ-агентов (MCP)

**MCP** (Model Context Protocol) — открытый протокол, по которому ИИ-агент (Claude Code, Claude Desktop или любой другой MCP-клиент) вызывает инструменты внешней программы — MCP-сервера. Клиент сам запускает сервер как дочерний процесс и обменивается с ним сообщениями через стандартный ввод и вывод. Сервер сообщает, какие у него есть инструменты, что каждый делает и какие параметры принимает, а агент решает, какой инструмент вызвать, и получает ответ.

Для программ StockSharp есть два MCP-сервера. Оба работают только на том же компьютере, что и программы, и связываются только с программами той же учётной записи пользователя.

| | [DesktopDriver](mcp/desktop_driver.md) | [Studio.Mcp](mcp/studio_mcp.md) |
|---|---|---|
| Что делает | читает интерфейс программы, нажимает кнопки, вводит текст, прокручивает, делает снимки | передаёт программе команды: выставить или снять заявку, запустить источник Hydra, запустить тестирование стратегии |
| С какими программами | Terminal, Hydra, Designer и Installer (Avalonia- и WPF-версии), Shell и UDP Dumper — только в сборке с включённой автоматизацией | Avalonia-версии Terminal, Hydra, Designer и Shell — в обычной сборке |
| Что видит агент | окна, панели, таблицы, графики, стаканы, редакторы свойств, схемы стратегий | только то, что возвращают команды: списки источников, стратегий и заявок |
| Ограничение на действия | нажатия и ввод принимает только программа, запущенная с тестовым профилем (кроме UDP Dumper, который принимает их всегда) | ограничения по профилю нет: заявка уходит туда, куда подключён Terminal |
| Где взять сервер | пакет NuGet `StockSharp.DesktopDriver.Mcp`, расширение для Claude Desktop | собирается из исходного кода |

## Какой сервер выбрать

- Нужно проверить, что показывает окно, пройти сценарий кнопками так, как это сделал бы человек, или получить снимок панели — [DesktopDriver](mcp/desktop_driver.md).
- Нужно, чтобы программа выполнила действие по команде, без нажатий: выставить заявку, запустить скачивание источником Hydra, запустить тестирование стратегии — [Studio.Mcp](mcp/studio_mcp.md).
- Программа собрана обычным образом, без автоматизации, — подойдёт только Studio.Mcp, и только для Avalonia-версий программ.
- WPF-версия программы — только DesktopDriver, и только в сборке с автоматизацией.

Оба сервера можно подключить к агенту одновременно. Например, Studio.Mcp запускает тестирование стратегии в Designer, но результатов не возвращает — их агент может прочитать с панелей Designer через DesktopDriver, если Designer собран с автоматизацией.

MCP — не то же самое, что [удалённое управление](shell/remote_control.md) с сайта и из [Telegram-бота](telegram_services/control_panel.md). Удалённое управление работает через учётную запись StockSharp и не требует ни агента, ни MCP-сервера.
