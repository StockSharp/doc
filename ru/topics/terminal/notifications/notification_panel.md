# Панель уведомлений

Панель **Уведомления** представляет собой таблицу, в которой отображается информация о всех заданных на текущий момент уведомлениях.

![Terminal панель уведомлений](../../../images/terminal_notifications_panel.png)

На панели **Уведомления** можно отредактировать существующее уведомление ![Designer создание хранилища исторических данных 01](../../../images/designer_creating_repository_of_historical_data_01.png), удалить его ![Designer создание хранилища исторических данных 02](../../../images/designer_creating_repository_of_historical_data_02.png) или задать новое уведомление ![Designer создание хранилища исторических данных 00](../../../images/designer_creating_repository_of_historical_data_00.png).
