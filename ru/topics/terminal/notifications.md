# Уведомления

[Terminal](../terminal.md) сообщает о важных событиях всплывающими окнами в углу экрана: подключение установлено или разорвано, своя сделка совершена, заявку не удалось снять. Ошибка подключения показывается окном с предупреждением.

О событиях заявок и подключения Terminal может сообщать и другими способами. Они выбираются в окне [Настройки](settings/common_settings.md) (**Настройки → Настройки**), в группе **Уведомление**, для каждого события отдельно:

- **Изменение заявки** — заявка изменилась;
- **Сведение** — заявка исполнена;
- **Ошибка** — заявка не принята;
- **Потеряно** и **Восстановлено** — соединение с подключением потеряно и восстановлено.

Для каждого события можно выбрать, как о нём сообщать:

- **Звук** – будет проигран звуковой сигнал.
- **Всплывающее окно** – в углу экрана появится маленькое окно с сообщением.
- **Лог-файл** – сообщение будет записано в журнал, его видно в [Панели Логи](user_interface/logs.md).
- **Телеграм** – сообщение будет отправлено в канал Telegram, который указывается в той же группе настроек. Каналы берутся из учётной записи StockSharp, поэтому для этого способа нужно войти на сайт.

Если способ не выбран, о событии не сообщается.
