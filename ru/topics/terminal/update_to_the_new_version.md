# Обновление на новую версию

Обновляйте Terminal через StockSharp Installer. В руководстве по обновлению описаны проверка доступных версий и установка обновлений программ.

[Обновление программ](../installer/update_apps.md)

Новый кроссплатформенный Terminal, запущенный впервые в папке настроек прежнего Terminal, раскладывает панели так, как их оставил прежний. Дальше он хранит свою раскладку сам.
