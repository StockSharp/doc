# Портфели

Для работы с портфелями существует панель **Портфели**. Открыть ее можно нажав на кнопку **Портфели** вкладки **Общее**.

![Designer панель портфелей 00](../../../images/designer_panel_portfolios_00.png)

Панель **Портфели** представляет собой таблицу, в которой отображены основные данные по портфелю и текущим позициям по этим портфелям. Нажав двойным щелчком на портфеле или позицию появится окно **Создание портфеля** или окно **Создание позиции**, в котором можно отредактировать выбранный портфель или позицию. Для создания нового портфеля или новой позиции необходимо нажать на кнопку ![Designer панель схем 01](../../../images/designer_panel_circuits_01.png), и в выпавшем меню выбрать соответствующий пункт.

![Designer панель портфелей 01](../../../images/designer_panel_portfolios_01.png)

Правый щелчок по строке открывает меню с пунктами **Редактировать**, **Закрыть позицию**, **Перевернуть позицию**, **Вывод** и **Скрывать нулевые балансы**; они описаны на странице [Портфели](../../terminal/user_interface/portfolios.md) Terminal.
